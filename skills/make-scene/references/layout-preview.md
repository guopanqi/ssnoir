# 布局预览图

目的：**让人和 Agent 在动手搭之前，对空间关系及其表达的情境达成一致**。它不是美术图，不用来当参考纹理，也不喂给 image-to-3D。

画图前先读对应的 Scheme / 剧情设计，想清楚故事在这里发生时，哪些信息适合由空间表达：人物如何相处、行动如何展开、某件事为什么会在这里发生，或这个地点平日如何运作。空间不必单独讲完剧情，但布局应支持这场戏，而不是一处与故事无关的漂亮背景。根据具体情景选择空间手段，不套用固定的人物站位或冲突模板。

## 提示词

- 明说 **单张独立图**（one single standalone image），否则会回来一张四格联络表。
- 视角固定为 **等轴俯视剖切**（isometric cutaway，约 35–45° 俯角）：朝镜头那面墙切到护墙板高，屋顶去掉。这和游戏机位一致，搭灰盒时可以直接对照。
- 写清 **尺度和比例**：长宽比、层高、哪面墙是窗、哪头是舞台/吧台/门。比例先于风格——见 `create-3d-assets/references/visual-definition.md` 的室内规则（上流社会室内 = Beaux-Arts 长厅，≥2:1、挑高；方厅均匀摆桌读成中式宴会厅，直接否）。
- 只写"**有什么、在哪**"，不写材质、灯光、氛围形容词——这些会挤掉空间信息。这一步不看已有资产，按这个地方最合适的东西想；复用是灰盒定了之后的事。
- 交锋里要落卡的每个分区（吧台、卡座、露台、沙龙圈、舞池）都要在图里有一块明确的地面。
- 提示词用可见的形体、位置、尺度、动线和留白表达故事所需的空间信息。具体要强调人物、建筑还是道具，由场景决定；不要依赖招牌文字、地面标记、光效或提示词中的抽象词替画面解释情境。

## 审图（Agent 先审，再给用户）

先做一次无文字读图：遮住标题和剧情说明，只看预览图，描述这个空间让人预期会发生怎样的事、它为故事提供了什么信息，再与具体剧情比较。若布局无法支持这场戏，即使画面漂亮、比例正确，也应改布局；不要留到模型精修时补救。接着检查游戏机位是否让承担表达的关键空间关系可见、清晰。

淘汰：拼贴/多格；不是剖切俯视；比例不对（方厅）；把门画成主角（等轴视角下门不重要，去掉更干净）；分区缺失或挤在一起；风格年代错（见 visual-definition.md）。

交给用户时附：图、一句「这张空间布局如何支持当前故事情景」、分区与尺度，以及要用户拍板的点。用户否决时把理由追加到 `prefabs/review/<名>/prompts.md`，编号递增（04、05、06…），最终依据那张标 APPROVED。

## 来自《别给他们想要的》

这场要读出酒馆一侧的人、家属和警察各自占位，尼尔处在他们之间，空街是随时可能被越过的缓冲带，记者能旁观并把冲突变成新闻。03 号虽然各方都能辨认，但开阔街段没有老街聚落的围合感；04 号用三面密楼、窄出口和内向门廊建立了这个地方的边界，同时保留各方关系，才成为灰盒依据。这里验证的是「局势和地点身份能否同时从空间读出」，不是给所有场景规定人群或围合街道。
