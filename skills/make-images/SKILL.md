# 制作 SSNoir 图片


## 共通基准

世界是上世纪美国黑色电影语境，内容虽用中文，画面不能出现中国物件。画面以轮廓、体块和高对比明暗传递信息；细节投入服从玩家在目标尺寸下真正需要读到的东西。

## 按用途判断

**舞台人物及姿势**：先读 [人物形象设定总表](../../角色库/人物形象设定总表.md)，再看该人物已有基础图和姿势图。保持身份剪影、体型、服装、主线与原有点缀色；新姿势只改表演所需的身体动作，不重新设计角色。黑底、镂空内部、白色霓虹主线是既有舞台语言。重要人物可有少量帮助识别和表演的内部线条；点缀色只用于已确立的身份或剧情象征，不因人物有姓名就自动加色。

一场戏先用现有姿势、走位、短促特效和音效编排。只有新姿势在目标画面尺寸下能传达这些手段无法传达的关系或状态变化，才生成新图；不要按动作的每一步拆图。主要人物可以有少量关键姿势，但新图的头身比例、画幅占比、脚底基线和朝向须与基础图及同场人物合拍。

**路人、黑影和其他背景人物**：他们承担人数、移动或环境气氛，而不是独立角色辨识。只保留可读的外轮廓，内部纯黑；不要面部、衣褶、口袋、衣领等内部线条，也不要点缀色。若剧情需要观众认出某人，就按重要人物设计，并明确这次身份升级；不要把背景人形悄悄画成主角级立绘。

次要人物的对峙、打斗和受击优先复用少量剪影，用相对距离、方向、节奏与特效表达；不要给每名酒客分别生成出拳、防守、后仰等动作图。

**2D 道具与场景图片**：先确定玩家需要辨认的功能、年代特征、轮廓和使用尺寸。重要道具突出一个可识别的形态或动作线索；背景小件压低细节和对比，不与主要人物争夺注意力。用途涉及 3D 建模参考图时，同时读取 [create-3d-assets 的视觉定义](../create-3d-assets/references/visual-definition.md)：主体完整、可建模、无遮蔽，结构信息优先于装饰。

## 生成与验收

项目图片当前**默认**使用 `tools/gemini-image-web`（Gemini Images / Nano Banana 2 网页适配器）：文生图用 `--prompt` / `--prompt-file`，调整已有形象用 `--reference` 加编辑指令。用法与鉴权看工具 README / `--help`；`--out` 可直接落到制作目录；同一浏览器 profile **不能并发**。服务不可用时报告阻塞，不自行切换到别的生图服务（含不擅自改回 `tools/tripo/image.py`）。需要保持人物身份或修改姿势时，输入已定稿的基础图，并在编辑指令中限制“只改什么、保留什么”。服务生成成功不代表符合项目风格。

审图时按目标画面尺寸检查外轮廓、主体完整性、主次层级、时代物件和角色一致性。重要人物若姿势可读但身份特征丢失，不合格。
