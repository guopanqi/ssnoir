# 制作 SSNoir 图片


## 共通基准

世界是上世纪美国黑色电影语境，内容虽用中文，画面不能出现中国物件。画面以轮廓、体块和高对比明暗传递信息；细节投入服从玩家在目标尺寸下真正需要读到的东西。

## 按用途判断

**舞台人物及姿势**：先读 [人物形象设定总表](../../角色库/人物形象设定总表.md)，再看该人物已有基础图和姿势图。保持身份剪影、体型和服装；新姿势只改表演所需的身体动作。用户于 2026-10-08 明确修正人物方向：以有实质填充的体块构成人物，再加克制的描线，与游戏建筑的视觉语言一致。外轮廓较重，内部线条只服务五官、衣领和关键动作；明暗用少量大面表达，颜色以深灰及低饱和身份色为主。不要继续把纯镂空、全线条 Neon 或彩色剪纸漫画作为新设计标准。现有 Neon 图仍可用于识别身份和姿势，属于历史资产；正式工程中尚未替换的资源不因这条新方向而自动覆盖。

夜莺保持已有形象的年轻、优雅与灵动。用户于 2026-10-08 明确否定显老的形象；画风探索不得擅自加入年龄数字、成熟疲惫神情、眼袋、皱纹、脸颊刻痕或松弛感。正常人物比例不代表老化面貌，黑白排线与网点优先放在衣料，不在脸部制造年龄痕迹。

一场戏先用现有姿势、走位、短促特效和音效编排。只有新姿势在目标画面尺寸下能传达这些手段无法传达的关系或状态变化，才生成新图；不要按动作的每一步拆图。主要人物可以有少量关键姿势，但新图的头身比例、画幅占比、脚底基线和朝向须与基础图及同场人物合拍。

基础立绘遵守人物形象设定总表中的「基础立绘的取景与尺度标准」：统一完整全身并包含双脚／鞋，统一画布、鞋底基线和绘制比例，保留角色相对高矮。禁止混用截腿图与全身图，禁止逐人裁紧后撑满画布来统一大小。缺失腿脚必须重绘；展示半身由镜头裁切处理。验收须在同一地面、同一显示尺度下并排比较。

旧姿势取景不合标准时，按标准基础图重新制作；不要在运行时按角色或姿势补偿缩放。使用 Gemini Image Web 编辑时只上传当前标准基础图作为身份与尺度参考，用文字描述旧姿势的动作；双参考容易让旧姿势的大取景覆盖尺度标准。生成后与基础图以同一画布并排审阅，坐姿、弯腰和奔跑须保持头部及肢体尺度，不能以轮廓总高度重新撑满。

**路人、黑影和其他背景人物**：他们承担人数、移动或环境气氛，而不是独立角色辨识。只保留可读的外轮廓，内部纯黑；不要面部、衣褶、口袋、衣领等内部线条，也不要点缀色。若剧情需要观众认出某人，就按重要人物设计，并明确这次身份升级；不要把背景人形悄悄画成主角级立绘。

次要人物的对峙、打斗和受击优先复用少量剪影，用相对距离、方向、节奏与特效表达；不要给每名酒客分别生成出拳、防守、后仰等动作图。

**2D 道具与场景图片**：先确定玩家需要辨认的功能、年代特征、轮廓和使用尺寸。重要道具突出一个可识别的形态或动作线索；背景小件压低细节和对比，不与主要人物争夺注意力。用途涉及 3D 建模参考图时，同时读取 [create-3d-assets 的视觉定义](../create-3d-assets/references/visual-definition.md)：主体完整、可建模、无遮蔽，结构信息优先于装饰。

## 生成与验收

优先使用 `tools/gemini-image-web`（Gemini Images / Nano Banana 2 网页适配器）；额度耗尽后使用 Tripo 的 `tools/tripo/image.py`，默认选择较便宜的 `banana2`。用法与鉴权看各工具 README / `--help`。Gemini 文生图用 `--prompt` / `--prompt-file`，调整已有形象用 `--reference` 加编辑指令；同一浏览器 profile 不能并发。需要保持人物身份时输入基础图，并限制只改什么、保留什么。视觉画风比较先用同一个姿势，不为每个动作生成新图。服务生成成功不代表符合项目风格。

审图时按目标画面尺寸检查外轮廓、主体完整性、主次层级、时代物件和角色一致性。重要人物若姿势可读但身份特征丢失，不合格。
