# 道具与参考图

## 2D 道具

先确定玩家需要辨认的功能、年代特征、轮廓和显示尺寸。重要道具突出可识别的形态或动作线索；背景小件压低细节和对比，不与主要人物争夺注意力。需要透明背景时检查实际 alpha 和边缘，不把纯色底或棋盘格当作透明资源。

## 场景概念与布局

与 [make-scene](../../make-scene/SKILL.md) 配合确定故事动作、体量、入口、通路、空间关系和机位；布局图读取其[布局预览](../../make-scene/references/layout-preview.md)，视觉组合读取[组合设计与审核](../../make-scene/references/visual-language.md)。

先检查空间和取景是否成立，再审视觉层级、时代物件与整体气氛。只要求图片探索时交付候选图，不自动进入建模。3D 色盘、配光和组合参数由场景侧维护。

## 单件资产建模参考

读取 [make-3d-asset 的视觉定义](../../make-3d-asset/references/visual-definition.md)。主体完整、结构明确、关键连接可见且无遮挡；造型信息优先于装饰。参考图不能证明网格、尺度或运行时材质正确，后续由资产制作流程判断。
