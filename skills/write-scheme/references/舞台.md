# 舞台：人物、声音与对白

线绘布景、可编程图形和布景灯光使用独立 `play-theatre!`，见 [线绘舞台](../../../docs/线绘舞台.md)。
其画面审阅使用 [Unity 线绘舞台预览](../../../tools/theatre/README.md)：从 Scheme 入口导出整场无声 GIF、序列帧和对白时间索引，先通看全场再检查局部原图。
它直接复用 Unity 绘制代码；游戏字幕排版、城市转场、实际声音和点击仍在 Play Mode 验收。下面的舞台序列图工具针对 `play-stage!`，不要混用两套入口。
`play-stage!` 仍用于原有立绘演出；不要把线绘指令混进它的拍点。

`play-stage!` 是连续的阻塞演出，`play-dialogue!` 是其中只由台词构成的简便入口。
公共层只提供对象与时间的基本动作；某一场戏的“三人穿场”等组合函数留在该场脚本里，
不要因为一场戏用到了就加进 `engine.scm`。

```scheme
(play-stage!
  (stage-spawn "尼尔" "尼尔" -5 'middle)
  (stage-say "尼尔" "这里怎么回事？")
  (stage-parallel
    (stage-move "尼尔" 0 0.4)
    (stage-sound "码头/急活" 7))
  (stage-remove "尼尔"))
```

舞台横轴以中心为 `0`，可见范围约 `-10..10`；画外可用到 `-30..30`。
位置是逻辑坐标，同一套版面用于所有平台。`stage-spawn` 给对象一个本场唯一 ID、
立绘资源名、横坐标和 `back` / `middle` / `front` 层；随后 `stage-move` 按秒移动，
`stage-remove` 才销毁对象。退场因此是 `move` 到画外后再 `remove`。
`stage-pose` 换姿势；`stage-light` 改 `normal` / `surge` / `faint` / `ember` 灯光状态；
`stage-sound` 从 `Resources/StageSounds/` 读取音频，横坐标决定左右声像，
音频开始播放后不延长这一拍；`stage-pause` 明确占用时间；`stage-remote-say` 用于电铃、电话等画外回应，显示对白框但不生成说话人；`stage-say` 显示对白并等点击。说话人 `"世界"` 是旁白：不需要也不应该 `stage-spawn`。

**舞台声 vs 对白声：** 画外令、齐声喊、环境里的人声若只要“听得见、不占对白框”，走 `stage-sound`（SFX 通道，`StoryStagePlayer`，不经 `DialogueVoicePlayer`）。需要名牌+对白框+点击推进时才用 `stage-say`（可选 VoiceId 走 `Resources/Voices/`）。`stage-sound` 不挡拍：台词长度用同拍的 `stage-pause`（或更长的 move）盖住。
普通指令顺序执行，`stage-parallel` 同时启动子指令，等最慢的移动或停顿结束。
并行分支不能同时改同一个对象的同一属性；配置错误会立即报错。
无字动作拍自动播完才进下一拍，点击和 ESC 都跳不过；只有 `stage-say` 拍等输入——
第一下补全打字机，第二下进下一句。

下面的 `line` 舞台指示仍用于 `play-dialogue!`。它适合两人对白中的姿势、灯光和短距离逼近；
需要多人进退场、剪影穿行或对白之间的无字动作时用 `play-stage!`。

`play-dialogue!` 不是对话框，是一场**霓虹立绘的人偶戏**。拿掉视频之后，人物的内心和状态几乎全靠
这个舞台来演；台词说的是事，舞台演的是人。它有这些表现手段：

- **身体**：姿势（换一张灯管图）和距离（逼近中央 / 退回边上）。这是观众一眼看懂的那层。
- **灯**：每个人是一块霓虹招牌，灯就是他的内心——亮度（灼 / 弱 / 残烛）、电流（呼吸 / 狂飙）、
  事件（颤 / 燃 / 黑）。
- **震**：情绪爆发那一下。
- **画面**：整个屏幕翻成负片（白热化的一段）、白闪一帧（枪声、耳光）。
- **听的人**：一句台词可以同时给对方下指示——他质问时她转过身、她讲往事时他点烟。
- **心里话**：没说出口的句子，没有框、没有名牌，是 noir 的画外音。
- **标志色**：人物灯管的点缀色可以随剧情变，表现观念的改变。

图库不限制剧情姿势；需要新人物图或姿势图时，按 [make-images](../../make-images/SKILL.md) 判断人物的视觉层级、既有形象和图片质量，再用当前 Tripo 生图入口制作。

### 用少量姿势编排动作

先确定每拍观众需要读到的关系变化，再选手段。对峙可以靠两人的间距和停顿成立；出手由主要人物的一张关键姿势、短促前移和音效标出；受击者稍后位移、闪光或震动，形成清楚的因果。次要人物优先复用无细节剪影，不为每次攻防换图。主要人物也只在姿态本身承载剧情信息时增加姿势，避免把连续动作逐帧画成图库。

同一拍不要把逼近、命中、反应全压在 `stage-parallel` 里；按出手、接触、受击拆出短暂时间差。特效和音效要落在接触点，位移方向与人物朝向一致。具体时长以画面试演调整，不能只看脚本是否顺序正确。

## 语法

台词后面接关键字对，每一项都是**终态**：写了就保持到下一句改它为止，没写的保持上一句的样子。

```scheme
(line "夜莺" "那都是五六年前的事了！" "语音id"
      :pose "逼近" :move 'in :light 'surge :shake #t)
(line "夜莺" "一个窝囊废。" "语音id" :pose "背身" :other :pose "点烟")
(line "尼尔" "我知道那个名字已经成了一枚钉子。" "语音id" :inner #t)
```

### 默认规则（不用写）

- 谁说话谁亮，听的人压暗到三成——他还在场，只是这句不是他的。
- 说话人 `surge` 时听者被压得更暗——谁的光占屏幕谁占上风。
- 人第一次开口时通电点亮；旁白句（`"世界"`）两个人都留在台上、都压暗。
- 尼尔永远在左，对手在右；右边只站一个人，新来的把上一个顶下台。

### 词

| 词 | 值 | 意思 |
|---|---|---|
| `:pose` | 姿势名字符串；`"基础"` 回招牌姿势 | 换一张灯管图。名字见下面的姿势表 |
| `:move` | `'in` / `'back` | 逼近舞台中央 / 退回自己那边 |
| `:light` | 亮度 `'normal` `'surge` `'faint` `'ember`；电流 `'still` `'pulse` `'racing`；事件 `'flicker` `'relight` `'blackout` | 灯。三个轴，同一句可各写一个：`:light 'surge :light 'racing :light 'flicker` |
| `:shake` | `#t` | 一震，带残影。只对说话人 |
| `:screen` | 状态 `'normal` `'negative`；事件 `'flash` | 整个画面。旁白也能下 |
| `:other` | 不带值，分隔符 | 它后面的 `:pose` `:move` `:light` `:shake` 落到台上另一个人身上。对方还没上台时 Console 报一声 |
| `:inner` | `#t` | 心里话：没有框、没有名牌，字直接落在夜色上。舞台照常认说话人 |

`:light` 各词的样子：

| 词 | 类型 | 灯的样子 |
|---|---|---|
| `surge` 灼 | 亮度 | 光晕撑开、光池炸开、这个人的颜色洗半个台。内在翻涌：怒、骄傲、下决心 |
| `faint` 弱 | 亮度 | 光晕全收，只剩细管。人还在灯没了：羞、退、认输 |
| `ember` 残烛 | 亮度 | 欠压的钨丝：管子发暗橙、没有光晕。消沉、绝望 |
| `normal` | 亮度 | 招牌本来的样子 |
| `pulse` 呼吸 | 电流 | 一两道亮光沿管子慢慢绕整个人一圈。平静地活着 |
| `racing` 狂飙 | 电流 | 好几道亮光又快又长在轮廓里狂奔。心跳加速 |
| `still` | 电流 | 不走 |
| `flicker` 颤 | 事件 | 接触不良：亮、死一段、打火、再死、回来，约两秒。被戳中、动摇 |
| `relight` 燃 | 事件 | 全灭，从脚到头一格一格重新点亮。回过神、"我在这儿" |
| `blackout` 黑 | 事件 | 整台黑半秒，两盏灯再一起亮。这句之前的沉默 |

`:screen 'negative`：世界翻成白底黑线、人物变成墨线、对白框墨底纸字。灯的语法在负片里换成纸上的
物理（surge 是墨渗开，faint 是墨淡了，flicker 是线断掉露出纸）。`'flash` 白闪一帧（负片里闪黑）。

### 标志色

```scheme
(set-portrait-accent! "林" "#8A5A2B")   ; CSS 十六进制；存档里跟着走
(set-global! "立绘色/林" #f)            ; 恢复默认
```

舞台在几秒里把颜色过渡过去，之后他的光晕、光池、洗台都是新颜色。


## 姿势

姿势图按 `Portraits/Neon/<人物>_<姿势>.png` 命名，写了不存在的姿势会在 Console 警告并保持当前姿势。
现有：

| 人物 | 姿势 |
|---|---|
| 夜莺 | `逼近` `背身` `低头` `仰头` `恳求` `抱臂` `掩面` `回眸` `坐` |
| 尼尔 | `逼近` `侧身退` `点烟` `摘帽` `抱臂` `背身` `伸手` `攥拳` `靠墙` |

其他人物目前只有基础图（莱恩、林、弗兰克、沃尔特、艾迪、薇拉、经理、黑影、路人）；贝恩斯有`回身` `朝右` `出脚` `立定` `低踢`。酒馆门前的酒客用无面部细节的路人剪影，以走位和短促特效演打斗。

### 要新姿势

1. 按 [make-images](../../make-images/SKILL.md) 设计、生成和审阅候选图；提示词与候选保存在 `角色库/<人>/形象/姿势/`，以人物基础图为身份参考。姿势应服务这场戏，不复制别人的表演。
2. 图片合格后复制到 `UnityClient/Assets/Resources/Portraits/Neon/<人>_<姿势>.png`，`.meta` 照抄同目录任一张
   姿势图的（改 guid）。
3. 离线加工，派生线稿、点缀蒙版和骨架（没跑的话标志色改不了、电流走不了）：
   ```bash
   python3 tools/portrait-neon/process.py 夜莺_<姿势>
   ```
   派生的 `.png` / `.json` 同样要 `.meta`。
4. 把姿势名加进上面的表。

## 试演

在进 Unity 前，用 [舞台序列图工具](../../../tools/stage-preview/README.md) 执行演出的 Scheme 入口，按真实拍点和素材生成关键帧与密集 contact sheet。Agent 先用带拍号、时间戳和对白摘要的索引图通看**完整演出**，再打开可疑拍的原尺寸单帧，核对出手、接触、回位、道具轨迹与全场空间关系。预览应尽量复现运行时的裁切和遮挡，不另造一套理想化排版。

逐帧检查主次人物的身高与头身比例、脚底是否齐地、朝向与接触距离、动作前后因果、道具在实际尺寸下是否可辨，以及对白区是否遮住关键信息。发现问题先调走位、时间和层级；只有关键姿态确实无法读懂时才增加图片。

准备让用户审核演出时，默认用工具的 `--gif` 导出整场低分辨率 GIF，连同序列帧提供；只检查局部动作才用 `--gif-beats 起始拍:结束拍`，并明确标注为片段。GIF 方便看整体节奏和位移，序列帧方便指出具体哪一拍有问题；无声 GIF 不用于验收音效。离线预览用于发现构图和节奏问题，最终仍以 Unity 试演验收实际灯光、特效和音效。

Play → 顶栏 Debug ▾ → 「舞台试演：…」不改任何状态直接演一段。自己的戏想这样试：把那段
`play-dialogue!` 拎成一个 define，在模块的消息表里加一个 `debug-*` 消息，再在
`DebugPanelDrawer.ChapterJumps` 加一行。范例见
[三封信.scm](../../../UnityClient/Assets/Resources/Content/scenes/world/三封信.scm) 的
`bridge-aftermath-dialogue!` 等。

时长、幅度、亮度档这些数字都在 `UnityClient/Assets/Scripts/Runtime/IMGUI/Stage/StageState.cs` 顶上，
内容里不写数字。
