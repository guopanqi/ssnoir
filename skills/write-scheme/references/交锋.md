# 写交锋

## 一、入场与场内转场

- **场内转折用阻塞式重对话。** 走完一段路线、敌人正式出面、局面换幕——这些真正改变题面的事件，
  用 `play-dialogue!` 交代过程，然后更新阶段状态、让下一份 render tree 接管场面。
  转场对话同样受锚定约束（见 [表现.md](表现.md)）：动作内只能让旧画面已有的角色说话；
  刚进入下一幕的角色若还没有锚点，先用"世界"叙述它的出现，或拆成下一幕里的独立对话。
- **`spotlight!` 只宣告结果。** 它适合交锋成功 / 失败 / 阶段结算这类告示卡，不承担人物对白，
  也不拿来替代换幕过程。
- **入场摆盘面用 `'load!`，不用 `'set!`。** `on-encounter-enter` 里把钟拨到初始格是摆盘子，
  不是玩家造成的变化；`'set!` 会写进发起交锋那个世界动作的报告，点进去先弹一张空的
  行动结果（曾经实测漏出过"踪迹 +3"）。`'load!` 静默设值，越界直接报错，正好拿来做初始化。
