# 写 SSNoir 内容

以下文件按职责拆分；小改不要求通读整套指南。

## 设计人物和故事

读取[故事与人物](references/1-story-and-characters.md)：故事的吸引力、人物生活与行动能力、关系建立、节奏，以及主线与支线的失败边界。

## 把故事编排成可玩的过程

读取[交互与情节编排](references/2-interaction-design.md)：行动颗粒度、持续投入、事项追踪、期限、承诺与防止阻塞。

## 写文案和选择表现载体

读取[文案与演出编排](references/3-writing-and-staging.md)：世界观语调、人物对白、手机文案预算，以及标注、观察、气泡和对白的用途。

## 落地代码

读取[引擎与 DSL](references/4-engine-and-dsl.md)：节点身份、Anchor、Clock、生命周期、配音资产和语言边界。接口以实际 [engine.scm](../../UnityClient/Assets/Resources/Content/scripts/engine.scm) 与解析器为准；用搜索读取相关定义，不凭指南猜参数。

实质工作、搜寻、调查默认投入骰子进行 Roll；明确指定的固定消耗交换使用 Instant。交谈、赴约、进入事件等按实际行为决定，不由按钮文字决定判定方式。

## 专项参考

需要具体能力、风险、工作或 Scenario 编排时，继续读取项目现有的[行动](references/行动.md)、[工作](references/工作.md)、[Scenario](references/Scenario.md)、[表现](references/表现.md)与[舞台](references/舞台.md)。
