# 非城市独立资产交付

本文件只适用于不进入整城的独立资产。城市地点建筑必须走 [make-scene 的城市交付](../../../make-scene/references/citybox-delivery.md)。

## 目录

- `Buildings/`：不属于 CityBox 的独立建筑或立面。
- `Environment/`：独立完整空间、地形或环境组合。
- `Props/`：可独立摆放的物件。
- `Vehicles/`：车辆和车辆系统资产。

按运行时职责分类，使用稳定名称；不要使用 `final2`、`new`、`修复版` 等过程名。

## 交付

1. 用户确认最终 Blender 预览后写入正式目录。
2. 优先保存 `.blend`；只有既有消费者明确要求时导出 `.fbx`。
3. 保留既有 `.meta`，不要伪造或替换 GUID。
4. 沿用现有消费者和导入契约时，检查 Blender 源资产、资源路径、语义节点和 `.meta`；普通交付不自动启动 Unity。新增/修改导入契约、Unity 专有表现改变、出现两端差异或用户明确要求时，才检查对应导入日志、VCam/Anchor 绑定或实际画面。两类证据分别报告，按 [验证边界](../../../../tools/VERIFYING.md#unity-验证边界) 选择。

最终报告包含正式路径、分类理由、几何统计、语义节点、执行过的验证和最终预览图。
