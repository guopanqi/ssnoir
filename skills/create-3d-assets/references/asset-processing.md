# 游戏化加工

## 几何

1. 保留生成器原文件，另存工作 `.blend`。
2. 删除生成器灯光、相机、隐藏残片和无意义 Empty；不要保留默认过程命名。
3. 使用 Metric，`1 Blender Unit = 1m`；地面放在 `Z=0`，原点和朝向可解释。
4. 调整最终尺寸后应用 Rotation/Scale，正式主体 Scale 为 `(1,1,1)`。
5. 检查 NaN/Inf、零面积面、非流形、孤立碎片、反法线、穿插、过薄结构和自定义分裂法线。
6. 记录顶点、面数及三角/四边/ngon 分布。不要用“低模”替代实际统计。

## 城市源与独立资产

- `city-box/models/*.blend` 只保存主体几何和语义节点。删除生成器或旧流程留下的描线对象；最终 Low/High 由 CityBox 生成。
- 非城市独立资产只有在其消费者确实需要时才运行专用描线脚本。先找到该消费者和现行脚本，不默认套用历史 `model-outline-handpaint.py`。
- 描线必须在全部几何变换完成后生成；若描线顶点处于世界坐标，移动主体后必须整体移动或重建。

## 语义节点

- 建筑根、`Anchor_<地点>`、`Camera_<地点>` 使用同一正式地点名。
- 行动空间使用 `Anchor_<地点>-<功能>`；角色跨地点使用 `Anchor_<实体>@<地点>`。
- Orbit 镜头加入 `orbit pivot`，放在相机实际注视的视觉重心；Anchor 是卡片投射位置，不能与 pivot 合并。
- Camera 必须直接看向其绑定 pivot，误差不超过 0.5°。避免非等比缩放破坏对齐。
- `Actor_*` 当前没有运行时消费者，不主动创建。

## 预览

- 资产预览使用能暴露入口、圆弧、薄片和遮挡的 3/4 视角，主体占画面约 75%–85%。
- 城市地点还要提供整城布局预览；单体正确不代表城市位置正确。
- 审批图显示最终主体与现行描线效果。wireframe/clay 只作为附加诊断图。
- 正式文件不保留预览 Light、Ground 或临时对象。

保存后用后台 Blender 重新打开并运行验证脚本；二进制可读、几何合格、语义契约和相机对齐是四项独立检查。
