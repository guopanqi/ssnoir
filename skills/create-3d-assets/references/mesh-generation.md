# 网格生成与质量门

本文件定义从确认参考图到可加工低模的统一阶段契约。输入是参考图、资产用途与预算；输出是可下载低模、预览和技术统计。

## 服务形态

- **直接低模**：一次生成可用低模，直接进入低模质量门。
- **高模再拓扑**：先生成高模确认形体，再通过 retopology 得到低模。高模是中间结果，不进入正式源。

服务选择不改变阶段契约。比较不同服务时使用同一参考图、预算口径和审计脚本。使用 Hunyuan 时读取 [providers/hunyuan.md](providers/hunyuan.md)；使用其他服务时读取其专用 Skill 或适配说明，不推断网页、API 或计费细节。

## 质量门

需要比较生成结果或判断是否能进入游戏化加工时运行：

```bash
blender --background model.blend \
  --python skills/create-3d-assets/scripts/audit_mesh_quality.py
```

按以下顺序判断：

1. **轮廓与体块**：入口、屋顶、圆弧和主要层级是否在目标镜头可读。数字再好也不能补救错误造型。
2. **表面起伏**：建筑平面中相邻面夹角 5°–20° 的比例过高，通常意味着 image-to-3D 噪声；近景会出现跟随三角面的脏明暗。
3. **拓扑健康**：检查非流形边、零面积面、孤立碎片、反法线和穿插。它们会使法线、简化和导出不稳定。
4. **着色数据**：生成器常带全 smooth 和自定义分裂法线。硬表面资产应清理自定义法线并按实际硬边重建。
5. **拓扑预算**：记录三角、四边和 ngon，而不是只看总面数。全三角不必然错误，但不能冒充已完成的四边低模。

米制尺度、应用 Rotation/Scale、正式命名和语义节点属于游戏化加工，不用来评价生成服务。旧资产的某次统计不是永久门槛；最终预算由资产用途和 CityBox 报告决定。

## 审阅输出

高模门只判断形体是否值得继续投入：轮廓、体块、结构完整性和明显生成伪影。低模门还要判断表面起伏、拓扑健康、法线、碎片和实际面数。

每次对外审阅提供 3/4 预览，必要时补侧视或俯视，并附顶点、面数与主要风险。低模确认后才进入游戏化加工。
