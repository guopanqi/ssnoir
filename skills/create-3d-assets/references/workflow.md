# 固定工具链与执行入口

## 职责与准确入口

不要根据搜索结果猜测工具，也不要因为 Codex 自带生图能力就改变职责。按以下入口执行：

| 职责 | 服务与入口 | 约束 |
|---|---|---|
| 撰写、审阅、迭代提示词 | Codex/GPT | 只产出文字并操作网页，不直接生成参考图 |
| 生成、编辑参考图 | [Gemini AI Studio](https://aistudio.google.com/prompts/new_chat) | 当前优先 Nano Banana Pro；图片必须来自这里 |
| 从图片生成原始模型 | [Hunyuan 3D Studio Geo](https://3d.hunyuan.tencent.com/studio/creation/geo) | 上传用户已确认的 Gemini 图片 |
| 低模拓扑 | [Hunyuan 3D Studio Poly](https://3d.hunyuan.tencent.com/studio/creation/poly) | 从最小档开始；优先四边面，但按资产用途选择合适的四边/三角组合 |
| 本地加工 | Blender | 运行项目脚本并建立 Unity 语义节点 |
| 正式交付 | `UnityClient/Assets/Resources/Models/` | 按职责选择子目录 |

优先使用 Codex 内置浏览器并复用其中已有的正确登录标签页；只有用户明确指定 Chrome 或内置浏览器无法使用时，才切换到 Chrome。否则直接打开上述 URL；不要通过网页搜索选择一个看似相关的 Gemini、Hunyuan、腾讯混元或第三方站点。入口无法使用时停止并说明，不自行换服务。

## 阶段产物

| 阶段 | 当前工具 | 必须交付给用户的内容 | 通过条件 |
|---|---|---|---|
| 提示词 | Codex/GPT；需要时使用用户指定的网页 GPT 配置 | 完整提示词与关键假设 | 时代、功能、轮廓和禁用项明确；此阶段不调用 Codex 生图 |
| 参考图 | Gemini AI Studio，当前优先 Nano Banana Pro | Gemini 原图或清晰截图 | 整体完整、不裁切、无时代穿帮、适合 image-to-3D |
| 原始模型 | Hunyuan 3D Studio Geo | 合适 3/4 角度预览 | 大体块、入口、圆弧和遮挡可接受 |
| 低模拓扑 | Hunyuan 3D Studio Poly | 低模预览与面数 | 拓扑组合与资产用途相称；从最小档开始，质量目标未通过只升一级 |
| 视觉加工 | Blender + 项目脚本 | 最终相机预览 | 尺寸、朝向、描边、材质和构图正确 |
| 语义节点加工 | Blender | 对象清单与契约校验 | Anchor/pivot/Actor 标记的名称、层级和变换正确；无需视觉预览 |
| 交付 | Unity `Resources/Models` | `.blend` 与 Unity 导入结果 | 导入无错误，VCam/Anchor/交互行为符合契约 |

模型名称和按钮会变化，因此 Nano Banana Pro 是当前偏好而不是永久型号。服务域名和职责是当前工作流约定；网页布局变化时重新检查可见控件，不复用旧坐标，也不因此换到其他网站。

## 快速执行策略

- 优先复用 Codex 内置浏览器的已登录会话，避免重复登录或无故切换浏览器。
- Gemini AI Studio Playground 中出现 `No API key selected` 时，不把它当作参考图生成的阻塞条件，也不要打开或操作“Link a paid API key”。优先直接点击输入框旁的 `Run`。若某一回合生成失败或需要重新生成，悬停该回合右上角，点击出现的 `Rerun this turn`；这是重试既有提示词的首选入口。
- Hunyuan Geo 的“模型面数”必须显式选择最低档（当前为 `50k`），并在点击“立即生成”前以高亮选中态复核；不能只根据预期点击位置推断选择已生效。Geo 虽可能仍产出高面原始模型，但这不改变先选最低档的要求。
- 从 Hunyuan 下载模型时，`下载` 不是可靠的直接下载按钮：先把鼠标 **hover** 到它上面，等格式菜单出现后再选择所需文件。若自动化无法触发该 hover 浮层，读取当前 Hunyuan 页面已加载资源，按所选资产的实际面数、顶点数与生成时间定位对应的 `.fbx`，再下载该已加载直链到临时制作目录。不得因此误下载仍在页面中的 Geo 高模；进入 Blender 前用 FBX 版本、网格统计和当前 Poly 资产统计交叉核对。
- 中间确认以“足够判断”为准：普通预览截图通常已经足够，不强制打开详情页。
- 每次抵达需要用户审批的关口，必须同时交付可直接判断的图片或截图，并先写出 Codex 的审阅结论与具体风险点；不能只用文字声称模型或图片已经完成。
- 模型审批图必须采用能暴露主要体块、入口、圆弧、薄片和遮挡关系的合适角度，优先 3/4 视角；必要时补一张侧向或俯视截图。避免用正面平视、裁切严重或加载中的画面要求用户判断。
- 进入 Blender 视觉加工后，审批预览必须表现该资产将交付的主体与描边材质；灰色 clay / wireframe 工作台图只可用于拓扑诊断，不能单独用于材质或加工审批。单独新增或调整不可见语义节点不触发这项审批。
- 生成期间优先选低面数、单张参考图和单体资产；暂不做多图拼接。
- 预览必须选择能暴露问题的角度，而不是只选最漂亮的角度。圆形、拱顶、薄片、入口和密集遮挡要刻意露出。
- 每个阶段保留原始下载文件和确认过的预览，正式 Unity 目录只放最终资产。

## 工具更换

不要主动更换服务。只有用户明确修改工作流时，才比较候选工具是否能维持以下输出：

- 图片工具：能稳定保持完整构图、时代约束、无文字、清晰体块。
- image-to-3D：能下载可进入 Blender 的模型，几何不是只适合单角度观看的空壳。
- 低模工具：可控制面数和拓扑类型，并能预览或下载结果。
- DCC：能保留 Camera、Empty、层级、材质名和 Curve，且 Unity 导入链可读取。

如果新工具不能保留 Empty/Camera 等语义节点，就在 Blender 加工阶段重建这些节点，不把它们寄托在生成器上。

## 失败与回退

- 图片不适合建模：回到提示词/参考图，不在 3D 阶段强行修复构图缺陷。
- Gemini 无法访问或未登录：停止并报告，不调用 Codex ImageGen 作为回退。
- 指定的 Hunyuan Geo/Poly 无法访问：停止并报告，不搜索或改用另一个“混元”产品。
- 最低面数生成失败：提高一个档位后重试；记录实际选择，不直接跳到高面数。
- 低模使圆形崩坏：先判断它是轮廓预算不足、拓扑流向错误，还是原图形体不清；只对症提高面数。
- 模型细节满意但整体比例错：在 Blender 统一缩放并应用 Scale，再生成描边。
- Unity 行为不生效：先检查命名契约和导入器日志，再改模型或代码；不要靠重复导入碰运气。
