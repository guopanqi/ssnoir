# 视觉定义

本文件指导 Agent 把资产需求转成适合 image-to-3D 的视觉定义、参考图提示词和审阅标准。艺术标准不绑定 Gemini、LibTV 或某个 API。

## 持续维护

把本文件作为跨资产复用的艺术基调与提示词知识，不把它当作固定不变的说明书。用户在审图或审模时若明确纠正了整体风格、年代口径、构图原则或反复出现的生成问题，在当前工作中直接更新本文件，使下一次 Skill 调用使用新规则。

只记录能够指导后续多个资产的结论。诸如“当前公园右侧少放两棵树”属于单次资产反馈，不写入这里；“重复树冠不得遮挡主体建筑”属于可复用规则，应当写入。新结论推翻旧规则时直接修改旧规则，不保留并列冲突版本；历史交给 Git。

## 固定世界观

SSNoir 的世界是上世纪美国黑色电影语境。公园、街道、建筑、车辆、灯具、报刊亭、招牌和家具必须属于目标年代；当前公园基准为 1940s American urban civic park。不要因为内容文本使用中文，就生成中国城市或当代亚洲元素。

年代不是一句风格标签。提示词应具体约束可验证的物件：

- 建筑轮廓、雨棚、窗型、街灯、长椅、车辆和铺装做法。
- 当时存在的市政设施与商业设施。
- 禁止现代 LED、现代极简景观、当代广告牌、现代车辆、塑料户外家具等。

不确定某个物件是否符合年代时，先查可靠资料再生成；不要用“复古感”代替年代判断。

## 主次细节分配

场景类参考图（尤其是室内/多功能区空间）不要通篇同等精度。先分清哪些物件承担具体玩法功能或构成视觉焦点，哪些只是重复出现的背景装饰：

- 承担节点动作、视线焦点或构图重心的物件（入口、主舞台、人群聚集的核心区域等）用有明确形状细节的方式画，值得多花面数。
- 成排重复的背景物（柱子、吊灯、成排桌椅等）不必逐个精细刻画；应合并简化成体量正确、轮廓抽象的色块或极简重复单元，减少数量或降低单件复杂度。
- 判断标准不是"好不好看"，而是"这里会不会被造得比它实际的玩法重要性更贵"：通篇同等精度会让最终低模的面数预算失焦，也会让参考图本身显得杂乱、找不到主次。
- 用户在审图时指出"这里太精细/那里没必要"，通常就是在做这个主次判断，应据此重新分配，而不是整体拉低或拉高精度。

## 城市地点首先是叙事角色

城市一级地点的写实可信度服从于辨识度与故事表达。不要只从“这种功能的建筑通常长什么样”出发；先决定这个地点在故事中的立场、动作和情绪，再把它落实为远景可读的大体块。

- 每个一级地点必须有不可与其他地点互换的主导轮廓。优先拉开高宽比、对称/偏心、实心/空心、单体/聚落、屋顶线、主要缺口、悬挑和附属构筑物，不靠材质、颜色、招牌、窗型或表面装饰冒充差异。
- 把建筑当作角色，先为它确定一个能驱动形体的动词，例如压迫、拒绝、招揽、吞吐、藏匿；模型的大轮廓应表达这个动词，而不只是表达警局、酒店、诊所等功能类别。
- 同一批城市资产要做阵容审查，避免各自合理、合在一起却全部变成中等尺度、基本对称的盒状建筑。单体通过不等于城市阵容通过。
- 参考图和低模都要做纯黑剪影缩略测试：去掉标签、压到约 96px 高仍能依靠外轮廓认出，才算一级地点的辨识度通过。
- 描线服务于主形读取。不要让窗框、墙缝和内部结构获得与外轮廓相同的视觉权重，否则统一描线会抹掉建筑个体差异。

## 面向 image-to-3D 的提示结构

按以下顺序组织：

1. **输出形式**：3D reference sheet / isolated environment / isometric 3/4 view。
2. **视觉语言**：film noir、黑白、高对比、硬表面、清晰轮廓。
3. **年代与地点**：明确十年、国家和功能类型。
4. **总体布局**：先写平面组织和主轮廓，再写附属物。
5. **关键物件**：只保留会影响识别和游戏用途的物件。
6. **建模约束**：平滑纯色表面、简化几何、低表面噪声、网格友好。
7. **负面约束**：无人物、无可读文字、无 logo、无现代物件、无真实草皮/泥土/树皮/叶脉、无污渍风化。
8. **构图约束**：整体完整、居中、四周留边、不得裁切；明说 **单张独立图**（one single standalone image），否则容易返回拼贴/联络表。

需要多视图 reference sheet 时，可加入俯视平面、关键建筑正视和侧视；但当前 image-to-3D 主输入仍优先使用一张信息清楚的主视图，不做拼接。

## 审阅参考图

确认以下问题后才进入 3D：

- 主体是否一眼可辨，剪影是否有独特性。
- 入口、道路、中央体块和边界是否形成可读层级。
- 圆形结构是否真正闭合、厚度一致，而非透视幻觉。
- 树冠等重复物是否遮挡关键建筑。
- 所有边界是否完整留在画面内。
- 是否出现文字、数字、Logo 或年代不明的设备。
- 细节是否能转成低模，而不是依赖纹理噪声成立。

公园类资产尤其要避免生成“自然荒野”或“现代景观广场”；用规则路径、低墙、Art Deco 灯具与亭子建立 1940s 市政空间。

上流社会室内（酒店宴会厅、俱乐部）用 Gilded Age / Beaux-Arts 建筑语言（约 1900–1925 建成，故事年代里它已是老钱的场所）：高拱窗、成对壁柱、台口式乐池、半圆卡座、石栏杆露台。厅的长宽比至少 2:1 并明显拉高；接近方形、四周均匀摆桌的大厅会被读成中式宴会厅或会议室，直接淘汰。
