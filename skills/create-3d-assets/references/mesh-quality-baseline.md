# 生成式网格质量

需要比较生成结果或判断是否能进入正式源时运行：

```bash
blender --background model.blend \
  --python skills/create-3d-assets/scripts/audit_mesh_quality.py
```

## 判断顺序

1. **轮廓与体块**：入口、屋顶、圆弧和主要层级是否在目标镜头可读。数字再好也不能补救错误造型。
2. **表面起伏**：建筑平面中相邻面夹角 5°–20° 的比例过高，通常意味着 image-to-3D 噪声；近景会出现跟随三角面的脏明暗。
3. **拓扑健康**：检查非流形边、零面积面、孤立碎片、反法线和穿插。它们会使法线、简化和导出不稳定。
4. **着色数据**：生成器常带全 smooth 和自定义分裂法线。硬表面资产应清理自定义法线并按实际硬边重建。
5. **拓扑预算**：记录三角/四边/ngon，而不是只看总面数。全三角不必然错误，但不能冒充已完成的四边低模。
6. **流程状态**：米制尺度、应用 Rotation/Scale、正式命名和语义节点属于 Blender 加工，不应用来评价生成服务。

对比生成器时使用同一参考图和同一审计脚本，优先比较表面起伏、拓扑健康、法线数据和低模稳定性。旧资产的某次统计不作为永久门槛；最终预算由资产用途和 CityBox 报告决定。
