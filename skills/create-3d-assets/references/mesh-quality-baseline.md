# 生成式 3D 模型的质量问题与实测基线

这份文件回答两个问题：生成出来的网格有哪些**反复出现**的毛病、每个毛病在 SSNoir 里
实际造成过什么后果；以及换一个生成服务时，拿什么尺子去比。

测量用同一个脚本，不要靠眼睛看：

```bash
blender --background 模型.blend \
  --python skills/create-3d-assets/scripts/audit_mesh_quality.py
```

下面的 Hunyuan 基线就是这么跑出来的。换 Tripo 或别的服务时，**用同一张参考图**生成，
跑同一个脚本，比同样的几个数字。

## 先分清两类问题

对比生成器时最容易犯的错，是把流程没做到位的地方算到生成器头上。

- **生成器固有**：模型出厂就带着，换服务才可能改善——表面起伏、非流形、零面积面、
  法线处理、UV、拓扑类型。**这些才是对比 Hunyuan 和 Tripo 的有效指标。**
- **流程执行**：出厂后该由 Blender 加工环节消化掉——缩放、命名、朝向。
  换生成器不会自动变好，漏了就是漏了。

SSNoir 现有资产里两类都有，且后者暴露出加工环节执行得并不一致：警察局和诊所面数低、
以四边面为主、名字也改过；家和雕像却是全三角、面数爆炸、还留着 `mesh_rep_0_ori_repair`。
同一条流程，产出差了一个数量级——**看到"某个模型很糟"时，先确认它是不是只是没走完流程**。

## 生成器固有问题

### 1. 表面起伏：本该平的面是歪的

从图片重建时，平面会带波浪状噪声。指标是**相邻面夹角落在 5°–20° 的比例**——这个区间
既不是平面（<0.5°），也不是设计上的转折（>20°），只可能是噪声。

后果：近距离镜头下墙面出现跟着三角面走的明暗块。远景看不出来，**特写必现**。
2026-08 做过场时第一次撞上，当时误判成 shadow acne。

它也解释了为什么导入设置只能缓解不能根治：Unity 重算法线修得掉"假明暗"，修不掉
"墙真的是歪的"。

### 2. 全 smooth shading + 自定义分裂法线

出厂时 100% 的面是 smooth，且带 custom split normals。建筑这种硬表面按这套着色，
相邻三角面的法线互相平均，平墙上直接出现渐变。

**8 个模型全部中招，无一例外。**

后果：曾经长期被强环境光掩盖着。2026-08 把环境光按 Blender 对齐、调暗之后集体显形——
强环境光从各方向均匀补光，会盖住法线瑕疵；暗环境加强方向光则把它放大。

缓解（Unity 侧，不用重导出）：模型资产 Import Settings → Normals: **Calculate**，
Smoothing Angle **30**。根治要在 Blender 里清掉 custom split normals 再按角度重新平滑。

### 3. 非流形边和零面积面

每个模型都有，量级差别极大：少的 9 条，多的 3446 条（码头）。零面积面 1–177 个。

后果：阴影和法线计算出错、布尔/简化操作失败、导出时可能被静默丢弃。目前还没有单独
归因到它的可见事故，但它是后续加工环节不稳定的温床。

### 4. 完全没有 UV

**8 个模型全部 0 层 UV。**

目前不致命——SSNoir 用的是纯色加描边，不吃贴图。但它封死了以后走贴图路线的可能，
届时要么重新展 UV，要么重做。选生成器时值得把它算作一项。

### 5. 低模拓扑不稳定

流程要求"优先四边面"，实际产出分两种：

- 走到位的：警察局 70% 四边、诊所 79% 四边、剧院 83% 四边
- 没走的：家 9210 面**全三角**、雕像 27210 面**全三角**

全三角的那两个同时也是面数最高的——说明它们跳过了低模拓扑，直接拿原始生成结果用了。

## 流程执行问题

### 6. 未应用缩放

剧院、大厦是 10 倍，码头、雕像是 5 倍，缩放没有 apply 到网格。

后果：法线和物理计算在非均匀尺度下容易出问题；Unity 侧再叠一层缩放后更难排查。
Blender 加工环节应该 apply 掉。

### 7. 生成器默认命名

8 个里 6 个还叫 `mesh_rep_0_ori_repair` 或 `..._quad`。

后果：SSNoir 有一整套靠名字触发的 Unity 契约（Anchor、orbit pivot、Actor 标记、
描边材质）。留着默认名，这些契约无从谈起，只能靠父物体兜着。

近景物件，是重做或换生成器时最值得先拿来试的对象。

## 对比 Tripo 时看什么

同一张参考图，两边各生成一次，跑同一个脚本，按重要性依次比：

1. **起伏 5–20° 的比例** —— 最能反映重建质量，也是最难在后期补救的
2. **是否强加 smooth + 自定义法线** —— 若 Tripo 出厂就是 flat 或按角度平滑，省一整道工序
3. **非流形边和零面积面的量级**
4. **有没有 UV**
5. **低模拓扑能否稳定出四边面** —— 注意排除"没走低模环节"的情况，否则比的不是生成器

不要比的：缩放、命名、朝向。那些是加工环节的事，跟生成器无关。

也不要只看数字。轮廓辨识度、体块关系、圆弧质量、年代感这些得人来判断，脚本测不了——
一个各项指标都漂亮但看不出是哪个年代的建筑，对 SSNoir 没有价值。
