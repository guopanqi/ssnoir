# Web 读档性能与失败隔离

检查日期：2026-11-04。环境：macOS、Node v26.13.0、Playwright 1.55.0 Chromium，Vite 开发入口，固定 seed=42。

基线为 `404a5048`。本次改动在安全快进整合 `2ab8dede` 的读取/模块恢复细分计时后验收，未改动 Unity 或 Scheme 内容。

## 问题与改动

6,162 字符的新世界存档在 Node 探针中读取约 37 ms，逐模块恢复约 35 秒；第一幕、第三幕及人物的多次关联表查询占用大量时间。`assoc-get` 是通用表查询，本次在 LIPS 适配层加速字符串键的逐行查找，保持首个匹配、默认值和返回值身份；非字符串键由原始 Scheme helper 执行。没有可失效的表索引，原地修改字符串键、值、链表尾后仍读取最新数据。错误与循环列表明确抛错。
