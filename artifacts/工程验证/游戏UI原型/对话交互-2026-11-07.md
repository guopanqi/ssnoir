# 对话 UI 原型交互验证（2026-11-07）

范围：`experiments/游戏UI原型` 的对话实验。未修改 Unity 或正式剧情。

实际通过本地 HTTP 服务运行 Chromium 浏览器，检查以下流程；最终 15 项检查全部通过，无 pageerror。检查脚本缓存于 `tmp/ui-prototype/check-dialogue.mjs`，命令 `node tmp/ui-prototype/check-dialogue.mjs`。它借用现有 Gemini CLI 安装的 Playwright 依赖，不调用图片服务。

- 两侧入场方向正确，入场时明确禁止推进
- 从首条旁白开始，没有预先跳过三句
- 第一次补全、第二次继续，发言角色切换
- 布局切换保留同一进度
- 回看保留记录、暂停逐字显示，Esc 返回
- 方向键与数字选择；分支两句逐句出现
- 退场后恢复场景的真实交互状态
- 本地选图、原图模式、姓名、缩放、镜像即时更新
- 损坏图片有反馈并保留当前画像
- 项目路径加载与恢复默认
- 连续重播没有旧动画回调、重复舞台或跳句
- 自动推进到选择时暂停
- 横屏尺寸变化仍沿用同一画布字号
- 减少动态效果偏好可跳过入场与逐字动画
- 没有页面脚本异常

画布仍按 1280×720 统一缩放。检查视口为 1440×1040 与 844×480，对白源字号不因视口变化而改变。
