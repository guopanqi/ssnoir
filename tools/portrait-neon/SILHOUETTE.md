# 剧场人物剪影遮挡

线绘剧场对 `Portraits/Neon/` 图片默认绘制对应的 `<名>_silhouette.png`，再画 Neon 原图。底色 `#070B12`，实体不接收亮度或灯光染色；继承人物透明度、位置、缩放、镜像、旋转。姿势替换取新图对应遮罩，缺资源直接报错。道具图片不走这条路径。

执行 `python3 tools/portrait-neon/silhouette.py` 生成所有遮罩，或传人物/姿势名局部生成。派生图保持原图画幅，只在离线处理时闭合小断口、填充封闭内部并柔化边缘；被画幅裁断的腿在底边封口。它是轮廓初稿，新增姿势须目视审阅，必要时直接修订遮罩，尤其关注手臂空隙、腿间空隙和细小道具。原 Neon 图不会修改。纹理导入须使用输入 alpha（`alphaUsage: 1`），不能从白色 RGB 生成 alpha。

雨夜、烟盒、弗兰克的桌子中的固定头/身体/裙子多边形已移除，遮挡统一跟随实际姿势。预览工具同步复制遮罩依赖。已有 `_lines` / `_accent` 加工排除 `_silhouette` 文件。

验证：Unity 生成 csproj 编译通过（4 条既有 CS0649 警告）；`--test-theatre` 通过。雨夜真实 GPU 序列导出成功，审阅对白时间索引和门格/门内强光时刻的原尺寸图，确认背景不穿过人物、换姿势同步遮挡。未进行游戏 Play Mode 输入或声音验收。
