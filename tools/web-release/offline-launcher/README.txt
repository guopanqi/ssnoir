SSNoir Demo (browser build, no installation required)

Mac:     double-click  START-Mac.command
Windows: double-click  START-Windows.bat

首次在 Mac 上打开时，系统可能提示「无法打开，因为来自身份不明的开发者」。
解决办法：在 START-Mac.command 上点右键 -> 打开 -> 再点「打开」。

启动后会自动打开默认浏览器（推荐 Chrome / Edge），首次加载约需 20-60 秒。
关闭浏览器后，回到弹出的黑色终端窗口按 Ctrl+C 即可结束。

game 文件夹是游戏本体和内置的本地服务器，不需要手动打开。
