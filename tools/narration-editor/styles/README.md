# Narration Editor Styles

Switch the editor theme by changing the stylesheet link in `../index.html`.

```html
<link rel="stylesheet" href="styles/unity-imgui.css">
```

Available themes:

- `unity-imgui.css` — current Unity IMGUI-style default.
- `claude.css` — dark terminal / CI-style test theme.
- `macos.css` — light macOS-style test theme.
