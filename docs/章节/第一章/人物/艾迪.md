# 艾迪

> 依据正式设定 V1.0 及后续讨论整理；2026-11-01 合并人物与事件文档。后续事件顺序、参与与缺席的衔接，以[艾迪命运草图](../../../experiments/人物命运草图/艾迪.html)为设计基准。创作方向与已接入内容分别看待。

艾迪是一个在粗粝的旧港里过日子的年轻工人，能干、开朗、可靠，也有些笨拙。他照顾过尼尔，如今终于开始为自己建立工作之外的生活。玩家应该先喜欢和他在一起的日子，而不是因为担心他最终失业才关心他。

## 人物

### 他是谁

艾迪是旧港的青年装卸工，初识时只比尼尔早到这个码头几天，是先熟悉一些做法的工友，会把已摸熟的做法教给他，也会漏看问题或与尼尔一起补救失误；随着持续上工，逐渐熟悉搬运、吊挂、索具与起重设备配合。他熟悉老式装卸作业，知道怎样让一组工人安全、有效率地把货物卸下船，也能处理一些常见的机械小故障；但他**不是现代自动化设备的专业工程师或维修主管**。

他有力气、经验和一双好用的手，懂得什么时候该使劲，什么时候该让别人停下来。他在自己的工作环境里很自然，愿意照顾新人，熟悉码头上各种脾气的人；到了舞厅、讲究穿着的餐厅或陌生人的约会场合，却可能显得不太自在。

他喜欢笑话，偶尔吹牛，喝便宜的酒，盼着星期天休息。他不是一个需要时时证明自己品德的人，也不是天生承担某种政治使命的角色。

### 性格层次

| 外在表现 | 内里的另一面 | 如何在游戏中让玩家看见 |
| --- | --- | --- |
| 开朗、爱开玩笑 | 害怕别人看出自己在体面场合不够熟练 | 穿上不合身的西服去舞厅，嘴上说轻松，临到邀请跳舞却犹豫 |
| 能干、肯照顾新人 | 会判断失误，也会被普通生活难题难住 | 做工中逐渐熟练，到了陌生社交场合却可能犹豫；搬家的具体细节暂不确定 |
| 重感情、可靠 | 有自己的烦恼，未必总能照顾所有人 | 工作忙时忘记赴约，或为搬家、房租和未来计划烦心 |
| 认真工作 | 并不认为工作是人生全部 | 攒钱租房、约会、招呼朋友来家里吃饭 |
| 乐观、韧性强 | 遇到失业仍会受伤、沮丧、焦虑 | 尾声仍开玩笑，却在收拾工具或看账单时露出实际压力 |

**避免**：圣人式“好人”、工运领袖、拳手、天才维修工程师、注定落伍的失败者、只为结局制造罪恶感的道德人质。

### 他想得到什么

艾迪想要一份稳定的工作，不再每天为下一笔工钱发愁。他还想有一间自己的屋子，有窗户，有能坐朋友的桌子；可能认识一个喜欢的姑娘，买一辆二手车或摩托，拥有真正属于自己的休息日。

这些愿望没有伟大的意义。他也不觉得自己在实现什么伟大理想。**他只是想开始过自己喜欢的日子。**

### 和其他人的关系

- **尼尔**：最初是带新人上手的工友，后来逐渐成为可以一同工作、喝酒、出去玩、互相取笑的朋友。友情的证据是共同生活，不是累计好感点。尼尔如果不参加他的私人事件，艾迪照样前进，只是两人的亲近程度不同。
- **弗兰克**：上一代码头人，曾教艾迪做事。弗兰克嘴硬、爱骂人，却真心为艾迪得到稳定工作高兴。艾迪可能尊敬他，也会取笑他的坏脾气。
- **其他工友**：不是只有“被艾迪保护的弱者”。有人敬佩他，有人和他互相打趣，有人不认同他的选择；艾迪在班组中是一名熟练工，不是天然领袖。
- **可能的约会对象**：是独立生活的普通人，而非奖励艾迪的“女朋友奖杯”。两人是否发展成长期关系可以随具体戏剧设计决定；第三幕的重点是艾迪的笨拙、真诚及新的生活经验。

### 表现细节

- **手套**：初次工作时递给尼尔，建立被照顾的关系。
- **不合身的西服**：舞厅里有点局促的艾迪，打破“永远能干的工友”印象。
- **请朋友喝酒**：工作相对稳定，日子一天天变好，愿意与朋友分享。
- **共同搬家**：尼尔也能反过来帮艾迪，把家具和生活物件搬到新家；具体物件暂不确定。
- **朝港口的窗户**：他选择这个家不是为了某项剧情象征，而是确实喜欢醒来能看到船。
- **一张能坐朋友的桌子**：他的私人生活得以进入玩家的城市日常。

对白应简短、自然，有互相取笑的余地。不要让艾迪长篇表达“我代表传统劳动者的尊严”；也不要每次见面只说“我工作很努力”。

### 与整章的关系

艾迪的故事应当**独立成立**：即使没有夜莺、经理与旧港清场阴谋，玩家也可以喜欢他、期待他的下一段生活。

他不是替尼尔揭开罗科秘密的人，也不是经理阴谋的受害者代言人。其生活与主线真正交汇的地方发生在后段：旧港能否被特别程序提前封闭，影响他的现有工作与正在建立的私人生活。玩家理解代价，不是因为他演讲了城市政策，而是因为曾经陪他工作、出去玩、搬进新房，又在家里坐过。

艾迪与弗兰克构成对照：**弗兰克试图保住一生的旧地方；艾迪才刚建立自己的新生活。** 两人可以相互关照，但不把他们写成同一种政治立场的传声筒。

## 事件

### 发展顺序

| 阶段 | 故事发展 | 艾迪的变化 | 玩家应获得的感受 |
| --- | --- | --- | --- |
| **第一幕：相识** | 《搭把手》：带尼尔熟悉码头工活、开玩笑、帮忙收拾失误 | 玩家认识一个可靠又好相处的工友 | “和这个人一起干活挺愉快” |
| **第二幕：熟悉** | 《大船靠岸》：参与一次真正热闹、有危险又有成就的装卸工作；《今晚不上工》：穿西装去舞厅 | 从“会干活的大哥”变成有趣、有欲望、有不擅长事情的普通青年 | “原来艾迪也有自己的生活” |
| **第三幕：建立生活** | 《请朋友喝酒》：得到正式的旧港装卸岗位；《一间有窗户的房间》：租房、搬家具、邀请朋友来 | 不只获得工资，还开始拥有自己的生活空间 | “我真为他高兴，也愿意常去他家” |
| **第四幕：享受日子** | 《艾迪的星期天》：新住处的日常、约会与休息、工作上的小波折；港口改造的消息渐近 | 他真正拥有了值得留恋的平凡生活，仍有小烦恼 | “这就是他一直想要的日子” |
| **第五幕及尾声：变化** | 旧港特别清场可能使岗位被提前取消；若清场受阻，工作与新生活暂时延续 | 乐观并非无痛；他会继续尝试生活，不必被判永久失败 | 玩家因真实共同记忆理解这次变化的代价 |

> **时间原则**：此处明确人生先后和情绪节奏，不预先确定具体第几天。某个场景可跨幕调度，但不得把第三、第四幕的幸福压缩为一条升职通知后立刻失业。

ED 编号是设计索引，不是日期或运行时节点 ID。日常搬运中的相助是关系状态，不单列命运事件。

### ED01《搭把手》｜第一幕｜码头｜城市工作 + 短对白

**事件**：艾迪只比尼尔早来几天，已摸熟一些做法。尼尔第一次做码头工，动作笨拙，不了解老码头的规矩。艾迪自然地分给他一副手套，教他看吊钩、货箱和工头的手势，顺手替他补救一个小失误。两人合作干活，休息时说笑。

**玩家经历**：仍然做正常的码头工作，不另外领取“认识艾迪”任务；第一次发现有人会主动照顾自己，而且这人并不居高临下。

**缺席与延续**：艾迪照常上工；第一幕没有相识，第二幕大船靠岸时尼尔仍可在装卸中认识他。相识后继续日常搬运，艾迪仍会教他、在困难时搭把手。共同回忆只来自实际经历。

**场景目的**：建立可靠、好笑、能够相处的第一印象。不要让所有人从一开始就称尼尔为“大侦探”。

### ED02《大船靠岸》｜第二幕｜码头｜主要 Contract 候选（沿用已有方向）

**事件**：第二幕大船必定靠岸，不以尼尔是否认识艾迪为条件。必定发生不等于强制尼尔参加。一艘大船进港，码头需要完成靠泊、吊运和装卸。工作中出现设备、货物或天气引起的困难，工友互相打趣，也会急躁、犯错。艾迪凭索具与装卸经验协助众人解决问题；尼尔参与的是自己能够承担的工作。

**消息与入口**：大船临时靠港、需要额外人手并提供额外报酬的消息固定到达。已经认识艾迪，由他传话；尚未相识，由其他工人或招工人传话。消息说明去哪里、什么时候及额外报酬，不再要求先认识艾迪或跑前置线索。玩家仍可选择不参加，船与艾迪的这班工作照常发生。

**玩家经历**：一段有劳动节奏、风险与现场变化的冒险，不是三次“维修设备”刷条。可以保留早先讨论的设备故障，但作为**大船行动的一部分**，不必在第三幕又复制一次同性质故障 Contract。

**相识接续**：尼尔到场时，若尚未相识，就在这班装卸中认识艾迪；若已认识，就继续熟人共事。此时艾迪已在码头工作一段时间，相对熟练，会教尼尔、在困难时帮他。以后日常搬运仍延续这种帮助。

**人物表现**：艾迪能干但不是绝对正确；某个问题可能由尼尔或其他工友及时发现。两人一起完成一件值得自豪的工作。弗兰克可以在工作后招待他们，形成真实的旧港人际网络。

**后续**：工头与同事对艾迪的信任逐渐增加，成为他随后获得正式装卸岗位的可信基础。

### ED03《今晚不上工》｜第二幕末／第三幕前段｜酒馆、舞厅｜人物故事 + 短互动

**事件**：尼尔在酒馆看到艾迪穿着明显不太合身的西服，头发梳得认真。艾迪准备去舞厅，打算邀请认识的一位姑娘跳舞，希望尼尔陪同。

在码头能自然指挥吊挂作业的艾迪，到了舞厅却拿不定主意，不知道什么时候开口。他吹嘘自己很会跳舞，实际可能踩错舞步，或者将一句本来准备好的邀请说得很可笑。

**可玩的部分**：玩家可以与他一同进舞厅、喝酒、跳舞、认识新的人；短互动应服务于共同尴尬与欢笑，不必制造黑帮打架、复杂恋爱数值或者人为失败条件。尼尔可以帮他化解一个场面，却不能代替艾迪完成追求。

**人物深入**：他有自己的虚荣和不安，想被喜欢，不总是那个无所不能的工友。姑娘可以接受一支舞，也可以婉拒下一次约会，不能被当成完成后发放的奖励。

**缺席**：艾迪照样会去；下次见面可从他的笑话、羞赧或讲述里知道那晚发生了什么，但尼尔没有现场的共同记忆。

**情绪**：轻松、热闹、亲近，带一点笨拙的浪漫。

### ED04《请朋友喝酒》｜第三幕｜码头、酒馆｜世界进展 + 工作 + 庆祝

**事件**：旧港运营方把艾迪聘为一个稳定装卸班组的正式成员，可长期负责他熟悉的装卸工位、索具与老式设备操作。相比过去的零散雇用，他有了更稳定的工钱和工作安排。日子一天天变好，他在酒馆请朋友喝酒。

**因果**：不是因为尼尔替他讨薪、修好机器才拿到职位；主要来自他过去这段时间的经验、表现和同事的信任。前面的《大船靠岸》使玩家亲眼见过他为什么值得被聘用。

**玩家参与**：可以一起做码头工作，听他宣布好消息，或参加酒馆庆祝；若选择忙于罗科调查，这些事仍然发生，之后工位、请朋友喝酒、稳定收入的变化仍可见。

**情感**：职位本身不是故事高潮；高潮在于他第一次觉得自己有条件计划工作以外的生活。

### ED05《一间有窗户的房间》｜第三幕中后段｜旧货店、公寓｜短 Scenario 候选 + 私人场景

**事件**：艾迪租下一间简单的小屋，请尼尔帮忙把家具和生活物件搬过去。先确定“帮他把一个家搬过去”的共同经历，不预先指定具体家具、搬运障碍或解决办法。

**玩家参与**：从过去搬运时得到艾迪帮助，到现在也能帮他搬家。事件的具体互动、是否需要短 Scenario、投入与结尾场景，留待后续设计。

**世界结果**：艾迪开始拥有自己的生活空间。房间的回访与生活内容见后续事件，具体规模待定。

**缺席**：艾迪自行安排或找其他工友，照样搬进新住处；尼尔没有参加，就不引用共同搬家的回忆。

### ED06《艾迪的星期天》｜第四幕｜艾迪住处、街道、舞厅或港口周边｜可重复的生活事件

**事件**：他的生活确实在继续。可能是买一张俗气的风景画挂到墙上；为第一次正式约会挑衣服；星期天请尼尔吃饭；连续夜班后抱怨自己错过一个重要约会；准备攒钱买二手车或摩托。

这些不需要都做成独立任务，只挑一两件最有生命力的具体事表现：他忙于工作，却不再只为了工作而活。他有快乐，也有新的不如意。

**玩家参与**：回访、简单社交、一起进行小规模城市休闲或临时行动。如果玩家只是来借地方休息，也能看到房间物件与人物状态变化。艾迪有时有事不在家，不能成为永远等待玩家的“回复冷静机器”。

**暗流**：港区改造、设备停运与合同变化开始有传言，但不能让艾迪从此每句话都在谈失业。他可以认真考虑培训、新工作机会，同时依然享受现在。

### ED07《我这两只手还在》｜第五幕／尾声｜码头、住处｜条件变化

**条件一：旧港特别清场未获关键授权。** 旧港运营暂时继续，艾迪原岗位没有被本次紧急处置打断。他照常工作、吃饭、计划下一次休息。**不是获得永久就业保证**；正常改造和劳动市场仍可能改变未来。

**条件二：特别清场获批。** 旧港相关工位被提前封闭，原运营方不再保留艾迪的装卸岗位；新的港区运营者招聘体系独立，他必须重新找工或学习新设备，而非因为人笨、失去双手或永远不可能胜任机械化工作。

**可见场面**：日子刚好转，班组却不再开工。艾迪在新房整理账单、翻看招工广告。和尼尔讲话时仍可能开玩笑，却不再像刚搬来那晚那样轻松。他仍然会问朋友吃饭没有。

**关于房间的因果限制**：**失去工作并不等于当晚立刻被房东赶走**。如还有储蓄，艾迪可以暂时继续住着，寻找工作；只有在故事经过合理时间、房租与积蓄确实无法维持时，才安排搬走的分支。若以后需要搬走，可回应实际共同搬家的经历，暂不指定家具细节。

**关系后果**：尼尔若参与过艾迪的舞厅、搬家或饭局，尾声可以出现私人的对话与记忆；如果尼尔的证言实际促成清场，艾迪有理由失望、难以开口，但不必机械地突然翻脸；如果不认识，表现为一个普通码头工人的职业变故，不制造假亲密。

**人物原则**：艾迪会受伤，会沮丧，但保有继续行动的能力。他不是剧情结束后静止在“被害者”姿态中的人。

### 行动与场景形式

| 内容 | 建议形式 | 玩家实质参与 | 不应变成 |
| --- | --- | --- | --- |
| 码头普通工作 | 常驻城市行动 A | 挣钱、消耗骰子、和艾迪形成日常共处 | 艾迪每天发布相同任务 |
| 大船靠岸 | 第二幕重点 Contract C | 靠泊、装卸、突发困难、协作抉择 | 第三幕又来一次重复维修事故 |
| 舞厅之夜 | Dialogue + 短互动 S | 与艾迪共同经历不同于工作的新场所 | 强制恋爱小游戏或无缘无故的打架 |
| 正式受聘、庆祝 | 世界事件 W + Dialogue | 到场祝贺、工作后一起喝酒；缺席也推进 | 帮艾迪刷满“聘用 Clock” |
| 帮艾迪搬家 | 形式待定 | 帮他把家具与生活物件搬到新住处 | 预先锁定家具、障碍或多阶段任务 |
| 艾迪的新住处 | 持续地点 R + 生活对话 | 休息、吃饭、重访、感受家具与生活变化 | 无成本无限恢复站 |
| 旧港岗位变故 | 后期世界事件 W/R | 看见工作与房间真实变化，关系随经历呈现 | 自动永久失业、必然破产、必然搬家 |

**体验密度判断**：艾迪的线不以 Contract 数量衡量。码头已有大型工作场景；第三幕以一个轻松可玩的搬家小情景和若干有生命力的社交时刻形成新的游戏体验。是否需要更多机械挑战，待城市全章试玩，而不为凑数再安排故障。

### 确定范围与待定细节

**确定**

1. 艾迪核心性格：可靠、善良、勤恳、幽默，也会虚荣、害羞、笨拙、犯普通人的错。
2. 职业口径：旧港熟练装卸工，擅长索具、吊挂、传统装卸设备操作，懂一般设备问题但非现代设备维修专家；逐渐获得稳定的正式装卸岗位。
3. 故事主轴：工作中的友情 → 工作以外的快乐和个人愿望 → 正式岗位 → 独立住处与共同生活 → 对未来的期待 → 可能遭遇岗位中断。
4. 关键场景方向：《搭把手》《大船靠岸》《今晚不上工》《请朋友喝酒》《一间有窗户的房间》《艾迪的星期天》《我这两只手还在》。
5. 独立推进：尼尔的参与改变共同经历与关系，而不是艾迪是否获得工作、是否搬家和是否拥有自己的人生。
6. 后期清场不保证艾迪永久失业或立刻搬家；他有技能、韧性和继续寻找生活的能力。

**仍需在场景开发时具体决定**

- 与他跳舞的姑娘的姓名、背景及关系最终走向。
- 大船场景中的具体机械事故和遭遇决策结构，是否沿用现有已实现玩法。
- 搬家短情景究竟需不需要独立 Scenario，以及行动/金钱/冷静的数值代价。
- 舞厅、房间的制作规模和可重复互动的次数。
- 准确城市日、事件窗口及第四幕后清场导致的职位变化时间。
- 尼尔未参与任何艾迪私人事件时的对白与场景回访内容。

> **创作检验**：把清场结局完全拿掉，只看艾迪前三、四幕的故事。如果玩家仍然想和他工作、去舞厅、看看他的新房，那么这个人物才真正成立。否则不应靠第五幕失业来补救前三幕的人物匮乏。
