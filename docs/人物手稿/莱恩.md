# 莱恩 —— 手稿归拢（原样搬运，未改一字）

畸形的爱情

他不是想靠夜莺发财；他想让已经离开自己的人承认，她还没有真正摆脱他。
钱、照片、勒索，只是这种欲望的一种形式。
他的生活处境让他的注意力全部倾注在爱情上，这是他唯一的快乐，过去的，夜莺的离开和他的处境纠缠在一起，他的处境或许又和夜莺的离开有一些关系

尼尔，在莱恩眼里，只会变得更加嫉妒。
