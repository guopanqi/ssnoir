# 线绘舞台：内容与实现边界

这是独立的 2D 表现模块。Scheme 定义布景与演出，纯 C# 校验并求值时间，Unity 绘制与播放声音。
舞台不认识世界地图、交锋规则或存档。游戏只提供播放请求、输入锁和完成回调。

## 文件边界

| 文件 / 目录 | 职责 |
|---|---|
| `UnityClient/Assets/Resources/Content/scripts/theatre.scm` | 创作构造器和曲线采样，生成普通 Scheme 列表 |
| `UnityClient/Assets/Resources/Content/scripts/theatre/路灯下.scm` | 样板的布景、时间结构与本场组合函数 |
| `Engine/Runtime/Scripting/TheatreParser.cs` | 唯一的数据入口，校验并转换为类型化演出 |
| `Engine/Runtime/Theatre/TheatreScene.cs` | 不依赖 Unity、Schemy、游戏状态的演出模型 |
| `Engine/Runtime/Theatre/TheatreSession.cs` | 纯 C# 播放器：唯一时钟、嵌套时间结构、对白等待、暂停与取消 |
| `UnityClient/Assets/Scripts/Runtime/Theatre/TheatreMesh.cs` | 加载时生成 Mesh，描线进度写入 UV |
| `UnityClient/Assets/Scripts/Runtime/Theatre/TheatreSurface.cs` | 独立 RenderTexture、层级变换、图片与灯光绑定 |
| `UnityClient/Assets/Resources/Theatre/LineTheatre.shader` | 路径显露、柔光、图片照明；显式矩阵，不依赖城市相机 |
| `UnityClient/Assets/Scripts/Runtime/Theatre/TheatreCaptions.cs` | 无框字幕排版与逐字淡入；读取播放器状态，不维护计时器 |
| `UnityClient/Assets/Scripts/Runtime/Theatre/TheatrePlayer.cs` | Unity 宿主：资产预加载、输入转交、音频实例、资源释放 |

`play-theatre!` 只通过现有阻塞表现队列或即时广播进入客户端。旧 `play-stage!` 没有增加线绘指令。
独立播放器无需城市 Prefab，也不修改城市灯光、层、相机或后处理。

## 写一套布景

`(theatre-scene width height background objects)` 定义一套布景，`objects` 是对象列表。
根对象的 parent 是空字符串。父对象必须是此前声明的 group/light，所有 ID 全场唯一。
源文件里的对象顺序就是从后到前的绘制顺序；不按父子树自动重新排序。

坐标沿用网页布景习惯：左上原点，X 向右、Y 向下。样板采用 1600×900。
渲染保留场景高度，按宿主宽高比在中心扩展或裁切横向范围；绝不按设备改布局。
矩形、路径都能用分组平移和旋转，旋转中心是分组局部原点。正角度在画面上顺时针。

```scheme
(theatre-group "窗户" "建筑" 380 180)
(theatre-line "窗框" "窗户" "#6F86B8" 1.5
  '((0 0) (54 0) (54 64) (0 64) (0 0)))
(theatre-line "窗格" "窗户" "#6F86B8" 1
  '((27 0) (27 64)))
```

上面的组合可以包装成 Scheme 函数，再递归生成一排窗户；无需 C# 窗户组件。

| 构造器 | 参数 |
|---|---|
| `theatre-group` | id parent x y |
| `theatre-line` | id parent color width points |
| `theatre-polygon` | id parent color points；仅支持简单凸多边形 |
| `theatre-glow` | id parent color x y width height；位置为中心，尺寸为直径 |
| `theatre-image` | id parent asset x y width height light；位置为图片脚底中心，light 可为空 |
| `theatre-light` | id parent color x y radius brightness；不可见，同时作为可见光部件的分组 |
| `theatre-with` | object property value；设置或覆盖初始属性 |
| `theatre-cubic` | a b c d samples；四个控制点，2..128 个整数采样间隔 |
| `theatre-ellipse-points` | x y rx ry；输出闭合椭圆折线 |

颜色是 sRGB `#RRGGBB` 或 `#RRGGBBAA`；由绘制层统一转换到工程色彩空间。
图片和声音使用不带扩展名的相对 Resources 路径。任何缺失资产，包括后续换姿势的图，均在开始前报错。
图片使用资产本身的 alpha；现有霓虹素材通过项目 Importer 从灰度生成 alpha。

可动画属性：`x y scale-x scale-y rotation opacity reveal brightness`。
默认：位置与旋转为 0，缩放、透明度、描线进度和亮度为 1。`reveal` 仅适用于线条；
`opacity/reveal` 为 0..1，`brightness` 为 0..4。分组的 opacity、brightness 与子对象相乘。
设置线条初始 reveal=0，再逐渐增加到 1，才能形成逐笔构建的效果。

灯的子对象（灯泡、光锥、柔光、光池）共同继承 brightness。绑定灯的图片逐像素计算距离衰减、
暖色照明和基础暗光；改变灯亮度时人物真的响应。灯的层级变换也应用于照明范围。
这是可控的舞台照明，不产生物理阴影，也不向城市的 Unity Light 注入状态。

## 写一场戏

```scheme
(play-theatre! 布景
  (theatre-parallel
    (theatre-tween "灯杆" 'reveal 1 1.4)
    (theatre-tween "尼尔" 'x 470 2.8))
  (theatre-say "尼尔" "现在可以说了？")
  (theatre-parallel
    (theatre-animate "路灯" 'brightness
      '((0 1) (0.04 0.15) (0.11 0.15) (0.13 1) (0.66 1)))
    (theatre-sound "电流" "Theatre/路灯电流" #f 0.28 0)))
```

`play-theatre!` 的参数依次执行，也可以显式写成 `theatre-sequence`。构造器每次返回一个动作节点，嵌套后形成一棵时间结构树；不再存在“每句话必须独占一拍”的限制。

| 时间结构 | 执行规则 |
|---|---|
| `theatre-sequence` | 依次执行，前一个结束后开始下一个 |
| `theatre-parallel` | 同时开始，所有分支结束后继续 |
| `theatre-during` | 第一项是主动作；其余同时运行，主动作结束时自动取消其余分支 |
| `theatre-repeat n action` | 重复有限次；每次必须消耗正时间，不能等待输入 |
| `theatre-loop action` | 持续重复；只能在 during 的背景分支中使用，同样必须消耗正时间 |

持续效果的边界是**作用域**，不是另一个计时器。例如等玩家读完对白时，灯继续闪：

```scheme
(theatre-during
  (theatre-say "尼尔" "现在可以说了？")
  (theatre-loop
    (theatre-sequence
      (theatre-tween "路灯" 'brightness .4 .15)
      (theatre-tween "路灯" 'brightness 1 .35)
      (theatre-wait 1))))
```

对白结束，闪灯分支随之结束；属性保留取消瞬间的值，需要复位就明确写下一步 tween。常用闪灯、窗户排列等函数留在 Scheme 中，不增加路灯专用 C# 模式。

`theatre-tween id property value seconds [easing]` 从动作开始时的当前值过渡；easing 是 `'linear`（默认）或 `'smooth`（平滑起止）。
`theatre-animate id property keys` 是线性关键帧曲线，使用 `(秒 值)`，首帧为 0，时间严格递增。
`theatre-image-to id asset` 瞬时替换图片，保留位置、尺寸、朝向与灯光绑定。
`theatre-wait seconds` 明确占用时间。

`theatre-say speaker text` 等待点击：首击补全文字，再击推进；可以与动画并行。自动字幕则由内容指定时长。
同一并行结构中最多一个字幕分支；不同分支不能写相同对象属性、相同音频 ID 或同时改字幕。这项检查覆盖整个嵌套分支，故意不猜测“它们也许不会同时执行”。父子对象可以分别修改自己的属性。
台词不会自动生成舞台人物；说话人和图片分别声明，允许画外对白。
无字动作期间输入不跳过动画。

`theatre-sound id asset loop volume pan` 音量为 0..1、声像为 -1..1，开始播放不延长动作。
循环声用唯一 ID，`theatre-volume id value seconds` 渐变其音量，`theatre-stop-sound id` 明确停止。
`theatre-sound-after` 是 Scheme 中的 wait + sound 组合，不是另一套计时机制。
声音实例归开始它的时间作用域所有：during 背景结束、一次 repeat 结束、整场结束或取消时，所属循环声和未播完的短音都停止。
短音的自然结束由 Unity 回报，不参与剧情计时。样板有脚步与电流，没有对白配音。

时钟只接受宿主注入的 dt，入场、演出、出场与字幕都使用它。跨动作剩余时间继续使用，低帧率不会拖长顺序动作；等待输入期间背景仍推进，暂停同时冻结所有分支、字幕与音频。
Scheme 在播放前生成结构，不调用系统时钟、不写逐帧 callback，不在绘制时重新求值。

`theatre-caption-for speaker text seconds color` 是自动定时字幕，不接受点击跳过。字幕在后续动作中保持，直到下一句或 `theatre-clear-caption`。路灯样板沿用 Claude 的完整台词、每字 48ms 淡入（300ms 渐显）、时长 `450ms + 字数 × 105ms`，以思源宋体显示无框字幕，姓名分色与疏排。字幕浮在舞台下部，左右各留 7%、底部留 3.5%，最多两行加姓名：超长台词由作者拆句，播放器只在 0.7 倍前逐档缩小兜底，仍超出行数直接报错；内容校验用同样的贪心换行估算行数。字幕状态与当前阻塞对白分开，暂停同时冻结逐字淡入。

`theatre-focus id x y inner outer` 是柔和的外围渐暗遮罩，半径直接使用场景坐标（0 < inner < outer），不随中心移动而变大。中心保留原来的光，外围逐渐压暗；不模糊人物，也不额外叠加蓝色光圈。支持 x/y/opacity，作为根节点按声明顺序绘制。样板放在人物后、字幕前，因此环境和人物一起受影响，字幕始终清楚。焦点直接移向说话人，1.2 秒平滑起止；短字幕通过 during 控制，不会被焦点移动拖长。

内部用半精度透明纹理合成，末尾统一还原非预乘透明度并转换到工程色彩空间，防止在 GUI 上再次乘透明度后线条过暗。布景颜色和柔光在显示空间合成，保留 SVG/CSS 的色彩习惯。抗环带使用亚 LSB 的静态 alpha 抖动。焦点不复制背景纹理、不做多次模糊采样，也不改变城市后处理。

样板不再串行画完地面后才画灯杆：全部路径按照原型的 CSS 延迟并行描绘；人物使用原型的错峰进场、整体移动与退场时长。人物仍使用现有立绘与姿势，未移植 SVG 身体、手臂和表情动画。
地面高度是样板唯一的纵向基准（`地面` define，默认 790 即原型的 87.8%）：地面线、路沿（+16）、路面刻线（+70）、灯杆灯座底部、人物脚底、光池中心全部由此派生；焦点 Y 与灯头位置不动。
舞台呈现由播放器固定拥有，不进入 Scheme：开场城市在 `0.6s` 里压黑成画布，线绘舞台淡入；收尾反向 `0.5s` 淡出，城市回来。第一笔描线即开场，收尾淡出不需要剧本手写。
舞台纹理空白处本身透明；Unity 宿主在其下用场景底色铺一层背景，透明度为入场淡入 × `DimStrength` × 底色 alpha。默认不透明底色与 `DimStrength=1` 盖住城市；调小后城市从没有线条的地方透出来。想全透看城市，把 `Vignette` 也调低——暗角盖在舞台上，同样会压住后面的城市。

舞台参数资产 `Resources/Theatre/LineTheatreSettings` 必须存在，缺失或数值越界直接报错。可在 Inspector 实时调整 `ContentScale`（全屏画布中的内容缩放）、`FocusStrength`（焦点外围渐暗）、`DimStrength`（城市压暗）、`Vignette`（固定四角暗角）、`Dither`（抗环带幅度）、`EnterSeconds` / `ExitSeconds`（入场与出场时间）。所有平台共用这套参数。
`TheatrePlayer.Pause` 暂停统一时钟和音频，`Reset` 释放临时 Mesh、材质、RenderTexture 和音频对象。

舞台几何由 **Mesh + Shader + 独立 RenderTexture** 绘制。IMGUI 只把结果纹理放到全屏并画字幕；它不负责画窗户、计算灯光或推进动作。Unity 宿主不解释 Scheme，不持有自己的演出计时器；纯 C# 播放器不认识 Unity 的图片、相机或 AudioSource。这是三层的实际代码边界。

## 从 JS 原型移植

保留原型的构图单位、部件名、旋转中心和时间关系，先分清布景与剧情，再写 Scheme 构造函数。

- SVG `M/L/H/V` 转为折线点；`C` 转为 `theatre-cubic`；`Q` 先换算为等价 cubic 控制点。
- `stroke-dashoffset` 转为 `reveal`。多个部件的延迟显现用 sequence、wait 和 parallel 表达。
- `translate/rotate/scale/opacity` 转为同名对象属性；`scaleX(-1)` 对应 `scale-x=-1`。
- 模糊椭圆光转为 glow；复杂阴影或纹理优先使用图片。
- `await sleep` 转为 wait；异步同时开始的变化转为 parallel；台词按需求转为点击等待或自动定时字幕。
- WebAudio 振荡器与噪声可以离线生成 WAV。样板的电流声是固定种子生成的短 WAV，可用 `python3 tools/theatre/generate-lamp-sound.py` 重建。

第一版不支持 SVG 字符串解析、任意 CSS Filter、网页骨骼自动转换或任意 JS callback。
路灯片段复用了现有姿势图片，保留进退场、距离变化、停顿和灯的反应，不逐帧复制网页肢体动画。
城市推近与模糊转场、雨粒子、浏览器预览和 WebGL 独立播放器尚未实现。

## 试演与验证

Unity：Play → 顶栏 Debug → **线绘舞台试演：路灯下**。试演不改变故事状态。
调试入口每次重新加载样板 Scheme，调整内容后可重新试演；基础 DSL 随解释器初始化加载。

```bash
dotnet run --project tools/content-validator/SSNoir.ContentValidator.csproj -- --test-theatre
./run --validate
```

`--test-theatre` 实际执行样板并跑完完整演出，同时覆盖嵌套顺序/并行计时、背景作用域、声音释放与音量渐变、入退场计时、暂停、对白推进、零时长事件、
并行冲突与非法资源引用规则。内容校验不替代这条样板执行检查。

Unity 关闭时可以运行离屏 GPU 检查：

```bash
/Applications/Unity/Unity.app/Contents/MacOS/Unity -batchmode -quit \
  -projectPath "$(pwd)/UnityClient" \
  -executeMethod SSNoir.EditorTools.TheatreRenderCheck.Run \
  -logFile /tmp/ssnoir-theatre-unity.log
```

检查加载实际 Scheme、Shader、图片和声音，检查焦点在两侧的明暗变化和透明度，比较灯泡、光池与隔离人物的亮暗差异，
并输出 4:3、16:9、20:9 的内部检查帧到 `.cache/theatre-check/`。
它不加载 Main、不进入 Play Mode，不证明游戏内点击、实际音响或完整演出节奏已验收。
