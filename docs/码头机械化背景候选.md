# 码头机械化背景候选

身份：当前讨论采用的背景方向，供剧情与场景设计使用；本文不自动修改全城年代、人物经历或运行时内容。

图示均为 Gemini 生成的设计概念图，不是历史照片、施工图或已经落实的游戏场景。局部设备图用于解释工作方式；港区总览表达公司提出的改造设想，其夸张程度见文末。

## 年代与地方

大致设在1950年代，一座虚构的美国老港城。保留更早年代建成的栈桥、货棚、船载吊杆和散杂货劳动方式；战后的航运公司与港口资本正在推动一次规模激进的整体改造。

故事的分界点是：公司准备把依赖大量工班、各自运转的旧港，变成由机械吊装、连续输送线和集中管理连接起来的新港区。它不是几处泊位的小修小补，而是足以改变整片岸线、劳动组织和居民生活的工程。技术未必刚被发明，但旧港此前的经营、资金与空间条件没有允许它成套落地；如今公司要一次性越过这道门槛。

本港不以成套集装箱运输为改造核心。主要货物仍是袋装货、木箱、桶和成组货物，木托盘也只是便于整托搬运的底板。画面不采用现代集装箱桥吊、无人运输车、自动堆场或电脑调度中心的形象。

![旧港的传统工班：船上吊货，岸上逐袋搬运](../city-box/prefabs/review/码头机械化背景/01-旧式工班.png)

**图1｜旧办法不是没有机器，而是机器之间仍靠大量人手衔接。** 船载吊具把成组货物放上岸，工人解索分货、扛袋、推车入仓。图中“落地拆包”指拆开吊运货组、分开搬运，不是把袋内货物倒出来。旧港的热闹和谋生机会都集中在这条劳动链上。

## 公司设想的新港区

公司所说的“自动化”，是用大规模机械化和预先安排好的输送流程，替代原先遍布每条通道的搬运人手。少量人员在操作室和机器旁按按钮、控制吊装、启停与切换输送路线，另有司机和维修工维持运行；货物在大部分路段由机器连续移动。

改造后的主要货流是：

**船舱 → 机械吊装 → 岸侧接货台 → 长距离输送线 → 分流口与新货栈 → 叉车或动力拖车送往堆放区、铁路及卡车装卸点。**

- **机械吊装区**：新岸吊、抓斗或适合对应货种的吊具承担成组起落。仍有操作人员及必要的挂索、接货工作，但公司不再沿用旧工班的人数和分工。抓斗适合散料，不能拿来随意抓取木箱和袋货。
- **连续输送系统**：长皮带、滚筒线、提升段和转运台穿过原先由工人往返的地面，有些线路架高、跨过道路，连接数座新货栈。护罩内有电机与减速箱，沿线设操作点、按钮、指示灯和电气控制柜。它是改变港区形状的大型设施，不只是一台推到门口的便携输送机。
- **货栈内部与末端运输**：适合的袋货、箱货进入对应线路；成组货物由叉车和动力拖车送往其他位置。公司要求调整包装、货组和接货办法，让更多货物适应新流程，而非让一条皮带神奇地兼容所有货物。
- **集中控制与少量岗位**：过去随货移动的一长串人，被几个固定操作点和一支较小的司机、检修队伍取代。公司宣传画可以几乎看不到工人，突出连续运转的机器；真实运转仍需要人，也仍有不规则货物、故障和收尾工作。

![电动袋货输送机与有人驾驶的叉车](../city-box/prefabs/review/码头机械化背景/02-新货栈设备.png)

**图2｜局部设备怎么减少搬运人手。** 输送机跳过原先长距离扛袋的路段；叉车把适合的货物整托运走。图中仍有人上料、接货和操作。此图只是辨认机器的近景，正式改造设想中的输送线会更长、连接更多货栈，不能据此把改造缩回一台便携输送机。

因此，巨变来自设备、货流、空间与雇用制度的共同重组。不能用“它仍需要人”冲淡故事：需要少数人，不等于原来那群人还有工作。

![公司设想的整片港区机械化改造](../city-box/prefabs/review/码头机械化背景/04-整片港区改造-修订.png)

**图3｜公司要重写的是整片岸线。** 对照人群密集的旧栈桥、贯穿港区的长输送线，以及新设施中稀少的操作人员。图中标出的拆迁范围把货棚、食堂和住所与新运输路线联系起来；它表达公司规划的空间冲击，不代表全部设施已经同时建成，也不预先确定每一栋正式剧情建筑都会被拆。


## 新旧并存，但旧生活面临拆除

故事发生在规划、征收、施工和试运行相互交叠的时期。

旧栈桥仍挤着搬运工，船上的吊杆和绞车照常卸货；隔壁已经能看见新吊装设施、长输送线和由少数人值守的新货栈。未开工的地方先出现测量标记、围挡和拆除通知。公司图纸上的线路正好穿过人们日常吃饭、修车、等活和存放工具的地方。

为了拓宽泊位、接通输送线路和车辆通道，公司计划拆掉部分旧栈桥、货棚、临时修理棚、工人食堂、小店及邻近居住空间。哪些地点被划入改造范围，按正式剧情逐处决定，不把所有旧建筑一律写成待拆。

这不是单纯的设备更新：有人失去工班岗位，有人失去经营多年的小生意，有人即使争取到一份新工作，仍可能失去原来住的地方和熟悉的邻里。旧港作为一个共同生活的地方，也在被拆散。

## 抵制的原因与人物分歧

工人最直接的恐惧是：新港确实能运更多货，却只需要很少的人；公司是否还需要自己，第一次成了无法回避的问题。拆除又让这种恐惧从以后的班表，变成眼前的门、屋顶和饭桌。

不把所有人写成同一种态度：有人强烈抵制改造，有人想争取补偿、保留岗位和公开培训，有人盼学开机器，有人愿意接受新工作却反对拆掉食堂和住所。旧伤工人欢迎少扛重物，也可能发现新岗位根本没有向自己开放。

经营者希望提高周转、降低成本、控制货物流转，也可能真实相信新港更安全、更有竞争力。但谁承担改造代价、谁取得收益，不能由一句“进步不可阻挡”抹平。公司可以把反对者说成阻碍城市发展的落后者；剧情应让玩家看见这些人的具体处境，而不是替宣传作结论。

艾迪等人的经验仍能解决复杂装卸，但这不保证他们或整个工班会被新体系接纳。少数能转岗的人，与多数可能失去工作的人之间，也会产生感激、愧疚、猜疑和裂痕。

## 与大船靠岸衔接

可选方案：船上最后一件长货是新港输送系统的一段重型机架与驱动总成。能看见滚筒、机架、传动和电机，底座较长，驱动端偏重。它属于整套新港设施，不是为一台普通小输送带配一部夸张的巨型发电机，也不是一件能够自动卸完所有货物的神奇机器。

前后两吊点分别照顾长底座两端，艾迪统一指挥、协调落货。设备尺寸、重量与吊具能力最终共同校准；不先承诺具体吨位，也不把双吊杆额定能力直接相加。

![大船卸下新港输送系统总成的场面构图](../city-box/prefabs/review/码头机械化背景/大船卸载构图/联合卸载.png)

**图4｜今天卸下的，是未来改造系统的一段。** 船上前后两组吊装设备分别承托总成两端，艾迪统一发令，岸侧工人引导其落上垫木。两条行动线对应两端作业班组，不能仍解释成“一边承重、另一边只接应”。此图交代场面与人物关系；具体索具、承载能力和空间净空另行校准，图中文字标注不直接作为游戏UI。


工人可以提前知道它的用途。有人为这班工钱接活，有人盼学新设备，有人已经听说自己的货棚在拆除范围内。成功落货仍值得欢呼，因为大家完成了一件困难的工作；但不会人人都以同一种心情庆祝。

后续让公司图纸、施工围挡、新工班名单和逐渐减少的叫工机会把变化落实。人们今天共同卸下的，只是庞大改造工程的一段；他们此刻还能依靠彼此完成的劳动，正是公司打算大幅压缩的东西。这里记录叙事方向，不因此新增玩法系统。

### 在我们的港城里怎样使用

这是美术与叙事建议，尚未新增车辆、服装资源或运行时内容：

- **旧港街口**：旧轿车、货车、自行车与步行人群共存；工装和普通日常装构成人群主体。留给工人换洗、收工后穿好衣服的空间，不把贫穷等同于永远肮脏。
- **公司视察当天**：维护得锃亮的新式黑色豪华轿车驶到围挡前，经理与测量人员下车；旁边是工人用了多年的工具与旧工作服。让新旧差别进入同一幅画面。
- **夜间俱乐部或富裕街区**：少量敞篷车、门童、晚装和灯光形成另一种城市生活；这与码头白天属于同一个年代。
- **共同底线**：不是所有男性都穿风衣礼帽，不是所有女性都穿晚礼服，也不是所有年轻人都是摇滚青年。阶层还要通过地点、动作、关系和财物表现，不能只靠一套制服。

## 有意夸张的部分与历史边界

本设定选择有年代依据的设备，并有意加强它们组合后的规模、集中程度、减员强度和对一座老港的冲击；不是对某一真实港口的复原。

### 有意加强的部分

- **把渐进变化压缩为可感知的转折**：真实技术采用往往历时多年、分货种推进。本故事让一家公司的整体计划把拆迁、设备入港、试运行和岗位缩减集中到相近时期；实际改造仍分段进行，不是一夜之间完工。
- **把输送线做成主导岸线的新形体**：长距离、高架、跨货栈的设施覆盖旧劳动路线，以强化机器正在重写城市的视觉冲击。具体规模属于虚构设计，不宣称当时所有美国散杂货港都如此。
- **加强公司承诺的省人程度**：宣传中可以描绘几乎无人搬运的未来。这是公司的目标和权力叙事，不是旁白确认所有货种都能在当时技术下实现无人装卸。正式运行可以显露其遗漏、代价与依赖的隐形劳动。
- **让设备更新与地产改造绑定**：技术上未必每处都必须拆除；公司选择整片重建、整合用地，才把效率工程扩大为旧生活的拆除。不能把经营与征收选择写成机器自身不可避免的要求。

### 那个年代可以真实存在的情况

- 机械吊货、电机、绞车、输送带、滚筒、提升设备、叉车及动力搬运车可以成为战后港区改装的材料。不同港口和货种的采用程度不同，它们也不是1950年代才全部被发明。
- CLARK厂史记录1946年的Yardlift 40、1951年的动力托盘搬运车，支持战后早期搬运设备的技术可用性和造型参考：[CLARK厂史](https://www.clarkmhc.com/history/)。
- 1901年美国农业年鉴的Pacific Wheat Ports已经展示袋装小麦电动输送设备，说明袋货机械输送有更早的先例：[年鉴资料](https://ageconsearch.umn.edu/record/344494/files/PacificWheatPortsYB1901.pdf)。
- 散料码头可以较早实现高度机械化，不能把这类专用系统的效率直接套到包装、尺寸、重量混杂的全部杂货上。本港的新计划需要选择货种并改变包装和作业方式。
- 1950年代提高船舶周转效率的压力，以及随后机械化、集装箱化引起的岗位与雇用制度争议，有历史背景可循：[Smithsonian码头历史](https://americanhistory.si.edu/explore/exhibitions/america-on-the-move/online/transforming-waterfront)。
- 美国现代集装箱航运在1950年代后期开始形成重要转折，但本故事不要求本港已经采用集装箱系统：[纽约—新泽西港务局历史](https://www.portauthoritybuilds.com/port/en/our-port/history.html)。机械化、集装箱化与无人化不是同一件事。

本故事中的“自动化”主要指连续、预先安排的机械输送和少数人集中操纵。控制室可以有按钮、指示灯与开关柜；不画现代电脑屏幕、视觉识别、无人驾驶或自动机械手。仍需挂索、整理货组、处理异常、维护设备等工作。公司如何压缩、外包或忽视这些劳动，可以成为冲突的一部分。
