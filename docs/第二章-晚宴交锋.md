# 《晚宴》交锋设计

第二章锚点一。核心不是说服所有人，而是：**在一个时间不够的房间里，把时间给谁。**

这场不强调身体伤害。压力来自六支舞、有限骰子以及恢复冷静同样会占用行动。夜莺唱歌未必是一流，
但她的社交与表演能力是一流；玩家通过她更高、更稳定的推进效率看见这一点。

## 第一幕：熟悉这个房间

前三回合面对的是人群与场合，而不是具名人物：赞助人那一圈、谈生意的人、舞池、餐桌和露台。
全幕共用一根八格「熟悉这个房间」钟。普通行动根据判定推进，夜莺成功时通常比尼尔更快。

夜莺的控制权按固定节奏减少：

- 第一回合，两颗骰都由玩家安排。
- 第二回合开始，主人过来敬酒，自动占用尼尔与夜莺各一颗骰，并稳定推进目标。
- 第三回合开始，夜莺主动接下一支舞，自动占用自己一颗骰并稳定推进目标。
- 第三回合结束，她已经能独自在厅里行动，离开玩家队伍；她仍在场景中，没有离开晚宴。

自动行动发生在新回合开始、玩家获得操作权之前：动作卡出现，输入完全锁定，骰子被占用，读条完成，
结果与对白播放完毕后才解锁。晚宴是单层场景，不处理跨层导航。

第一幕固定三回合结束，不把总钟做成第二幕的复杂前置条件。它负责让玩家学会这个房间的节奏，
并亲眼看见夜莺从紧张变得如鱼得水。

## 第二幕：把时间给具体的人

后三回合只使用尼尔的四颗骰。场上有四个人，每人一根统一的四格深谈钟；只有填满才写回明确后续，
未满不授予脸熟、折扣或引荐等半成品奖励。两格时最多播放一句克制的 banter。

- 薇拉：高风险；失败损失冷静，谈满后她把尼尔当成可以交付事情的人。
- 货运代理：陪酒，高风险；成功推进两格，失败倒退一格并损失冷静。谈满后给出一桩城市生意。
- 贝恩斯：较稳定，他已经听见这间屋子怎样称呼尼尔；数日后会把私人调查员的备案手续办好，并直接接通家里的委托电话。
- 记者：只在今晚有机会谈成；谈满后开启他的人物线。

林不占竞争席位。他是主线关键人物，在第一幕随夜莺的社交自然露面，晚宴结束后自动开启后续。

人物之间不做引荐链、互斥路线或顺序解谜。人物差异来自各自的谈话方式和风险，不来自额外网络规则。

## 散场

没有胜负，时间到了就结束，所以收尾不是一张成败卡。幕尾几句固定不变，讲的是**她的那一晚**——
她在厅那头被围着，外套被人送到手上，走过来一路被拦下三次；你谈成了谁对这一晚之于她毫无影响。
你的那一晚交给城市侧那张聚光卡。先对白，后聚光卡，中间不插判定。

## 冷静与恢复

不增加局部「失态」规则，沿用全局冷静与伤势规则。普通谈话失败不推进但会损失 1 点冷静；薇拉的高风险谈话失败损失 2 点冷静；货运代理的陪酒失败
会倒退深谈并扣冷静。露台和餐桌都能恢复冷静，但需要花行动骰，因此恢复的真实代价是晚宴时间。

## 引擎能力

本次不增加 `req-actor-die`。普通动作仍使用 `(req-die)`，玩家不需要学习新的骰槽类型。

只增加 `auto-action!`：内容在回合规则中声明动作标题、副标题、`(actor-id count)` 列表和可选锚点。
引擎在新骰发出后严格校验并按稳定骰位占用指定人物的骰子；缺骰、人物不在场或重复超额占用都是
内容错误，直接中断。客户端把它作为临时 `GameNode` 放进正常卡片集合：有锚点就空间投射，没有就进
网格；骰子从手牌缓动到真实骰槽，随后卡上的标准执行按钮自动读条。全过程使用明确的输入锁。

UI 拖拽、选中资源和失效卡槽引用属于可丢弃的临时状态，在采纳新快照时清理；逻辑状态错误不得靠
「有几颗拿几颗」或静默清理来兼容。
