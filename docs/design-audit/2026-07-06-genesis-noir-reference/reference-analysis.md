# Genesis Noir UI 参考分析与 SSNoir 转译方案

- 日期：2026-07-06
- 范围：用户提供的 Genesis Noir UI 参考合集
- 证据：[01-reference-board.png](01-reference-board.png)
- 目标：提取可转译到 SSNoir 的视觉语法，不直接复制具体素材。

## 总结论

参考的核心不是“所有 UI 都纸质化”，而是 **UI as artifact：界面是世界中的信息物件**。不同介质表示不同信息类型：

- 海报 / 通缉令：人物身份、目标、重要任务。
- 拍立得 / 相片：某个已发生场景、记忆、发现。
- 邮票 / 图章：章节、行动类型、快速选项。
- 手册 / 剪贴簿：线索、规则、持续积累的资料。
- 表格 / 版式化档案：结算、对比、精确数值。
- 纯黑工具条：高频、常驻、不应打断游戏的系统操作。

这些表达虽然不同，但由统一语法维持为同一个系统：黑 / 暖白二色骨架、少量暗金点缀、手绘黑白图形、大量留白、强中心构图、短文字、缓慢且具有物体感的转场。

## 参考步骤

### 1. WANTED 通缉海报（健康度：强）

- 几乎纯黑的环境中放入大面积暖白纸张，靠明度反转而不是发光吸引视线。
- 图像、大标题、简短说明是一条单向阅读路径。
- 适合 SSNoir 的具名人物、通缉、任务开启和重大后果；不适合普通按钮。

### 2. 相片式叙事卡（健康度：强）

- 画面被一个物理化边框包围，下方仅保留一句文字，像“被记录下来的时刻”。
- 适合对话关键帧、地点第一次发现、行动后的结果残留，不应成为常驻 HUD。

### 3. 图章 / 邮票式选择（健康度：强）

- 图形是第一识别层，文字是准确语义层；两者并存，因此既能快速扫读又不会让玩家猜图标。
- 每个选项的外框、图形尺寸和标题位置一致，所以图形内容可以很自由。
- 这是 SSNoir 地点 / 行动节点最有价值的参考：**符号负责预判，文字负责确认**。

### 4. 剪贴手册（健康度：强，但只适合低频界面）

- 通过不同尺寸的相片、图示和手绘笔记表达“资料是逐步累积的”。
- 适合线索手册、城市档案、人物关系图；不适合频繁拖放骰子或查看基础数值。

### 5. 干净图形工具条（健康度：强，但有图标歧义风险）

- 这类 UI 并不追求纸张感；它是纯黑块上的白色符号，目标是不打断场景。
- 只适合高频、已学会、数量少的操作。对于 SSNoir 的地点和剧情行动，不能只使用图标。

### 6. 版式化档案 / 结算表（健康度：中等）

- 横向细线、对齐字段和大量留白营造正式记录感。
- 小字在低分辨率和远距离下易失去可读性。SSNoir 可用于行动结算、队伍状态对比，但中文正文不应低于界面的基准字号。

## 推荐的 SSNoir 视觉方向：“墨迹与纸物”

不把上一轮的“象牙纸档案”平铺到整个 HUD，而是建立两层系统：

1. **系统层：黑白净界面。** 常驻状态、骰子、库存、返回、调试等高频操作使用高不透明墨黑背板 + 暖白文字。
2. **叙事层：有语义的纸质物件。** 当信息成为“人物、线索、记忆、通缉、记录”时，才切换为海报、相片、邮票或手册。

这会让界面有多种触感，但不会因为每个面板都在表演而破坏整体性。

## 组件映射

| SSNoir 内容 | 建议形式 | 图形与文字 |
|---|---|---|
| 未选中地点节点 | 水平墨黑标牌 | 24–28px 地点符号 + 中文名称 |
| 已选中地点 | 放大标牌 + 侧边地点档案 | 符号 + 名称 + 一句描述；文字为主 |
| 普通行动节点 | 小型邮票 / 图章卡 | 32–48px 行动图形 + 行动文字 |
| 高风险行动 | 带红褐边签的图章卡 | 图形 + 行动名 + 简短后果，不只靠红色 |
| 人物节点 | 姓名标牌；选中后展开相片 / 人物卡 | 头像或人物符号 + 姓名 + 关系身份 |
| 具名线索 | 小相片 / 票据 / 纸条 | 图像 + 线索名，详情在手册中展开 |
| 主线任务 / 通缉 | 海报 / 通缉令 | 主图 + 大标题 + 短说明 |
| 对话 / 行动结果 | 拍立得或定格卡 | 画面 + 一句叙述 |
| 线索与城市档案 | 剪贴手册 | 多媒介卡片 + 手写式联系，低频全屏界面 |
| 常驻队伍 / 物品 | 干净墨黑工具条 | 可熟记的图形 + 数量；关键物品保留文字 |

## 地点和行动节点的具体结构

### 地点节点

- 默认尺寸应是一条可读的横向标牌，而不是只有一枚邮票图标。
- 左侧图形表示地点类型（住宅、港口、商店、机构等），右侧中文名称表示具体地点。
- 选中时保留原标牌，另外展开一张侧边“地点档案”，避免把所有信息塞进地图节点。

### 行动节点

- 可以比地点更接近邮票 / 图章，因为它代表动词而不是空间。
- 标准结构：上方或左侧图形，旁边必须有动作名；需求骰子、物品、风险等信息放在统一的底部栏。
- 图形不应重复文字字面意思，而应先传达行动类别或情绪；例如“潜入货仓”的图形可表达门缝与人影，文字则给出具体行动。

## 图形风格规则

- 使用黑白二值或极少量暗金的手绘剪影 / 线刻图形，避免通用扁平办公软件图标。
- 先建立 8–12 个高频语义的小型系统，不要一次性为所有剧情动作生成图标。
- 地点类型图形可重用；具名线索、人物、重大任务才值得制作唯一插画。
- 小图形以 64×64 或 96×96 母版绘制，在 UI 中按 24–48px 显示；保证缩小后仍只有一个明确主轮廓。
- 未熟识的图标永远配合文字；只有返回、关闭、播放等已高度标准化的系统操作可考虑只用图标。

## 统一视觉语法

| Token | 建议 | 语义 |
|---|---|---|
| `WorldInk` | `#0B0E14` | 世界底色和系统背板 |
| `Paper` | `#E7E1D2` | 叙事纸面，不作全局 HUD |
| `PaperDim` | `#B8B2A5` | 非焦点纸面或次文字 |
| `InkText` | `#151820` | 纸面上的正文 |
| `ChalkText` | `#ECEBE5` | 黑色系统层上的正文 |
| `ArchiveGold` | `#C5A94B` | 已选中、关键线索、书签 |
| `Rust` | `#A24F3F` | 风险、通缉、严重后果 |

金色只是标记和笔记，不应变成大面积发光按钮。常驻系统层仍需要 88–96% 不透明背板，否则暖白图形仍会淹没在 SSNoir 的白色建筑描边中。

## 不建议直接照搬的部分

- 不要让每个节点都变成大邮票；地图会失去空间感，文字也会无处安放。
- 不要把纸纹、划痕、污渍随机铺到所有面板；材质必须有信息语义。
- 不要使用大量细小手写字作正文；中文应继续使用清晰的 MiSans 或同类无衬线字体，手写只作标记。
- 不要为了纯净而删除所有文字。SSNoir 的数据驱动节点信息变化大，图形只能提供快速识别，不能承担精确命名。

## 可达性与验证限制

- 用图形 + 文字同时表达节点，比仅靠颜色更稳定。
- 选中状态仍需要边签、反转底色或位移等第二线索，不能只用暗金。
- 纸张颗粒必须保持在低对比度，不能穿过小字影响阅读。
- 本次只能观察静态合集，无法判断原作的转场时间、音效、焦点顺序和操作命中区。
