# SSNoir 城市生活-提案

> 本文是一个提案，一个想法，不作为guideline或者施工文档。
> 本文记录城市生活系统的**机制现状与未落地方向**——大部分机制已在 demo 中实现，
> 尚未在第一章真实落地。它是"系统现在长什么样 + 想做但还没做的"的集合，
> 机制细节的真相以 `engine.scm`、`world.scm` 与引擎常量为准。

## 0. 设计哲学

游戏是一个**可供交互、可供游览的产品/建筑**，不是电影或文学故事。

- 城市不是关卡，是一台**玩家能读懂的机器**：不同的活法真的产生不同的结果，而且结果可见。
- 玩家愿意投入，是因为他在**设计属于自己的生活方式**。每天分配骰子的模式，会自然沉淀成一种活法。
- 玩家从"工作和生活背后的事情"里，一步步理解这座**美丽而致命的城市**的世界模型（黑色电影 / 马洛的世界）。

核心机制不变：**人物每天有一个行动骰子池，分配到不同地点、不同行动之中。**
骰子从"推进剧情的燃料"变成"你如何度过一天"的表达。

### 0.1 资源互联总纲

> **每种资源至少两个来源、至少两个互相竞争的去处，且去处横跨不同系统。**

判断任何产出是否成立的标准：玩家拿到它时会不会犹豫"用在哪"。
会犹豫的是资源，不会犹豫的是优惠券。由此派生三条原则：

- **跨线依赖优先于全局仪表。** A 线的产出直接做成 B 线的输入（私货→销路、
  情报→投资），比加一个全局状态条产生更强的咬合和更多的故事。
- **恢复要有吞吐上限，而不是加惩罚。** 身体成为真正的第二货币的前提是
  它不能被钱即时无限买回。
- **产能放大是最高级的回报。** 同伴的一颗骰子相当于文明里多一个工人：
  它改变"你的一天有多长"，是唯一会复利的奖励。

| 资源 | 来源（≥2） | 去处（≥2，互相竞争） |
|---|---|---|
| 金钱 | 各工作、卖私货、卖货单、投资结算、布告栏委托 | 房租/药/酒/香烟、应酬、投资本金、住所升级、首期/封口价/舱位 |
| 私货 | 走私好/中结果 | 码头散卖（保底价）/ 卖给货运代理（渠道价，需富商相识；富商信任后满价） |
| 情报 | 走私好结果、交锋成功、趁乱搜寻 | 货运公司"凭消息找项目" / 布告栏"打听门路" |
| 药品 | 诊所购买 | 家中用药（每天限量） |
| 酒 | 老街酒馆购买 | 城市或交锋中饮用恢复冷静；代价是下一次城市骰池带"宿醉"降质 |
| 香烟 | 老街酒馆购买 | 交锋功能区抽烟恢复冷静。它比酒回得少，所以在交锋里是"救一口"而不是"回满" |
| 办案通行证 | 阿瑟的人物线完成后在警局办理 | 交锋程序干预（单一用途，扩展留给交锋改版） |

私货和情报**不能直接按固定价格变成万能金钱**：必须经营另一条路线的关系或
等待限时机会才能兑现更高价值——这就是互联。

日常检验判据：**每天早上分骰子时，玩家是否需要想超过五秒。**


## 2. 机制原则

### 时间与可见性

- **所有跨回合的持续、冷却、到期和延迟事件都必须对玩家可见**，统一使用 Clock 表达
  剩余时间，备注明确归零或填满后的结果；不能只在脚本里维护隐藏计数器。
- 到期后被定义为"当天必须处理"的关键事件会**阻止休息和推进日期**；事件无论成功或
  失败，只要完成就解除阻塞。系统允许多个关键事件同时等待处理。

### 资源

- 资源分三类各有其家，总体"一线货币"控制在少数几种；**每个动作至少触碰两种资源**，
  让任何选择都是取舍。
- **房租是这套经济的地板。** 它把"时间"直接标价，让每天都有一个不属于案子的账要还。
  两条意图：**不能提前买断**（它是节律，不是余额）；**交不上不当天赶人，先动用老板的
  宽限，而宽限会记住你**——第一次拖欠的代价不是钱，是下一次没人等你了。
- 具名线索走物品（某处产出 → 某个动作需要它），判断线是"它在虚构里能不能揣进兜里、
  递给别人、被人拿走"；不能的留在脚本状态里。

### 身体状态

- 只有**冷静**和**伤势**两条轴。一句话分工：**冷静是你今天还能扛几件事，
  伤势是你这身骨头还剩多少。**
- **冷静是伤势的缓冲垫。** 当天扛不住的那一次开始欠明天的账——当天的小代价先记在
  冷静上，睡一觉抹掉；冷静见底还在扛，才击穿溢出成跨日的伤势。
- **缓冲要小，但也要每天从满的开始扛。** 一天只扛得住有限的几次失败；上限和过夜恢复量
  要配得上，选择发生在这一天之内。
- **伤势是一条有刻度的轴，不是血条。** 刻度是可规划性的来源：玩家全程看得见自己在第几格，
  风险因此可以主动承受。一次只有一处伤；倒下不在刻度上，是"条满了又挨了一下"，
  且**不是 GAME OVER**——它是最贵的兜底，不是终局。
- **倒下要留下东西。** 钱、骰子、伤势都会还回来，所以送医那一下如果只扣这些，它就只是
  一笔账。倒下在当时伤着的部位永久留下**一道疤**：那项能力从此差一点，治不掉，可叠加。
  它是这局里唯一不可回收的损失——玩家此后每次投那项能力都会重新读到自己当初栽在哪儿。
  落点跟着伤势走，而伤势第一次是随机命中的，所以反复倒下更可能把人磨成四处都差一点，
  而不是把某一项钉死到不能用；谷底校验因此仍然成立。
  疤也是给世界看的：认得出来的人会先看一眼再开口。
- 两条硬规则：**不治疗不会自行恶化**（治不起的人会被拖慢，但不会被拖进死亡螺旋）；
  **倒下只由「带着满格的伤再受一次伤」触发**。
- **恢复的吞吐上限（酒、药每天限量）是设计支柱之一**：把"钱→身体"的兑换从即时无限
  改成每天限量，高风险工作连做几天欠账当天还不清，玩家必须真正安排慢生活——"一边磨损
  一边回血"的对冲由此成立。
- **谷底校验（硬约束）**：最低状态下"睡觉 + 一颗骰打零工 + 一颗骰恢复"必须仍能覆盖
  房租与日常开销，并让状态缓慢回升。爬起来可以慢，但永远爬得起来。

### 成长

- **成长点只来自完成一个不可重复的主线或人物支线小节**，不由重复工作刷取。
  重复工作负责金钱和势力关系；真正经历完一段处境，才形成个人成长。


### 工作与机会

- 同一地点的工作是一条**梯子**：越深钱越多、看到的世界越多，门槛用声望档位；
  核心档解锁的不是工作，而是**援助 / 门路**（会改变打法的能力）。
- 布告栏是"**限量的好机会**"：报酬刻意高于同风险的日常工作，但供给有限、过期即失——
  这是"今天要不要为它挪一颗骰子"的来源。只要它管够，日常工作就没有存在意义。


### 声望

- 三个势力对应城市的三种力（官僚 = 秩序体面、劳工 = 生存暴力、富商 = 欲望资本）；
  玩家在每派眼里的位置用**每派自己的文化命名**（登记在册 / 认这张脸 / 有往来），
  不是通用的好感条。
- 结构两条要求：**中立段要够宽**（日常小幅波动不该来回翻档），**正面三档要够近**
  （每一档都够得着，不让第三档变成看得见摸不着的装饰）。
- 每派必须有**从 0 就能做的零门槛工作**，否则会出现"要声望才能挣声望"的死锁。
  核心档只认事迹，不能靠刷工。
- **敌视三条边界**：带薪工作永远不禁；可替代的便利服务可以拒绝；唯一且必要的服务
  只能涨价，不能拒绝。
- 麻烦的代价**只作用于钱/冷静/物资等其他资源，绝不再扣该势力关系本身**，否则会形成
  自我强化螺旋。
- 失败降低哪个势力由具体后果决定（谁看见失手、谁受损失、侵犯了谁的秩序），
  不由工作所属势力自动决定。


## 1. 一天的循环

```
早晨   掷骰（主角固定几颗；同伴入队后再加一颗）
白天   分配到地点：工作 / 服务 / 委托 / 休息
傍晚   城市结算：涌现事件、势力状态变化（第一版可最简）
夜间   结束一天 → 重掷骰；具体睡眠地点决定冷静恢复量
```

所有跨回合的持续、冷却、到期和延迟事件都必须对玩家可见。统一使用 Clock 表达剩余时间，
Clock 标题说明状态，备注明确归零或填满后的结果；不能只在脚本里维护隐藏计数器。

时间状态挂在真正负责它的拥有者上。地点冷却和限时工作挂在地点；跨地点可见、会阻塞世界日程的
公共事件由世界协调器拥有并显示在世界根节点。排期到期后不能隐藏 Clock，而要显示为
"已经发生 / 等待处理"，直到玩家处理或事件明确失效。

到期后被定义为"当天必须处理"的关键事件会阻止休息和推进日期。住所中的休息动作直接灰显，
并以标签列出所有尚未处理的原因；玩家必须进入对应事件并完成其实际内容。交锋必须打完，对话必须
完成，选择必须作出，不在阻塞层额外提供"忽略事件"的通用选项。事件无论成功或失败，只要已经完成，
就解除对应阻塞。系统允许多个关键事件同时等待处理。
主线触发的必看对话场景（如夜莺交锋后的真相揭开）同样使用这一阻塞机制，当晚不看完不能睡觉。

## 2. 资源模型

资源分三类，各有其家。总体"一线货币"控制在少数几种，每个动作至少触碰两种，让任何选择都是取舍。

### 2.1 物品（Inventory，可计数）

| 物品 | 作用 |
|---|---|
| 金钱 | 房租、赌注、药、酒和香烟构成底层生存压力。开局的钱刚好交不起第一次房租；委托人的预付款能让你先喘一口气，但不足以同时承担恢复与剧情开销。 |
| 私货 | 走私产出。三档销路构成"保底 vs 渠道 vs 满价"的对比，越高的价钱越依赖富商那条关系。 |
| 情报 | 世界知识碎片，可消费物品。三个消费口：换投资项目、追加一张布告栏委托、换主线查访进度。 |
| 药品 | 诊所购买，带回住所使用；不占当天行动骰，但每天只能用一份。 |
| 酒 | 老街酒馆购买。恢复冷静，代价留到下一次城市骰池。 |
| 香烟 | 老街酒馆购买。交锋里少数几个能补冷静的口子之一。 |

> 具名线索走物品（某某的订单、买家的字条）：**某处产出 → 某个动作需要它**，
> 和买烟买药是同一套概念，玩家在物品栏里看得见自己手上有什么牌。
> 判断线是「它在虚构里能不能揣进兜里、递给别人、被人拿走」——不能的（"已经查清了"
> "已经交给谁了"）仍旧留在脚本状态里。
> 工作层级由**关系势力档位**决定（特殊情况可由资产 / 能力），**不消耗情报**。

**房租是这套经济的地板。** 它把"时间"直接标价：每隔固定几天要交一次，交不上就没有
能睡觉的地方。它存在的理由不是难度，是**让每一天都有一个不属于案子的账要还**——
玩家分骰子时永远有一件事在拉扯"今天到底该挣钱还是该往前推案子"。

两条设计意图，脚本按它们取数：

- **不能提前买断。** 攒够钱一次买下几个周期，房租就退化成预付卡，不再是每个周期都要
  重新面对的一件事。它是节律，不是余额。
- **交不上不当天赶人，先动用老板的宽限，而宽限会记住你。** 准时交，他下次多等你一会儿；
  拖过一次，他下次就少等。**第一次拖欠的代价不是钱，是下一次没人等你了**——这才是欠账
  在这个世界里的形状。宽限也有底：欠到底就是锁门。
  玩家必须能提前读到自己现在还剩多少信用，否则这条线只是突然的惩罚。

### 2.2 身体状态（Team / Actor）

只有**冷静**和**伤势**两条轴，饱腹已移除（其"城市日常消耗"职能由房租接管）。
一句话分工：**冷静是你今天还能扛几件事，伤势是你这身骨头还剩多少。**

| 状态 | 被谁消耗 | 靠什么恢复 |
|---|---|---|
| **冷静** | 内容明确写出的工作/交锋坏结果 | 睡觉、喝酒、公园散步、家里仪式；交锋中只有烟和酒能补 |
| **伤势** | 高风险 / 非法工作的**坏结果**、交锋暴力升级点、冷静击穿后的溢出 | 睡觉只养得好轻伤；重伤只能靠药品和诊所治疗。是最硬的资源 |

**伤势：一条有刻度的轴，不是血条。** 旧版是健康点数加一个门槛，结果满血和半血对玩家
完全一样，掉血读不出任何含义；而"看见红了买两份药"当天就能补满，坏结果从不欠到明天。
现在是一条从 0 往上涨的刻度，只有两档：

```text
完好   身上没有需要处理的伤
轻伤   命中的那项能力 −1；睡一觉自己会好一点
重伤   该能力 −2，并少一颗行动骰；睡觉不回，只能花钱花骰子治
```

**倒下不在刻度上。** 它是「条已经满了，又挨了一下」。条填满不是终点，是"再挨一下就
完了"的警告。任何"某一格既属于轻伤又已经越线"的排法都不成立——**以界面上看得见的
那道分组留白为准**，刻度分几格、线画在哪儿，读脚本与 `Injury.cs`。

**一次只有一处伤。** 第一次受伤由引擎**随机命中一项能力**（力量/见识/敏锐/交际），
并定下与之一一对应的部位名（手/头/眼/脸），面板上读作「手伤 · 力量 −1」；之后的伤害
都加深同一处，归 0 才清除。内容层因此不需要选部位——`(injure!)` 无参。这条同时解决了
"部位分散会稀释压力"：没有第二处伤可分散，第二次受伤必然是加重。

部位随机是刻意的：**事前规划伤在哪里是负担，事后适应伤在哪里才是戏。** 玩家不必预测
某份工作会伤到什么，只需要读一行字然后调整明天的安排——带着手伤那天不去扛货，改去
整理文书。伤因此会**改变最优解**，而不只是削弱你，这是标量血条做不到的。

**刻度是可规划性的来源。** 从完好到重伤要挨好几下，而且玩家全程看得见自己在第几格。
轻伤段每晚自愈，让中等风险变成可持续的——离重伤线还远的时候，这个险可以明明白白地冒；
贴着线的时候，同一份活会把你推过去，玩家才会真的犹豫：不接、先花钱上药、还是赌这一把。
风险因此可以**主动承受**，而不是只能躲。**调数值时守的是这条曲线，不是某个具体格数。**

伤害量在内容层只分两档：一般坏结果 `(injure!)`，明确的重创（枪伤、坠落、被围住打）
`(injure-badly!)`。**不写具体数字**，写手只需判断"这一下算不算重创"。

**药品和诊所压的是同样多的伤，差别只在货币。** 药不占骰、可以提前囤，但贵；
看医生便宜，要占一颗骰子还得走一趟。同一个效果、两种付法，玩家读到的是一句
"省一颗骰，多花点钱"。治疗一次也**不该清空一整档**——那样伤势永远攒不起来，
另一条路也被压死；一档伤要么治两次，要么治一次再睡几觉，它才是一笔慢性欠账。

**两条硬规则（谷底校验的落地）**：

1. **不治疗不会自行恶化。** 伤势钳在当前值，只是不会好。治不起伤的人会被拖慢，
   但不会被拖进死亡螺旋。
2. **倒下只由「带着满格的伤再受一次伤」触发，而且不是 GAME OVER。** 结算是当天剩余
   骰子作废、付一笔很贵的治疗费（付不起则扣光现金并记账，官僚 −1）、伤势回落到重伤段。
   它是最贵的兜底，不是终局。

**冷静与伤势的关系：冷静是伤势的缓冲垫。** 今天扛的小代价先记在冷静上，睡一觉抹掉；
只有当天扛不住了（冷静见底还在扛），才会击穿溢出到身体，变成跨日的伤势。这道闸门
以前没有意义——因为闸门后面是一条读不出含义的血条；现在后面是"手伤 · 力量 −2 · 少一颗骰"，
闸门本身就有了分量。**当天扛不住的那一次开始欠明天的账**，这一句就是整个身体系统。

**冷静没有档位效果**：花掉本身不产生任何惩罚，它记录的只是"今天还能扛几次失败"；
归零之后，此后每一点消耗直接转成伤势，并以通用生理文本说明代价。

**缓冲要小。** 一天只扛得住有限的几次失败，再往下就进身体。缓冲一大，它在当天之内
根本见不了底，这条轴在城市里就不产生任何决策——早期的大缓冲版本就是这个毛病。

**但也不能小到每天开局就欠着。** 上限和过夜恢复量要配得上：如果睡一觉回不满，
第二天一开始就比前一天更紧，那不是压力曲线，是慢性失血。目标是**每天早上从满的开始扛**，
选择发生在这一天之内。自有住所比旅馆多回一点——"有个自己的地方"的差别就落在这儿。

**失态 / 失控两档已删除（2026-08-04）。** 它们的效果是"随机挑一个骰池位置 −1 / −2"，
和轻伤/重伤的"随机挑一项能力 −1 / −2"完全同构——玩家分不出这两套惩罚的差别，却要
各学一遍。删掉之后**所有机械效果只由伤势一处承担**，冷静回到它真正该是的东西：一个
纯缓冲，唯一的紧张感来自逼近 0，而不是中途挨罚。冷静低时的表达全部交给文字（手在抖、
注意力涣散），不再给机械惩罚。

骰池位置状态的结构仍在，但现在只剩两种住客：酒的宿醉（下一次城市掷骰结算后消失）
和后续人物经历可能造成的永久损伤。位置本身保持抽象：时间由玩家实际执行的行动决定，
不由骰子位置预先命名；状态附着在位置而非骰子列表下标，骰子仍可自由投入任意行动。

**交锋每回合自动 −1 已取消（2026-08-04）。** 缓冲这么小，这条流失会让长一点的交锋
在中途反复撞穿倒下线，变成"每打一场必重伤 + 反复付治疗费"。而交锋的时间压力本来就由
各场自己的钟表达——老板到场、拖走进度、危险钟——那些是可见的、每场不同的、和这一场的
处境有关的，比一条全局流失好。

于是冷静的定义收敛成一句话：**它就是"今天还能扛几次失败"**，城市和交锋里都一样，
只由失败和事件驱动，不由时间驱动。

公园散步是投入行动骰恢复冷静的主要日常方式，坏结果不回、好结果回得多。
住所不再提供"整理房间"的固定恢复。

恢复的吞吐上限（酒、药每天限量）是设计支柱之一：不靠改数值，只把"钱→身体"的兑换
从即时无限改成每天限量。高风险工作连着做几天，冷静和伤势的欠账**当天还不清**，
玩家必须真正安排慢生活（公园、看花、睡觉）——"一边磨损一边回血"的对冲由此成立。
所有上限必须在节点上可见（副标题/置灰），不做隐藏计数。

**谷底校验（硬约束）**：最低状态（重伤，少一颗骰）下，
"睡觉 + 一颗骰打零工 + 一颗骰恢复"必须仍能覆盖房租与日常开销，并让状态缓慢回升。
爬起来可以慢，但永远爬得起来——这是未来调周期性资源抽取力度的上限。

### 2.3 声望（城市名号，底层连续整数 + 离散档位）

三个势力，对应城市的三种力：

| 势力 | 内涵 |
|---|---|
| **官僚** | 秩序、体面、流程、政府、市长 |
| **劳工** | 生存、暴力、阴暗面、普通人的生活 |
| **富商** | 欲望、享乐、资本、科技、服务 |

玩家在每派眼里的位置叫**声望**——不是通用的「好感 +6」，而是**每种力用自己的文化给你起的名号**：
官僚把你**登记在册**，劳工**认你这张脸**，富商**跟你有往来**。底层存连续整数
（每次工作小步变化），效果映射到离散六档。负面段三派通用；正面三档只用通用内部名
（相识 / 信任 / 核心）做门控，面板上显示各势力的定制称呼。

| 档位 | 内部名 | 效果 |
|---|---|---|
| 敌视 | 敌视 | 该势力地点的工作判定吃一笔可见修正（原因标注"势力敌视"，与「非法」同构）；工作的中/坏结果有概率惹出一次「麻烦」（见下） |
| 冷淡 | 冷淡 | 服务和机会受限 |
| 中立 | 中立 | 默认 |
| 一档 | **相识** | 门开了：一份本派熟手活 + 被引荐给某个人 |
| 二档 | **信任** | 更深一层的营生 / 人脉 |
| 三档 | **核心** | 你进去了：关系门地点、援助、投资等会改变打法的**门路** |

档位之间的具体阈值读 `engine.scm` 与 `world.scm`。结构上只有两条要求：中立段要够宽
（日常小幅波动不该来回翻档），正面三档要够近（每一档都得着，不至于让第三档变成
永远看得见摸不着的装饰）。

**每档的诱饵按三条轨设计**（不强求每格都填，一档一个够强的**具名**诱饵即可）：

| 轨 | 是什么 | 定位 |
|---|---|---|
| 营生 | 本派地点开一份更赚的活 | 收入（基础回报） |
| 引荐 | 被介绍给一个**具名角色**→ 通往一条新支线/新地点 | 准入 →内容（最好读的勾子） |
| 门路 | 常驻能力：投资、高价销路、保护、战力援助、通行证 | 产能放大（最高级、会复利） |

各势力三档的定制名号与诱饵（内容层 `world.scm` 的 `relation-band-name:*` / `relation-goal:*`，
`（demo 暂未开放）` 表示诱饵指向的新地点/角色尚未落地——每档只写一件确实能做到的事，
不堆第二个未落地的想法凑数）：

| 势力 | 相识 | 信任 | 核心 |
|---|---|---|---|
| **官僚**〈秩序·洗白〉 | **挂号**：阿瑟主动提出程序管不了的麻烦 | **备案**：请阿瑟提级、延期并办理通行证 | **有里子**：引荐市长秘书（demo 暂未开放） |
| **劳工**〈组织·施压〉 | **面熟**：参加码头搬运 | **够朋友**：参与货船抢修 | **自己人**：在扣船交锋中得到弗兰克认可；首演夜可请求外圈人手 |
| **富商**〈资本·圈层〉 | **有往来**：私货能出手·陪代理谈投资（渠道价，非最高价） | **座上宾**：私货满价收购·投资本金打折 | **合伙人**：引荐博士·实验室科技线（demo 暂未开放） |

三条线的高潮各不相同：官僚终点是**保护 + 主线权限**，劳工终点是**组织援助 + 非法施压**，
富商终点是**复利投资 + 科技线**——对应「产能放大是最高级的回报」，三边不撞车。
劳工的核心档通过[弗兰克的人物线](第一章-弗兰克与不开的船设计.md)落实：
主线进入老街后开放限期货船抢修；抢修结算后进入唯一的扣船交锋。

抢修是一件**有期限的集体活**：只使用一根统一投入进度；到期按玩家的实际参与结算，
但不会吞掉后续扣船内容。它的代价落在坏结果上，而不是每一班上——一整队人轮班上泵，
不是一个人在雨里熬着。这条区分决定了它该扣什么（对照踩点那种独自蹲守的线）。
本线不再开放新的通用走私系统、查账或旧悬案。得到弗兰克认可后，夜莺主线终场可以请求他的人守外圈。

**爬升方式随档位换，不是从头到尾刷同一种动作就能通关**（`engine.scm` 的
`grant-work-relation!` / `grant-favor-relation!`，阈值 `work-relation-cap` / `favor-relation-cap`）：

- **面熟（相识）**：每派都必须有一份**从 0 就能做**的零门槛工作，好结果调用
  `grant-work-relation!`，只在该势力当前值 < 3 时生效——劳工是"搬运"，官僚是"整理警局文书"，
  富商是"联络货主"。这份工作不能被任何关系门槛卡住，否则会出现"想挣声望，
  却先要声望才能接到能挣声望的活"的死锁（劳工线一度只把关系工作挂在"替工头记账"上，
  而记账本身又要求相识才能接，导致新档从 0 永远爬不动——已修）。
  出勤混到相识后，这份基础工作不再管声望，再触发只提示"普通做工已经混得再熟不过了——
  想更进一步，得接不计报酬的忙"。
- **够朋友（信任）**：相识解锁的第二份工作，或不计报酬的帮忙类动作，都调用
  `grant-favor-relation!`，只在值 < 5 时生效，封顶提示同上一档。劳工的例子是"替工头记账"——
  工钱比搬运低，但要工头已经把你当熟人才让你碰；另一类是替弗兰克查账、
  替阿瑟处理麻烦、陪货运代理应酬/核对条件这类不计报酬的人情动作。
  两类活动都算"够朋友"，不区分是否领工钱——区分点在于"要不要先熟人才接得到"。
- **自己人 / 有里子 / 合伙人（核心）**：只认事迹——人物小节或主线段落真正完成时
  （乔或弗兰克的人物支线、阿瑟人物支线、第一笔货运投资结清）直接调用 `change-faction-relation!`，
  +1～2，不设上限。这是唯一能越过 `favor-relation-cap` 的路，也是"核心档必须靠做成一件事，
  不能靠刷工"的落地方式。
- 一次成功最多算一档来源：普通工作永远算"面熟"，帮忙类动作永远算"够朋友"，
  不会因为玩家关系已经很高就自动升级成"事迹"分量。
- 失败降低哪个势力，不由工作所属势力自动决定，而由具体后果决定：谁看见玩家失手、谁受到损失、
  玩家侵犯了谁的秩序，就降低谁的关系。普通的身体受伤、返工或少赚一笔通常不影响势力关系；
  只有公开失职、背叛或政治性越界才扣关系。例如走私成功且未暴露不会降低官僚关系，被巡警发现的
  坏结果才降低官僚关系。
- 三个势力**互不排斥**：现阶段唯一约束是时间有限，理论上刷不满三边。
- 非法行动必须在副标题或描述标签中点名事败会得罪的势力；关系损失只挂在暴露、失职或
  背叛等具体结果上，不作为行动的固定入场费。
- 关系解锁的地点一旦被发现便永久留在地图上；关系跌回门槛以下时地点置灰，而不是消失。
- 势力面板显示当前档位、到下一有效解锁档的差值，以及内容层配置的具体解锁名称。
  非此即彼的对抗留给未来的主线关键选择。
- 玩家看到的永远是清晰的档位，底下是可以慢慢磨的进度。

**敌视时该禁什么、不该禁什么**：敌视是玩家自己惹出来的代价，但代价不能堵死玩家
挣回关系的路，也不能卡住游戏本身的运转。三条边界——

1. **带薪工作永远不禁。** 面熟档就是靠出勤挣的；工作一旦被禁，敌视就成了回不去的死局。
   高阶工作（相识/信任门槛解锁的那些）敌视时天然就够不到，不需要再额外处理；
   这里只保证零门槛的基础工作（整理文书、搬运……）永远可选。
2. **可替代的便利服务，敌视时可以直接拒绝。** 判断标准是"这件事在别处有免费或更省事的
   替代路径"：警局的"延期""办案通行证"都是锦上添花的程序工具，不是唯一手段，
   拒绝了也不会卡关，直接 `:disabled` 并给出理由（"阿瑟现在不会替你签发"）。
   这一类的典型例子还包括"用钱换取本可以免费获得的效果"——比如酒馆的"打酒/点一杯酒"
   是花钱买冷静恢复，玩家始终还有公园散步这条免费路径，禁掉也不影响生存；这类服务
   一旦以后要接入敌视惩罚，也走"直接拒绝"而不是"涨价"。
3. **唯一且必要的服务，只能涨价，不能拒绝。** 诊所买药/看医生是压伤势的唯一采购渠道，
   敌视时只把价钱往上调（`hostile-markup`），绝不整个禁掉——否则会把玩家的
   生存路径堵死，变成惩罚过了头。
4. 当前只在**官僚**一侧落了实际内容（诊所涨价、警局延期/通行证拒绝），因为"走私被巡警
   发现 → 官僚 −2"是玩家在这个 demo 里唯一现实会走到敌视的路；劳工/富商的敌视规则留着，
   但暂不专门写内容——以后要给它们加东西时，请先套上面三条边界，再动笔。

**麻烦**：敌视势力的地点，零门槛工作的中/坏结果有一定概率惹出一个「麻烦」——一根挂在
地点上的限时时钟，同时该地点出现一个可以主动处理它的行动（占骰子、要判定，同样吃
"势力敌视"的修正，成功即清除）。拖到到期会自动付出一次代价。

一条硬约束：**代价只作用于钱/冷静/物资等其他资源，绝不再扣该势力关系本身**，
否则会形成"关系差 → 麻烦 → 关系更差"的自我强化螺旋。到期代价和「麻烦」本身都要
明确提示玩家；具体资源与说法（罚单、泼漆、被顺走东西……）按各地点的势力气质写，
不强求三派用一样的措辞。实现见 `make-trouble`（engine.scm）。

声望也是跨线耦合的载体：码头、警局、货运三处分别提供夜莺真相调查的一条证据；
玩家先经营哪条生活线，就先取得哪一类证词或记录。

### 2.4 个人能力与成长点

主角有四项个人能力，有效范围为 0–4。能力直接加入判定总和，
提高掷骰可靠性，并在交锋中解锁不同的处理方法：

| 能力  | 内部 ID       | 主要用途            |
| --- | ----------- | --------------- |
| 力量  | `violence`  | 劳动、压制、追逐、承受身体风险 |
| 见识  | `knowledge` | 账目、医学、技术、档案     |
| 敏锐  | `sharpness` | 观察、识破、寻找异常、把握时机 |
| 交际  | `social`    | 说服、欺骗、交易、威慑、周旋  |

成长点只来自**完成一个不可重复的主线或人物支线小节**，不由重复工作直接刷取。失败若已经让
小节不可逆地推进，也算完成。玩家在人物成长面板中把可用成长点投入任一未满级能力；住所不提供
重复的升级入口。
重复工作负责金钱和势力关系；真正经历完一段处境，才形成个人成长。

### 2.5 人物同伴（当前第一章不启用）

当前第一章不再通过乔获得同伴骰，也不实现坍塌、受伤、照料和招募。
乔的当前边界见[第一章：乔](第一章-乔设计.md)。以下内容是冻结的后续系统候选，
来自[后续章节候选：码头坍塌与乔受伤](后续章节候选-码头坍塌与乔受伤.md)，不能作为第一章执行依据。

乔的人物小节推进后，招募不再是"信任磨满就能
邀请"的单一数值门槛，而是一场**必须每天投入、结果随维护质量分叉**的养伤危机——这是本作
第一个"daily-tended trajectory"结构：连续几天，玩家每天都要决定是否维护，维护的方式和质量
决定它最终的走向，不管或管不好都会真的变差，不是摆设时钟。照顾与用药是两种独立手段，
各自每天最多一次。

**触发**：码头坍塌是主线进入老街后独立发生的两日公共事件，不依赖乔的关系或新机器建设。
玩家完成「接送孩子」后，事故结束会打开乔的私人养伤线；公共救援结果决定其初始伤势。
关系没有达到门槛时，乔在事故后以半残疾、非同伴状态进入第二章。不再使用每日伪随机工伤。

触发对白里顺带交代了他为什么不去诊所：这座城市的医疗是门生意，保险公司和诊所是一伙的——
没保单进不去门，有保单也是照保单上的价钱往死里治，一张账单能顶工人大半年工钱。扛活的人
保不起这个，伤了只能自己扛或求朋友帮衬。这是本作的世界观底色（黑色电影年代的美国：
医疗与保险捆绑成产业，普通劳工被排除在外），以后写劳工线或其他因病/因伤的内容，
这条逻辑可以直接沿用，不必每次重新解释诊所为什么"帮不上忙"。

**每天有两种维护方式，各最多一次，权衡不同**：

| 方式 | 消耗 | 特点 |
|---|---|---|
| 照顾乔 | 一颗行动骰，低风险社交判定 | 好结果推得多，坏结果不推进还搭上冷静 |
| 给乔用药 | 一份药品，无需掷骰 | 稳定推进，但药品是玩家自己压伤势的同一份资源 |

照顾失败不倒扣进度，顶多是没有进展——代价已经是白扔一颗骰子加 1 点冷静，
再往回扣等于罚两次，而且"尽力照顾反而害了他"也不成立。
放着不管（当天两种方式都没做）才会倒扣——这是"不维护会变差"的具体落地。
于是进度跌成负数只有一条路：整天完全不管他。死亡结局因此不再是手气问题，而是选择问题。
照料进度是乔身上的一条可见时钟（填满即痊愈），和"乔的伤势"倒计时并排。
原本的设计是全程不显示数字、只靠乔的处境描述给模糊暗示、揭晓留到期满那一刻；
实测下来这个"模糊"变成了"没有"——档位跨度太宽，投一次骰子界面上什么都不动，
玩家无法判断自己的投入有没有用。现在改为进度可见，处境描述（"他脸色不太好"……）
保留为氛围与负数区间的表达：时钟钳在 0 以上，跌破 0 的死亡风险只由文字承担。

**结算三分叉**（`finish-injury!`）。痊愈这一叉不必等期满：进度一填满就立即结算，
否则满格之后继续挂着，只会被"当天不管"的倒扣把已经填满的条子重新掏空，反直觉。
其余两叉在期满时按累计进度判定：

- **填满（悉心照顾）**：乔痊愈，可以按原始状态邀请入队。
- **没填满、但没跌破 0（勉强留住）**：乔活下来但留下残疾；入队后每天仍提供一颗骰，该骰永久降质。
- **进度 < 0（没能留住）**：乔死亡，不再入队；这份交情不会转化为势力敌视，
  但这一局里再没有机会重新招募他。

其余同伴规则不变：
- 入队后的次日开始，他每天在城市模式提供一颗自己的行动骰；同伴骰可以用于工作和人物行动，
  不能带入交锋。
- 同伴冷静耗尽会暂离；在家休息会逐日恢复乔的冷静，回满后自动归队。
- 乔加入队伍本身就是人物线的帮助与产能回报，不再另设「请乔出面」之类的交锋援助。
- 入队后乔不再刷新码头和居民区的个人请求。

这套"人物投入→公共危机→连续维护→结局真的分叉"的结构是
通用的，以后其他人物支线或城市设施要做类似的"悉心经营 vs 放任不管"内容，可以直接照搬，
不必每次重新发明。

### 2.6 资产

由玩家拥有的**住所**推导，不做独立数值：

| 住所 | 资产等级 |
|---|---|
| 旅馆（付房租） | 低 |
| 公寓（一次性买断） | 中 |

资产等级是富商圈的隐形门槛（如夜总会看资产而不只看关系），也有故事级回报：
公寓会改变夜莺主线小节二「抢人」的第一幕：场景发生在自己的住处，
玩家熟悉后窗与消防梯，离开公寓的路线开局多一格。

## 3. 地点

每个地点 = **一张城市的脸** + **2–3 个动词** + **一个住在这儿的人** + **一个自走的状态**。
地点是"城市向你提的一个问题"。动词分两类：

- **工作**：可重复、掷骰（`roll-action`）、耗状态、产资源。
- **行动 / 服务**：即时（`instant-action`）、花钱换物或服务。

### 3.3 码头居民区：城寨

**这是全城唯一一个不遵守「一张脸 + 2–3 个动词」的地点。**

老街的居民区不是一片平房，是一栋长起来的东西：原本几幢货栈工人的公寓，几十年里被住户自己
往上、往外加盖，天桥把它们缝在一起，缝到最后分不出哪一段是谁盖的。天光进不到下面几层，
白天也点灯。没有门牌，路是私有的——要上到某一层，得先穿过别人家的厨房。

它对玩家的第一个性质是：**外来者读不懂它。** 你不是"到了一个地点"，你是站在一个入口前面，
只看得见眼前那一小块。这里没有地图，有的是你认识谁。

第二个性质是：**它是自治的。** 不是无人管的贫民窟，而是有自己的规矩、自己的裁决人、
自己的经济和消息网络。警察不进来，进来也办不成事。所以这里同时是藏人的地方和藏东西的地方。

> **口径提醒**：这里借的是九龙城寨的**空间性格**——垂直、密集、自建、自治、外人读不懂——
> 不是它的地域。世界仍然是上世纪美国的港口城市；写成移民聚居的违建街区、码头棚户加盖，
> 不要出现任何香港或中国的地名、称谓和器物。

#### 结构含义：它靠探索长出来，不靠解锁动词

别的地点是"一张脸 + 几个动词"，进去就全看见了。城寨相反：**你在里面探索，探索会长出新的
内部地点**，每个内部地点有自己的脸、自己的进度钟、自己住着的人。你事先不知道哪条路通往哪里。

这条结构第一次用在第一章小节二（追查勒索者），但城寨本身是**常驻的**：小节二结束后它不关门，
那次探索里认识的人和摸熟的路都留在城里。只有"这一次调查专有的机会"（某间空屋里还能搬走的
东西、当铺里一次性的赎回）会随小节结束而过期——**地点不消失，机会消失**。

进城寨的判定统一受「老街的戒心」影响（可见负修正，随熟脸递减）。所以这里始终有两条解法：
硬闯着查，或者先花时间混成半个自己人再进去。

## 4. 工作模型

每个工作只分为**低风险**或**高风险**，掷骰产生 **好 / 中立 / 坏** 三种结果（沿用现有 `roll-action`）。
惩罚货币的严重度排序：**钱 → 冷静 → 伤势**（直接加伤势是全局最重的惩罚）。收益随风险单调上升。

**统一判定规则：**

```text
准备值 B = 放入骰 + 技能 + 修正
B 直接查一张「按值定制的结果分布表」（不再加命运骰求和）。
命运骰 d6 仍摇，只作为在赔率条上的落点，不改变分布本身。

分布表（六面里各档占几面，坏 / 中 / 好），低面更差、高面更好：
  B≤1 : 3 / 3 / 0   —— 五五开，有空间
  B=2 : 2 / 3 / 1
  B=3 : 1 / 3 / 2   —— 均衡
  B=4 : 1 / 2 / 3   —— 均衡偏优
  B=5 : 0 / 2 / 4   —— 显著优势
  B=6 : 0 / 1 / 5   —— 很强
  B≥7 : 0 / 0 / 6   —— 技能+好骰堆出的「干啥都成」
```

**为什么是查表而非两骰求和**：放入骰 + 命运骰两个 d6 相加是三角分布，天然向中间回归，
会把放 1 与放 6 的性格都抹平（"概率对了但没手感"）。查表让每个准备值都有清晰、
独立的性格，同时结算时仍摇一颗 d6（保留"这把会不会中"的悬念）——随机性锚在放入骰的值上，
而不是再赌一颗与之无关的骰子。这贴近 Citizen Sleeper 的分配张力：**你放的那颗骰子就是你的命运**。

技能与修正通过抬高 / 压低 B 来移动你在这张表上的行：**技能就是把弱骰抬成强结果的杠杆**——
新手（技能0）放 1 落在五五开那行；老手（技能4）放 1 → B=5 直接进"显著优势"。
低/高风险都不改变分布；风险由各档结果的收益和代价表达。
「非法」是难度标签：因为超越法律边界而吃一笔固定修正（在表上往下移几行），同时通常意味着更高风险与收益。
其他情境修正继续以可见 `modifier` 叠加。玩家放入骰后，卡面用六格**命运条**直接显示当前 B 的
坏/中/好占比（它本身就是一条赔率条）；结算时命运骰 1–6 落在其中一格（引擎实现见 `FateStrip.cs`）。
表中数字可调，结构是关键。

**工作助手**（`工作` / `关系工作` DSL，见 engine.scm）：负责统一结构（req-die + roll）、
断言 faction/risk 合法、生成风险标签，并仅为「非法」注入难度修正；只有 `关系工作` 的好结果
自动增加对应势力关系。**好 / 中立 / 坏三个结果由每项工作显式传入**，
避免自动生成固定收益导致所有工作同质化。非法工作失败掉关系，写在该工作的坏结果里（可见）。

**风险提示不推迟**：工作节点 `:subtitle` 直接标注风险（如"高风险 · 可能伤身"），
让玩家行动前就知道"可能受伤 / 掉关系"，无需先做完整 UI。

| 风险级 | 例子 | 好（成功） | 中立 | 坏（失败） |
|---|---|---|---|---|
| 低 | 文书、接孩子、查账 | 少量资源或关系 | 少量收益，通常无损失 | 轻：掉一点冷静或少量钱 |
| 高 | 搬运、赌博、危险交涉 | 较高收益或显著推进 | 仍可能付出冷静、钱或轻伤 | 重：较多冷静、关系损失，或受伤 |

「非法」不属于第三档风险，而是独立标签和一笔固定难度修正。非法行动通常按高风险书写，
并在失败结果中明确谁会追究、会损失哪条关系。

非法工作的中结果不得是纯正收益：至少付出冷静、少量金钱、暴露进度或减少产出之一。

这就是"不同活法产生不同的一周"：服务员的人平稳、钱少、冷静掉得慢；扛货走私的人钱多，
但身体和精神在磨损，还赌着关系。

走私是私货链的源头：好结果给私货和情报，坏结果掉官僚关系和冷静。
它的纸面收益和直接产钱的活相当，**但满额兑现需要富商线的关系**——
不经营富商线的走私者只能在码头散卖，拿一个明显低的价。劳工线由此第一次"需要"另一条线。

### 4.1 工作阶梯（越干越深、越深越看见）

同一地点的工作往下走是一条梯子，越深钱越多、看到的世界越多，门槛用**声望档位**（不消耗情报）：

```
一层  零工     人人可做     +钱 −状态 +本地势力声望
二层  熟手活   需相识       +更多钱  世界模型漏出（产出情报 / 具名线索）
三层  非法的活 需信任       高薪 / 违法  直连主线
```

工作阶梯到「信任」封顶；**核心档解锁的不是工作，而是援助 / 门路**（战力援助、
关系门地点、投资等会改变打法的能力）——正面三档不与三层工作一一对应。

## 5. 布告栏

布告栏是顶层地点（始终可见），是"选项集动态化"的载体：每隔几天补充到固定张数，
每张只挂几天，并用 Clock 显示期限。完成或尝试后委托消失；同名委托不会同时出现。

**它的定位是"限量的好机会"**：报酬刻意高于同风险的日常工作，但供给有限、过期即失——
这就是"今天要不要为它挪一颗骰子"的来源。反过来说，只要它的报酬贴近日常工作，
布告栏就没有存在意义；只要它管够，日常工作就没有存在意义。

模板池覆盖四项能力各一张，另加一张消耗物品、不掷骰的即时委托（送药）——
让"手上正好有那件东西"本身成为一种机会。常驻行动"向消息灵通的人打听"消耗一份情报，
不占骰，立即多翻出一张限时委托：情报在这里换的是**机会**，不是钱。
在板委托与剩余期限随存档保存。

## 6. 主线：夜莺委托线

此处只记录它与城市系统的关系。

结构：**故事提出具体账单 → 城市生活提供多种解决方式 → 完成账单打开新的城市结构。**
三个小节是三张到期账单：在酒馆与码头查出盯梢者的藏身处、给她弄到一种临时保护、
在六条路线里选定并落实一条（付钱封口 / 交锋了断 / 送她走 / 立案送警 / 完整移交 / 坐视不管）。
每张账单都有横跨不同生活线的多条抵达路径（钱可以买、关系可以换、
程序可以压、拳头可以抢，也可以背过身去）；交锋是结算方式之一，不是小节本体——要么嵌在
抵达路径里（你主动上门），要么是账单未清时的后果（他们找上门）。

对城市系统的意义：

- 主线是存量的**水槽**——它提供几笔大到必须专门去攒的开销（首期、封口价、送她走的舱位），
  "攒大钱"因此有了意义；同时它是经济系统的**扩张器**（每拍结算打开新工作、新节点、新场景）。
- 每个小节无论成功或失败，只要状态已推进就奖励成长点——这是成长点的主要来源。
- 夜莺状态卡常驻账单行，让玩家每天早上能回答"我现在缺什么、到期日是哪天、
  我打算用哪种活法把它办成"。

## 7. 交锋：成长兑现的地方

城市生活里长出来的东西 = 交锋中的准备和动词。三种生活方式共同消耗行动时间，但回报不对称：

- 劳工通过弗兰克的货船线获得组织援助；得到他认可后，终场可以请求他的人守外圈。
- 官僚通过文书、走访和具体程序获得一次延期与办案通行证。通行证是最多持有一张、有再次签发冷却的
  一次性物品；当前可在码头交锋中压住危险钟的推进节奏，未来可由其他地点提供不同的使用行动。
- 富商通过合同、应酬、考察和投资获得延迟收入，并为私货提供高价销路；它增强资源能力，不增加直接战力。

当前码头交锋本身偏向劳工，这是允许的。无路线玩家仍有力量、敏锐、交际和金钱等基础方法。
交锋只返回成功或失败，不按最后手段重写码头政治状态。

第一次交锋另有可选目标「异常货单」。它与主目标争夺骰子；取得后即使本场失败也保留，没能取得
则永久错失。带回城市后可以继续持有，或花时间交给乔、阿瑟、货运代理之一。去向不修改已结束
的交锋，但持续改变人物关系、官方检查或投资条件。

交锋结算与城市之间**不做暗线耦合**：玩家事先看不到、也无法决策的隐形奖惩
（如结算后自动加钱/加关系、隐形保险）不算真正的耦合，一律不做。

## 8. 城市涌现事件（暂缓）

每回合结算（或开始）有概率从可用事件堆抽取随机事件，在某些地点产生变化。

## 10. 待办 / 未决

- **可见风险（UI）**：玩家选中 / 放入卡片时，卡片给一小段"可能后果 / 风险"提示，不用详细，
  但要让玩家知道这回事。属 UI 层，货币层稳定后再做。
- **势力对抗**：现阶段三派可并行刷，仅受时间约束；后期主线关键选择引入非此即彼。
- **城市涌现事件**：事件堆与抽取机制，见 §8。
- **判定重构已选定方案B**（数字骰 + 命运条，见 §4 与 `FateStrip.cs`）；
  方案A（记号骰）留档作为未采用的备选。
- **规划中的地点**：见 §3.2。
- **更大的主线章节**：夜莺线是自闭环的最小骨架；未来用更大章节替换或扩展时，
  沿用 [故事设计总纲.md](故事设计总纲.md) §2 的四条结构原则作为写作模板。
- **恢复量对 2 点缓冲明显过大**：酒（城市 +2 / 交锋 +3）、香烟 +2、公园散步好结果 +2、
  看花 +2、听歌 +2 现在**全都是一次填满**，彼此之间不再有强弱差别；公寓睡觉 +2 也是满的，
  旅馆 +1 只回一半（这一条反而让住所升级有了意义，可留）。等这版试过手感后统一重定，
  方向是把大部分压到 +1，把"一次填满"留给真正花钱的那几个。
- **冷静的入场费**：现在冷静只由失败驱动。若想让"早上分骰子时冷静就参与算术"，
  可以让高风险 / 非法行动在**投骰之前**预付 1 点，不管结果如何。2 点缓冲下这会非常硬，
  要先确认失败驱动本身够不够。
- **冷静系统的其他未落地部分**：城市恢复动词随缺钱程度自动浮动机会成本；诊所经济的进一步细节。
- **官僚线缺可重复的「保护/权限」产出**：按 §2.3 的定位，官僚终点是「保护 + 主线权限」，
  刻意不产钱。但目前它的保护/权限**只以一次性的夜莺剧情钥匙兑现**（调案卷、教训交锋、
  立案、通行证、抢人放行）——这些用完后，官僚关系在城市生活层就没有持续值得投入的去处，
  「攒了没处花」。作为临时补丁，入门工「整理警局文书」已把现金回报提到与其他生计持平；
  但这只是遮住问题，不是解法。**长远应给官僚一条可重复的、非经济的价值**（如「消一件麻烦 /
  抹一条对你不利的记录」的保护服务，或把它接到某条权限/结局路线上），使建设官僚关系本身
  持续有意义，而不必靠现金补足。此项**暂缓**：当前 demo 只有码头 / 劳工线内容较丰富，
  官僚与富商线待后续补内容时一并处理。
