# 第一章：林与机器

> 定位：第一章的一条轻量人物线。玩家在码头认识林，参与试验装卸机的安装调试，
> 看见他作为研究者和操作者对机器本身的热爱。
>
> 第一章不讨论机器造成的裁员，不安排码头坍塌、救援、劳工冲突或剧院任务。
> 这些内容如需使用，必须在后续章节重新设计。

## 1. 人物支点

林相信：**技术能够把人从危险、重复、没有意义的劳动中解放出来。**

第一章先表现这份信念积极而有吸引力的一面：他善良、聪明、专注，愿意亲自弄脏手，
也真心欣赏熟练工人的经验。他不是站在机器旁讲道理的人，而是最了解它、最愿意亲手操作它的人。

这一章只留下一个轻微而不解释的阴影：当他把老操作者多年积累的经验写进机器时，
他看见的是知识被保存和推广，没有继续追问那个人以后靠什么证明自己的价值。

## 2. 第一章结构

> 机器上岸 → 参加安装调试 → 把老操作者的经验写进机器
> → 最终负载试验 → 开放试验工棚工作

| 段落 | 类型 | 玩家投入 | 功能 |
|---|---|---|---|
| 机器上岸 | 城市变化与初见 | 无或第一次工作行动 | 开放试验工棚，认识林 |
| 安装调试 | 统一持续目标 | 数日内可反复投入行动 | 提供见识向人物内容与生活方向 |
| 老操作者的经验 | 项目过程剧情 | 不另开任务 | 表现林如何理解人的经验 |
| 最终负载试验 | 项目结算场景 | 无独立交锋 | 结算机器状态与人物关系 |
| 协助机器试验 | 可重复工作 | 普通工作行动 | 第一章生活方式扩容 |

全线没有专属交锋，也不再在第一章回收社会后果。

## 3. 机器上岸

### 3.1 触发

主线进入老街阶段后，试验装卸机运抵码头，地点「三号货栈的试验工棚」开放。

机器到达是城市变化，不要求玩家先认识林，也不依赖其他人物线。玩家可以通过查看机器或参加安装认识他。

### 3.2 初见

林正在机器上下反复检查，而不是站在一旁监督工人。他说话容易过快，谈到液压、配重和控制响应时会忘记时间，
但发现玩家听不懂时会重新换一种说法，不嘲笑对方。

初见只需要让玩家记住两件事：

- 他真心喜欢机器，也真正理解机器；
- 他认为危险的体力活迟早应该消失，这对他而言是一件明显的好事。

## 4. 安装与调试

### 4.1 统一项目

安装调试只有一根持续进度，不拆成寻找控制器、搜集零件、铺线、配重和负载测试等多条任务。

林负责控制器、仪表和液压系统等精密部分，玩家提供现场需要的人手：

- 搬动与固定底座；
- 铺设线路和油管；
- 安装配重；
- 在负载试验中记录和调整。

这些是同一行动在不同阶段的结果文字，不是四个并列目标。

### 4.2 验收窗口

机器上岸后给出清楚的验收日。玩家不参与，公司的装配人员也会完成最低限度安装；
因此人物线不会永远停在一台坏机器前，也不会阻塞任何主线。

| 结果 | 条件 | 后果 |
|---|---|---|
| `精密调试` | 玩家在验收前完成项目 | 机器能够稳定处理不规则负载；林信任玩家的现场判断 |
| `保守试运` | 玩家没有完成或没有参与 | 机器只能按保守参数运行；林与玩家保持陌生或普通相识 |

这两个状态主要作为以后可能使用的存量。第一章不通过救援、裁员或剧院事件立即兑现它们。

## 5. 把一双老手写进机器

安装过程中，第一次负载试验始终有轻微摆动。仪表读数正常，但一名做了多年的老吊机手能从钢索声音、
货物边缘和脚下振动判断它何时将要失稳。他无法把经验说成工程术语，只知道什么时候应该收力。

林没有轻视他。相反，他请对方反复示范，自己记录时机和负载变化，再把这套经验转成控制参数。

这段通过项目推进中的对话和结果表现，不新增寻找人物、说服人物或收集记录的任务。

林真诚感谢老操作者，并为成果兴奋：

> 下一台机器也能知道这些；以后不必再等一个人花几十年学会。

第一章不让两人争吵，也不宣布谁对谁错。老操作者可以为自己的经验被承认而骄傲，
也可以在机器稳定下来以后沉默片刻。玩家只需要记住这一幕。

## 6. 最终负载试验

验收日自动播放一次简短结算场景，不进入交锋：

- `精密调试`：林亲自操作，机器稳定吊起一件不规则重物，并在狭窄范围内准确停住；
- `保守试运`：机器完成基本举升，但只能保持更大的安全距离，由公司按保守条件签字。

无论结果如何，机器本身都不是失败品。区别是玩家是否亲手参与过它从粗笨到可靠的过程。

## 7. 生活回报

只要玩家参加过安装，验收后试验工棚开放可重复工作「协助机器试验」。

- 它是一份稳定的见识向工作；
- 产出工资以及与林的相识；
- 工作结果继续表现机器的小改进和林的操作习惯；
- 不再从这份工作长出第一章裁员、救援或劳工冲突。

这项工作是林线对城市行动集合的直接扩展，也是第一章完成这条轻线的主要玩法回报。

## 8. 状态与章节结算

第一章只保存必要状态：

| 状态组 | 取值 |
|---|---|
| 与林的关系 | `陌生 / 认识 / 信任` |
| 是否参加安装 | `未参加 / 已参加` |
| 机器状态 | `未验收 / 保守试运 / 精密调试` |
| 工棚工作 | `未开放 / 已开放` |

第一章结束时：

| 经历 | 章末结果 |
|---|---|
| 从未接触 | 公司完成保守试运；林与玩家陌生 |
| 参加但未完成 | 机器保守试运；玩家认识林并开放工棚工作 |
| 完成安装调试 | 机器精密调试；林信任玩家的现场判断并开放工棚工作 |

第一章不要求玩家完成林线，也不因未参与而补发人物冲突或负面命运。

## 9. 当前执行边界

第一章 Demo 只需实现：

1. 机器上岸与试验工棚开放；
2. 一个统一的安装调试持续目标；
3. 验收日与`保守试运 / 精密调试`结算；
4. 项目过程中老操作者经验被写入机器的简短内容；
5. 最终负载试验结算场景；
6. 可重复工作「协助机器试验」；
7. 四组必要状态的保存、读取和章节结算。

不在第一章实现：码头坍塌、机器救援行动、救援后对话、「少了一班人」、旧工人培训、
剧院技术帮助、林与薇拉关系、裁员争议，以及第二章技术与劳工冲突。
