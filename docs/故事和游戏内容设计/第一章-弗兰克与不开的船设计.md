# 第一章：弗兰克与不开的船

> 定位：第一章最完整的码头人物切片。玩家先在普通工作中看见弗兰克为什么得到拥护，
> 再通过一场扣船交锋看见：他对自己人的照顾与他掌握的地方权力，本来就是同一件事。
>
> 本线不包含码头坍塌、机器劳工冲突或第二章城市局势。货船抢修是持续城市目标，
> **不是交锋**；全线只有「船修好了却不开」一场专属交锋。
> 具体 Clock 长度、判定数值与对白以内容脚本为准。

## 1. 人物支点

弗兰克不是正式的工会领袖，而是码头工头、组织者和老街事实上的头人。

他的原则是：

> **外面的规矩不会照顾我们，所以自己人必须由我们照顾。**

他记得谁受了伤、谁欠房租、谁家里有人生病，也会用扣船、藏零件、做假账和私下分配等非法手段解决问题。
人们拥护他，不只是因为怕他，而是因为钱、药、工作和保护真的会经过他的手抵达需要的人。

这也构成他的阴影：谁算自己人、谁应该先得到帮助、所有人该承担多大风险，最后都由他决定。
他享受别人等待他作决定，但这种享受不能写成虚伪；权力欲与责任感在他身上不可分割。

## 2. 第一章结构

> 追逐中的摩托车背影 → 货船抢修 → 船修好了却不开
> → 分钱 → 老金牌香烟 → 莱恩主线回收 → 首演夜回收

| 段落 | 类型 | 玩家投入 | 功能 |
|---|---|---|---|
| 摩托车背影 | 主线伏笔 | 无额外投入 | 先把弗兰克放进疑点中 |
| 货船抢修 | 限期持续目标 | 数日内可反复投入行动 | 表现他的工作能力和领导方式 |
| 船修好了却不开 | 唯一人物交锋 | 一场对峙 | 表现照顾、非法手段与权力 |
| 分钱 | 事后剧情 | 无 | 说明人们为什么拥护他 |
| 老金牌香烟 | 短对话 | 无 | 回收追逐疑点，但不做定罪证据 |
| 莱恩 | 主线接口 | 读取既有状态 | 表现“我们的人由我们处置” |
| 首演夜 | 主线接口 | 读取既有状态 | 把个人关系兑现为有自己意志的人手 |

本线不再追加查账、旧悬案、工伤照料或第二场人物交锋。

## 3. 摩托车背影

### 3.1 主线出现

交割夜追逐中，玩家快要追上莱恩。一辆摩托车从侧面冲出，前灯迫使玩家闪避，莱恩趁机逃走。

玩家看不清骑手的脸，只留下几项印象：皮夹克的背影、摩托车后架绑绳的方式，以及对方没有停车询问便介入。
后来在码头见到弗兰克时，玩家觉得背影似曾相识，但第一章不把它写成可以定罪的物证。

弗兰克当时未必知道莱恩为何被追。他的本能只是：一个外地人在追老街的人。

### 3.2 与人物线的关系

摩托车只负责伏笔，不作为货船抢修的进入门槛。玩家即使在追逐中没有看清线索，也能正常认识弗兰克。

## 4. 货船抢修

### 4.1 触发与期限

主线进入老街阶段后，一艘进水的旧货船被拖回码头。船主只给出一个很短的抢修窗口；
到期仍不能恢复基本航行，工作便会被转交，码头工人也拿不到紧急抢修的额外报酬。

事件开放「参加货船抢修」。它是一根统一的持续进度，不拆成泵水、补船板、固定货物等多条任务。
玩家可以在期限内反复投入行动；普通结果推进工作，坏结果消耗身体或冷静，但不因为一次失手永久关闭人物线。

### 4.2 弗兰克如何被看见

每次抢修的结果文字从以下方面选取具体片段，不让弗兰克只在项目结算时出现：

- 安排体弱的老工人清点工具，使其仍能算一班工；
- 记得谁熟悉泵房、谁会补船板，把人放到合适的位置；
- 弄来来源不明但确实能用的零件；
- 有人受伤时立即换人，必要时亲自顶上；
- 给疲惫的人弄来食物和药，同时要求还能站着的人继续干；
- 在所有人说完以后作出决定，也自然地享受那一刻的安静。

玩家看见的是一群人围绕弗兰克工作的事实，而不是一段宣称他有领导力的对白。

### 4.3 抢修结算

| 结果 | 条件 | 对后续交锋的影响 |
|---|---|---|
| `按时修好` | 玩家充分参与并完成进度 | 抢修记录完整，工人团结，谈判起点较好 |
| `勉强修好` | 玩家参与但项目未填满，码头工人到期补完 | 代理可以用延期和损失压价 |
| `未介入` | 玩家没有参加 | 弗兰克仍带人完成基本抢修；玩家不获得抢修记录与私人认可 |

无论哪一档，船都恢复到可以离港的最低状态，因此「船为什么不开」仍会发生。
差异只改变玩家在交锋里的手段和起始态势，不让一次错过吞掉整段后续内容。

## 5. 唯一交锋：船修好了却不开

### 5.1 触发

抢修期限结算后的下一个合适白天，货运代理准备让船离港，却拒绝直接支付工人。
他的说法是：船主已把钱交给承包人，承包人失踪不属于船主责任，工人应当自行追讨。

弗兰克早有准备。他收起了一件可以随时装回去的关键部件：

> 船修好了，但工钱到账以前，它不会开走。

交锋当天开放。玩家可以继续生活或处理主线；如果当天结束前没有进入，事件按`缺席`自动结算。

### 5.2 交锋问题

场上只有两条主要进度：

| 进度 | 含义 |
|---|---|
| `工钱到账` | 玩家已经逼出多少实际付款；中段可接受部分付款，填满得到完整结算 |
| `警卫进场` | 随时间与激烈手段推进；填满后对峙被强制清场 |

玩家随时可以选择交回部件、结束封锁。交锋的问题不是能否打赢代理，而是：

> **为了让谁拿到多少钱，愿意把局面推到多危险？**

### 5.3 玩家手段

| 手段 | 主要作用 | 性质 |
|---|---|---|
| 摆出抢修记录 | 稳定推进工钱，不额外激化局面 | 只有参与抢修的玩家掌握强版本 |
| 和代理谈清责任 | 缓慢推进，可在部分付款档收场 | 合法、较安全 |
| 让工人守住跳板 | 较快推进，同时推进警卫 | 公开施压 |
| 指出未登记货物 | 一次性强手段，同时明显推进警卫 | 敏锐发现或既有情报解锁 |
| 搬货抵债 | 把部分欠款直接变成货物 | 非法、高风险，形成独立结算 |
| 交回关键部件 | 立刻结束交锋 | 船离港，工钱继续拖欠 |

具体能力、格数和结果强度由脚本调试，不在设计文档钉死。

### 5.4 弗兰克的主动性

弗兰克不是等待玩家替他讨钱的委托人。

- 对峙开始时，封锁和部件已经由他安排好；
- 回合推进时，他的人会逐渐守住跳板、停止装货，使代理压力增加；
- 玩家可以利用这种压力，也可以花行动稳住工人、避免过早失控；
- 弗兰克不会接受“先放船，以后再走程序”是可靠答案。

实现上不需要把他做成玩家可操纵的普通单位；他的意图通过场景规则、节点变化和台词持续存在。

### 5.5 结算

| 结算 | 条件 | 结果 |
|---|---|---|
| `全额到账` | 填满工钱并控制住警卫进度 | 实际出勤者、伤者和临时工都得到一份；弗兰克高度认可玩家 |
| `部分到账` | 到达中段后主动接受付款 | 出勤者拿到钱，伤者与边缘人员被排除；弗兰克接受但不满意 |
| `以货抵债` | 成功搬走足够货物后收场 | 工人得到补偿，公司把事情记为盗窃；弗兰克认可玩家的手段 |
| `放船离开` | 主动交回部件 | 没有冲撞，工钱继续拖欠；弗兰克不再信任玩家会站在他们一边 |
| `失控` | 警卫进场填满 | 强制清场，按工钱进度保留已经争取到的部分，并产生逮捕或受伤余波 |
| `缺席` | 玩家当天没有进入 | 弗兰克自行逼到部分付款；玩家不获得私人信任，也不承担直接后果 |

坏结算保留已经发生的事实，不把整场归零。警卫进场时工钱已经到哪一档，就按哪一档写回城市。

## 6. 分钱

玩家参加过交锋时，下一次回到码头会看到一次免费事后场景；缺席时只通过观察得知结果。

弗兰克亲自分配拿到的钱或货物：

1. 先给受伤、暂时无法工作的人；
2. 再给欠租或家中有病人的工人；
3. 然后按抢修班次分配；
4. 留下一部分进入没有正式账目的互助金。

他没有把大部分钱装进自己口袋，但账本由他保管，优先级由他决定。玩家若质疑平均分配，
弗兰克会明确说：每个人遇到的不是一样的日子。

这场戏完成两件事：解释人们为什么拥护他，也让玩家看见“被照顾”意味着接受他的裁量。

## 7. 老金牌香烟

分钱或抢修结束后，玩家看见一包红色「老金牌」在工人之间传递。它说明这种烟经过许多人之手，
能把调查引向工会房间，却不能单独证明谁帮助莱恩逃走。

玩家可以提起摩托车。弗兰克不必正式认罪，只需追问：那晚玩家是否喊过自己的身份，
以及一个本地人看见外地人追逐老街人时还能怎样判断。关系较深时，他可以近似承认自己曾经介入，
但不承认知晓勒索。

## 8. 主线接口

### 8.1 莱恩

弗兰克知道莱恩做得下作，但坚持老街的人由老街处置。本线不替代「教训莱恩」交锋，只改变开局态势：

| 弗兰克状态 | 主线兑现 |
|---|---|
| 认可玩家 | 让看堆场的人离开，但要求玩家不能把莱恩交给警方 |
| 关系普通 | 不帮玩家，也不主动预警莱恩 |
| 不信任玩家 | 提前放出风声，使潜入开局更差 |

玩家是否遵守“不把人带出去”的边界，作为弗兰克的后续记忆保存，但第一章不再由此另开任务。

### 8.2 首演夜的游行与外圈

游行的诉求、路线与首演事故由主线拥有。弗兰克线只提供人物状态：

- 获得弗兰克认可时，玩家可以提前请他约束路线或安排人手；
- 他的人只听弗兰克，不成为玩家的普通同伴；
- 首演夜他们守外圈并按自己的方式处理局面；
- 局面恶化时会自行使用暴力，抓住人也可能令物证散失。

这不是无条件加成，而是一支已经组织起来、能够帮助玩家、也有自己意志的力量。

## 9. 状态与章节结算

至少保存以下状态：

| 状态组 | 取值 |
|---|---|
| 弗兰克关系 | `陌生 / 认识 / 认可 / 不信任` |
| 抢修参与 | `未开放 / 进行中 / 按时修好 / 勉强修好 / 未介入` |
| 扣船事件 | `未发生 / 待处理 / 全额到账 / 部分到账 / 以货抵债 / 放船离开 / 失控 / 缺席` |
| 摩托车怀疑 | `未注意 / 怀疑 / 近似确认` |
| 莱恩边界 | `未提出 / 已提出 / 遵守 / 违背` |
| 首演援助 | `未开放 / 可请求 / 已请求` |

第一章结束时：

| 经历 | 章末状态 |
|---|---|
| 从未参加 | 弗兰克仍是码头事实上的组织者；玩家只在主线中感到他的存在 |
| 参加抢修但未站队 | 弗兰克承认玩家能干，私人关系停在认识 |
| 争到全额或以货抵债 | 弗兰克认可玩家，开放主线中的劳工帮助 |
| 接受部分付款 | 双方能够合作，但玩家尚未成为自己人 |
| 主动放船 | 弗兰克不信任玩家，莱恩交锋得到较差开局 |
| 事件失控 | 按玩家在失控前的行为决定认可或不信任，并保存公司／警方余波 |

弗兰克第一章没有思想转变。他的弧线发生在玩家的认识里：

> **可疑的摩托车手 → 能把船修好的工头 → 敢扣住船替人拿钱的头人
> → 能让老街按照他的意志行动的人。**

## 10. 当前执行边界

第一章 Demo 只需实现：

1. 主线追逐中的摩托车伏笔及后续可读取状态；
2. 一个统一、限期、可缺席的货船抢修持续目标；
3. 抢修过程中体现弗兰克领导方式的结果片段；
4. 一场「船修好了却不开」交锋及六类结算；
5. 免费的分钱场景与老金牌对话；
6. 对莱恩交锋开局和首演外圈援助的最小状态接口；
7. 必要状态的保存、读取与章节结算。

不在本轮实现：第二场货船交锋、码头坍塌、林的机器线、记者事故报道、完整工会政治、
第二章劳资冲突、查账旧案，以及新的通用走私系统。
