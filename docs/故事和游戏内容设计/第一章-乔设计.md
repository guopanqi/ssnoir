# 第一章：乔

> **状态：人物线待重新设计。**
> 当前只确定乔在第一章如何存在，以及哪些旧内容已经移除；在新的性格事件获确认以前，
> 不用通用的接送孩子、排班冲突或随机受伤填补人物线。

## 1. 当前确定的角色位置

乔是码头上的普通搬运工。玩家第一次参加码头搬运时自然认识他；继续同班可以让两人从陌生变成相识。

第一章对他的要求不是完成命运转折，而是先让玩家认识一个具体的人。当前可保留：

- 搬运结果中的初见和少量工作片段；
- 乔在码头的常驻位置；
- `陌生 / 认识`这类最小关系状态；
- 以后人物事件与主线能够读取的相识事实。

重复工作只负责自然认识，不应靠刷搬运直接完成一条人物弧。

## 2. 已移出第一章

当前第一章不再包含：

- 码头坍塌；
- 乔在坍塌中受伤；
- 四日照料、用药、痊愈、残疾或死亡；
- 完成接送孩子后才开放照料；
- 乔在第一章加入队伍并提供额外行动骰；
- 章末强制把未介入的乔结算为半残疾；
- 以随机工伤代替人物故事。

这些旧设计保存在[后续章节候选：码头坍塌与乔受伤](后续章节候选-码头坍塌与乔受伤.md)，
只有后续章节重新确认后才能进入实现。

## 3. 第一章人物线的待定方向

接送孩子与加班冲突只能说明乔忙和穷，不能充分表现他的性格，因此不作为当前方案。

新的乔事件应满足：

1. 从码头普通生活中自然长出；
2. 迫使乔暴露自己的价值排序，而不只是需要玩家替他跑腿；
3. 同时表现他的可贵与局限；
4. 主要属于乔本人，不需要弗兰克、林或公共事故共同表态；
5. 第一章可以只建立关系和留下后续，不要求受伤、招募或完成一生的命运。

候选想法「多出来的一张工牌」——乔暗中替一名无法上工的人保留工资——目前只作为讨论素材，
尚未获得确认，不进入执行范围。

## 4. 当前实现边界

在人物事件确认以前，第一章只实现或保留：

1. 玩家通过码头搬运认识乔；
2. 少量表现其工作习惯的结果文字；
3. 最小相识状态的保存、读取；
4. 城市与主线不再依赖乔受伤、照料、入队或坍塌结算。

不要自行补写新的乔任务，也不要用接送孩子恢复旧进度结构。
