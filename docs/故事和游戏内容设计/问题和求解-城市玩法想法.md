

一个问题被提出之后，目标、线索、行动、资源、时间和结果以什么关系组织起来，从而让玩家产生哪一种决策，这个过程又产生什么样的体验。这个文档主要收录这样一些关于问题和求解的想法。它们并不全部互斥，可以用一个想法构成小节的主体，再用另外一些想法组织其中的局部路径，共同形成玩家解决问题时的感受。

```
戏剧问题
为什么玩家在乎这件事？
        ↓
可操作目标／账单
什么状态算是把事情办完？
        ↓
问题—求解结构
玩家能够从哪里入手？这些行动是汇聚、发散、并行、互斥还是依赖？
        ↓
决策压力
为什么玩家不能机械地把所有事情依次做完？
        ↓
结算与扩容
玩家保住了什么、失去了什么，城市因此打开什么？
```

想法收集

信息拼图指玩家从多个地方收集彼此不完整的信息，最后让这些信息汇聚到同一个目标上，拼出一个名字、地址、动机或者判断。它可以表现为不同来源共同推进一根目标 Clock，也可以让每个来源留下一个能够互相印证的具体事实。从决策拓扑看，它是一种汇聚结构：玩家从几个点出发，最后回到一个点。它主要制造“先去找谁、相信哪条信息、现在知道的是否已经足够”的选择，希望带来逐渐确认、交叉印证，以及原本分散的事情终于连在一起的体验。每一块信息最好同时带出它所在的人物和城市生活，这样玩家得到的不只是抽象的“线索 +1”，而是对这座城市多知道了一件具体的事。

并发问题指同时出现多个需要解决的目标，它们共同争夺同一批行动骰、时间或其他资源。玩家可能随着时间推移把它们全部解决，也可能只能解决其中一个，或者分别保住每个问题的一部分。从决策拓扑看，它是一种并行结构：几张账单同时向前走，玩家必须不断决定今天先照顾哪一张。它主要制造优先级和机会成本的选择，希望让玩家犹豫、改计划，并真切感到把一颗骰子交给这件事，就意味着另一件事今天没有得到处理。
并发问题实际上出现在整个游戏中，玩家总是在同时面对很多问题，需求，求助，麻烦，欲望，并从中选择先做哪个，要如何分配，如何利益最大化。

紧急问题争夺行动骰子可以看作并发问题中更紧张的一种。它通常突然出现，期限更短，并会挤占玩家原本已经安排好的生活或故事计划。它的重点不只在于同时有两件事，而在于新的事情迫使玩家重新分配已经稀缺的行动。这样的结构主要制造“是否打断原计划”和“哪一个损失更能承受”的选择，希望形成被局势推搡、临时救火和来不及把一切办好的压力。

保护指存在一个需要被保护的对象，许多事件、Clock 或玩家行为都可能使它受损，而玩家要让它撑过一段时间。保护对象可以是一个人，也可以是一家店、一段关系、一个秘密或者某种已经取得的生活。从决策拓扑看，它是一种持续状态结构：目标不是完成一次动作，而是在时间流逝和多种损伤之间维持状态。它主要制造“哪些伤害必须阻止、哪些代价可以承受、现在应该预防还是修复”的选择，希望带来责任、牵挂和逐渐被消耗的体验。保护的过程可以由不同的具体威胁组成，让玩家每次是在处理一件发生于世界中的事，而不是每天重复同一个维护按钮。

积累和兑现
来自《活侠传》中很有力量的一种体验：玩家在前半部分积累的人物关系、属性和其他存量，在之后某个情节分支中兑现，并产生关键性的效果。
从决策拓扑看，它是一种跨小节的依赖结构，前面的生活选择在后面的关键问题中获得新的用法。它在前期制造“我要把有限时间投入到谁和什么上”的选择，在后期制造“这份积累现在应该用于哪里”的选择，希望让玩家感到游戏记得自己过去怎样生活，而长期建立的关系终于成为具体的杠杆。最有力量的兑现往往是具名而具体的，例如某个人替你签下一张纸、带人守住一个入口，或者愿意说出原本不会告诉外人的消息。

对一个问题以多种方式求解
指的是像《苏丹的游戏》中那样，游戏给出一张必须处理的牌、一个明确目标或者一条确定的结局路线，而玩家可以用不同资源、人物关系和行动方式去完成它。或者用不同的方式和资源去推进一条路线的一个节点。
或者是CS2中的八角巷的场景
```
燃料管
- 400金币
	- 工作
	- 外出合同
- 合同取得核心
	（带上朱妮后，会有潜在的第三条路径，完成合同后，把核心交给朱妮，这个地方骇入斯卡腾的电脑获取燃料管。）
```
从决策拓扑看，它是一种替代路径结构：几条路线都通向同一个目标，但经过的城市生活和付出的代价不同。它主要制造“我想以怎样的方式、怎样的身份把事情办成”的选择，带来自主性和角色塑造。真正形成差异的不是几个行动分别使用力量、敏锐或交际，而是玩家究竟靠钱购买结果、靠关系出力、借程序施压、花时间调查，还是承担风险强行解决。

探索和发散
指《Citizen Sleeper 2》中从一个探索动作开始，随着进度推进逐渐发现新的地点、人物、机会和未知目标。

```
【远枢空间站 Far Spindle】
│
├─ 等待布利斯修理
│  └─ 与布利斯交谈
│     └─ 解锁【布利斯工坊】
│
├─ 探索【尖顶 Pinnacle】
│  ├─ 发现【春潮号】事件
│  │     └─ 与马利克交谈
│  │        └─ 接下合同
│  └─ 发现【信号站】
   └─ 发现【逐星胜地】
	   服务员工作（0/16)
		   赌博(0/4) (趣味赚钱方法，有成功次数限制)
│
├─ 调查 【空间站核心 Spindle Core】
│  └─ 【运输隧道】
│     └─ 遇见卡狄特
│        └─ 调查【条带线快车 Stripline Express】（人物故事会在星罗坞继续）
	├─ 【远枢贸易大厅】
	├─ 【盖亚环流】
	│  └─ 喝酒0/4
	│     └─ 遇见于进和维斯娜
	│           └─ 接下后续合同
	│              └─ 返回远枢，招募于进
│
└─ 探索 【下悬区 The Underhang】
   ├─ 发现【内穆巴厨房】（食物，施舍）
   │  └─ 开启内穆巴的孢子支线
   ├─ 发现【远枢边缘 Spindle's Edge】（常驻工作）
   └─ 发现【拆解船 Scrapper Ship】（零件与工程工作）
```

从决策拓扑看，它是一种展开结构：玩家从一个点出发，逐渐看见更多方向；这和信息拼图从几个点收集信息、最后汇聚到一个点恰好形成相反的运动。它主要制造“先往哪里走、是否继续深入、要不要把行动投入尚不知道回报的方向”的选择，希望带来陌生、摸索、逐渐建立空间认识以及意外发现城市生活的体验。

同样是探索和发散，空间表达还可以分成“区域重塑”与“前沿推进”。远枢的下悬区属于前者：玩家先把它认识成一个模糊区域，探索完成后，这个整体认识消失并被厨房、工作区和拆解船等平级地点重塑。城寨尝试后者：探索动作本身位于入口，走通一段后消失，由更深处的新动作接替；途中可以留下已经认识的人物或生活职能。它制造的不只是“这里包含什么”，还有“我正沿哪条路往里走”的空间感，因此要求三维模型至少提供可辨认的入口、途中节点和终点，并为每个前沿准备独立 Anchor；不要求把建筑做成可自由行走的完整关卡，但相邻 Anchor 的顺序必须能从体块和视线关系上读出来。

钥匙和锁指玩家已经看见一个问题，却还缺少进入、理解或解决它所需的东西。钥匙可以是实物，也可以是资格、关系、名字、证据、路线知识或某个人的同意。从决策拓扑看，它是一种依赖或门槛结构：一些行动必须先于另一些行动发生。它主要制造“先去取得哪一把钥匙、基础钥匙是否已经够用、是否值得继续寻找更好的钥匙”的选择，希望带来准备、取得资格，以及原本无从下手的问题终于可以被处理的体验。几把不同的钥匙可以打开同一把锁，并分别改变进入后的风险、可用动作和人物态度。

旅途事件指《Citizen Sleeper 2》后段常用的旅行结构。玩家有一个确定的目标，并在逐渐接近它的过程中遇到障碍、机会和人物；这些事件要求玩家消耗资源、承担风险、停留或绕路，从而不断改变原来的计划。从决策拓扑看，它是一种顺序推进结构：终点是清楚的，途中发生的事情会改变抵达终点时还剩下什么。它主要制造“继续赶路、处理眼前机会、付代价硬闯还是绕开”的选择，希望带来计划在运动中不断被扰动、玩家必须持续重新计算的体验。旅途不一定只是地理旅行，逐层深入一栋建筑、通过一连串程序、执行一次潜入或者进行一场多阶段谈判，也可以使用同样的结构。

清单式准备指一个已经确定会到来的事件存在若干不同漏洞，玩家可以提前逐项处理，但时间和行动不足以覆盖全部。每一项准备解决的是不同问题，并在最终事件中改变相应的起始条件、可用行动或损失。从决策拓扑看，它是一种覆盖结构：玩家不是寻找唯一正确路线，而是在有限能力下决定自己的方案覆盖哪些危险。它主要制造“我最担心哪一种失败、哪些准备能够互相替代、哪一个漏洞只能暂时放着”的选择，希望带来制定方案和承担遗漏的体验。准备过的内容应在最终事件中以具体变化兑现，让玩家认得出这正是自己此前堵住或者留下的那个洞。

见好就收指玩家已经取得可以带走的成果，继续行动会增加收益，也会让风险和不可逆后果不断升高。从决策拓扑看，它是一种递增风险与自选退出的结构：离开本身就是主要行动，目标不再天然等于把 Clock 填满。它主要制造“现在是否已经足够、还要不要为了多拿一点再走一步”的选择，希望带来克制、贪心、止损，以及事后清楚意识到自己曾经有机会停下的体验。过去取得的知识、钥匙或人物帮助可以让玩家更早拿够、更晚暴露，但最后的停点仍然由玩家决定。

这些想法并不是彼此排斥的小节类型。一个小节可以用其中一个作为主要想法，再让其他想法组织局部路径。信息拼图中的某一条线索来源可以先展开成一段探索；旅途中的一个障碍可以要求玩家寻找钥匙；清单式准备中的某一项可以有多种完成方式；保护期间也可能突然出现一个并发的紧急问题。主要想法决定这个小节反复让玩家思考什么，次要想法则让抵达目标的过程获得变化。

第一章的问题与求解结构

| 小节 | 戏剧问题 | 主要想法 | 次要想法与决策压力 | 形成的体验与新开放内容 |
|---|---|---|---|---|
| 交割 | 比你还穷的人把攒下的钱交给你，你拿什么去办？ | 积累和兑现 | 并行的并发问题：4 颗骰子在挣钱、踩点、交租与恢复之间争夺；交割日期固定 | 玩家用自己的生活方式凑出一笔具体账单，并决定要不要分骰子去做一件当天不挣钱的事；城市基本盘、工作、房租与第一次交锋开始运转 |
| 城寨 | 她长大的地方不欢迎她，也不欢迎你 | 探索和发散 | 局部使用信息拼图与钥匙和锁；经理耐心持续施压 | 玩家从未知入口逐渐读懂一栋自治建筑；埃迪、工会房间、桥廊公寓等人物和地点留在城市里 |
| 找到莱恩 | 为她出头时，你有权在别人的地方走多远？ | 空闲期 + 两幕交锋 | 三天不可加速的空闲，城市生活本身就是在配钥匙，钥匙只改交锋的开局态势；第一幕潜入用限时窗口结构（造窗口 → 趁窗口连推），惊动的人结转为第二幕危险钟的起始格；第二幕施压用合同语法：目标钟＋危险钟＋随时可走，唯一的问题是现在够不够 | 玩家先决定怎样走进去，再决定在他面前停在哪儿；货栈后巷、莱恩留下的材料以及老街人物的新用途进入后续故事 |
| 死亡威胁 | 她不肯取消首演，你能堵住哪些危险？ | 清单式准备 | 保护与积累和兑现；首演日期限制能够完成的准备数量 | 玩家制定一套不完整但属于自己的安全方案；剧院内部、警方保护和既有人物的援助获得新用途 |
| 首演夜 | 局面失控时，你先保护谁、追什么？ | 并发问题 | 保护夜莺、控制现场与追逐执行者共同争夺行动；前期准备改变可选路径 | 整章的生活选择在一次危机中结账，完成第一章的表面胜利，并留下能够在第二章重新解释的结果 |

探索发散结构和第一章第二小节的城寨漫游，探索尤其契合。玩家从门廊和楼梯开始推进前沿步伐，在一个外来者读不懂的空间里寻找道路，沿途遇见人、发生摩擦、逐渐发现常驻地点，最后才从混乱中找出与案件有关的方向。探索完成后，入口动作可以消失，玩家认识的人和摸熟的地方却留在城市里。结构由此直接表达了“在未知中逐渐读懂这里”的戏剧感受。
