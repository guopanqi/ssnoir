# 第一章：三封信

> 本文是**真正第一章**的故事与玩法设计——不是 demo 短篇的扩展，而是从手稿剧本出发、
> 以三封信为骨架重新构建的完整第一章。
> Demo 短篇（[demo短篇·夜莺故事设计.md](demo短篇·夜莺故事设计.md)）是自闭环的
> 试验故事，验证了系统与小节写法；本文沿用其中验证过的好想法（人物生活职能、
> 城市生活感、多路径求解、交锋与城市生活的交替节奏），但剧情、人物弧和小节结构
> 全部为三封信版本重新设计。
> 通用写作原则见 [故事设计总纲.md](故事设计总纲.md)，
> 系统侧姊妹篇是 [城市生活设计.md](城市生活设计.md)，
> 手写剧本源头见 [手稿/夜莺剧本-第一章.md](手稿/夜莺剧本-第一章.md)。

## 0. 一句话

一个穷侦探接了一个穷歌女的委托，解决了一桩勒索案，保护了一场首演——
然后相信了一个精心构建的谎言。

## 1. 核心思想

### 1.1 第一章要完成什么

第一章是一次**看起来已经完全解释清楚的错误结案**。

玩家在章末应当认为：莱恩是勒索者，他从要钱升级到报复，最终在首演之夜被抓获。
案件结束了，夜莺安全了，我保护了她。

隐藏真相只有一层：第三封信由公司伪造，夜莺知情并利用了玩家。
这层真相属于第二章，第一章不揭露、不暗示、不弹提示。

### 1.2 故事简单，人物丰富

情节本身不复杂——一桩勒索案，三封信，一场首演。
不通过增加事件数量制造曲折。复杂性完全来自人物行为的**双重解释**：
同一个微笑、同一句关心、同一次请求，在真相揭晓前后有不同的含义。

### 1.3 夜莺的双重身份

她的弱势是真的，她受到的羞辱是真的。
但她也清楚别人会因为她的弱势而保护她，并且有意识地使用了这种保护欲。

她不是从受害者突然反转成阴谋家。她一直同时是受害者和操纵者，
只是第一章让玩家只看见前一面。

最有效的操纵不是伪造情感，而是选择在什么时候让对方看见真实的脆弱。
感情可以是真的，时机是经过选择的。两者共存比"全部都是演戏"更可怕。

### 1.4 莱恩不是无辜的

他是一个真实的勒索者。他有案底，酗酒，用匿名信和别人的手榨取受害者。
他对第一封信和第二封信负有全部责任。

但他没有写第三封信，也没有组织首演事件。
正因为他真的有罪，才会成为完美的替罪羊。

第一章留下的不是"莱恩可能无辜"——他显然不无辜。
留下的是一个更细微的东西：**首演之夜发生的事情，不像他这种人能组织出来的。**
这个感觉在第一章可以被合理解释（"他雇了同伙"），到第二章才会被重新打开。

## 2. 玩法结构总览

```
开场（第 1–2 天）
  ↓
小节一：交割（第 3–4 天）—— 封闭教学问题 + 交锋
  ↓  人物幕间
小节二：老街（第 5–14 天左右）—— 第一个多路线问题，城市生活主要时段
  ↓  人物幕间 / 隐藏转折
平静期（2–4 天）—— 人物支线，生活建设
  ↓
小节三：第三封信（首演前 4–5 天）—— 调用积累制定方案
  ↓
首演交锋 —— 检验方案，完成错误结案
```

时间跨度约 18–22 个游戏日，具体天数后调。
玩家有 **4 颗行动骰**（乔入队后 +1）。

每个小节使用统一节奏：
触发剧情 → 一张具体的账单 → 数天城市生活 → 玩家落实解决方案 →
结算 → 人物戏 → 城市发生变化。

## 3. 开场（第 1–2 天）

玩家刚到贝城。旅馆、码头、布告栏、公园、诊所、警局从第一天可见。

第一天晚上或第二天，夜莺找上门来。

她不是通过经理来的——经理此时不知道勒索信的事。她从老街的人脉听说
旅馆住了一个新来的侦探。一个穷歌女能请得起的，刚好是一个穷侦探。

她带着一封信的复印件和一小叠钱（约30金——刚够几天房租，对她是攒了一阵子的）。
信的内容：交一笔钱，否则公开她的过去。交钱地点码头邮箱，期限三天后。

她说可能是莱恩——"她在老街的旧朋友"——也可能不是。她不想报警，
理由含糊。她希望你查清是谁，让他们别再来。

**夜莺此时的身份**：老街酒馆的驻唱歌女，最近被一个剧院经理看中，
首演定在两三周后。她还没离开酒馆，还没有高薪，还住在老街某处。
首演是她人生的转折点——如果能到达的话。

**什么过去**：她在老街唱了好几年。年轻时候的生活不是无可挑剔——
几个男朋友、一些酣醉的时刻、一些不体面的照片。对普通人无所谓，
对即将登台的新人，添油加醋就可能毁掉她。

你离开时，夜莺跟上来："谢谢。演出的夜晚我会给你留一张票的——如果你有空的话。"

## 4. 小节一：交割

### 4.1 账单

按照勒索信的约定，在期限日把钱放到码头邮箱，盯住来取钱的人。

### 4.2 准备（第 2–3 天）

玩家可以做的事：
- 在码头踩点（了解地形、巷道、藏匿点）
- 查看邮箱位置和周围环境
- 赚钱交房租
- 恢复身体状态

4 颗骰子分配在踩点、赚钱、生活之间。**核心教学体验：你的一天不够用。**

### 4.3 交割日交锋

交割日是一场**交锋**。

夜莺把钱放进邮箱后离开。玩家在附近蹲守。取信人出现——可能伪装成邮差
或路人。玩家需要识别、跟踪、追上他。

交锋结构待定，但大方向：追逐场景，考点是准备（踩点的投入在这里兑现）。
前几天的城市准备改变交锋的起始条件（知道哪条巷子通、提前标记了邮箱周围的视野）。

结果影响玩家获得的信息量和代价：
- 好：追到取信人，看清特征，拿回部分钱，获得直接指向老街的线索
- 中：跟丢了人，但从扭打中获得他身上的东西（衣物碎片、一个地址）
- 坏：人和钱都丢了，只有方向性线索

**无论结果**：玩家知道取信人来自码头居民区方向。故事推进。
交锋失败留下代价（伤、丢钱），但不阻断主线。

### 4.4 结算后的人物戏

夜莺来旅馆看玩家。

她问伤势，问钱的事。"那些钱本来就是破财消灾。"
她更担心的是：他们还会来吗？会索要更多吗？

玩家告诉她要去码头居民区调查。她说："我在那里长大。我每天要排练，
有半天的时间可以和你一起。在那之前你先把伤养好。"

这场戏的双重读法：
- 第一次：她逐渐信任玩家，愿意一起冒险
- 真相后：她在确认玩家是否还愿意继续，同时提供自己作为向导——
  让玩家更高效地进入老街，也让她能控制玩家看到什么

### 4.5 打开

老街区域（酒馆、居民区）出现在城市地图上。

## 5. 小节二：老街

**第一章的核心段。占全章近一半的自由行动时间。**

### 5.1 触发：第二封信

莱恩发现对方会付钱，加码了。第二封信金额更高，附上一张裁过的旧照片，
证明他手里确实有底片和更多材料。额外条件：钱必须由夜莺本人送到老街。

这封信寄到了剧院——莱恩可能从第一次交割知道了经理的存在。
**经理因此第一次介入**：他从收发室看到信，找到夜莺追问。
他开始出钱（提高委托报酬），也开始用他的方式处理——
但他的利益（首演成功、品牌不受损）和夜莺的利益（摆脱过去）从此不完全重合。

### 5.2 账单

**在莱恩公开照片之前，查清他手里还有什么，终止勒索。**

压力不是精确倒计时，而是不确定性——莱恩随时可能行动，越快越好。

### 5.3 老街作为游戏空间

老街在小节二开放，包含：

**酒馆**：夜莺唱歌的地方，老街的社交中心。
- 工作：当服务员（夜莺或老板介绍，门槛低）
- 服务：买酒、买烟
- 人物职能：听夜莺唱歌（恢复少量冷静）；打听消息；和老板、常客交谈
- 夜莺每天有时间段在这里——**这是她的日常生活存在感**

**码头居民区**：莱恩和工人们的住处。
- 通过关系或具体事件逐步进入更深的部分
- 乔、弗兰克等已有人物在这里活动

**市集/当铺**（视需要开放）：买卖东西，以及底片可能存放的地方。

老街人对玩家戒备的原因是朴素的：你穿得不像这里的人，你在替一个
"走了就没回来的"姑娘办事，你问的问题像警察会问的。
不是政治愤怒，是护短和戒心。

### 5.4 三个解决方向

**交易**：攒钱或通过中间人买回底片和材料。最直接，代价纯经济。
经理愿意出一部分。问题是：给了钱怎么确保莱恩不留底？

**关系**：进入老街的生活，找到知道底片来历的人。酒馆服务员是最低切入点。
从酒馆认识的人可以引向知道莱恩藏东西位置的人。代价是时间和骰子。

**强制**：直接堵莱恩、偷取材料、或让警方介入。最快，
但可能破坏老街关系、让莱恩销毁证据或逃跑。阿瑟在这条路线上可以帮忙。

路线可以混合。比如先在酒馆打工混脸熟，查到底片在哪，然后用钱买回来。

### 5.5 莱恩的人物塑造

玩家在调查过程中逐渐认识莱恩：
- 有案底——偷窃、诈骗、小额敲诈
- 因港口新机器失去工作
- 酗酒，大放厥词
- 和夜莺多年前认识（可能是旧男友，也可能只是圈子里的人）
- 他的照片和信件不一定是他自己的——可能从旧房东、当铺或某个地方弄到
- 勒索既为了钱，也带着怨恨："她从这里出去以后再没回来"

**要表现的行为模式**（为第二章的重新解释做铺垫）：
- 从不亲自取钱，找不知内情的人代取
- 靠匿名信和别人的手控制受害者，不愿当面承担后果
- 被堵住时首先找出口、推卸、把酒壮胆
- 会说狠话，但真正身体冲突时只想逃
- 索要的始终是钱，总给对方留"继续付钱就能没事"的台阶
- 杀了夜莺反而断了财路

第一章里这些特征不替他洗清嫌疑。
第二章才让同一组事实产生新的解释：
这个人擅长躲在纸后面榨钱，但第三封信背后的行动需要组织、内部情报
和承担巨大后果的能力——不是他熟悉的犯罪方式。

### 5.6 莱恩的下作

第二封信要求夜莺本人送钱——他想让她穿着漂亮衣服回到她拼命离开的地方低头。

玩家在老街能看到：
- 他把照片给别人看
- 他添上不存在的故事
- 他以"我们都认识她"为理由，把她的过去当公共谈资

但玩家也应看到：**老街不是莱恩。**
有人拒绝看照片，有人帮忙找底片，有人说莱恩做得恶心但不肯把本地人交给警察。

### 5.7 小节二期间的城市生活

这是玩家建设生活的主要时段：
- 在某处有稳定营生（酒馆服务员、码头搬运、警局文书、布告栏委托）
- 和一两个人建立关系（乔、弗兰克、阿瑟）
- 处理乔的伤势（如果已触发）
- 长期住所投入
- 每天四项竞争：主线调查、挣钱交租、身体恢复、人物机会

### 5.8 结算

- 底片/材料问题解决（拿回、买断、销毁，或通过警方扣押）
- 前两封信确认都是莱恩写的
- 莱恩没有被彻底控制——他逃走、被问话后释放、或因夜莺不愿正式指控而仍自由
- 勒索确实结束了。玩家应有"这件事我办完了"的满足感

**夜莺的变化**（微小，不宣言式）：
- 不再要求玩家"别伤害莱恩"
- 第一次主动问警方能把他关多久
- 经理说"采取必要办法"时没有反对
- 把取回的照片烧掉，却留下了一封莱恩写过的信

第一次看：受害者终于不忍了。
第二章回看：那封被留下的信是后来公司模仿笔迹的材料。

**打开**：经理报酬到账；剧院作为可前往地点出现；首演倒计时可见。

## 6. 平静期（2–4 天）

主线没有新压力。勒索结束了，首演还有一段时间。

玩家可以：
- 推进人物支线（乔的伤势、弗兰克、阿瑟）
- 巩固城市生活模式
- 去剧院看夜莺排练——她正在从酒馆歌女变成剧院演员
- 酒馆里她出现的频率降低（去排练了），这个变化本身就是叙事

**幕后（不给玩家看）**：公司与夜莺之间的交易发生。

公司掌握了两样东西：莱恩前两封信的原文（可以模仿措辞），
以及夜莺正在被勒索的事实（现成且可信的嫌疑人）。

公司向夜莺提出方案：伪造一封更严重的威胁信。
把桃色勒索改写成"歌手不向暴徒低头"的故事。
用生命威胁合理化安保和媒体关注。首演获得远高于普通宣传的关注度。

夜莺同意了。她不需要亲自写，也不需要知道全部安排。她只需要：
- 交出莱恩前两封信（或者——那封留下的信就是这个用途）
- 没有指出某个排练细节莱恩不可能知道
- 同意继续雇用玩家，让玩家成为威胁真实存在的独立见证人

她知道第三封信会被认为是莱恩写的。她知道他没有写。她仍然同意。

## 7. 小节三：第三封信

### 7.1 触发

第三封信出现在夜莺的化妆间或排练室。

不要钱，不提过去。只写一件事：如果她在首演当晚登台，她会死在舞台上。
信里提到一个只有内部人员才知道的排练细节（登台时间、后台入口、
换装顺序或舞台位置）。

玩家和经理都认为是莱恩——勒索失败后升级到报复。合理推断。

### 7.2 账单

**经理拒绝取消首演。在首演之前，让夜莺安全登台。**

这是一个准备问题，不是调查问题。玩家不需要查出第三封信谁写的
（他已经"知道"），而需要用有限时间做尽可能多的安全准备。

### 7.3 可做的准备

每一项消耗行动骰和时间，不可能全做，必须按优先级选择。
选择取决于玩家此前积累了什么关系和资源：

- **寻找莱恩**：他跑了/被释放了，找到他至少确认有无同伙
- **请警方保护**：阿瑟可以安排人手，官僚关系好则力度更大
- **检查剧院后台**：通行证、临时工、舞台结构、登台路线
- **改变登台安排**：需要夜莺足够信任，她才愿意改变演出
- **设诱饵**：放出假排练时间或登台顺序，逼威胁者提前行动

**这是第一次让玩家此前积累的关系产生杠杆。**

### 7.4 人物戏

夜莺拒绝取消首演——"我等了这么多年"。
她请玩家首演当晚留在后台或舞台附近。

- 第一次读：她信任玩家，只有他能保护她
- 真相后：她知道会有"事件"，需要一个真心相信威胁的人在场

## 8. 首演之夜

**第一章的大型交锋。交锋预算集中在这里。**

### 8.1 事故

演出进行中，舞台升起时发生异常——停电、烟雾、机械故障、恐慌。

公司安排的是"可控惊扰"，但涉及真实的物理危险：
停电导致踩踏、烟雾引发恐慌、执行者动作过大可能真的伤人。
**玩家的准备不是在防一个假威胁，而是在控制一个随时可能失控的局面。**

起始条件由小节三的准备决定：
- 封住了哪些入口
- 有没有警方在场
- 夜莺的位置是否改变过
- 诱饵是否发挥了作用

### 8.2 交锋

玩家在混乱中做取舍。交锋结构待定，但核心选择空间：

- 保护夜莺 vs 追执行者
- 控制现场 vs 保留物证
- 借助警方 vs 借助老街认识的人

追上执行者可能留下物证；留在夜莺身边则她更安全但人跑了。
准备做得好则多数入口已封，追逐更容易；准备不足则现场更混乱。

夜莺不是等待被救的人。在条件允许时，她自己从备用通道回到舞台，
把中断的演出唱完。

### 8.3 结算状态（保存到第二章）

四个向量：
1. 夜莺是否受伤
2. 首演完成程度（完整谢幕 / 勉强收尾 / 严重中断）
3. 执行者是否被抓、是否留下物证
4. 哪些人物在现场帮助过玩家

## 9. 公开结案

警方迅速行动。莱恩被逮捕或被宣布在逃。

报纸标题：港口无业人员勒索威胁，夜莺不惧危险，华丽谢幕。
经理的公关团队准备得异常充分。三封信被装进同一份案卷。
警方以搜索莱恩同伙为由封锁老街。

夜莺完成了从酒馆歌女到剧院明星的蜕变。
玩家拿到报酬，完成委托。

**第一章在情绪上是一次胜利。**

### 9.1 留在叙事中的细节（不标注、不提示）

- 莱恩前两封信都要钱，第三封突然只要命
- 莱恩惯于让别人代劳、自己逃跑，首演事件需要内部情报和周密安排
- 现场追到的人比莱恩冷静、专业，知道后台出口
- 夜莺在事故后恢复得异常快
- 经理和报纸的反应速度异常快
- 夜莺从未明确说过"我不知道第三封信谁写的"——她只说过"听起来像他"

这些在第一章都有合理解释（莱恩雇了同伙、公司擅长宣传、她是专业歌手）。
它们只在第二章被新事实打开时，才从"合理"变成"可疑"。

## 10. 人物弧

### 10.1 夜莺的表面弧（玩家第一章看到的）

```
酒馆歌女，害怕被过去拖回去
  → 接受玩家的帮助，逐渐信任
  → 被莱恩的下作伤害，决心和过去切断
  → 面对死亡威胁仍坚持登台
  → 在混乱中回到舞台，完成蜕变
```

### 10.2 夜莺的真实弧（第二章揭露后回看）

```
收到勒索信，立刻猜到是莱恩，但需要一个人替自己去查
  → 挑选了一个穷、没有关系、容易被激起保护欲的侦探
  → 观察他是否靠得住：会不会为她冒险、会不会坚持、会不会听话
  → 被莱恩的下作真实地伤害——这部分不是假的
  → 利用真实的愤怒做出决定：允许公司伪造第三封信、允许莱恩背锅
  → 知道玩家会为了她在首演冒险，让他留下
  → 得到了新的人生，代价是让另一个人承担了不属于他的罪
```

### 10.3 每场人物戏的双重读法

| 场景 | 第一次理解 | 真相后理解 |
|---|---|---|
| 她坚持不报警 | 害怕警方、念旧情 | 避免警方直接查穿她已认出莱恩 |
| 她让玩家调查老街 | 她不敢独自面对过去 | 让玩家替自己确认材料、承担冲突 |
| 她在玩家受伤后登门 | 关心和信任 | 真实关心 + 确认玩家是否还愿意继续 |
| 她在老街谈起自己怎样离开 | 袒露内心 | 让玩家理解为什么她"值得被带出去" |
| 她在第二封信后变得坚决 | 受害者不再忍让 | 她已决定莱恩和老街可以承担代价 |
| 她拒绝取消首演 | 勇敢、珍惜职业 | 她知道第三封信不会按字面兑现 |
| 她要求玩家留在后台 | 信赖玩家 | 玩家是保险，也是让骗局可信的证人 |
| 事故后重新登台 | 惊人的勇气 | 她事先知道会有中断，准备过怎样回来 |
| 演出后和玩家相见 | 劫后余生的感情 | 感情可能存在，也同时确保玩家接受同一个故事 |

### 10.4 莱恩的人物弧

```
失业的酗酒者，拿到了夜莺过去的照片和信件
  → 用匿名信试探对方会不会付钱
  → 发现对方会付，加码并附上照片
  → 要求夜莺亲自来，不只是挣钱，也是惩罚"离开后再没回来"的人
  → 被玩家查到，勒索材料被拿走
  → 逃走或被释放
  → 首演之夜被捕，成为三封信案的唯一嫌疑人
```

他的功能是**一个真实的坏人被加工成一个更有用的恶人**。

## 11. 三个小节的玩法递进

| 小节 | 问题类型 | 玩法重心 | 考什么 |
|---|---|---|---|
| 一：交割 | 封闭执行 | 单线准备 + 交锋 | 骰子分配的基本取舍；城市准备怎样进入交锋 |
| 二：老街 | 开放探索 | 多路线求解 + 城市生活建设 | 在不欢迎你的社区里用不同方式找到一样东西 |
| 三：第三封信 | 优先级准备 | 有限资源下的方案选择 | 调用已有积累——关系、钱、人脉——产生杠杆 |
| 首演 | 结算检验 | 交锋 | 在混乱中做取舍，准备决定起始条件 |

## 12. 人物生活职能

|---|---|---|

## 13. 与 demo 短篇的关系

Demo 是自闭环的试验故事（歌厅卖身约 / 收账人 / 老板），用来验证系统。
本章沿用 demo 验证过的想法：

- 人物有日常生活职能，不是任务图标
- 城市有活着的感觉——工作、恢复、人物、天气构成一天的质感
- 同一个问题可以用不同生活路线抵达
- 交锋是城市节奏的一环，不是独立的战斗关卡
- 坏结算留疤不做硬 game over
- 所有状态可见（时钟、账单、期限）

但剧情、人物弧和小节结构全部为三封信版本重新设计，不受 demo 的
人物关系和故事走向约束。
