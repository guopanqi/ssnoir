## 0. 一句话

一个穷侦探接了一个穷歌女的委托，解决了一桩勒索案，保护了一场首演——
然后相信了一个精心构建的谎言。

## 1. 核心思想

### 1.1 第一章要完成什么

第一章是一次**看起来已经完全解释清楚的错误结案**。

玩家在章末应当认为：莱恩是勒索者，他从要钱升级到报复，最终在首演之夜被抓获。
案件结束了，夜莺安全了，我保护了她。

隐藏真相只有一层：第三封信由公司伪造，夜莺知情并利用了玩家。
这层真相属于第二章，第一章不揭露、不暗示、不弹提示。

### 1.2 故事简单，人物丰富

情节本身不复杂——一桩勒索案，三封信，一场首演。
不通过增加事件数量制造曲折。复杂性完全来自人物行为的**双重解释**：
同一个微笑、同一句关心、同一次请求，在真相揭晓前后有不同的含义。

### 1.3 夜莺的双重身份

她的弱势是真的，她受到的羞辱是真的。
但她也清楚别人会因为她的弱势而保护她，并且有意识地使用了这种保护欲。

她不是从受害者突然反转成阴谋家。她一直同时是受害者和操纵者，
只是第一章让玩家只看见前一面。

最有效的操纵不是伪造情感，而是选择在什么时候让对方看见真实的脆弱。
感情可以是真的，时机是经过选择的。两者共存比"全部都是演戏"更可怕。

### 1.5 卷宗和人是两回事

案子和委托人在界面上是分开的两样东西。

**案子**是一份卷宗：期限、账单、案情、已经查到的东西。它跟着你走，在城里任何地方都看得见。

**夜莺**是一个人，她有自己在哪儿。第一章期间她的人物节点始终留在老街酒馆：她在那里唱歌，
等一个演出、成名并进入上层社会的机会。她可以临时与你同行半天，但人物节点不随这种短暂活动搬家；
以后身份真正改变时，她的常驻地点才可能改变。受伤的日子谁也见不到她。

这条对所有人物都适用：乔在码头和居民区，阿瑟在警察局。人不该是浮在世界上的一张卡。

### 1.4 莱恩不是无辜的

他是一个真实的勒索者。他有案底，酗酒，用匿名信和别人的手榨取受害者。
他对第一封信和第二封信负有全部责任。

但他没有写第三封信，也没有组织首演事件。
正因为他真的有罪，才会成为完美的替罪羊。

第一章留下的不是"莱恩可能无辜"——他显然不无辜。
留下的是一个更细微的东西：**首演之夜发生的事情，不像他这种人能组织出来的。**
这个感觉在第一章可以被合理解释（"他雇了同伙"），到第二章才会被重新打开。

## 2. 玩法结构总览

```
开场（第 1–2 天）
  ↓
小节一：交割（第 3–4 天）—— 封闭教学问题 + 交锋
  ↓  人物幕间
小节二：城寨（第 5–12 天左右）—— 静态地点探索，查出他是谁
  ↓  她说起莱恩
小节三：教训莱恩 —— 三天空闲 + 一场两幕交锋
  ↓  人物幕间 / 隐藏转折
小节四：第三封信（首演前 4–5 天）—— 在剧院那张图上布置
  ↓
首演交锋 —— 同一张图活过来，固定日程表上的分诊，完成错误结案
```

时间跨度约 18–22 个游戏日，具体天数后调。
玩家有 **4 颗行动骰**（乔入队后 +1）。

**两个钉死的日子**：交割日（登门当天 +3，信上写的期限）与首演之夜（第 22 天，
开场起全程可见）。整章总长因此有上限，玩家能决定的是这些天怎么分配。
另有一个钉死的日子：**第 7 天第二封信寄到剧院**。玩家当天醒来会先接到剧院的紧急电话；
这不是地图上等待点击的普通开放动作。电话之后，剧院出现「见剧院的经理」，并成为当天睡前必须处理的事件。
见面读信之后经理才正式介入，耐心从这一刻开始跑。
中间的分界浮动：小节二由查明身份推进，小节三由巷子那一场收尾，第三封信在收尾后第 3 天到——
越晚办完，小节四的准备天数越少。小节二、三没有自己的倒计时，压力来自经理的耐心。

每个小节使用统一节奏：
触发剧情 → 一张具体的账单 → 数天城市生活 → 玩家落实解决方案 →
结算 → 人物戏 → 城市发生变化。

## 3. 开场（第 1–2 天）

玩家刚到贝城。旅馆、码头、老街酒馆、布告栏、公园、诊所从第一天可见（见 4.2）。

第一天晚上或第二天，夜莺找上门来。

她不是通过经理来的——经理此时不知道勒索信的事。她从老街的人脉听说
旅馆住了一个新来的侦探。一个穷歌女能请得起的，刚好是一个穷侦探。

她带着一封信的复印件和一小叠钱（30 金——刚够几天房租，对她是攒了一阵子的）。
这只是她眼下能拿出的部分；信上要 100 金，否则公开她的过去。交钱地点码头邮箱，
期限三天后。玩家需要用城市中的工作凑出差额，同时仍要面对房租与身体状态。

她说可能是莱恩——"她在老街的旧朋友"——也可能不是。她不想报警，
理由含糊。她希望你查清是谁，让他们别再来。

**夜莺此时的身份**：老街酒馆的驻唱歌女，最近被一个剧院经理看中，
首演定在两三周后。她还没离开酒馆，还没有高薪，还住在老街某处。
首演是她人生的转折点——如果能到达的话。

**什么过去**：她在老街唱了好几年。年轻时候的生活不是无可挑剔——
几个男朋友、一些酣醉的时刻、一些不体面的照片。对普通人无所谓，
对即将登台的新人，添油加醋就可能毁掉她。

你离开时，夜莺跟上来："谢谢。演出的夜晚我会给你留一张票的——如果你有空的话。"

## 4. 小节一：交割

### 4.1 账单

三天内备好 100 金交割款；期限日把钱放到码头邮箱，盯住来取钱的人。

交割款直接读取玩家库存，钱仍可挪作房租、恢复与其他生活开销。

**夜莺的兜底是有限的。** 她能当掉的首饰就值那么多，不是一张无限额的保险单。这一条是整个
小节一「攒钱」这条线成不成立的关键：如果她无限补差额，摆烂的玩家现金更多、骰子更多，
唯一的代价是一个他这会儿还读不懂的状态变量——攒钱就成了纯支出，算下来是被惩罚的。

三档结果，代价全部落在城里，不进交锋：

- **凑够了**：钱交出去，没有额外后果。
- **差在她能补的范围内**：她当掉首饰补齐，处境差一档。
- **差得比她能补的还多**：她补到底，信封仍然是薄的。写信的人回去一清点就知道——
  小节二开场他已经在准备下一步了。

> **待定**：这一档目前只改叙述，还没有落到机械上。它原本挂在「照片在老街传开」
> 那根钟上，那根钟已经整个移除。等小节二的压力结构定下来再给它一个真实的代价。

这样她的兜底还在（不会卡死、不会软锁），但不再免费。钱留在城市经济里：你挣它是为了
付得起，不是为了给交锋买一格进度。

> 顺带记一条原则：城里做的事不该全都以「所以交锋会不一样」收尾，否则那几天就变成
> 交锋前的读条。这一小节的两条线因此分开兑现：**钱在城里兑现**（房租、身体、下一小节的
> 手头），**踩点在交锋兑现**。玩家每天要答的就是这一句——这颗骰子拿去挣钱，还是拿去踩点。

**小节一不是多路径小节。** 它只有一条主干（凑出交割款）加一条可选的调查支线（踩点）。
早先试过让「借钱」「找人代付」「吓走他」并列成几条路，都不成立：账单是一个数字，
而数字只有一种满足方式，任何一条"路"最后都塌回同一件事上。真正的选择不在**怎么弄到钱**，
在**要不要分一部分骰子去做一件当天不挣钱的事**。多路径留给后面几节，它们的账单不是数字。

### 4.2 这几天的城市

开场的地图刻意是紧的：旅馆、码头、老街酒馆、布告栏、公园、诊所。

货运公司与警察局都留到第三小节：她开篇就说不要报警，第二小节又该专注老街调查；
首演威胁明确后，玩家带着信去请阿瑟安排后台保护，再从货运公司踏进投资方的资本线。

酒馆是例外，开场就开着——她在那儿唱歌，委托人必须找得到人。但它只开一半：台上的她、
跑堂的活、喝一杯、买点东西。角落里放贷的等老街一起开；开场就能借到四十金，这一小节的
压力会当场垮掉。

挣钱只有两份固定的活，别的机会都贴在布告栏上，而且会过期：

- 码头搬运：力量，高风险，收入较高；第一次出工自然认识乔。
- 酒馆跑堂：交际，低风险，收入稳定；干活的地方正好是她唱歌的地方。
- 布告栏临时委托：四种能力各有一档，收益高但机会会过期。

见识和敏锐在这一小节都没有可重复的日结工作，只能走布告栏。这是收紧地图的代价，也顺带
强化布告栏的教学位置：**这座城里能天天干的活只有两份，别的事情都是从一张纸和一个陌生人
开始的**——那正是玩家自己接下这单委托的方式。

#### 踩点 0/6：一根长钟，两个价位

**「替邮务站清点邮袋」不再是一份工作。** 它原本是敏锐向的低薪活，顺带填情报格，结果
两头都不像：工钱低到没人为钱去做，情报又混在工资单里读不出分量。现在整条摘出来，
做成一条**纯支出的调查线**——投进去的骰子当天一分钱不挣，这才是它该有的重量。

一根 0/6 的钟，顺序推进，中途有一个明确的兑现点。**两个价位从一开始就写在钟的备注里，
玩家要能一眼看见"到哪儿就够本、再往前还有什么"：**

| 里程碑 | 交锋里兑现成什么 |
|---|---|
| **3 格·认得那张脸** | 第一幕蹲守：真邮差变成一个**不花骰子、不掉冷静**就能认出的人 |
| **6 格·这一片你熟了** | 第二幕：多一条只有你知道的路（货栈边门） |

**认人兑现在第一幕，认地兑现在第二幕**，一格不越界——恰好对上这根钟前后两段学的东西。

六格是按"小节一只有三天"定的。0/8 在这个窗口里长得没人填得满；0/2 又太轻，两颗骰子就满，
加上白送的两格等于不用付钱——那不是投资，是签到。也不做成两根 0/3：这是全章第一个进度
结构，两根钟在教学位置上读起来太重。

**成本必须吃得到肉。** 三天 12 颗骰，凑够交割款约要 7 颗，交租与恢复再吃掉一两颗，
真正能自由支配的只有 4–5 颗。乔和夜莺各白送 1 格之后：

- **到 3 格**：自己投 1 颗。便宜，多数玩家会拿。
- **到 6 格**：自己投 4 颗，**几乎吃光全部余量**——钱多半会差一截。

而钱差一截会发生什么，§4.1 已经写死了：她当掉首饰补齐，处境差一档。所以填满这根钟的
真实代价是一句能说出口的话——**为了抓住他，你让她又当了一件首饰。** 这比"少赚几十金"
重得多，也把钱和调查两条线咬在一起，不再是各走各的。

**6 格装什么。** 每一格是一件具体的事，填格时直接说出来，玩家要知道自己"知道了什么"，
而不只是看着条往上涨。前三格是人：真邮差每天下午才来这一片 → 他隔天换班，换的人走
同一条线 → 认得那张脸了，车铃坏的那辆。后三格是地方，而且**顺带是小节二的预告片**：
邮箱背后那条巷子通到货栈 → 货栈的边门天黑落锁、可锁舌是坏的 → 后街那几户都是常年
住这儿的，往东是门廊，往西是楼梯。玩家还没走进城寨，已经开始认得它的外墙。

**动作只有一个**，标题和 subtitle 随进度改变（和城寨的前沿推进同一套语法）：混进邮务站
帮着清点邮袋 → 白天到那一片转转 → 天黑了蹲在对街看。清点邮袋保留成前段的一句 outcome，
不再单独立一个节点。

**中和好都只填一格**——情报不该靠运气发。两档的差别记在**冷静**上：中结果要付 1 点
（在雨里站了太久），好结果不付。这条顺带解决了节流：冷静只有 2 点，所以一天之内也踩不了
三次点，**身体自己就是这条线的闸门**，不必再写一条每日上限。

**两格白送的来自人，不花骰子也不掷判定**——跟乔卸过两班货之后问一句，以及问夜莺
（她在那一带长大）。它们不是奖励，是**人物关系的兑现**，也是「具名人物比抽象声望有感觉」
这个命题的实际考点：一格来自你新认识的人，一格来自你的委托人。**认识谁，本身就是情报的一部分。**

满格后钟不撤走，改写成交割日那晚的具体承诺，玩家得一直看得见自己攥着什么。

这里不再使用「码头准备 0/6」这类通用进度。普通工作负责钱与生活方向；案件只保留具名事实。
玩家在挣钱、踩点、交租与恢复之间分配 4 颗骰子。**核心教学体验：
你的一天不够用，而你选择靠什么活下来会留下具体痕迹。**

> 人物线（酒保、房东、弗兰克、布告栏上署名的委托）都推到小节二再展开。小节一的骰子
> 已经被交割款和这根钟吃满，再挂一条要花骰子的人物线，攒钱这条线就垮了——和这一节
> 不开放放贷是同一个理由。第一小节只让乔自然出现。

乔的后续人物线保持原结构：工作只能让两人从陌生到相熟；吃饭、接送孩子、受伤与照料
才推进更深关系。第一小节只负责让他自然出现，不让抽象劳工声望成为认识他的前置条件。

### 4.3 交割日交锋

交割日是一场**两幕交锋**。夜莺把钱放进邮箱后离开，你留在街对面。

分两幕，是因为这四拍里最有戏的不是追逐，是**等待**。追逐本身决策很薄——他跑你追，
剩下的只是快慢；而蹲守要回答一个真问题：**这些人里哪一个是他，你什么时候起身。**
两幕各问一种问题，这一场因此不会因为主目标只有一个就变单调。

> 这不算超前。重的不是幕数，是语法——小节三那种「目标钟＋危险钟＋随时可走」的合同语法
> 仍然留到小节三。这一场用的还是最朴素的钟，只是在追逐前面接了一段**看**。
> 而它正好一幕教一件事：**先读局面，再选代价。**后面每一场交锋都在做这两件事。

#### 第一幕：对街的窗口

天擦黑，**三个人**先后接近那个邮箱：

- **背邮包的老头**——车铃是坏的，慢悠悠地骑过来，一路和人点头
- **另一个穿制服的**——制服有点大，停在邮箱前一直没下车
- **门口抽烟的男人**——站了快一个钟头，烟一根接一根

只有三个人。**认人的问题不靠人多变难，靠"两个都像"变难**：他伪装成邮差，所以场上有
两个穿制服的，第三个人负责让排除法不是白送——划掉一个还剩两个，你仍然要付点什么才敢起身。

### 一个人一张卡，卡上一根钟和两种弄明白他的办法

每个人身上挂一根 **0/3** 的短钟「看明白他」，填满就有结论。喂它的动作有两种，
**故意不同技能**——如果三张卡都是「看清」，那就是同一个动作抄三遍，骰子往哪儿放没有区别。

| | 办法一 | 办法二 |
|---|---|---|
| 背邮包的老头 | 听那辆车的铃（敏锐） | 问面摊老板（交际） |
| 另一个穿制服的 | 看他的制服（敏锐） | 想想这个点该谁当班（学识） |
| 门口抽烟的男人 | 看他脚下（敏锐） | 过去借个火（交际） |

眼睛之外还有嘴和脑子。**"看明白"不等于"看见"**，所以它不该只有一种能力去解。

统一读法：坏 = 白花一颗骰、冷静 −1；中 = +1 格；好 = +2 格。好的那一档一颗骰子
就够得出结论，于是"这颗六点放哪儿"是个真问题。

- **结论是他** → **直接追出去。**结论本身就是推进，不再要玩家补点一次「起身」。
- **结论不是他** → 划掉，接着看下一个。

压力全部由窗口承担：**两回合**，走完信封就被取走了，你没看见是谁，巷口那一段也没了。

（骰池每回合末重掷，所以骰子在交锋里从来不紧——真正紧的是回合。窗口定成两回合，
就是让"三个人挨个弄明白"这件事本身来不及。）

**格数不按 2 点冷静去反推。** 交锋里的缓冲是可以用钱买的——烟、酒都是这条渠道；
把每根钟都压到"冷静刚好够"，等于提前把那条经济线废掉。

### 踩点在这里兑现成"这个人你不必费神去认"

**3 格**：真邮差那张卡不再有钟，也不再要办法——它塌成一次**不花骰子的执行**，
点一下「你认得背邮包的老头」，划掉。省下的是整整一根 0/3。

**排除法自己也是一条兑现路线**：排到只剩最后一个人时，那张卡也变成不花骰子的执行——
你已经知道了，不必再确认一遍。所以踩点省下的那一次，往往就是让你在窗口内排完的那一次。

**兑现必须由玩家自己按下去。** 早先的写法是踩过点的人在开局直接被划掉——那样玩家只
看见场上少了一张卡，感觉不到那几天蹲在雨里换来了什么。现在他还在场上，只是认出他
**不用花任何东西**：玩家按一下，那两天才落回他手里。

半途的投入也要看得见在往哪儿去：踩了一两格但没到 3 格时，那张卡会写"他有点面熟，
可你一时想不起来在哪儿见过"——只给一句话，不给机械好处。

**6 格不再往第一幕加第二个免费名额**：三个人里免费认出两个，等于把答案递到手上。
它整份兑现移到第二幕的边门。这也让"认人在第一幕、认地在第二幕"变成字面上成立的一句话。

**踩点从不直接指认取信人，它只让你免费排除错的人。**答案始终要玩家自己够到。

**看走眼这条分支删掉了。** 早先写的是「起身按住错的人 → 一街人围过来 → 巷口那一段没了」，
它要求先看清再起身两步走。现在钟填满就是结论，没有"以为是他"这一步。
输的方式只剩一种——**窗口关上，你还没弄明白**。

**时间压力用一根可见的短钟「他随时会动手」**（每回合 +1），不用"每回合扣冷静"。
[城市生活设计 §2.2](城市生活设计.md) 已经明确取消了交锋的每回合自动流失：缓冲只有 2 点，
任何逐回合流失都会让交锋反复撞穿倒下线，变成每打一场必重伤。冷静仍然会掉，
但只掉在**看错、白看**这类明确写出的坏结果上。

短钟填满时信封已经被取走，你没看见是谁——照样进第二幕，只是从最差的位置起跑。
**这一幕没有空结局**，只有位置好坏。

> 早辨认和晚辨认不额外挂第二幕的加成或惩罚。窗口本身就是压力，再叠一层就是罚两次。

#### 第二幕：三段街景，两个目标

取信人伪装成邮差，骑自行车逃向码头居民区。三段不断向前移动的街景：巷口、货栈区、
邮局后街。移动本身停不下来，每结束一个回合就永久驶过一段，未完成的局部进度随街景离开。

**每段是一个具体的障碍，两三种代价不同的解法**，而不是同一个「追击动作」做三遍：

每段两条路，**快的伤身、稳的慢**，玩家答的是"这一段我付什么"：

- **巷口**：一辆卖夜宵的推车横在中间。翻过去（力量，快，可能挨一下）／绕（敏锐，干净，但好结果也只推一格）
- **货栈区**：他钻进黑巷。跟进去（敏锐，最短，但看不见路）／贴着货堆推（力量，稳）
- **邮局后街**：人多了。扑上去（力量，坏结果直接受伤）／喊住他（交际，快，但整条街都会记得今晚是谁在这儿喊）

**每一张卡上都带着它自己那根局部钟。** 一根不显示在你正要按的按钮上的进度条，
等于不存在——玩家读不出这一按是往哪儿填的。主钟（拦下他 / 捡回散掉的钱）留在场景顶上，
段钟贴在卡角。

**取信人是一张真卡，不是空壳。** 他既是场上唯一的人、也是结算时唯一开口的人，
台词需要一个锚点；那张卡上写着他此刻在干什么，并且挂着主钟「拦下他」——
你追的东西和你离他还有多远，写在同一张卡上。

**6 格的兑现是货栈区多出来的第三条路：从边门包抄。**它不喂那一段的局部钟，直接推主目标
2–3 格——一手抵得上一整段街景。而且它是**你手里多一张别人没有的牌，由你决定打不打**，
不是系统自动送你跳过一段。玩家自己按下去的兑现，比自动生效的兑现记得住。

##### 今晚你要人还是要钱

两根钟，共用同一批骰子，三段街景填不满两根：

**拦下他（主）**——由追击动作喂。填满就是把他按住了。

**捡回散掉的钱（副）**——信封在他翻过推车时就散了，钱一路撒在街上。每弯一次腰，
他就远一点。0/4，每格 20 金。三段各有一个具体的捡法：摊子底下抢（敏锐）／
掀开压住钱的板条箱（力量）／在水沟里捞（敏锐）。

> 货栈区那一段原本写的是「喊搬运工替你捡」。**钱只能自己捡**——一地散钱面前，
> 没有一个搬运工会替你弯腰，这句话在这个世界里根本不成立。

两条轨道之间没有换算，谁也不喂谁。玩家真正要答的是那句话：**今晚你要人还是要钱。**
副目标在别处兑现——那是房租，是明天的饭——所以放弃它是真的疼。

> 这根副钟中途删过一次，理由是"它只在玩家真的付了钱时才存在"。小节一收成单一路径
> 之后玩家一定付了钱，信封里一定是真的，这条反对意见不再成立，所以恢复。

#### 结尾的扭打是剧情，不是又一层玩法

拦下他之后必定打起来，主角必定挨一记——**不掷骰**。你按住了一个不想被按住的人，
挨一下是既定代价，不是又一次运气。玩家用三段街景赢来的东西，不该被最后一掷推翻。
（同理，也不在交锋结束后补任何剧情检定。）

那场扭打里跑腿的招了：雇他的是个在老街酒馆喝多了的先生，穿得体面，袖口是磨的，
给钱时顺手抽了两根烟给他——**半包「老金牌」就落在了他这儿**。

#### 结果是两个轴，不是三档

- 人：拦下 / 跟丢
- 钱：0 / 20 / 40 / 60 / 80

最有味道的组合是「人按住了，钱散在街上没捡」——你选了人，明天还得交房租。
**拦下他不附带找回任何钱**：他手里攥着的只是一把空纸，钱全在你身后那条街上。
否则副钟就没有意义了。

**拦下**：拿到半包「老金牌」。这个牌子老街的铺子不进货；买得起的人不住这儿，
住这儿还抽它的人，是从别处落下来的——这就是莱恩。它是小节二唯一的具名物证。
**跟丢**：只剩一个方向，夜莺的处境也差一档。

跟丢的代价要落到机械上，不能只是"少一个道具"：**没有那半包烟，埃迪的信任就得从更低的
地方起步**——你走进城寨时手里没有一句能开口的话。这也顺带填上 §4.1 里「信封是薄的」
那一档一直悬着的待定：交割那晚手里空着的玩家，在小节二第三天会真的想起来。

物证不是硬门槛。没拿到，小节二照常开，只是没有那句「谁抽得起这个牌子」当敲门砖。
**无论哪个组合**，玩家都知道取信人来自码头居民区方向，故事推进。

### 4.4 结算后的人物戏

夜莺来旅馆看玩家。

她问伤势，问钱的事。"那些钱本来就是破财消灾。"
她更担心的是：他们还会来吗？会索要更多吗？

玩家告诉她要去码头居民区调查。她说自己在那里长大，指出东边门廊通向工会房间，
西边楼梯上去是桥廊，也提醒玩家外人走哪边都不会顺利。

这场戏的双重读法：
- 第一次：她逐渐信任玩家，愿意把老街的入口告诉他
- 真相后：她在确认玩家是否还愿意继续，同时只给出足够开始调查的方向

### 4.5 打开

码头居民区（城寨）出现在城市地图上，酒馆的另一半（放贷的）也一起开。警察局与货运公司留待第三小节首演威胁明确后开放。

## 5. 小节二：老街

**第一章的核心段。占全章近一半的自由行动时间。**

### 5.1 触发：交割后的来访

交割后夜莺来到住所，告诉玩家取信人回了码头居民区；她也承诺每天能抽出半天带路。城寨调查从此立刻开始。

第 7 天，第二封信才寄到剧院。当天醒来，旅馆前台转来剧院的紧急电话：经理要求玩家今天过去。
电话是关键剧情的触发，不能被玩家无限搁置；接到电话后可以先安排当天的其他行动，但不能在见经理之前休息。

玩家到剧院见到经理后，才真正读到第二封信：

莱恩发现对方会付钱，加码了。第二封信金额更高，附上一张裁过的旧照片，
证明他手里确实有底片和更多材料。额外条件：钱必须由夜莺本人送到老街。

这封信寄到了剧院——莱恩可能从第一次交割知道了经理的存在。
**经理因此第一次介入**：他从收发室看到信，先把信扣下，再通过电话把玩家叫去。
他开始出钱（提高委托报酬），也开始用他的方式处理——
但他的利益（首演成功、品牌不受损）和夜莺的利益（摆脱过去）从此不完全重合。

### 5.2 账单

**查出那个抽「老金牌」的人是谁。**

就这一句话。不是拿回底片，不是终止勒索——那些都得先知道该找谁才谈得上。
你手上是半包烟和一个方向。

压力不是精确倒计时，而是不确定性：他随时可能再动手，越快越好。

### 5.3 城寨

老街的居民区不是一片房子，是一栋自己长起来的东西。它的完整设定见
[城市生活设计 §3.3](城市生活设计.md)——垂直、密集、自建、自治，外来者读不懂。

**它借用静态地点探索的结构（Citizen Sleeper 那一路），但目的不是解谜，
是让玩家在过程里认识这个地方和住在里面的一群人。**

码头居民区下面不设探索容器或东、西子空间，所有可交互节点在渲染树中平级出现。探索动作却不是固定在
一个抽象区域上：它代表玩家当前抵达的空间前沿。一段路走通后，旧动作消失，新的探索动作在更深处的
Anchor 出现；途中发现的埃迪等常驻人物可以留在原处。这样既不制造没有玩法意义的 UI 嵌套，也让
动作、视线与三维空间中的行进方向一致。

| 路线 | 第一段前沿 | 中间结果 | 第二段前沿 | 最终结果 |
|---|---|---|---|---|
| 东侧 | 穿过东侧门廊 0/4 | 埃迪常驻在门廊 | 沿东侧回廊继续深入 0/4 | 工会房间 |
| 西侧 | 沿西侧楼梯往上走 0/4 | 楼梯口出现必须解决的阻碍 | 穿过上层桥廊 0/4 | 桥廊公寓 |

两段 0/4 合起来仍承担原来 0/8 的地点尺度，不是八段剧情。普通格数由每次行动的 outcome 表现当次所见；
前沿节点的标题、subtitle 和 outcome 承担持续的场景描述；填满后更换前沿、发现人物或地点、出现或解除
阻碍时，才用 Spotlight 明确宣布空间状态的转折。探索过程中人物真正开口时使用非阻塞 Banter。
坏 / 中 / 好结果分别推进 0 / 1 / 2 格。失败意味着这次确实被挡回来，并损失冷静。

好结果增加**老街熟脸**。熟脸不改判定难度——它只在两个地方兑现：酒馆闲话说到哪一层，
以及小节二结算时这栋楼是把你送出来还是把你赶出来（报酬档位）。**积累要么有关键兑现，
要么不要存在**；只给一两点判定修正的积累，玩家读不出意义，只读出复杂。

西侧楼梯填满时旧探索动作消失，居民区平级出现「楼梯口的人拦住了你」。这是一次高风险行动：坏结果
可能受伤且阻碍仍在，中、好结果才让新的上层桥廊探索前沿出现；解决后，当晚与夜莺谈起她为什么离开。
它不是另一根 Clock，而是路线中必须跨过去的一场摩擦。

每一段走通后，其探索动作与 Clock 一同消失。埃迪可以在路线中途留下，工会房间和桥廊公寓则在终点留下；
它们始终是码头居民区的平级节点。第一章结束后保留的是有后续用途的人物和地点，不是完成过的路线层级。

### 5.4 从烟进入人

埃迪在东侧门廊 4/4 被发现。他是常驻人物，不是章节结束后消失的线索机关：

- **买烟**：复用城市现有的「香烟」物品与价格，不为本节创造一次性商品；信任尚未填满时，
  每次交易也让埃迪的信任增加一格。
- **让埃迪相信你的来意**：填「埃迪的信任 0/8」。这是正向积累；每到 2、4、6、8 格，
  用阻塞 Dialogue 让他多说一层，而不是让数字孤立上涨。
- 半包「老金牌」提供可见判定优势，但不是硬门槛。交割时没拿到烟盒，仍能靠跑腿人的描述与关系推进。

信任填满以后，他才说出近一个月两笔特殊订单：一箱记在弗兰克账上，送进工会房间；
另一个穿旧西装、袖口磨白的男人一包一包买，从桥廊公寓方向过来。这两笔烟单就是信息钥匙。
在此之前，两处地点一经发现，就会在地点的第一层直接显示不可用的调查行动，并明确写出缺少
「埃迪的两笔老金牌烟单」或「埃迪记得的买家特征」。玩家因此先看见锁，再知道该去哪里拿钥匙。

拿到线索后，两处调查各消耗一枚骰子并一次完成，不再各自展开一根调查 Clock：

| 地点 | 调查 | 结果 |
|---|---|---|
| 工会房间 | 拿烟单与弗兰克对质 | 弗兰克在会后把烟留给众人；他是合理的嫌疑人，但不是雇跑腿的人 |
| 桥廊公寓 | 把买家特征交给洛蒂辨认 | 她由旧西装、烟和生活经历直接叫出名字：莱恩 |

工会线是有价值的岔路，不是主线硬门槛：它把弗兰克、工会和新机器接进这栋楼，也让玩家理解
「老金牌」曾经经过许多人之手。即使玩家先在桥廊找到莱恩，工会房间仍作为城市地点留下，
以后承接弗兰克与劳工线。

### 5.5 收场

桥廊调查完成时，洛蒂叫出莱恩的名字，小节目标立即完成；不再追加一个「就是他」按钮，
也不要求玩家先把工会调查做完。

如果第 7 天的第二封信已经到剧院，马上结算；如果玩家查得更早，则先保留「名字有了」，
等经理看见第二封信后结账。查得干不干净仍由老街熟脸决定：

- **熟脸满格**：这栋楼里的人肯把话说给你听——你不是被赶出来的，是被送出来的。
- **不满**：话是问出来的。有几扇门以后不会再对你开。

经理按这个结账。她把照片烧了，却留下一封莱恩写过的信，压在梳妆台的镜子底下。

底片与照片本身（买回 / 关系 / 强制三个方向）从这一节移出去了，现在落在小节三的
巷子对质里兑现（§6.5）。原方案见 [archive](archive/)。同理，原本的「照片在老街传开」
倒计时已整个移除：它对叙事没有帮助，这一节不设硬倒计时。

### 5.6 莱恩的人物塑造

玩家在调查过程中逐渐认识莱恩：
- 有案底——偷窃、诈骗、小额敲诈
- 因港口新机器失去工作
- 酗酒，大放厥词
- 和夜莺多年前认识（可能是旧男友，也可能只是圈子里的人）
- 他的照片和信件不一定是他自己的——可能从旧房东、当铺或某个地方弄到
- 勒索既为了钱，也带着怨恨："她从这里出去以后再没回来"

**要表现的行为模式**（为第二章的重新解释做铺垫）：
- 从不亲自取钱，找不知内情的人代取
- 靠匿名信和别人的手控制受害者，不愿当面承担后果
- 被堵住时首先找出口、推卸、把酒壮胆
- 会说狠话，但真正身体冲突时只想逃
- 索要的始终是钱，总给对方留"继续付钱就能没事"的台阶
- 杀了夜莺反而断了财路

第一章里这些特征不替他洗清嫌疑。
第二章才让同一组事实产生新的解释：
这个人擅长躲在纸后面榨钱，但第三封信背后的行动需要组织、内部情报
和承担巨大后果的能力——不是他熟悉的犯罪方式。

### 5.7 莱恩的下作

第二封信要求夜莺本人送钱——他想让她穿着漂亮衣服回到她拼命离开的地方低头。

玩家在老街能看到：
- 他把照片给别人看
- 他添上不存在的故事
- 他以"我们都认识她"为理由，把她的过去当公共谈资

但玩家也应看到：**老街不是莱恩。**
有人拒绝看照片，有人帮忙找底片，有人说莱恩做得恶心但不肯把本地人交给警察。

### 5.8 小节二期间的城市生活

这是玩家建设生活的主要时段：
- 在某处有稳定营生（酒馆服务员、码头搬运、警局文书、布告栏委托）
- 和一两个人建立关系（乔、弗兰克、阿瑟）
- 处理乔的伤势（如果已触发）
- 长期住所投入
- 每天四项竞争：主线调查、挣钱交租、身体恢复、人物机会

### 5.9 结算之后

- 前两封信确认都是莱恩写的，名字有了
- 莱恩本人没有被控制——他早不敢回那栋楼，人还在外面
- 玩家应有"我把他挖出来了"的满足感

**夜莺的变化**（微小，不宣言式）：
- 不再要求玩家"别伤害莱恩"
- 第一次主动问警方能把他关多久
- 经理说"采取必要办法"时没有反对
- 把取回的照片烧掉，却留下了一封莱恩写过的信

第一次看：受害者终于不忍了。
第二章回看：那封被留下的信是后来公司模仿笔迹的材料。

**打开**：经理报酬到账；剧院作为可前往地点出现；首演倒计时可见。

## 6. 小节三：教训莱恩

名字有了。你以为剩下的是件小事——**这个判断本身就是第四小节的引信。**

### 6.1 戏剧问题

**表面**：教训一个所有人都讨厌的混混。

**实际**：老街保护的不是莱恩，是「我们的人由我们自己处置」这条规矩。你是剧院雇来的
外地人，在这儿没有处置任何人的资格。这句话早就写在居民区的见闻卡上了——
「他们不喜欢那个写信的人，做得恶心。但真提到把本地人交给警察，所有人都摇头。这是两码事。」

**藏着的**（玩家读不到）：这件事从一开始就不该这么办。

### 6.2 拓扑

**三天空闲，然后一个晚上。**

小节二是探索——你不知道前面有什么，问题是要不要继续往未知里投骰子。
小节三是旅途——**你知道终点是莱恩，问题是你走到他面前的时候还剩下什么。**

```
经理雇的人去找他住哪儿：三天（不可加速）
  ↓  这三天是玩家自己的：挣钱、交租、在码头和老街过日子
第三天消息回来，出发卡亮起
  ↓
一场两幕交锋（一个晚上，中间不回城市）
   第一幕·潜入（infiltration 骨架）──惊动的人──→ 第二幕·施压（CS2 合同语法）
```

城市侧只有三件事：等三天、（可选）去问她一句、挑一个晚上出发。
**没有任何小节三专属的跑腿卡。**

### 6.3 那三天

经理花钱雇人去查莱恩住哪一间。三天，**不可加速**——一旦能花骰子催，最优解就是催，
这段时间又会变回一张跑腿卡。

三天做三件事：

- 经理的耐心第一次真的咬人：三天里它掉一到两格，而你只能等
- 它解释了首演之后那句「公关团队准备得异常充分」——**他一直有自己的人手**
- 最重要的：**这三天就是配钥匙的时间，而玩家不知道**

第三点是这一节的设计核心。玩家在这三天里做的是普通生活——在码头扛活、在老街露脸、
跟埃迪打交道——而这些正是钥匙的来源。他不觉得自己在准备什么，等进了场发现
「我认识乔」直接省掉一次惊动，那是回头才看懂的兑现。

这三天能不能撑住，取决于港口有没有比骰子更多的去处。**如果第三天玩家没事可干，
那不是三天太长，是常驻内容还不够**——解法在小节二多铺人，不在缩短这三天。

### 6.4 第一幕·潜入（骨架照 [infiltration.scm](../Content/scenes/encounters/infiltration.scm)）

**环境潜入，不是三个 buff 按钮。** 除了你站着的堆场，还有两个**去处**，
每个去处握着一个**改写全场规则**的开关——这才是 infiltration 的骨架，
不是"先按一手加成再按主按钮"。

| | |
|---|---|
| 压力钟 | **他快回来了 4 → 0** —— 每回合末走一格，**跟你做什么无关**。归零时你还没到位，就是从堆场追出去的 |
| 失败钟 | **惊动的人 0/6** —— 两幕全程可见。满格：整排屋子的灯都亮了，今晚办不成事 |
| 目标钟 | **摸到他门口 0/10** |
| 主动作 | **往里摸**（敏锐）——既推目标，也推惊动；**灯亮着 −1、老头在棚子口 −1** |

**这一幕的题在「他快回来了」这根钟上。** 惊动只有你自己作死才涨——所以光有它，
谨慎的玩家根本不受压迫，这一幕会既短又温吞。真正的压力是他在往回走：
两个开关都很值，但**每个开关都要花你一个回合**，而他不等你布置完。

**走廊尽头的灯 —— 大开关，一次性。** 拧掉三盏气灯（见识），全灭那一刻整片黑下来：
往里摸**完全不惊动人**，两个 −1 一起消失。代价前置（灭的瞬间 +1 惊动）、
限时（两回合）、而且**只有一次**——灯一亮回来 **+2 惊动**，还有人换上新灯罩守在那儿，
这条路从此锁死。对应 infiltration 的断电与备用电源。

**看堆场的棚子 —— 小开关，可反复买。** 把老头引开（交际）只清掉他那一个 −1，
但三回合后他坐回来，你可以再引一次。两个开关的角色是**不对称**的：
一个是押上大半个惊动预算换两回合自由，一个是随时可以再买的小便宜。

**由头** —— 顺一件工服（敏锐）攒下来，**不掷骰**，可以花在两处：往里走一段，或灭一盏灯。
差骰子的去处，也是一次真的分配。

玩家的循环因此是：**先支开老头把灯这一手变便宜 → 拧灯 → 黑下来的两回合一口气冲 →
还差两格，灯就要亮了、他也快到家了：是硬推着走完，还是把由头留到这一刻**。
两头都不能不管：一次也不动开关，灯亮着一路硬推，惊动会先满；
全花在布置上，他到家的时候你还在堆场。

**钥匙不给专属按钮，只改开局态势**：弗兰克 → 看堆场的是劳工的人，开局他就不在棚子里；
酒馆老板 → 这一片的门道他讲过，开局气灯已经灭了两盏；
乔 → 白送一个由头；埃迪 / 洛蒂 → 开局目标钟各 +2；夜莺 → 见 6.5。
钥匙省掉的是你本来要花在开场上的那两颗骰，不是一条别人没有的路。

### 6.5 那把最脏的钥匙

「他一个人回来」是**夜莺**告诉你的：去问她莱恩晚上几点出门、走哪条路。

她会告诉你。代价是她的信任 −1，以及那段对话本身：

> 他喝完最后一杯才回家，从来不走大路，走巷子那头。
> 他十四岁那年就那么走，怕人看见他鞋破了。

兑现在幕间：**第二幕开局的巷口的人 −1**。这是全章唯一一把要你付人的代价才能拿到的钥匙，
也是城市侧唯一一张小节三的卡。它留下来不是因为机械上需要它，
而是因为让他身边没有人的时候，是她告诉你的。

### 6.6 幕间：你走到他面前的时候还剩下什么

第一幕交给第二幕的是**巷口的人的起始格**，由两件事算出来——正好是 §6.2 那句话的机械形式：

- **一路惊动了多少人**：惊动的人有几格，巷口就有几格。
- **你是等在那儿，还是追出去的**：摸到门口时「他快回来了」还剩两格以上，你能挑地方等他，**−1**；
  没摸到门口就被他先到家，你是撞倒一摞板条箱追出去的，**+2**。夜莺那把钥匙再 **−1**（§6.5）。

起始格封顶在 5——再糟也不会一进巷子就被架出去，但你只剩一格可花。
两幕之间只有这一条线，它现在有两个来源。

### 6.7 第二幕·施压（CS2 的合同语法）

不再有窗口和倒计时——第二幕换一套骨架，而且是最成熟的那一套：

| | |
|---|---|
| 目标钟 | **他撒手 0/6** —— 格数就是你今晚的收获 |
| 危险钟 | **巷口的人 0/6** —— 满格被架出去，什么也带不走 |
| 常备 | **就到这儿** —— 全程可用 |

四个动作，每一手同时推两边，差别只在比例：

| 手法 | 推他 | 推街 |
|---|---|---|
| 摆事实 | 慢 | 不推 |
| 拿住他的软处 | 中 | 轻 |
| 按到墙上 | 快 | 重 |
| 搜他身上 | 中，另带额外收获 | 重，一次性 |

**唯一的问题是「现在够不够」。** 2 格他答应不再写，4 格照片和信到手，6 格连底片都交出来——
每一档都有他自己的一段话。收获是连续的，不是通关与否。

旧版本那根「0 嘴硬 / 1 动摇 / 2 服软 / 3 崩、要停在第 2 格」的状态轴**已经删掉**：
目标在中段、过冲有代价，读起来是个有正确答案的谜题，而且推进量 1–2 让过没过头一半靠运气。
玩家读到的是「别手滑」，不是「我决定到此为止」。现在「推崩他」不再是一个格子，
而是巷口已经快满了你还在逼——那时候你是明知道的，所以它是决策。

#### 他会回嘴

莱恩的行为模式（§5.6）就是他的应对表：讨价还价 → 拿酒壮胆 → 交东西留台阶
（「继续付钱就能没事」是他的本能）→ 最后连底片也从炉子后面掏出来。

#### 结算是谱系，不是成败

- **0–1 格**：他什么也没给。第三封信来的时候你会想起这一手。
- **2–3 格**：他只答应不再写，东西还在他那儿。
- **4–5 格**：照片和信到手，你是自己走出去的。
- **6 格**：连底片都交了。
- **被架出去**：什么也带不走，挨一下，经理耐心掉一格。老街那边的后果写在文案里，
  不再动熟脸——熟脸在小节二结算时就已经用完，这里再扣它没有任何下游会读到。


### 6.8 经理的耐心

第二封信寄到剧院、你去见过他之后，他的耐心开始走，而且是自己往下走的。

人物表里他的底色：对夜莺的维护是一笔投资，"千方百计呈现在别人面前，要人家感恩他"。
所以补它的唯一方式是**让他觉得这件事是他推动的**——办完一个小节，带着结果去见他，
他会当着别人说"我找的这个人，是懂事的"。没办完就没有可讲的，空手去只会更难看。
归零是硬失败：他换了人，委托到此为止。

这是全章第一根有脸的倒计时——不是流逝，是被扣，而且扣它的人会跟你说话。

**它到巷子为止。**你把那一段交代给他，他说"那就到这里，接下来是我的事"——
那句话就是这根钟停下的地方。往后事情看起来已经结束，你手上再没有东西可以拿去补它，
再让它走就成了没有出口的惩罚。后半章的时间压力换成另一样东西：钉死的首演日。

### 6.9 她说起莱恩（必看）

城寨查明身份后、动手之前。她讲那层楼上的两个孩子，讲他替她挑过水，
讲他写过信而她一封没回。

**双重读法**：第一遍是她终于肯说实话；第二遍回看——**她没有劝你别去**。
她只是确认了你会去，并且确认了你会觉得这是件小事。她一句假话也没说。
这是 §1.3「感情是真的，时机是选的」的一次具体实施。

### 6.10 这一节第一次做的事

- **人际关系从加成变成开局态势**：认识谁，决定你潜入时省下哪两颗骰。
- **第一个减法决策**：前面每一场的最优解都是填满钟，这一场是自己决定够了。
- **第一次用人的代价付账**：问她莱恩晚上的习惯，换她的信任 −1。
- **第一次有一段真正空着的时间**：三天，不可加速，做什么都由你。
- **第一次自己开关环境**：不是给自己加成，是把这一片的灯拧灭——世界变了，才有「趁现在」。
- **已有人物第一次在主线里担责**：弗兰克从「劳工声望的那道门」变成故事里的一条界线。
- **第一次有硬失败**。

## 7. 小节四：第三封信

小节四和首演之夜是**同一个东西的两次访问**：你先在剧院这张图上布置，
那天晚上这张图活过来。分开设计不成立，所以 §7 和 §8 要一起读。

这一节的时间压力来自**钉死的首演日**，不再是经理的脸色（见 §6.8）。

> 格数、期限、判定能力这些一律以脚本为准
> （[三封信.scm](../Content/scenes/world/三封信.scm)、[首演之夜.scm](../Content/scenes/encounters/首演之夜.scm)）。
> 本文只说为什么这么设计。

### 7.1 那三天：让玩家松手

巷子之后到第三封信之间隔三天。这三天**不是又一段等待**——小节三已经用过一次
"等三天、不可加速"，重复一遍没有新意。

这三天的设计目标是**制造一个假的结束**。经理结前半段报酬（一笔实钱），
城里能做的全是收尾性、消耗性的事：交清欠的房租、把伤治回来、还阿瑟那份人情、
请乔喝一杯、把借的钱还掉。玩家会自然地把钱和状态花在别处——因为案子结了。

然后第三封信落下来，他手上什么也不剩。

这是**资源节奏上的一次故意诱导**，也是 §6 开头那句"你以为剩下的是件小事"的兑现点。
这三天里她第一次不在酒馆：托人带话请你去剧院看彩排（人物节点仍留在酒馆，
只是一次性事件，不违反 §1.5）。

### 7.2 触发

第三封信出现在夜莺的化妆间。

不要钱，不提过去。只写一件事：如果她在首演当晚登台，她会死在舞台上。
信里提到一个只有内部人员才知道的排练细节——登台时间、换装顺序、
她从台底升上来的那个时刻。

玩家和经理都认为是莱恩——勒索失败后升级到报复。合理推断。

### 7.3 账单

**经理拒绝取消首演。在首演之前，把她要走的那条路清干净。**

命题不是"她别受伤"，是**让她重新站上舞台**。这个差别决定整节的形状：
她不肯走，她要唱完，所以保护 ≠ 站在她身边，保护 = 提前把场子布置好，
到那天晚上你才有余地。

这不是调查问题——玩家已经"知道"是谁。他要做的是布置。

### 7.4 剧院是一座圆形剧场

贝城旧圆形剧场，早年在这儿办拳赛。一句话解释了为什么是圆的、
为什么外圈那么多门（散场要快）、为什么演员从台底升上来（拳手从来不从侧面进场）。
**她站在当年打拳的地方唱歌。**

这个形状本身就是设计：**没有侧台、没有幕布、没有后台屏障，她在正中央，
三百六十度都是人。**三个位置因此是三个同心环，而且它们不是并列的，是串起来的：

- 她出事时会被挤下中央台，退到内环。**她要走回舞台，必须穿过人群。**
  内环没布置，你就算守住了中央台她也回不去
- 圆形剧场没有隔断，**从外圈门进来的人能直接走到她跟前**。
  外圈失守不只是"人跑了"，是有人够得着她

整场交锋因此是**从外往里收**的一场仗。

### 7.5 三个环的准备

| | 环 | 城里做什么 |
|---|---|---|
| 外 | **外圈的门与后廊** | 五六扇门，插销、值夜的人、后廊堆的杂物 |
| 中 | **内环走道与看台** | 疏散路线、领班和引座员、把翻得过去的栏杆钉死 |
| 内 | **中央台与升降口** | 升降台的行程、台底那个封了一年的通风口 |

中央能布置的东西最少，**因为那块地方本来就没什么可布置的**：圆台四面无遮，
没有门可封，没有走道可清，你能动的只有机械和台底那点风。少不是因为谁不肯配合——
是这座剧场的形状决定的。**她站的地方就是最没法保护的地方。**

（不要写成"她愿不愿意为你改演出"。首演是她等了六年的东西，
一个刚认识几周的侦探不构成她放弃或改动它的理由，那个交易本身不成立。）

每一格填的是具体的一件事，填格时直接说出来，不是"准备度 +1"。
三个环加起来做得完，但要牺牲别的——这几天还得交房租、把伤治回来。

### 7.6 人手是有脾气的人

人手不占准备格——**格子是布置，人是活的**。花一次行动去谈，位置由他自己决定，
那天晚上他每回合按自己的方式做一件事，出一行他做了什么。

重点是每个人都有"他会做的"和**"他不会做的"**：

| 人 | 在哪 | 他每回合做什么 | 他不会做什么 |
|---|---|---|---|
| **乔** | 外圈 | 把货运推车一辆辆横到门口 | 不进场。人从他手里过去了他也不追 |
| **弗兰克的人** | 外圈 | 站满后廊，压住那一头 | 不等你下令。局面难看了他们自己动手，人是按住了，那人身上的东西也散了 |
| **阿瑟的警察** | 内环 | 按程序疏散，一回合清一段环廊 | **不管她。**他们的任务是人群和门，她在人堆里他们不会去捞 |
| **剧院领班** | 内环 | 认得每一排座位，把人往对的门引 | 一旦有人推他，他就不干了 |

**中央环没有人手。**没人能替你站在她旁边——这一条是保护命题的底线，
也是为什么最后一手永远得你自己去。

所以部署决定的不只是效率，是**那天晚上事情用什么方式被解决**：
警察在内环意味着人群疏得快而她没人管；老街的人在外圈意味着人抓得住但东西留不下。

### 7.7 后台名册

信里写着只有后台的人才知道的顺序，所以那个人**就在这栋楼里**。

查名册（通行证、临时工、谁最近被替换过）不产出真相，产出的是**首演之夜那张表上的几条**：
你提前知道台底会进烟、知道三号门是活的，于是你知道该往哪个环铺格子。

**第一次玩靠名册，玩过一次靠记忆**——这两者是同一件事的两个来源，规则上不区分。
这也是固定日程表最实在的好处。

### 7.8 人物戏

夜莺拒绝取消首演——"我等了这么多年"。
她请玩家首演当晚留在她看得见的地方。

- 第一次读：她信任玩家，只有他能保护她
- 真相后：她知道会有"事件"，需要一个真心相信威胁的人在场

赞助方的薇拉在这一节露一次面，两句话，零机制。第一章不解释她是谁。

### 7.9 这一节第一次做的事

- **第一次布置一件还没发生的事**：你在图上放东西，几天后这张图活过来
- **第一次让积累变成人**：关系不再是判定修正，是那天晚上站在某个环上的一个有脾气的人
- **第一次有假的结束**：那三天让你把资源花在别处
- **第一次让空间本身成为上限**：中央能布置的最少，因为圆台上没有东西可布置

## 8. 首演之夜

**第一章的大型交锋。交锋预算集中在这里。**

### 8.1 事故

第三段唱到一半，舞台升起时全场的灯一起灭了。烟从台底涌上来。

公司安排的是"可控惊扰"，但涉及真实的物理危险：停电会踩踏，烟会引发恐慌，
执行者动作过大会真的伤人。**玩家的准备不是在防一个假威胁，
而是在控制一个随时可能失控的局面。**

### 8.2 三处大麻烦，不是一串小事

演出剩下几段唱。三个环上各烧着**一处大麻烦**——每一处都要连着几回合往里
投骰子才压得下去，而不是一堆两三格就打完的小事。小事只是清单；玩家要的感觉是
**自顾不暇**：三处同时烧，每一处都吞骰子，而你只有一个人。

每处麻烦有自己的进度和期限，**期限归零就造成真的伤害，不是扣分**：

- **中央 · 升降台卡在半程**——她半个人还在台面下，齿轮咬着裙摆。
  归零就是她的腿伤了，今晚不会再站上那个台子。
- **内环 · 台下的恐慌**——前排站上椅子，环廊最窄那段堵死。
  归零就是环廊塌成一团，人群把她一起卷走。
- **外圈 · 那个人**——他不慌，穿过人群一直朝正中间去。归零就是他够到她。
- **中央 · 她要重新站上去**——升降台解开之后才出现。这是今晚你真正要的东西。

四处加起来的量，跟你这几段唱里能投出的骰子大致相当——**账面刚好，期限一错开就不够**。
前半场你得同时喂中央和内环，而外圈随后就烧起来。**没有人手，必然崩掉一处。**

固定而不是随机，理由有三：每一格都能写成一句具体的事（"手闸在台底左边，你摸到了，
台面松了半寸"）；玩过一次的人知道该往哪个环铺；而最重要的是，玩完你会觉得
这一晚**是编排过的**——它本来就是。

「她要重新站上去」一满，交锋就结束。所以最后还有一个取舍：
**你要现在把她送回台上，还是先把那个人按住。**

### 8.3 准备与人手怎么兑现

**布置 → 开局就已经压下去一截。**那一处起始就带着进度，期限也多撑一会儿。
布置替不了你把事办完，它只是让你不至于太晚才动手。中央能布置的最少，
所以**中央的麻烦你永远得亲自去**。

**人手 → 每回合替他那个环啃一口。**一个人手大致等于替你分掉一整处：
警察和领班都在内环，人群那一摊他们能自己啃完；乔和弗兰克都在外圈，
那个最危险的人被替你挡住。**中央没有人手**——升降台和最后那几步全是你的骰子。

这就是"没有人帮忙你压不住全部"的具体形状：不是加成变少，是**你少了一双手**。
弗兰克的人还有自己的脾气——外圈眼看压不住时他们自己上，人按住了，
那人身上的东西也散了。

**名册 → 提前知道会烧起来的是哪几处**，于是知道该往哪个环铺。

### 8.4 结算向量（保存到第二章）

不另设结算钟，四个向量直接由哪几处归零决定：

1. 夜莺是否受伤（升降台归零 / 那个人够到她）
2. 首演完成程度（她有没有重新站上去，站到第几格）
3. 执行者是否被抓、是否留下物证（外圈那处；弗兰克的人动过手则物证散了）
4. 哪些人物在现场帮助过玩家

### 8.5 那个疑点

三个圈子同时烧起来，而且每一处都大到一个人按不住——**莱恩一个人怎么可能。**

第一章要给玩家一个当场就够用的解释：场内让弗兰克的人或警察说一句
"这不像一个人干的手笔"，阿瑟结案时一句"他雇的人"压掉它。玩家收下这个解释，
疑点埋成，等第二章打开。

## 9. 公开结案

警方迅速行动。莱恩被逮捕或被宣布在逃。

报纸标题：港口无业人员勒索威胁，夜莺不惧危险，华丽谢幕。
经理的公关团队准备得异常充分。三封信被装进同一份案卷。
警方以搜索莱恩同伙为由封锁老街。

夜莺完成了从酒馆歌女到剧院明星的蜕变。
玩家拿到报酬，完成委托。

**第一章在情绪上是一次胜利。**

### 9.1 留在叙事中的细节（不标注、不提示）

- 莱恩前两封信都要钱，第三封突然只要命
- 莱恩惯于让别人代劳、自己逃跑，首演事件需要内部情报和周密安排
- 现场追到的人比莱恩冷静、专业，知道后台出口
- 夜莺在事故后恢复得异常快
- 经理和报纸的反应速度异常快
- 夜莺从未明确说过"我不知道第三封信谁写的"——她只说过"听起来像他"

这些在第一章都有合理解释（莱恩雇了同伙、公司擅长宣传、她是专业歌手）。
它们只在第二章被新事实打开时，才从"合理"变成"可疑"。

## 10. 人物弧

### 10.1 夜莺的表面弧（玩家第一章看到的）

```
酒馆歌女，害怕被过去拖回去
  → 接受玩家的帮助，逐渐信任
  → 被莱恩的下作伤害，决心和过去切断
  → 面对死亡威胁仍坚持登台
  → 在混乱中回到舞台，完成蜕变
```

### 10.2 夜莺的真实弧（第二章揭露后回看）

```
收到勒索信，立刻猜到是莱恩，但需要一个人替自己去查
  → 挑选了一个穷、没有关系、容易被激起保护欲的侦探
  → 观察他是否靠得住：会不会为她冒险、会不会坚持、会不会听话
  → 被莱恩的下作真实地伤害——这部分不是假的
  → 利用真实的愤怒做出决定：允许公司伪造第三封信、允许莱恩背锅
  → 知道玩家会为了她在首演冒险，让他留下
  → 得到了新的人生，代价是让另一个人承担了不属于他的罪
```

### 10.3 每场人物戏的双重读法

| 场景 | 第一次理解 | 真相后理解 |
|---|---|---|
| 她坚持不报警 | 害怕警方、念旧情 | 避免警方直接查穿她已认出莱恩 |
| 她让玩家调查老街 | 她不敢独自面对过去 | 让玩家替自己确认材料、承担冲突 |
| 她在玩家受伤后登门 | 关心和信任 | 真实关心 + 确认玩家是否还愿意继续 |
| 她在老街谈起自己怎样离开 | 袒露内心 | 让玩家理解为什么她"值得被带出去" |
| 她在第二封信后变得坚决 | 受害者不再忍让 | 她已决定莱恩和老街可以承担代价 |
| 她拒绝取消首演 | 勇敢、珍惜职业 | 她知道第三封信不会按字面兑现 |
| 她要求玩家留在后台 | 信赖玩家 | 玩家是保险，也是让骗局可信的证人 |
| 事故后重新登台 | 惊人的勇气 | 她事先知道会有中断，准备过怎样回来 |
| 演出后和玩家相见 | 劫后余生的感情 | 感情可能存在，也同时确保玩家接受同一个故事 |

### 10.4 莱恩的人物弧

```
失业的酗酒者，拿到了夜莺过去的照片和信件
  → 用匿名信试探对方会不会付钱
  → 发现对方会付，加码并附上照片
  → 要求夜莺亲自来，不只是挣钱，也是惩罚"离开后再没回来"的人
  → 被玩家查到，勒索材料被拿走
  → 逃走或被释放
  → 首演之夜被捕，成为三封信案的唯一嫌疑人
```

他的功能是**一个真实的坏人被加工成一个更有用的恶人**。

## 11. 三个小节的玩法递进

| 小节 | 问题类型 | 玩法重心 | 考什么 |
|---|---|---|---|
| 一：交割 | 封闭执行 | 多途径挣钱 + 交锋 | 骰子分配的基本取舍；人物与具名线索怎样进入交锋 |
| 二：老街 | 开放探索 | 多路线求解 + 城市生活建设 | 在不欢迎你的社区里用不同方式找到一样东西 |
| 三：教训莱恩 | 旅途 → 情绪状态机（两幕） | 三道锁怎么过 + 在窗口里停手 | 你能不能在别人的地盘上知道分寸 |
| 四：第三封信 | 空间布置 | 三个环各自的准备 + 请谁那天到场 | 你几天前放下的东西，那晚替你站在哪儿 |
| 首演 | 分诊 | 三处大麻烦之间的取舍 | 每一处都吞骰子，而你只有一个人 |

## 12. 人物生活职能

| 人物 | 日常存在 | 对玩家的实际作用 |
|---|---|---|
| **夜莺** | 第一章期间都在酒馆驻唱 | 每天可投入一枚行动骰请她唱一首歌，稳定恢复 2 点冷静；也是主线委托人与信息来源 |
| **经理** | 小节二起出现在剧院 | 提高报酬；提供剧院相关信息；代表公司利益 |
| **莱恩** | 老街游荡（不可直接互动，通过其他人描述） | 调查对象 |
| **乔** | 码头工人 → 居民区养伤 | 同伴骰（入队后 +1 颗） |
| **弗兰克** | 码头工头 | 劳工深线人物；首演之夜可请他的人守外圈（不等你下令） |
| **阿瑟** | 警局文员 | 程序工具；首演之夜可请警察守内环（不管她） |
| **酒馆老板** | 老街酒馆 | 服务员工作的入口；老街的守门人 |

## 13. 与 demo 短篇的关系

Demo 是自闭环的试验故事（歌厅卖身约 / 收账人 / 老板），用来验证系统。
本章沿用 demo 验证过的想法：

- 人物有日常生活职能，不是任务图标
- 城市有活着的感觉——工作、恢复、人物、天气构成一天的质感
- 同一个问题可以用不同生活路线抵达
- 交锋是城市节奏的一环，不是独立的战斗关卡
- 坏结算留疤不做硬 game over
- 所有状态可见（时钟、账单、期限）

但剧情、人物弧和小节结构全部为三封信版本重新设计，不受 demo 的
人物关系和故事走向约束。
