## 持久叙事结果

- 艾迪：本幕只保留联合起吊；工钱争执、自动停班和停班探望退出正式流程。安全落货／延期卸载都完成当天必须参加的夜班。
- 夜莺：`完整试唱`／`压缩试唱`，都让赞助人听见她；不是“旧歌善、新歌恶”。
- 最后一排的观众：`车辆线索`／`错失车辆`／`倒下`及已取得情报数量；车辆信息与已知机械隐患进入手头的事。
- 演出服：`完成`／`另找他人`；混合钱与骰子不会生成更多结局。
- 露西：`已入学`／`延后`，不直接决定她对尼尔的态度。
