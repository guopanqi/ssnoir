# SSNoir 第一版资源循环审计

## 0. 结论

当前版本的主要问题不是资源数量不足，而是绝大多数产出只有一个终点：六天一次的码头公共交锋。

```text
码头关系 → 交锋援助
办案通行证 → 交锋程序行动
保险 → 交锋失败赔付
```

这些更接近“交锋优惠券”，还没有形成城市内部的资源循环。下一阶段应暂停增加新路线和新地点，先让现有产出在普通城市生活中具有多个、清晰、可预测的用途。

本轮建议只落实三个改动：

1. 让办案通行证在交锋、码头和货运公司之间三选一使用。
2. 重做银行与货运投资的收益关系，使投资确实能替代未来的一次工作。
3. 将老周的长期价值指向“同伴／额外行动力”，不再增加不直观的小概率修正。

普通“情报”暂不扩张。官方关注可以在上述循环稳定后作为第一个城市状态加入；货运行情继续延后。

## 1. 现有资源审计

### 1.1 金钱

#### 当前来源

- 饭摊刷盘子：低收益、低风险。
- 码头搬运、记账：中等收益。
- 码头走私：最高单次收益。
- 警局文书：低收益。
- 货运公司联络货主：中等收益。
- 货运投资：锁定本金三天后结算。
- 银行：当前每天按余额 5% 复利。
- 公共交锋和线索出售。

#### 当前用途

- 房租、食物、药品、酒。
- 花、唱片机、公寓、豪宅。
- 交锋贿赂。
- 货运投资本金。
- 保险。
- 银行存款。

#### 问题

金钱的消费口数量不少，但大部分属于：

- 维持生存；
- 一次性终点购买；
- 公共交锋准备。

真正能改变未来时间分配的用途只有公寓和投资。

当前银行与投资的收益关系也不成立：

- 银行存入 100，按每天 5% 复利，三天约增加 15，而且不消耗行动骰。
- 货运投资投入 60，先花若干行动考察和谈判，三天后返回 50／75／90，净收益为 -10／15／30。

银行的安全收益接近普通投资，货运投资却需要更多时间、承担亏损并锁定本金。因此富商线没有形成明显的资本优势。

### 1.2 普通情报

#### 当前来源

- 走私成功。
- 公共交锋成功。
- 交锋中趁乱搜寻。

#### 当前用途

当前激活的城市生活内容中没有明确消费口。

#### 结论

普通“情报”目前不是资源，而是一个尚未完成的计数器。

它也不应被定义成“另一种钱”。第一版暂定语义为：

> 一条尚未指向具体对象、但值得继续追查的消息或门路。

它未来应该用于生成或揭示新的选择，例如：

- 在布告栏中发现一张额外委托；
- 找到一个投资机会；
- 开启一次调查入口；
- 发现某个事件的可选目标。

它不应用作所有工作的通用难度减免，也不应直接兑换普通商品。

由于第一版尚未实现布告栏和事件发现系统，本阶段建议：

- 不为普通情报继续增加新来源；
- 暂时移除走私和公共交锋的普通情报奖励，或保留但不把它纳入平衡；
- 继续使用“异常货单”这类具名线索表达具体事实；
- 等布告栏或城市事件系统落地后，再正式启用普通情报。

### 1.3 势力关系与人物关系

势力关系当前主要承担地点和行动门槛；人物关系主要解锁一次支线和一次交锋能力。

问题不在于关系必须提供大量细碎加成，而在于关系完成后没有改变玩家的普通生活结构。

以下效果不适合作为第一版的主要关系回报：

- 提前提醒某项工作风险；
- 小概率把一次坏结果降为中性；
- 模糊地“介绍一些人”而没有立即可见的新能力。

这些效果难以规划，玩家也很难感受到它们改变了生活。

劳工关系需要一个直接、稳定、能改变行动预算的长期兑现。建议使用项目已经预留的同伴系统：

- 老周完整支线结束后，可以成为世界模式同伴；
- 同伴每天提供一颗自己的行动骰；
- 同伴有明确能力和压力状态；
- 同伴压力过高时暂时离队；
- 交锋模式继续使用老周的显式援助节点，不直接使用同伴骰。

这使人物关系形成清晰反馈：

```text
玩家牺牲若干工作时间建立关系
→ 获得一个真实的人
→ 每天拥有更多可分配时间
→ 可以工作、休息或经营其他关系
```

这是类似“食物 → 人口 → 更多产出”的长期循环。由于额外行动力非常强，老周不应在当前短小支线结束后立即加入；建议将“人物小节完成”和“正式成为同伴”分成两个阶段，后者至少还要求一次重要选择，例如将异常货单交给老周或完成下一段人物内容。

如果本阶段不准备接入动态同伴招募，就不要用难以感知的小修正填补关系回报。可以暂时保留当前交锋援助，等同伴系统作为独立里程碑实现。

### 1.4 身体状态

健康、压力、饱腹已经形成基础循环：

- 高风险工作和交锋损耗健康与压力；
- 食物、药品、住所和休息负责恢复；
- 饱腹每日下降。

当前问题是身体循环主要限制玩家，而很少改变行动形态。但这不是下一阶段的首要问题。第一版暂不增加高压力减骰、低健康减骰等惩罚，以免制造死亡螺旋。

只需在资源平衡时确认：

- 高风险收入确实需要消耗恢复资源；
- 富商囤积药品和拥有住所确实能缩短恢复周期；
- 劳工高收益不能在长期完全无视身体成本。

### 1.5 资产

当前最有成长感的资产其实是公寓：投入 120 后永久免除房租，并提高睡眠恢复。这是一个会改变未来资源转换的购买。

花和唱片机也会增加新的恢复行动，但作用较窄。银行存款和货运投资存在严重收益重叠，需要重做。

第一版不再增加更多家具或资产种类。先用公寓和投资验证：

- 一次性资产能否减少长期维持成本；
- 周期项目能否减少未来必须工作的次数。

### 1.6 一次性能力

#### 办案通行证

当前只在公共交锋中使用，属于单用途优惠券。

第一版建议让同一张通行证在三个明确场合中三选一使用：

1. **公共交锋：程序干预**  
   保留当前效果：回退压力并跳过一次压力推进。
2. **货运公司：调阅货运备案**  
   消耗通行证，直接把当前项目设置为“已考察／普通质量”，省下一次考察行动，但不能获得最高质量。
3. **码头：销掉巡查记录**  
   当走私因官方风声关闭时，消耗通行证立即清除走私冷却。

三个用途全部是玩家主动点击、结果完全可见的行动。玩家能明确比较：把这张证用来救眼前的交锋、节省一次投资考察，还是恢复非法收入。

通行证仍然最多持有一张，并保留签发冷却，避免囤积。

#### 保险

当前保险花 15，只有公共交锋失败时赔 20，净效果过小且只服务交锋。

若要把保险扩展到所有工作事故、健康损失和投资亏损，需要建立统一损失事件系统，第一版认知和工程成本都过高。

本阶段建议直接删除保险，而不是继续扩展。富商路线先靠投资、现金储备、药品和住所体现抗风险能力。以后出现统一损失记录后再重新设计保险。

## 2. 第一版可落地的三个循环

### 2.1 资本循环

第一版采用“单次、可重复的周期项目”，不采用永久每三天自动生钱的资产。

```text
考察一次
→ 可选谈判一次
→ 投入本金
→ 锁定三天
→ 结算一次
→ 项目结束，可以重新寻找下一项
```

选择单次项目的原因：

- 结果直观；
- 不会产生无限复利；
- 不需要维护费和复杂资产管理；
- 玩家每轮仍需决定是否继续把时间和本金投进去。

永久资产可以留给后续“拥有生意”阶段。

#### 收益目标

投资的普通结果必须明显优于把同一行动用于普通工作，否则没有资本意义。

建议先测试以下范围，而不是立即锁死具体数值：

- 本金：60。
- 差项目：返还 50～60。
- 普通项目：返还 85～90，净赚约 25～30。
- 好项目：返还 105～110，净赚约 45～50。
- 锁定期：3天。
- 同时只能有一个项目。

进入投资循环后，每轮项目建议只强制一次“考察”行动；谈判为可选，玩家可以多花一个骰子争取更高回报。这样普通项目的净收益能够替代约一次普通工作，好项目能够替代两次左右工作。

#### 银行调整

银行不能继续每天 5% 复利。建议改成安全储存与极低固定收益：

- 存款门槛仍为 100；
- 每 6 天固定增加 5，而不是按余额百分比复利；
- 或第一版直接取消利息，只保留安全储蓄。

银行负责安全和流动性，货运投资负责高回报和本金风险，两者边界必须清晰。

### 2.2 官僚循环

官僚路线不新增“权限点”。它用工作和人物支线获得可见、具体、一次性的办案通行证。

```text
花时间处理文书与探长事务
→ 获得一张通行证
→ 在三个明确用途之间选择
→ 节省时间、控制交锋压力或恢复非法机会
→ 冷却后才能再次办理
```

这条循环当前版本即可实现，不需要新的通用权限系统。

延期一天也是清晰有效的官僚能力：它直接提供三颗新的日常骰子，但每个公共小节最多使用一次，而且仍然必须处理事件。

官僚路线第一版的可感知价值由两部分组成：

- 延期一天：增加准备时间；
- 通行证三选一：改变交锋、投资或码头非法工作的时间成本。

### 2.3 人际循环

当前老周关系只有交锋援助，尚未形成城市循环。

第一版有两个选择：

#### 方案A：本阶段接入同伴招募（推荐，但工程量较高）

- 扩展人物支线至第二个小节；
- 满足明确条件后招募老周；
- 老周每天提供一颗世界行动骰；
- 老周有自己的能力、压力和暂离状态；
- 这颗骰可以用于城市工作和人物行动，但不能直接用于交锋；
- 交锋继续使用一次性老周援助。

这是最清晰、最有成长感的关系反馈。

#### 方案B：本阶段不扩展

- 保留老周当前人物小节与交锋援助；
- 不增加概率美差、风险预告或坏结果修正；
- 等同伴招募作为独立系统完整落地。

不建议为了让关系“看起来有用”而加入玩家无法规划的细碎被动效果。

## 3. 普通情报的定义与处理

### 3.1 它与钱的区别

金钱代表：

> 已知商品和服务之间可以自由交换的通用购买力。

普通情报代表：

> 一条可以继续追查、从而生成新机会的消息来源。

因此：

- 金钱购买已经存在的选项；
- 情报发现原本没有出现的选项。

情报不应该像钱一样直接支付固定价格，也不应该成为“花一点，所有判定 +1”的通用增益。

### 3.2 第一版决定

当前版本没有布告栏刷新、调查入口生成或机会发现系统，所以普通情报暂时无法兑现其语义。

本阶段不强行打通普通情报循环。先暂停其数值增长和UI重要性，继续使用具名线索承担具体事实。

等布告栏或城市涌现事件落地后，再使用普通情报执行：

```text
消耗一条情报
→ 从当前可用事件池中揭示一个额外机会
```

## 4. 城市状态设计判断

### 4.1 官方关注

“官方关注”可以作为下一个加入的城市／玩家状态，因为当前已经存在走私、警局、通行证和公共冲突，具备足够的生产与消费节点。

它更接近玩家当前受到的官方注意，而不是整个城市的抽象治安值。

#### 状态

第一版只做四档可见状态：

- 0：无人注意。
- 1：有人留意。
- 2：重点关注。
- 3：被盯上。

#### 增长

- 走私坏结果：+1或+2。
- 在公开事件中违法且失败：+1。
- 未来其他明确的公开违法行为。

正常工作、秘密成功且无人发现的行动不自动增加。

#### 效果

- 0～1：非法工作正常开放。
- 2：走私获得明确的负修正，节点直接显示原因。
- 3：走私暂时关闭，必须等关注下降或使用具体官僚手段处理。

#### 下降

- 连续三天没有新增关注：-1。
- 或消耗一张办案通行证执行“销掉记录”：-1。

所有变化和阈值必须显示，不能隐藏概率。

#### 与其他循环的连接

- 走私提供高收益，但可能提高关注。
- 关注限制高收益非法工作。
- 警局关系和通行证可以更快处理关注。
- 玩家也可以主动停止违法工作，花时间等待它自然下降。

这已经形成一个完整、可读的风险循环。因此在资本与通行证循环稳定后，可以优先实现官方关注。

### 4.2 货运行情

货运行情的概念成立，但不应现在实现。

如果行情只让所有工资和投资收益一起上涨，玩家当然会无脑追求高行情。它必须在不同活动之间制造相反激励。

未来可采用三个公开档位：

- 低迷。
- 平稳。
- 繁忙。

建议作用：

| 行情 | 普通货运工资 | 投资进入成本／利润空间 | 玩家倾向 |
|---|---|---|---|
| 低迷 | 较低 | 项目便宜、利润空间较大 | 适合买入和经营关系 |
| 平稳 | 基准 | 基准 | 自由安排 |
| 繁忙 | 较高 | 项目昂贵、利润空间较小 | 适合工作和回收现金 |

因此行情不是越高越好：

- 低迷时工作收入差，但适合投资；
- 繁忙时工资高，但投资买入条件差。

投资项目在创建时锁定本金和预计回报，后续行情变化不追溯修改已经投入的项目，避免认知负担。

#### 行情如何变化

第一版不允许玩家通过重复某个动作无限推高行情。它应主要由公开、可预测的城市周期或事件改变，例如：

- 每三天在低迷／平稳／繁忙之间推进；
- 公共事件使下一阶段行情下降；
- 后续正式主线或城市事件改变周期。

玩家的普通工作暂时不直接推动全城行情，避免出现“无脑刷高”。

#### 与官方关注的连接

两个状态不需要直接互相加减。它们通过玩家选择发生联系：

```text
行情繁忙
→ 合法工作和走私机会都更有吸引力
→ 玩家可能选择高收益走私
→ 暴露失败提高官方关注
→ 高关注限制继续走私
→ 玩家转向合法工作、警局处理或等待
```

连接来自行动选择，而不是公式强行绑定。

#### 实施时机

先固定没有行情时的工资、投资和生存基线，再加入行情修正。否则无法判断问题来自基础经济还是动态状态。

因此顺序为：

1. 重做银行与货运投资。
2. 扩展通行证用途。
3. 决定是否接入老周同伴。
4. 完成至少十天的静态经济模拟。
5. 加入官方关注并重新模拟。
6. 最后决定是否需要货运行情。

## 5. 下一阶段实施建议

### M1：修正资本基线

- 银行取消每天5%复利，改为每6天固定小额收益或无利息。
- 货运项目保持单次、三天结算、可重复。
- 普通项目净收益调到约25～30，好项目约45～50。
- 每轮强制一次考察，谈判保持可选。
- 删除当前只覆盖公共交锋的保险。

### M2：让官僚能力跨系统使用

- 保留公共事件延期一天。
- 保留交锋中的程序干预。
- 增加“调阅货运备案”，用通行证替代一次普通质量的项目考察。
- 增加“销掉巡查记录”，用通行证清除码头走私冷却。
- 三个用途全部消耗同一张通行证。

### M3：决定关系循环的第一版边界

- 若接受增加动态同伴：扩展老周支线并接入世界行动骰。
- 若暂不接受该工程范围：保持现状，不增加细碎被动收益。

### M4：暂停普通情报

- 停止为现有重复工作和交锋继续增加普通情报。
- 保留具名线索。
- 在布告栏／机会发现系统设计前，不把普通情报纳入平衡。

### M5：静态经济验证

暂时关闭公共交锋，模拟十天：

- 纯劳动。
- 劳动后投资。
- 警局与投资混合。
- 买公寓。
- 银行储蓄。

验证玩家是否会因当前钱、关系、投资和住所状态改变每日行动，而不是始终选择同一个最高工资工作。

### M6：加入官方关注

只有M1～M5成立后再实现四档官方关注。

### M7：重新评估货运行情

官方关注运行稳定后，再判断静态经济是否仍然缺乏时间变化。如果仍然需要，加入低迷／平稳／繁忙三档行情；否则继续延后，避免为变化而增加状态。

## 6. 验收标准

- 银行与投资具有清晰不同的风险和回报。
- 投资普通结果能够替代约一次普通工作，好结果能够替代约两次。
- 办案通行证至少有三个完全可预测、互相竞争的用途。
- 保险不再是只服务公共交锋的弱优惠券。
- 老周关系要么产生明确的同伴成长，要么不增加不直观的被动修正。
- 普通情报在拥有明确的“发现机会”系统前不继续膨胀。
- 暂时移除公共交锋后，玩家仍能进行至少十天有意义的城市资源选择。
- 官方关注加入后，走私形成高收益与暴露风险的清晰循环。
- 货运行情只有在能同时创造“适合工作”和“适合投资”的不同窗口时才实现。
