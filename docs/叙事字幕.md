# 叙事字幕：同一视觉语言的三种使用方式

`StoryCaptionDrawer` 是旁白、线绘剧场与立绘 Dialogue 的公共绘制入口。它只排字和绘制，不维护播放时钟、不消费输入、不持有剧情状态。人物气泡仍指向场景中的人物；黑幕 intertitle 仍属于换幕，不作为普通字幕变体。

| 用途 | 落点与身份 | 推进 |
|---|---|---|
| Narration，以及气泡系统中说话人为「世界」的旁白 | 最底部两侧 UI 之间；空隙不足时才贴操作栏上沿；无姓名 | 按配音/内容时间自动播放，不锁操作 |
| 线绘剧场字幕 | 恢复舞台下缘的无底字幕；姓名与正文 | 定时或点击推进按内容决定；不显示底部状态提示 |
| Dialogue / 立绘舞台台词 | 操作栏隐藏时贴近屏幕底部；较宽的半透明矩形底、姓名与正文 | 第一次点击补全文字，全文显示后点击进入下一句 |

三者共用思源宋体正文、半粗体姓名、暖白正文和居中换行。剧场不画任何底板、雾带或「自动播放」提示，恢复此前的电影字幕。世界 Narration 与 Dialogue 只画平整的半透明矩形底，不画柔边、装饰框或纸片。Narration 字号略小；Dialogue 的底更宽。Dialogue 播放时世界操作栏已隐藏，不再为隐藏的底栏预留高度，避免字幕悬空。尼尔姓名用暖金，普通人物用淡冷色；线绘剧场可沿用内容明确声明的姓名色。负片使用反向文字，世界字幕使用浅色半透明矩形底。对白不再使用独立纸框、悬挂名牌或逐句弹跳；心里话与旁白不署名。

两条世界旁白路径使用同一位置计算：读取 `HandPanelDrawer.BottomGap` 的真实两侧 UI 边界，字幕贴底并在中间折行；只有可用宽度不足时才紧贴操作栏上沿，不常驻抬到画面中部。有配音的 Narration 正在显示时，不叠出第二句「世界」气泡字幕；进入阻塞 Dialogue 或剧场时，上一段非阻塞旁白退场，避免旧旁白继续响而字幕已被新演出覆盖。

现有剧场和 Dialogue 共用右上角「跳过（ESC）」；跳过整段与点击推进当前句保持不同的含义。无字动作和定时剧场字幕继续自动播放；本次没有新增倍速、按住快进或自动对白功能。演出作者仍需选择合适的节奏与推进方式，不能把字画成一样就称为交互已经一致。

## Bubble（2026-10-16）

人物气泡正文由16调为18，姓名由14调为15。自动停留按 `clamp(1.6 + 字数 × 0.075, 2, 6)` 秒估算；显式停留和配音仍可延长，上一句保留0.6秒的短暂重叠。气泡只承载可错过的简短氛围与反应，不能承载必要说明。
