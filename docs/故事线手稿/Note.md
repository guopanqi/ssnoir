
## 莱恩的真相

他和尼尔冲突结束之后，一个中间人找到他，告诉他“夜莺愿意给你最后一笔钱，只要你离开她，也离开贝尔维尔”。这句话非常击中他的自尊，但他缺钱，而且弗兰克也已经明确不再替他收拾残局，于是他收钱，搭上一艘离港的货船/去外地做短工。他以为这是夜莺花钱赶他走。
真正策划第三封信的人需要的恰恰就是：
莱恩从城市里消失。

所以第三封信出现之后，所有人的解释都会自动变成：
“他发出死亡威胁以后逃了。”

实际上顺序完全相反：
莱恩离开贝尔维尔
→ 第三封信才出现
→ 首演夜事故
→ 他的消失反而成为他的罪证。

后面揭露也因此可以非常具体，而不需要谁突然站出来解释阴谋。第二章调查可以逐渐找到三块事实：莱恩房间里留下的货运/招工碎片；码头记录证明他在第三封信送达前已经离港（或者信里提到了他离开后才确定的演出安排）；最后再追到是谁替他付的钱或者安排的名额。做到第二步，尼尔已经知道“第三封信不是莱恩”；做到第三步，才开始知道“有人主动制造了莱恩的消失”。
这个结构还有一个好处：莱恩以后真的可以基本退出故事。尼尔继续调查，并不是因为莱恩跑回来要求洗清冤屈，而是因为**一个已经从所有人生活里消失的坏人，被方便地承担了一件他没有做过的事情。**这会让尼尔坚持追查显得更纯粹。

（现行[首演之夜.scm (line 675)](/Users/usr/Documents/play/ssnoir/UnityClient/Assets/Resources/Content/scenes/encounters/首演之夜.scm:675)仍有莱恩当晚被控制的叙述。选离城方案后，需要连同尾声一起调整，不能只修改调查对白。）

但是这会让游戏的选择的天平从 一个人承受他不该承受的罪名并付出严重的代价 和 自己和其他人（上层人士）的幸福最大化，转移到 一个消失的人承受他不该承受的罪名 和 自己和其他人（上层人士）的幸福最大化 的选择中，正义的分量会变弱。

事实上在最完整的游戏中，这个人承受他不该承受的罪名的时候，老街也承担这个罪名并因此引发全城的事件，拆迁，改造，毁灭，对玩家而言的选择要重得多，所以也许我们该保持现状，为最完整的故事内容服务。

**夜莺还需要一次主动选择，和一次真正的相互照顾。否则容易变成一个利用男人的女人**

目前夜莺有求助、隐瞒、带路、坚持演出，但后半段比较容易变成“尼尔负责解决，她负责相信他”。

让她在准备阶段提出一个具体要求会更好：保留某段演出、坚持谢幕、拒绝某种会毁掉现场效果的安保安排。她知道这会增加风险，却有自己的理由。尼尔也可以据此答应、劝阻或提出替代办法。人物冲突就进入了玩法。

但不能所有主动行为都指向她的野心，否则玩家很早就会把她读成一个利用男人的人。假平静里最好有一次她照顾尼尔的事，而且与调查无关。不是增加一场泛泛的吃饭，而是让玩家看见：**当尼尔暂时帮不了她时，她仍然愿意把时间给他。**

你括号里问彩排的“这是我的工作”要不要说，我建议这里删掉，或让尼尔说到一半停住。前面用它遮掩感情很合适；彩排如果终于拉近了距离，再完整重复一次，就把关系推回原处了。

彩排也不必重点证明她“唱得不够好”。可以让尼尔看见她怎样调整站位、停顿和目光，让同一段歌突然有了力量。这会把人物手稿里“不是天才歌手，却是出色表演者”的设定真正演出来。
