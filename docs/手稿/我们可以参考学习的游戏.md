- 动物迷城

%%- 明镜江湖行：朔风起
反面教材
这个游戏有点像武林群侠传，它的确有选择、有分配，但是行动就是堆属性，而且游戏的大部分意义最终还是落在战斗上，有点无聊。我想我唯一学到的东西就是它那个合同。有点类似于《动物迷城》里面那个给回报的任务一样。
这个游戏我认为仍然有借鉴的意义。它的很多借鉴是反面的，比如说钱完全不需要做出选择，队友的配置和玩法是重复的，整个文本对话是无聊的。一个是分句太多，另一个是根本不抓人。每天做的事情很快变成一种重复的流程，去A和B回复心情体力，在两个练习中选择目标需要的那个，需要稍微根据一些元素做一些权衡。每次到了市集，把所有东西都买了。和其他角色的互动感觉也很快变成为了亲密度而刷的一种疲惫的操作。
但是这个游戏有时候我仍然想玩下去。培养你的这个角色的能力，组合主角的招式。以及争取更多的同伴，这件事情是有趣的，是有目标感和成就感的。

推进好感，然后人物作为奖品，完成任务，然后获得奖励，这种模式让人厌倦。
