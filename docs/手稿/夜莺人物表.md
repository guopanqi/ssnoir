莱恩

剧院经理
他是一个老练的、体面的，从生意角度去看待一切的人。他看起来欣赏夜莺，也给了他机会，他知道这些小角色也有机会，他对于夜莺的爱和维护是一分投资，而且千方百计呈现在别人面前，要人家感恩他。穿得很好，对于有价值的人说话非常客气，对于没有价值的人就非常吝啬，在他这里非常合理，他喜欢别人对他具有价值，也努力在别人面前呈现自己的价值，公平，合理。他不是公司派来的恶人。他记得每个赞助人的名字，也记得每个演员的弱点。给她机会、帮她改口音、教她面对记者、让她穿对衣服、替她挡掉早期的丑闻。但在他心里，夜莺已经不只是一个人，而是一次必须成功的投资。

酒吧老板
夜莺过去的见证人，对于夜莺不愿意谈起，态度矛盾。他是夜莺旧生活的线索。四十多岁、很会算账、脾气不太好的人。他以前让夜莺在酒吧唱过，也许给过她第一份稳定工作；夜莺在最穷的时候，欠过他的酒钱、房钱，或者曾经睡在酒吧后面的储物间。他对夜莺的态度矛盾。

工会负责人
不是莱恩的朋友，而是曾经把莱恩留在队伍里的人。工会里不能只有一群吵闹、保守、反机器的男人。你需要一个真正有判断力的人，让工会既有道理，也有自己的阴影。


警察文员
他不是恶人，他只是比真相更相信秩序。他尊重主角的职业，也许还会说：你这种刚来的私人侦探，最好不要太快相信客户讲的故事。他甚至可以给主角一点不正式的帮助，例如确认莱恩有过醉酒闹事记录、确认工会最近确实在组织集会。但他始终有自己的底线：秩序优先于事实。可当首演夜真的爆发冲突时，他会选择最容易被写进报告、最容易被市政厅接受的版本：旧港失控，警方依法处置，剧院遭受威胁，城市必须尽快恢复秩序。后面莱恩被“控制起来”、玩家无法见到他，就可以由这个警探来负责执行。他不需要亲口承认谋杀或阴谋。他只要不断说：这是现在最稳妥的处理。你拿不出别的证据。你也不希望事情再死人。

人物的命运不必总是发生的，不必所有事情都是按照日程表一样发生的，我们可以说乔的受伤发生在第一章，但在第一章里面可以是玩家驱动推进的，如果玩家不推进或者没有推进到乔的受伤事件，到了第二章这条线就终止了，乔在某一天发生了受伤，成为残疾状态，进入第二章。

弗兰克我之前想把他加上就是第一小节交割的结尾追逐你差点追上了，一辆摩托车过来你闪了一下，那人（莱恩）趁机逃走了，你只有一个红色“金”牌香烟的线索，骑摩托车的人正面你看不清闪得你眼睛疼，但远去的背影，你见到弗兰克似曾相识，这样设计可以吗？

货船抢修到了最后，弗兰克感谢你，你有些眼熟，但没能确认，弗兰克是工人事实上的组织者，机警原滑，他为了他们的群体最大利益兜兜转转 无视规则和秩序，他是这样的一个人

林研究员我想把他设计为一个技术主义者，你能感觉到他的热诚、甚至对于技术进步的狂热，也能感觉到他对于机器取代人的现实问题缺乏了解，从技术主义的角度来说，历史的车轮滚滚向前，人力无法阻挡，从更宏大的角度来说，当下人们的幸福相比较于人类的进步而言未必更重要，因为某种意义上不是分配，不是和平和善良让人们今天的出生率死亡率治愈率下降，而是技术和进步。技术主义者关心技术，关心抽象，往往忽略现实和真实的人。
注意，我并不是想要说他是错误的，我希望玩家看到自动化替代人力它好的一面，同时感受到有人被抛弃，有人坠入深渊，苦难无时无刻不在发生。我并不想林研究员成为一个反面角色，他是一个有原则的，有思想的，一个善良，非常聪明，有创造力，热爱工作，也乐于帮助你的人，但是他的人生哲学是他的出发点。

记者代表着对于真相的探索，对他而言真相就是最重要的，无论它会产生什么样的后果，无论如何，这是他的哲学的支点。相比而言，对市长而言真相不重要，妥协是一种方法，所有人都稳定，经济也能继续发展最重要，这种平衡最重要，也可以说到了最后对于市长来说其实莱恩是不是威胁和行凶者一点都不重要，导致的结果才重要，选票是重要的。

这是我想的人物他们自己的哲学支点，请你看看他们的故事线情节会有怎么样的变化

这个地方我还想到的一点是记者这个角色，因为如果我我在想他在前面可能对我们是恶意的，因为你作为一个侦探，你作为一个这种为有钱人拿钱办事的这种职业，你穿着这种戴着帽子穿着西装和码头的人格格不入，其实人们是会排斥你的。这个记者我觉得他的立场其实是可以说他是有一点人文关怀，但是怎么说呢？因为他如果我们表现他纯粹是一种人文关怀，很难让玩家在第一章去就是就是其实你在玩家在做事情的时候，他一定认为自己是正义的。是有人在勒索，所以说这些事情。所以说这个记者我觉得可以表现出一些，就是对事实不怎么了解，但是就有点咄咄逼人，或者说对你很挑剔，或者说拿你身上的一些，就是有点小题大做吧，或者说他根本对事情很多事情都不了解，就匆匆下一些定论。其实到了后面我们可能说这是他比较年轻的这个一体两面，这个人就是有一腔热血，他有时候头脑也不那么成熟。在在拿钱办事和工作，像你这种消除麻烦的人里面，也并不都是坏的，像那些人里面也并不都是好的，对吧？像弗兰克或者什么这种人，我们就能看得出来，在游戏中，这种势力的复杂性。但这个记者可能对他来说，他是一个，就说像一个大学生一样冲动的，但是有可能就是在第二章，由于他的这种冲动和简单，有机会指引我们去揭开真相。我觉得他应该是这样一个行为，第一章他应该是令人厌恶，不然的话，我觉得一个同情弱者，一个民主的人。这种年轻的知识分子，是很难让玩家去确信自己的立场是正义的。我认为玩家作为主角的身份，当他在游玩的时候，无论在第一章还是第二章，他始终肯定会认为自己是正义的一方。当然到了最后，他会发现正义没那么简单。

像弗兰克这样的人，你说他是工会领袖，他前面有一些不是，他是工头和组织者，前面有一些就是为了这种群体的利益，然后等等。但实际上他作为一种组织者，有领袖气质的人，也许我们有机会看到他的另一面，就是他其实对于这些地方的，比如说弱者，受伤的人非常的照顾，他会为他们去争取权益，虽然可能是一些非法的手段，为他们改善生活。我觉得这样他才会得到这些人的拥护。你说他是善良还是邪恶？我不这么看，因为这就是他哲学的支点，只不过，你这种身边人，或者说这种地域性的人团结起来的，他有这样一种，但他也许还有一些其他的，比如说享受。有凝聚力，也享受权力。但是我觉得这是每一个身为领袖的人都会身上有的东西。
