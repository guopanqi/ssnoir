**立即**：
最基础的模式，投入骰子 → 判定好坏 → 立即获得不同数量的钱，或者承受金钱、压力的损失

**接线**:
动作结构不变，只是改变结果连到哪些存量上。送外卖回精力，是把产出接回了驱动动作本身的资源，形成一个小正反馈；氢核之门和塞拉维亚的免费物资，是把"金钱"这个中间媒介从回路里拆掉了，劳动直接兑换成物。这类设计模式仍然是立即结算，新鲜感来自奖励组合符合劳动内容。它很重要，因为它让工作有个性，但它还没有改变动作的基本结构。

- 钱多，但消耗身体。（高风险，或者固定高消耗工作）示例：CS2 废料拆卸
- 钱少，但恢复精力。（低风险，或者有额外回报，外快）示例：CS1 面馆
- 不给钱，但增加关系。
- 失败仍给钱，却增加怀疑。

- 效果组合，根据好、中、坏结果的不同而改变回报的组合，示例： CS1 面馆。或者两个动作之间，能够获得的潜在存量不同。
- 寄生目标，其实也是回报组合的一种，但是具有特别的叙事意义。比如打扫卫生的同时侦查消息。给旧码头送货，同时绘制仓库路线。替警局誊写卷宗，同时寻找被篡改的案件记录。或者互动的同时推进和某人的关系。让玩家感觉自己是在**利用职业身份调查**，而不是在地图上点击一个名为“调查”的按钮。活侠传中门派生活中的动作差异在于，推进不同属性存量，也推进不同的人物关系存量，同时也可能触发不同的涌现事件。

- 使用劳动而不是金钱去兑换物资（CS2奥利维拉集体公社，通过劳动而非金钱获取物资，也是规则制度的一种。CS2氢核之门的荒野搜集其实也是这一种，但因为压力很大，感情叙事色彩截然不同，有一种荒凉求生的感觉）
- 获得资源，同时消耗机会。在这个概念下，次数隐喻着机会，市场需求，使用寿命（例如CS2中的有限使用次数的组装机）无限工作默认世界是静止的：无论玩家搬了一百次货，码头永远还有同样多的货。机会生态则意味着：赌客会被赢光，一片废墟会被搜空，机器会耗损，它可以用“剩余次数”表达，但更好的形式是让机会状态发生质变：富裕赌桌 → 普通赌桌 → 警觉赌桌 → 封禁  ，未搜索仓库 → 零散资源 → 危险深层 → 坍塌  ，陌生街区 → 可行骗 → 开始传言 → 已被认出，这样有限次数不再像人为限制，而是环境对玩家行为的记忆。也可以表达通道本身的稀缺。稀缺的不是材料，是加工能力。

- 使用人情进行交易（也许是一种新的？通过帮忙获得人情，通过消耗人情来获得帮助，我觉得适合）
- 活侠传中动作产生效果时，可能产生一些涌现事件。

**积累**：
一种很基础的模式，动作不立即产生效果，而是产生一种积累，在指定容量触发产生效果。标量形式常常被视为进度，进展。它把单次判定的方差**存起来**，延后到批次结束一次性兑现。玩家的紧张感因此从"这把中不中"转移到"这一批还救不救得回来"，从而大大消减了单次判定的不可控性。

**载体（carrier）**:
动作产生积累，但积累的东西本身换了形态。标量进度→带质量标签的组成（工坊、你的假币）→空间性的拼装（CS1建家，本质是把材料放置进一个持久的图样里）→图结构中的位置（Overseer的工作阶梯，成败不改变数值而是让你在一条职位链上升降，而且降职不是"更少的成功"，是另一段内容）。

- 带质量标签的组成，一些例子：两半组成的机械零件。三段组成的演出：排练、布景、宣传。一剂药：原料纯度、配比、封装。一份伪造证据：来源、物证、证词。
- 积累是图结构中的位置、状态机，比如职场轨迹，层级的升职，降职，位置改变后动作自身被替换，干得好换一份更好的工作，干得差退回去，动作不是风险收益改变，而是全部替换。故事上隐喻着维持工作，职业阶层的流动，工作的疲惫与积累，以及“越战越勇”或“恶性循环”的现实感。
- Citizen Sleeper 1 的职业阶梯是一个例子，但可以更有意思。比如一个线人的信任状态：你可以把他从"警惕"推向"合作"，也可以不小心推向"背叛"。每次动作不是在一个线性进度上移动，而是在一个有多个状态的网络里转移。结果的好坏决定了你向哪个相邻状态移动。这跟进度时钟的核心区别在于：路径是非线性的，可能有分叉和死路。
- 积累是持久的空间性的图纸，可以是建设一个家（材料+劳动），也可以是用家具放入家里，每个家具为他们增加一个独特的动作（或者效果），打造一个家，积累财产在故事和情感上天然隐喻着塑造，扎根，安全感

**制度/规则/心理模型（institution）**：
包裹动作的交换规则和社会语义变了，不再是最普遍的人们认为理所当然的付出就会获得回报。厨房那个工作是最典型的——成功消耗次数、失败换来同情，其实是把工资制度换成了施舍制度，成败的效价被虚构重新映射了。出老千是把赌博的风险结构单方面篡改。塞拉维亚的劳动自给也属于这条轴：同一套动作语法嵌进不同的经济制度里，表达出完全不同的社会关系。还有霍尔姆岩那台限次机器——稀缺性不挂在你的精力上，而挂在生产资料本身上，这也是制度层面的移动。
**经济框架的变化。** 标准经济框架是雇佣劳动：付出时间，获得钱。但 Citizen Sleeper 里有好几种完全不同的经济关系。Hydrogen Gate 的搜集是直接从环境中提取，没有交换对象。Seravía 是公社式的自给自足——劳动直接变成食物，没有货币中介。赌博是投机——你投入的和获得的之间不是劳动关系，而是概率关系。出老千又加了一层：你在操纵那个概率关系本身。那个机器是转化——材料A变成材料B，你付出的不是劳动而是原料加上有限的使用机会。这些经济框架的变化是很重要的，因为它们改变了玩家对动作的**心理模型**。当你在"工作"的时候，心态是效率最大化；当你在"赌博"的时候，心态是风险管理；当你在"搜集"的时候，心态是探索和发现；当你在"共同劳动"的时候，心态是社区参与。同样的骰子放置动作，因为经济框架不同，感受完全不同。

伤害分配，而不是成功失败。某些危机必然发生，玩家不能把事故时钟清零，只能决定伤害落在哪里：它比“填满成功时钟赶在失败时钟之前”更能产生真正的选择，因为问题不是能否完美解决，而是**谁来支付代价**。

玩家反复使用同一种办法，世界会学习。每种手法拥有一个“熟悉度”或“暴露度”。这不仅防止最优动作被重复点击，也让城市显得会回应玩家。

成功消耗需求，失败保留市场

**共享/竞争资源池。** 多个动作节点从同一个有限池子里取资源，彼此挤压。这不是一个新的时钟模式，而是动作之间的关系模式。比如一个地下工坊同时可以做假币和伪造文件，但它们共享同一套工具和材料——你把资源投入一个就减少了另一个的产能。这创造了一种内部的优先级博弈。Citizen Sleeper 里其实已经有这种张力（你的骰子是有限的，分配给不同动作就是竞争），但如果把这个逻辑下沉到具体的叙事节点内部，会更有味道。

**磨损即品质漂移。** 霍尔姆岩那种有使用次数的机器，归零时通常是"坏了"。更有意思的是归零后**功能改变**而不是消失：磨损的印版仍然能印，但品质分布整体下移。于是同一个动作在游戏后期自动变成一个更糟的动作，不需要任何叙事介入。

**强制动作（来自苏丹的游戏）。** 苏丹的游戏最有力的结构是：每个周期有一张卡**命令**你必须做某类事，做不到就死。设计乐趣全在"用最小代价满足字面要求"。Citizen Sleeper 的时钟只施压，不下命令。如果 sincity 每章有一个必须消耗一个行动去满足的外部指令——比如"周五之前给我找一个人顶罪"——而满足方式开放，那么道德选择就被转换成了成本优化问题。而**最便宜的满足方式通常是最坏的那个**，这就是主角堕落的机制化表达。我认为这是你能从苏丹的游戏里抢过来的最值钱的一件东西。

**带区间的时钟。** 几乎所有时钟都是单调的：填满就触发。但可以做一个必须**保持在中间**的时钟——热度太低没生意，太高被抓。不同动作把它往两个方向推。这是我能想到的、和 noir 契合度最高的新原语，因为它把"你不能停手也不能太成功"直接编码进了资源结构里，而这正是黑色电影主角的处境。

**对抗时钟 / 拉锯。** 两侧是区域，可以推、拉 你和另一个力量各自填同一个时钟，但方向相反。比如审讯一个人：你的好结果推进他的松口，坏结果让他加固防线。或者更微妙地，你们填的是同一个时钟但在争夺"颜色"——最终谁占的比例多决定结果。这跟工坊的质量时钟很像，但差异在于坏的那一面不是你自己的失误，而是一个对手在主动推。在 noir 的语境里，这很适合谈判、对峙、或者试图说服某人的场景。

倒计时，衰变。

**副产品 / 废料。** 工坊模式的另一个变体：坏的结果不仅降低质量，还产生一个副产品或风险。制造假币时，坏的工作不只是让假币质量差，还会产生可辨认的废料或留下证据——这变成了一个独立的资源（或者说负资源），可能在后续引发麻烦。这让动作的结果从一维（产出多少）变成了二维（产出多少 + 麻烦多少），玩家需要在"继续做还是及时收手"之间做一个有意思的判断。

**级联 / 供应链。** 一个时钟的产出成为下一个时钟的输入质量。你先做原材料（时钟1的质量决定原材料品质），然后用原材料做成品（时钟2的结果叠加在原材料品质上）。这创造了一种传递性的紧张——前面的失误会在后面被放大。在 sincity 的框架里，这可以表达一种多步骤的犯罪计划：先搞到假身份，再用假身份去做另一件事，每一步的质量都影响最终结果。不过这个可能更适合做一个 arc 级别的长线结构，而不是单个动作节点。

贪婪区间，【none】【good】【贪婪】，贪婪区间需要承担额外的代价，假设一个8格的时钟。前4格是绿色（安全区），后4格是红色（贪婪区）。 只要时钟达到4格，玩家随时可以**主动选择“结算”**，拿走基础奖励。玩家可以选择继续投入动作。填入红色区域时，如果掷出好结果，最终奖励成倍增加。

【掩盖与疑云时钟】（Cover-up / Suspicion Engine）—— 适用于作案、盗窃、毁灭证据。这是一个双向挤压的时钟。你必须填满 4 格的“偷窃/清理进度”，但每次掷骰如果出现不良结果，会在同一个时钟上填充“怀疑度（红格）”。如果进度先满，你成功带走物品，但红格的多少决定了后续几天警察/追兵的搜索力度。如果红格先被填满，说明你在未完成前就被当场抓获。

【戒断与抵押时钟】（Addiction / Collateral Clock）—— 适用于借高利贷、使用禁药、黑市交易
执行这个动作可以**无条件获得极高收益**（比如立刻得到大笔钱或强力 Buff），但会在时钟上填入 1 格“借债/隐患”。你可以在日常工作中消耗骰子去“清空”这个时钟（还债/解毒）。但如果你放任不管，这个时钟每过一天会**自动增长 1 格**。当它填满时，会触发灾难事件（黑帮找上门/身体器官衰竭）。
**叙事效果：** 饮鸩止渴的快感与悬在头顶的达摩克利斯之剑。将“短期的爽感”与“长期的慢性压迫”打包成一个动作。

**双半结算的其他拓扑。** 工坊是"一个物件、两半、各掷一次"。同样的骨架可以长成：三半取中位数（允许扔掉最差的一次，这让"再干一天"成为一个有意义的选择）；两半由你和一个搭档各掷一次而你看不见对方的结果（不写一句对话就做出了信任机制）；或者**第二半的难度由第一半的结果决定**——开局崩了，后面更难救。最后这个能在一次生产内部造出"这活正在变坏"的弧线，成本几乎为零。

桌面RPG（如《Blades in the Dark》，这也是《Citizen Sleeper》借用“进度时钟”机制的来源）和叙事驱动游戏中最核心的设计美学：**将抽象的数值（如骰子点数、进度条）赋予具体的“隐喻（Metaphor）”和“概念（Concept）”。**
**用极简的机制原语（骰子、进度时钟、资源池），通过改变其内部逻辑和叙事隐喻，表达完全不同的生活状态和情感体验。**

传统的进度时钟代表的是“时间”或“完成度”（满了就做完了），而你的设计将其转换成了**“配比”或“质量”（满了代表产品定型，里面好坏的比例决定了最终的产出）。
叙事隐喻极强： 这完美契合了“造假”的现实心理——你不可能一点手艺都没有（那叫印废纸），也不可能每次都完美。假币总能印出来，但里面有多少能骗过验钞机、有多少只能当废纸，取决于你这次操作的瑕疵积累了多少。这种设计将“失败”从“阻碍进度”变成了“引入杂质”。失败不再是让你停滞不前，而是让你的产物变得更加“有风险”或“低劣”。

1. **【目标反转：同情与乞讨】（如远枢站厨房）**
        - **概念：** 成功不等于奖励，失败不等于惩罚。
    - **机制：** 高点数（成功）消耗可用次数且收益平平（因为你表现得太能干了，不需要施舍）；低点数（失败）反而因为显得可怜而获得保底收益。
    - **本质：** 将“能力测试”变成了“社会阶层测试”。
2. **【阶梯与滑坡：升职与降职】（如造船厂工作）**
    - **概念：** 动作的结果不是产出资源，而是改变你所处的“环境”。
    - **机制：** 一系列相连的时钟。好结果填满当前时钟，把你推向下一个更高级的时钟（动作解锁）；坏结果清空时钟，把你踢回上一个时钟。
    - **本质：** 用进度时钟来模拟社会阶层的流动或信任度的攀升。
3. **【经济体隔离：金钱社会 vs 劳作公社】（如塞拉维亚避难所）**
    - **概念：** 游戏世界中存在两套完全不兼容的经济法则。
    - **机制：** 外部世界是资本主义，需要“动作->换钱->买食物”；避难所是公社，是“动作->直接产出食物/安全感”。
    - **本质：** 规则本身的切换就是一种强烈的叙事表达。

### 关于 clock 的想法 

时钟不是基础概念，它是一种记法（notation）。基础概念是"有容量的状态变量"——一个存量，带上界，由动作分次填充。时钟、0到5的数字、五个点、切成扇形的圆，都是同一个状态结构的不同渲染。

当状态本身从标量变成带标签的组成时，任何表示法都必须扩容来携带这些标签。数字表示法要变成"2好1坏"，圆形表示法要上颜色。表示的信息量必须不小于状态的信息量。所以真正发生变化的地方在状态结构层——标量、带类型标签的multiset、空间排布、图上的位置，这是我说的"载体"的准确含义。

时钟本身就不是一个准确的名词，它更更可能是人们需要一个直观的事物或者符号来描述暗夜刀锋中这样的一个东西——对一个圆进行任意切分，然后用它来描述过程。它最终指的是一个有容量的状态变量。

GEMINI说，在游戏设计中，人们经常把 UI / 表现层的符号与底层的数据结构混为一谈。约翰·哈珀（John Harper）在《暗夜刀锋》（Blades in the Dark）中创造性地把“切片圆形”引入 TTRPG，是因为圆盘在视觉上给人类一种极其直观的**“时间正在被吃掉/过程正在被填满”的心理暗示（界限清晰），还有一些特点包括离散，可以任意切割。但从系统设计（System Design）的角度来看，这完全是表现层（Presentation Layer）对数据层（Data Layer）的隐喻，clock只是数据的一种记号方法。
