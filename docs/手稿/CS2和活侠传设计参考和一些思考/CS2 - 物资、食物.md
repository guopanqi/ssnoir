《Citizen Sleeper 2》把金钱转化成了安全时间，又把能力成长转化成了时间效率。这比“物资是一种消耗品”更接近它真正巧妙的地方。

食物在城市中是一种承受压力的缓冲，这个缓冲代价较低（4食物12金币）。物资在外出合同中是安全回合的缓冲，这个缓冲代价较高（每个安全回合15金币，最多5物资）。

旅途结构的实质是：前往下一个地点有燃料的代价，也会花费更多时间（低效的），
再加上我们预期未来是有危险的，我们会囤积来应对未来的危险，我们会尽量在前往下一个地点前，尽量利用时间，清理掉这里的事情
旅途结构产生的决策像是八角巷的预演，一种重复和发展，

```

│  │      │        └─ 买「弯道薯条 Bends Fry」7 cryo（廉价食物）

│  │                   （人物线在浮渣站 Flotsam 继续，需 HazNav 升级）

│  ├─ 卖废料（Engineer）／打动经纪人（Interface）
│  │   └─ 进度条

   ├─ 搜索厂区（Intuit）／搬运物料（Endure）
   │   └─ 积累【可信供应商 Trusted Supplier】进度条

      ├─ 数据拆弹班（Interface，10/7 cryo）
      ├─ 废料场轮班（Engineer，12 cryo，Dangerous 判定，会累压力）
      └─ 出售原始废料（1 废料 ≈ 16 cryo）
```
