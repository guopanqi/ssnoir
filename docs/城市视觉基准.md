# 城市视觉基准

当前基准以已选 Three.js 夜城的阅读层级为目标：蓝灰建筑与暗面构成连续的城市空间，象牙白地标和少量暖光承担注意力。正式实现由 Unity 的共享资产维护；Three.js 是视觉参考，不是生产依赖。

## 资产与作用域

唯一映射入口为 `UnityClient/Assets/Resources/City/WorldPalette.asset`。模型声明角色，导入器按角色绑定共享材质；CityBox 重建不覆盖 Unity Shader 参数。调整材质后不用重新导出几何。

| 职责 | 正式资产 | 范围 |
|---|---|---|
| 城市建筑外墙 | `Style/M_建筑*.mat` | 所有使用这些角色的建筑；保留街区之间的小幅色差 |
| 城市地面、郊野、驳岸 | `Style/M_城市地面.mat`、`M_郊野.mat`、`M_驳岸.mat` | 全城与地点共同可见的基础设施 |
| 普通填充建筑及设施线 | `Style/次线.mat` | always 描线；蓝灰、低亮度，不能抢过地点主线 |
| 地点真实模型描线 | `Style/主线.mat`、`结构线.mat`及装饰线 | 聚焦地点；其主次关系来自源模型的 tone 与 line_palette |
| 地标世界代理主线 | `Style/地标远景线.mat` | `描线_world_*` 中的主线，使用 `WorldLandmarkLine` 单独绑定；颜色不从近景主线联动 |
| 河面 | `Assets/Materials/RiverFlowUV.mat` | WorldPalette 的“河面”角色，输入导出名 RiverFlowUV；世界与地点使用同一 Shader |
| 水面实体短线 | `Style/水面短线.mat` | 源模型声明的装饰几何；与程序波纹不同，不能当作河面材质替代品 |

地标世界代理仍遵循 CityOutlineState 的可见性：世界显示 world + always，聚焦显示对应 focus + always。装饰色线保留自己的角色；本轮只分离代理主线，不统一抹掉其装饰色。

## 当前调节原则

- 外墙保留受光明暗，略提蓝灰底色并降低蓝色饱和度；不通过自发光把建筑照平。
- 地面在暗部应可读，仍比建筑低一个层级。世界环境补光独立于地点灯光，不能靠世界曝光修正所有地点。
- 通用地点主线采用略冷的白色，不能继承夜城地标的暖白色。金色只用于模型明确声明的金色装饰角色。
- 普通建筑线只帮助读结构；地标远景线负责识别地点。调后者不会改变地点的主线资产。
- 河面采用连续深蓝灰底色、稀疏低强度波纹与缓慢漂移。现有 UV Shader 保留沿河转弯的流向，使用屏幕覆盖抗锯齿与距离衰减：近景能看到笔触，远景降低波线强度。参数写在同一 .mat 中，不按场景或平台替换材质。
- 车流、船尾波光与河面波纹各自有职责；波纹不能成为第二套亮点噪声。
- 世界 Bloom、雾、颗粒只在世界作用域启用，地点继续使用正式地点环境。地标主线材质独立，但 Bloom 仍作用于所有超过阈值的亮部，并非地标专用。

## 校准与验证

至少同时观察世界与一个地点近景；涉及河流时包含码头。共享角色调整后再观察晚宴，避免把地点特有的象牙、金色与抛光材质强行压成城市外墙。

使用 `python3 tools/citybox-unity-preview/preview.py --verify-play --scene 世界 --scene 码头 --scene 晚宴` 获取正式共享资源的 Editor/Play 证据。截图是固定机位，不能替代手机性能或动态波纹的人工观看。

本轮截图保留在 `city-box/prefabs/review/世界/Unity夜城迁移/视觉基准03/`。画面参数仍是待用户评估的基准，不要求 Unity 与 Three.js 逐像素相同。

## 世界环境校准 04

仅调整 WorldPalette 的 Overview / Night，不更换共享材质：环境补光略提高，方向补光从 0.18 调至 0.32；主要路灯的地面光池宽度从 72 调至 96、中心强度从 0.13 降至 0.10。灯的实际位置和点光强度保持原样。

高度雾密度 0.00065、垂直衰减 0.012、远距离薄雾 0.00022；雾的低层蓝灰比高层略亮。让道路空隙与远处街区连续，但不以整体曝光提亮地标。曝光、Bloom、颗粒和动态元素参数保持不变。

这些参数只在世界作用域生效。固定世界与码头截图用于检查边界；不把固定截图称为镜头过渡动画或动态雾的验证。

## 探索运镜：直接靠近

`SSNoirCameraManager.ExplorationPath` 提供两条路径，普通玩家探索默认选择 `DirectApproach`，原来的 `AuthoredArc` 完整保留。该选择是当前开发实验入口，未新增存档设置或 UI。

- orbit 地点：以当前镜头所在的一侧决定到达方位；预设机位提供取景半径与俯角，俯角遵守地点 orbit 限制。看向正式 orbit pivot，不修改模型机位或 pivot。
- 运动：位置直线插值并轻微抬升（路程的 4%），注视点同步移动；五次 smootherstep 平缓起停，按路程取 0.9–1.5 秒。FOV 与裁剪面延续既有插值，途中拖动与重定向仍使用现有输入和清理机制。
- 返回世界：使用保留的世界 pan 机位作为终点，采用同一直接路径。地点内拖动不会要求返回时绕回地点预设方位。
- pan 地点、静态地点、剧情与过场：沿用旧路径和预设机位；新路径仅由普通探索入口选择，不改变剧情 BeginFocusTravel 调用的默认行为。
- “减少镜头动画”仍优先使用切换与溶解；要试运动路径需关闭该选项。切回旧实验方式可将 CameraManager.ExplorationPath 设置为 AuthoredArc。

此次完成 Unity C# 编译（0 错误，4 个既有 JSON 声明字段警告），未操作 Unity 做交互测试。人工观察：从世界点击两个不同方位的 orbit 地点、拖动后返回、运动途中切换目标，再检查 pan 地点；重点看是否突然旋转或结束跳位。

## 两岸灯光与建筑分离度校准 05

路灯的岸别按发布河道的最近线段判断，不用固定 x 分界或屏幕左右。河道北→南，西侧为发达岸，东侧为较贫穷岸。主要立面点光与大光池最多 14 盏：西岸 10 盏，东岸沿河 4 盏；候选间距至少 100 米，选择使用固定种子。东岸沿河范围暂为距中心线 180 米，参数是中心线距离，不冒充离岸距离。候选不足时不向内陆补灯。

普通灯晕与小光池按两岸降低强度（西岸 0.45，东岸 0.12），颜色改为低饱和的暖白／琥珀。大光池保留柔边，中心强度 0.085；不增加真实灯数量。

地标远景主线独立提高 HDR 亮度至约 1.65 倍，世界 BloomScatter 从 0.4 提至 0.75；近景冷白主线与金色装饰不受远景材质调整影响。

为恢复建筑与地面的分离，回收校准04过强的均匀补光与蓝雾，增强主光／补光比例；颗粒由 0.018 降至 0.012，仍保留复古质感。不要靠进一步加亮所有蓝线来补偿平坦的照明。

## 材质色阶与冷色克制校准 06

上一轮仅调整照明仍不能解决“蓝色糊成一片”：街区底座、城市地面与建筑的蓝色明度带过于接近。本轮直接调整正式共享材质，近景与远景采用同一基准。

- 城市地面与街区底座的 sRGB 色值分别为 (0.055, 0.065, 0.080) 和 (0.060, 0.070, 0.085)，比建筑低一个层级，保留道路负空间。
- 各街区建筑保留自己的明度，颜色向其均值收拢55%，保留45%的原色差；减少蓝色占比，不把所有建筑变成同一颜色。
- 普通填充／设施次线调至 (0.15, 0.18, 0.23)，降低远景结构网的存在感。近景主线与地标独立远景线不在本轮减弱范围内。
- 世界主光颜色由硬编码蓝色提升为 Overview.KeyColor 的冷白 (0.83, 0.86, 0.91)，强度2.25；环境色更中性，仍有冷暖对比。
- 颗粒保持0.012，地标辉光、两岸灯光分布和河面材质保持上轮设置。检验材质层次是否能在保留颗粒时清楚阅读。

共享材质调整需要同时检查码头近景；不要求每个地点照明都与世界保持相同亮度。
