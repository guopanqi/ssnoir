# 原语扩展提案

> 现有原语集:**地点、动作(roll/instant/observe)、钟表、骰子、单位闭包、
> 规则(turn-rule/define-rule)**,加上物品、势力关系、对话演出
> (play-dialogue!/banter!/spotlight!)。它们的共性:可组合、可读、有 UI 形态。
> 本文提案新原语,按表达目标分三组;每条给出:定义、它解锁的结构、
> 实现成本(内容层糖 / 引擎)。文末 §4 是纪律规则——原语通胀比原语匮乏更危险。

## 1. 人物表达类

### 1.1 人物(persona)——最重要的一个

**定义**:具名 NPC 作为一等对象:好感/心境轨道、记忆 flag 集、
**出场表**(今天在哪:白天市集/晚上酒馆)、话题集(随剧情/记忆开关)。
现在这些散落在各地点闭包里(laozhou-favor、夜莺 scene-flags),
每个新人物都要手搓一遍。

**解锁的结构**:
- **出场轮换**:人物在地点间移动,城市自动产生"今晚她在不在"的牵挂;
- **人心钟**(结构库 §4.3)的通用实现:交锋自动读在场人物、写回好感;
- **人物支线的树根**:CS2 式支线(跟随一个人看世界的一角)需要的
  全部状态,一处声明。

**成本**:内容层糖(闭包模板 + 存档约定)即可起步;出场表进 UI 需少量引擎。

### 1.2 印记(mark)

**定义**:挂在人、地点、关系上的**定性持久状态**——"脸上带伤"
"被收账人记住的脸""欠码头一个人情""酒馆记得你那晚的挺身"。
自动暴露为两样东西:相关判定的可见 modifier + 文案钩子(描述/台词分支)。

**解锁的结构**:
- **长后果叙事**:交锋的结果不再只是数值增减,而是留下一个词,
  这个词在两周后的另一个场景开口说话;
- **伤痕系统**:健康掉 1 是数字,"右手缠着绷带,力量判定 −1,
  她替你换了药"是戏;
- **这座城记得你**:地点印记让重访产生历史感。

**成本**:内容层糖(全局印记表 + modifier 约定);
文案钩子靠各场景自查印记,无引擎改动。

### 1.3 台词触发器(commentary)

**定义**:注册式旁白规则——"当 X 发生(交锋失败/挣到大钱/她在场时
你喝醉),在场人物说一句"。引擎已有 `play-banter!`(非阻塞气泡),
缺的只是一张事件→台词的注册表。

**解锁的结构**:**反应式人物在场感**——人物不再只在剧情拍子里活着,
而是对你的日常做出评论。人物表达成本最低、回报最高的一项。

**成本**:内容层糖。

### 1.4 对话内选择(choice-in-dialogue)

**定义**:`play-dialogue!` 目前是线性放映;加一个选择行原语
(2–3 个短选项,可带 req/印记门槛),选完继续。

**解锁的结构**:**场景级扮演**——幕间场景里"留下/让她走"这类选择
不必再做成世界节点,对话自己会呼吸;印记门槛选项
("你右手有伤,这句硬话说出来没分量")是人物表达和后果系统的交点。

**成本**:引擎(对话 UI 加选择态)。是本组唯一必须动 C# 的,也值得。

## 2. 交锋描绘类

### 2.1 意图(telegraph)

**定义**:交锋单位每回合亮出下一步——"他下回合要掀桌""打手二
在摸口袋"。一行文本 + 可选的对应反制动词。

**解锁的结构**:
- **反制戏**:Into the Breach 式的可读回合戏剧——玩家不是在刷进度条,
  而是在回应一个正在动的人;
- 与"赌注可读"原则在微观层面同构:宏观可读账单,微观可读来招。

**成本**:内容层约定(单位闭包渲染一行意图,turn-rule 兑现)。零引擎。

### 2.2 提案(offer)

**定义**:一等"条款对象":谁提的、内容(价格/条件/期限)、
当前状态;动词可以抬价、压价、加条件;**"接受"永远可用**,
接受即按当前条款结算。

**解锁的结构**:
- **谱系结局**(结构库 §2.3)的原生实现——谈判不再是填钟,
  而是围着一张明码标价的桌子博弈;
- **竞拍**:两个提案对象互相竞价;
- 黑色电影的本命:noir 的每场对话本质上都是一次报价。

**成本**:内容层糖(闭包 + 渲染为带备注的节点);UI 无需新形态。

### 2.3 场景状态(stage)

**定义**:交锋/场景的**环境条件集**——雨、深夜、人群、灯光——
每个条件 = 一个可见 modifier + 一组文案变体钩子。

**解锁的结构**:**氛围的系统化**:雨不再只是文案,它让追逐更难、
让枪声更闷、让"淋透的你"带着印记进下一场。noir 的天气终于有机械身体。

**成本**:内容层约定起步(条件表 + modifier);天气跨日流转可后补。

### 2.4 命名骰(story die)

**定义**:带名字和来源的临时骰——"她给你的骰子""喝了酒的骰子"。
可附一条小规则(用在故事动作上 +1;失败时有专属文案)。

**解锁的结构**:
- **把叙事塞进核心资源**:骰子是这个游戏的心跳,一颗叫"她的指望"
  的骰子躺在骰池里,是任何状态卡都给不了的表达;
- **礼物/负担结构**:人物给你骰子(信任)、拿走骰子(宿醉、伤)。

**成本**:引擎(ActorState 的骰子目前是 int 列表,需扩展为带标签对象)。
表达力/成本比很高,但排在对话选择之后。

### 2.5 框架场景(frame)

**定义**:以**另一个角色**进入一段封闭交锋/场景(她的属性、她的骰子),
结束后回到主角上下文。

**解锁的结构**:**可玩回忆**——已在计划中的"扮演夜莺的过去"依赖它;
未来任何支线人物的关键往事都可复用。

**成本**:引擎(TeamState 客座 actor + 存档边界)。一次投入,长期复用。

## 3. 城市叙事类

### 3.1 人情账本(ledger)

**定义**:承诺/欠情作为一等对象:谁欠谁、内容、到期(可选)、
见证人。兑现加关系与印记,违约扣得更重。UI 上是一页可翻的账。

**解锁的结构**:
- **恩义经济**:noir 的真正货币不是钱,是人情——"老周记得你欠他一次"
  成为和金钱并列的资产/负债;
- **违约戏剧**:到期未兑现的承诺自动生成一个小危机(慢交锋的天然弹药);
- 与账单节拍语法同构:故事账单(主线)、金钱账单(房租)、
  人情账单(账本)三层同屏。

**成本**:内容层糖 + 状态卡渲染。

### 3.2 传闻(rumor)

**定义**:世界事件产生的**衰减信息对象**:内容、可信度、时效;
在酒馆/布告栏流通,可购买、可核实(核实转为情报或证伪)。

**解锁的结构**:
- **信息生态**:玩家的所作所为(交锋胜败、走私暴露)以传闻形式
  回流城市,被 NPC 议论——世界在看你;
- **侦探场**(结构库 §2.4)的燃料:传闻是假设的自然来源。

**成本**:内容层糖(传闻表 + 日终衰减规则)。

### 3.3 慢钟(city clock)

**定义**:按天走的世界级钟,正式化为原语(现在靠各地点手搓 turn-rule):
声明式的"N 天后 X,可被 Y 干预",自动遵守可见性规则。

**解锁的结构**:**慢交锋**(结构库 §1.5)的标准载体;涌现事件系统
(设计文档 §7)的地基——事件 = 抽一张带慢钟的卡。

**成本**:内容层糖(封装现有 clock + turn-rule 模式)。

## 4. 纪律规则(比清单更重要)

1. **三次法则**:一个原语入列的条件是,已经想出**三个互不相似的场景**
   会用它。为单场戏加原语 = 把内容写进了引擎。
2. **糖优先于引擎**:凡能用现有原语在 stdlib.scm 里包出来的,先包;
   被内容反复验证后再考虑下沉 C#。上表大多数是糖,
   真正要动引擎的只有:对话内选择、命名骰、框架场景。
3. **每个原语必须三有**:有 UI 形态(玩家看得见)、有组合性
   (能和钟/动作/规则互操作)、有存档故事(save/load 想清楚再动手)。
4. **表达力的敌人是稀释**:骰子之所以是心跳,因为全游戏只有这一种
   投入物。新原语不得引入第二种"通用投入物"(不加第二种骰子、
   不加平行的行动点)。
5. **本 demo 阶段冻结全部**:这张表是第二章及以后的武器库。
   若只挑一个先做,做**台词触发器**(1.3)——零引擎成本,
   直接回答"人物活不活"这个当前最贵的问题。

## 5. 组合示例(原语相乘的样子)

- **印记 × 人心钟**:交锋里你当众用了狠手 → 印记"老街见过你的狠";
  三天后人心钟开局 −1,酒馆台词分支切换。赢了架输了街,城市记账。
- **意图 × 双战线**:两条战线各自亮意图,你只有三颗骰——
  "他要砸琴"和"他要拖她"同时亮起来,分诊变成台词而非数学。
- **提案 × 竞争者**:布告栏限时买家变成活人:你抬价,他加价,
  第三回合他亮出底牌提案——接受还是再赌一轮,谱系结局自然长出来。
- **命名骰 × 框架场景**:回忆里她的三颗骰子叫"嗓子""胆子""运气";
  回忆结束,"运气"那颗跟她一起回到现实,躺在你的骰池里一天。
- **人情账本 × 慢钟**:你答应老周查账,账本记下,慢钟走三天;
  第四天未兑现,酒馆传闻"那人说话不算话",劳工 −1,印记上身。
