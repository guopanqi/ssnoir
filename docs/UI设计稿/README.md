# SSNoir UI 设计稿

[index.html](index.html) 是持续维护的游戏 UI 交互设计稿，当前包含行动卡片、概率与结算、左下角角色状态、右下角资源、空间节点和两种 Clock。后续 UI 校准在此逐步扩充，Downloads 中的副本不作为维护源。

直接用浏览器打开 index.html，或在本目录启动静态 HTTP 服务。设计稿为自包含 HTML，场景图片已内嵌，不依赖外部素材。

## 共同颜色

- 主强调 / 成功 / 标准 Clock：sRGB `#E8C35A`。
- 失败 / 损伤 / 压力：sRGB `#E83323`；半透明状态由使用处设置透明度。
- 部分成功：纸白。

Unity 的 Linear 项目中，以上明确的 sRGB 色值在 IMGUIStyles 的颜色令牌处转换一次 `.linear`，使用处不再转换。原型用于确认视觉与交互，游戏规则仍以运行时代码和内容数据为准。

保留同一套横屏版面，通过可用宽度适配宽高比，不按平台切换布局。
