# 第一章·第二幕《这里有我的朋友》｜内容设计与验收

> **唯一有效的第二幕设计稿（2026-10-24）**。第一幕既有生活循环延续；第二幕 D7–D13 目前已接入 Scheme 纵向样本，但正式资源、美术、音响、经济及玩家体验仍需实机验收。本稿与 [第一章总纲](00_第一章总纲_这座城里的人.md)、[运行时间线](03_前两幕运行版_时间线与验收.md)、[对白整理](../../../对白整理/第二幕_剧情与对白审核稿.md)一致。旧 V0.2/V0.3 可以从 Git 历史找回。

## 创作命题

尼尔第一次觉得自己属于这座城市，也第一次相信自己和夜莺都可能过上更好的生活；恰恰当他开始珍惜这种生活时，两个世界的幸福开始彼此冲突。

**情绪曲线：新鲜 → 美与喜悦 → 热闹与归属 → 温暖遭受阻力 → 亲密的短暂幸福 → 赞叹中出现裂缝 → 不安与调查悬念。**

不能只有新的任务。玩家应主动回忆起三段生活：夜莺在空荡剧院的演唱、码头上工友一起卸货的热闹、与夜莺在侧门吃东西的平静。由此才会在乎旧港与剧院接下来发生什么。

## 逐日内容

| 世界日 | 实际戏剧职责 | 主要可玩内容 |
|---|---|---|
| D7 | 酒馆空了；旧街、剧院生活开始 | 旧街餐食/牌桌、剧院临时工作、原有工作继续 |
| D8 | **第一次真正的美**：空舞台上的两遍演唱；经理第一次认可尼尔 | 已有剧场 DSL 的灯光/人物/音乐表演；演出服轻委托 |
| D9 | **崭新的热闹**：大船临时靠岸，艾迪保护新人，弗兰克安排众人 | 进入独立加班Scenario：共同卸完指定货批，事故后恢复设备与继续搬运；收工由弗兰克请宵夜 |
| D10 | **关系与阻力**：夜班工资被少算，艾迪为工友开口；夜莺约尼尔吃夜宵 | 工钱Scenario开放；夜宵不扣骰；露西继续报名 |
| D11 | **舞台上真正的能动性**：赞助人压缩时长，夜莺靠实力赢得喝彩 | 一条「争取完整演出时间」目标与节目表压力；夜莺自己决定唱法 |

| D13 | **第一轮不安**：货栈被测绘，剧院张贴「从旧港走向新城」 | 空间状态变化、经理的新调查邀请；第三幕尚未落地 |

第十三天的两处变化不要求玩家完成支线才发生。个人生活可以错过，世界不会暂停。

## 人物：由玩家感情设计，不迁就旧人物稿

- **夜莺**：她对尼尔的亲密是真的；她欣赏自己的新衣服、新舞台和上层的认可，也是真的。第二幕不能暗示喜欢新曲就是堕落。赞助人试演中她主动应对时间不足，玩家帮助争取机会，绝不代替她决定唱什么。真正的认知反转留在后半章。
- **艾迪**：如大哥一般可靠，从一开始就在保护尼尔，到了第二幕也保护年轻工友。因为坚持原则可能被停班；他不需要为了显得复杂而出手打人或者责怪尼尔。持久后果只有「在岗／停班」，无论哪种都愿意把手套交给尼尔。
- **露西**：有趣、机灵，主动想去上夜校。玩家可用骰或钱帮助安排值班，她自己也会找办法。学会打字后拿尼尔名字做练习纸；不强制玩家完成她的梦想。
- **弗兰克**：老街照料者，能在码头组织工人，也会替老人付账。不能只是一个降低危险 Clock 的工具人。
- **经理**：参考旧人物稿的喜剧商人——胖、爱笑、握手拍肩、反复叫「兄弟」，把一点小恩惠说成莫大照顾。他真的提供工作与认可，也真的将利益放在首位。他不能只是冷淡的出题者或刻板反派。
- **尼尔**：想走出零工生活，成为可靠的调查者；这是一种可被现实机会检验的愿望，不制作新的「侦探等级」数值。

## Gameplay：四种不同决策，而不是相同的双 Clock

| 内容 | 结构 | 后果 |
|---|---|---|
| 大船 | **班组加班**：固定货批与离港期限；事故让吊车停用，玩家在搬货与协助检修间取舍，艾迪自主检修或起吊 | 完成发加班费与奖金，未完成只领辛苦钱；昨夜亲历可用于次日查证，未参加仍可调查 |
| 艾迪讨薪 | **证据与停班威胁**：先查工时，年轻工人退缩后改查吊车签到或请弗兰克协助 | 在岗／停班；只改变艾迪是否还能搭班及在哪见到他 |
| 夜莺试演 | **短舞台争取**：完整演出时间与节目表锁定，中途赞助人提前落座 | 完整／压缩试唱；她在两种条件下都主动赢得舞台 |
| 演出服 | **轻经济转换**：同一4格进度，后台与码头可混合投入骰，付钱请人补足剩余线索 | 交付衣箱与45美元；不另开五种调查结局 |
| 露西夜校 | 4格代班；可花钱补格数 | 入学／延后，不依赖艾迪或夜莺线 |

**数值验收必须确认**：玩家每天有限骰与房租压力下确实可以决定放弃哪件事。不是要求四个事件同一存档全部完成。新Scenario应当有中途转折，而不是把钟拖长几格。

## 大船加班：搬运与检修

当前实现以 `scenarios/大船靠岸.scm` 和 `world/第二幕节奏.scm` 为准。目标36格，期限七回合；第二回合末固定发生事故，艾迪自主救下年轻工人。完成领取36块加班费及12块奖金；未完成或倒下仅领6块辛苦钱，无主动退出选项。

| 行动或人物 | 实际效果 | 选择的意义 |
|---|---|---|
| 搬运散货 | 力量判定，坏／中／好卸货0／1／2，不额外扣冷静 | 立即推进交货；设备故障时仍能完成劳动 |
| 跟吊起货 | 力量判定，卸货0／2／3，冷静损失2／1／0 | 设备正常时可反复投入骰子；承担身体代价以争取提前交活 |
| 协助检修 | 敏锐判定，维修0／1／2，不卸货、不额外扣冷静 | 放弃眼前搬运，缩短停机时间；不再固定花两颗低骰就能修好 |
| 年轻工人 | 前两回合结束各卸货1格 | 自主劳动；事故后去货棚休息 |
| 艾迪 | 回合末故障时维修2格，正常时卸货3格 | 自主完成一项工作；自己修好的当轮不再卸货 |

事故后显示“恢复吊车”6格 Clock。吊车初始可用，事故将维修进度置零；只有修满才能起吊。玩家在回合内修满后，剩余骰子立刻可以起吊，艾迪在回合末也会卸货。玩家起吊不占用艾迪的工作机会，不限每回合次数。检修完成后收起维修 Clock 和检修行动，正常设备状态仍明确显示。

**搬货与检修的平衡来自何时恢复设备，而不是维修是否必做。**完全不帮，艾迪会在第三、四、五回合各修2格，从第六回合开始起吊；玩家在这期间可以一直搬货。协助维修能让艾迪提前回到卸货岗位，并让玩家更早获得起吊行动。只差少量货物时直接搬运可能当场收工；距离完成还远、敏锐较好或准备后续赶工时，检修更有价值。维修看敏锐，劳动看力量，也让同一颗骰在不同人物成长方向下有不同用途。

每回合结束另由引擎扣1点冷静；满冷静为5，伤势到2、5点分别封锁一颗骰，到7点倒下。身体代价与治疗成本仍延续到城市生活，不额外增加疲劳系统。完成报酬48块，诊所治疗2点伤势需20块及一颗骰，抢吊带来的损伤仍会侵蚀这晚收益。

先以真实判定概率、四骰、自动劳动和伤势封锁做随机纸面推演，再用真实引擎比较“主动帮修后劳动”“故障时搬货等艾迪自行修复”“帮修但不冒险起吊”。小样本只检查这些路线能否运转，不以某一套固定打法跑通作为体验成立的证据。原先基于每轮一次起吊的平衡结论已废弃。

### 本轮验证（2026-10-24）

真实引擎共48局：力量／敏锐同为0或同为1，三种固定打法各8个种子（0–7），满冷静、无伤、四骰，不使用消耗品。

| 力量／敏锐 | 主动帮修后以高骰起吊 | 故障期间只搬货，等待艾迪修好 | 帮修后仍只搬散货 |
|---|---|---|---|
| 0／0 | 完成8/8，平均第6.38回合 | 完成7/8，平均第6.75回合 | 完成7/8，平均第6.88回合 |
| 1／1 | 完成8/8，平均第5.38回合 | 完成8/8，平均第6.13回合 | 完成8/8，平均第6.13回合 |

无样本倒下；低能力的抢吊路线结束伤势仍较高，不能把更快收工作为无代价收益。另执行确定性边界：同回合可连续起吊、事故后维修钟归零、艾迪独修每轮推进2格且不卸货、第三轮修好后下一轮才起吊，均通过。内容加载与渲染校验通过。上述结果只证明当前几种路线均有完成空间，不代替真人对选择和节奏的判断；本轮未做 Unity 画面与交互试玩。

## 节奏与表现要求

- D8 彩排必须允许玩家欣赏音乐和舞台，而非把美感只写在旁白。现已使用已有舞台 DSL 和音乐资源搭建双段演出，**视觉质量、音乐长度、声音资产和手机版表现仍需要截图/实机审核**。
- D9 已通过现有剧场 DSL 绘制船体、吊车和工人剪影，并播放已有的码头音效；它与独立 Scenario 衔接。仍需在移动端核验实效，不是完整船舶模拟。
- D10 夜宵应独立于任务报酬，保留停顿、沉默与夜莺对尼尔的关心。不要再在 D12 复播同一段吃东西的对白。
- D11 试演不是现场维修考试；夜莺主动面对赞助人，公开宣传开始强调旧港的「落后」形象。
- D13 让测绘标记与新城海报成为空间事实，少量人物反应即可；经理的新委托是下一幕悬念，**当前不提供尚未制作的第三幕调查Scenario**。

## 版本边界与下一轮验证

**已写入**：班组加班独立Scenario、共享吊车与两档报酬、工钱证人退缩转折、试演两种时长结果、演出服钱/骰子转换、经理初见、D10 夜宵、D8 剧场演出脚本、D13 空间变化、主要存档字段和回归用例。

**仍需要制作性验证**：舞台实际镜头及声音、3D 场景的船体/港口灯火、不同骰质下的真实成功率、跨日可达性、所有路径的完整实机试玩。第三至第五幕只有总纲方向。制作新素材时先改善已有镜头和声音，不增加独立系统。

**体验验收四问**：玩家是否能记起一段美好？是否因艾迪遭受不公而难过？是否真正替夜莺高兴又开始不舒服？D13 后是否愿意查明新委托背后的真相？
