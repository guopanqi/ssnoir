# 第二章：他们要夜莺

第一版骨架。只写走向、节拍和「玩家花出去的时间落到哪儿」，不写数值、不写状态变量、不写实施方案。

---

## 一、这一章的全部结构

```
Phase A：成功以后的贝尔维尔          城市的方向 = 扩张

    自由生活
       ↓
    《晚宴》
       ↓
    自由生活 / 人物故事 / 新区域
       ↓
    《制造一个故事》
       ↓

============ 世界真正变化 ============

Phase B：真相与替换正在逼近          城市的方向 = 收紧、逼近

    调查 / 人物故事 / 城市开始紧张
       ↓
    《第三封信的秘密》
       ↓
    继续调查 / 上层压力 / 老街变化
       ↓
    《关于莱恩的真相》
       ↓
    三日倒计时 / 最后准备
       ↓
    《机器进入老街》
```

**两个世界阶段，五个主线锚点，中间全是自由生活。**

锚点只是主线必经的事件，它们不负责每次都重置城市——完成一个锚点，世界不会刷新一遍。整章只有一次真正的 Phase Shift。

人物故事**不服从这张表**。他们有自己的窗口和节奏，只有少数几个人真正和城市变化绑在一起。

一句话的主线问题：**第一章那个让所有人都满意的结局，是谁替他们准备好的？**

---

## 二、Phase A：成功以后

第一章首演之后进入。城市状态很简单：夜莺成功了；莱恩被捕，案子看起来结了；尼尔第一次手里有钱，也第一次有比较宽松的生活空间；夜莺开始进入上流社会，上城区随之逐渐开放。

**这一阶段的核心体验是：「我们终于进来了。」**

主线不急着要求玩家查第三封信，只是慢慢留下疑点。玩家在这一段里主要在做的是：赚更好的钱、改善住处、认识新的人、把时间给某个人。

城市在这一阶段的方向是**扩张**——地图扩张、关系扩张、机会扩张、生活余裕扩张。

### 锚点一《晚宴》

短事件。作用非常明确：

- 夜莺和尼尔一起进入上流社会；
- 林和公司的人正式进入主线视野；
- 玩家拿到上城区的一部分活动空间；
- 尼尔第一次感到「她越来越属于这里」的那种距离。

这一场要让玩家**被吸引**，不是被恶心。钱很多，生活漂亮，事情好像都很容易办。林在这里以「他真的做出了新东西」的面目重新出现——第一章那台在工棚里散架的破机器，现在是公司拿出来展示的项目。玩家甚至会替他高兴。

也是在这里，玩家第一次看见权势：有人一句话就决定了普通人要花很多天才能改变的事。不解释他们的钱从哪儿来，只让玩家看见那种「轻易」。薇拉在这一场第一次开口——她是这一面的脸：克制、准确，真诚地欣赏林，也真诚地认为这座城市该被重新组织一遍。

晚宴给出几个有限的机会，玩家占不全：陪着夜莺 / 认识林 / 接近薇拉 / 和警政那边的人说上话。不是每个都有回报，但每个都有代价——你站在谁旁边，另一边的门那晚就不开。

**散场以后不切 Phase。**世界只是自然变丰富了，玩家继续过日子。

### 锚点二《制造一个故事》

夜莺请尼尔帮她处理成名之后一件和过去有关的事——一张旧照片、一段旧演出记录、某件和莱恩有关的东西。玩家因此走进报社、摄影师的住处或者档案室。

人物问题：**尼尔愿不愿意帮夜莺成为她想成为的那个夜莺？**他不再只是保护她，他开始参与她如何塑造自己。

过程中玩家第一次发现：**有人似乎在第三封信出现以前，就已经知道后来要发生什么。**一篇稿子、一份采访提纲、一张宣传排期——日期明显早于那封信。

这一场最重要的作用不是马上开启阴谋。是让玩家产生一个念头：

> 这个案子是不是其实没有结束？

到这里，Phase A 才走到尾声。

---

## 三、世界真正变化

Phase Shift 不是「完成了第二个锚点所以进入第三阶段」。

它发生是因为**两件事同时到位**：玩家开始真正去碰不该碰的东西；公司的自动化计划从「未来规划」变成「正在发生的事」。这两条线本来无关，在这一刻合流——这是第二章唯一一次明显的世界转换。

地图不用换掉，但氛围整个变了。

---

## 四、Phase B：真相与替换正在逼近

城市从「成功、机会、进入新世界」变成「调查、排斥、替换正在逼近」。方向是**收紧 + 逼近**。

不是地图变小了，是原来白拿的便利突然有了代价：

- 原本很好接触的人开始回避尼尔；
- 一部分上层便利可以被收回；
- 但**靠私人关系建立起来的入口仍然保留**——这一条很重要，它是「你自己挣来的东西不会被收走」；
- 老街出现更多公司的人、测量、登记、培训；
- 林的项目开始接近部署；
- 弗兰克开始意识到这不是普通的商业活动；
- 玩家第一次面对来自上层社会的真正压力。

这一整个 Phase 一直持续到机器真正进入老街。

### 锚点三《第三封信的秘密》

正式的调查 Contract。玩家追查：谁制造了第三封信？

至少要查到**具体执行者，加上他直接服务的那一方**。不需要查清市长、公司、报社、警局之间的全部关系，只需要确定两件事：莱恩真实的勒索被人利用了；第三封信是被人添进去的。

这场里上层力量第一次动手阻止尼尔。这才真正完成那句话：上流社会不只是光鲜，它在利益受威胁的时候也会残酷。

### 锚点四《关于莱恩的真相》

这一段不继续查阴谋，它是**把第一章重新解释一遍**。

玩家找到莱恩，确认：第一封是他的，第二封是他的，勒索确实是他干的，首演那晚他为什么会出现——但第三封不是他写的。

玩家面对的不是「莱恩无辜」，而是：**一个坏人，也可以被加上他没有做过的罪。**

同时第一次把问题指回夜莺：她什么时候开始知道第三封信有问题？这一章不回答。

### 锚点五《机器进入老街》

Phase B 的终点。一直在背景里逼近的替换，第一次真的发生。

林的技术、弗兰克的抵抗、艾迪这样的工人、贝恩斯代表的秩序、公司代表的未来——第一次在同一件现实的事情里碰撞。不是因为他们来参加剧情，是因为他们本来就都得在场。

冲突的每一面都成立：机器可能真的有效；公司真的在赶工期；老街确实有人要砸设备；人群随时会失控；警察已经准备清场。

**没有完美结果。**重点不是公司赢还是老街赢，是让玩家亲身承受一次：当这个漂亮的新世界真的开始改造旧世界时，会发生什么。

第二章到此结束。尼尔基本知道第三封信是谁造的，只剩最后一个私人问题：**夜莺是什么时候知道的？**第三章从这里开始。

---

## 五、城市：两个 Phase 里各是什么样子

第二章不新建一座城，它接手第一章那张地图再加一层。

**Phase A 打开的**

- **上城的酒店与酒吧**——社交与高薪委托的入口。钱在这儿好赚得不像话。
- **报社**——记者在这儿。既是调查入口，也是「故事是怎么被写出来的」这件事的现场。
- **公司试验场**——林线推进后开放。机器在这儿从图纸变成会动的东西。
- **私人场合**——不是常驻地点，是夜莺偶尔为你开的一扇门：某场晚宴、某次私人放映、某个只有被邀请才进得去的房间。随机会出现，也随关系消失。

**委托是怎么找上门的**

第一章那块布告栏不再是一个要玩家自己去翻的地方。它变成家里的一件东西：**装了电话**。

电话是住所建设的一部分，和花、床垫、书桌一样，是你自己搬进来的。通了电话，你才第一次有资格接那种「有人打听到你这个人、直接打上门来」的活——上城的委托本来就是零散的、来自互不相识的人的，不像老街那样有固定日结；它们没有一块板子可挂，只有一个能打进来的号码。

这条升级属于住所自己的进程，不归第二章的 Phase 管：玩家什么时候攒够钱装电话，什么时候开始接。

**Phase A 里照旧、但已经不同的**

三号货栈工棚：林已经调走了。工棚成了**旧的那一边**——剩下没做完的活，和还在这儿上班的人。

**Phase B 改的**

- 上城那几处**不关门**，但里面的人换了脸色：委托变少变冷，有人不再见你，有人开始警告你，有人在打听你。
- **码头**是这一章唯一被主线直接改掉的谋生地点：班次减少、岗位重排。玩家会在自己的钱包上先感觉到「未来」。
- **老街**出现公司的人、测量、登记、培训通知、少量仓库重新登记。不要拆迁，不要推土机——只让玩家知道，一直在耳边响的那个词终于要落到一块具体的地上了。
- **警察局**的存在感提高，巡逻加密。

## 六、人物：他们按自己的节奏走

设计单位不是「谁在哪个 Phase 有几拍」，而是这三个问题：

> **这个人的故事由哪几件值得玩的事组成？它们大概在哪个窗口可能发生？玩家不去的话，他会怎样继续？**

人物只在必要的时候和世界 Phase 发生关系。绝大多数人不需要因为城市要自动化了就把人生调过来对准自动化。

### 夜莺

第二章跟主线绑得最紧的人，但她的重心在 **Phase A**：晚宴、处理自己的过去、成名以后的生活、和尼尔关系的变化。

到 Phase B 她反而应该**少出场**。这时候真正有力量的不是她又出了什么事，而是玩家正在调查她所享受的那个故事背后有什么。后半章她只要三个场合：她愿不愿意谈；她对莱恩的态度；公司请她出现在机器部署现场。

**玩家不去**：她照样红、照样忙。这一章结束时她会成为报纸上的那个夜莺，而不是化妆间里的那个夜莺。

**落点**：上层私人场所（B）、一条交锋能力（A）、人物结局（E）。她的情感结算几乎全部留给第三章——第二章只负责让关系产生裂缝（见第八节）。

### 林

他的故事横跨两个 Phase，而且**不需要和第三封信调查同步**。他就是一直在做他自己的机器。

第一段第一章就开始了（旧机械区、试验）。Phase A 的晚宴让玩家重新见到他——那台破机器现在是公司的展示项目。玩家可以选择继续进入他的故事：试验场、部署前的准备、一次次「能不能工作」。

到 Phase B，因为机器真的要部署了，他才自然而然和主线汇合。这个汇合是被现实推的，不是被剧情安排的。

**玩家不去**：他照样成功，照样被公司抬起来，只是到第三章为止他仍然认为「能不能工作」是唯一的问题。

**落点**：公司试验场（B）、一条交锋能力（A）、城市结局条件（F）。锚点五第一次结算他走上哪条路，最终去向留第三章（见第八节）。

### 弗兰克

**Phase A 他几乎可以没有大剧情。**玩家回老街看到的就是：他在处理自己人的事，照顾谁，教训谁，维持他那套秩序。这些本身就是内容——**他的前半章讲的是「这个人平时怎么治理这里」**。

直到 Phase B，公司真正进老街，他才被迫卷进城市主冲突。**后半章才变成「这个人面对自己的世界要被改掉，会怎么做」**。

**玩家不去**：他也会做他要做的事，只是没人在旁边给他第二种做法。

**落点**：老街内部空间（B）、一条交锋能力（A）、城市结局条件（F）。锚点五第一次结算他还压不压得住，最终去向留第三章（见第八节）。

### 艾迪

一条相对独立的线，核心是：**手伤 → 干活越来越难 → 拿到培训机会 → 培训并不适合他 → 选择越来越少。**

它跨两个 Phase，而且有些节点完全由他自己的时间推动，不理会主线：拳赛还有两天；培训考试后天；他被通知结果。玩家没去就是没去。城市 Phase 只是让他本来就有的问题变得更严重。

这样艾迪会像一个真正住在这里的人，而不是一台城市剧情说明器。

他**不给地点权限，也不给交锋能力**。这条线是这一版里最纯粹的一次感情投资，也是整套时间系统的对照组：**一个不给你任何回报的人，你还去不去。**正因如此，接近他的成本要低（一次探望不该和一天工作一样贵），但窗口要紧——错过就是错过了。

**落点**：只有命运（E），而且是这一章唯一的一次 **Major Payoff**：锚点五里那一整块「艾迪破坏机器」到底存不存在（见第九节）。真正不可逆的那件事留到第三章。

### 贝恩斯

不需要完整故事线。第一章已经把人立住了，第二章只有两三件事：案子已经结了；尼尔来查第三封信；他慢慢发现事情确实不太对；最后他被派去机器部署现场。

他的价值来自人格 + 制度视角 + 调查入口，不需要硬给他「人物成长」。

**落点**：一个调查优势（A，形状是信息，见第十节）。没有复杂结局，也不需要有。

### 记者（新人物）

这一章必须有他。他是《制造一个故事》里那个疑点的来源，是第三封信调查最硬的一条线，也是「故事是被写出来的」这件事唯一的现场。

年轻、冲动、对事实有近乎苛刻的热情，判断却常常先于了解——第一章那种让人厌烦的挑剔，在这一章开始变成有用的东西。他会在锚点三之后被吓退一次，这是第二章里最直白的一次「权势如何工作」的展示。

**落点**：报社（B）、调查线（不给能力）。

### 和城市命运无关的人

**这一条其实很重要。**否则整座城看起来就像：贝尔维尔要自动化了，于是所有人的人生突然都围着自动化转。那反而不真实。

应该有一些人物故事就是：职业、爱情、欠债、犯罪。一个演员想争角色；一个记者想出名；酒馆老板想换个地方；某个医生；某个房东；某个上城的联系人。

这些故事可能只发生在 Phase A，也可能两个 Phase 都在，甚至机器来了以后他们照样做自己的事。**他们的故事在第二章就结束**（见第八节第一层），不必为了大结局拖到第三章。他们承担的是**落点 C 和 D**：让家里多一个恢复功能、让食物便宜些、让某种状态恢复得更快、给尼尔一份稳定的侦探活、开始有高薪委托找上门。

他们不需要出现在最终高潮里。

## 七、人物故事能产出什么：六个落点

**一个人物故事只需要落进其中一两个，不是全部。**这一条是这一节的全部意思。

| 落点 | 是什么 | 给谁 |
| :--- | :--- | :--- |
| **A 真正的玩法能力** | 一条能在交锋里用出来的抽象能力（形状见第十节）。这是**日常回报**，不是 Major Payoff | 极少数人：夜莺、林、弗兰克、贝恩斯 |
| **B 打开城市的一部分** | 一处别的路进不去的空间 | 夜莺（上层私人场所）、弗兰克（老街内部）、林（试验场）、记者（报社） |
| **C 改善生活结构** | 家里多一样恢复手段、某种消耗更便宜、某种状态恢复更快 | 完全由和主线无关的人承担：医生、房东、酒馆老板、木匠 |
| **D 新的工作与赚钱方式** | 一份稳定的侦探活、一类高薪委托 | 次要人物、上城联系人。这就是「我的职业生涯发展了」 |
| **E 改变人物自己的命运** | 他走上哪条路，以及最终落在哪里（分三层兑现，见第八节） | 第一版重点只做两个：夜莺、艾迪 |
| **F 打开一个新的城市结局可能** | 一整个本来不存在的剧情模块（见第九节） | **只此一处**：林 + 弗兰克 + 第三封信的真相，共同让「妥协方案」成为可能 |

F 只有一处，它才珍贵。

### 分布应该是不规则的

这反而是对的。大致会长成这样：

- **夜莺**：四件主要事 · 强情感 · 一个地图权限 · 一个人物结局
- **林**：三件主要事 · 一条交锋能力 · 一个城市结局条件
- **弗兰克**：三件主要事 · 一个地点权限 · 一条交锋能力 · 一个城市结局条件
- **艾迪**：四件短事 · 没有任何技能奖励 · 一个非常强的命运结局
- **贝恩斯**：两件主要事 · 一个调查优势 · 没有复杂结局
- **某个医生**：两件事 · 家里的恢复能力升级 · 和城市命运无关
- **某个上层联系人**：一两件事 · 给玩家一类高薪工作 · 以后可能再也不重要

第一版尤其要避免的是另一种：五个人 × 每人三阶段 × 每阶段一件事 × 每人一条能力 × 每人一个结局。那不是城市，那是表格。

## 八、人物命运什么时候兑现

不统一放第二章，也不统一放第三章。分三层。

### 第一层：这一段故事自己的结果——第二章就兑现

一个次要人物想从一份低收入的活跳进一个新行当。玩家认识他，替他准备，或者没有。最后他成了、砸了，或者自己放弃了。

这个故事第二章就完了。**不必为了「大结局」硬把他拖到第三章**，他甚至和机器、老街、第三封信都没关系。

这种人非常有必要。如果所有人最后都汇进城市命运，世界反而显得人工。他存在的意义只是让玩家觉得：我在这座城里真的认识了几个人，他们也在过自己的日子。

### 第二层：第一次命运转折——锚点五当场结算

林、弗兰克、艾迪这些和城市变化绑在一起的人，在机器进入老街那天第一次结算玩家的介入。**但这不是最终结局，它决定的是他走上哪条路。**

- **艾迪**：只有两种状态——**掉下去了**，还是**离开了这条路**。前者他在破坏行动里，后者他根本不在场，而且是一整块内容不存在（见第九节）。是否入狱、手是不是彻底废了、能不能重新找到生活——第三章。
- **林**：他现在有足够的地位吗？他更愿意停机，还是因为玩家一路鼓励他追求技术上的成功，反而成了最坚持继续运行的那个人？他最终成为公司最重要的自动化工程师、还是试图改变部署方式的人、还是干脆走人——第三章。
- **弗兰克**：他还压得住下面的人，还是已经默认了暴力？他最终成为能代表这条街坐下来谈的人，还是一个地方暴力头领——第三章。

一句话记住：

> **第二章高潮决定「他走上哪条路」，第三章决定「这条路把他带到哪里」。**

注意林和弗兰克在锚点五**不发好处**。他们在那一天只是表现出自己已经变成了什么样的人，玩家看得见，但兑现不在这里——他们真正的 Major Payoff 在第三章（见第九节）。

### 第三层：真正值得重玩的结局——很少，且几乎全在第三章

只有夜莺、艾迪，也许再加城市本身。玩家不会为了十个人的结局重玩，他会为两三个真正喜欢的人重玩。

**夜莺是特例。**她第二章的兑现不该是「好结局 / 坏结局」，第二章只负责让关系产生**裂缝**：第一章她需要尼尔；第二章她进了自己梦寐以求的世界，而尼尔越来越看得见这个世界背后的东西。到第二章结束，玩家应该清楚地感觉到——

> 我们还是很亲近，但我们可能已经不站在同一个地方了。

这就是第二章对她全部的兑现。她最终会不会让别人继续替她讲这个故事，他们还能不能选择彼此——留给第三章，那样才有分量。

**艾迪要的是那句「我当初应该去找他的」。**第一章认识，第二章生活不断变坏，玩家可能进也可能不进；机器部署那天他的人生已经明显走向某处；第三章的最终冲突里才发生那件不可逆的事。到那时，关系浅，尼尔根本没有资格阻止他；关系够深，他会听你一句；如果你还真的替他弄出过一条出路，他才可能不去。

玩家第一次看见那个悲剧时会非常清楚：**不是最后少点了一个按钮，是之前有几个晚上我没去找他。**

## 九、玩家的介入怎么进入主故事：模块级兑现

**不要做「关系高 → 人群压力 -1」「关系高 → 故障率 -10%」这一类东西。**这种修正玩家感知不到，也不值得开发。

真正有重量的是：

> **因为你之前做过某件事，所以这次主线事件里，本来会发生的一整件事不发生了，或者换成了另一件事。**

这叫**模块级兑现**。判断标准只有一条，而且非常好用：

> **把两个存档并排放在一起，玩家能不能一眼看出这一场主线发生了明显不同的事？**不是去看后台数值，是看内容本身。

所以人物内容分成两层：

- **平时**：关系给一点权限、地点、交锋帮助。这些只负责让日常玩法有回报。
- **在某一个主线节点**：真正重要的人物必须有一次 **Major Payoff**，它一定是模块级的。

### 模块级兑现的三种形式

**一、某个主线模块出现或消失。**艾迪最适合这一种。

**二、同一个主线位置，由不同的人占据。**比如第三章最后老街冲突里，本来就需要有人带头最激进的那一批人：弗兰克一路走向激进，那就是弗兰克本人；弗兰克仍然克制而莱恩没被处理好，那个失控的人就是莱恩；如果艾迪也掉下去了，他可能站在莱恩旁边。**同一个主线骨架，谁站在那里变了，整场的意义就完全不同。**

**三、一个关键场景直接换版本。**林最适合这一种（下面是这种形式长什么样，不是第一版的承诺——林的 Major Payoff 在第三章）。机器正式部署时固定有一次关键故障：默认版本是公司要求继续运行、林也坚持继续，玩家必须自己去处理危险；如果玩家真正改变过林，他自己先按下停机——「危险运行」那一块直接不发生，主线换成公司负责人质问他为什么停机，林第一次公开和公司起冲突。同一个时间点，内容整个换掉。

### 第一版只做三个 Major Payoff

**艾迪｜第二章高潮兑现（这一章唯一的一个）**

机器第一次进入老街那天，Contract 里默认存在一整块内容：

> 艾迪参与破坏设备 → 玩家在现场发现他 → 破坏失控 → 他可能再次重伤，甚至连另一只手也毁掉。

这是完整的一段剧情，不是一个危险值。它默认会发生——因为失业、手伤、培训失败之后，他本来就被推到了那个位置上。

如果玩家前面真正改变了他的命运，**这一整段直接不存在**。不是「危险降低了」，而是 Contract 少了一块：玩家走到本来该撞见他的地方，只看见别人。

那一刻玩家会非常清楚地意识到：**哦，他真的不在这里了。**

这一块如果落在交锋里，就是交锋树上**少一整块**——少几张卡、少一个阶段、少一场危机；而不是把某个数字调低。

**林 + 弗兰克｜第三章城市结局兑现**

他们**不需要**在第二章高潮各自贡献几个小修正。第二章只负责继续塑造他们。

到第三章：如果林已经是有能力改变部署方式的人，弗兰克仍然是能坐下来谈的人，再加上玩家手里握着第三封信的真相——**「第三种城市方案」这一整个剧情模块出现**。条件不够，这个模块根本不存在，玩家只能在「公司推进」和「老街死守」两个坏答案之间处理。

这是全局最大的一次系统级兑现：不是林 +10、弗兰克 +10，而是**一条原本不存在的故事路径出现了**。

**夜莺｜最终私人结局兑现**

她更不需要在每场 Contract 里帮你。她真正的兑现只有最后那一个场景：

- 普通版本：她按照别人写好的故事继续走下去；
- 如果玩家过去真正影响过她：她自己停下来，说出第三封信的真相。

整个结尾场景换版本。这是这个游戏里最重的一次兑现，所以它必须留到第三章。

### 三条线各自的形状

```
艾迪人物线
    ↓
【掉下去】 / 【离开这条路】
    ↓
第二章 · 机器部署
    ↓
出现「艾迪破坏机器」模块
        或
该模块完全不存在
```

```
林 + 弗兰克人物线
    ↓
【有第三种可能】 / 【没有】
    ↓
第三章 · 最终城市冲突
    ↓
出现「妥协方案」模块
        或
只能在两种坏答案里处理
```

```
夜莺人物线
    ↓
【仍由别人讲她的故事】 / 【能够自己开口】
    ↓
最终公开场景
    ↓
念稿
        或
自己说出真相
```

人物线最终产生的是**几个离散的命运状态**。这些状态在特定的主线节点上，直接决定某个剧情模块**是否存在、由谁承担、或者换成哪个版本**。

### 一个现在就定下来的原则

> **每一个真正重要的人物，最多只找一个「玩家介入过，他的人生会明显不一样」的时刻。**

不要让他在五个节点各变一点，那只会把重量稀释掉。

- 艾迪就是**那天他有没有去**。
- 夜莺就是**最后她有没有自己开口**。
- 林和弗兰克共同对应**这座城市有没有第三条路**。

三个瞬间，足够强，玩家反而记得住。

### 所以人物内容是一条很不规则的河

有的小河第二章 Phase A 就流完了。有的流进机器部署。有的一直流进第三章。真正汇入大海的只有几条：夜莺、艾迪，以及林和弗兰克共同影响的城市命运。其他人不必——正因为如此，那几条汇进去的才显得重要。

重要的从来不是「每个人都走完一个完整的生命周期」，而是：

> **当一个人物值得进入世界主线时，他过去的故事能够改变他后来在那里做什么。**

这也重新定义了锚点五：它不是所有人物的最终结算，它是整个游戏的**第一次总检验**——你介入过这些人，现在第一次看看他们已经变成了什么样的人。第三章的清退与最终冲突才是：看看他们最终付出什么代价，以及你到底改变了什么。

## 十、交锋能力必须是抽象能力

这一节讲的是**日常回报**那一层——真正重要的兑现是模块级的，见第九节。

**关系兑现出来的东西，要能用引擎已有的词说出来。**判定是「放入骰 + 技能 + 修正」查一条命运条；场上还有骰位、换手骰、可见修正、钟、同伴骰位。能力就该长在这些词上。

不能写成叙事动作。「夜莺替你挡一下」不是能力——它只在作者预先想到的那一场里成立，玩家学不会它、算不进自己的计划，下一场作者还得再写一次。

**能力的几种合法形状：**

1. **容量**——多一个骰位，但有条件（只能投在某一类动作上）。
2. **概率**——一档可见修正，挂在某一类判定上，进准备值。
3. **时间**——对钟的操作：压回一格、延后一次触发。
4. **信息**——让本来隐藏的钟提前可见，或者让一条判定在放骰前显示它真正的难度。
5. **人手**——那个人自己入场，占一个骰位，用他自己的技能。

第一版只做四条，一人一条，四种形状各占一个——这样玩家一眼就知道每条关系是干什么用的：

- **夜莺｜容量**：交锋中多一个骰位，只能投在交际类动作上。她不替你做事，她让你在人堆里多出一只手。
- **林｜概率**：涉及机械与装置的判定获得一档可见修正。他不替你修机器，他让你看得懂它。
- **弗兰克｜时间**：每场一次，把一条正在逼近的钟往回压一格。人群升级、清场、走火——他压的是时间，不是人。
- **贝恩斯｜信息**：本来看不见的倒计时对你可见（比如警察几回合后清场）。他甚至不需要做成一个按钮：**「因为认识贝恩斯，所以你提前知道三回合后警察会清场」本身就已经是玩法优势了。**

具体的档数、格数、骰位数留给实现时定，写在代码里，不写在这份文档里。（这一节写的是能力的**形状**和各自属于谁；**最终的能力设计以结合引擎实施为准**——真做起来发现某个形状在交锋里不成立，改的是这里，不是硬把它塞进去。）

## 十一、这一版要验证什么

不是「人物系统完不完整」。只有五件事：

1. **玩家有没有感觉到 Phase A 和 Phase B 是两个不同的城市？**前面是世界向你打开，后面是世界开始关门、机器开始逼近。
2. **自由时间有没有真正产生取舍？**玩家心里出现过这句话就算成功：「我今晚想去找艾迪，可那个记者明天就走了。」
3. **把两个存档并排放在一起，能不能一眼看出主线发生了不同的事？**这一章只测一个点：锚点五里那块「艾迪破坏机器」在不在。看内容，不看数值。
4. **有没有一个人，玩家明知没有收益也愿意为他花一天？**这是艾迪的测试。如果玩家愿意为艾迪浪费一天，人物系统就成功了一半。
5. **第一周目结束时，有没有人让玩家想「原来我当时要是做了另一件事，他会不一样」？**夜莺、艾迪，以及林和弗兰克共同带来的第三种城市结果——这三处足以支撑重玩。

## 十二、几处还很薄的地方（做之前要先定）

- **夜莺目前没有自己的人物模块。**第一章她是主线的一部分，第二章她要变成一个有关系、有门、有能力的常驻人物。这是这一章最大的一块新东西，也最容易被低估。
- **记者是全新的人，没有形象也没有声线。**但调查线绕不开他。要么补，要么把他的功能拆给经理和贝恩斯——不推荐，那会让「故事是被写出来的」这个主题失去现场。
- **薇拉第一章只有形象没有戏。**晚宴是她第一次开口，那句话决定玩家会不会把「权势」当成一个人来理解。
- **Phase Shift 的触发条件要能被玩家读出来。**它由「调查推进」和「部署逼近」两条合流，如果玩家事后说不出自己是哪一天越线的，这次转换就白转了。
- **钱变好赚会不会把第一章那套生活系统架空。**这一版的答案是时间接手压力：上城的活省钱不省天，恢复和体面同步变贵，锚点又都带死线。这个答案要在 Phase A 的头几天就能被感觉到，否则整章的取舍都会松。
- **玩家要看得见自己放弃了什么。**没推进的人物线不能从卷宗里消失，要一直摆在那儿，直到锚点五那天变成他没有的选项。
- **第二章要替第三章存住三样东西，而且都得是离散状态。**一是每个核心人物在锚点五「走上了哪条路」；二是玩家和夜莺之间那道裂缝有多深；三是妥协方案的三个条件各自成不成立（林的地位、弗兰克还坐不坐得下来、第三封信的真相在不在玩家手里）。它们要能直接回答「第三章那个模块出不出现」，所以是几个离散的命运状态，不是一条连续的好感度，不能只做成锚点五当天的一场演出——否则第三章接不住，第二章所有的介入也就白花了。
