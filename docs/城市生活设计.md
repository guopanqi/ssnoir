# SSNoir 城市生活设计

> 本文是当前版本的**内容与机制源头文档**。它描述"游戏该是什么"，是所有 `.scm`
> 内容和货币层实现的依据。工程规则在 [../AGENTS.md](../AGENTS.md)，
> 代码架构在 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 0. 设计哲学

游戏是一个**可供交互、可供游览的产品/建筑**，不是电影或文学故事。

- 城市不是关卡，是一台**玩家能读懂的机器**：不同的活法真的产生不同的结果，而且结果可见。
- 玩家愿意投入，是因为他在**设计属于自己的生活方式**。每天分配骰子的模式，会自然沉淀成一种活法。
- 玩家从"工作和生活背后的事情"里，一步步理解这座**美丽而致命的城市**的世界模型（黑色电影 / 马洛的世界）。

核心机制不变：**人物每天有一个行动骰子池，分配到不同地点、不同行动之中。**
骰子从"推进剧情的燃料"变成"你如何度过一天"的表达。

## 1. 一天的循环

```
早晨   掷骰（主角 3 颗）
白天   分配到地点：工作 / 服务 / 委托 / 休息
傍晚   城市结算：涌现事件、势力状态变化（第一版可最简）
夜间   睡觉 → 饱腹 −1、压力少量恢复、重掷骰
```

## 2. 资源模型

资源分三类，各有其家。总体"一线货币"控制在少数几种，每个动作至少触碰两种，让任何选择都是取舍。

### 2.1 物品（Inventory，可计数）

| 物品 | 作用 |
|---|---|
| 金钱 | 房租、饭钱、赌注制造的底层生存压力 |
| 情报 | 世界知识碎片，同时是解锁高阶工作 / 地点的钥匙（用 `req-item` 当门槛） |
| 食物 | 吃饭 → 回饱腹 |
| 药品 | 诊所购买 → 回健康（健康的唯一恢复途径） |

> 具名线索（如"货单编号对不上"）走 global flag，不进物品。
> 情报有两个来源：码头走私线（阴暗面）、警局探长（官方渠道）。

### 2.2 身体状态（Team / Actor）

| 状态 | 被谁消耗 | 靠什么恢复 |
|---|---|---|
| **健康** | 高风险 / 越界工作的**坏结果**、交锋 | **只有药品**。睡觉不回。是最硬的资源。 |
| **压力** | 工作的坏结果（高风险从中性起就可能加）；**不普遍 +** | 睡觉（少）、喝酒（多）、公园散步、家里仪式（唱片 / 花） |
| **饱腹** | 每天睡觉 −1，归零后开始扣健康 | 食物（吃饭） |

### 2.3 关系（势力好感，底层连续整数 + 离散档位）

三个势力，对应城市的三种力：

| 势力 | 内涵 |
|---|---|
| **官僚** | 秩序、体面、流程、政府、市长 |
| **劳工** | 生存、暴力、阴暗面、普通人的生活 |
| **富商** | 欲望、享乐、资本、科技、服务 |

底层存连续整数（每次工作小步变化），效果映射到离散四档（阈值示意、可调）：

| 档位 | 阈值 | 效果 |
|---|---|---|
| 敌视 | < −5 | 该势力地点涨价、拒接高阶活、惹事概率升高 |
| 中立 | −5 … +4 | 默认 |
| 脸熟 | +5 … +14 | 小折扣、有人打招呼、**二层工作开放** |
| 自己人 | ≥ +15 | **三层（越界）工作**、关系门地点、支线（如老周） |

- **关系只在工作"好"结果 +**（中 = +少 / 0，坏 = 0）。够到"自己人"约需 5–7 个成功班次。
- 三个势力**互不排斥**：现阶段唯一约束是时间有限，理论上刷不满三边。
  非此即彼的对抗留给未来的主线关键选择。
- 玩家看到的永远是清晰的四档，底下是可以慢慢磨的进度。

### 2.4 资产

由玩家拥有的**住所**推导，不做独立数值：

| 住所 | 资产等级 |
|---|---|
| 旅馆（付房租） | 低 |
| 公寓（购买） | 中 |
| 豪宅（购买） | 高 |

资产等级是富商圈的隐形门槛（如夜总会看资产而不只看关系）。

## 3. 地点

每个地点 = **一张城市的脸** + **2–3 个动词** + **一个住在这儿的人** + **一个自走的状态**。
地点是"城市向你提的一个问题"。动词分两类：

- **工作**：可重复、掷骰（`roll-action`）、耗状态、产资源。
- **行动 / 服务**：即时（`instant-action`）、花钱换物或服务。

| 地点 | 势力 | 工作 | 行动 / 服务 | 门槛 | 人物 |
|---|---|---|---|---|---|
| 码头 | 劳工 | 搬运 / 记账 / 走私 | | | 老周（关系够 → 开支线 → 全部完成可作同伴加入） |
| 老街市集-饭摊 | 劳工 | 刷盘子 / 送外卖 / 摆摊 | | | |
| 老街市集-黑市 | 劳工 | | 借钱 / 购买家具 / 购买物品 | | |
| 老街酒馆 | 劳工 | 服务员 / 打听消息 | | | |
| 老街酒馆-地下酒吧 | 劳工 | 赌博 | | 关系好才能进入 | |
| 诊所 | 官僚 | | 购买药品 | | |
| 银行 | 官僚 | | 存款（见 §5） | | |
| 警局 | 官僚 | | | | |
| 警局-探长 | 官僚 | 收集情报 | | | 探长 |
| 花店 | 富商 | | | | |

## 4. 工作模型

每个工作按风险分级，掷骰产生 **好 / 中 / 坏** 三种结果（沿用现有 `roll-action`）。
惩罚货币的严重度排序：**钱 → 压力 → 健康**（直接扣健康是全局最重的惩罚）。收益随风险单调上升。

| 风险级 | 例子 | 好（成功） | 中（中性） | 坏（失败） |
|---|---|---|---|---|
| 低 | 刷盘子、代写信、跑腿 | +钱（少）+关系 | +钱（更少），无损害 | 轻：+压力一点 **或** −很少钱 |
| 中 | 记账、送外卖、摆摊、调研 | +钱 +关系 | +钱（少），基本无害 | +压力 **或** −一定钱 |
| 高 | 搬运、赌博 | +钱（多）+关系 | +钱（少），**可能小惩罚**（压力 / 钱） | 重：+压力 2，**甚至 −健康 1** |
| 越界 | 走私、替探长办事 | +钱（很多）+关系 | +钱（多） | **−关系（掉档）** ＋压力 / 健康 |

这就是"不同活法产生不同的一周"：刷盘子的人平稳、钱少、压力低；扛货走私的人钱多，
但身体和精神在磨损，还赌着关系。

### 4.1 工作阶梯（越干越深、越深越看见）

同一地点的工作往下走是一条梯子，越深钱越多、看到的世界越多，门槛用关系 / 情报：

```
一层  零工     人人可做       +钱 −状态 +本地势力关系
二层  熟手活   需脸熟 / 情报   +更多钱  世界模型漏出（+情报 / 具名线索）
三层  越界的活 需自己人       高薪 / 违法  直连（未来的）主线
```

## 5. 银行

存 `金钱` → 每过几天 +利息（低回报、稳）。作为"安稳生活"的隐喻，
对冲走私 / 投资那种"押本钱、有风险"的高回报路子。取款随时。

## 6. 布告栏

每过 4 天，刷新 2–3 张委托（寻物 / 寻人 / 带话 / 盯梢），部分要求能力或关系达标，有期限。
**任何零散想法都能做成一张贴在板上的纸**——它是内容注入口，不需要额外系统。

## 7. 城市涌现事件（第一版可最简 / 暂缓）

每回合结算（或开始）有概率从可用事件堆抽取随机事件，在某些地点产生变化。
第一版可以不做，或只做最简单的一两个。

## 8. 主线（本版丢弃）

第一版**完全丢掉旧主线**，重点验证整个城市生活模拟的可行性——即使重建全部内容也无所谓。

未来会加回一个**有容差的主线节点**（类似"经理的耐心"）：

- 一个计时器每天减少，主线有进展则恢复。
- 开头受限、像教程；之后自由分配到城市生活。
- 每过几天主线发生一件必须参与和交锋的事情。
- 作用：给玩家的选择加上时间限制，让"如何分配骰子"有了优化的意义。

## 9. 交锋：成长兑现的地方

城市生活里长出来的东西 = 交锋场景里的动词。码头练的身板 → "硬闯"亮起；
剧院 / 关系 → "从后台混进去"；诊所学的药理 → 一眼看穿被下了什么。
**靠拳头活的玩家和靠人情活的玩家，走进同一场交锋，看到的选项完全不同。**

## 10. 待办 / 未决

- **可见风险（UI）**：玩家选中 / 放入卡片时，卡片给一小段"可能后果 / 风险"提示，不用详细，
  但要让玩家知道这回事。属 UI 层，货币层稳定后再做。
- **势力对抗**：现阶段三派可并行刷，仅受时间约束；后期主线关键选择引入非此即彼。
- **城市涌现事件**：事件堆与抽取机制，见 §7。
- **住所系统**：`home.scm` 从单一固定家改成旅馆 / 公寓 / 豪宅的可升级住所（内容层，货币层之后）。

## 11. 落地顺序

1. **货币层**（进行中）：物品加 `情报 / 药品`；`Supplies → 饱腹` 正名并显示；
   三派关系底层整数 + 四档读写；银行存款 / 利息最小骨架。
2. 一个地点垂直切片（码头：搬运 → 记账 → 走私 三层工作梯 + 关系门）验证核心循环。
3. 逐步铺开其余地点、布告栏、涌现事件。
