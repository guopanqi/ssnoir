# SSNoir 城市生活设计

> 本文是当前版本的**内容与机制源头文档**。它描述"游戏该是什么"，是所有 `.scm`
> 内容和货币层实现的依据。工程规则在 [../AGENTS.md](../AGENTS.md)，
> 代码架构在 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 0. 设计哲学

游戏是一个**可供交互、可供游览的产品/建筑**，不是电影或文学故事。

- 城市不是关卡，是一台**玩家能读懂的机器**：不同的活法真的产生不同的结果，而且结果可见。
- 玩家愿意投入，是因为他在**设计属于自己的生活方式**。每天分配骰子的模式，会自然沉淀成一种活法。
- 玩家从"工作和生活背后的事情"里，一步步理解这座**美丽而致命的城市**的世界模型（黑色电影 / 马洛的世界）。

核心机制不变：**人物每天有一个行动骰子池，分配到不同地点、不同行动之中。**
骰子从"推进剧情的燃料"变成"你如何度过一天"的表达。

## 1. 一天的循环

```
早晨   掷骰（主角 3 颗）
白天   分配到地点：工作 / 服务 / 委托 / 休息
傍晚   城市结算：涌现事件、势力状态变化（第一版可最简）
夜间   结束一天 → 饱腹 −1、重掷骰；具体睡眠地点另行决定压力变化
```

所有跨回合的持续、冷却、到期和延迟事件都必须对玩家可见。统一使用 Clock 表达剩余时间，
Clock 标题说明状态，备注明确归零或填满后的结果；不能只在脚本里维护隐藏计数器。例如码头风声
会显示走私还要封闭几天，限时美差会明确显示只在本回合有效。

时间状态挂在真正负责它的拥有者上。地点冷却和限时工作挂在地点；跨地点可见、会阻塞世界日程的
公共事件由世界协调器拥有并显示在世界根节点。排期到期后不能隐藏 Clock，而要显示为
“已经发生 / 等待处理”，直到玩家处理或事件明确失效。

到期后被定义为“当天必须处理”的关键事件会阻止休息和推进日期。住所中的休息动作直接灰显，
并以标签列出所有尚未处理的原因；玩家必须进入对应事件并完成其实际内容。交锋必须打完，对话必须
完成，选择必须作出，不在阻塞层额外提供“忽略事件”的通用选项。事件无论成功或失败，只要已经完成，
就解除对应阻塞。系统允许多个关键事件同时等待处理。
主线触发的必看对话场景（如夜莺交锋后的真相揭开）同样使用这一阻塞机制，当晚不看完不能睡觉。

## 2. 资源模型

资源分三类，各有其家。总体"一线货币"控制在少数几种，每个动作至少触碰两种，让任何选择都是取舍。

### 2.1 物品（Inventory，可计数）

| 物品 | 作用 |
|---|---|
| 金钱 | 房租、饭钱、赌注制造的底层生存压力。开局 15,刚好交不起首期 40 房租;夜莺预付 30 后喘不过气,迫使你第一天就必须找工作。 |
| 私货 | 走私好/中结果；可在码头低价散卖，或交给富商脸熟后的货运代理（简洁性修订 2026-07-10：布告栏限时买家已删除，两口足以构成"六折 vs 满额经富商"的对比） |
| 情报 | 世界知识碎片，可消费物品。可在货运公司换取普通投资项目、在布告栏追加一张委托，或在夜莺主线消耗 1 情报换 1 查访格进度（简洁性修订 2026-07-10 新增第三个消费口） |
| 食物 | 吃饭 → 回饱腹 |
| 药品 | 诊所购买，带回住所使用 → 回健康；不占当天行动骰，但每天只能使用一份 |
| 酒 | 住所订购；饮用恢复少量饱腹并缓解压力，每天只有第一杯有效 |

> 具名线索（如"货单编号对不上"）走 global flag，不进物品。
> 情报有两个来源：码头走私线（阴暗面）、警局探长（官方渠道）。
> 工作层级由**关系势力档位**决定（特殊情况可由资产 / 能力），**不消耗情报**。

私货与情报不能直接按固定价格变成万能金钱：玩家必须经营另一条路线或等待限时机会，才能获得
更高价值。它们是当前城市互联的两个主要接口。

### 2.2 身体状态（Team / Actor）

| 状态 | 被谁消耗 | 靠什么恢复 |
|---|---|---|
| **健康** | 高风险 / 越界工作的**坏结果**、交锋 | 药品，或诊所中消耗行动骰的康复训练。睡觉不回。是最硬的资源。 |
| **压力** | 工作的坏结果（高风险从中性起就可能加）、门口露宿 | 有住所睡觉、喝酒、公园散步、家里仪式（唱片 / 花） |
| **饱腹** | 每天睡觉 −1，归零后开始扣健康 | 食物（吃饭） |

### 2.3 关系（势力好感，底层连续整数 + 离散档位）

三个势力，对应城市的三种力：

| 势力 | 内涵 |
|---|---|
| **官僚** | 秩序、体面、流程、政府、市长 |
| **劳工** | 生存、暴力、阴暗面、普通人的生活 |
| **富商** | 欲望、享乐、资本、科技、服务 |

底层存连续整数（每次工作小步变化），效果映射到离散五档：

| 档位 | 阈值 | 效果 |
|---|---|---|
| 敌视 | < −6 | 该势力地点涨价、拒接高阶活、惹事概率升高 |
| 冷淡 | −6 … −4 | 服务和机会受限 |
| 中立 | −3 … +2 | 默认 |
| 脸熟 | +3 … +5 | 小折扣、有人打招呼、**二层工作开放** |
| 自己人 | ≥ +6 | **三层（越界）工作**、关系门地点、支线 |

- **关系只在工作"好"结果 +1**，中/坏默认不增加；具体坏结果可以降低关系。到脸熟需 3 次成功，
  到自己人需 6 次成功。
- 失败降低哪个势力，不由工作所属势力自动决定，而由具体后果决定：谁看见玩家失手、谁受到损失、
  玩家侵犯了谁的秩序，就降低谁的关系。普通的身体受伤、返工或少赚一笔通常不影响势力关系；
  只有公开失职、背叛或政治性越界才扣关系。例如走私成功且未暴露不会降低官僚关系，被巡警发现的
  坏结果才降低官僚关系。
- 三个势力**互不排斥**：现阶段唯一约束是时间有限，理论上刷不满三边。
  非此即彼的对抗留给未来的主线关键选择。
- 玩家看到的永远是清晰的四档，底下是可以慢慢磨的进度。

### 2.4 个人能力与成长点

主角有四项个人能力。能力提高掷骰可靠性，并在交锋中解锁不同的处理方法：

| 能力 | 内部 ID | 主要用途 |
|---|---|---|
| 力量 | `violence` | 劳动、压制、追逐、承受身体风险 |
| 见识 | `knowledge` | 账目、医学、技术、档案 |
| 敏锐 | `sharpness` | 观察、识破、寻找异常、把握时机 |
| 交际 | `social` | 说服、欺骗、交易、威慑、周旋 |

成长点只来自**完成一个不可重复的主线或人物支线小节**，不由重复工作直接刷取。失败若已经让
小节不可逆地推进，也算完成。玩家在人物成长面板中把可用成长点投入任一未满级能力；住所不提供
重复的升级入口。
重复工作负责金钱和势力关系；真正经历完一段处境，才形成个人成长。

### 2.5 人物同伴

老周人物小节完成后，还需要满足一个额外条件才能邀请他成为同伴：把异常货单交给老周，或把
老周信任磨到满格。邀请本身消耗一颗行动骰。

- 老周属性：力量 2、见识 3、敏锐 1、交际 2。
- 入队后的次日开始，他每天在城市模式提供一颗自己的行动骰。
- 同伴骰可以用于工作和人物行动，不能带入交锋。
- 同伴压力达到上限会暂离；在家休息会逐日缓解老周压力，归零后自动归队。
- 交锋中的“请老周出面”仍是独立的具名援助，不使用同伴骰。

### 2.6 资产

由玩家拥有的**住所**推导，不做独立数值：

| 住所 | 资产等级 |
|---|---|
| 旅馆（付房租） | 低 |
| 公寓（购买） | 中 |

资产等级是富商圈的隐形门槛（如夜总会看资产而不只看关系）。
（简洁性修订 2026-07-10：豪宅档位已删除——它唯一效果是副标题承诺，
`资产="高"` 全仓零消费方，睡眠恢复与公寓相同；旧档 residence="豪宅"
读档时映射为"公寓"。）

## 3. 地点

每个地点 = **一张城市的脸** + **2–3 个动词** + **一个住在这儿的人** + **一个自走的状态**。
地点是"城市向你提的一个问题"。动词分两类：

- **工作**：可重复、掷骰（`roll-action`）、耗状态、产资源。
- **行动 / 服务**：即时（`instant-action`）、花钱换物或服务。

## 4. 工作模型

每个工作按风险分级，掷骰产生 **好 / 中 / 坏** 三种结果（沿用现有 `roll-action`）。
惩罚货币的严重度排序：**钱 → 压力 → 健康**（直接扣健康是全局最重的惩罚）。收益随风险单调上升。

**工作助手**（`工作` DSL，见 engine.scm）：只负责统一结构（req-die + roll）、成功自动 +势力关系、
断言 faction/risk 合法、由 risk 生成 `:subtitle` 风险提示；**好 / 中 / 坏三个结果由每项工作显式传入**，
避免自动生成固定收益导致所有工作同质化。越界工作失败掉关系，写在该工作的坏结果里（可见）。

**风险提示不推迟**：工作节点 `:subtitle` 直接标注风险（如"高风险 · 可能伤身"），
让玩家行动前就知道"可能伤健康 / 掉关系"，无需先做完整 UI。

| 风险级 | 例子 | 好（成功） | 中（中性） | 坏（失败） |
|---|---|---|---|---|
| 低 | 刷盘子、代写信、跑腿 | +钱（少）+关系 | +钱（更少），无损害 | 轻：+压力一点 **或** −很少钱 |
| 中 | 记账、送外卖、摆摊、调研 | +钱 +关系 | +钱（少），基本无害 | +压力 **或** −一定钱 |
| 高 | 搬运、赌博 | +钱（多）+关系 | +钱（少），**可能小惩罚**（压力 / 钱） | 重：+压力 2，**甚至 −健康 1** |
| 越界 | 走私、替探长办事 | +钱（很多）+关系 | +钱（多） | **−关系（掉档）** ＋压力 / 健康 |

这就是"不同活法产生不同的一周"：刷盘子的人平稳、钱少、压力低；扛货走私的人钱多，
但身体和精神在磨损，还赌着关系。

### 4.1 工作阶梯（越干越深、越深越看见）

同一地点的工作往下走是一条梯子，越深钱越多、看到的世界越多，门槛用**关系档位**（不消耗情报）：

```
一层  零工     人人可做     +钱 −状态 +本地势力关系
二层  熟手活   需脸熟       +更多钱  世界模型漏出（产出情报 / 具名线索）
三层  越界的活 需自己人     高薪 / 违法  直连（未来的）主线
```

## 5. 银行（已删除）

简洁性修订（2026-07-10）：银行已整体移除。取消利息后它仍是无风险的安全保管箱，
现金没有任何丢失风险，纯占位休眠，不构成一个真正的去处。`银行.scm` 已删除，
`world.scm` 不再挂载/存读档；旧存档中的 `bank` 字段被直接忽略。

## 6. 布告栏

布告栏已经作为顶层地点实现：每三天补充至两张委托，每张只保留两天，并用 Clock 显示期限。
完成或尝试后委托消失；同名委托不会同时出现。当前模板池（5 张，简洁性修订 2026-07-10：
"急收私货的买家"已删除——私货已有码头散卖/货运代理两个换钱口，该模板是同类换钱模板的
第三个，对无私货玩家是常驻置灰噪音）：

- 帮人寻物（敏锐）、替人带话（交际）、押送一批货（力量）、代查一笔账（见识）。
- 有人需要药：消耗一份药品，获得 20 金钱和 1 点劳工关系。

常驻行动“向消息灵通的人打听”消耗一份情报，不占骰，立即增加一张额外限时委托。
在板委托与剩余期限随存档保存。

## 7. 城市涌现事件（第一版可最简 / 暂缓）

每回合结算（或开始）有概率从可用事件堆抽取随机事件，在某些地点产生变化。
第一版可以不做，或只做最简单的一两个。

## 8. 主线节奏（夜莺委托线·最小骨架）

旧侦探主线已经丢弃。当前 demo 用一条自闭环的短故事线提供拉力：
雨夜歌女夜莺委托玩家查清盯梢者，三次交锋逐次揭开她为何被追、为何不能回头，
最终按玩家准备的活法（金钱 / 劳工 / 官僚 / 无准备硬打）分岔。

- **第 1 天**：旅馆敲门开场，预付金 30，睡眠阻塞直到回应。
- **第 2–5 天**：老街酒馆打听，得知盯梢者用另一个名字找她。
- **第 6 / 12 / 18 天**：三次强制公共交锋（“找上门的人”换皮），到期阻止休息。
  - 交锋一后揭露卖身约与 150 赎身钱，进入 story-stage 2。
  - 交锋二后揭露码头落水命案，进入 story-stage 3;失败会让酒馆停业 2 天、夜莺受伤。
  - 交锋三为了断，成功后她说出真名（story-stage 90），失败则她被带走（story-stage 91）。
- **中途放走**：第 9 天后酒馆出现软选择“她要走”，选“让她走”取消后续公共事件（story-stage 92）。

每个公共小节无论成功或失败，只要状态已经推进就奖励一点成长。
夜莺状态卡（“夜莺安危”Clock + 目标注记）始终让玩家知道“保护谁、下一个坎是哪天、走哪条路凑筹码”。

## 9. 交锋：成长兑现的地方

城市生活里长出来的东西 = 交锋中的准备和动词。三种生活方式共同消耗行动时间，但回报不对称：

- 劳工通过共同劳动和无工资的人情行动获得老周的直接援助。
- 官僚通过文书、走访和具体程序获得一次延期与办案通行证。通行证是最多持有一张、有再次签发冷却的
  一次性物品；当前可在码头交锋中控制压力，未来可由其他地点提供不同的使用行动。
- 富商通过合同、应酬、考察和投资获得延迟收入，并为私货提供高价销路；它增强资源能力，不增加直接战力。

当前码头交锋本身偏向劳工，这是允许的。无路线玩家仍有力量、敏锐、交际和金钱等基础方法。
交锋只返回成功或失败，不按最后手段重写码头政治状态。

第一次交锋另有可选目标「异常货单」。它与主目标争夺骰子；取得后即使本场失败也保留，没能取得
则永久错失。带回城市后可以继续持有，或花时间交给老周、探长、货运代理之一。去向不修改已结束
的交锋，但持续改变人物关系、官方检查或投资条件。
