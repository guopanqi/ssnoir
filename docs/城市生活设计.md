## 0. 设计哲学

游戏是一个**可供交互、可供游览的产品/建筑**，不是电影或文学故事。

- 城市不是关卡，是一台**玩家能读懂的机器**：不同的活法真的产生不同的结果，而且结果可见。
- 玩家愿意投入，是因为他在**设计属于自己的生活方式**。每天分配骰子的模式，会自然沉淀成一种活法。
- 玩家从"工作和生活背后的事情"里，一步步理解这座**美丽而致命的城市**的世界模型（黑色电影 / 马洛的世界）。

核心机制不变：**人物每天有一个行动骰子池，分配到不同地点、不同行动之中。**
骰子从"推进剧情的燃料"变成"你如何度过一天"的表达。

### 0.1 资源互联总纲

> **每种资源至少两个来源、至少两个互相竞争的去处，且去处横跨不同系统。**

判断任何产出是否成立的标准：玩家拿到它时会不会犹豫"用在哪"。
会犹豫的是资源，不会犹豫的是优惠券。由此派生三条原则：

- **跨线依赖优先于全局仪表。** A 线的产出直接做成 B 线的输入（私货→销路、
  情报→投资），比加一个全局状态条产生更强的咬合和更多的故事。
- **恢复要有吞吐上限，而不是加惩罚。** 身体成为真正的第二货币的前提是
  它不能被钱即时无限买回。
- **产能放大是最高级的回报。** 同伴的一颗骰子相当于文明里多一个工人：
  它改变"你的一天有多长"，是唯一会复利的奖励。

当前资源总表（验收基准）：

| 资源 | 来源（≥2） | 去处（≥2，互相竞争） |
|---|---|---|
| 金钱 | 各工作、卖私货、卖货单、投资结算、布告栏委托 | 房租/食物/药/酒、应酬、投资本金、住所升级、首期与赎身钱 |
| 私货 | 走私好/中结果 | 码头散卖（12 金/件，保底）/ 卖给货运代理（25 金/件，需富商脸熟） |
| 情报 | 走私好结果、交锋成功、趁乱搜寻 | 货运公司"凭消息找项目" / 布告栏"打听门路" / 主线"花消息买线索" |
| 药品 | 诊所购买 | 家中用药（每天限一份） |
| 酒 | 家中订购 | 喝酒解压（每天只有第一杯有效） |
| 办案通行证 | 警局办理、交货单给探长 | 交锋程序干预（单一用途，扩展留给交锋改版） |
| 老周同伴骰 | 老周支线第二阶段招募 | 任何城市工作/人物行动（不可用于交锋） |

私货和情报**不能直接按固定价格变成万能金钱**：必须经营另一条路线的关系或
等待限时机会才能兑现更高价值——这就是互联。

日常检验判据：**每天早上分骰子时，玩家是否需要想超过五秒。**

## 1. 一天的循环

```
早晨   掷骰（主角 3 颗；老周入队后 +1）
白天   分配到地点：工作 / 服务 / 委托 / 休息
傍晚   城市结算：涌现事件、势力状态变化（第一版可最简）
夜间   结束一天 → 饱腹 −1、重掷骰；具体睡眠地点另行决定压力变化
```

所有跨回合的持续、冷却、到期和延迟事件都必须对玩家可见。统一使用 Clock 表达剩余时间，
Clock 标题说明状态，备注明确归零或填满后的结果；不能只在脚本里维护隐藏计数器。

时间状态挂在真正负责它的拥有者上。地点冷却和限时工作挂在地点；跨地点可见、会阻塞世界日程的
公共事件由世界协调器拥有并显示在世界根节点。排期到期后不能隐藏 Clock，而要显示为
"已经发生 / 等待处理"，直到玩家处理或事件明确失效。

到期后被定义为"当天必须处理"的关键事件会阻止休息和推进日期。住所中的休息动作直接灰显，
并以标签列出所有尚未处理的原因；玩家必须进入对应事件并完成其实际内容。交锋必须打完，对话必须
完成，选择必须作出，不在阻塞层额外提供"忽略事件"的通用选项。事件无论成功或失败，只要已经完成，
就解除对应阻塞。系统允许多个关键事件同时等待处理。
主线触发的必看对话场景（如夜莺交锋后的真相揭开）同样使用这一阻塞机制，当晚不看完不能睡觉。

## 2. 资源模型

资源分三类，各有其家。总体"一线货币"控制在少数几种，每个动作至少触碰两种，让任何选择都是取舍。

### 2.1 物品（Inventory，可计数）

| 物品 | 作用 |
|---|---|
| 金钱 | 房租、饭钱、赌注制造的底层生存压力。开局 15，刚好交不起首期 40 房租；夜莺预付 30 后喘不过气，迫使你第一天就必须找工作。 |
| 私货 | 走私好/中结果产出；可在码头低价散卖（12 金），或经富商脸熟后卖给货运代理（25 金）。两口构成"六折保底 vs 满额经富商"的对比。 |
| 情报 | 世界知识碎片，可消费物品。三个消费口：货运公司换普通投资项目、布告栏追加一张委托、夜莺主线消耗 1 情报换 1 查访格进度。 |
| 食物 | 吃饭 → 回饱腹 |
| 药品 | 诊所购买，带回住所使用 → 回健康；不占当天行动骰，但每天只能使用一份 |
| 酒 | 住所订购；饮用恢复少量饱腹并缓解压力，每天只有第一杯有效 |

> 具名线索（如"货单编号对不上"）走 global flag，不进物品。
> 情报有两个来源：码头走私线（阴暗面）、警局探长（官方渠道）。
> 工作层级由**关系势力档位**决定（特殊情况可由资产 / 能力），**不消耗情报**。

### 2.2 身体状态（Team / Actor）

| 状态 | 被谁消耗 | 靠什么恢复 |
|---|---|---|
| **健康** | 高风险 / 非法工作的**坏结果**、交锋 | 药品（每天一份），或诊所中消耗行动骰的康复训练。睡觉不回。是最硬的资源。 |
| **压力** | 工作的坏结果（高风险从中性起就可能加）、门口露宿 | 有住所睡觉、喝酒（每天一杯）、公园散步、家里仪式 |
| **饱腹** | 每天睡觉 −1，归零后开始扣健康 | 食物（吃饭） |

压力上限为 4：0–1 点没有系统影响；2–3 点进入「心绪不宁」，所有人物任务判定获得
可见修正 `−1`；4 点仍维持 `−1`，但此后新增的压力会逐点溢出为健康损失。
这使压力影响「一天的行动质量」，健康继续承担更硬的身体账单。

恢复性判定明确豁免「心绪不宁」修正，且坏结果只浪费投入的行动，不会继续制造损失。
公园散步采用坏/中/好为压力 `0/−1/−2`；家中“整理房间”每日一次，投入任意行动骰、
不掷命运骰，固定恢复 1 点压力，作为低质量骰的保底去处。

恢复的吞吐上限（酒、药每天限量）是设计支柱之一：不改数值，只把"钱→身体"的兑换
从即时无限改成每天限量。高风险工作连续做三天后，压力和健康的欠账**当天还不清**，
玩家必须真正安排慢生活（公园、看花、睡觉）——"一边磨损一边回血"的对冲由此成立。
所有上限必须在节点上可见（副标题/置灰），不做隐藏计数。

### 2.3 关系（势力好感，底层连续整数 + 离散档位）

三个势力，对应城市的三种力：

| 势力 | 内涵 |
|---|---|
| **官僚** | 秩序、体面、流程、政府、市长 |
| **劳工** | 生存、暴力、阴暗面、普通人的生活 |
| **富商** | 欲望、享乐、资本、科技、服务 |

底层存连续整数（每次工作小步变化），效果映射到离散五档：

| 档位 | 阈值 | 效果 |
|---|---|---|
| 敌视 | < −6 | 该势力地点涨价、拒接高阶活、惹事概率升高 |
| 冷淡 | −6 … −4 | 服务和机会受限 |
| 中立 | −3 … +2 | 默认 |
| 脸熟 | +3 … +5 | 小折扣、有人打招呼、**二层工作开放** |
| 自己人 | ≥ +6 | **三层（非法）工作**、关系门地点、支线 |

- 普通带薪工作不自动产生关系；只有明确标为“关系工作”的低收益、帮忙或高风险行动，
  才在好结果 +1。中/坏默认不增加；具体坏结果可以降低关系。到脸熟需 3 次成功，
  到自己人需 6 次成功。
- 失败降低哪个势力，不由工作所属势力自动决定，而由具体后果决定：谁看见玩家失手、谁受到损失、
  玩家侵犯了谁的秩序，就降低谁的关系。普通的身体受伤、返工或少赚一笔通常不影响势力关系；
  只有公开失职、背叛或政治性越界才扣关系。例如走私成功且未暴露不会降低官僚关系，被巡警发现的
  坏结果才降低官僚关系。
- 三个势力**互不排斥**：现阶段唯一约束是时间有限，理论上刷不满三边。
- 非法行动必须在副标题或描述标签中点名事败会得罪的势力；关系损失只挂在暴露、失职或
  背叛等具体结果上，不作为行动的固定入场费。
- 关系解锁的地点一旦被发现便永久留在地图上；关系跌回门槛以下时地点置灰，而不是消失。
  敌视可以带来涨价和涌现事件等负面效果，但必须保留至少一条不受关系门槛阻挡的修复行动。
- 势力面板显示当前档位、到下一有效解锁档的差值，以及内容层配置的具体解锁名称。
  非此即彼的对抗留给未来的主线关键选择。
- 玩家看到的永远是清晰的档位，底下是可以慢慢磨的进度。

关系也是跨线耦合的载体：警局"陪探长走访"的证人是码头工人，劳工关系 ≥ 脸熟时
获得可见修正（"码头工人认得你" +1）。这是软耦合——加成而非门槛，不阻塞纯官僚
玩家，但让先混码头的玩家在警局获得可感知、有来由的优势。

### 2.4 个人能力与成长点

主角有四项个人能力，有效范围为 0–4。能力直接加入判定总和，
提高掷骰可靠性，并在交锋中解锁不同的处理方法：

| 能力 | 内部 ID | 主要用途 |
|---|---|---|
| 力量 | `violence` | 劳动、压制、追逐、承受身体风险 |
| 见识 | `knowledge` | 账目、医学、技术、档案 |
| 敏锐 | `sharpness` | 观察、识破、寻找异常、把握时机 |
| 交际 | `social` | 说服、欺骗、交易、威慑、周旋 |

成长点只来自**完成一个不可重复的主线或人物支线小节**，不由重复工作直接刷取。失败若已经让
小节不可逆地推进，也算完成。玩家在人物成长面板中把可用成长点投入任一未满级能力；住所不提供
重复的升级入口。
重复工作负责金钱和势力关系；真正经历完一段处境，才形成个人成长。

### 2.5 人物同伴

老周人物小节完成后，还需要满足一个额外条件才能邀请他成为同伴：把异常货单交给老周，或把
老周信任磨到满格。邀请本身消耗一颗行动骰。

- 老周属性：力量 1、见识 2、敏锐 0、交际 1（账房出身）。
- 入队后的次日开始，他每天在城市模式提供一颗自己的行动骰。
- 同伴骰可以用于工作和人物行动，不能带入交锋。
- 同伴压力达到上限会暂离；在家休息会逐日缓解老周压力，归零后自动归队。
- 交锋中的"请老周出面"仍是独立的具名援助，不使用同伴骰。
  城市里他是同伴，交锋里他是有名有姓的援手，两者语义分开。
- 入队后码头"老周美差"停止刷新——他已经在你身边，不再托人带话。

### 2.6 资产

由玩家拥有的**住所**推导，不做独立数值：

| 住所 | 资产等级 |
|---|---|
| 旅馆（付房租） | 低 |
| 公寓（购买） | 中 |

资产等级是富商圈的隐形门槛（如夜总会看资产而不只看关系），也有故事级回报：
公寓是夜莺主线节拍二的一条保护方案（"藏进你的公寓"）。

## 3. 地点

每个地点 = **一张城市的脸** + **2–3 个动词** + **一个住在这儿的人** + **一个自走的状态**。
地点是"城市向你提的一个问题"。动词分两类：

- **工作**：可重复、掷骰（`roll-action`）、耗状态、产资源。
- **行动 / 服务**：即时（`instant-action`）、花钱换物或服务。

## 4. 工作模型

每个工作按风险分级，掷骰产生 **好 / 中 / 坏** 三种结果（沿用现有 `roll-action`）。
惩罚货币的严重度排序：**钱 → 压力 → 健康**（直接扣健康是全局最重的惩罚）。收益随风险单调上升。

**统一判定规则：**

```text
准备值 B = 放入骰 + 技能 + 修正
B 直接查一张「按值定制的结果分布表」（不再加命运骰求和）。
命运骰 d6 仍摇，只作为在赔率条上的落点，不改变分布本身。

分布表（六面里各档占几面，坏 / 中 / 好），低面更差、高面更好：
  B≤1 : 3 / 3 / 0   —— 五五开，有空间
  B=2 : 2 / 3 / 1
  B=3 : 1 / 3 / 2   —— 均衡
  B=4 : 1 / 2 / 3   —— 均衡偏优
  B=5 : 0 / 2 / 4   —— 显著优势
  B=6 : 0 / 1 / 5   —— 很强
  B≥7 : 0 / 0 / 6   —— 技能+好骰堆出的「干啥都成」
```

**为什么是查表而非两骰求和**：放入骰 + 命运骰两个 d6 相加是三角分布，天然向中间回归，
会把放 1 与放 6 的性格都抹平（"概率对了但没手感"）。查表让每个准备值都有清晰、
独立的性格，同时结算时仍摇一颗 d6（保留"这把会不会中"的悬念）——随机性锚在放入骰的值上，
而不是再赌一颗与之无关的骰子。这贴近 Citizen Sleeper 的分配张力：**你放的那颗骰子就是你的命运**。

技能与修正通过抬高 / 压低 B 来移动你在这张表上的行：**技能就是把弱骰抬成强结果的杠杆**——
新手（技能0）放 1 落在五五开那行；老手（技能4）放 1 → B=5 直接进"显著优势"。
低/中/高风险都不改变分布；风险由各档结果的收益和代价表达。
「非法」是难度标签：因为超越法律边界而固定修正 −2（在表上下移两行），同时通常意味着更高风险与收益。
其他情境修正继续以可见 `modifier` 叠加。玩家放入骰后，卡面用六格**命运条**直接显示当前 B 的
坏/中/好占比（它本身就是一条赔率条）；结算时命运骰 1–6 落在其中一格（引擎实现见 `FateStrip.cs`）。
表中数字可调，结构是关键。

**工作助手**（`工作` / `关系工作` DSL，见 engine.scm）：负责统一结构（req-die + roll）、
断言 faction/risk 合法、生成风险标签，并仅为「非法」注入难度修正；只有 `关系工作` 的好结果
自动增加对应势力关系。**好 / 中 / 坏三个结果由每项工作显式传入**，
避免自动生成固定收益导致所有工作同质化。非法工作失败掉关系，写在该工作的坏结果里（可见）。

**风险提示不推迟**：工作节点 `:subtitle` 直接标注风险（如"高风险 · 可能伤身"），
让玩家行动前就知道"可能伤健康 / 掉关系"，无需先做完整 UI。

| 风险级 | 例子 | 好（成功） | 中（中性） | 坏（失败） |
|---|---|---|---|---|
| 低 | 刷盘子、代写信、跑腿 | +钱（少）+关系 | +钱（更少），无损害 | 轻：+压力一点 **或** −很少钱 |
| 中 | 记账、送外卖、摆摊、调研 | +钱 +关系 | +钱（少），基本无害 | +压力 **或** −一定钱 |
| 高 | 搬运、赌博 | +钱（多）+关系 | +钱（少），**可能小惩罚**（压力 / 钱） | 重：+压力 2，**甚至 −健康 1** |
| 非法 | 走私、替探长办事 | +钱（很多）+关系 | +钱（多），**必有轻微代价** | **−关系（掉档）** ＋压力 / 健康 |

非法工作的中结果不得是纯正收益：至少付出压力、少量金钱、暴露进度或减少产出之一。

这就是"不同活法产生不同的一周"：刷盘子的人平稳、钱少、压力低；扛货走私的人钱多，
但身体和精神在磨损，还赌着关系。

走私是私货链的源头：好结果 +2 私货 +1 情报，中结果 +1 私货，坏结果官僚−2、压力+2。
纸面收益与直接产钱相当（好结果 2×25=50），但满额兑现需要富商线的关系；
不经营富商线的走私者只能在码头散卖拿六折。劳工线由此第一次"需要"另一条线。

### 4.1 工作阶梯（越干越深、越深越看见）

同一地点的工作往下走是一条梯子，越深钱越多、看到的世界越多，门槛用**关系档位**（不消耗情报）：

```
一层  零工     人人可做     +钱 −状态 +本地势力关系
二层  熟手活   需脸熟       +更多钱  世界模型漏出（产出情报 / 具名线索）
三层  非法的活 需自己人     高薪 / 违法  直连主线
```

## 5. 布告栏

布告栏是顶层地点（始终可见），是"选项集动态化"的载体：每三天补充至两张委托，
每张只保留两天，并用 Clock 显示期限。完成或尝试后委托消失；同名委托不会同时出现。
委托报酬刻意高于同风险日常工作（日常约 10–15/骰），过期即失——
这是"今天要不要为它挪一颗骰子"的来源。

当前模板池（5 张）：

| 委托 | 要求 | 判定 | 报酬（好/中/坏） |
|---|---|---|---|
| 帮人寻物 | 占 1 骰 | 敏锐 | 22 金 / 12 金 / +1 压力 |
| 替人带话 | 占 1 骰 | 交际 | 20 金 / 10 金 / +1 压力 |
| 押送一批货 | 占 1 骰 | 力量 | 25 金 / 14 金 / +1 压力、−1 健康 |
| 代查一笔账 | 占 1 骰 | 见识 | 22 金 / 12 金 / +1 压力 |
| 有人需要药 | 持有药品 | 无（即时） | 20 金 + 劳工关系 +1 |

常驻行动"向消息灵通的人打听"消耗一份情报，不占骰，立即增加一张额外限时委托
（超出两张上限也允许，仍有各自期限）。在板委托与剩余期限随存档保存。

## 6. 主线：夜莺委托线

详细设计见 [夜莺主线设计.md](夜莺主线设计.md)，交锋内容蓝图见
[夜莺交锋设计.md](夜莺交锋设计.md)。此处只记录它与城市系统的关系。

结构：**故事提出具体账单 → 城市生活提供多种解决方式 → 完成账单打开新的城市结构。**
三个节拍是三张到期账单（第 4 / 10 / 17 天）：查出盯梢者的落脚处、给她弄到一种临时保护、
备好一种了断方案。每张账单都有横跨不同生活线的多条抵达路径（钱可以买、关系可以换、
程序可以压、拳头可以抢）；交锋是结算方式之一，不是节拍本体——要么嵌在抵达路径里
（你主动上门），要么是账单未清时的后果（他们找上门）。

对城市系统的意义：

- 主线是存量的**水槽**（首期 60、赎身钱 150/90 给"攒大钱"以意义），同时是经济系统的
  **扩张器**（每拍结算打开新工作、新节点、新场景）。
- 每个节拍无论成功或失败，只要状态已推进就奖励 1 成长点（成长点的主要来源）。
- 夜莺状态卡常驻账单行，让玩家每天早上能回答"我现在缺什么、到期日是哪天、
  我打算用哪种活法把它办成"。

## 7. 交锋：成长兑现的地方

城市生活里长出来的东西 = 交锋中的准备和动词。三种生活方式共同消耗行动时间，但回报不对称：

- 劳工通过共同劳动和无工资的人情行动获得老周的直接援助。
- 官僚通过文书、走访和具体程序获得一次延期与办案通行证。通行证是最多持有一张、有再次签发冷却的
  一次性物品；当前可在码头交锋中控制压力，未来可由其他地点提供不同的使用行动。
- 富商通过合同、应酬、考察和投资获得延迟收入，并为私货提供高价销路；它增强资源能力，不增加直接战力。

当前码头交锋本身偏向劳工，这是允许的。无路线玩家仍有力量、敏锐、交际和金钱等基础方法。
交锋只返回成功或失败，不按最后手段重写码头政治状态。

第一次交锋另有可选目标「异常货单」。它与主目标争夺骰子；取得后即使本场失败也保留，没能取得
则永久错失。带回城市后可以继续持有，或花时间交给老周、探长、货运代理之一。去向不修改已结束
的交锋，但持续改变人物关系、官方检查或投资条件。

交锋结算与城市之间**不做暗线耦合**：玩家事先看不到、也无法决策的隐形奖惩
（如结算后自动加钱/加关系、隐形保险）不算真正的耦合，一律不做。

## 8. 城市涌现事件（暂缓）

每回合结算（或开始）有概率从可用事件堆抽取随机事件，在某些地点产生变化。
第一版可以不做，或只做最简单的一两个。

## 9. 已裁决移除的设计（防止回潮）

以下设计曾实现或规划过，经"简洁、凝练、必要"审查（2026-07-10）裁决移除。
记录在此是为了未来不再以同样的形态回潮：

| 设计 | 移除理由 |
|---|---|
| 银行 | 取消利息后它是无风险保管箱，现金没有任何丢失风险，纯占位休眠，不构成真正的去处。 |
| 货运保险 | 15 买 20 赔的期望值教玩家"系统不值得认真对待"。 |
| 豪宅档位 | 唯一效果是副标题承诺，`资产="高"` 全仓零消费方，睡眠恢复与公寓相同。旧档读档映射为公寓。 |
| 布告栏"急收私货的买家" | 私货已有两个换钱口，第三个同类模板对无私货玩家是常驻置灰噪音。 |
| 码头风声（走私冷却） | 依赖已删除的暗线耦合，玩家无法决策。 |
| 交锋→码头暗线耦合（`on-public-event` 自动奖惩） | 玩家事先看不到、无法决策的隐形奖惩不是耦合，是旧骨架残留。 |
| 探长担保（隐形失败保险） | 玩家从未主动决策，只在失败时自动消耗；官僚线可见回报收敛为通行证 + 延期两个工具。 |
| 全局仪表（官方关注、货运行情） | 跨线依赖优先；等现有互联全部验证后再评估。 |
