# 第一节：照相馆演出交接

已按 Claude 的 `22-photo-develop.js` 与 `23-photo-source.js` 接入线绘剧场。保留布景、道具、事件与对白顺序；不新增剧情、收费、等待日或交锋。

接入文件：`UnityClient/Assets/Resources/Content/scenes/world/照片委托.scm`。
`develop-script!`、`source-script!` 调用 `scripts/theatre/照相馆.scm`。物品、费用、阶段变化与交锋启动仍由调用者拥有，演出不重复结算。

入口为 `(照相馆冲印-演出 #t)`（两卷）、`(照相馆冲印-演出 #f)`（一卷）与 `(照相馆查来源-演出)`。调试菜单中可分别试演。尼尔复用基础／伸手立绘，店主复用普通男性立绘；网页骨骼和面部动画以姿势、走位与停顿表达。门铃、写单、滴水等 WebAudio 提示声已离线生成，源脚本为 `tools/theatre/generate-photo-shop-sounds.py`。

## 一、冲印与发现压纹

触发：点击照相馆「冲印照片」。花费$5并投入家庭胶卷；有取证胶卷时一同冲印。无需换日。

空间：照相馆柜台，店主在柜台后；柜台上有胶卷、取件单和相纸样片。气氛普通而略显冷淡，尚未发生对抗。

1. 尼尔把胶卷放上柜台。有取证胶卷时放两卷。
   - 两卷：尼尔：“这卷替我洗出来。还有这一卷。”
   - 一卷：尼尔：“这卷替我洗出来。”
2. 店主收下，写取件单。短暂停顿后把单子推回来。
   - 店主：“拿着取件单，别丢了。”
3. 用一次简短的画面过渡表达冲印已完成，仍在同一次访问内。不增加等待玩法。
4. 尼尔接过照片，翻到背面；视线停留在压纹上，再看向样片。
   - 尼尔：“我能看看你们的相纸吗？”
   - 店主：“喏，最好的纸张。”
5. 店主递出样片，尼尔轻轻摸过背面。
   - 尼尔：“这背面的压纹，是原来就有的吗？”
   - 店主：“嗯，应该是吧。”
6. 尼尔若有所思，内心独白：
   - “夜莺给我看的那张照片背面，好像也有这个。”

演出结束：获得家庭相片；有取证成果时取证胶卷转换为亲密相片。酒馆开放「交付调查」，照相馆开放「查照片来源」。相纸相似只是待验证推论。

## 二、查照片来源

触发：点击「查照片来源」。先演出，再进入「照相馆交涉」；开场归城市侧，交锋侧不重复演出。

1. 尼尔回到柜台，把勒索照片放在店主面前。
   - 尼尔：“老板，我这儿有张照片想请你看看。”
   - 店主：“要洗照片吗？”
2. 尼尔没有取出胶卷，手指轻压照片边缘。
   - 尼尔：“我只是问问，这张是不是也在你们这儿洗的？”
3. 店主看一眼，目光移开，手停在照片旁，迟疑。
   - 店主：“这、这我怎么知道……”
4. 店主收起方才的敷衍，恼火地看向尼尔。
   - 店主：“你到底想问什么？”
5. 演出结束，进入既有交锋。不要提前展示订单、取件人或调查结论。

## 三、交锋之后（已接入，无需制作额外演出）

A、A1、B、B1均为6格。每完成一层，使另一条路线判定点数+1，最多+2。两条路线全部完成才成功。

成功：获得「冲印记录抄本」。小幅六张，星期二傍晚取件；取件者是染金发的年轻男人，穿着不合身的邮务制服；姓名未知。该描述不直接证明取件者就是勒索者。

尼尔内心独白：
- “六张。星期二傍晚。一个头发染成金色的男人，不合身的制服。”
- “我得跟夜莺谈谈了，看看这件事到底怎么办。”

失败：不发放线索，不触发额外事件。
- “还是没能查出点什么。”
- “照片这条路行不通的话，还是得按信上的来。”
- “尼尔，你要冷静，你需要想想其他办法。”

成功后，酒馆出现「与夜莺商量」，使用 Dialogue：
- 尼尔：“洗照片的地方找到了。”
- 夜莺：“那他人呢？”
- 尼尔：“还不知道。不过，我有他的一点线索了，我应该能找到他。”
- 夜莺：“那封信呢？”
- 尼尔：“……”

到此停止。不得继续设计抓捕、设局或夜莺的回应。
