我还从视觉上这设计，美术设计上学到一个概念。比如说他们有时候会把所有的人物都放在一起去观察他们相对的情况。另外还有一个就是美术上面的投影，就是他们会把它只做成一个黑影的样子，然后去看它在轮廓上的辨识度。

我觉得有时候我也会把这游戏中所有人物放在一起，看他们的性格，他们的故事。而且我认为在我现在这个游戏中，时间轴为一个时间轴去，不同人物去分布他们的时间线、故事线，其实也是一个很好的，能让我从更高的尺度上去观察这些东西，去理解整体，而不是关注每一个细节。你说的对，就是越高分辨率越接近成品的东西，它的噪音就越多。就是你经常会感觉这个东西这么多内容，你不知道是哪里产生了作用。而一种投影的办法有助于去你去了解它的某一方面。比如说一种卡牌的原型，对于我们现在在做的游戏而言，是一种失去大部分资源的投影。这个东西能表现游戏的决策、选择、利益得失等等东西，但是它同时也缺少了很多空间、情景、人物、感情这些东西。一种写在纸面上的故事，它缺失的东西会更多，但是它非常干净，它能够让你专注在对白，语气，故事情节发展。

唉，游戏开发还是太复杂了。

草稿是一种绝佳的东西，原型也是。如果没有那个2D的卡牌原型，我们的交锋机制恐怕难以实验，难以聚集想法。
如果我现在不能专注于这个纸面上的故事，那我觉得我就像过去一样，永远也无法专注，无法捕获这个作品里最核心的东西。
每次我一打开Unity就是有无数的细节可以改进，于是所有的时间都花在这些细节上，抛光上面。
