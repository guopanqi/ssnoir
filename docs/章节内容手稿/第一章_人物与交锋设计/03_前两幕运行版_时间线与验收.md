## 已接入的内容边界

- 大船 `encounters/大船靠岸.scm`：卸货 Clock、吊索风险、天亮前收工、结束后报酬；不需要玩家加入才能让码头工资事件发生。
- 艾迪 `encounters/少了十块钱.scm`：一条查证目标、一条停班威胁、证人退缩转折；长期结果为在岗/停班。
- 夜莺 `encounters/赞助人试演.scm`：争取完整表演时间；两种演出时长，两种情况下她都主动赢得掌声。
- 经理 `world/第二幕生活.scm`：演出服4格，可查找或花钱补足，45美元回报。
- 露西 `world/第二幕.scm`：四格代班，自己也会努力；入学／延后。
- `scripts/theatre/第一幕对白.scm`：D8 已用剧场 DSL 表现两段演唱；`world/第二幕剧院.scm` D10 夜宵独立于报酬。

## 需要验证的实际路径

1. **不参与**：一路工作/恢复到 D13，不能被可选故事阻止生活，公共事件都发生。
2. **旧街/艾迪**：参与大船、走风险或安全策略；D10 查证到中段看到证人退缩，可通过其他办法完成；也能主动放弃，检查艾迪位置变化及送手套。
3. **剧院/夜莺**：D8 演出实际能播音乐，D10 夜宵可以主动见到，D11 两种演出时长都能正确结算，D13 宣传与测绘不重复播两次。
4. **经济**：演出服同一进度混合骰与金钱；露西顶班与请人代班混合投入；房租、恢复不会造成软锁。
5. **存读档**：D9 大船结算不能重复领钱；D10/11 事件状态读档后不重放；D13 公共标记不重放。

**自动测试**：`Game/tests/second-act-relations.ts-test.mjs` 与原生内容验证工作流。须以 GitHub Actions 的实际最终结果为准；已写脚本或括号结构检查不能代替运行验收。

**待制作**：港口及剧院的正式美术/声音审核、玩家体验与数值分布验收、第三至第五幕。没有完成就保持此状态，不把结构目标写成既成效果。
