## 运行时结构

- `scenes/world/第一幕.scm`：世界第 1–6 日；工作中认识夜莺、艾迪、露西；第六日酒馆告别；第八日首次正式彩排仍由它负责结算
- `scenes/world/第一幕同行.scm`：第 3–5 日可拒绝的雨夜请求；**必须先在酒馆和夜莺有过一次真正的相处**，未相识不会弹私人请求
- `scenes/world/码头.scm`：普通搬运、每日可见搭档和艾迪失手帮忙；不再有邮箱、取信调班及勒索推进
- `scenes/world/第二幕.scm`：艾迪的十块工资纠纷（第9–11日）、露西的夜校报名（第9–12日），均有独立日期窗口
- `scenes/world/第二幕生活.scm`：第七日开放旧街与剧院新日常；旧街提供食堂、每日救济餐、牌桌和跑腿；剧院提供临工与经理初见；旧码头工作可引导玩家去食堂（非强制解锁）
- `scenes/world/第二幕余波.scm`：十日之后在原本工作的地方再次遇见两人；接受帮助与自己解决会有不同对白
- `scenes/world/第二幕剧院.scm`：第一次彩排后夜莺的主动关心、两种唱法、赞助人复排与旧港宣传稿
- `scenes/world/第二幕公告.scm`：联合公告之后，码头、咖啡馆、剧院分别有反应；尼尔对夜莺的回答留为跨幕事实
- `scenes/encounters/雨夜同行.scm`：回家进程与夜莺恐惧双钟，单次人影障碍及听她指路
- `scenes/encounters/少了十块钱.scm`：工资进度、争执升级、艾迪工作风险与不同解决方法
- `scenes/encounters/赞助人试演.scm`：四格试演倒计时，修理、找替代伴奏、争取清唱；如果不介入/没来，夜莺自己唱完

登记统一位于 `scenes/world/模块清单.scm`，世界加载位于 `scenes/world/world.scm`。

## 需要手动验收的四组游玩路径

1. **只生活、不交朋友。** 从家出发，仅靠工资维持生活，连续换日直到第十三日。不得被雨夜、工资争执、夜校报名或彩排锁住；世界大事照常发生。
2. **第二幕扩张路线。** 第七日直接进入旧街，用一枚骰领取救济餐，再选择食堂、牌桌或跑腿；直接去剧院做一次临工，确认经理初见；回码头工作后再走艾迪引路路径。两条入口都应成立。\n3. **夜莺路线。** 第一至三日去酒馆工作，在第 3–5 日接受雨夜，分别试玩顺利抵达、恐惧满格叫车。第六日告别，到第八日彩排；对比不认识她的版本。
4. **工友/咖啡馆路线。** 码头首次搬运得到艾迪帮助，反复工作认识他；在工钱交锋分别拿回工资/保住工作/退出。咖啡馆帮露西顶班、付代班费和不参与，十日后检查每个人的继续生活。
5. **剧院路线。** 第八日初次正式彩排；第九日选择不同唱法；第十日复排分别修好、换乐手、争取清唱或不在场；十三日联合公告后，再问夜莺怎样看旧港。

验收重点：**玩家投入时间以后能认出人物，并能从他人的自发行动理解情感，而不只是记住完成了哪个时钟。** 不应通过简单好感数值或剧情锁强迫玩家达到该效果。

## 边界与未完成

- **前两幕是可运行纵向样本，不等于五幕全部实施。** 第三幕「工作机会与老街的冲突」及后续转折仍需正式改写和接入；旧第二章调试代码与支线保留用于独立旧系统验证，并非新第三幕剧情。
- 美术分镜、演唱、镜头与大量对白目前使用基础脚本/舞台落点，不代表完成正式演出制作。
- 一部分早期剧情测试已按退役主线更换；必须以 `Game/tests/first-act.ts-test.mjs`、`Game/tests/second-act-relations.ts-test.mjs` 和 `SSNoir Phase 2 Authored Runtime Contracts` 为新行为的基本回归入口。
- 从旧《三封信》阶段的旧档不能保证迁移，应在当前版本创建新档试玩。
