# SSNoir 第一幕《活下去》——剧场演出与对白初稿 V0.2

> **状态：供作者修改的第一版，不是最终定稿，也不是已批准实施的台词。**
>
> **配套设计：** [`01_第一幕_活下去_内容网络与交锋.md`](./01_第一幕_活下去_内容网络与交锋.md)。主稿负责时间、行动、触发、交锋与资源结算；本文负责剧场、角色动作、对话与状态变体。二者有分歧时，先交由作者裁决，不由实现 Agent 自行调整剧情。
>
> **叙事基调：** 黑色电影，但不让每个人都讲漂亮台词。生活场景轻松、简短、有烟火气；夜莺的魅力主要通过舞台和两人相处呈现，而非主动解释自己有多迷人。尼尔是自由接活的人，**不预设有侦探执照或侦探职业认同**。
>
> **剧场制作边界：** 重点用固定机位、有限角色动作与简短对白。长交锋的每次行动用一两句反馈，不要每掷一次骰都播放完整 Cutscene。歌唱只写表演与音乐意图；**歌曲旋律、歌词、配音均未定**，不得把本稿中的指示文字当作正式歌词。场景时段是戏剧时段，按既有抽象日循环处理，不额外创造真实时钟机制。

## SC-A01｜旅馆清晨（固定）

**地点**：廉价旅馆单间。  
**演出**：约 8–12 秒固定机位，接一个简短对白或独白；不要铺陈大段身世。

（窗帘没拉严，天光落在桌上的几枚零钱上。尼尔坐在床沿系鞋带。桌上压着一张房租单。他数过钱，还是把一枚硬币从左边移到右边。）

尼尔：这点钱……

（门外有人敲了两下。）

旅馆老板（门外）：房钱别忘了。

尼尔：没忘，我过两天给你。

（门外脚步声走远。尼尔拿起外套，看到袖口破了一点，又把它放下。）

尼尔：还是先去酒吧打听打听吧。

**进入游戏后的可见信息**：旅馆的休息、恢复、房租规则；前往酒馆的引导。此场景不强制玩家承诺做侦探，也不设定人生梦想。

## SC-A02｜固定开场：酒保与夜莺初次亮相

**地点**：酒馆，吧台与小舞台。  
**性质**：所有玩家必经的公开亮相，**只产生「听说/见过夜莺」这一事实，不自动产生私人关系**。

（酒馆还没坐满。酒保擦着玻璃杯。）

酒保：又没活儿了？
尼尔：有就不来问你了。

酒保：码头，咖啡馆都有零工可做 。

尼尔：你这儿呢？

酒保：还是和以前一样，看场子，有人闹事就你来处理。至于平常的工钱，你知道。

（舞台那边有人试了一下麦克风，发出短促的噪声。酒保朝台上看了一眼。）

（追光亮起。夜莺站在小舞台中央。她轻轻扶正麦克风，等伴奏过了两小节，开始演唱。镜头保持稍远的位置，先展示舞台与观众，不急着特写脸。末尾才给一个侧面的近景：她听见台下的掌声，露出短暂的笑。）

尼尔：她是谁？

酒保：夜莺。就快去大剧院了。

尼尔：那里会要我们这儿的人？

酒保：也许是她唱得好吧。

（夜莺向乐手点头，继续下一段。酒保收走尼尔面前的空杯。）


**玩家离开酒馆时的界面呈现**：咖啡馆、码头、酒馆工作均已开放；

**舞台制作说明（建议，不是固定资产要求）**：一束硬光、两三个观众剪影、乐手的手部动作即可；不需完整歌曲或复杂嘴型。此处让表演本身承担吸引力，酒保不替玩家评价她美不美。

## SC-A09a｜夜莺：台边的一句话

**触发：** 第一次在酒馆工作后，夜莺仍在台上准备或刚唱完。不另扣骰；第一次失败也能遇见她。

（尼尔正把椅子推回桌下。台上的乐手在收谱。夜莺抱着一叠纸走过来。）

夜莺：麻烦让一下。我总觉得自己要从这里掉下去。

尼尔：台阶就在那儿。

夜莺：我知道。就是每晚下来的时候都觉得比上台更难。

（尼尔让开，她轻轻提起裙摆，下了最后一级。）

夜莺：你是新来的？

尼尔：哪里有活就在哪里做。

夜莺：那你今天挑中了最吵的地方。

（她把一张掉下来的歌谱拣起，朝尼尔笑了笑。）

**结果事实：** 两人在酒馆私下说过话。她还没有任何理由叫尼尔帮忙调查。

---

## SC-A09b｜夜莺：收工后坐一会儿

**触发：** 已发生 A09a，夜莺仍在酒馆的另一个晚上；玩家选择留下短暂交谈，可设明确的时间机会成本。拒绝不扣关系、不补播「一起坐过」的记忆。

（最后一桌客人离开。夜莺端着一只盘子，从后台出来，坐在靠门的桌边。）

夜莺：你也还没走？

尼尔：酒保还没给我结账。

夜莺：那我们都是等人发钱的。

（她掰开手中的面包，吃了一小口。）

尼尔：去了大剧院，还会吃这个？

夜莺：到了那儿再看吧。我可不指望他们管我晚饭。

（外面路灯亮了。夜莺看着街道，很安静。）

夜莺：我在这里唱了好些年。有时候真想快点走；可真要走了，又有点舍不得。

**可选回应：**「总会回来看看」／「换个好地方是好事」。没有标准正确答案。

**结果事实：** 两人真正谈过夜莺离开酒馆的心情，雨夜邀请可因此更私人。未参与的玩家不获得这段经历。

## SC-A09c｜夜莺：她也替尼尔解围

**触发：** 夜莺在酒馆、尼尔刚处理过看场麻烦或遭到客人轻慢时的首次合适机会。仅一次，不重开交锋、不额外覆盖既有结算。

（喝醉的客人朝尼尔摆手，语气很冲。）

客人：哎，叫你呢，干杂活的。

（夜莺从一旁走来，顺手拿走客人桌上的空酒杯。）

夜莺：他今天忙了很久。您要续杯，我来叫酒保。

客人：我没跟你说话。

夜莺：那这杯就先不给您续了。

（客人不再说什么。她转身朝尼尔扬了扬眉。）

夜莺：你刚才不用一直听他骂。

尼尔：我挣的是这份钱。

夜莺：也不用把每句话都算进去。

**替代触发：** 如果没有发生轻慢事件，可在尼尔冷静低或受伤时，用很短的问候代替上述解围，不得虚构客人冲突。

夜莺：你今天看起来很累。

尼尔：还好。

夜莺：你每次都说还好。

（她让尼尔坐下，自己去给他倒了杯水。）

**核心：** 她能看见尼尔的不容易，不仅是一次请求保护的人。场景不直接恢复冷静，以免与酒馆付费恢复混淆。

## SC-A04｜露西初识：今天又在哪里上工？

**地点**：咖啡馆。  
**触发**：第一次完成咖啡馆工作。工作收入与判定先正常结算，随后播放短片段，不另扣骰。

（尼尔端着托盘经过桌边，露西站在收银台后数零钱。她看了看尼尔的外套。）

露西：你是新来的？

尼尔：嗯。

露西：只干今天？

尼尔：看老板明天还要不要我。

露西：只要你没摔盘子就行。

（露西伸手接过托盘上晃动的杯子，放稳。）

露西：先学会把杯子摆平。

（露西笑了）

**衣服观察句按事实替换，不能强行假定玩家已经去过码头：**

- `[玩家此前做过码头搬运]` 露西：你之前在码头干过活？袖子上还有煤灰。
- `[玩家尚未做过码头搬运]` 露西：你以前干什么的？看起来不像常端盘子的人。

尼尔（接上相应分支）：哪儿有活儿就去哪儿。

露西：那你挺忙的。明天要是还来，记得从后面拿托盘，别挡住客人。

（她拿起一只杯子继续擦。没有刻意停下来等尼尔答复。）

**结果事实**：见过露西；她认得尼尔的脸。没有职业崇拜、没有立即求助，没有强行给玩家恢复道具。

## SC-A05｜露西再次相遇：字母和咖啡

**触发**：认识露西后，再次到咖啡馆工作或短暂停留；只演一次完整对话，之后换短闲谈。

（露西低头在一张报纸背面写字。听见开门声，她很快把纸倒扣过来。）

露西：你来了。今天还是端盘子？最近有没有别的活儿？

尼尔：没有，老板肯给钱，我就能干。

露西：那你会打字吗？

尼尔：不会。怎么？

露西：我想学。城里有个夜校，教打字和记账。我以后想找一份不用站一整天的活儿。

（她把纸翻回来。上面抄着一行歪歪斜斜的字。）

尼尔：这字不是挺好的吗？

露西：这是用笔写的。打字机可不管你写得好不好看。

（外面有人喊点单。露西把报纸夹进抽屉，跑去招呼客人。）

**后续短闲谈，第二次完整片段之后才可出现：**

露西：今天别把杯子摔了。老板还记得上回呢。

或

露西：学校的事还没定，我再攒一阵钱。

**结果事实**：知道露西想学打字。这里不生成「帮她交学费」任务；她的报名机会在第二幕另行发生。玩家晚认识时也能够自然得知这一点。

## SC-A06｜艾迪初次解围：一只太重的箱子

**地点**：码头，货箱通道。  
**触发**：第一次完成搬运工作；不要求失败才能触发。**本次救场可按照主设计稿减少一点坏结果冷静损失，须在动作效果条中如实结算与显示**；不要再用旧版『只演出、不改变资源』规则。

（尼尔拖动一个木箱，箱子卡在地板接缝里。工头朝这边喊。）

工头：别堵着路！后面还要过车！

（艾迪走过来，先把旁边一只空木箱踢开。）

艾迪：你让开点。

### 好结果变体

（尼尔已经把箱子一端抬了起来。艾迪搭上另一端，两人顺手搬过去。）

艾迪：不错嘛，第一天就知道找省力的办法。

尼尔：我只是怕砸着脚。

艾迪：那也是个办法。

### 中结果变体

（尼尔好不容易搬过通道，艾迪替他把绳结重新系紧。）

艾迪：下次先绑好，省得一路追箱子。

尼尔：你们都这么干？

艾迪：会搬的人都这么干。

### 坏结果变体

（箱角猛地滑下，艾迪从旁边顶住。箱子落地，尼尔喘了口气。）

艾迪：手先松开。别跟一只箱子拼命。

尼尔：我差一点就搬起来了。

艾迪：差一点和搬起来，是两回事。

（他朝工头摆手，示意通道马上清空。原判定已有的损失仍照常结算。）

### 三种结果的共同结束

艾迪：第一次来？

尼尔：有这么明显？

艾迪：太明显了。

（艾迪一边说一边拿起下一根绳索。）

艾迪：我叫艾迪。明天来得早，站我那边，别去跟那几个老家伙抢活儿。

**结果事实**：艾迪先给出善意，而不是立刻向尼尔发布人物任务。不强制称呼「大侦探」，主角没有固定侦探职业。

## SC-A07｜艾迪再次招呼：今天赚多少

**触发**：认识艾迪后，再次与艾迪在码头同一班工作。搭档应在投骰之前确定并可见，短片段不重复播放。

（尼尔走到货栈前。艾迪正在吃东西，看见他便抬了抬手。）

艾迪：嘿！又来了。

尼尔：昨天不是你让我来的？

艾迪：我叫你站我这边，没叫你天天来。

尼尔：工钱比别处高。

艾迪：那你算来对地方了。

（艾迪把吃剩的一小块面包递过去。尼尔还没接，他就收了回来。）

艾迪：算了，沾灰了。下班请你吃点好的。

**如果尼尔先前有码头工作伤势或严重疲劳，可替换一句：**

艾迪：你那只手还好吧？今天别搬最大的。

**结束**：艾迪转回工作。此时尚未强制安排下班邀约，先让玩家感觉这个人记得自己。

## SC-A08｜艾迪的下班邀请

**触发**：艾迪相熟后，玩家再次收工。邀请明确是当天收工以后，可选择参与或拒绝；参与占用主稿规定的行动机会。

艾迪：今天下工以后去酒馆坐坐？

尼尔：怎么突然请我？

艾迪：你今天搬了半天货，怕你回去还梦见箱子。

尼尔：我可没替你数。

艾迪：你看，都开始记不清了。该喝一杯。

**玩家选择：**「去坐一会儿」／「改天吧」。

### 接受：酒馆一小段

（两人在靠墙的小桌旁坐下。艾迪把两只杯子推过来。）

尼尔：你每天都来？

艾迪：手里有钱就来，没钱就在门口跟人打招呼。

尼尔：听着也挺忙。

艾迪：你以为认识这么多人是白认识的？

（酒馆里有人冲艾迪打招呼。艾迪挥挥手，又压低声音。）

艾迪：以前我还打过拳。

尼尔：打得怎么样？

艾迪：他们现在都不肯跟我打了。

尼尔：为什么？

艾迪：怕我赢。还有一次是怕我输得太难看。

（尼尔笑了。艾迪举起杯子。）

艾迪：行了，不说我的英雄往事。你呢？打算一直这样到处找活儿？

**可选回答，不设正确答案：**

- 「先把这个月的房租交了再说。」
- 「碰上什么好机会，就做什么。」
- 「总得找点像样的事做。」

艾迪（通用回应）：也对。先过完这个月。

（两人碰杯。远处酒保喊艾迪结清上回的账，艾迪装作没听见。）

**关于喝酒的机制边界**：这段演出本身不自动视为玩家购买一次恢复服务；除非主稿明确规定，不额外给冷静恢复，也不默认支付 15 金。

### 婉拒

尼尔：今天不行，还有事。

艾迪：行。下次我逮着你再说。

（艾迪没有生气，拎起外套走了。）

### 接受后失约

（下次在码头遇见。）

艾迪：那天没等到你。

尼尔：临时有事。

艾迪：下回提前说，我还以为你在跟哪只箱子决斗。

### 晚认识或没赶上邀请

不补播已经过去的酒馆小聚。后续仍可触发艾迪正常的工作闲谈，第二幕可以有新的、不同的相处机会。

## SC-C01｜酒馆短交锋：《赖账的客人》

**触发**：早期某次看场工作之后；玩家可选择不介入。  
**结构**：收回应付款 → 交涉失败使「闹大」升级 → 玩家决定止损、安抚或继续施压。  
**表现原则**：酒保是一个忙碌、熟悉这类麻烦的人，不把普通赖账拍成黑帮大战。

### 开场

（酒保正在结账。一名喝得脸红的客人把账单推回桌上。）

客人：这不是我点的。

酒保：你坐了一个晚上，这三杯是谁喝的？

客人：我只点了两杯。第三杯你自己送的。

（客人把空杯往桌子上一放，声音很响。酒保转头看向尼尔。）

酒保：你来一下。

尼尔：怎么了？

酒保：他不肯结账。你要是愿意管，收回来的钱有你一份。

**玩家选择**：「过去看看」／「让酒保自己处理」。

### 不参与

尼尔：今天不想碰这个。

酒保：行。你忙你的。

（酒保把账单放回客人面前，招呼另一个伙计过去。）

**演出结果**：不给额外报酬，但不惩罚、不关闭酒馆。

### 交锋进行中：三类行动反馈

**核对账单**

（尼尔将账单与桌上的空杯对照。）

- 进展：尼尔：三杯。账上没多写。／客人：……那你们得把价钱说清楚。
- 未取得进展：客人：你又是谁？轮到你来算我的账？

**好好说话**

（尼尔把椅子拉开，站在客人视线里，没有碰他。）

- 进展：尼尔：把钱放下，这事就过去了。／客人：你说得倒容易。
- 未取得进展：客人：你们是不是看我喝多了，想多收钱？

**直接施压**

（尼尔把账单按在桌上，挡住客人起身的方向。）

- 进展：客人：行行行，别拉扯，我给。 
- 风险增长：客人：你敢碰我？

### 危机打断：「闹大」到达阈值

（客人猛地站起来，碰翻一只杯子。旁边两位客人转过身，其中一人走近。）

同伴：怎么回事？

客人：他们不让我走！

酒保（隔着吧台）：杯子算我的。别碰桌子。

**此时行动目标从“讨回钱”扩大为“别让酒馆失控”。玩家可选择：**

- **先安抚**：尼尔：都坐下。先把账算清楚，谁也不用难看。
- **继续硬来**：尼尔：他欠的钱还没付。你要替他付？
- **退出并交给酒保**：尼尔：我管不了了。／酒保：那就让开，我来。

**动作说明**：若判定造成轻微碰撞，可表现为椅子后退、杯子破碎或推搡；第一次教学不安排严重枪械冲突或未知帮派介入。

### 结算与酒保反应

**全款收回，现场未闹大**

（客人把钱压在桌上，嘟囔几句后离开。）

酒保：行，省了我一场麻烦。

尼尔：就这么简单？

酒保：你还想怎么样？

**收回部分赔偿，客人离开**

酒保：（数钱）少了点。算了，桌子还在就行。

尼尔：人跑了。

酒保：人不跑，明天还来闹。

**闹大之后才解决**

（酒保拿扫帚扫碎玻璃，抬眼看尼尔。）

酒保：下回先动嘴，别先动手。

尼尔：是他先碰的。

酒保：我说的是下回。

**玩家退出或未能解决**

（酒保回到吧台，接着清点玻璃杯。）

酒保：没事。这样的客人每个月总有几个。

尼尔：抱歉。

酒保：下次愿意管，再叫你。

**状态边界**：全款、部分、闹大、退出只消费主稿给出的奖励/损失；酒保不会因为一次失败永久剥夺看场机会。记录玩家采取的处理方式，用于以后偶尔一句合情合理的闲谈即可。

## SC-A10｜夜莺的请求：今晚能陪我走一段吗？

**触发**：第 2 天左右，由酒保转达夜莺当晚需要人陪同；提前公开当晚的机会与预计行动花费。夜莺可和尼尔私下说话，但不假设他们已经相熟。

### 普通初识版本（此前仅看过舞台演唱）

（酒保看见尼尔走进来，向后门点头。）

酒保：夜莺今晚一个人走。后巷最近总有个家伙站着看，你要有空，陪她走一段？

尼尔：她认识我？

酒保：现在不就认识了。

（夜莺刚换下演出外套，站在后门边等。酒保简单介绍两人。）

夜莺：不好意思，突然麻烦你。

尼尔：有人在跟着你？

夜莺：不太确定。最近有两次，我回头，他还在那里。

夜莺：你不用替我找人。陪我走到住处就行。

### 此前与夜莺有过私人交谈的版本

（夜莺主动走到吧台，看到尼尔便停下。）

夜莺：你今晚忙不忙？

尼尔：怎么了？

夜莺：我不想一个人走回去。

尼尔：出了什么事？

夜莺：也许什么都没有。就是后巷那个人，我又看见了。

夜莺：你能陪我一段吗？

### 玩家回答

**「我陪你。」**

夜莺：谢谢。我收拾一下，马上来。

（她把围巾绕好，走到门边。随后进入雨夜同行的约定/准备窗口。）

**「今晚不方便。」**

夜莺：没关系。我再问问乐队的人。

（她没有失态，也没有指责尼尔。）

**答应之后失约**

（夜莺等过约定时间，最后把围巾系紧，向酒保说了几句话，跟另一位工作人员从亮着灯的大路走了。）

**可见后果**：明确夜莺另找了办法，没有因玩家不参与受到必然伤害。玩家下次见面时可以提起这件事；不能播放「两人共同走过雨夜」的经历。

## SC-C02｜主要交锋：《雨夜同行》

**情感命题：** 怎样让一个害怕的人，感受到和你待在一起是安全的？

**地点：** 酒馆后门 → 灯火街道 / 暗巷 → 路口 → 夜莺住处。**机制：** 回到住处 0/4（进度），夜莺的恐惧 0/3（压力），中途可出现一次人影障碍。恐惧满格意味着她不再愿意继续同行，去亮处叫车；不是「被跟踪者抓走」。机制收益与概率由主稿核定。

### C02-00 出发

（雨很大。夜莺试着撑开伞，伞骨卡住了一下，尼尔帮她拉开。）

夜莺：以前我总走那条近路。今天不想走了。

尼尔：那就走有灯的地方。

夜莺：好。你走在我旁边就行。

（两人离开酒馆后门。）

### C02-01 常规前进行动

**「沿街灯走」：** 两人走在亮灯的店铺旁。进展后，夜莺认出熟悉的招牌：「前面就是卖面包的那家店。」不利结果时，她再次回头、抓紧雨伞，「你看见后面那个人了吗？」

**「穿过暗巷」：** 尼尔提出抄近路，两人穿过货箱间隙。顺利则一下走到下一个街口；不利则夜莺被黑暗中的脚步声惊吓：「尼尔，别走那么快。」

**恐惧 1/3：** 她减少闲聊，开始回头。

**恐惧 2/3：** 她轻轻抓住尼尔的袖子：「我们走亮的那边，好吗？」

**如有一次安抚行动：** 暂时停在有灯的屋檐下。她缓一缓，玩家消耗一次行动；是否减少恐惧由判定真实结果决定，不允许反复无限减压。

### C02-02 短障碍：《街灯下的人影》

**触发：** 玩家经过中段路口一次；未经过、提前失利或成功抵达则不触发。此处不必新增长 Clock。

（前面的路灯下，一个戴帽子的人影停住。夜莺忽然把伞放低。）

夜莺：就是他……至少衣服像。

尼尔：你确定？

夜莺：我不确定。我只是想回去。

- **绕进亮灯的店铺：** 两人向开着门的小店靠近。店员看了眼雨和他们的神情，让他们先待在灯下。避开正面接触，付出时间。
- **挡在她身前，出声喝问：** 尼尔朝人影喊话；对方或许退开，也可能只是陌生路人，声音与动静会让夜莺更紧张。失败不直接确认其犯罪身份。
- **听夜莺的，改走熟悉的路：** 夜莺主动指出旁边的通道，尼尔跟上，两人相互照看；她不必始终是被动的保护对象。

### C02-03 结束的差异

**安全抵达：** 夜莺收起伞，看看尼尔湿透的肩头：「你都淋湿了。进来擦一擦吧。」

**途中尼尔受伤，但仍抵达：** 夜莺回来扶他：「是你陪我回来的。现在换我照顾你。」演出不自动抹除玩法伤势。

**恐惧满格：** 她站在街灯最亮的位置，尽力平复呼吸。「对不起，我走不下去了。我去前面叫辆车。」如果尼尔一直优先护送，她只是受惊；若尼尔执意追看人影、把她留在原地，则说：「我找你来，是因为不想一个人在街上等。」两者不可使用同一责备。

**拒绝/缺席：** 夜莺另找乐队成员同行，或坐车回家。她的生活照常继续；不能伪造两人共有的雨夜回忆。

**同时完成进度与恐惧：** 建议视作抵达但惊魂未定的部分成功，规则应先经作者确认，不能由不同执行路径各自定义优先级。

## SC-A11｜雨夜余波：后来的见面

**触发**：参加交锋后下一次与夜莺私下相处，或未参加/失约后在酒馆重逢。根据真实经历播放其中一段，不要同时叠加所有分支。

### A. 一起安全走完雨夜

（夜莺正准备离开酒馆。看到尼尔进来，她先停了一下。）

夜莺：那天谢谢你。

尼尔：后来还有人跟着你吗？

夜莺：没有。我特意留心了一下。

（她微笑。）

夜莺：下次你要是来看我演出，我留个靠前的位置给你。

### B. 尼尔受伤，她主动关心

夜莺：你的手怎么样了？

尼尔：还能用。

夜莺：我又没问你能不能干活。

（她把一小包干净的布放到尼尔面前。）

夜莺：回去记得换。

**限制**：这包布是演出道具，不默认等于购买或赠送治疗物资；伤势仍按系统恢复。

### C. 尼尔追人、把她独自留下

夜莺：那天后来，你找到那个人了吗？

尼尔：没有。

夜莺：我知道你想弄清楚。

（她停了一会儿。）

夜莺：但下回先跟我说一声，好吗？

### D. 玩家婉拒请求

夜莺：那晚还好，乐队的人把我送回去了。

尼尔：后来没再看见那个人？

夜莺：没有。也许真是我多心。

（她说完便去忙自己的事情，没有再继续这段话。）

### E. 答应后失约

夜莺：那晚我等过你一阵。

尼尔：对不起，临时出了事。

夜莺：没关系，我后来找了别人。

夜莺：只是下次不能来，早些告诉我。

**情感原则**：雨夜一次成功不等于恋爱关系；一次拒绝也不永久关闭夜莺线。改变的是下次见面时，双方具体知道些什么、愿意怎样开口。

## SC-W01｜酒馆告别夜（第 6 天，世界固定）

**目的：** 同一个小酒馆，开场时是陌生人唱歌，末尾是已可能熟悉的人将要离开。夜莺这晚的演唱不以玩家参与为条件；尼尔是否见证、是否与她私下相处取决于玩家。

### W01-00 公共演出

（酒馆里的桌子挪得比平时近。有人把「今夜最后一场」的小纸牌搁在吧台。酒保擦杯子，一边提醒站在门口的客人往里面走。）

（台上灯亮。夜莺扶正麦克风，看向台下，等乐队奏出第一个音。）

**导演提示：** 使用开场同一机位与同一束光，强调她即将离开这里。无须新增宏大歌曲或复杂群戏；掌声与场内的日常动作已经足够。

（唱完以后，她向台下轻轻鞠躬。几位熟客敲杯子鼓掌。酒保把门拉开，让更多人先走。）

### W01-01 人物自然在场，不做「全员集合」

**艾迪可选短镜头：** 只有当玩家与艾迪认识且他今日实际在酒馆时：他在角落端起杯子：「唱得真不错。」之后继续和工友说话，不在舞台前硬凑合影。

**露西可选短镜头：** 只有当已知她喜欢夜莺、且她今晚有空时：她在门口把围巾绕紧，专心听完最后一首。她可以与夜莺根本没说上一句话。

**没有对应经历：** 两位角色都不出现，酒馆里照样有普通顾客，演出照常成立。

### W01-02 与尼尔的关系变体

**此前和夜莺共同度过雨夜、又在酒馆相处过：**

（人散得差不多时，夜莺走到尼尔旁边。）

夜莺：下次再听我唱歌，就得去大剧院了。

尼尔：门票想必不便宜。

夜莺：我给你留个位置。

**只在酒馆说过几句话：**

夜莺：有空来看看我在那边唱得怎么样。

尼尔：会的。

夜莺：那就说定了。

**没有私人关系：** 尼尔作为观众看演出；她跟熟客道谢，随后离开。不能强制触发上面的私人承诺。

### W01-03 第二幕入口

（酒保收走最后几只杯子，取下「今夜最后一场」的纸牌，重新擦起柜台。）

第二天城里仍然有工作、房租和人要照顾；夜莺已开始去剧院准备彩排。

## 二、事件状态与内容回归检查

以下字段名仅用于**对照剧情事实**，不是强制要求程序直接采用这些变量名。

| 状态事实 | 设置时机 | 哪些场景可以读取 |
|---|---|---|
| 已公开见过夜莺 | SC-A02 | A10 普通引荐；W01 世界前提 |
| 与夜莺曾有私人接触 | 实际发生接触后 | A10 请求方式；W01 普通/私人区分 |
| 接受并履行雨夜陪同 | SC-C02 真实发生 | A11、W01-01 |
| 雨夜保护优先 / 执意追看 | SC-C02 相应结算 | A11 的对话变体 |
| 雨夜后受伤 | 实际骰子结算 | A11 的反向关怀，不清除伤势 |
| 答应却失约 / 婉拒 | A10 邀请结算 | A11，且不得触发雨夜共同记忆 |
| 见过露西 / 知道打字愿望 | A04 / A05 | 后续咖啡馆事件与第二幕 |
| 艾迪解围 / 再次相熟 / 喝酒赴约 | A06 / A07 / A08 | 后续码头日常与第二幕 |
| 酒馆赖账处理结果 | SC-C01 | 酒保未来的短评与既有结算 |
| 亲眼看过告别演出 | W01 实际到场 | 以后关于夜莺歌唱的对白 |
| 告别演出已经发生 | 第 6 天固定世界事件 | 幕次推进；W01-NEWS |

### 必须覆盖的回归情形

1. **玩家第一幕从未去码头**：不出现艾迪相关回忆或熟人称呼；第二幕仍可正常初识。
2. **玩家第一幕从未去咖啡馆**：不出现露西的打字愿望回忆；第二幕仍可初见。
3. **玩家拒绝夜莺邀请**：夜莺有自己的回家办法；不进入雨夜交锋；第六天告别演出照常举行。
4. **玩家答应却失约**：可出现轻微失望，但不能伪造共同经历。
5. **玩家雨夜受伤**：资源伤势按系统保留；夜莺关心伤势，不直接治愈。
6. **玩家雨夜追踪优先**：可以得到不确定的观察；夜莺的担忧应当在余波中反映。
7. **玩家不看告别演出**：不播放在场演出；通过消息获知告别演出已发生，进入第二幕。
8. **玩家酒馆交锋失败或退出**：仍然能在酒馆工作，主线不锁死。
9. **玩家第一次在咖啡馆工作前从未去过码头**：露西不能说他昨天搬过货。
10. **所有好/中/坏判定的资源变化**：艾迪确实分担冷静损失时，应显示真实的动作结算；夜莺的关心不自动治伤。

## 三、留给作者下一轮修改的重点

- **夜莺首次演唱**：选定歌唱风格、音乐与演出时长；如果已有正式舞台设计，以作者版本替换 SC-A02。
- **艾迪对白**：确认他的年龄感、方言、幽默程度，避免所有台词都像同一位作者说话。
- **露西性格**：是否更机灵、更调皮或更安静；现在这一版偏轻松俏皮。
- **雨夜可疑者**：第一幕故意不揭示身份，后续如决定与主线关联，应在后续故事单独确立证据链。
- **酒馆告别夜的余味**：不硬凑所有人物，镜头回到台上的夜莺与尼尔；「我在上面的时候看起来怎么样」保留给第二幕正式彩排。
- **舞台演出预算**：选择哪些片段真的需要固定镜头，哪些只使用 Dialogue / Action 文字承载。第一稿中的动作说明不等于必须全部制作模型动画。

**交给 Codex 前的规则：** 本稿 V0.1 是编剧提案，**尚未经过作者审定**。Codex 可以根据已确认的机制主稿做技术筹备；正式接入这些对白和演出前，应以作者修改后的版本为准，不擅自替换台词、创作歌曲或合并不同结果分支。
