## 1. 为什么要有这条线

城市生活模拟提供"怎么活",故事提供"为什么活"。夜莺委托线是给 demo 的
意义与驱动力:一条自闭环的短故事——委托与保护——并开始往后延伸。

故事是线性的,小节是固定的,但每个小节的满足条件是自由的:
**故事是线性的,抵达方式是非线性的**。每次小节推进是重新规划的时刻,
也是局势的变化;完成之后,故事奖励会打开新的经济能力和可探索的世界。
**不要把交锋当小节本体、把一切当备考——方向是反的。**(详见总纲 §1–2)

## 2. 故事

### 2.1 梗概

雨夜,老街酒馆的歌女——艺名"夜莺",真名全篇只在尾声出现一次——找到玩家
落脚的旅馆,用一小笔预付金委托玩家查清是谁在盯她的梢。她是从邻城一家
歌厅逃出来的:签了十年卖身约,跑在第七年。

她的秘密分四层,前三层随小节逐次揭开,第四层要玩家自己去查:

1. **开场**:有人盯梢、字条和死鸟。她说不知道是谁。
2. **第一次逼近之后**:她知道。来的是歌厅老板派的收账人——要么带她回去,
   要么收赎身钱。而且现在,这是你的账了。
3. **第二次逼近之后**:她逃走那晚,老板的心腹追到码头失足落水死了。
   老板咬定是她推的。这不是一笔账,是一条命的交代。
4. **暗账(可选,玩家自己查)**:她对你撒了谎。那晚她在码头——
   他抓住她的手腕往船上拖,是她推的。既不是纯谋杀,也不是纯意外;
   这个事实意味着什么,由玩家决定。

对面的人也在升级:先是收账人独自一人来打量,然后带着人手来抢,
最后老板亲自到场要一个了断。玩家在这三次逼近之间生活、凑钱、结交、
调查,最终选一种方式了断——钱、拳头、牺牲、法律,或者背过身去。

### 2.2 人物

- **夜莺**:她不是委托板上的一张单子。她始终在出力——预付金、情报、
  每天往封口钱里放的钱、一枚旧戒指;保护欲由她的韧性勾出,不靠眼泪。
  她也撒谎,谎被拆穿时她认。她的安危是这条线胜负的一部分:坏结算
  让她不安、受伤,失败意味着她被带走。她的符号物是一把红伞:她在,伞立在看得见的地方;她怎样离开,决定伞的下落。
- **收账人**:老板派来的生意人。他不狂热,只办事;对他来说这是一笔账,
  不是一段仇。他给过警告、碰过钉子,最后站在老板身后。
- **老板**:邻城歌厅的主人。十年卖身约的持有者,也是那条人命的债主。
  他要的"了断"可以用钱清、用法律压,也可以用人抵。
- **萨姆(邻城刑警,编外)**:从邻城追旧案而来。他不受雇于任何人,
  也不会因为玩家不理他就停下。他知道死者叫亨利·奎因——替老板做脏活,
  也给病中的妹妹寄过钱,曾是他的同事。他的存在让夜莺的困境
  不再只有她一个人的视角。他在玩家看不见的时候也在查:登场之前,
  玩家会在酒馆、码头、警局撞见他三次——登门那天,三次目击对成同一件事。
- **探长、码头兄弟、货运代理人**:三条城市生活线伸进故事里的手。
  他们不属于这个故事,但玩家的活法决定其中谁会为这件事出力。

### 2.3 玩家的选择与结局

终局的了断方式由玩家选定,原则是:**不是所有路都通向交锋,
但每条路的付出类型都不重样**——钱、拳头、牺牲、法律、背过身去。
其中后三条路(立案、完整移交、坐视)要求先查明暗账真相;
没查真相的玩家收了她的钱,这就是他的账,没有背过身的台阶。

| 路线 | 付出的类型 | 结局 |
|---|---|---|
| 付钱封口 | 钱——最干净的路必须最贵;她每天也在往里放钱 | **A 真名** |
| 交锋了断(保底) | 拳头——零门槛,城里攒下的一切作场内增益 | 胜 **A** / 败 **B 她跟他们走了** |
| 送她走,自己扛 | 牺牲——她安全了,账不跟船走,换你自己站上去 | 胜 **D1 远方的信** / 败 **D2 信和疤** |
| 立案送警 | 法律(半份)——只交老板那一半真相,她那一半压着 | **F 案卷** |
| 完整移交 | 法律(全份)——她随案回邻城,面对口供与死者亲属 | **G 随案移交** |
| 坐视不管 | 背过身去——免费,这就是它的性格 | **B′ 你没有去** |

结局的质感各不相同:A 是唯一听得到真名的结局——她第一次唱完整的一场,
唱完走到你桌前;B 是她自己走出去换你一条命,酒馆再没有人唱歌,
戒指留在你手里;B′ 比 B 更冷,第二天酒馆关着门,没人告诉你发生了什么,
你也没问;D1/D2 是怅然的暖,数日后一封没有署名的信和一笔钱寄到住所——
D2 里她不知道你付了什么;F 里案子只是压着,你们都知道;G 里刑警带走的
不是一件货,而是一份要面对三方的案卷。真名只属于 A——法律的了断
买不来那一场歌。

遗憾层:真相被面对的结局,尾拍指向亨利的妹妹(开始还);真相被埋掉的结局,收束卡记一行“有些事,她始终没跟你说”。
A 与 F 里,她还在台上;听歌的日常延续到故事之后,是这两个结局的余温。

## 3. 构建原则(demo 专属)

总纲的四条小节原则、人物规则、文案基调在此全部适用;以下是本篇的具体化:

- **每两个小节之间必须有她的场景**。幕间戏不占行动骰,是她给出东西的
  时刻(情报、戒指、一段真话);"必看"场景用阻止休息表达("她在等你回来")。
- **坏结算留疤,不做硬 game over**。她的处境(安好/不安/受伤)可见、
  会改变后续场景与终局余量;故事可以失败(B/B′),游戏继续。
- **暗账是钥匙,不是义务**。不查真相照样能打完全场;查了,选择空间
  变宽,但她那一半也进了案卷。查与不查都要有真实、可见的后果——
  萨姆不会因为被无视就从故事里消失。
- **她的日常在场**:酒馆里每天可以听她唱一段——比酒便宜、比酒干净。她不在台上的日子,这份便宜随她一起消失;缺席先由账本说出来。
- **信任**:这十七天你对待她的方式(主动上门、按时保护、没让她受伤、收下她的出力)会让她逐渐信任你，并以她节点上的 Clock 显示。足够时,第 16 夜她自己说出那晚的真相——通往暗账的第二条门径;不够时,失败里她连自己走出去的余地都没有。
- **文案戒律**:黑色电影腔,短句、具体名词、不解释情绪;她不哭,
  玩家不独白;真名只出现一次(结局 A),其余一律"夜莺"或"她"。她不哭,也不解释;她交出东西(钱、戒指、真话)用“按”这个动作。
- **已裁决不做**(防回潮):交锋内不留免打出口——免打的解全部长在
  城市侧、到期日之前;不做隐形奖惩;不做玩家死亡;不接支线进主线,
  故事自闭环;远征/出城留给后续章节。

## 4. 节奏大纲:三个小节

到期日是全篇的鼓点:第 3 / 10 / 17 天。每个小节都遵循同一个循环——
**故事提出具体账单 → 城市生活提供多种解法 → 到期日必须给交代 →
结算揭开下一层、打开新东西**。

### 小节一「找到盯梢的人」(第 1–3 天)

- **开场**:新游戏自动播放"雨夜来客"。她放下预付金——刚够几晚房钱,
  她不哭,只是把钱按在桌上。委托就是这一拍本身:"查清是谁在盯梢",
  不是"保护我"。保护是后来长出来的。
- **玩家做什么**:在酒馆和码头两处打听,拼出对陌生人的了解;
  同时他得活着——房租第一天就在倒数。
- **推进**:查清之后,城里出现收账人的藏身处,玩家可以**主动上门**
  ——这是第一场交锋「照面」(见 §5)。不去也行:第 3 天他找上门,
  同一场戏,但她受了惊。
- **结算**:无论哪种方式,账转到玩家头上;第二层揭开——卖身约、
  第七年、赎身钱的数目。当晚有她的必看场景。
- **打开**:她引荐酒馆老板,服务员工作解锁;赎身的账单上屏。

### 小节二「给她弄到保护」(第 5–10 天)

- **玩家做什么**:第 10 天他们会来抢人。玩家可以攒出 100 金交首期,
  也可以完成阿瑟的人物小节,让他把事情提级;此前买下的公寓同样会让
  后窗退路更熟。每天早上重新规划:攒钱、跑关系,还是买下一个真正属于
  自己的地方。
- **推进**:首期是唯一的免战方案——付出足够大的经济代价后,收账人先认
  这笔钱,第 10 天不动手。其余情况照样进入「抢人」:先在搜查逼近前
  离开公寓,再坐酒馆的送酒车穿过鱼市、电车路口和警察封锁线。阿瑟的
  安排会让最后的岗哨直接放行;自己的公寓令离开路线开局多一格。败则
  她受伤、酒馆停业;无论如何,收账人都会放话:老板要亲自来。
- **结算**:当晚第三层揭开——落水的人。若她受了伤,这段对话在你的
  住处播,是另一种更浓的相处文本,不是空白。
- **打开**:每条保护路线为它指向的终局路线降一点门槛——**小节二的
  选择是对终局的软承诺**,但不锁死;她的住所场景线开启。

### 小节三「她对你撒了谎」(第 11–17 天)

- **明账**:第 17 天老板亲自到场。封口钱的总数上屏,她每天固定往里放
  一份——玩家每天醒来都看得见进度,也看得见她没躲在他身后。
- **暗账(可选)**:萨姆登门,撂下他的怀疑:"你想听,随时来找我;
  你不想,我也一个人查。"三条查访线(码头老人、邻城案卷、船期记录)
  各自要求先在某条生活线上混到脸熟——查真相不是副任务,是把时间
  投进哪种活法的选择。查明触发必看场景「撒谎的人」:她认了。
  玩家的对话选择不锁路线,只定姿态(责问/体谅),疤留在结局文案里。
- **幕间**:旧戒指——她塞给你一枚旧戒指,"当了它,能顶一点"。
  收不收、当不当,都是玩家自己按下去的取舍,不当场折现。
- **推进**:状态卡列出当前可达的路线与门槛;查过真相多三条路。
  第 17 天到期,按玩家落实的路线各演各的戏:交割烧约、码头送别、
  来的不是老板是巡警、她随刑警回邻城、你在街角喝酒——
  或者,什么都没落实,进第三场交锋「了断」(见 §5)。
- **结算**:七种结局(§2.3),每条线都以一张明确的收束卡到此为止。

## 5. 三场交锋

> 本节只是三场交锋的**纲要**:用什么模式、描述什么情景、在整体中的位置。
> 精确的钟表、动词与数值以三个交锋脚本为准;玩家/设计视角的关卡结构图
> 以各场的结构图(artifact)为准。结构语汇见 [交锋结构库.md](交锋结构库.md),
> 其用法原则(一场一个主结构、连场换结构、赌注永远可读)全部适用。
> 旧交锋方案已归档(archive/)。

城市与交锋之间有**两条汇入通道**,口径不混用:

- **城市的好与坏 → 场景元素**:门安不安全、退路封没封、谁到场、
  终点在哪。它们改变场面,不改变骰子。
- **同伴 → 场内技能**(CS2 主动能力式):不作用于场景元素,只改骰子
  与状态(重掷、改值、回冷静之类)。次数少、效果大、时机由玩家选,
  是烂手气的兜底阀。

三场交锋对应三次逼近,场面从**点到线到面**,考点连成一条弧线:
**贪心 → 分诊 → 调度。**主结构互不重复。

### 5.1 「照面」(小节一)——话题桌:假身份下的见好就收

你冒充一个**替外地人找门路的本地掮客**,接近收账人(或他找上门时,
顺势扮下去)。场上话题平铺:**他的身份**(主目标,成败只看这条,
满后解锁「见好就收」)、**他的钱**(副目标,满格一次性取得「欠账凭据」
和一笔钱,错过不补)、以及**他的疑问**——按固定节奏丢回来的麻烦话题,
可以花钱糊住或凭嘴圆回去,不接就留在桌上发酵。「他的疑心」是唯一
危险钟,**没有自动推进**,只因可读的原因上涨(判定坏结果、疑问答砸、
回合末未接的疑问);过档位线后他起疑,疑问来得更密;满格被打出去——
主目标若已完成仍算成功,但健康、冷静和钱的损失照付,并留下
「收账人识破过你」的疤(第三场读它)。被动等他上门则她在场:
疑心开局先走一格,并多一个关于她的疑问。考的是贪心的自知。

### 5.2 「抢人」(小节二)——固定场面与逐回合换景

他们已经开始搜夜莺藏身的公寓。第一幕是固定场面:不可处理的「有人正在
搜查」令「搜查逼近」每回合上涨一格;第一回合后,一个具体的「搜查者」
来到这一层,未被引开时再多涨一格。玩家在清出后窗、引开搜查者、
布置两个假人和收拾箱子之间分配骰子。箱子只有两个位置,每格选择贵重物品
或路障材料:前者成功逃脱后换成钱,后者留给第二幕做确定性的低骰出口。
只有假人和箱中物结转:假人只让第二幕追兵少一格开局,不继续牵动其他规则。

第二幕坐酒馆的送酒车逃离,**每结束一个回合就永久离开一段街景**:
鱼市—电车路口—警察封锁线。每段只有两个对象,分别为 2 格和 3 格;
夜莺在回合开始随机推进其中一个一格,玩家再把三颗明牌骰分给两个对象。
坏/中/好统一采用 0/1/2 格,因此基础人物也能稳定完成一个、冒险双吃;
未填满的局部进度随街景消失。每驶过一段,追兵固定 +1;对象完成后的汇率
不同:鱼市让玩家在
劳工关系和健康之间选代价;电车路口让玩家在立即压回追兵和保护下一段
之间选时机;警察封锁线让官僚关系直接改变场面。达到官僚「信任」或已由
阿瑟提级时,岗哨无判定放行并拦住追车。

城市积累按三种方式兑现:**100 金首期**仍是唯一免战路线(世界侧,
这场不发生);**阿瑟提级/官僚信任**改变警察封锁线;**已有公寓**令
第一幕后窗路线开局 +1。主结构考的是不可追回的逐回合分配:集中保证一个、
拆骰赌两个、用准备物接住低骰,以及选择把代价记在身体还是城市关系上。

### 5.3 「了断」(小节三)——单位化的两幕:每个麻烦都是一个人

语法沿用 combat 脚本验证过的单位结构——每个敌人有命数、出招倒数与
明牌的招,是 CS2 分诊结构的具象人版。全场两幕、约十一二个回合,
是 demo 最长最重的一场;冷静曲线会在第二幕中段自然击穿,
第 17 天之前买烟酒就是这场的远征补给。

**第一幕·他进门以前**(老板到场倒计时,自动):三个打手的威胁类型
互斥(磨冷静的、伤健康的、偷钱的),首招错开落地;收账人不动手,
只用眼色给全场加速,唯一的解是亮出欠账凭据请他退场;「老街的眼睛」
是幕内可选的贪心目标(敬酒花钱、说破判定、亮通行证)。骰子预算
略小于全清所需——**清不完,必须取舍**;弗兰克到场直接移走两个打手。
没倒的人跟着老板进第二幕;收账人无论如何在转场时合上账本离场。

**第二幕·对面**:老板本人是唯一目标,拳头和逼账都在打他的命数;
命数过半后转「撕破脸」档,亮招加速——越接近倒下他越危险。他的招
全部预告(倒数、落点、拆法可见),**每招至少三种答案**:拆招(稳,
但不产生进度)、硬吃(省骰子,用健康付账;人心争到后他当街动粗
反而掉命)、抢拍打崩(倒数内对他造成足够伤害则招作废——进攻即防御);
夺人的招还可以撂倒执行的打手。失败向量具体而分岔:她在场是
「她被拖走」(中途触发她的固定转折:体谅/责问,姿态写进结局),
无人变体是「你撑不住」。暗账真相是一次性重拳。考的是全面调度。

### 5.4 对外契约(手写交锋不可违反)

1. 以成功/失败两种结果之一结束,回传给故事模块;不做其他出口。
2. 零准备可进入,以失败退出也可(不做硬 game over)。
3. 本场失败对她意味着什么,必须在场内可见(时钟备注/风险预告)。
4. 连续两场不用同一主结构;赌注可读,难度可以不可读。

## 6. 试玩观察项(先标记,不预防性实现)

- 封口路线中她每日凑钱的节奏,是否既让玩家感到并肩、又不消解经济压力。
- 坐视路线是否被当成"最优解"刷——它免费;若成主流,考虑加一层
  可见代价(老街的人记得你那晚在哪)。
- 暗账查访与攒钱的骰子竞争是否真实(第 11–14 天分骰是否有五秒犹豫)。
- 三场新交锋的考点(贪心/分诊/调度)在场内是否真的读得出来。
- 小节二的首期免战是否贵到足以成为真正选择;阿瑟与公寓改场后,
  玩家是否能一眼看出自己少处理了一整段,而不是只得到隐形数值优惠。
