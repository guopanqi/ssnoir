# SSNoir demo短篇·夜莺故事设计（账单结构）

> 本文是 **demo 短篇**的故事设计——一条短而完整、多结局的试验故事，
> 用来验证系统与节拍写法；**它不是真正的主线**。
> 真主线剧本（手写源头）见 [手动编辑的/夜莺剧本-第一章.md](手动编辑的/夜莺剧本-第一章.md)。
> 通用写作原则见 [故事设计总纲.md](故事设计总纲.md)，
> 系统侧姊妹篇是 [城市生活设计.md](城市生活设计.md)，
> 三场交锋的实施蓝图另见 [demo短篇·夜莺交锋方案.md](demo短篇·夜莺交锋方案.md)。
> 实施史与逐模块验收见 archive/ 中的实施计划。
>
> 本文与真实脚本（`Content/scenes/world/夜莺.scm` 等）冲突时，以脚本为准并回来修订本文。

## 0. 为什么要有这条线

城市生活模拟提供"怎么活"，故事提供"为什么活"。夜莺委托线是给 demo 的
意义与驱动力：一条自闭环的短故事——委托与保护——并开始往后延伸，
是游戏很重要的一环。

故事是线性的，节拍是固定的，但每个节拍的满足条件是自由的：
**故事是线性的，抵达方式是非线性的**（苏丹的游戏的概念）。每次节拍推进
（账单的完成）本身是重新规划的时刻，也是局势的变化；完成之后，故事奖励
会打开新的经济能力和可探索的世界。

从经济的角度看，故事主线是目标之一，是存量前往的水槽；但主线的推进同时
拓展你的行动空间、可用动作集合。从故事的角度看，经济是你用不同方式提高
能力、完成故事节拍的方式。**不要把交锋当节拍本体、把一切当备考——方向是反的。**

## 2. 故事梗概

雨夜，老街酒馆的歌女（艺名"夜莺"，真名全篇只在尾声出现一次）找到玩家
落脚的旅馆，用一小笔预付金委托玩家查清是谁在盯她的梢。她是从邻城一家
歌厅逃出来的：签了十年卖身约，跑在第七年。秘密分四层，前三层随节拍
逐次揭开，第四层要玩家自己去查：

1. **开场**：有人盯梢、字条和死鸟。她说不知道是谁。
2. **节拍一结算后**：她知道。来的是歌厅老板派的收账人——要么带她回去，
   要么收赎身钱。而且现在，这是你的账了。
3. **节拍二结算后**：她逃走那晚，老板的心腹追到码头失足落水死了。
   老板咬定是她推的。这不是一笔账，是一条命的交代。
4. **节拍三期间（可选，暗账查访）**：她对你撒了谎。那晚她在码头——
   他抓住她的手腕往船上拖，是她推的。既不是纯谋杀，也不是纯意外；
   这个事实意味着什么，由玩家决定。

终局按玩家选定的路线分岔（六条路线、八种结局，见 §5.4 与 §8）；
尾声（结局 A）她第一次唱完整的一场，然后说出真名。

### 2.1 人物规则

- **她不是任务标记**：每两个节拍之间必须有她的场景；她始终在出力
  （预付金、情报、戒指），保护欲由她的韧性勾出，不靠眼泪。
- **她的安危是胜负的一部分**：节拍以坏结果结算会推进"夜莺安危"，可见、
  会改变后续场景；终局失败 = 她被带走，demo 的故事失败结局
  （不做硬 game over，与"交锋不终局"规则一致）。
- **所有故事状态可见**：状态卡、当前账单、到期倒计时、酒馆停业期限，
  全部遵循城市生活设计 §1 的 Clock 可见性规则。
- **文本量上限**：每一拍两三屏；对话用 `play-dialogue!`，过场用 `spotlight!`。

## 3. 三个节拍总表

到期日由世界排程 `public-event-intervals '(3 6 7)` 驱动，即第 4 / 10 / 17 天。

| | 节拍一「找到盯梢的人」 | 节拍二「给她弄到保护」 | 节拍三「她对你撒了谎」 |
|---|---|---|---|
| **故事问题** | 谁在盯她？他在哪？为谁来的？ | 他们要来抢人，你能不能让她暂时安全？ | 真相是什么？你拿真相做什么？ |
| **可见目标** | 第 4 天前查出收账人的落脚处 | 第 10 天前落实一种临时保护 | 第 17 天前选定并落实一条路线 |
| **抵达路径** | 酒馆打听 / 码头闲话 / 警局查登记簿 / 花消息买线索 | 付首期 / 警局取证 / 码头兄弟看场 | 六条路线：付钱封口 / 交锋了断 / 送她走 / 立案送警 / 完整移交 / 坐视不管（后三条需查明真相） |
| **完成 → 结算** | 解锁"去找收账人"：**你上门**（主动交锋，占先手） | 到期日是**场景**：他们碰了钉子退走，放话了断之日 | 按路线分岔：封口 / 送走 / 立案 / 坐视是**场景**，其余进交锋「了断」（见 §5.4） |
| **未完成 → 结算** | 第 4 天**他找上门**（被动交锋，他占先手） | 到期日是**交锋「抢人」**，败则她受伤 | 保底交锋「了断」，城市里攒下的东西作场内增益 |
| **结算后的局势变化** | 账转你头；第二层揭开；赎身钱账单上屏 | 老板知道收账人不够用了；第三层揭开；了断日锁定 | 八种结局（见 §8） |
| **结算后的扩容** | 她引荐酒馆老板 → 服务员工作解锁 | 按所选方案各自扩容（见 §5.3）；她的住所场景线开启 | 结局态内容（随结局各异，见 §8.2） |

三个节拍无论以哪种方式结算，只要推进即各奖励 1 成长点（沿用公共小节规则；
例外：结局 B′ 坐视不管不奖励——背过身去不算经历完一段处境）。
幕间场景（她的戏份）穿插其间，见 §7。

## 4. 状态归属与开场

### 4.1 状态归属

故事闭包 `nightingale`（[夜莺.scm](../Content/scenes/world/夜莺.scm)）拥有全部故事状态：

```
story-stage    ; 0=未开场 1=查访中 2=账转你头(二层已揭) 3=知道真相(三层已揭)
               ; 90=真名(A) 91=她被带走(B) 92=中途放她走(C)
               ; 93=远方的信(D1) 94=信和疤(D2) 95=案卷(F) 96=你没有去(B′)
beat1-progress ; 查访进度 0..4
beat1-early?   ; 节拍一是否已由玩家主动结算
protection     ; 节拍二方案: 无 / 首期 / 警局 / 码头
installment-paid? ; 是否付过首期(影响封口总价)
truth-progress ; 暗账查访进度 0..4(节拍三)
truth-known?   ; 是否已查明真相(暗账满格且看过「撒谎的人」)
farewell?      ; 是否已送她上船(路线三)
hush-paid?     ; 是否已付封口钱(路线一)
case-filed?    ; 是否已立案送警(路线四)
surrendered?   ; 是否已将完整真相交给刑警(路线五)
detective-stage ; 邻城刑警：未见 / 初谈 / 说起死者
detective-evidence ; 无 / 老板（有限立案）/ 完整（随案移交）
safety         ; 夜莺安危 0..3 (0=安好 1=受惊 2=受伤 3=被带走)
scene-flags    ; 各幕间场景是否已看(防重复)
tavern-closed  ; 酒馆停业剩余天数
```

世界协调器（world.scm）只保留节拍排程（计数、到期、阻塞）；故事状态归夜莺
模块，通过 `set-global!` 镜像必要字段（`'夜莺阶段` `'夜莺安危` 等）供交锋
脚本读取。到期时世界置 pending 并阻塞休息，pending 节点的内容向 `nightingale`
询问——由故事状态决定当天是**交锋**还是**场景**。世界只管"到期必须处理"，
不管"处理长什么样"。节拍一主动结算走 `resolve-beat-early!`（消费当期排程）；
结算后世界回传 `(nightingale 'on-beat-result 节拍号 result)`，由夜莺模块推进
safety、解锁当晚对话、执行扩容与留疤。中途放走调用 `cancel-public-events!`；
但节拍三的封口 / 送走 / 立案**不取消排程**——第 17 天照旧到期，
pending 内容按路线呈现各自的场景（见 §5.4 到期日分派）。

### 4.2 开场·雨夜来客（第 1 天必办）

复用"关键事件阻止休息"机制（`rest-block!` / `rest-release!`）：

- 新游戏 `story-stage = 0` 时，旅馆内出现必办节点**"回应敲门声"**
  （instant，不占骰），同时挂 rest-blocker"今晚有人敲门，先看看是谁"。
- 触发开场对话（委托、预付金、死鸟字条），然后获得预付金 30、
  `story-stage = 1`、解除阻塞、一屏定场文案。
- 开场对话要点：她付的钱刚够几晚房钱；她不哭，只是把钱按在桌上；
  委托就是节拍一本身——"查清是谁在盯梢"，不是"保护我"。
  保护是后来长出来的。

### 4.3 她的状态卡（账单外化）

`nightingale 'render-data` 在世界根节点渲染容器**"夜莺"**：

- observe 节点：她现在的处境描述（随 story-stage 与 safety 变化）。
- **当前账单行，从第 1 天起常驻**，随节拍更新——玩家每天早上第一眼
  就能回答"我现在缺什么"。
- 查访/账单进度以 Clock 显示（节拍一 0/4；节拍二、三显示已落实的方案）。
- safety 三格 Clock，标题"夜莺安危"，备注"节拍以坏结果结算会让处境恶化；
  了断失败，她会被带走"。

## 5. 节拍详情

### 5.1 节拍一「找到盯梢的人」（第 1–4 天）

目标是一个具体结果：收账人的落脚处。四条来源，满 6 格即达
（开局用 3 颗骰可达，但要挤占挣房租的骰子）：

| 来源 | 地点 | 判定 | 好结果 | 坏结果 |
|---|---|---|---|---|
| 酒馆里问 | 老街酒馆 | 交际 | +1 格（有人见过他进出） | 冷静 −1 |
| 码头上问 | 码头 | 交际（劳工≥相识 +1 修正） | +1 格（他是坐船来的） | 冷静 −1 |
| 查旅店登记簿 | 警局 | 见识 | +1 格（外地人都得登记） | 无进展 |
| 花消息买线索 | 夜莺状态卡 | 无（即时，消耗 1 情报） | +1 格 | — |

进度、来源与剩余天数全部可见；每格附一句情报文案（他用的假名 / 他为谁
办事），信息本身就是报酬。查访来源只在节拍一期间出现，结算后酒馆恢复
普通"打听消息"。

结算：满格解锁主动行动**"去找收账人"**（占 1 骰）→ 交锋一"你上门"变体，
先手优势；玩家也可以拿着落脚处不去——第 4 天他照样上门，但你对他的了解
仍在。未满则第 4 天被动交锋"他找上门"。无论胜败，结算相同：收账人记住
你的脸，撂话"这是你的账了"；当晚第二层揭开，`story-stage = 2`。
交锋失败额外：safety = 1（受惊）。

### 5.2 节拍二「给她弄到保护」（第 5–10 天）

三条路线，完成任一只落实保护（设置 `protection`），不提前推进节拍。
三条路刻意错开成本类型——钱 / 官面脏活 / 江湖人情：

| 方案 | 门槛 | 成本 | 落实动作 |
|---|---|---|---|
| **付首期** | 无 | 60 金 | 交割（占 1 骰） |
| **警局取证** | 官僚≥相识 | 一场取证交锋 + 交割 | 警局"替探长取证"→ 跑交锋「夜莺·套线」拿到「把柄」→"把把柄交给探长" |
| **码头兄弟看场** | 劳工≥相识 | 凑齐 3 段看场人手（多次社交判定，约 2~3 天） | 码头"请码头兄弟看场" |

警局这条刻意区别于码头的"人情"：探长碍于警察身份，不便亲自套话 / 钓鱼 / 取物，
把这件脏活交给你去办；跑一场「夜莺·套线」交锋拿到能按住收账人的「把柄」，
再交回探长，他才有由头让巡警第十天守着酒馆。这是官僚线在故事里第一次
从"办程序"变成"替他做他做不了的事"。

这是账单节拍的核心体验：每天早上重新规划——攒钱赎人？拉官面上的探长？
还是求码头的兄弟撑场？三条路横跨凑钱与两个势力，"生活方式互联"在此兑现。

第 10 天到期必办：**已有保护 → 场景**（他们碰了钉子退走，按方案出对应
文案；收账人放话老板要亲自了断，safety 不变）；**无保护 → 交锋「抢人」**
（胜则撑住，败则 safety = 2、她躲进你住处、酒馆停业 2 天）。
结算当晚第三层揭开，`story-stage = 3`。

### 5.3 节拍二扩容（按方案分岔）

- **首期**：`installment-paid?`，封口总价减为 420（账目连续，付过的钱有意义）；
  收账人对你的称呼变化（生意人待遇）。
- **警局**：探长收过你替他弄来的把柄、记下这桩事 → 节拍三"立案送警"
  路线的交割少一步（他信你；官僚线可见回报仍是通行证 + 延期两个工具，
  不加隐形折扣）。
- **码头**：码头兄弟认下这件事 → +1 劳工关系，交锋「了断」中
  "码头兄弟到场"场内增益的门槛从"核心"降为"相识"（他们看过一次场，认这件事）。

每条路都为自己指向的节拍三路线降一点门槛——**节拍二的选择是对终局路线的
软承诺**，但不锁死：玩家仍可换线，只是没有折扣。

### 5.4 节拍三「她对你撒了谎」（第 11–17 天）

节拍三不是"备考七天等一场交锋"。账单拆成两层：

- **明账**：第 17 天老板亲自到场要一个了断。封口总价是 **480 金**（付过首期
  420）；夜莺从节拍三开始每天接活凑 40，最多承担 240。状态卡同时显示总价、
  她已凑出的数额与玩家还需承担的数额——她不是等你赎的任务标记。
- **暗账**（可选）：她先把那晚说成"他自己踩空落水"，说得含混。两天后，
  一个跟梢者拿着关于夜莺的消息出现；截住他，再花 50 金买下线索，才会解锁
  三处查访。暗账是路线四到六的钥匙；不查照样能走路线一到三打完全场。

#### 暗账查访「那晚码头上发生了什么」

买下消息后，跟梢者只指出三条有门路才够得着的线：码头老人、邻城案卷、货栈
船期。调查仍是 4 格、仍要和日常工作争夺行动骰；每格附一句情报文案：

| 来源 | 地点 | 判定 | 情报文案方向 |
|---|---|---|---|
| 问那晚在码头的老人 | 码头 | **劳工≥相识**后交际（+1） | 那晚有个女人上过栈桥；有人听见争执 |
| 调邻城的案卷抄件 | 警局（托探长） | **官僚≥相识**后见识 | 死者手腕上有抓痕；案子在邻城压着没立 |
| 查船期与货栈记录 | 货运公司 | **富商≥相识**后见识（+1） | 那晚根本没有她说的那班船——她的说法对不上 |

三个渠道在地点中始终可见，但未满足关系门槛时明确灰显并写出所缺的人情。
因此查明暗账不是第 11 天立刻用四颗骰子就能完成的副任务：玩家必须先决定
把时间投入哪条城市生活线，换到能见人、调卷或翻旧记录的资格；拿到第一条
实证后，夜莺会当面问玩家为什么还要翻那一晚，试图让他把旧账留在水里。

满格触发必看幕间「撒谎的人」（见 §7），此后 `truth-known?` 置真，
状态卡亮出路线四到六。

#### 邻城刑警与证据交割

买下消息后，警局会出现一位从邻城追案而来的刑警。玩家第一次见他时，会知道
死者叫何迁：他替老板做脏活，也给病中的妹妹寄过钱，曾是刑警的同事。调查到
两格后，刑警会补完这段人的生活；这不是为死者洗白，而是让夜莺的困境不再只
有她一个人的视角。

真相查明后，证据必须由玩家主动交割：

- **只交老板那一半**：刑警追查雇凶、拐卖与压案；夜莺在栈桥上的部分先不写死。
  这才解锁原有的「立案送警」路线。
- **交出完整真相**：刑警带夜莺回邻城录口供、面对死者亲属；她不是被交还给老板，
  但也不能继续被任何人的沉默留下。
- 真相已经揭开却不交代时，刑警会在码头拦住送她离开的玩家；送走不再是无代价的
  擦除。玩家仍可选择封口、交锋或坐视。

#### 六条路线

状态卡从第 11 天起列出当前可达路线及门槛（含节拍二折扣）；
未查暗账时只显示路线一到三。原则：**不是所有路都通向交锋，
但每条路的付出类型都不重样**——钱、拳头、牺牲、法律、背过身去。

| # | 路线 | 需要真相? | 门槛 / 付出 | 第 17 天形态 | 结局 |
|---|---|---|---|---|---|
| 1 | 付钱封口 | 否 | 封口总价 480 金（付过首期 420），夜莺最多承担 240，第 17 天前交割 | 场景：交割，烧约 | **A 真名** |
| 2 | 交锋了断（保底） | 否 | 零门槛；码头 / 通行证 / 老周为场内增益 | 交锋「了断」 | 胜 **A** / 败 **B** |
| 3 | 送她走，自己扛 | 否 | 舱位（富商相识 80 金正规 / 劳工信任 50 金渔船+走私判定）+ 第 16 天前"送她上船"（占 1 骰） | 交锋「了断·无人变体」：失败钟指向你，不指向她 | 胜 **D1** / 败 **D2** |
| 4 | 立案送警 | **是** | 先向刑警交出「老板那一半」+ 通行证 + 官僚信任；节拍二警局方案可少拼案卷一步 | 场景：来的不是老板，是巡警 | **F 案卷** |
| 5 | 完整移交 | **是** | 听完刑警讲死者、交出完整真相 | 场景：夜莺随刑警回邻城 | **G 随案移交** |
| 6 | 坐视不管 | **是** | 无——这就是它的性格 | 场景：你在饭店，酒馆那边出事 | **B′ 你没有去** |

路线细则：

- **路线一（付钱封口）**：钱这条最"干净"的路仍必须最贵，但夜莺不会把账
  全压给你。她每天接活凑 40，最多承担 240；玩家看得见自己还需承担的数额，
  也看得见她没有躲在你身后。
- **路线二（交锋保底）**：码头兄弟到场 / 程序干预 / 请老周出面全部降格为
  **场内增益**，不再是免打王牌——免打的资格属于钱、属于远走、属于法律。
  交锋结构见 [demo短篇·夜莺交锋方案.md](demo短篇·夜莺交锋方案.md) §3。
- **路线三（送她走）**：两步动作。① 弄到舱位：货运公司正规舱位
  （富商相识，80 金）或码头渔船夹带（劳工信任，50 金 + 一次走私判定，
  失败被收账人的眼线看见 → 交锋失败钟开局 +1，逃跑失败的代价可见）。
  ② 送她上船（占 1 骰，第 16 天前）：码头夜戏按 `truth-known?` 分两版——
  知道真相，她在跳板上说出那句实话；不知道，她只是把戒指塞回你手里
  （真名都不说，见 §10）。她走后交锋照打——老板的账不会跟着船走，
  只是赌注换成了你自己（无人变体）。
- **路线四（立案送警）**：真相里她自己也在案卷里。这条路的努力长在
  道德结构上：你先把**老板那一半**（雇凶跨城抢人、死者腕上的抓痕）交给邻城
  刑警，再请探长立案，把她那一半暂时压下去——通行证是由头，官僚信任是探长
  愿意替你压的人情。
  警察接管后，那些人没法再追查。
- **路线五（完整移交）**：把全部证据交给刑警。夜莺随案回邻城，去面对口供和
  死者亲属；这不是老板的私刑，也不是玩家替她宣布无罪。
- **路线六（坐视不管）**：必须是看得见的选择，不能是躺平超时。第 17 天
  pending 节点上明写替代动作**"去饭店喝酒"**，副标题写清后果
  （"你不去，今晚就没人站在她那边"）。仅 `truth-known?` 时出现——
  查明她撒过谎，故事才提供背过身的台阶；没查真相的玩家没有这个选项：
  你收了她的钱，这是你的账。

#### 到期日的分派（排程不动）

第 17 天照旧由世界置 pending、内容问 `nightingale`：已付封口 / 已送走 /
已立案 / 已完整移交 → 各自的场景；`truth-known?` 且未落实其他路线 → 交锋入口旁
多一个"去饭店喝酒"替代动作；否则 → 交锋「了断」。世界只管"到期必须
处理"，不管"处理长什么样"——world.scm 零改动。与中途放走
（92，取消排程）刻意不同：路线一、三、四、五不取消排程，
第 17 天仍要到期演各自那场戏。

## 6. 交锋的对外契约（手写交锋不可违反）

1. 以 `(end-encounter 'success)` / `(end-encounter 'fail)` 结束，
   经世界回传 `on-beat-result`；不做其他出口。
2. 零准备可进入、以失败退出也可（不做硬 game over）。
3. 本场失败对她意味着什么，必须在场内可见（时钟备注 / 风险预告）。
4. 异常货单可选目标是否保留、放在哪场，手写时定（机制不改）。

三场交锋（`夜莺·警告` / `夜莺·抢人` / `夜莺·了断`）的结构语法见
[demo短篇·夜莺交锋方案.md](demo短篇·夜莺交锋方案.md)。

## 7. 幕间场景（她的戏份）

全部为即时对话节点（不占骰、一次性、看过置 scene-flag），按 story-stage /
天数注入酒馆：

1. **第二层揭开**（节拍一结算当晚，必看）：卖身约、跑在第七年、赎身钱数目。
   若查访拿到过假名/雇主碎片，她的反应有两版（问过 / 没问过）。
2. **她唱歌**（story-stage ≥ 2，第 5 天后首次进酒馆）：一屏氛围文案，
   不给数值奖励——这一拍的报酬是文本本身。
3. **软选择"我走就是了"**（story-stage ≥ 2，第 7 天后）：她提出离开以免
   连累你（那 60 块首期，够她走很远）。
   - **"留下"**：一句回应；状态卡多一行"她留下了——因为你开口了"。
   - **"让她走"**：`story-stage = 92`，取消后续公共事件，状态卡变为
     怅然结语后次日消失；酒馆恢复普通打听。不奖励成长点。
4. **第三层揭开**（节拍二结算当晚，必看）：落水的人。若节拍二以交锋失败
   结算（她受伤），对话在住处播放，文案为受伤版——失败玩家拿到的是
   另一种更浓的相处文本，不是空白。
5. **旧戒指**（story-stage = 3，第 12 天后）：她塞给你一枚旧戒指，
   "当了它，能顶一点"。收下（+15 金）或不收（一段对话），均置 flag。
6. **撒谎的人**（暗账查访满格，必看）：你把对不上的地方摊在她面前，
   她认了——他抓住她往船上拖，是她推的。玩家的对话选择**不锁路线，
   只定姿态**（留疤在结局文案里）。看完置 `truth-known?`，
   状态卡亮出路线四到六。

"必看"场景复用 rest-block!（当晚不看完不能睡），备注写明原因（"她在等你回来"）。

## 8. 留疤与结局

### 8.1 安危推进（on-beat-result）

| 节拍 | 好结算 | 坏结算 |
|---|---|---|
| 一 | safety 不变（主动或被动交锋胜） | 交锋败：safety = 1（受惊） |
| 二 | 场景结算或交锋胜：safety 不变 | 交锋败：safety = 2（受伤，躲进你住处）；酒馆停业 2 天 |
| 三 | 按路线分岔（§8.2） | 路线二交锋败 → B；坐视 → B′（路线三的败是 D2，safety 不推——她已上船） |

酒馆停业：夜莺模块置停业天数，酒馆读取后隐藏工作、显示歇业 Clock；日终递减。

### 8.2 八种结局

| 结局 | 到达方式 | story-stage |
|---|---|---|
| **A 真名** | 路线一（封口）或路线二交锋胜 | 90 |
| **B 她跟他们走了** | 路线二交锋败 | 91 |
| **C 怅然** | 中途放走（§7 软选择） | 92 |
| **D1 远方的信** | 路线三 + 交锋胜 | 93 |
| **D2 信和疤** | 路线三 + 交锋败 | 94 |
| **F 案卷** | 路线四（立案送警） | 95 |
| **B′ 你没有去** | 路线六（坐视不管） | 96 |
| **G 随案移交** | 路线五（完整移交） | 97 |

- **A 真名**：酒馆，她第一次唱完整的一场，唱完走到你桌前说出真名。
  状态卡变为长期状态"她留在了这座城"；酒馆永久多一个 observe 节点
  （她在台上）。
- **B 她跟他们走了**：她自己走出去，换你一条命。酒馆再没有人唱歌；
  住所物品栏多一枚"旧戒指"（若此前未收过）。状态卡变为结语后消失。
  游戏继续，不做 game over。
- **B′ 你没有去**：比 B 更冷。第二天酒馆关着门，没人跟你说发生了
  什么——你也没问。状态卡结语后消失。不奖励成长点。
- **C 怅然**：见 §7 软选择。
- **D1 远方的信**：她安全，你也站住了。数日后住所收到一封没有署名的信
  和一笔钱（她把赎身钱寄回一部分——她始终在出力，§2.1 人物规则不破）。
  酒馆再没有歌，但和 B 的死寂不同，是怅然的暖。
- **D2 信和疤**：她安全，但你带伤扛下了这笔账（−健康、−钱，场面文本
  是你被打过）。信照样来——她不知道你付了什么。
- **F 案卷**：第 17 天来的不是老板，是巡警。她留下了，但你们都知道
  案子只是压着。真名不出现——法律的了断买不来那一场歌（§10：
  真名只属于结局 A）。
- **G 随案移交**：她跟着巡警回邻城，把那一晚说完。刑警带走的不是一件货，
  而是一份必须面对死者、夜莺与老板三方的案卷；真名同样不出现。

## 10. 文案基调（写 .scm 文本时的约束）

- 黑色电影腔：短句、具体名词、不解释情绪。她不哭；玩家不独白。
- 她的每次出场都要"给出"点什么（钱、情报、一首歌、一枚戒指），
  保护欲来自她的韧性，不来自可怜。
- 所有账单、到期日、风险预告写在看得见的地方（状态卡、时钟备注、
  动作副标题）；惊吓只用于剧情揭示，不用于机制惩罚。
- 真名只出现一次（结局 A），全篇其他位置一律"夜莺"或"她"。

## 11. 已裁决不做（防止回潮）

- **了断场内王牌与"最后报价 120"**（2026-07-13 撤销）：三张王牌把三条路
  挤进同一场交锋换文案，分岔是皮不是路。免打的解全部移到城市侧、
  第 17 天之前（§5.4 六条路线）；交锋内只留增益，不留出口。
- **收账人落脚处的可交互节点**：状态卡 + 交锋入口已完整表达"你知道他在哪、
  可以主动上门"，额外节点是没有独立读法的占位。
- **警局线通行证冷却减免**：官僚线可见回报已收敛为通行证 + 延期两个工具，
  冷却折扣是同一奖励的重复表达。
- **黑市买消息**：黑市从未挂载；已由"花 1 情报 +1 查访格"替代，语义相通。
- **探长担保（隐形失败保险）**：玩家从未主动决策；隐形奖惩一律不做。
- **旅途/出城**：CS2 的远征节拍留给第二章语法。
- 不接异常货单/老周支线进主线；故事自闭环。
- 不做玩家死亡（引擎无此概念）。

## 12. 试玩观察项（先标记，不预防性实现）

- 查访是否需要限制同一来源重复贡献。
- 第 10 天前警局取证路线（跑一场交锋 + 交割两步）是否节奏过长、实际可达。
- 封口路线中夜莺每日凑钱的节奏，是否既能让玩家感到并肩、又不消解经济压力。
- 路线六（坐视）是否被当成"最优解"刷——它免费；如果试玩中它成为主流，
  考虑给它加一层可见代价（老街的人记得你那晚在哪）。
- 暗账查访与攒钱的骰子竞争是否真实（第 11–14 天分骰是否有五秒犹豫）。
