# Scenario 决策结构卡

> **术语约定：** Scenario 是一个聚焦的体验单位，可以短至一个瞬间，也可以展开成一段连续经历或小故事。这个名称不预设对抗、战斗或戏剧强度。`Scene` 指内容呈现的场景/舞台；`Episode` 通常指更长的故事段落。

## 第一次彩排（贪婪）

| 字段   | 内容                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 情景   | 尼尔在剧院彩排期间承担三次舞台准备与交付，也能抽空打听后台消息。                                              |
| 目的   | 在五回合中自行决定争取多少工作报酬与额外情报，同时控制冷静和伤势损耗。                                           |
| 行动对象 | 首段布景、侧灯标记、尾段布景，以及可重复取得情报的后台消息。                                                |
| 决策核心 | 是把可靠的骰子用来接齐工作、争取更高档工钱，还是投入稳妥的消息收益；局势不利时，是否降低预期、放弃部分回报？                        |
| 局势变化 | 工作在第2、3、5回合分别交付，各为4格且开场都可准备。一次交付后，剩余可争取的工钱档位和投入对象改变；坏结果扣冷静，继续追求全部收益会累积身体风险。   |
| 结果   | 不以漏掉一次工作判整场失败；按时交付一／二／三项分别获得5／15／40美元，情报每满4格取得一份、每份可卖10美元。中途倒下仅按已到节点且完成的交付结账。 |
|      |                                                                               |

备注：

> 如果你贪婪的话，你想全部都要，就会很容易受伤或者怎么样。但是如果你合理的调整自己的预期，也许能取得一种平衡。



## 最后一排的观众

| 字段 | 内容 |
| ---- | ---- |
| 情景 | 第十三天必须处理的赞助人试唱结束后，尼尔发现后排的黑大衣男人与银色打火机，追查他离开剧院的路线。完整与压缩试唱均会进入，演出只触发一次。 |
| 目的 | 找出内部通道，争取车行标志与部分车牌；追查途中可取得额外情报。 |
| 行动对象 | 第一阶段公共走廊、工作通道各4格；第二阶段离场去向6格、可重复后台消息4格。 |
| 决策核心 | 依据局部发现选择搜寻路线、是否改道；第二阶段在同一骰池与有限回合内分配主目标和额外收益。 |
| 局势变化 | 每次从两套预写路线中选真实路线，开场细节与2格发现一致。错误路线满格确认排除，给正确路线2格；正确路线满格进入第二阶段，立即刷新一手骰，不推进回合或收取时间代价。第一阶段无截止；第二阶段有3回合收工倒计时，每回合结束减1。 |
| 行动与代价 | 第一阶段询问为稳妥社交，坏/中/好推进0/1/2；搜寻为冒险敏锐，推进0/2/3，坏扣1冷静。第二阶段只留打听离场去向（冒险社交，0/1/2，坏扣1冷静）和打听后台消息（冒险敏锐，0/1/2，坏扣1冷静）。沿用引擎每回合冷静消耗。 |
| 结果 | 主目标满格立即追出侧门，关闭额外情报；记下联城车行与车牌末三位472，并准确告诉夜莺。超时错失车辆信息，但确认内部通道与侧门离场。每满4格消息发1份情报，余量保留；首次消息揭示换景机维修拖延，后续为后台闲谈。倒下按已有情报数结算，不凭空获得车辆或通道发现。 |
| 表现 | 场景变化用括号旁白，人物与必要发现用 Dialogue。保留独立演示入口；正式流程由试唱结束直接进入。车辆/错失/倒下结果与情报数量写入剧院模块存档，线索进入手头的事；情报不重复发放。 |


## 侧门的陌生人（配合投资）

| 字段 | 内容 |
| ---- | ---- |
| 情景 | 陌生男子在剧院侧门打听夜莺，工作人员各自忙着接待与交班。 |
| 目的 | 调查外貌、出没时间与去向，取得一处能够继续追查的地点。 |
| 行动对象 | 跟踪线索、场务的交班整理；可询问门房、查记录或自己观察。 |
| 决策核心 | 是利用较短窗口直接调查，还是提前投入帮忙换取配合；手里的骰子与剩余进度，是否还值得继续投资？ |
| 局势变化 | 直接询问门房无修正，门房留到第2回合末。场务帮忙3格，仅第1回合开放，完成后查记录修正−3→0；场务第3回合末下班后，值班簿仍可不限回合自行查阅，修正−3。自行观察无需帮忙、判定修正+1，但坏结果扣1冷静；夜莺第2回合末离开后观察关闭。 |
| 结果 | 各调查途径可混合推进8格线索，填满取得旧旅馆接送车的追查方向，不揭示身份；没有整场失败倒计时，可以继续查簿；每回合结束仍消耗冷静。 |

备注：帮场务可改善查记录的条件，不锁死其他路线。第一手骰不适合整理交班时，可以转向门房或自行观察；门房离开后，已取得的场务配合及剩余线索会影响后续查阅的成本。

## 侧门的陌生人（查阅窗口）

| 字段 | 内容 |
| ---- | ---- |
| 情景 | 尼尔在剧院侧门调查打听夜莺的陌生人。门房按自己的工作节奏看门、去后台核查，再回来；离开时值班簿留在桌上。 |
| 目的 | 查清陌生人的去向，得到一处可以继续追查的地点；也可抽空取得额外情报。 |
| 行动对象 | 始终可用的侧门观察与打听后台消息，以及仅在门房离开时可用的出入记录。 |
| 决策核心 | 是稳妥推进调查、争取额外消息，还是趁门房不在投入成功率较高但失败会消耗冷静的查阅？是否值得等下一个窗口？ |
| 局势变化 | 门房看门两回合、离开核查一回合，持续交替，当前工作与进度始终可见；玩家不驱动这项变化。门房离开后查阅开放，回来后关闭。观察与查阅都需判定；查阅成功率较高，坏结果扣冷静。消息可反复积累换取情报。 |
| 结果 | 主目标完成即取得旧旅馆接送车的追查方向；额外情报可保留并在报社卖钱。窗口会再次开放，没有整场倒计时，但持续调查会消耗回合冷静。 |

备注：人物按公开节奏自主行动，玩家分配的是同一池骰子。可体验窗口开放与关闭时，主目标、额外回报和冷静成本之间的优先级是否改变。


## 雨夜追车（表现试演）

沿用「雨夜追信」的追逐进度10／脱逃危险6与三个行动数值：紧追推进距离，确认去向降低危险，绕行截车以必增危险换较多进度；回合结束危险+1，两钟同时满先判跟丢。独立入口保留原跑步版本。

车追车发生在独立 Stage「雨夜追车」；进入地点即自动播放24秒的环境闭环，街景速度32m/s，慢车相对镜头后退24m/s（相对道路向前8m/s）；不压影幕、不阻塞操作，也不记录发动引擎状态。追赶、确认、绕行的行动卡分别挂在本车、前车与旁街锚点。街景、慢车与追逐车辆按闭环运动；闭环只表达正在行驶，不推进 Clock，不代表一次成功或失败。当前动作结果只通过原有 Clock 与文字呈现，没有按进度移动两车，也未制作追上／跟丢的结尾动画。

## 巷子里在打人（击倒表现）

原有三目标的生命、伤害、出手节奏和胜负条件不变。原版与“新实验”都在单个目标生命由非零归零时播放一次实时重拳击倒近景；回到牌面后，该目标保持倒地并移除行动卡，其他人的姿势与决策状态保持。三个次要打手共用人物网格来源和动作，尼尔独立建模；重入时从当前目标树恢复初始显示姿势，不另存演出状态。具体片段与检查记录见`city-box/prefabs/review/巷子里在打人/实时接入/`。

## 大船靠岸（协作试验）

| 字段 | 内容 |
| ---- | ---- |
| 情景 | 尼尔跟艾迪参与货轮卸货，将船上货物经 PlaceA 转运进仓库。 |
| 目的 | 把船上的八批货全部送进仓库。 |
| 工作对象 | 船上货物、PlaceA 现有货物、仓库已收货物。 |
| 行动 | 吊机搬运使船上货物减少、PlaceA 增加；转运使 PlaceA 减少、仓库增加。两项进度由玩家行动推进。 |
| 结果 | 仓库填满即完成。 |



## 大船靠岸（联合起吊）

| 字段 | 内容 |
| ---- | ---- |
| 情景 | 尼尔跟艾迪卸普通货物，随后合力卸下一台巨型输送线驱动总成。独立演示，保留旧版城市事件。 |
| 目的 | 准备与吊运共用六个工作回合，两侧各完成8格且摆动未满，安全落货。 |
| 工作对象 | 普通卸货4格；必要吊具3格、必要落点3格、可选防摆2格；前端8格、后端8格、摆动4格；危机稳定3格。 |
| 行动 | 尼尔沿用默认4骰、不修改骰池配置，艾迪1骰，沿用既有判定及同伴技能修正。开场搬运货箱（violence）或协助挂索（sharpness），均稳妥、坏/中/好推进同一普通货物Clock 0/1/2格。必要及可选准备均稳妥，坏/中/好为0/1/2；防摆完成将容许差从1扩大到2。谨慎推进0/1/2；加快推进坏行动者冷静−1、中进1、好进3（失败不增加摆动）；无主动减摆动行动，仅停吊危机完成后恢复至1格。 |
| 决策关系 | 花时间增加协调余量，或尽快起吊；行动价值取决于另一侧进度。回合末超差摆动+1，不禁用领先侧加快；玩家自行权衡追赶时间与继续失衡的风险。没有工友自动推进。 |
| 阶段与期限 | 普通卸货满4格即发现巨型机器并进入准备；普通卸货不计六回合，进入准备时重发一手骰；两项必要准备满即起吊，不刷新骰子，可选准备此后关闭。准备、吊运及危机均消耗工作时间。 |
| 危机 | 摆动满立即停吊，危机期间原吊运行动隐藏、不重复结算失衡；稳定满3后摆动降至1，保留工作进度。可重复触发，不预设必发事故。 |
| 结果 | 第九天码头的正式抢卸夜班必须处理后才能休息，进入本场。安全落货获工人认可并领48美元；六回合耗尽则延期卸载，含倒下只领6美元。城市统一结账且仅结算一次。摆动满优先处理停吊；按引擎规定倒下时结束并清理临时同伴。普通卸货不按重复行动额外发钱。 |
| 待观察 | 是否退化为一直补落后侧；防摆投入是否值得；六回合余量与停吊成本。联合起吊采用独立近景舞台，不改进港货船。准备完成播放起吊并停在悬吊态；回合末失衡使摆动增加后按1～4格及前后端领先方向播放对应摆动，艾迪提醒，满4后停吊；成功播放横移落地。状态显隐由场内悬吊标记驱动，离场或重新进入时恢复舱内姿态。动画审片记录见 city-box/prefabs/review/联合起吊/；数值手感未验证。 |

通过的低机位构图与重制审片：`city-box/prefabs/review/联合起吊/通过构图重制/`。前后端动作分别锚定在两组船上绞车工的位置；已移除单中央吊钩与岸上大门架。进港靠泊模型和动画保持不变。
