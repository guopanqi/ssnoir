# 交锋实验：十个候选模式

十场独立原型已实施并完成作者逐步CLI初评。十条作者轨迹在最终版本逐项比对完整观测与事件，并生成原生回归记录，全部严格重放通过（目标提示补充前的版本）。作者自测与脚本对照分别记录；这些是等待人类反馈的候选，不是已证明好玩的模式。

| 顺序 | 场景名 | 主要决策关系 | 首次试玩重点 |
|---|---|---|---|
| 1 | 实验·橱窗里的脸 | 信息窗口、位置准备与对手认脸 | 接近是否紧张，空档是否太宽 |
| 2 | 实验·逼他出门 | 施压创造机会，过冲使对手报警 | 什么时候停手，强骰是否冲淡风险 |

## 在Unity试玩

进入Play Mode并开新游戏，点击顶部“调试”，滚动到“交锋测试（直接进入）”，选择表中带“实验·”的场景。现有调试面板动态扫描Content/scenes/encounters，无剧情前置。入口依据当前DebugPanelDrawer实现，尚未由Codex操作Unity做画面验收。

每场最好从新的游戏状态开始。调试跳转使用当前人物、库存和能力，不自动恢复基线；连续试玩的冷静和现金变化会影响下一场。CLI记录使用新档、成长1、初始十五金、五冷静；信封换人完整付款需要十五金。不要通过调试加钱后把结果与标准初评直接比较。

先自主试玩，再读场景目录中的实验记录，避免作者解法影响第一印象。优先反馈场景名、在哪一步犹豫或误解、以为会发生什么、哪些动作没用，以及是否想再玩。无需完成表格或每场都赢。

原型结束会返回世界；地址、账本、现金袋数等独立结果尚未接入主线奖励和人物剧情。原型使用现有引擎与Unity界面，没有重建Raylib客户端或额外存档系统。Unity空间表现、触控和玩家紧张感留给本次人类试玩验收。
