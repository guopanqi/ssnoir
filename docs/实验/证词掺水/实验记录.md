# 证词掺水

## 假设

快速增长会污染目标；修复污染必须撤销已经取得的部分进展。比单纯花一骰保护信息多一个关系：玩家可能已经达标，仍应主动让进度倒退。

## 规则

只有当前一手骰。听证人讲完，坏档无口供花一冷静，中档一格，好档两格。逼他说名字一骰确定两格口供、增加一句假话。核对车牌一骰，删一句假话同时删一格口供。至少四格足以指认，但任何未核实假话都会误指无辜司机。不自动结束，免费交稿；结束回合则警车到场强制交稿。数值完全公开，结果区分不足、可信与误指，暂不接入城市剧情。

## 作者逐步试玩

seed19五步，原始观测和理由见作者逐步-seed19.json.gz。先用两颗4听证词，第一次好、第二次中，得到三格。此时余下3与1，3骰追问仍有坏档；改用1逼问到五格，再用3核实退到四格、假话归零，交出可信证词，冷静五，无伤。

具体策略转折：原先希望两个强骰直接达标；中档出现后，余下两骰从“继续问”改成保证净增一格的逼问加核实。最后接受钟倒退是有利行动，不只是填满所有钟。作者知道规则，此局不是盲测。

## 尚未证明的部分

逼问加核实相当于两骰买一格保证进展，可能被玩家直接视为一个组合动作；是否仍产生情景感需人类判断。只有一手骰，表达更接近短预算谜题。当前假话量只决定是否误指一个司机，不代表更多假话牵连更多人。需补充纯听、未核实交稿、强制交稿及不足路径对照，再复核整批最终版本轨迹。已通过内容载入校验，未验收Unity触控、空间表达。
