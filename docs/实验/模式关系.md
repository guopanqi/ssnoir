# 与既有结构库的关系

比较对象为docs/手稿/交锋结构想法收集.md。这里的新模式指本项目中新的可运行组合或有效拓展，不声称发明了游戏史上全新机制；人类反馈前不把它们放进“觉得不错的例子”。

| 候选 | 既有基底 | 本次具体新增的决策关系 |
|---|---|---|
| 橱窗里的脸 | 距离走廊、位移轨道 | 偷听累积认脸，下一次回头随既往行动更危险；需提前为限定信息窗口摆位置 |
| 逼他出门 | 情绪状态机、过冲 | 中间压力制造仅一轮拦截机会，压力2与3还改变截获收益，出门不是永久解锁 |
| 枪口认路 | 多路线、多阶段 | 对手下轮枪口记住本轮最后路线，动作顺序会改变危险；硬闯与诱开各有代价 |
| 最后一页 | 多目标取舍 | 同一证据绑定具名来源，复制与来源保护占不同预算；未带走原件也会暴露未保护来源 |
| 赃款会拖脚 | 贪婪、资源代价 | 已保留战利品直接改变后续移动判定收益，割舍不可逆；当前手牌改变是否值得丢 |
| 只够一条线 | 前置投入、赛跑 | 永久修理免维护，同时压缩总期限，临时维护保留最后一轮容错；两条路线存在但优势尚待人类检验 |
| 信封换人 | 吃背包、明码交易 | 分段付款改变人质位置，也改变强抢的中坏后果，可在中途转成暴力而不是付够后按按钮 |
| 证词掺水 | 口供是货物、可信度 | 污染由自己的快行动确定产生，修复会撤销进展；有时主动退钟优于继续增加口供 |
| 封死退路 | 追猎者、承诺 | 永久解除威胁同时封掉原有安全退出，不是免费升级；余下阶段必须重建出口或伤身体 |
| 等买主现身 | 见好就收、多目标 | 两个目标依次出现，兑现第一个永久惊走第二个；准备衰减与每轮动作上限使等待有机会成本 |

这些关系都通过现有clock、动作、回合回应与结果表达，没有添加新的引擎原语。多数包含常见赛跑基底，差别在玩家何时改变动作、如何承担后果，而不是钟的名称或长度。第4、8场偏短预算抉择，第6场投资关系仍弱；把差异说清不等于证明每场都值得长期复用。
