# 等买主现身

## 假设

眼前较小的确定收获与未来更完整的证据互斥。抓送货人得到仓库地址，但买主掉头；等待买主有机会得货主账本，但等待丢失准备，不能事后补抓送货人。

## 规则与预算

0轮无人、1轮送货人、2轮买主、3轮全部离开。准备上限六，每回合最多两次：好二、中一、坏零并花一冷静；结束回合丢二准备。抓送货人需四，抓买主需六；免费捕获立即结束。理论最好开场四，送货人轮六，买主轮仍可补六，所以大目标可行。开场若只两格、随后只能升四，等待以后两次必须全好才追得上买主，风险明确。无隐藏来客随机或兜底捕获。

## 作者逐步试玩

seed19六步：开场两颗4得到三格，结束回合留一格；送货人轮用6保证到三，再用3中档到四。此时可确定拿地址，但等待后只剩二，必须在未知新手牌上连续两个好档才能得账本。选择抓送货人，剩四冷静无伤。每一步观测和理由见作者逐步-seed19.json.gz；作者自测不是盲测。

这是主动放弃更大目标，不是失败后才收小目标。当前尚未作者试玩等待买主路线，需补第二局或分支对照，确认等待成功与错过都实际可达。主要风险：开场两次准备基本固定，剩余骰空耗；判断是否只成一次收手概率题，人类反馈后决定是否保留。
