# 信封换人

假设：分段交付不仅推进目标，也改变强抢的失败后果。继续支付是确定的安全进展；提前动手可以保住现金，但要根据人质位置与当前骰子承担风险。

三只信封各五金，每回合仅交一只，交后回合末接近出口加一。满三完成交割；强抢每回合一次，远处好档靠近一并花一冷静，中档惊动一，坏档惊动二直接失去人质；接近二后好档救人，中档花二冷静救人，坏档退一步、惊动一并花一冷静。惊动满二或期限满四失败。全部信息公开显示，现金使用现有库存；新档十五金可完成保守路线。

## 作者逐步局

seed19五步，原始观测和每步理由在作者逐步-seed19.json.gz。开场4、3、1、4，无保证好档，先用1付五金，再结束回合。新手牌出现6，改变保守打算：用6保证强抢好档，接近从一到二。此时可再付五金确定交割，但选择等待一轮保十金，承担额外时间冷静。第三轮用5，近处中档也能救人，最终抢回人质、只付五金、剩二冷静、无伤。

这局提供一次公开信息引起的策略改变：不是预先写好交两次钱的固定解法。它仍是作者自测，不证明陌生玩家能理解。试跑发现混合推进后交割也可能只付两只信封，原结算却说第三只信封；已将结算文案改为不限定数量。当前文案修订使全局指纹变化，旧局为历史作者证据，最终整批须重新复核。
