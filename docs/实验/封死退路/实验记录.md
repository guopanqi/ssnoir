# 封死退路

## 假设

主动永久消除持续威胁，也永久失去廉价退出路线。不是解锁出口：玩家原本就能安全离开，承诺以后才需要准备另一个出口。说服证人后，未封门可以直接走楼梯；封门后需两骰修梯，或花三冷静跳下。

## v1作者局与问题

seed19四步原始记录在作者逐步-seed19.json.gz。先用4说服得到二格，再用4得到一格，随后3中档补齐四格，直接带她走楼梯；一回合完成，追兵没有推进，封门当前只有负收益。记录中第三步理由把五面有进展误写成“五成”，实际赔率是五面中或好，一面坏；行动依据仍是当前公开赔率。

这个局没有观察到主假设，不把走通当作模式成立。v1目标四格太短：封门所避免的威胁难以发生。目标调整为十格，保持三回合追兵期限、好二中一。最乐观两回合仍能完成，封门不是强制前置；低质量手牌可能需要更多时间。

## 当前状态

v2已经实施，尚未逐步试玩，不计入完成作者试跑的八场。封门改称楔死，避免屋顶临时携带焊枪的无交代设定。下一步根据真实手牌选择何时封门，检验是否存在值得保留楼梯出口的局面，并检查跳跃代价造成倒下时是否与成功结果冲突。旧作者记录仅证明v1过短，不证明v2好玩。没有Unity视觉验收或主线结算。

## v2逐步局及对照否定

seed41逐步十步，在三回合内不封门成功，剩三冷静。第二轮1、1、3、3较弱，但推进到七格；第三轮5、5、4、1保证补齐，保留安全出口是合理选择。完整记录归历史/v2。

随后三策略、五种子共十五局：不封门五次成功；开场封门五次成功；最后一骰保底策略五次都没用到封门。该样本没找到封门实际必要性，不能以“两条路线都成功”认定主关系成立。

v3把追兵期限缩为两回合，目标仍十格，理论最优两轮可得十六格，故不封门仍可行。缩短期限是针对观察到的低压力修订；当前v3尚待逐步试玩和对照。跳跃、放弃、倒下路径也待验证。

## v3作者局：何时值得封门

seed41逐步十三步。第一轮推进四格，不封门，等待新手牌；第二轮看到1、1、3、3，用两颗3推进到七格。剩三格、两颗1，如果全投说服就失去封门保底，因此改用1封门，另一颗1修梯。第三轮用1补好梯子，5和4说服完成，安全下楼，三冷静无伤。记录作者逐步-v3-seed41.json.gz。此次承诺由当前手牌与期限共同触发，不是假定必须选封门。

后续十五局原种子对照仍全部能不封门成功；补充0–6、8–10、12–18种子后找到seed12：始终不封门被抓；保留最后骰封门再修梯救出，剩一冷静。不同操作导致后续随机消耗不同，这只是可行路线证据，不是控制所有随机结果的因果实验。其他多数种子未触发保底，说明封门更像容错工具，玩家是否觉得这值得一个模式仍需试玩反馈。当前有四十九局v3对照，完整记录分别对应三个汇总文件。

该模式列入第九个候选。当前成功路径已试跑，跳跃、放弃与倒下边界仍待整批分支复核；尚不宣称最终验收。
