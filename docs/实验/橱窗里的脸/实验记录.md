# 橱窗里的脸

2026-10-02，独立交锋原型。状态：作者已试跑，等待人类试玩；尚未列为成熟模式。

## 假设与表达

尾随的目标不是把距离填满，而是保持接触。靠近才能听到短暂线索，距离较远能躲开回头，但目标加速可能让你跟丢。对方会记住反复偷听的脸：短期疑心可以消退，面孔记忆不消退。第三次靠近因此不同于第一次。

六段路线，名字／时间／暗号三个一次性窗口。移动花任意一颗骰，偷听判定使用敏锐；每段只能尝试一次。好：拿线索；中：拿线索并加疑心；坏：没有线索并加疑心。每次尝试均加认脸。回头时距离≤2，疑心增加1＋认脸；距离≥3则疑心消退1。疑心达到4暴露，距离达到5跟丢。既可提前撤离，也可能因冷静耗尽倒下。结果回传结局和实际听清的词，未接入主线。

## 实验修订

初版疑心上限5，好／中都无代价拿线索。三组seed的脚本全拿打法均成功，取舍被压平。先将上限降至4，出现普通全拿暴露、提前靠近后全拿成功的差别。

随后用户指出，应先逐步观察CLI再做脚本。实际逐步观察seed19的电话窗口发现：4点骰没有坏档，好／中同效使偷听几乎无风险；脚本的提前准备还借用了作者知道的后续路线。修订中档疑心代价、精确展示回头公式，并在电车段预告酒店即将出现交代，给提前靠近提供玩家可见依据。

值得记录的决策：
- 电话段用1、3点骰移动，4点骰偷听，剩余4点骰拉开；橱窗段根据回头预告退至3，而不是用完全部骰。
- 车流段听完时间后，最后一颗2点骰用于抽烟，没有再拉远。目标自动加速带来的距离变化被接受。
- 电车段看到酒店交代预告后提前靠近，酒店段按“一近、一听、两退”分配四骰，避免认脸3导致回头直接暴露。
- 最后一段距离3，目标加速后4，冷静2足以付时间税；直接结束，保留第二包烟。

## 脚本对照的用途与结果

`tools/content-validator/experiments/window-tail.py` 是本原型的数值对照工具。它只使用会话协议，不读内部变量，但策略知道固定路线，不应作为玩家体验评价。记录里的reason是策略模板，不能冒充Agent当场思考。

最终版本seed7／11／23，七策略共21局：

| 策略 | 三局结果 |
|---|---|
| 只保尾随 | 跟到交割，无线索 |
| 不拿暗号 | 跟到交割，名字＋时间 |
| 不拿名字 | 跟到交割，时间＋暗号 |
| 只在窗口临时靠近，三条全拿 | 三条拿到，但暴露 |
| 电车段提前靠近，三条全拿 | 跟到交割，三条线索 |
| 始终贴近 | 暴露 |
| 不调整距离 | 跟丢 |

同seed不同策略不是受控因果证明：操作顺序不同也可能改变随机数消耗。这里只证明这些具体策略能产生不同结局。

## 初评

值得保留的是“短暂信息窗口＋位置准备＋对手记忆”。好骰用于偷听，低骰用于确定性移动，结束回合可以主动接受目标移动。回头让历史行为改变当前危险，而不是所有问题都用相同推进收益比较。

目前更接近可解的短战术题，还不足以声称形成了优秀新模式。空档回合骰子宽裕，提前准备较容易；固定路线学习后可能机械重复；距离0缺少独立的风险意义。姓名、时间、暗号也尚未在后续情景兑现不同用途，当前主要考拿多少，不能证明三者之间已有内容取舍。大部分对手行为仍为固定预告，认脸只改变惩罚强度，没有改变其行动。暂不叠加新机制来掩盖这些问题，先由人试玩决定是否继续。
