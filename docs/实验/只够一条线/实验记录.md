# 只够一条线

## 假设与规则

临时维护每回合花一骰；永久修理花两骰，并因噪声缩短期限。永久修理应当是一种根据当前手牌判断的投资，而不是固定升级。

录音十格，搜线三格。稳住接头只持续本回合；垫好焊点再焊死共花两骰，永久可录音，但搜线立即增加一格。录音坏档零格并花一冷静，中档一格，好档两格。回合末搜线增加一格；未稳接头还会丢两格录音。录满立即结束，可以带部分录音撤离。

## 作者逐步试玩

seed19作者逐步局共十二步。开场有三颗可用的3、4、4，选择用1稳住接头，把三次录音机会和第三回合都留下。第一轮录到四格，第二轮到九格，第三轮先稳住，再用5保证补齐最后一格。结果完整录音十格、未焊接、三冷静。

关键观察是第二轮差一格时，保留第三回合的价值变得具体；此时焊接会缩短期限，不能盲目把永久修理当作更好的行动。逐步理由与完整观测在作者逐步-seed19.json.gz。这是作者自测。

## 后续脚本对照

五个种子下，手动维护五次完整录音；开场焊接三次完整，两次在九格或七格断线；不接线全部零格断线；直接撤离全部零格撤离。原始记录在对照记录，汇总在上级第二批对照结果.json。

两条路径都能成功，但当前样本手动更稳。焊接是否有足够的可读优势仍未证实，继续列为候选，不能凭存在两种打法就宣称选择有趣。不同操作消耗随机数不同，剩余冷静差异不构成严格控制的因果比较。

## 待人类验收

两步焊接是否过于琐碎；维护能否表达用手抓着松动接头的紧张感；期限代价是否明显；永久修理是否只是诱人的陷阱。未验证Unity视觉、触控和城市结算。旧作者记录的全局内容指纹早于赃款v2，整批完成时需要当前版本轨迹复核，不能宣称当前严格重放已通过。
