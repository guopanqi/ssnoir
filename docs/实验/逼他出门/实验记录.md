# 逼他出门

2026-10-02。作者逐步试跑完成，继续候选，等待人类验收。

## 假设

不是尽快把威胁清零，而是主动把威胁推到机会区间。压力2可引出人并留一次失手余量；压力3使他慌张，好结果一手截获，但一次坏结果就报警。能否让玩家根据手里的骰子改变要维持的压力？

相对普通目标钟／危险钟赛跑，压力既创造行动窗口，又改变行动收益。窗口在对方回应后打开，只持续一回合；没抓住会退回，堵截和压力各减1。警笛每回合加1，满4封街。三根钟都可见。

## 作者局

seed19，5步、一次回合结束。用1、3点骰敲门，将压力推到2，先结束让他出来；新骰里出现6点骰，观察赔率确定好档后，用1点骰把压力推到3，再用6点骰一次截获。冷静4，无伤，无烟消耗。

这里确实出现“先守2，看到强骰才改3”的计划变化，但风险消除得很容易。它更适合作为直观短交锋，而不是一场长战术考验。额外动作“砸店招”花冷静换少用一骰，当前局没有理由用；紧张局是否有去处还需检验，不因原型动作少就强行保留。

完整协议：`作者逐步-seed19.json.gz`。作者知道实现，不能称为盲测。
