# 枪口认路

2026-10-02。作者逐步试跑完成，继续候选，等待人类验收。

## 假设

你上一回合最后尝试的路决定下一回合枪口。货棚5格保底片，栈桥4格只保命；各路每回合一次。走枪口瞄着的路另花2冷静。一只空罐能一次性清掉当前枪口，但封锁提前1格。封锁每回合加1，到4失败。

区别于固定双战线：玩家动作顺序改变下一回合哪条线危险；换路既能备选脱身，又能转移敌人注意。诱饵的价值随离出口的距离和当前骰子变化，不能只按“少受2伤”判断。出路后果不对称。

## 作者局

seed19，7步、两次回合结束。先4点骰走货棚，好档进2；再4点骰走栈桥，中档进1，把下轮枪口移过去。第二回合6点骰走安全货棚，进到4。原计划下轮硬闯：现在为了改变枪口先闯栈桥也要花2冷静，不划算。

第三回合看到5点骰的赔率保证至少进1，货棚只差1；于是改变计划，用2点骰扔罐，封锁从2到3，清掉当前枪口，再用5点骰直接带底片脱身。此时提前封锁不影响立即结束，所以用时间换2冷静成立。最终冷静3，无伤，无烟消耗。

这是一处可指认的选择反转：第二回合不值得提前用诱饵，第三回合因“保证出门”而值得。不是只写理论上的两种策略。

完整协议：`作者逐步-seed19.json.gz`。作者知道实现，不能称为盲测。

## 对照与局限

逐步局之后的固定策略，seed7、23：一直冲货棚都带底片逃出，但冷静分别余1、0，seed23受轻伤；只走栈桥都逃出并丢底片，冷静余2；不动都被困；立即投降都丢底片。脚本会在冷静≤2时抽烟，其结果不能与作者局的资源消耗直接当同seed受控比较。

说明直接硬闯仍可行，转移／诱饵主要在身体资源上体现价值；尚不能证明它们必要，也不希望逼成唯一正确步骤。当前判定好中只影响走多远、坏扣冷静；主要的新关系是枪口反应，不是掷骰本身。

两个出口的进度同时存在可能让人觉得在两条路之间瞬移，这是抽象原型的重要表现风险。Unity验收时应看玩家是否把它理解成两处掩体／出口准备；如果读不通，应修空间表达或拆掉不成立的设定，而不是增添解释性长文。
