# S2 长阶段：多事件注意力网络与玩法语法

阶段启动：2026-10-12。状态：**进行中**。协调者：当前 ChatGPT 单会话；不依赖 OpenAI API、不定时后台执行。每次续研按本文件已冻结的整阶段目标推进**一个完整批次**，不再只因到两轮就停止。

## 阶段的唯一核心问题

玩家每天面对几件**同时值得关心、又无法全部兼顾**的事。行动会打开新线索、关闭机会、留下代价或改变他对城市人物的认识。要找到在四行动到跨日尺度下最少的规则，令玩家**知道在解决什么问题、真实地决定把注意力给谁**。检验的是游戏内行为和可解释的取舍，不是数学复杂度或产出模式数量。

R108/R109的边界：主动调查有独立因果收益；主线关门能触发严格切换，但强简明策略完全覆盖。这是出发点，不是成熟玩法验证。要避免再次围着同一四骰阈值模型刷参数。

## 工作方法／停止条件

- 一个阶段**不以轮数终止**。必须交付：精确规则与原始输出／最强公众可读简单策略／禁用新增机制的反事实／正常路径中至少一个严格反转或明确失败；再写可迁移的设计判断。
- 同一动作概率改变收益不等于改变注意力。重点是何时决定做哪件事；分别记录**开局分配**、**收到新信息后改计划**、**机会丧失**，不合并。
- 用户的真实反馈异步。尽可能少请设计者刷试玩；必要时只提供一个有剧情目的的可玩微型场景。**原生内容只做隔离新实验**，不无故覆盖已有正式P08/P20、原试玩和 Debug 白名单。
- Python Exact Fraction模型是数学，不是正式游戏；Actions成功也不是人类乐趣。允许失败与低复杂性结论，避免高维穷举、无意义扫参。
- 只使用当前 ChatGPT + GitHub connector + GitHub Actions，无费用密钥和轮询守护进程。若工具暂不可用保留恢复说明，**不中止整个研究阶段**。
