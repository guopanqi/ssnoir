# 当前研究队列 · 抽象决策关系

2026-10-12 接续[R302–R325三批审核](批次/R302-R325-跨机制质量审核/研究记录.md)，24项检查已收束；继续遵守[研究定位与评价](研究定位与评价.md)，**先写去情景机制卡**：公开状态→合法玩家行动/有限机会→独立反馈→下一次为何需要不同判断→最强可读短策略/固定序（允许条件停止）→同构与消融。数学效率不是体验创新，不为堆轮次数量扩大状态。

## A｜停止信息调查是否改变未来可行动对象（区别于问卷积分）

R302证明“知道足以行动的真相就主动停止”节约资源，但**预先排A→C配条件停止**已全最优。下一模型应让**行动本身改变未来哪些证据仍可获取**，从而研究“继续调查 vs 立即行动并关闭证据”这种不可逆互斥。必须与P03/P08、R269、R302和R253中途兑现强同构审查；不能仅换一个事件名称、把调查费从1/8改成1/4。如果最强预排问法仍全优，停止该变体。

## B｜空间观察产生不同种类的公开反馈而非单纯加扫描键

R310的SCAN尽管能看到准确格子，却在三版模型均对根值零贡献；即使部分观察确实有数学损失，也不等于付费全图能补回来。下一题优先寻找“站位能改变未来**合法动作/观测对象**”的最简关系，并先与R286中心追踪和R310付费扫描支配对照。允许等待/放弃收益，不得用加大站点数量强行制造难度。若普通站位+观察全面支配侦查，归档后换研究族。

## C｜回应后形成可以被下一轮重新协商的双方承诺

R318支持/反建议两分支继续已比R294只有拒绝继续多一个真实动作条件，却只需“支持则坚持，否则修改”就全最优。要研究更有意义的交换，必须让一轮选择改变双方下一轮可做的操作**并且有两种不同正常可达的选择理由**；不能只叠加新的好感度计量。与R261公开信誉蓄消、R294价格梯、R269条件诊断作最便宜反证。即使构造了更多分支也不自动独立新玩法。

## D｜跨不相邻机制族提出新的反复玩家活动（高优先级）

不能沿R编号只优化上面三种。选择至少两类其它动作原语：如有限权利转让、共享约束协议、生产与责任同时转移、行动规则在玩家操作下变化，但严格对照P02/P09/P13、R204编辑规则退化，说明玩家**每次具体重新做的决定是什么**。先机制卡及强固定/口诀反证，再写昂贵求解器。

## E｜真人理解证据（异步）

R278已有[无提示玩家卡](批次/R278-R285-诊断结构迁移与强负例/参与者卡片.md)及私有研究员规约，尚未有人类数据；如实际测试，应记录“为什么这一答改变第二问”和“你是否会提前停止调查”的解释原话及跨题迁移。不要把精确Bellman或自演的选择算真人反馈。现有精选6/历史20/Debug3保持不变，正式游戏功能冻结。
