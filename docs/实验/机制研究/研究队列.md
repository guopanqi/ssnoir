# 当前研究队列 · 抽象决策关系

2026-10-12恢复点：[R326–R357跨心理活动审计](批次/R326-R357-跨机制质量审计/研究记录.md)。四批32项实验/消融已通过精确模型与独立强策略对照，**没有认证新玩法**。下一步必须改变研究单位而不是继续把奖励、失败费、移动概率改成新数字。

## A｜无提示的人类心理活动迁移（优先）

现有R278[参与者任务卡](批次/R278-R285-诊断结构迁移与强负例/参与者卡片.md)仍未有真实参与者。已经准备**跨机制族**的小型纸面体验：[R334先知道位置还是先占位](批次/R334-R341-位置改变合法行动/参与者卡片.md)、[R350先等别人推进还是自己带头](批次/R350-R357-自主贡献与等待观察/参与者卡片.md)。先给可读完整规则/两个不同的事件输入，要求参与者写出下一手、理由、是否愿意再玩，**不要暴露最优条件口诀**。真人反馈以inbox异步登记，不能把数学求解器或虚构参与者数据当体验。

## B｜跨轴的不同玩家动作语言

- **授权下一手的控制权**：不是给哪根进度条加数，而是决定谁可以指定下一次行动以及另一方如何独立兑现其目标；严格对照R212改绑资源、R342权利协商和R350固定贡献。
- **玩家自己修订可执行操作**：修改一条操作的输入输出结构，获得反馈后再次决定怎样重组它；先反证R198“失配就编辑”、R204强阈值、R220/228算术排序口诀。
- **共同约束的共同编辑**：两个独立目标互相限制，且双方均可影响下一轮合法动作，不仅是帮助共同进度+1；先独立机制卡和正反连续局面再写求解器。

## C｜四批已证明的停止边界

R326封闭证据虽有成本，却在低错误代价时根本无影响；R334信息时效与位置移动已有简单条件规则；R342两轮协商/违约被两行口诀全解；R350还不是真正有独立诉求的其他行动者。不得靠扩大状态、添加剧情角色或微调p/奖金而自称新心理循环。

## D｜正常研究与准入契约

每个新提案先写**去情景机制卡**：公开状态、可行动作、反馈发生时刻、下一次为何要改判断、最强固定与可学口诀、消融、与20历史结构/P02/P09/P13同构对照。只有持续活动实质不同且可学、经过真实人类体验验证，才讨论新精选模式。保持精选6、候选20、Debug R09/R37/R54，正式游戏功能冻结。
