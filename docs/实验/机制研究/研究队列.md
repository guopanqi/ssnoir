# SSNoir 自主模式语言研究队列 · 2026-10-13

**对象：抽象玩法决策关系、完整交锋结构及其组合**，不是角色剧情。长期开放的研究有三个并行方向：吸收外部作品成熟结构、探索与组合决策关系、做最小体验/逻辑验证。不能按候选/精选和R编号决定有无成果。

## 第一优先｜把“危机打断”做成真的局势重规划

[本轮C01](批次/2026-10-13-模式语言与组合首轮/研究记录.md)已经在精确最小模型中证明：上一手进度1时先修复，进度2时绕行更好；有替代路线7/8成功、无替代路线3/4。但首手必然触发危机，下一步最优可压缩成一行规则。接下来建立**危机前的主动推进/整备与危机后的选择**；用独立批评和实际行动轨迹排查是否仅多了行动税或固定脚本；先不往正式游戏移植。

## 第二优先｜信息、承诺与目标可达性的连续变化

[本轮C02](批次/2026-10-13-模式语言与组合首轮/研究记录.md)发现两手时研究行动根值不变，三手时研究从4增至6，但“先研究再执行”全优。继续研究正常行动能获得逐步信息、信息揭示同时改变其他路线的可达性或退出机会；与P03/P14/R526排查同构，不把“隐藏秘密”当研究成果。若只是首手一问决定一切，记录边界后换方向。

## 第三优先｜见好就收×完成主目标关闭副机会

P09/P12与CS2可选目标的组合尚为纸面问题。先冻结可保留成果、机会窗口、风险与结算；对“额外目标无代价且总能先做”的强支配先作廉价反证，再决定有无可玩实验价值。

- 用[CS2分析](../../设计研究/Citizen_Sleeper_2_交锋决策模式梳理.md)的目标拓扑、压力动态和结果结构三轴横向寻找组合，不把九分类误称官方目录。
- 仍可随时自主另选不相邻机制族。每次给出结构假设、独立反证、验收边界及更新下一题的理由，避免每批固定八项精确扫描。
