# 交锋机制的持续研究约定

## 目的与判断

在现有交锋规则下，为玩家创造有趣、有策略、有选择的局部体验，逐步提炼可复用的设计模式。优先研究数学与系统关系；叙事包装随后处理。

追求少量规则产生丰富判断。动作多、状态多、最优解难算都不能单独证明质量。多个问题争夺行动力、改变优先级是一个分支；收益波动、动作之间的影响、时序、信息与承诺等分支也可以独立成立。设计空间保持开放，候选地图只是已探索区域的索引。

用户认可的参照是船体压力、漏洞与探索目标之间的取舍，以及生命、伤害、倒计时不同的敌人之间的处理顺序。旧实验“枪口认路”“信封换人”不作为优雅结构的质量范本。旧方向失败只否定对应假设与参数，不能宣布整个分支没有价值。

研究质量看是否产生了可复用关系、可信的适用边界或更好的试玩候选。不要以实验数量、文件数量、最优完成率作为进展目标。

2026-10-02试玩反馈补充：区别数学结构探索与游戏适配。数学原型可以暂时用隔离关系的收益数值，但不能自动成为正式游戏口径。游戏适配优先沿用玩家反复学习的结果模式与小数值尺度：用户举例的稳健行动为坏-1冷静、中0、好+1进度；风险行动为坏-1冷静、中-1冷静且+1进度、好+2进度。它们是当前参照，具体效果仍依场景与现有正式内容判断。偏离时说明必要性和学习成本；不要靠数值膨胀扩大策略差异。数学上存在例外而试玩仍像固定流程时，应降低单体优先级，不能用反例否定体验反馈。

2026-10-02第二次试玩反馈补充：基本模式合格与完整交锋合适分别判断。整段完成与边做边看获基本模式认可；边做边看有判断、猜测感与重玩意愿并存，呈现待改进。最终交锋可能趋向多个回合、持续调整和组合模式；这不是要求每个隔离实验都做成长回合。组合先检查前一回合的结果是否改变下一回合的行动价值，避免把独立重复或静态排序当成长局策略。原文与边界见 [R10](批次/R10-试玩裁决与交锋方向/研究记录.md)。

## 一批研究的闭环

每批选一个有明确判别问题的任务。通常先比较一个最小结构与一至两个对照；范围依据问题调整，开始前写明停止点。

1. **提出**：玩家会在哪些可见条件下改变判断？用最少规则表达关系，并说明它与已有候选的区别。
2. **反证**：尝试固定套路、支配动作、容量上限等廉价排除。若已解释全部差异，就停止复杂求解。
3. **检查**：仍有价值时，选择模型、正式会话、消融、邻域或可达状态分析中能回答问题的方法。不必每个假设都跑完整流水线。
4. **裁决**：保留试玩、继续研究、降级或停止本假设；写理由与反证范围。失败同样是可积累的成果。
5. **接续**：记录版本与具体下一步，更新队列和当前状态。未完成的输出明确标记，不能充当定稿证据。

兼顾两类工作：深化已有候选的适用边界；打开尚未检查的关系。不要让持续研究退化为只给三个现有候选调参，也不要不断换题而不复核已有结论。

## 快速筛选与选题更新

先用最小关系核检查：动作能否交换顺序；是否被固定路线解决；A/B是否只是对称换名；是否只有某策略容量必败才出现差异。随后加入一个可解释的手牌规则或有限前瞻作强参照。仍有价值才制作正式原型，避免反复为流程型候选找罕见反例。

模型只保留影响当前判断的状态，并合并真正等价的骰子排列或目标身份，保留组合概率。缓存续局价值，优先复用已校准的概率输入。有限模型不能替代正式引擎；正式收益、清零、期限、冷静与终止路径须逐步校准。伤势等未覆盖机制明确限定目标或标记模型外路径。

每批收尾写选题推导：新证据支持哪条关系、哪个解释被排除、下一步为何深化/换方向/组合、最便宜的判别是什么。队列可以重排和新增，不因旧编号靠前就必须继续。局部实验边界在裁决后重新审视，保持整体设计空间开放。

信息类关系另加两个廉价检查：揭示后是否还有行动余量使用信息；“首手受限、后续最优”是否已经解释开手价值。公开状态模型用开局固定真值的独立枚举复核，防止把信念更新写成重抽真值。统计可达选择时区分方向、明显决定与实际反转，并区分每局事件期望和至少一次概率；不能把它们都称为玩家犹豫频率。实例见 [R09](批次/R09-成长与行动中的信息/研究记录.md)。

R11补充三个快速检查。第一，先检查策略族的包含关系：若对照已在限制动作下自由选择结束回合，再附加固定换手规则只会缩小可行策略，原对照最优值就是该组合族的上界，不必扫描所有组合；保留例外与目标函数条件。第二，配对反例中两种条件分别核对实际到达质量；罕见配对不替代整体策略差异。第三，公开对照区分实际完成、无伤完成和首伤后的模型外继续，不把保守模型失败当作游戏失败；平手资源偏好可能导致终点前补给，真人反馈必须能修订研究目标。强滚动接近全局时，将结论限定为回合内及逐轮调整，不自动宣称长线规划。实例见[R11](批次/R11-跨回合余力/研究记录.md)。

R13补充：对容量不足的成果选择，先比较全程调整与“看首手后最优选定、其余仍优化”，隔离实际结果出现后的改计划价值。期望成果与得到任一成果的概率分别报告，避免混淆玩家的风险偏好。用最大行动数×单次最大代价加回合税，先证明伤势是否可能，能隔离就不要无谓扩展健康模型。阶段期限先用余骰容量判败，再比较强固定开启时点；增加一格后续需求可能让决策更固定，不能把更难当作更深。只查有解释价值的邻域，不铺开全空间参数组合。实例见[R13](批次/R13-启动窗口与成果取舍/研究记录.md)。

探索参数与冻结后新种子验证分开。先存一个可恢复的运行版本再长期积累轨迹；复现放在隔离目录，避免修改主工作树或绕过版本校验。方法实例与实测状态压缩见 [R07](批次/R07-顺序与选择权/研究记录.md)。

## 证据身份

| 证据 | 能支持什么 | 不能自动支持什么 |
|---|---|---|
| 纸面关系、数学模型 | 指定假设下的支配、取舍、边界与策略差异 | 正式实现一致、实际玩家体验 |
| 正式会话与严格回放 | 对应版本下的转移、操作与终止行为 | 随机源分布正确、真人觉得好玩 |
| Agent 作者逐步游玩 | 作者在公开信息下的判断与可操作性 | 盲测、新玩家评价；熟悉求解结果时须注明 |
| 真人试玩 | 可理解性、犹豫、计划变化、重玩意愿 | 全设计空间的数学结论 |

保留候选时同时检查：关系能否简短解释；玩家能否看到改变判断的条件；选择是否有实际后果；差异是否只藏在罕见状态或单一参数；简单策略是否已足够。记录这些判断的证据和局限，不设一个“有趣分数”替代它们。

比较策略前写清目标函数。完成概率、尽早完成、承担风险等目标可能相互冲突。模型的12/9/6效率分数只是研究偏好，不能写成游戏实际奖励。跨机制比较要核对基准策略的能力与复杂度，不能直接按偏离事件概率排好玩程度。

## 记忆的文件边界

- **研究约定.md**：长期目标、质量标准、工作方式。改变用户偏好或方法时修订。
- **当前状态.md**：短而可替换的接手摘要。只保留有效结论、证据入口、局限和下一步。
- **研究队列.md**：按假设编号管理待办、领取、裁决和再开启理由。
- **各批目录**：保存实际研究记录与原始证据。既有首轮、第二轮保持原路径；后续可用 `批次/R01-问题简称/`，无需迁移旧数据。

任务记录按需写以下信息，纸面任务允许省略不适用项：

```text
任务编号 / 日期 / 状态 / 负责人 / 专属输出目录
假设：预期改变哪一种玩家判断？
最小关系、对照、反证条件、本批停止点
条件：规则来源、内容与工具版本、目标函数、技能/道具等假设
方法与证据：实际命令、样本/种子身份、文件路径；尚未执行的步骤
结论：支持或否定了什么；哪些解释仍未排除
裁决与理由：保留 / 继续 / 降级 / 停止本假设
接续：下一具体步骤或命令、输入输出、需重新核对的条件
```

原始输出保留，摘要不复制全部日志。新摘要修正旧判断时，注明所依据的批次；不得悄悄改写旧结果。协调者在一次收尾中更新队列和当前状态，发生中断时由任务记录核对两者是否一致。

R15补充：分配候选需要区分“固定目标次序”和“固定资源归属”。先检查交错推进、固定次序但随结果选骰子等强简单策略，再解释自由求解的优势。若目标次序简单而资源仍需调整，应将结论缩小为资源分配关系；不拿动作树或状态数证明复杂体验。大能力差距可能让固定高低分配更充分，同等判定也可能存在动态价值，需要对照以免把整个效果归因于差异。详见[R15](批次/R15-能力差异与骰子分配/研究记录.md)。

R17补充：自愿承诺若仅删除后续选项且没有补偿，先用策略集合包含关系排除；无需先求解。停止问题先写“一步收益−坏档概率×已有成果”，用高骰优先加局部比较作强参照。检查当前容量上限与成长概率，避免不可达的停止阈值制造选择印象。比较初始平均与许可状态，再另查可达权重；三者身份不同。纸面或数学裁决足够时，可以停止接入，不要求每批产生新试玩入口。详见[R17](批次/R17-承诺与收手/研究记录.md)。

R19补充：转阶段用预先记录的门槛：已有判断条件不同的基础关系、新方向强反证、选题调整理由、实际可执行的组合及对照、关键转移与版本恢复。只宣布阶段准备完成，不把它写成好玩已证或设计空间已尽。组合优先比较只改一条规则的同状态动作反转，另报双方访问质量；不同难度下胜率差距不能单独证明交互。数值近平手采用相对最大值的容差带，独立复核冷静等次目标以发现舍入边界问题。实际带伤成功必须和无伤事件分开，目标偏好可由真人反馈修订。

R21/R22补充：若实际伤势仍可继续，须检查纯完成目标与健康偏好是否得出不同裁决；不将无伤硬约束的优势直接泛化。每级次目标亦需容差带，独立核对应覆盖逐手全部值而非只比较平均主值。正式覆盖复用已有足够轨迹，只补缺少的分支，搜索开局数与保存完整轨迹数分开。阶段候选列出小型合法里程碑偏序的全部固定线性序，族内仍优化用骰/稳险/恢复，开局择优作更强参照；固定序近乎充分时只保留基本关系。难度减轻与策略深度分开。

## 并行研究

用户明确要求并行时，采用一个协调者、两个探索者、一个反证审查者的分工；按当前可用槽位调整。小任务也可以由一个 Agent 完成。

协调者负责选择独立问题、分配互斥写入范围、冻结共用条件、审查证据并维护全局记忆。探索者各做一个不同假设，输出规则关系、最强反证和证据。审查者优先寻找固定套路、版本混用、难度混淆、信息偷看和罕见状态造成的虚假深度。多个 Agent 同意一个结论不等于多份独立证据。

先并行纸面分析或读取冻结的数据。探索者只写各自任务目录，不同时改队列、当前状态或共享 Content。需要接入正式原型时由协调者串行整合；整批规则冻结后，互不写共享状态的会话实验可以并行。若必须测试不同规则版本，使用明确隔离的检出与各自版本记录。

当前原生回放的指纹包含其他 Content 文件与校验器构建。即使只新增另一份实验内容，也可能使旧轨迹不能严格回放。运行前后记录版本，变化则分批；不能修改旧轨迹指纹绕过保护，也不能把不同版本混算。文件哈希能检测变化，不能恢复源文件；重要批次应保存可恢复的规则/工具版本或可达的 Git 提交，并记录位置。不要把用户无关的未提交改动一起打包进研究提交。

## 隔很久之后恢复

恢复顺序为 Skill → 当前状态 → 队列 → 所选任务记录 → 相关原始证据。先核对规则与工具是否变化，再判断哪些证据可继续使用；“时间过去了”本身不是重跑理由。

任务状态用待研究、进行中、已裁决、待外部输入。进行中必须记录负责人和已完成步骤；发现旧负责人已结束时，确认没有仍在运行的任务后再接手，保留交接记录。真人反馈等外部输入待补时，可以推进其他数学问题。

人工续研可在新的项目会话中说：“使用 research-mechanisms，按当前状态和研究队列继续一个研究批次，完成后更新接手记录。”若另有明确并行指示，再落实上面的分工。

周期续研适合每次唤醒推进一个有边界的任务并收尾。调度频率、执行环境与工作范围由实际自动任务配置保存；本约定不是调度器，也不保证某个 Agent 常驻。配置周期任务前，先验证普通续研确实能从文件接手。通知偏好放在自动任务设置中。

R25/R26补充：显式信息投资与普通推进比较时核对同信息、同揭示时点和副作用；满足逐结果支配前提就先排除专门调查。未知事实不同的跨批对比不可单归因于信息成本。正式覆盖第一次/第二次未定位等历史条件须与数学反例一致；历史不同就保留较窄的执行证据身份。长期搜索按关系索引进入，子任务只写专属目录，汇合时审查最强简单策略并统一裁决。

2026-10-02 R28/R29补充：对信息投资同时比较“最多购买一次但时点/骰归属仍自由”的强族。它既不等于固定首手口诀，也不能被几次重复投资反例推翻。跨回合信息可保留只是交互存在的必要关系；实际可达质量和强简单族的增量决定是否值得另做试玩。边界见R28/R29，原生或真人证据不因子Agent同意自动增加。

2026-10-02 R30/R31补充：强控制的“简单”要注明是哪一维简单。固定目标顺序仍可允许求解器优化骰归属、稳险与主动结束；开局或每回合择最优顺序使用受限续局值，不能冒称一个可读排序公式或完整玩家脚本。限制族能判别自由切目标的增量，不替代人的理解/学习证据。纯完成把首轮、末轮成功同记1，不能自动回答用户“越早完成收益越高”；时间目标另行冻结、分别比较，并报告完成时点分布。

2026-10-03 R32/R33补充：容量上界要覆盖剩余序列中会变化的有效技能。逐骰仅按当前技能的支持最大值求和是启发式，头伤转重伤恢复技能可使它低估，不能拿来剪掉“本轮不可能完成”。末回合成功主收益的支配不能扩成全维支配，失败路径健康次目标可能反向。子Agent额度中断时先核对已写源码、日志与版本，协调者能接手完成；未回传不等于所有已落盘输出无效，也不自动意味着研究受阻。

R34至R38补充：高完成率时先检查行动余量；规则变复杂不等于自由策略增量更大。容量校准一次冻结目标，惯用行动收益不膨胀，保留未调参的负结果；时间收益与纯完成分开比较，固定偏好族说明仍优化哪些资源维度。严格压力反事实必须核对全局所选动作，不能只比较修／推两值而忽略结束回合。正常前向频率、条件见证、独立后续核对、正式校准、真人体验分别记录。

用户希望长期同步HTML总览：每批收尾按队列→状态→总览更新。总览必须标明所对应批次、候选层级、是否已有正式入口、停止理由和下一问题；没有真人证据不能画成“验证好玩”。它不代替原始证据、Content或调度配置，也不能用累计文件数作研究成果。R37新增Content后旧原生轨迹使用各自冻结快照，禁止修改旧指纹。对称换名只在状态对称时成立；以未完成问题数量计成本时，不能未经证明按剩余工作总量归并状态。

R38至R40补充：目标对象规则、修／推时机、骰序、稳险要分开限制。一个维度被强简单族解释，不否定其他维度，也不自动授权改变正式呈现。工作总量相同而未完成数量不同，不能据此合并状态。根平均相同还需逐初始手与次目标核对，数值相同不扩成所有许可状态的定理。

高骰先用的损失不能全算成动态规划增量，增加看初始手牌后择最佳固定骰序的强族；利用有序剩骰后缀缓存评价各排列。严格反转需说明初始手牌／前缀与正常质量，初始手牌受限比例不等于路径反转概率。前向终端包含提前成功，条件见证合并相同公开状态的历史质量。未来产出先算能兑现几次，再做回本耦合排除，省去不必要完整求解。

R41补充：自动产出的主目标分量按进入的新回合计，不按刚结束的旧轮计；税／倒下／期限在产出前检查。回本耦合保持共同健康与判定前缀，允许直接推进提前成功，不依赖伤势有效技能单调。纯完成主值相等不代表未优化的完成时点分布相同；早完成目标另算。投资本身的增量与动态投资安排的增量分开。

R42补充：对会改变后续环境的动作，支配耦合还需保证相同判定档触发相同环境变化。证明只覆盖主完成时，资源次目标不能一起删除。环境固定后非负贡献和可以排除骰序主值；此前局部反转仍须与强初始序整体比较。指定最优前缀的联合质量不能扩称全局至少一次反转概率。

R43补充：简单响应规则达最优不自动意味着固定流程；它仍可要求按连续反馈改变方法。限制族解释哪个维度，就收窄哪个维度。隐藏判定模型启动前还应核对实际赔率预览／结果报告是否直接泄露真值；符合数学未知前提不等于符合现有游戏信息契约，不自主改UI来保住假设。独立固定真值策略执行可覆盖全初始手，但若读取主模型导出的策略，不能称独立全局优化。运行输出含耗时时，隔离比较忽略耗时，实际输入字节指纹仍逐项检查，不能悄悄绕过版本。

R44补充：改变终局奖励时，将两版本优化策略交叉按同一效用评分，先检查是否仍然最优；奖励提高不能自动当成新判断。固定资源分区要包含空组／全给一项，不复用纯双完成容量剪枝来抹掉保底。固定目标完成序仍可按结果重选骰，根值相等不扩为任意贡献序列的逐路径支配。

R45补充：任一目标完成立即退出且价值不同，更多进度可能提前兑现小项，不能无条件删除稳做；独立宽许可状态反例先查初始可达容量，必要条件不等于特定策略访问。强族历史限制从原开局计，局部独立任务从局部起点计时，要显式记录起点，不混同同名族。小平均增量与频繁响应可同时成立；研究可解释的实时策略，不以复杂求解或简单响应作为乐趣代理。

R46补充：近似判据的估值Q与执行后不断重算的实际策略效用分开；更多候选不自动让局部贪心执行更好。先用正常根定位遗漏，再推广可解释关系；一次或单根独立最优不扩称全部初始分布。锁定后独立贡献和可用多项式，无需重复自由策略递归；保证退路与最大期望分别判断。

R47补充：保证小成果／大成果的计划是一个可执行下界，不等于当前期望最优。储备枚举增加而全根策略相同，先查估值是否删掉有价值的概率机会，勿只扩搜索。贡献卷积可独立评分完整有限计划，不重复完整自由树；局部改进仍要检查原根是否值得启动。独立126根明确策略执行与独立126根自由优化分别记录；同根效用／正常动作相同不能推广任意许可状态。
