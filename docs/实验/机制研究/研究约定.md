# SSNoir 机制研究执行约定

这是执行层的小规则表；唯一目标权威为[研究定位与评价](研究定位与评价.md)，文件职责和完整数据流见[实验结构与维护契约](实验结构与维护契约.md)，可持续流程在[机制研究 Skill](../../../skills/research-mechanisms/SKILL.md)中。旧版长期积累方法原文完整保留于[校准前归档](归档/2026-10-12-方向校准前/研究约定.md)。

## 研究对象不变

先探索**可复用的抽象玩家决策关系**：有限行动/资源的分配、风险与机会、行动对后续动作价值的影响、结果反馈产生不同优先级，以及跨回合/阶段的决策循环。人物/故事/香烟/城市地图属于玩法创作应用或内容验证，**不是实验室的默认研究入口**。

研究目的不是制造最难解的数学题，也不是强求每手改道。玩家即使通过简单规则学会一种丰富的关系，也可能值得体验；判断其价值不能只看最优值差异。研究新颖性首先是玩家**持续反复做的活动与决策形态**，不是语义包装或动作数量。

## 每批最低执行

1. 写**去情景机制卡**：可见状态、A/B抽象行动、有限成本、反馈、下一判断、完成语义。
2. 查[关系索引](关系索引.md)、[20候选](结构候选20.md)和[精选库](模式库.json)里的最相近旧机制，列出什么仍然不同。
3. 先进行**支配、对称、可交换、有限容量、强固定/公开条件策略**反证；无新决策则停止变体并寻找另一机制族。
4. 仍具潜力才执行纸面/精确模型、关闭新增规则的因果消融、真实可达反向选择与频率；确实需要时才做最小独立试玩或正式会话校准。
5. 研究报告先用玩家语言说明玩法循环和为何会有意思，再记录负例、方法、版本、证据身份和下一可证伪假设。
6. 自主继续探索，不用同步等人类反馈；反馈到达就审其对可读性和玩法价值的影响。不要为算法数字和轮次计数开展无意义的参数扫荡。

## 保留的技术严谨性

- 区分结构推论、数学结果、原生 C#+Scheme 运行、Agent 作者推演、真人体验；CI 成功不代表真人认可。
- 不把模糊结算、已完成目标反复领奖或不可见真值用于人为制造选择。必要时提供合法结束/跳过动作。
- 比较自由策略、强可解释简单策略与**直接禁用新增规则**的反事实；用实际可达状态解释差别，不以罕见数学例外代替日常体验。
- 若靠“更高难度”“更复杂伤害”才能制造非零差异，先检查是否只是人为压容量；不能为了研究改第一章正典。
- 假说的首次试验、正式会话证据和真人反馈分开归档，种子相同不等于行动后的随机流相同。
- 模式库晋升、人工 Debug 白名单、工作台人类任务各有独立门槛，永不因新批次自动扩张。

## 持续维护

- 新研究只在[批次](批次/)写本轮完整记录；[当前状态](当前状态.md)和[队列](研究队列.md)持续覆写成简洁快照；[自主研究记忆](自主研究记忆.json)合并原则/失败解释，而非重复整份实验记录。
- 历史已经完成的 S/R 记录、阴性结果及旧方法在[校准前归档](归档/2026-10-12-方向校准前/README.md)和原有批次保留；需要旧细节时再打开。
- 工具及正式游戏原型均不得冒充本研究目标。研究入口从抽象问题开始，并随着新发现不断修订[探索地图](抽象探索地图-20261012校准.md)。
