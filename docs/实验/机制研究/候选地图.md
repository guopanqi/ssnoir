# 机制研究：候选地图

研究对象是现有交锋原语能产生的决策关系。质量参照仅为用户描述的船上搜索—漏洞—压力关系，以及多人战斗的生命—出手—伤害关系；不以旧实验的枪口认路、信封换人为成功范本。

目标：争取找到两三种简单、可理解、值得试玩的模式。作者分析不能认证“好玩”。保留明显的失败与淘汰，不以原型数量充当成果。

## 起始地图与纸面筛选

下表的判断是设计推断，非已完成的运行证据；运行结论另记研究记录。

| 路径 | 候选 | 最小关系 | 起始处理 |
|---|---|---|---|
| 目标分配 | 进展生成负担 | 阈值或失手产生持续压力源；修补与探索共享骰池 | 用户参照，研究其反馈，不计新发现 |
| 目标分配 | 伤害转移 | 处理甲，把同额威胁转给乙 | 暂缓：若仅改威胁名字，分配关系不变；需要先说明总威胁/时机改变 |
| 骰子匹配 | 余热转用 | 强推留下热量，借热消耗热量并推进同一目标 | 做原型；排查是否退化为固定交替 |
| 骰子匹配 | 高低配对 | 两颗骰搭配才能推进 | 暂缓：直接限制投入值会增加新入口约束；尚未说明现有原语组合的必要性 |
| 时机窗口 | 窗口储备 | 储备衰减，只在部分回合可兑现；随时可直接推进 | 做原型；排查是否固定等待到窗口 |
| 时机窗口 | 倒数打折 | 越晚执行越便宜，只有最终窗口 | 淘汰这个简化版本：若无其他状态变化且能承担等待税，固定等最后窗口即可 |
| 信息试探 | 情报承诺 | 花骰查条件，或直接押定；匹配提高以后所有行动收益 | 做原型；不读取隐藏条件作策略决策 |
| 信息试探 | 对称盲搜 | 两地完全对称，探索中无线索，只在终点揭示目标 | 淘汰这个简化版本：选择A或B没有可利用的信息依据；未知本身不是策略 |
| 风险兑现 | 分段兑现 | 备料失败损失储备；集中兑现递增收益；兑现本身吃骰 | 做原型；重点比较固定阈值与按手牌选择 |
| 风险兑现 | 风险收手 | 继续增加成果和压力；整理减压但损失成果；可收手 | 做原型；很可能只是成熟的见好就收，不能仅凭胜率保留 |
| 承诺顺序 | 承诺分流 | 花一骰永久换高速风险动作，关闭稳步动作 | 做原型；排查是否立即承诺支配、或只是已有不可逆路线模式 |
| 承诺顺序 | 预支行动 | 本轮得进度，下轮少行动；交锋结束后不再还债 | 淘汰这个简化版本：末轮免费借贷是终局漏洞；跨场债务超出本轮局部研究 |

## 研究与评价边界

- 六个原型及其消融/邻域配置均在正式 Content；配置 wrapper 只给参数，规则在 scripts/research，无运行时副本。
- 四骰、技能、三档判定、冷静时间税、伤势与结束流程均由正式 Engine 执行。
- 每个策略只读公开会话观察。固定策略对照不是玩家自测，不把模板理由称为作者逐步判断。
- 主样本统一禁用背包恢复品，以隔离交锋机制；这不改正式引擎。真人调试入场使用现有库存，需报告这个差别。
- 成功型原型首先比较完成率，再比较成功轮数；风险收手型比较实际带走的成果，失败归零。不给不同族混用总分。
- 同种子不意味着各策略逐步随机结果一致；记录完整情景结果。训练种子与留出种子分开，不能凭八局宣称总体胜率。
- 最小状态依赖反例、消融、参数扰动和真人可理解性共同判断；动作熵/切换次数不作“好玩分数”。
- 一个候选若要靠不断增加例外维持，停止投入。没有通过真人试玩的内容只标“试玩候选”。
