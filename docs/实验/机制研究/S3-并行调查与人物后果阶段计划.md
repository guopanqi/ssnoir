## 连续工作段与验收

**S3-I｜剧情合法性 / 语义约束。** 逐项冻结哪些事件同时可知、目标怎样兑现、老街为何一定要独自失败。列出能成立/缺少文本依据的依赖边与错过后果；保存消融前提，不新增正典。

**S3-II｜低成本反证与独立数学。** 只模拟抽象目标网：码头成果 D、老街先独自受阻 O→次日陪同 L、艾迪 E（独立可选、默认无到期）；统一有限行动容量，显式把日数与收益**标为研究参数而非剧情事实**。先固定优先级与分天优先级，再做有条件可观察口诀；消融“去掉艾迪”“夜莺无需受阻就加入”“只换纯并行任务”“忽略汇合奖励”，报告可达严格双向切换/或负例，不能把奖励差当策略深度。

**S3-III｜选择与后果审查。** 沿正常可达随机路径，标明玩家是否仍可完成另一条目标、同一公共状态行动优劣与第一天剩余容量；叙事审查先在最小人物情景独立进行，不在 UI 增加钟表或多加按钮。

**S3-IV｜正式能力与交付。** 只有发现需要引擎证据且不能被已有正式原生见证覆盖时才做隔离 C#+Scheme；否则解释为何不做。归档 Exact Fraction 程序、CI 和原始输出；更新当前状态/记忆/队列/模式库和工作台；准备无提示审阅，真人反馈异步。

## 通过/失败定义

- 通过**技术探索**：仅依据故事中已存在的时序展示至少两个并行且能真实兑现的关注目标、独立规则关闭反事实、强人类可学策略基准，以及可达分歧；或者清楚地证明一部分关系只有固定流程价值，并保留负例。
- 通过**情境准入**：一页纸的选择理由来自人物和事件的公开后果，且不会破坏夜莺次日陪同与莱恩身份揭晓顺序。
- **尚不能通过真人好玩验收**：未有针对新样例的独立真人反馈，不加入 Debug、20认证模式或剧情正典。
- 数学负例不是失败的产量指标：若艾迪默认无截止只造成有限行动的可学优先级，就记录、结束该方向，转向上下文带来可达性变化，而不编造新截止。
