# S3-W｜一份物证，两次正式用途：原生消耗、强反证与玩家信息

日期：2026-10-12。阶段计划：[S3-W五阶段目标](../../S3-W-单份物证原生守恒长阶段.md)。来源为现行 `main` 的正式 C# 与唯一 Scheme Content，承接已完成的 [S3-V双用途静态追溯](../S3-正式老街东西路线/唯一烟盒跨阶段用途审查.md)。本阶段**不重复计入 S2-D、新R编号或正式精选**。

## W1. 同一物品的原生资源合同

正式物品ID：`半包「老金牌」香烟`。取得条件在 `scenes/world/三封信.scm` 邮箱追逐后根据 `拿到线索` 分支调用 `grant-story-item! cigs-item 1`；不是每个正式新档天然拥有。

- 东侧柜台真实动作 `node-show-cigs-at-counter`：东门廊完成、东回廊尚未完成、西侧还未揭出莱恩、玩家拥有该物品才能生成这张卡。它不要求投骰，要求 `req-item cigs-item 1`，效果 `advance-east-gallery! 2 #f`。
- 莱恩交锋 `encounters/巷子.scm` 的真实动作 `node-cigs`：在**第二幕、莱恩形态1**的卡组，要求 `req-item "半包「老金牌」香烟" 1`，效果 `advance-lyon! 2` 且 `cigs-used? #t` 防止同场重复。
- 引擎 `SceneManager.ExecuteAction` 执行实际行动时检查 `SlottedResource` 与 `ActionCost` 的道具名称、数量，再把行动槽中的物品从 `InventoryState` 扣除。正式 Session 的 `AddActionChoices` 只有 `snapshot.Inventory` 的可用数量满足 `req-item`，才会生成可执行操作。**缺物品时可以仍看见 `node-cigs` 这张场景卡，但 Session 操作目录没有执行它的选项；不能笼统宣称卡片完全隐藏。**

## W2. 原版莱恩交锋 C# + Scheme 逐手原生验证

[可复现驱动](../../../../../tools/content-validator/experiments/s3_gold_cigarette_native.py) · [官方原生与严格重放CI](https://github.com/guopanqi/ssnoir/actions/runs/38205724249) · [升级含正常世界路径的四Job CI](https://github.com/guopanqi/ssnoir/actions/runs/38206113163)。

入场 `--session encounters/巷子 --seed 19 --growth 4 --item 半包「老金牌」香烟=0/1`。`--item` 是 `SessionRunner` 官方支持的测试环境设置，不是在世界剧情里凭空制造该物证。驱动**没有注入主线故事阶段、没有改 `巷子.scm`、没有直接跳过弗兰克第一幕**；通过公开合法的卡片导航、行动和回合推进实际进入第二幕。

| 对照 | 真正执行与原生观察 |
|---|---|
| 测试环境物品0 | 莱恩形态1的“把烟盒扔到桌上”**卡片可见**，但没有合法 item-cost 操作；物品始终0 |
| 测试环境物品1 | 原卡有合法 item-cost 操作；执行前背包1，执行后背包0；该卡不得再次执行 |
| 同一阶段多用 | 一份物品一次耗尽；不是“携带道具只解锁行动但不消费” |

**证据级别：真实正式 C# + Scheme 对原版后续交锋的原生行为验证。** 两份真实玩家可见操作目录/事件快照分别保存为原生逐手记录，并已通过**无物证6步、有物证7步的严格内容指纹重放**。覆盖了进入后续交锋时物品0/1的动作显隐、实际扣除与重复使用限制；**未验证正典世界的邮箱追逐→东侧柜台→第3节莱恩**完整路线，也**未验证玩家主观理解**。成长4与固定seed是明确的测试条件，不能推成自然玩家分布或胜率。

初次 CI 对照曾因为实验测试用 `growth=10`（正式技能容许范围-1到4）失败；第二次又把CLI路径 `encounters/巷子` 与观测场景名误作字符串全等，误报正常导航。已改为成长4、对比入场场景名并在CI明确标记，这两次是**测试驱动错误**，非金牌烟故事结算缺陷。后续成功见链接。

## W3. 整个第一章世界的贯通：明确尚未通过

[原世界无头新档自然入口探针](../../../../../tools/content-validator/experiments/s3_world_entry_probe.py)只按公开合法操作推进，**无任意Eval／`debug-finish!`／伪造物品／强制设置`story-stage`**。正常从 `--session world --seed 19 --growth 4` 出发，逐步检验能到哪一处。即使探针走通第一次委托，也不能据此写“柜台→巷子已原生贯通”。

**实际取得的新证据（2026-10-12）**：[不注入任何物品的原世界新档实验](https://github.com/guopanqi/ssnoir/actions/runs/38206113163)，在 `--session world --seed 19 --growth 4` 下，采取30步合法公开操作，正常接案、邮箱追逐、归来探望、独闯老街、夜莺带路后到东侧柜台，**第一幕真获得物证、真实柜台行动把物品从1扣为0**。测试使用了作者知道的邮差身份作为覆盖路线，并不代表初见玩家的策略，也未改写主线状态或通过测试夹具送物品。第一轮报告因“提前成功返回结果缺settings字段”而CI失败，已修复数据结构并经后续原生运行通过；这是测试报告格式错误而非道具逻辑错误。

**仍未贯通的是同一世界存档的柜台消费之后继续进入第三小节《巷子》且亲眼确认道具不可用。** 已分别证明原世界合法获取→柜台扣为0和原版《巷子》在0/1份下的动作合法性与扣除，但它们仍是**两份不同会话**；不能用它们冒充同一存档的跨阶段回放。之后应沿前一条30步世界路径继续到西侧揭晓、第二封信、经理耐心、三日后巷子；如果遇到游戏内有意义的行动压力或剧情门槛，应保存正常阻塞而不是编辑状态让它通过。

## W4. 最强可读策略／反事实：为什么“同一件能用于两处”仍不足以证明好玩

[Exact Fraction最小强反证](../../../../../tools/content-validator/experiments/s3_one_item_option_bound.py)，CI与W2分Job：**这不是SSNoir的剧情收益模型**。冻结一个简化的两阶段选择：玩家已到东侧柜台、有一份烟盒，立刻交出有边际效用 `e`，若保留至未来以概率 `q` 遇见可以用它的事件，届时边际效用 `l`。公开信息不包含未来真值。

无额外状态的最强简单策略：

> **现在用当且仅当 `e >= q × l`；否则保留。**

这已是该两阶段代理的整个最优规则，没有可冒充“深度”的动态规划差额。如果误把东侧+2进度、莱恩+2进度当完全同一种货币，且未来出现的可能性不超过1，那么**现在使用弱支配未来使用**。可见价值差只能来自**不同人物、失败风险、未来是否可达、剩余骰行动**，不能仅凭“两个+2按钮”宣称出现了丰富抉择。

四项单规则消融：

- 删除后续用途 `l=0`：交出通常弱支配，不再有保留理由。
- 删除当前用途 `e=0`：保留通常弱支配，没有真实二选项。
- 增加第二份不稀缺烟盒：若两处都可达就都能用，**消除了单份物证的互斥性**。
- 提前把未来是否能遇到莱恩的真相揭给玩家：信息有价值，但这会变成作者先剧透才能优化的情景，不是现有剧情允许的玩家信息。

例：假设 `e=2,l=4,q=1/2`，公开条件下“现在用”和“以后用”模型期望都为2，完全预知未来时则为3；高达1的“预知增量”是**假设信息优势**，不是实际游戏奖励、概率或玩家玩法复杂。此前 S3 的作者全知西优先DP也不能拿来做正确路线教程。

## W5. 人物后果／无提示理解裁决

[无提示第一人称阅读稿](无提示情景.md)。真实第一章没有明白告诉尼尔“你需要留烟盒打莱恩”；东侧字幕只保证现在拿不回烟盒，玩家可能合理地觉得交付物证是推动调查的正常行为。等以后才得知另一种用途，**不该因为没有预测未知未来而惩罚玩家为‘策略不好’**。

用既有真人反馈校验：R37认可行动中出现新问题改变计划；R50不接受目标含混的数值规则；R54批评已经无法切换时的假选择。因此最重要的不是烟盒前后+2的净效用，而是当前“用掉有立刻进展／留着有可能成为证物”的理由清晰、后果有剧情兑现。此情境没有新的人类评价，不晋升新模式、不增加 Debug。

## 阶段裁决与恢复

**完成 W1、W2（含严格重放）、W3前半段真实世界获取与柜台消费、W4 与 W5 的准备；W3同存档柜台→第三节莱恩尚未完成。** 研究可用的最简结构是“单份道具在未知未来的多个真实位置可使用，但是否现在消费取决于玩家能预期什么”。这属于**已有有限资源＋分阶段不确定机会的组合**，暂不认证为新独立玩法。

下次最有价值的独立问题，按顺序是：
1. 在已成功的**30步原生世界路径**之后，尝试西侧路线、揭晓莱恩、第二封信、经理委托、三日等待，再在《巷子》观察烟盒卡有卡无合法操作，保留同一世界资源史与严格回放；失败时保存最后公共状态，不造假改档。
2. 比较“**没有烟盒但仍成功与莱恩交锋**”的实际结果和持有烟盒路径，判断是否需要不靠+2奖励完成情节；只有实际结果可读才探索玩家行为，而不先加隐藏状态。
3. 在现行东/西路线、进入莱恩前的时序上审**玩家是否知道物证将被谁拿走**；如果不知以后用途，不把作者攻略写入卷宗。
4. 可能的人类阅读反馈异步，继续独立内容审查，不等玩家。

**未修改任何正典 `.scm`、引擎功能、付费 API Agent 或 Debug 白名单。** 本报告将包含后续世界探针最新状态，不会让尚未完成的 W3 冒充成功。
