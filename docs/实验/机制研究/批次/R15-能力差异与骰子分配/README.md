# R15试玩：按需用骰

2026-10-02，一个基础分配原型与一个对照，数学和正式会话已核对。可与R11/R13一起留到之后试玩，不要求现在反馈。先玩，再读[研究记录](研究记录.md)中的求解与策略提示。

在现有“交锋测试（直接进入）”中选择：

1. **研究·按需用骰**：乙判定额外+1。
2. **研究·同等判定对照**：两项均无额外修正。

从单人无伤、四项技能均为1的新局进入，先不用烟、酒、药品。入口设置冷静5，不会清除已有伤势。物品未被脚本禁止；若使用，之后反馈时请注明。

## 规则

一回合内完成工作甲、工作乙，两项各3格，全部完成立即结束。甲乙各有稳做、快做，每次投入一骰，共享单人四骰。完成的工作不再显示行动卡；结束回合还有工作未完成即到期。

稳做：坏−1冷静，中无变化，好+1进度。快做：坏−1冷静，中−1冷静且+1进度，好+2进度。结束回合另花1冷静，未用骰子丢弃。

按需用骰中，乙每次判定额外+1，收益相同；公开判定概率显示这一差异。对照只取消修正。无物品或剧情奖励，无隐藏目标。健康单人四骰从冷静5开始，最多四次损失加一次结束税，不会首次受伤。

这是隔离基础关系的一回合原型，尚未作为完整多回合交锋裁决。

## 之后反馈什么

记住一两手具体判断即可：哪颗骰子给哪项，是否因刚才的结果改变分配，以及你自己总结的做法。判断这个分配有没有值得思考的地方，还是很快变成明显固定套路；对照是否帮助理解，也可一起评价。

不需要完整逐手日志，初始条件和道具使用有助于辨别边界。研究者未核对Unity画面与触控，载入通过不代表呈现已验收。
