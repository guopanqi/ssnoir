# RECIP-01—05：公开承诺、第三方生产性证据与后到外部机会

日期：2026-10-15。研究领域：抽象 Gameplay Pattern Research。恢复基准是 SIGNAL-AUDIT01（main 703eeada）。这批以完整的双方行动后果、普通安全选项、外部独立替代和最强静态合同为共同参照；没有进入正式角色、剧情、Unity、精选或 Debug。

本批是连续三个机制问题、五个编号的可执行纸面模型：RECIP-01/02 研究承诺如何诱发别人投入及未来履约边界；RECIP-03/04 研究对方投入后新的外部机会、延迟信息与参与激励；RECIP-05 研究退出赔偿和提高成功报酬能否在总分一样时产生不同的后果。三份 Python 标准库 Fraction 回归脚本均配独立按世界前向计算或完整条件收益核对。**只验证指定纯分离策略下的激励相容和玩家最优合同搜索，不声称已枚举所有混合、池化及完美贝叶斯均衡。**

## 0. 旧研究与去重边界

- TRANSFER01：对方事后根据公开确定利益 ACCEPT/REJECT 可由普通条件菜单逐行动等价替代；第三方存在不是社交博弈证据。
- TRANSFER02 与 TRL/SIG：低类型能低成本模仿时，事先臆定的证据准确率失效；信息和权利必须区分。
- GRC：对方为合作先行支付不可替代的成本，若预见玩家将利用后来的旁路而不履约，会拒绝合作；可信条件承诺是重要强对照。
- HEDGE/FOCUS/OPTION-AUDIT：保留旧选择权未必有价值；必须审安全等待、行动余裕、是否可提前知道信息。
- STAKE/OBLIGATION/SUBMIT：相同玩家总分，不代表每个人保留同样的成果和承担同样的损失。

本批的“契约/第三方”是成熟设计原语的条件组合与社会选择成本审计，不把历史结论当作由本轮原创发现，也不借外部电影故事声称得到玩家体验反馈。

## RECIP-01：事先约束自己，才能诱发合作方的生产性行动？

**玩家活动**：在对方进行自费的有用工作之前，选择给出有约束力的合作承诺还是保留单方面自由。

类型H/L各半。证明本身是需要对方实际完成的工作，不是免费生成的抽象二值信号：H付1、L付5；得到合作时对方获3，否则获0。玩家合作H的基础价值8，合作L基础价值-8；SAFE收益1。为了研究未来后果，本批将合作机会放在GOOD/BAD状态，发生概率q/(1-q)：GOOD价值8、BAD价值1，可信履约时玩家需要付出成本2。对方先支付证明成本，之后事件才揭晓。

- NO_CONTRACT（没有强制履约）下，玩家证明后可以拒付以节省2，对方无法收回证明成本，所以两类型都不自发PROVE；玩家只剩SAFE1。这里假定玩家可无成本单方背弃且对方正确预见，不能用作所有谈话/口头承诺都无效的经验结论。
- FULL（强制无条件履约）让H获得3−1=2、L获得3−5=-2，因此H会PROVE、L不会。q=1/2时H分支收益是GOOD 6 / BAD -1，L分支SAFE1；玩家根7/4=1.75。
- CONDITIONAL（合同事先规定仅GOOD履约，BAD允许无责退出）时H预期收益3q−1，L为3q−5。q=1/2时H PROVE/L PASS；H分支GOOD6 / BAD SAFE1，L SAFE1；玩家根9/4=2.25。

### 第一组反事实

| q=1/2、无额外签约费 | 纯分离政策下玩家收益 |
|---|---:|
| SAFE或无有效承诺 | 1 |
| FULL无条件合同 | 7/4 |
| CONDITIONAL明确情况的合同 | 9/4 |
| 第三方*同时替代证明工作*，成本0 | 11/4 |
| 上述强替代成本1 | 7/4 |
| 上述强替代成本2 | 3/4 |

注意“外部替代”不只是免费检查真假，还实际提供原本需要合作方完成的生产性证明；因此比单纯INSPECT更强，不得错误地把两项互不相同的工作视作同成本同动作。

签约若另有固定花费1，FULL的玩家值降为3/4，CONDITIONAL降为5/4，后者仍严格高于SAFE1。它们是效用代价模拟，**不等于增加一个有限行动窗口**。

## RECIP-02：可信承诺仍可能没人愿意开始

对方只在预期报酬严格大于实际成本时开工。CONDITIONAL中H满足3q>1，即q>1/3；低于该阈值或恰好相等（本模型并列时选择PASS）时，H不再证明，玩家SAFE1。q=1/4时即使合同写好了，仍不存在这条生产性分离路线；q=1/2时才出现。FULL虽然可以在较低q维持H开工，却可能令玩家在坏状态承担损失：q=1/4时玩家合同价值7/8，反而不如SAFE1。

这是**另一人的参与约束改变了玩家可用行动**，不等于简单修改奖励倍率；但它依然是成熟的激励相容/可信承诺结构，不是不可表示的新动作原语。也不能把阈值边界上的并列策略称唯一均衡。

程序：tools/content-validator/experiments/pattern_bilateral_commitment_20261015.py。包括各类型PROVE/PASS激励、五个q样例、先行成本消融、独立按四个隐藏世界前向复算。

## RECIP-03：真正后到的新机会，让玩家放弃刚刚促成的投入

**变化后的玩家动词**：与对方谈合作条件 → 对方付证明成本 → 看到另一个机会 → 在承诺及替代机会之间兑现或放弃。该流程与“单次判断证据真假”不同，但必须找最强静态条款反证。

独立H/L各半、证明成本H1/L5。玩家接受H工作的价值8，L的价值-8。玩家先公开成功时支付给对方的报酬T；对方是否PROVE由预期成功收款决定。外部机会R∈{2,7}在对方生产证明之后出现，两者等概率且与类型独立。对方证明成功并不强制玩家履约；玩家可以兑现H、支付T，或改做新机会R。玩家见证明时在纯分离候选下后验H。低类型偏离模仿的效用亦逐个检查。

T=3时：R2，玩家合作净得8−3=5；R7，玩家改道拿7。高类型认为有一半可能履约，预期收入3/2−证明成本1=1/2>0而愿意PROVE；低类型3/2−5<0不会模仿。四个真实世界(H,R2)/(H,R7)/(L,R2)/(L,R7)玩家收益为(5,7,2,7)，根21/4=5.25，安全不签约时外部机会期望9/2=4.5。

这同时满足**真实他人投入、后到消息、实际弃约改投**，但仍是可用一行简短条件规则描述的成熟组合。

## RECIP-04：最强策略对照推翻“必须等消息才有优势”的过强说法

仅固定T=3时：
- 看见R之后有条件回应：玩家21/4=5.25；
- 后期看不见R，只能预先固定回应（履约）：19/4=4.75；
- 不允许以低代价取消（违约惩罚3），仍固定履约：19/4。

**如果允许事前重新选择T∈{0,...,8}，则看不到R也可选择T=2、固定履约，达到21/4；违约惩罚3时也能T=2达到21/4。** 因而所谓动态优势在这两个更强对照面前消失。不能只用固定T=3来误证新社交循环。

如果R在对方证明**之前**公开，玩家可用T=2并按R2时合作、R7时直接转别处，根11/2=5.5。相同报价T=3，提前公开与事后公开都令玩家根21/4，但提前公开H在R7时不再徒劳证明，其全体期望证明成本由1/2降为1/4。**同玩家收益、不同他人付出的沉没成本**，不能由纯玩家标量根看出来。

程序：tools/content-validator/experiments/pattern_bilateral_outside_option_20261015.py。两种信息时点×是否观察新机会×惩罚0/3，并对0—8全部报酬枚举、从每个隐藏世界独立前向核对。所有“最优”均限制在这一公开纯分离候选和离散报价范围，不包含池化或混合均衡最优性的声明。

## RECIP-05：退出补偿 vs 更高的成功费用——同值异果

换用R∈{2,8}和H证明成本2/L成本5，其余玩家合作H价值8、L价值-8。允许玩家除合作成功支付T之外，主动改投外部机会时向对方支付取消补偿D。玩家见证据后根据自身收益决定履约或退出；双方在事前知道条件。

- 合约A：成功报酬T=5，取消补偿D=0。
- 合约B：成功报酬T=3，取消补偿D=2。

两合约的纯分离激励都成立：H的预期证明收益[(5+0)/2]−2或[(3+2)/2]−2，均为1/2；L为−5/2，故不模仿。玩家在R2履约、R8退出；玩家四世界收益分别：
- A：(3,8,2,8)，平均21/4；
- B：(5,6,2,8)，平均21/4。

双方收益**期望都同分**：玩家21/4、对方平均1/4。但对方在H、R8这一具体世界的净损益分别是A的−2（证明成本全损）与B的0（补偿回收成本）；在H、R2世界则分别为+3与+1。**同样的平均值隐藏了谁在什么时候承担损失**。这不是逐状态同构：不同真实世界中的现金流和后果并不一样。

强反证：只提供T=3且D=0，H在R2有付款可能1/2，其收入期望3/2不够弥补成本2，所以根本不投入；T=4、D=0也只是收入2等于成本2，本模型严格参与规则下仍PASS。只有在承诺方式实际改善其期望净收益时，才可能启动合作。在T=0..8、D=0..3的小范围全枚举中，15份合约支持此纯分离候选，最佳玩家根为21/4；这不是一般合同设计的全局最优保证。

程序：tools/content-validator/experiments/pattern_cancellation_transfer_20261015.py。可复核4个世界的双方收益、严格参与诱因、15份候选合约及同值异果对照。

## 横向综合：我们研究到了哪一种真正不同的玩家活动？

1. **单方优化（CRISIS、HEDGE、OBLIGATION）**：玩家研究哪个任务还能完成、保留哪些旧选项和后期合法行动。
2. **观察行动作推断（TRANSFER、SIGNAL、TRL）**：别人自利的生产性信号是否可信，何时被模仿覆盖。
3. **相互约束及回应（RECIP）**：玩家先改变合作对方的收益条件，对方决定是否承担成本，之后新局面反过来改变玩家履约选择。RECIP-03有具体后到退出与沉没成本，RECIP-05有同值异果，但整体已能被成熟可信承诺、筛选与后到机会的有限树建模，**不认证独立原创原语**。

比“至少发生两次策略改变”更高的研究门槛是：玩家能否看懂对方为什么不愿行动、为何签约后必须为部分结果负责，且是否愿意按照同样的可学习规则再玩。数学阶段只能提供有意义的待观察局面，无法回答这类体验判断。

**最大负例：** 只固定一个预先写定的报酬，能制造出看似显著的临场动态价值；但加入同等自由度的事前报价优化，差异可能消失。今后必须同时对照*最佳事前条件合同*，否则不能把“动态优化胜固定流程”当新模式证据。

## RECIP-06：同样合理的报价，可以同时容许合作与无人参与

RECIP-03在T=3、R∈{2,7}、H/L证明成本1/5时，已经构造一个纯分离策略候选（只有H证明，玩家见证明且R2时兑现）：玩家21/4、H净证明收益1/2、L如果模仿净损失7/2。**这只说明指定分离策略各方愿意遵循，不代表该策略是唯一可能的均衡。**

进一步显式审计“不出示证明”路径上的接收方信念。若两类型都不证明，则玩家看到一份突然偏离原策略的证明时，Bayes本身无法强制给出后验π=P(H|证明)；按允许的离路径信念π，玩家在R2接受的收益为π·8+(1−π)·(−8)−3=16π−11，接受优于外部R2需要π≥13/16；R7接受则需要π≥18/16，不可能。

- **分离策略成立**：H证明、L不证明，证明路径上π=1；玩家R2兑付、R7退出。H愿证明、L无动机伪装，玩家21/4。
- **悲观的不合作均衡候选也成立**：H/L均不证明、离路径π<13/16；玩家即使遇到孤立证明也仍在R2/R7退出，两类型不会为了被拒而承担成本，玩家9/2。π=13/16时本脚本以玩家平局选择HONOR，H就有动机偏离，故无法以此具体平局原则支持无人证明候选。
- H/L都证明时在证明路径上π=1/2，玩家面对R2或R7均选择EXIT；双方都不愿白付证明成本，因此不成立。
- 只有L证明时证明后验π=0，玩家EXIT，L无动机付成本，故不成立。

以上是**指定纯策略、后验与离路径信念下的候选完美贝叶斯均衡条件核对**；未证明混合均衡的不存在性，也未进行精炼（refinement）筛选或唯一性裁决。离路径信念的自洽空间使仅从分离策略收益21/4得出“该报价必然促成合作”的说法过强。

一份可执行的托管支付（R2出示证据即强制支付T3，R7可以退出）不再由玩家对不寻常证明的主观信念决定付款，H预期拿3/2减成本1严格愿证明，L预期3/2减成本5严格不愿证明。在本合约机制的这两个类型决策中，悲观信念无法阻止高类型付证明成本。**托管是改变行动后果的制度，不是改写玩家相信某人的对白。**

程序：tools/content-validator/experiments/pattern_signalling_equilibrium_selection_20261015.py。枚举4种类型证明策略、接收方最优选择，并对离路径信念0/16至13/16核验边界；本地Fraction脚本断言通过。仅用于揭示非唯一性，非完整博弈求解器。

## 历史复核补充：GRC01—04 已有更强的真实互相作用先例

重新查看了 [2026-10-13 可信合作与信息公开逆转](../2026-10-13-可信合作与信息公开逆转/研究记录.md)。GRC01已证实未来低价旁路能让协作者提前拒绝不可替代的HELP，从玩家可能得11降到实际安全3；GRC02已有可执行排他/条件合同恢复合作的强对照；GRC03/04表明更早公开信息可能因为他人的自主参加约束而使玩家变好或变坏。**因此本批没有“第一次发现双向自利选择”的原创性。** 其独立价值在于补充以下可迁移的验证工具：

1. 第三方出示证明必须区分“投入真成本”与“纸面随机信号”；
2. 只审一个纯分离策略不足以证明Scenario一定进入该策略，必须查看悲观离路径信念与参与均衡；
3. 强静态报酬、可信条件合同与外部替代工作均应列为同等自由度的对照；
4. 玩家收益相同而第三方承担的沉没成本、退出补偿不同时，保留双方的逐世界收益向量。

这四条是**证据审计规则与已有机制的组合边界**，不是新独立机制。与SIGNAL-AUDIT01、TRL02/03及GRC01—04关系已标记入知识地图。没有新的真人意见可替代缺失的体验环节。


**进一步的均衡精炼警告：**在RECIP-06的数值中，低类型即使收到成功报酬T3的概率为100%，也无法弥补证明成本5；它的PROVE从自身角度严格不划算。相反，高类型在对方接受R2证明时愿意投入。因此如果玩家使用“偏离信号只有哪种类型真正可能受益”的前瞻推理，悲观离路径信念可能被Intuitive Criterion等信念精炼排除。本批只证明它在允许任意离路径信念的纯PBE候选条件下自洽，**不能用这条不合作候选证明稳健的均衡多重性或Scenario必然不可靠**。反过来说，必须向玩家呈现足够清楚的伪装成本，否则他也未必按理论精炼形成预期。这是模型选择与玩家理解的开放问题。
