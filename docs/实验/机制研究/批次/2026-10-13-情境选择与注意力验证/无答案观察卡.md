# STG01｜《明天之前》无答案观察卡（未执行）

**数据状态：尚无任何真人或真正独立 Agent 盲玩记录。** 该卡说明怎样获得后续证据，而不是参与者意见汇总。

### 实验条件与分配

打开 https://guopanqi.github.io/ssnoir/witness/ ，先使用默认“开始一次未知版本”，让A/B通过随机分配确定；研究者复现按钮藏在折叠区，不给首次参与者看。两个版本共享人物、时间、事件后果，唯一操纵是危险的具名递交是否可执行。不同版本应优先分配不同参与者；若同一人重复试验，保留顺序与之前已见信息，不当作独立盲测。不能向参与者解释X03、HARD/SOFT或“玩家自由表达”假说。

### 严格记录三次决定

第一幕17:00：参加者在记录、证人之间选择一项。记录其在事前提及的两件关切、是否因“只能选一项”感到自然/做作。

第二幕21:30：参与者看到具名证词的曝光风险，并选择匿名提交/延后/（若合法）具名递交。保留**选择前**描述中是否提到证人的明确要求、公共听证迫切性、自己之前的承诺；记录是否看见了被禁用的按钮。不给出标准答案。若说“我其实想违约”，不要自动翻译为“喜欢更多行动权”。

第三幕次日：参与者面临具体的后续动作菜单，应让他先描述是否理解为何不同历史让某些动作出现/消失，再实际选行动。注意在witness:redact与witness:delay两种历史中菜单完全一样——不是每条不同文字路线都改变可行动作。

结束后**先不评价好坏**，问：“你在第一幕想兼顾而没能兼顾的是什么？”“哪一个后果最出乎预料？”“如果有动作本来能做但现在不能做，你认为是谁阻止了它？”“你是否愿意为后面的某个人重新选择，为什么？”若回答非常简短或觉得这是数学换皮，也逐字保留。

### 评价与停止条件

分别记录“注意力真实取舍 / 对行动权的解释 / 后果是否理解 / 情景自然程度 / 愿不愿复玩”与原话；不要用作者判断代替参与者表述。收集是否首次看到页面、是否事先阅读答案、浏览设备、分配版本、完整复制轨迹。结果不能由脚本预测，不能把不同受试者的文本输出作为相同的客观评分。

失败也应保存：若大部分人认为单一行动限制做作，优先修复事件本身的可信度；若只能辨别文字结果而说不出哪项可行动作真正变化，停止为地图增加“新机制”节点；若都采取匿名提交，不足以证明SOFT无价值，仍需结合他们对可违约权的理解评估。

这不是 SSNoir 正式故事和角色剧本。它只针对抽象机制进入可玩的生活情境时的主观表现。没有新反馈时继续自主研究其它方向，不虚构偏好。


### 作者控制的历史菜单消融（非已执行真人试验）

额外网址 https://guopanqi.github.io/ssnoir/witness/?flat-menu=1 只提供**统一的两种下一幕行动**。第一二幕和发生的后果仍与正常版本相同。这个对照用于问“结尾文字不同是否已经足够让玩家觉得作出了实质选择？”，而非预设玩家必然认为条件菜单更好。

只有在真正具备独立参与者与平衡条件顺序时，才考虑加入这一组对照。不能让同一位玩家先体验A的结局再以完全不知情状态体验B。记录每组具体出现了什么动作，而不从作者设计了5种菜单倒推玩家察觉到了5种模式。
