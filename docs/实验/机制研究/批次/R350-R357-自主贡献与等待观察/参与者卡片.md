# 无提示纸面试玩 B｜别人也会推进共同工作

**仅供参与者。** 请勿在结束四局之前查看研究员规则答案或研究脚本。

每一局有三回合。你和另一个行动者正在推进同一个进度目标：累积**3点**就成功，最终获得6分奖励。你每回合可以：

- **投入**：本回合自己贡献1点进度，个人付出1分成本。
- **等待**：自己贡献0点，个人不付出成本。

另一行动者在你每回合决定完毕之后，会自行贡献0或1点。它本局的行为规律固定不变，但你起初不知道属于哪种：

- **AUTO**：每回合都自己贡献1点，不管你做了什么。
- **RECIP**：只有当你**上一回合**自己选择“投入”时，它本回合才贡献1点。它不会因为你本回合刚投入而立刻回应。

两种规律开局各占一半，研究员已经私下确定本局是哪一种。每回合结束你可以明确看到**你贡献了几点、它贡献了几点、共同进度现在几分**。下一回合再选投入或等待。第三回合结束后，如果进度达到3，你的净得分是**6减去自己累计投入的成本**；如果没有达到，净得分是**0减去自己累计投入的成本**。可以在已经达标时继续等待，不要求多做无意义投入。

共进行四局，研究员重新独立选择每局的类型，且不会按你的选择临时修改它的类型。

每回合写下：这次我选投入/等待，原因是什么；上一回合我观察到了什么；我猜另一方采用什么行为规律（或还不确定）；它实际贡献了多少；我是否需要改下回合计划。

四局结束，说明哪一次“自己不出力”是主动策略，哪一次只是无所事事；这种判断你是否愿意继续再做几局？有没有一种简单办法已经能解释你所有选择？
