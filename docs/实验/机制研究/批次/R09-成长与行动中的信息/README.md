# R09试玩入口

先在现有调试面板的“交锋测试（直接进入）”选择 **研究·边做边看**。建议从无伤、冷静5、技能均为1、没有恢复品的新局开始。

A、B可以互相替代，完成任意一条即成功。每条在开局就独立确定为短路3或长路6，各占一半；首次获得进度时揭示路长，已有进度保留。只限一回合。未知时显示的一格是揭示检查点，不是终点。四张行动卡沿用惯用的稳做/快做收益。

先玩几局，再看求解报告。重点反馈：发现长路时有没有认真考虑继续还是换路；长短不确定是可接受的机会，还是只像猜运气；自己的判断有无影响，是否愿意再来一局。没有遇到犹豫也直接记录，不要求交完整日志。

对照入口 **研究·路线明示对照**：路长在开局已经可见，其余规则相同。若两者体验差不多，未知信息未必值得保留。技能3、4会明显弱化当前参数下的取舍，首轮先用技能1。

此前的新模式 **研究·整段完成**仍可试玩：两回合完成5和3；半成品回合末清零、完成保留。它主要检查安排整块工作与判定后的计划调整；信息模式主要检查未知机会与已投入进度之间的判断。两者没有合并，分别反馈。

```bash
./run --session encounters/研究·边做边看 --seed 1801 --growth 1
./run --session encounters/研究·路线明示对照 --seed 1801 --growth 1
```

上面的种子未用于R09正式对照；复用同一种子不代表不同操作仍会得到相同判定。

[研究记录](研究记录.md)包含结果与裁决；[版本](版本.json)绑定源文件、模型和运行快照。运行快照保存本批Content与原生校验器构建，解压到新目录，可在兼容.NET运行时下严格回放 `正式对照/*.json.gz` 解压后的JSON；已经在隔离目录核对成功、到期两条轨迹。这不是完整Unity工程。

复算模型：`成长边界.py`、`行动信息.py`、`研究分析.py`。它们更新本目录的对应结果，复算时保留原证据副本。`正式对照.py`拒绝覆盖既有输出目录；完整重跑应使用新的隔离检出与相同版本。真人评价和Unity画面、触控尚未验证。
