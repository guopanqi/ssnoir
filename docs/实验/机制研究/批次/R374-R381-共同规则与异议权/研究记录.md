# R374–R381｜共同规则、独立目标和有限异议权：玩家改变的是别人的可行动作

2026-10-12。第三条不相邻心理轴：**修改双方共同适用的合法规则，另一方拥有自己的利益和一次异议/否决权**。不是新增SSNoir剧本NPC系统。代码 `tools/content-validator/experiments/r374_r381_shared_norm.py`、CI `.github/workflows/ssnoir-r374-r381.yml`。同构参照R212资源改绑、R342独占协议、R350固定产出、R358独立目标的委托。

## 去名机制卡与独立利益

连续3个时点，玩家自己的公开希望结果是A、B、A。另一参与者有**与玩家目标独立**的固定私人偏好θ∈{A,B}各半；它每次都希望执行θ，这能为它自己获得1。共同规则初始**OPEN**：A/B均合法。玩家每手可以保持OPEN、设置ONLY-A或ONLY-B；每次改变目前的公开规则付出1/4玩家效用，规则持续到下一时点。

另一参与者总是**先依当前合法集合追求自己的私人偏好**。如果玩家制定的限制不准它做θ，它手里还有一个仅能用一次的公开异议/否决权：本模型中它会立即花掉异议权、把规则重置OPEN，再执行自己的θ；异议一旦用尽，下次规则便能强迫它执行与自己意愿不同的合法行为。另一参与者的实际选择和是否异议都会在玩家已经选规则**之后**公开；它不是玩家可以提前读取的私密θ。

**重要边界**：另一方的异议政策是“当前被阻止就动用唯一否决”的固定理性短视行为，不是完整的跨期最优对手Agent。模型里的限制他人意愿是为了研究法定行动集与相互权利的形式，不表示赞成在真实世界中强迫或操纵他人。

本批值得保留的少量“规则惊喜”是：玩家某一手公开希望B，却**主动提出ONLY-A**，不是为了当手得到A，而是使另一方花掉一次性异议权，从而在下一手改变双方可行动集合；它不同于单纯按当前需求锁定规则。这个过程确实提出了“谁能修改规则、谁可以拒绝、什么时候消耗有期限的异议”的行为问题。但它仍与经典有限否决权/公共约束博弈相邻，并存在伦理语义风险；后续若在叙事作品里应用，更需具体人物与代价的审慎表达。没有人类数据、正式环境或新增精选/Debug。
