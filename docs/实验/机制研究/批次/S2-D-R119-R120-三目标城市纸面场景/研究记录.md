## 玩家能看见的一张纸

在一座黑色电影城市，剩下**两天，每天三次行动**。你手中同时有两件事：

- **A｜夜莺的信（主线）**：到第二天末前，设法截住即将交付的信。需要累计3个行动进度；当你调查达到2格，才有机会发现递信人的路线。一旦你直接拿到信（3格），递信人的踪迹会消失。
- **B｜帮艾迪一个忙（另一件当下值得关心的事）**：必须第一天办成，需要累计2格行动进度；若当天未完成，他只能自己承担后果。这项任务与夜莺的结局**并不自动合并**。
- **C｜顺着递信人追查（最初尚未出现）**：A调查达到2格时开放，需2格完成，目标是知道幕后是谁。这一条线可能因为A提前完成而永久失去机会。

每行动选择一项可以推进的事情，获得0/1/2格之一（数学模型各概率1/3）；已完成的成果保留。未完成B跨过第一天则关闭，C在A达到3格后若尚未完成则关闭，第二天末一并结算。没有额外装备、专门探查按钮、维持压力条或仓库资源。

**这一页纸的目标不是告诉玩家最优奖励多少**，而是引导一个心理循环：

> 我想赶快截住信。但艾迪今天就需要帮忙。如果我继续追信，可能发现递信人；然而直接截住信又可能错过真正的幕后。这一次行动我先给谁？

研究计算以A成果价值2、B=3/2、C=2的效用作为冻结审计代理。它不代表真实玩家的情感权重。

## R119：真正比较新增的是哪条因果？

六行动 Exact Fraction / 四种结构反事实：

| 规则开关 | 代理期望 |
|---|---:|
| 本纸面三目标自由动作 | **2359/729** |
| 关闭C这整条支线 | 比完整版本少 **563/1458** |
| C已开放后不再被A完成关闭 | 比完整版本多 **235/729** |
| C不需先调查A便从第一手开放 | 严格不低于完整版本 |
| B取消第一天期限 | 严格不低于完整版本 |

完整自由策略比**六条固定目标优先级**中最好的规则（固定优先级 C→B→A，按合法性跳过尚未解锁目标）多 **1/6** 期望效用。正常最优策略路径与该固定优先级出现严格相反选择的**访问质量期望**为79/243；这不是独立玩家比例，也不是已证明的人类计划改变。

代表状态1：第一天已过去两手，B仍0格、A仍0格、C还未开放，余4手；最优下一手应舍弃B转而调查A，而固定B优先会继续B。代表状态2：第二天剩1手，A已有2格、C未做；应先完成A而不是再去碰C，因为该手完成C的期望低于完成主线的期望。两者都可通过公开时间与进度解释。

## R120：更像玩家的公开判断是否已经足够？

追加强规则家族，只允许看**当前已完成／已投入进度、余下几手、第一天期限、C是否开放**；规则不读取动态规划的隐藏Q值。简明条件包括：

- 第一天最后一手，若B还几乎没推进，则考虑弃B转主线，而非把沉没成本再投入下去；
- C尚未推进且只剩最后一手时，优先救得完的主线；
- B已有进度、第一天快结束时，若任务还可完成则优先照顾紧急B；
- A到达接近完成的位置时，先检查追查C是否值得保留，而不是机械完成A。

在核心B价值3/2场景，**这类简单公开策略完全等于自由动态规划的2359/729**；B价值2场景亦相同。B价值1场景下，所测试策略尚低于自由值38/243，但未证明有更好的口诀不存在。

**裁决：**R119的固定优先级缺口1/6并不支持“复杂规划更有趣”。R120证明这种三事网络可以被少量条件性、可学习的优先级规则完整处理。让玩家在故事里**体验到选择的情境意义**，比寻找数学上更难的公式重要。

## 重要的公平性失败：不能直接上架试玩

这里存在一个**违反直觉的跳越问题**：当A已有1格，某一次行动结果+2，会直接把A推进到3格。C理论上要在A达到2格开放，却在同一次行动达到3格而立即关闭；玩家未曾获得在「C开放但A未完成」的公开状态作出选择的机会。数学允许这条轨迹，不等于玩法公平。

在正式纸面试玩／Scheme原生验证之前必须先解决**揭示→响应→关闭**的事件顺序：至少验证“跨过2格时先暂停在2格，让玩家收到新线索并得到一次明确可选的下一步”的机制是否会破坏原有容量结论。不得在原R119数学计算中默默把跨跃修正为分段推进；新版本需要单独计数与消融。

另一个风险是玩家对“B价值3/2”未必同意；这只是一种研究偏好，不能替作者预先规定艾迪的命运比掌握证据轻。
