# R21：伤势与目标偏好

2026-10-02，已裁决。本会话研究者。用户持续目标为“继续研究”，本批结束不终止线程目标。R20体验仍待补，下一数学问题R22已启动。

## 问题与冻结条件

R19无伤目标下的整顿/推进取舍，是否依赖“无伤比实际完成更重要”的研究偏好？把伤势机制纳入后，玩家愿意带伤赶工是否会改变结构判断？这次保持甲5/乙3、三回合、初始冷静3、稳险与整顿恢复2、冷静上限5，清零/全部保留两种结算。只扩展模型，不新建Content或调游戏参数。

正式伤势依据Engine主源与公开会话：冷静溢出一比一加伤势；首次随机落四处，已有伤加深同一处；轻伤1至3只有头伤影响本实验knowledge判定−1；重伤4至6取消该技能修正，新回合少一骰；中途重伤不回收当前剩骰；7伤倒下，跳过本步后续推进。整顿只恢复冷静。单人新局，无永久骰损/宿醉/物品。

预先比较效用P实际完成−λP曾受伤，λ为0、0.25、1。系数是研究偏好，不是游戏奖励或真人估值。模型假设独立公平骰、首次四部位均匀。数值平手依次较低受伤事件概率、较低成功加权伤势、较多成功冷静，每级最小化指标均采用1e−12容差带。参见[数值平手修正](数值平手修正.md)。

R19的91.11%是“无伤全部完成”的另一事件。不能把98.44%与其直接相减说成游戏通关改善，也不能把首伤自动算失败。三种偏好都允许受伤，λ1也不是无伤硬限制。

同样开局剩甲5/乙3、冷静3、健康、三回合、手牌1/2/4/5：纯完成选择2给甲快做，健康偏好选择4整顿。若纯完成被迫先整顿，完成概率损失1.56个百分点；若健康偏好被迫先快做，其自身效用损失0.0331。该初始手牌质量两条件均1/54。两策略各自前向轨迹至少遇到一次双向严格偏好反转状态的概率为43.71%/43.85%，共1320个共享可达严格反例。反例门槛是双方自身效用损失均≥0.01；这些是模型访问概率，不能称为真人犹豫频率。

更重要的反证：[简单参照](简单参照.json)中，纯完成时取消整顿仍有98.25%完成，仅比自由98.44%低0.19个百分点。健康偏好时取消整顿自身效用少0.1353，同时更多受伤。最高骰优先但仍优化目标/稳险/换回合，纯完成97.81%，差0.63个百分点；固定先做完甲或乙约96.8%。因此不能沿用无伤模型的结论，宣称本场的整顿维度在所有合理目标下均有强策略价值。取消整顿参照仍可动态分配骰子和目标，不代表全部选择已被一个固定套路解决。

**裁决：保留“目标偏好会改变策略”的明确关系；下调对R19整顿维度的普遍性判断。**现有整段留力仍可试玩，真人须裁决是否在意带伤、是否逐轮改计划。不给λ强加游戏奖励，也不为挽救候选添加更高伤害。R22另立一条最小关系：部分进度就解除持续威胁，看看是否在纯完成目标下也有直接策略价值。

## 方法、证据与效率

主模型递归缓存四维值（完成、曾伤、成功加权伤势/冷静）。独立C++定长表以回合和手牌容量递增迭代，独立健康索引及转移实现，只共用正式概率校准输入。六组各126手初始状态，共756手、每手四个指标全部吻合，最大差8.89e−16；不是仅比较平均完成率。定长表每条件覆盖907200个表位置（含终止/许可状态），状态数不作为策略体验证据。

初复核发现主要概率一致、次目标因极小舍入差错误分级。修正每级平手容差，重算六组并重新逐手核对；主完成/受伤概率未改变。新的方法把模型、目标偏好、策略限制分开，后续直接复用健康状态与校准输入，避免每个候选从头模拟游戏。

正式校准复用R19技能1的35条/317步。预先冻结[补覆盖条件](补覆盖条件.md)后，按6601至6650升序只寻找缺少的头伤后续行动；第10次完整游戏（6610）覆盖，保存第一条即可停止，其余九次搜索完整结束但没有头伤后续证据，不并入完整保存轨迹数。新增保存1条9步，严格回放通过。合计用于伤势校准36条326步，包括3次头部轻伤判定、3次重伤当轮行动、1次重伤新回合三骰、1次倒下及医院重置，三个判定档齐全。新增不是玩家样本，不估计胜率或部位概率。
