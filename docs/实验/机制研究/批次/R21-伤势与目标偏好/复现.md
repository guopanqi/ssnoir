# R21复现

`运行快照.tar.gz`保存R19冻结运行输入、R21模型/独立迭代源码与结果、旧校准轨迹和新增头伤覆盖。应解包到独立临时目录；勿替换主工程文件。使用Python3、clang++（C++17）与.NET9运行时，不要求Unity。

在恢复目录执行：

```sh
python3 docs/实验/机制研究/批次/R21-伤势与目标偏好/复现.py
```

该脚本在临时目录编译独立求解器，重新核对六组全部初始手牌四维结果、严格回放新增头伤轨迹，并重做36条伤势专门校准。它不启动新游戏。完整版Python最优核对：

```sh
python3 docs/实验/机制研究/批次/R21-伤势与目标偏好/独立核对.py
python3 docs/实验/机制研究/批次/R21-伤势与目标偏好/偏好可达.py
python3 docs/实验/机制研究/批次/R21-伤势与目标偏好/简单参照.py
```

时间字段依机器变化；比较语义值和逐手容差，不要求日志字节相同。`头伤覆盖.py`是已经执行的采样程序，已有证据时会拒绝再次生成；不作为恢复步骤。
