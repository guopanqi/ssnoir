# R478–R485｜另一方有私人目的，声明就能可靠地传达它吗？

2026-10-13。R462让另一个主体真正按照自身跨期效用行动，仍由一句玩家策略解释。本批转而检验**玩家依据什么能知道另一个主体想要什么**；不默认“另一个人发出信号”就意味着其真实意图可推断。使用一个**单次信息/回应**的极简博弈，先反证虚假的心理深度，再考虑是否值得扩大为反复活动。本批8项完整纯策略均衡枚举，无真人、无会自行学习的AI代理。

## 去情景协议与玩家心理循环

发送方有自己才知道的稳定类型θ=A或B，等概率。发送方希望接收者**正确理解自己的类型**（正确被理解得1，否则0）；接收者也希望判断正确得1。两者利益在这件事上完全一致，故已对“欺骗/敌意才导致误会”的解释给予最强反例。

发送方从合法消息中选一种；接收者见消息后选择判A或判B。若发送方要付可验证证据的成本，收益另扣其成本。依次穷举双方完整纯策略，保留所有满足：①发送方每个隐藏类型都愿按自己利益选择该信号；②接收者在实际出现的信号上按后验正确分类达到最大化的策略。普通廉价说法的**离路径**信念不凭空唯一指定；真实可验证的PA/PB会因物理事实及合法性强制为对应类型，不依赖它是否在均衡路径上出现。

区分三个机制：廉价声明0/1都允许任何类型发送；通用声明1也允许任何类型但有1/4成本；真实可核对的证据PA只能A型提交、PB只能B型提交，且收件人验证后必须按可核对事实解释，U为不核实的普通消息。证据成本可调作退化检查。这里不是“多一张凭证就必然增加乐趣”。

## 实质差异与最强负例

在冻结模型中，**“多次听同一个人的宣称”与“得到一条有物理可验证后果的行动”不是同一种信息对象**。如果一个类型能用不可伪造、其成本足够低的凭证让自己被正确分类，它有自身利益上的动机采取可核对的行动。反过来，口头声明即使和接收者完全同一目标，也存在误会仍自洽的均衡。

但两个局限非常严格：

1. **均衡选择仍是理论假设**：R478的1/2–1范围不表示实际真人会在每次局中随机均衡，也不是概率分布；R483无法断言哪个类型必然付证据成本。
2. **它只有一次真实选择和一次回应**，不是反复有意义的玩家工作方式。可验证证据影响判断是经典信号博弈/可信行动的知识，不得因此自动认证新模式。若将来研究多期持续独立意志，需要实际会改变未来合法动作或长期机会的可验证行为，而不只是连发三条廉价声明。

与R430的公开条件承诺以及R454的付费核验区分：这里直接检验**另一方自己选择发什么、为何发、哪些信息在任何均衡都可靠**；不把玩家收到的外部答案当自动可信。它仍是经典信号机制，不新增精选6、历史20、Debug3，也没有真人或正式游戏功能变更。
