# R45：公开专注与承诺时点

2026-10-03，已裁决。协调者四骰模型／正常前向与独立审查者一／两骰小树已汇合；没有活执行句柄。保留公开承诺的基本关系，当前不新增单体Content。下一R46研究能否把决策压缩成可解释的实时判据，不新增规则扩大差异。计划与停止点见[有界计划](有界研究计划.md)。

## 关系与边界

四公平独立骰、基础技能1、冷静5；甲3兑现1，乙6兑现2，完成任一立即离开、半成品0。未专注可随意推两边；行动前可免费专注一次，所选项公开准备值+1，另一项永久关闭，原进度不退还。稳／险使用惯用收益，无恢复／物品／额外回合。四动作加税最多耗5，隔离伤势，只优化终局兑现效用，不优化冷静或提前离开。

与R17不同：放弃选项有判定补偿，故只删选项的集合包含反证不适用。与R13不同：以关闭补救路线换持续公开判定优势；未专注版本的效用1.488623590与原路线取舍数学值相同，但不追加原生证据。

固定一项且永不转向时，早点专注用更好判定模仿之后行动，无理由拖延。动态价值须来自保留换路选择，而非判定提高本身。初始承诺族按初始手择甲／乙，仍优化后续骰序；一手反馈族包含初始承诺，也可试一手后承诺或从此永不承诺。不能用固定锁甲或强迫先浪费一骰作弱参照。

|---|---:|---:|
| 全程决定专注时点／对象 | 1.706183437 | 0 |
| 完全不专注 | 1.488623590 | 0.217559847 |
| 开局看手即专注 | 1.694005058 | 0.012178379 |

自由与开局有43种手严格差，一手族有26种；种类数不是正常路径频率。开局族保留约94.40%的“专注相对不专注”增益，自由增量仅完整效用约0.714%；不能把全部判定补偿收益宣传为延迟承诺价值。基本关系有区别，但本参数尚不足以优先占用另一个单体试玩入口。

自由选定策略终局：失败`75583/839808`，甲`191167/1679616`，乙`49529/62208`；总质量1，甲价值1、乙价值2的加权值与主递推精确相同。不是完成率1.706，也不是更多骰序等于更好玩。

平手优先立即承诺的指定最优策略正常前向：0／1／2颗已用骰后专注的概率分别`755/1296`、`127/432`、`10/81`；没有终局前从未承诺的路径。延迟专注`541/1296`约41.74%，专注对象不同于首个推进对象`863/7776`约11.10%。这些是模型策略质量，不是玩家体验；高延迟频率与小整体收益增量可以同时成立。

## 正常前缀与独立局部例子

初始手1／1／1／3，质量1/324。选定自由策略先投1快做乙：坏／中后专注甲，续局值11/12；好后专注乙，续局值37/27。三分支条件质量1/3、1/2、1/6，联合质量1/972、1/648、1/1944。总值643/648，开局最优专注值53/54。此具体正常首手可解释“有苗头争大，没有苗头保小”，只计这手前缀，不冒称全局至少一次反转率。

独立小树许可状态甲剩1／乙剩4、骰1／5：立刻专注最佳为1，先1快做乙后坏／中锁甲得1、好锁乙得2，期望7/6。该状态可由两次分别甲乙好2到达，但独立审查没有证明它被父最优路径访问；不拿它代替上面的正常前缀。

## 一个不能省略的容量判断

“快做更多进度”未必通用支配稳做：若完成低价值甲会提前退出，可能阻止继续争乙。独立宽许可域里110个指定同骰／目标动作稳做胜过快做反例证实了这一点。父模型因此先保留未锁完整稳险，锁定后只保留主效用弱支配的快做。

本批四骰总需求9、每手最大2，余n骰的必要条件是`a+b≥2n+1`。若快做这一步可以完成甲，a≤2，则b≥2n−1；用完此骰后最大容量2n−2，乙本来就无法完成。因此实际初始容量域内提前完成甲不剥夺可能的乙2收益；范围明确的主效用耦合可以成立。110个反例全部不满足此必要容量条件；条件本身仍不证明特定最优路径可达。

完整动作自由与仅快做逐126根精确相同。该实测及容量证明不能扩成任意未锁状态／更多回合／自动产出的定理。独立报告保存更完整推理。

## 验证、修订与版本

实际执行四脚本均exit0：`专注模型.py`、`审查两骰枚举.py`、`承诺前向.py`、`整合核对.py`。独立486条件、锁定972单目标对照；父整合2430值与36概率分量、正常首手三分支及前向全部通过。独立小树不是四骰全局独立优化；正常前向共享主模型。

## 为什么下一步研究实时判据

强初始族的骰子仍由求解器动态优化，不能称完整玩家口诀。另一个简单响应若达到自由，也仍可能有真实选择。R46将复用本版本，以“现在专注的值”和“先试一手、再专注的值”做滚动比较，再限制试探为最低骰快做乙。先检验解释和遗漏，再判断是否值得呈现给玩家，不加成本／复锁／高倍率救题。
