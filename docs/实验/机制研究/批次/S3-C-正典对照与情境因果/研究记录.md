# S3-C｜不让纸面机制改写第一章因果：人物/故事独立审查

日期：2026-10-12。基准 Git main 此时手稿和原生隔离实验均已存在。**本批是内容语义反证，不是新玩法、数值研究或玩家证据。**引用来源为 `docs/章节内容手稿/第一章.md`、`docs/故事线手稿/夜莺故事线.md`、`docs/故事线手稿/作者真相.md`，同时对照 `批次/S2-D-玩家真选择与原生审查/无提示纸面情境.md`。以原本故事文件为事实权威，绝不覆盖剧情手稿。

## 研究目标

S2-D 数学与正式 C#+Scheme 在一个**隔离实验**中分别确认：

1. 发现消息之后，玩家确实拥有多条可以执行、后果不同的行动；
2. 花一行动正式交信，会关闭尚未完成的递信人追查；
3. 第一日四骰内，交信／追踪／帮助艾迪可能带来互斥结果。

这三条是**技术模型**。S3-C反问：现有第一章情节真的赋予“交信→线索关闭”和“艾迪当天也在同一行动窗口”明确的因果理由吗？

## 不扩展系统的迁移方向

**方向一（与第一章已写结构更相符）**：第一节的意义不在“交付或继续追查”，而是通过不同的**筹备路线**去完成同一目标。交付后必然发生追逐，成为第二节的调查引线。第二节中当码头见证人、老街调查、艾迪生活同时开放时，可用 S2-D 的**不同期限 + 新信息揭示后主动分配注意力**语法，但不预设哪件事会关闭哪件事；要求具体手稿明确是谁、为什么离开、错过会带来什么后果。

**方向二（第四节可选，更待作者确定）**：第三封信出现后同时有“寻找莱恩”“调查剧院安全”“和彩排中的夜莺见面”，各自有不同成本和故事性后果。是否存在“完成一项会关闭另一项”的剧情因果必须另行书写，而不能为了数学严格反转凭空制造。夜莺彩排代表梦想的短暂纯粹呈现，不应该因为玩家选择而以隐藏的效用值奖惩爱情。

两方向**只提出结构迁移的可检验位置**，不是改写剧情或保证未来两个按钮都值得点击。

## 新阶段质量判断

**数学成立、原生因果跑通，只能证明一种“可复用决策语法”技术上有可能。** 把这种语法搬回一个具体故事之前，至少需要：

1. **合法的情节时序**：人物真正同时开放，不能随便把第二节艾迪事件移到第一节；
2. **可解释的机会丧失**：玩家为什么因为做甲就错过乙，必须从人物行动和场景本身自然产生，而非一个隐蔽的脚本锁；
3. **独立的后果兑现**：救一个人、查到新线索、尽快完成委托，各有清楚的故事后果，不能只换进度条名称；
4. **消息与人类理解**：玩家应该能够一句话理解新消息与两个仍可执行的动作；等待无提示真人反馈前，不可宣称“情感深度已证”。

这些要求与现有R37反馈（新问题打断计划）、R50反馈（目标含混）、R54反馈（剩余行动根本不能转向）直接相符。
