# 双向因果与操作回流：A解锁B，B关闭或恢复A，是否产生新的玩家活动？

2026-10-14。基点 main 612f3bff0688c9844b68e39ecf2243339cbd6ceb。遵守[研究定位与评价](../../研究定位与评价.md)、[实验维护契约](../../实验结构与维护契约.md)；沿[EDGE-B](../2026-10-14-B行动资格与延期兑现/研究记录.md)提出的开放问题，不重复从库存许可增加一个数字。**原始可复核实验**：[三族统一Fraction程序](../../../../../tools/content-validator/experiments/pattern_bilateral_decisions_20261014.py)。本批去情景，只谈A/B/U公开活动；没有新增正式内容、精选、历史候选或Unity Debug。

在研究开始时核对当前反馈：inbox仍仅历史R37、R50、R54；questions无新增回答。本批没有真人、独立第二Agent的无提示试玩、正式C#+Scheme原生验证。以下均为同一研究者设计、精确模型、独立反证视角；不能将数学称为游戏体验证明。

## 研究问题与事先反证

上批PL-AB02是“一手A取得匹配B的未来消费资格；B可消耗也可保留”。它确实在完整开局引出低价值日准备、高价值日兑现，但全树可改名为库存CRAFT/SELL，非新独立原语。

本轮**横向取两个不相邻关系族**：
1. **不可逆门槛/撤权**：A产生B使用权，B使用后关闭尚未完成A；是否真正要求反复计划，还是有一个固定先后顺序？可不可以付费再开A？对应历史PL-D02、PL-CLAIM03、PL-C05，绝非首次发明。
2. **内生负担/容量循环**：B会让今后B自己不能再做，需A处理负担重开；与单次闸门不同，可在5—8日反复出现。对应P11压力、PL-REC01互惠动作，既要和无代价B比，也必须和简单优先级规则比。

审查两种误判：**(i) A→B 与 B→A两支箭头不一定在真实最优开局两支都被使用；(ii) 有数学收益差不代表新的心理活动。** 每一个对照均从同一个全零初始状态求解，不将人工拼好的中途状态冒充可达历史；观测只在当日公开，DP没有偷看后续机会。

## GATE：真正支撑犹豫的是早期机会 × 不可逆关闭，不是表面A先B后的解锁

### 冻结三日规则

每日一手，SIDE得1；WORK_A使进度+1，第二次工作完成A一次得8。完成B只需一手CLAIM_B：原则上必须曾做过至少一手A；普通时得6；**第1日**的B价值在行动前公布，高14/低4各概率1/2。若A还未完成便领取B，余下A工作被永久禁止；已经完成A的成果不会失去。没有B重复领取。

完整开局第0日最优WORK_A；来到进度1时第1日：
- 低B=4：WORK_A完成A8，第2日CLAIM_B6，总14。
- 高B=14：立即CLAIM_B14，A被关闭，第2日SIDE1，总15。

根为(14+15)/2=**29/2=14.5**，强固定A→A→B得14。此时玩家不是换得分对象而已：终局(A完成,B完成)的概率分布为(真,真)=1/2、(假,真)=1/2。这些是**不可互相用货币替代的结果标签**；总分只是冻结模型的一种展示权重。

| 全局同起点对照 | 根精确值 | 核心发现 |
|---|---:|---|
| A给B资格，提前B会关闭A，早期高低公开 | **29/2** | 真正有高B放弃A、低B完成A的分叉 |
| **只移除**B关闭未完A | **18** | 高B可先CLAIM再WORK_A，终局100%双目标都完成 |
| **只移除**A是B的前置条件 | **29/2** | 不仅根一样，**最优正常可达动作历史和结果分布完全一样** |
| **只移除**第1日的高低价窗口（普通B总为6） | **14** | 固定先完成A再B，早期改道消失 |

**最重要的阴性结论**：尽管写着A→B许可，删除该许可前置关系丝毫不影响根值、最优选中的正常路径和终局分布。A→B是一个真合法性约束，但在实际开局策略里不是必要的因果边；B关闭A与早期报价共同产生玩家的改选。不能说“有两支箭头所以产生双向联动”。

与PL-D02已知“提前真实结算/关闭后续工作”的比较：该结构保留为明确的**不可逆承诺×机会报价×结果取舍**成熟组合例，不认证新玩法机制。

## REOPEN：B既关闭A又允许付费重开，是否形成真正循环？

在GATE基础上改为四日，新增第2日公开的紧急U，概率1/2出现、立即得9。若B提前关闭了A，可用一手REOPEN_A重新开放此前未完成A的工作，但不会自动获得A的进度或得分；之后仍须再WORK_A完成。这是新的四日协议，不能把它与三日GATE的分数直接作为单变量比较。

基准根 **21**。正常路径四种等可能的公开高低机会×U是否出现：

| 第1日B报价 | 第2日U? | 第0—3日最优路径 | 得分 | A/B终局 |
|---|---|---|---:|---|
| 低 | 无 | A→A→B→SIDE | 15 | 两者完成 |
| 低 | 有 | A→A→URGENT→B | 23 | 两者完成 |
| 高 | 无 | A→B→REOPEN_A→A | 22 | 两者完成 |
| 高 | 有 | A→B→URGENT→SIDE | 24 | A不完成、B完成 |

这有真正的“后悔/付费补救或接受损失”分叉：高B已使A关闭，但第2日没有U就付行动重开A，有U则领取U且放弃A。允许REOPEN的A/B全部完成概率**3/4**，禁REOPEN只有**1/2**。

| 四日规则变动 | 根值 | 正确解释 |
|---|---:|---|
| 可REOPEN、仍关闭A、有U | **21** | A→B后可根据外部机会选择再开A |
| 仅禁REOPEN | **39/2=19.5** | 失去补救选项；是真实价值，不是免费撤销 |
| 仅去掉B关闭A | **23** | 从未关闭，重开不需要；不能归功REOPEN |
| 仅去掉紧急U | **37/2=18.5** | 高B后固定花一手重开A，**动态补救抉择退化为顺序** |
| 仅去掉A为B前置条件 | **21** | 最优实际开局及终局路径仍完全相同 |

**最强无聊口诀**：先A；第1日低B就完成A，高B就B；若过早B使A关闭，第2日有U拿U，否则重开A再补完；最后用剩余一手B或SIDE。这条四条件规则完全解释21，不需要高复杂递归策略。REOPEN主要是已有CLAIM03有损撤回/补救×机会竞争的组合，新增菜单能改变实际结果，但不构成证明新“循环”的独立形式。

## BURDEN：真正反复的B→负担→A→B关系是否优于单次闸门？

### 完全不同的六日协议

不继承GATE/REOPEN的奖项或动作窗。每天只一手；行动前看到当日B机会高8/低3（各概率1/2），独立紧急U以1/4概率出现得5；SIDE得1。每次B同时增加一份待清理负担d，最大2份。d=2时B**非法**，只有花一手A_CLEAR使d减少1才能恢复B的部分容量；终局每份未清负担扣7。A_CLEAR本身无即时收入。目标不是完成一个A进度条，而是持续面对B的额外工作。

精确全局根 **21415/1024 ≈20.9131**。从真实开局正常可达：
- 第0日高价值B，不论是否有U，均选B，d=1；
- 第1日若d=1、B高且无U，可继续B使d=2；若B低且无U，则A_CLEAR，改为恢复未来容量；
- 实际路径可能来到第2日d=2，即便当天高价值B，**B也非法**，A_CLEAR便重新打开后续B。

六日最优的分解向量，而不是只给一项总分：

| 项目 | 期望量 |
|---|---:|
| 高价值B次数 | 32233/16384 ≈ 1.967 |
| 低价值B次数 | 303/2048 ≈ 0.148 |
| A_CLEAR次数 | 4103/2048 ≈ 2.003 |
| U次数 | 7439/8192 ≈ 0.908 |
| SIDE次数 | 15945/16384 ≈ 0.973 |
| 终局未清负担数量 | 1833/16384 ≈ 0.112 |

这些行动计数求和恰为6；按高B8、低B3、U5、SIDE1、终局负担−7重新计算，严格重得21415/1024。公开历史的决策期望d=2占用量为83/128（指6天内累计访问d=2状态的期望**次数**，不是至少一次的概率）。这是实打实的反复清理，而非单次按钮演示。

| 六日版本 | 根值 | 反证 |
|---|---:|---|
| B制造负担，A清理后恢复B，终局扣未清债 | **21415/1024** | 正常游戏确实多次使用A_CLEAR |
| B不制造任何负担，仍有同一B/U/SIDE收益 | **69/2=34.5** | 清理动作根本没必要；低负担版分数更高不能表示更好玩 |
| B仍制造负担，但完全禁A_CLEAR | **12** | 自我制造的负担无法恢复，B容量耗尽 |
| B仍有容量封锁和A_CLEAR，但**仅终局不扣未清负担** | **439527/16384≈26.827** | 仍有容量重开价值；并非所有A_CLEAR仅因末期罚分 |
| 容量上限1或3，其它固定 | **40795/2048 / 85885/4096** | 改容量会改调度分数，不自然变出另一基础机制 |

### 用“最强可讲清策略”反证动态数值复杂度

测试五条只依已公开状态的短优先级法则，不偷看未来、不调用DP：
- 高B优先，不能B时U优先，再A清负担；期望612849/32768≈18.70。
- 最后一手有负担先清理，其余高B→U→清理；期望331155/16384≈20.21。
- 高B只在非最后一日做，其余U→清理；期望328089/16384≈20.02。
- 总是先清已有负担再处理U/B；期望628911/32768≈19.19。
- **最后一日优先清债；其余日高B优先；遇U先U；无U有债就清，否则SIDE**；期望 **166859/8192≈20.368**。

最强短规则比DP差 **4461/8192≈0.545**，仅约2.6%的DP最优总值。本模型确有一些需要稍微估计未来的状态，但大部分连续决策可用一个紧凑的容量/清债优先级解释。五条规则不是人类行为的观察，也不是穷尽所有能用自然语言表达的规则。

更关键的是，这个B→A负担→B恢复，恰是成熟 **P11压力预算/推进与负担** × **可用行动容量限制**：可以把d改名“待维修机器/库存欠单”，全树保持一样。与[REC01双向生产余效](../2026-10-13-双向动作余效与操作顺序/研究记录.md)相比，关系不是“换动作获得生产加倍”，而是“玩家自己封住B，花行动A重开”，却仍属于标准的自我负担调度，不认证独立原语。不能把“因为A被做了两次”写成新的玩家心理过程。

## 本批最关键的跨模型发现：四种证据严格分开

1. **菜单因果**：删除A前置，确实多了原来非法的B行动。
2. **策略因果**：上面两组GATE/REOPEN即使去掉A前置，最佳正常历史仍完全相同；这条菜单因果在**当前参数真实开局**对决策没有边际价值。相反，关闭A/补救A、U与早报价明确改变最优策略。
3. **结果因果**：GATE有1/2概率失去A成果；REOPEN提高A完成率到3/4；BURDEN产生多次未完成义务。它们不能仅因期望分数更高就认定“玩家真的觉得值”。
4. **体验证据**：本批没有。数学证明确实存在这些可达分叉及反例，不能证明玩家自然理解关闭/补救/欠债的语义，或认为它们比固定AAB有意思。

## 同一研究者的独立反证视角（非独立盲Agent）

- **最强无聊操作**：GATE就是“第1日B报价高就卖，否则先保A”；REOPEN多一句“U来了不重开A”；BURDEN是“高B、逢期清债”。这些清晰也可能机械；不应用添加第五个按钮来掩盖。
- **貌似双向但缺了实际边**：GATE/REOPEN里A→B约束从根从没决定最佳，移除后完全同一正常轨迹。即使研究日志画着两个箭头，也只是其中一箭影响最优。真正已发生的是B关闭/开放A与外生价格或U。
- **预先排除同构**：B关闭未完成A与CLAIM不可撤销窗口同族；REOPEN付费补救与CLAIM03同族；BURDEN与P11工作负担、容量管理同族。它们是可复用成熟组合，不是编造三种新机制。
- **不让分数替代关心**：提前B高可提升统一收益但永久丢A，这是单独值得解释的结果。若A是真正必须保护的目标，允许结果集合里“B高而A毁掉”不能通过把B奖金提高补偿；需设计师明确非补偿条件，而不是替玩家擅自设置。
- **复杂度并非价值**：六天BURDEN即使按精确最优处理，A_CLEAR期望约2次，但玩家实际体验仍可能是一种单调维修税。少量真实游玩才能知道“B创造新问题”有没有被理解为值得处理的决策，还是碍事的工作。

## 结论与下一研究入口

**保留三项有条件的结构知识，不自动提升精选或Debug。** GATE是“先取得权利”可能对最优路线零作用，而“早B关闭A”真的分叉；REOPEN是“带付费补救权且随新机会判断是否修复”的成熟可用Scenario变奏；BURDEN是能真正反复出现的“推进制造负担、清理恢复生产容量”，但仍是P11相关的调度组合。

下一阶段不再继续把BURDEN的终局罚金7调整为8，或把GATE的报价14改为15。优先探索**在同一正常可达局势下，A怎样改变B实际取得的信息或结果资格，B又怎样使A原本依赖的证据不可用；再与安全观察、同成本完整菜单和先等待后行动对照**。横向另测**自主他者是否会因B披露A而重新选择是否参加**，若只是随机机器则不宣称社交决策。

未来若进入人类体验阶段，优先拿不带最优答案的简版GATE与BURDEN对照，让参与者逐手讲“我关心的是A还能做还是B报价值不值”，以及“清债是在处理自己造成的问题，还是被迫按税交钱”。没有人类反馈仍可继续抽象研究。
