# 双向因果 · 无答案纸面观察卡（尚未执行）

仅用于将来独立体验，不是作者的模型验证、真人认可或 Unity Debug 入口。关联[完整抽象研究](研究记录.md)。测试时不要提前展示数学最优、口头提示或研究者的结论；记录参与者在每手**行动前已经看到什么**，以及他们自己讲的原因。

## 试玩 A：三日 GATE（3分钟）

规则公开给参与者：

- 每天做一项事，总共三天。
- WORK_A 每次推进A一格；做到两格时A完成并获得8。
- SIDE立即获得1。
- CLAIM_B完成B并获得当天所见价值；B只可领取一次，且至少曾经做过一次A。太早领取B后A尚未做完的部分不能再继续。
- 第0天/第2天B价值6；第1天在行动前才揭晓是4或14。第0天不知道第1天的报价。

组织者分别用“第1天B=14”和“第1天B=4”运行；顺序随机，两个条件都重新从全零开局，不能假装是同一局。第0天实际只能做一手，不让玩家提前知道未来报价。每手询问：“你现在最在意保护哪件已做的事，或哪件还可以做的事？”不要追问“为什么不先完成A”等泄露答案的问题。

体验后再给另一规则：B可以在任何时刻领取（无需A前置），但提前领取仍使未完A关闭。询问玩家是否感觉自己的有效选择发生变化，不给“其最优动作其实完全一样”的提示。

## 试玩 B：四日 REOPEN（3分钟）

保留A/B规则，延长到四天；第2天50%出现紧急U，做U可得9。提前领取B关闭A后，增加REOPEN_A：完整消耗一天后可以继续做未完成A，但不自动获得进度。

组织者有两张隐藏于玩家之外的时间线，只逐日揭晓：

- 方案一：第1天B=14，第2天U出现。
- 方案二：第1天B=14，第2天U不出现。

询问玩家：“高B已经领取，现在是否还打算完成A？”“第2天发生变化后，是哪一个未来行动变得不值得做？”之后可去掉REOPEN再体验，重点判断他们是否认为新按钮是有代价的补救而非游戏故意拦路。

## 试玩 C：六日 BURDEN（最多7分钟）

玩家看见每日B机会价值高8/低3，及是否有U（有时立即得5）。可以B、处理U、SIDE得1；做B生成1份待清负担，上限2份时不能再做B；A_CLEAR用一整天清除1份，终局每一份未清负担减少7。

固定可重播但未来对参与者隐藏的**公开机会序列**（这里只供组织者逐日翻开）：

| 日 | B机会 | U |
|---|---|---|
| 0 | 高8 | 无 |
| 1 | 高8 | 无 |
| 2 | 高8 | 无 |
| 3 | 低3 | 有 |
| 4 | 高8 | 无 |
| 5 | 低3 | 无 |

另造一组从低B开始的序列可以自由探索，但须作为独立条件记录，不能和本卡混为一份严格对照。观察参与者是否自己说明“我做B制造了一个需要花日子处理的东西”、是否理解A_CLEAR在满负担时恢复B的合法性，以及清理是否只是反复交税。

## 统一记录字段

- 版本/规则、已公开信号、玩家真实每手动作、该手理由、哪一个未来按钮因此打开或关闭。
- 哪个目标结果在他看来不能用单一分数替代？例如A完成率还是B即时价值。
- 玩家是否在相同公开条件下形成可学的简短规则？是否觉得第二遍仍值得玩？
- 哪些细节被组织者提示过？若有提示，这不能再算完全无提示体验。
