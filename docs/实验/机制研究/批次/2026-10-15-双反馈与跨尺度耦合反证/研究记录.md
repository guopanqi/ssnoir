# CROSS-SCALE07：发生两次改道，仍可能没有跨阶段因果协同

日期2026-10-15。承接CROSS-SCALE06，主动从预约价值/成果向量转向**两次反馈后是否真的需要连续重规划**。未改变正式游戏与Debug，所有状态用抽象A/B表示。

## 规则

六行动、两个阶段（t=0,1,2与t=3,4,5），地点A/B，初始A，GO_A/B花一手移动、WORK在当前地点工作、SIDE得1。各阶段有隐藏的优先工作方向，A或B等概率，两个信号独立。WORK在正确方向得5，错误得1。第一个偏好在t=1开始前公开（若启用反馈1），第二个在t=3开始前公开（若启用反馈2）。行动t0必须在首次反馈前选择；已知信息只决定后续合法条件政策。全部累计收益、不设置人工退出罚分。额外对照禁用t=3的移动行动（跨阶段转场受阻）。这是“驻留状态跨期传递”但不保证数学非加性。

脚本 `tools/content-validator/experiments/pattern_crossscale_two_signals_20261015.py` 用Fraction自底向上逐状态枚举全部合法动作及后续观察分支；再依据每个隐藏世界的实际轨迹前向复核期望，检验双次转场可达。

| 第一反馈 | 第二反馈 | 正常最优 | t=3不能移动 |
|---|---|---:|---:|
| 否 | 否 | 18 | 18 |
| 是 | 否 | 39/2 | 39/2 |
| 否 | 是 | 43/2 | 39/2 |
| 是 | 是 | 23 | 21 |

正常条件下，两个信息的交互项23−39/2−43/2+18=0；禁t=3移动时为21−39/2−39/2+18=0。虽然限制t=3移动降低第二次信息的可兑现价值，却仍没有产生跨反馈的收益协同。

在真实世界BA且两次反馈均有的最优策略轨迹为：
`WORK, GO_B, WORK, GO_A, WORK, WORK`。
首波得6，次波得10，共16。玩家第一次改去B，第二次又返回A，是**实际两次改道的可达最优分支**，不是只在纸面画两条箭头。

## 独立反证视角

- 两次**行为调整**存在，但不能把“出现两次判断”直接当成世界—局部的非可分性证据。阶段偏好独立，WORK的收益当场到账，没有未完成负担、跨期资格、事件处理责任，最优跨波结果仍加性。
- 阻止边界时刻换站会影响单个信号价值，但由于首轮结束可以把已有位置视为一个普通状态变量，仍不保证真正的双向因果耦合。
- 这并非证明游戏设计中“非零交互项”是必需条件；非零交互也可能只是共享行动数量、倍率或封锁造成的数值差。更重要的是玩家能否从第一个行为的结果中学会和重新运用第二个行为的规则。
- 固定策略价值18已与不观测两次信号的全DP比较。绝对安全SIDE六手得6；不动地点WORK六手期望18，所以SIDE劣于强固定。每条具体公开世界轨迹都核对收益，未宣称真人感受或独立盲Agent观察。
- 归属成熟的“信息更新×切换成本×阶段性机会”；先对照REC、FOCUS、INFO-WINDOW、CROSS-SCALE03—06，**不认证新原语**，不自动进入精选/Debug。

## 下一轮

比起强行增加随机事件，应寻找可持续的跨期**未完事项**：前一阶段某个行动产生次日必须处理或可以放弃的责任，处理与改道真实竞争同一行动预算；与已知HEDGE/CRISIS/OBLIGATION及普通条件菜单并列去重。先反证“总是立即处理”“一直忽略”“简单固定巡回”三条公开口诀。需要单层表示下的行为同构与人类无提示观察；没有证据不能称实质创新。
