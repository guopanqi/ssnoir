# R41回本审查

身份：纸面审查；负责人 `r41_payback_review`。只审查本批冻结规则，不求解、不同步全局、不构成正式游戏或真人体验证据。

## 前提与结论

三回合；只有进入第二、第三回合时，已经完成的产能各给主目标1进度。第三回合结束不会再产出。主进度保留且越多越好，达到目标立即成功。投资与推进使用相同技能、判定概率、稳／险收益和冷静代价；投资完成后移除。没有压力、因推进而生成的问题、投资专属副作用、后续可消费的储备、自动产出之外的奖励。回合税、伤势部位、头伤技能变化与重伤骰池只依赖共同的健康历史。7伤先失败，之后才处理进度。

在这些前提下：

- 投资阈值2，被把所有投资动作换成直接推进的策略逐结果弱支配。
- 投资阈值1，在第二、第三回合做的投资，被直接推进逐结果弱支配。因此最优策略总能取为“只允许第一回合投资”，而不降低纯完成概率或3／2／1早完成收益。
- 以上不是“最低骰第一手投资”或“最多尝试一次投资”的证明。第一回合投资仍可能在坏档后重试；是否值得、用哪颗骰、用稳还是险，要由另一个比较回答。

## 同结果耦合证明

取任意原策略，把它的骰子、判定档、伤势部位及新回合骰池作为共同随机历史。替换策略内部维护原策略的虚拟投资进度和虚拟主进度，按同一可见历史模拟原策略的决定；遇到被替换的投资动作，就用同骰、同稳险方式推进。其余动作与结束回合决定先保持一致。虚拟记忆由自己的动作和观测计算，不偷看未来。

在双方都尚未终止的共同前缀中，骰子消耗、判定档、冷静与伤势完全相同。记被替换投资的累计**原始行动收益**为 `G`，这些投资在原策略已经兑现的累计自动收益为 `A`。替换策略比原策略的主进度多 `G−A`，或者因主目标上限而已提前成功。

阈值2时：未建成之前 `A=0`，`G≥0`；建成之后 `G≥2`，而整个交锋最多兑现2，因此所有前缀都有 `G≥A`。即使建成时溢出，例如先投1再投2，`G=3`而工厂只需2，也只会加强这个关系。把投资进度封顶，不应同时把直接推进的收益错误封顶在投资阈值。

阈值1的晚投资：若进入第二回合时还未建成，则以后最多兑现1；若进入第三回合时还未建成，则以后兑现0。未建成前 `A=0`；建成后 `G≥1≥A`。在第一回合保留原策略所有投资动作，只从第二回合起替换仍未完成的投资，也得到同一关系。阈值1不存在“第一回合成功获得少量投资进度，但工厂还没完成”的中间状态；第一回合失败档只消耗冷静，没有需要跨回合保留的正投资进度。

所以原策略成功的每条共同历史，替换策略都已在同回合或更早成功。其余历史中替换策略还可能额外成功。逐历史有成功指示不减少，且成功时点不推迟，因此纯完成概率与3／2／1早完成收益均不降低。替换后的策略属于相应限制族，而限制族又包含在自由族内，故这些限制不改变最优主目标值。

## 容易误判的边界

**头伤与重伤。** 本证明不用“当前技能不再变化”或按当前技能计算整个回合容量。双方未终止时伤势前缀相同，轻度头伤会同时降低判定技能，跨到重伤时也会同时取消该惩罚；下一回合三骰同时生效。同一动作先结算判定、再付冷静并判断7伤；到7伤时双方都不能兑现本动作收益。这些变化不破坏耦合。

**提前成功与税。** 直接推进可能在原策略还想建设或等待产出的时刻先完成；提前终止是更早成功，不必强行继续扣税保持健康相同。若原策略等到进入新回合靠产出成功，替换策略在此前已经累计至少同量进度，因而不会更晚。共同前缀直到第一次终止为止即可。

**晚产出与超时。** 进入新回合之前先扣税；7伤或已到最后回合结束就失败，不允许在失败后产出。这个顺序只会减少原策略能收到的 `A`，不会推翻上界。不能把“第2／3回合各产一次”写成每个回合结束都产一次；后一规则实际给了额外收益。

**主目标封顶。** 用未封顶的累计进度比较最方便。一旦替换方达到目标，就已经成功；原策略投资溢出不会给主目标额外收益，直接推进的溢出也不产生惩罚。本证明不适用于必须恰好达到目标、越过目标会失败的R39式位置规则。

**次目标。** 在本批没有恢复、伤势只增和冷静只减的前提下，提前结束也不会增加是否受伤、成功时伤势或降低成功时冷静。若主目标值平手，最优健康次目标也可取为不劣的替换策略。不过纯完成目标没有逐一优化首／次／末轮成功概率，数值求解平手时可能选不同完成分布；本证明不保证六维报告向量的每个分量自动相等。比较实现时应断言目标值和明确优化的次目标，不把未优化的分量相等当成定理。

## 没有被证明的推广

阈值1的**第一回合**投资尚未排除：成功档若只产生1投资进度，放弃当前1主进度可换未来两次共2主进度；其收益可能比直接推进多1。若成功档原始收益为2，则对应分支最多换回同量且更晚，但玩家在行动前不知道判定档，不能据此把整个风险投资动作删掉。

若不同路线有不同判定或冷静代价，自动产出有其他作用，投资会改善后续动作，直接推进生成负担，主目标有过头惩罚，建设成果有终局价值，或回合数／每次产出提高，本次排除都不能直接沿用。它们可能有合理设计空间，但本批不靠加这些规则救题。

裁决：阈值2无需完整求解；阈值1自由族与只第一回合投资族的最优主目标相等应先作为模型核对。之后真正待检验的是第一回合投资的时点、骰归属、尝试次数及其相对强简单族的增量。纸面没有找到冻结前提内的反例，也没有证明投资体验有趣。
