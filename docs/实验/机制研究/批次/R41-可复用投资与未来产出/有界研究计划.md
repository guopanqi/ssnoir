# R41：可复用投资与未来产出

状态：待研究；协调者。R38已收束修复对象，R39／R40将幅度匹配降为基础材料，下一问题转向正的未来产出。Content／原生不属于本批。

最小关系：花当前骰建立产能，完成后每进入一个新回合自动给主目标+1。稳／险收益仍0／0／1与0／1／2；投资有完成阈值，主进度跨回合保留。不是R06只改善下一颗骰的准备，而是牺牲当前进度换反复产出；仍须防止低骰先投资成为固定流程。

先纸面判断回本：三回合只有两次新回合进入，产能最多兑现2主进度。若投资完成需2进度且与直接推进相同判定／冷静代价，无额外副作用或未使用收益，建立产能所投入的总进度至少2，直接推进得到不少于总自动产出，且更早；优先做同结果耦合排除，不先求解。明确最后回合结束不会再进入新回合，因此不支付第三次产出。失败／期限顺序不能悄悄多算一轮收益。

只有“投资1、两次各产1”的回本关系未被排除时，才按一次冻结条件建有限模型：主目标16、三回合、单人技能1、初始冷静3、不用物品／恢复，完整伤势与结束税。目标16根据名义12骰风险均值约17.67、重伤后少骰及投资最多净增1的容量理由预设，不扫主目标。投资完成后移除动作，自动产出仅通过进入第2／3回合；7伤、期限先失败，不允许首次受伤硬判失败。目标16只属于本批，不与R37跨批胜率作单变量比较。

强参照：无投资但同目标／伤势；首手最低骰先投资、此后仍优化；最多一次投资尝试但时点／骰仍自由；只在第一回合投资（后续仍完整自由）。两目标分别为纯完成、越早完成收益3／2／1。核对投资成功／失败后哪些可见条件改变判断，先检查简单族是否已解释收益。若固定低骰开手近乎足够，降为基础投资关系并停止接入；不增加第二座产能、回合奖励倍率或额外资源救题。

停止点：回本耦合边界，若需要则最小模型与强族裁决；有解释的增量才做可达／独立小树，未得到时不创建试玩。R37体验待补不阻塞本题。所有执行前登记冻结版本和负责人，完成后队列→状态→HTML同步。
