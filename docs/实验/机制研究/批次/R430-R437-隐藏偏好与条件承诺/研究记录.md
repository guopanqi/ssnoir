# R430–R437｜隐藏的长期偏好与事先声明的条件回应

2026-10-12。接R390（完整规则计划事前公布，另一方知道自己的θ）及R406（双方**公开**θ的在线战略博弈），本批把研究问题严格改写为：玩家不知道θ，另一方知道θ；玩家能不能在开局声明“如果看到你否决，我以后将如何改变规则”的**条件承诺**？该条件改变另一方的未来自身收益，可能间接透露偏好。注意玩家**事先锁定整个条件政策**，不等于真正逐回合临场制定政策。

源代码：`tools/content-validator/experiments/r430_r437_private_contingent.py`，独立CI：`.github/workflows/ssnoir-r430-r437.yml`。8项冻结模型检查，零真人或真实代理互动。去情景决策关系：玩家预先分配对未来回应的控制权→另一方按自身跨期目标决定何时否决→玩家公开承诺的政策自动生效→影响下一期的双方可选行动。

## 冻结规则与同协议对照

- 玩家3期想要实际结果A/B/A；提O（开放）或A/B（只准某类），相对前一**实际生效**规则变动花1/4。
- 另一方θ在开局等概率为A或B，**本人知道**、玩家不知道，且每期希望执行自身θ（各期成功得1）；有且仅有一次机会否决与自己θ冲突的限制，令本期O。
- 双方事前公开玩家的条件计划；对方完全知道该计划，以**自己整个三期的收益**最大化决定是否与何时否决。自身收益同分时，分别给出对玩家最不利及最有利两种解析，不把任意偏好塞进“理性”。
- 玩家允许给6个可见历史状态写规则：第1期1格；第2期两格（此前有没有否决）；第3期三格（此前没有否决/第1期否决/第2期否决）。故完整候选为3^6=**729**，其中只按回合写死O/A/B、不随否决变动的**27**条脚本属于严格子集。同一效用与同一θ信息对照，**不拿R406的公开θ在线值作效应差**。

### 可直接读懂的策略

最佳策略 **AAAAAO**：几乎总让A独占；**唯独在第2期观察到对方动用否决权后，第3期改成开放**。如果另一方实际偏好A，三期本来就能持续得到A，玩家得7/4。若它偏好B，知道“第2期否决→第3期开放”会使它三期自己拿到2次B，胜过第1或3期否决时的1次，因此有自己的理由选择第2期否决，玩家亦得7/4。

这是一种**条件承诺塑造对方行动激励**，而不仅是被动对异议权作反应。它比固定脚本多出1/4的最不利平局下收益，但其核心完全能写成**一个条件句**；对方平局若按相反方式选，则固定三期A已经追平完整承诺最优。不能据此推断出现新的深度谈判游戏、人格动机或重复可玩性。

## 横向质量审查

- R390是隐藏θ、固定整套计划；R406是双方公开θ、在线反应；R430是隐藏θ、公开**条件计划并提前承诺**。三种**不同协议**都可能合理，不能拿不同协议的最优数值简单相减归因“对手更聪明”。
- 本批保留“对方为跨期自身收益选择行为，玩家可通过公开条件承诺产生诱导”的经典机制组合潜力。它接近R374的有限异议权、R342的承诺/破约与博弈论中的可信承诺，而非全新形态。数学四舍五入并不能证明人愿意玩。
- 更贴近真人独立主体的下一步不应变成追加更多否决次数或复杂效用函数，而应在**没有公开完整政策的交互**中观察对方如何真实形成、修订、保留自己的目标，以及玩家如何根据外源行动辨认它。未满足此门槛，不进精选/历史20/Debug。正式游戏功能冻结。
