# 横向机制卡｜先否定同构，保留真正的行动差异

2026-10-12。对照关系索引、P01–P20、R269、R342、R358、R366/R382、R390/R398。**纯纸面概念审查，没有虚构参与者或求解器结果**。

### H01｜提交完整猜测 → 接收特定反例 → 修补猜测

- 状态：隐藏的4位目标表；已提交的4位规则；已揭露的位；还可用的尝试数。
- 动作：直接提交4位猜测，每次输出“全对”或目标中第一个不同格及正确位；下一手可选择在新表上再次提交。
- 新判断：玩家不断选择整个假设而不只是问一个问题；反馈是**反例**而非总分。
- 最强反证：这个“第一个不符格”实际上把16个秘密目标分成“全中/首错第0/1/2/3格”五组；提交一张表在信息结构上就是发起一条五分支查询。若提交本身不产生持久产出或额外代价，该活动严格归入R269主动诊断，**先停止**；不能只靠把问问题叫“写程序”制造新模式。
- 保留的变体假说：提交的规则在遭遇反例前仍真的运行并影响下一期合法操作，因此“本期执行/暴露漏洞/修补系统”才可能比纯诊断多一个不可逆取舍。尚未建精确模型，不能晋升。

### H02｜相互对规则施加最低保障 → 观察对方的拒绝/反提议

- 状态：两方有不同跨期目标、公开可用限制；双方可以付代价提出条件和撤回条件。
- 动作：要求、让步、接受、拒绝；具体哪个动作会真正改变**双方今后合法集合**必须写明。
- 最强反证：如果始终只有一方可修改规则、另一方一次性用否决，则重回R374/R390；如果拒绝只返回同一个继续分支，重回R294–R301的“仅一拒绝分支”退化。**不在现有证据上增加一名智能谈判者**。
- 未解决问题：当双方可观察自己的机会成本、却无法知道对方将来替代机会时，是否存在具有可理解的双向让步循环？先定义共同可理解的时序，再建模型。

### H03｜让另一个主体处理不可见的思考工作 → 检验可靠度后重新分派

- 状态：相互独立的信息工作、两方能力边界、交付时间与至少一种用户不可直看但能交叉验证的报告。
- 动作：交给对方、交叉核对、自己执行、改派；后续的行动空间会受谁先报告与谁保留决策权影响。
- 最强反证：若另一方只提供同品质信息，就同构于P08的信息购买；若仅把玩家动作代做，落回R398容量替身；若有隐藏但固定配合率，落回R350。不能凭“不可见脑力”三个字认证新玩法。
- 暂保留的具体未证假说：对方拥有持续独立目标并在玩家离开后继续改变问题，使玩家必须决定何时**信任**不完整报告、何时验证、何时拿回行动权。下一轮需先写最小三期合法规则，而非直接加入剧情角色。

结论：H01纯诊断版本停止；H02需非单分支协商协议；H03留作横向候选。三个都不是新增精选。
