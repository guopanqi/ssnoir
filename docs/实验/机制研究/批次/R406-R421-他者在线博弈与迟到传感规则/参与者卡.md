# 参与者任务卡｜迟到输入的可执行规则（未执行真人）

**只给参与者本页；研究员不可先透露最优策略。** 这里是抽象系统，不需要熟悉布尔代数。你可以把输出表当成四格机器。

初始四格程序：输入 00、01、10、11 的输出都是0。每期研究员先告诉你 **x是0还是1**；另一个数字 **y** 直到你确定动作以后才从均匀随机的0/1中出现。输入为xy。例如 x=1、迟到y=0，则读机器第三格10。

本期只能选一个动作：
- **MANUAL-0 / MANUAL-1**：预先给出0或1。之后y出现，研究员按目标判本期正确得1分，否则得0分。
- **RUN**：你在不知道y时下达指令；y出现之后机器读取当前四格中xy对应的数字作为本期输出。对错同样得1或0分。
- **EDIT-X**：翻转第三、四格；**EDIT-Y**：翻转第二、四格；**EDIT-I**：翻转全部；**EDIT-N**：仅翻转第四格。编辑会永久保留，但是本期不能输出也不能得分。

**第一局8期**：前4期目标为“两位输入不同则输出1、相同则0”；后4期相反，“相同输出1、不同输出0”。阶段切换提前告知。机器与手工都只能做本期同一件事，机器不会在你手工操作同时再干活。试着取得尽可能多的分数，但不用算最优解。

**第二局9期（第一局结束后再开始）**：程序重置全0；每3期目标交替为“不同输出1”、“相同输出1”、“不同输出1”。其余规则不变。

逐期请口头说明：x是多少，当前表四格是什么，你为何选择编辑/运行/手工，你现在对下一期有什么预计。之后才公布y和正确与否。两局结束再谈：是否能说清自己在写一张反复执行的规则？有没有哪次必须牺牲眼前收益？第2次阶段变换需要真正重想吗？还愿意多玩几局，还是已经是固定操作？
