## A｜R406–R413：双方有长期自身目标，动态回应还是预先承诺？

**去情景机制卡**。玩家有公开的三期目标 ABA；每期可订 O（开放）、A（只许A）、B（只许B），与上一次**实际生效**规则不同扣1/4。另一个主体稳定地希望三期实际选择都符合自己的类型 θ（A或B），一次可否决阻止自己的限制，令本期变为 O。否决保留到未来，另一个主体最大化自己三期总收益，不是第一遇阻就否决。

**同协议严格比较**：本批 θ 对双方**在开局公开**。预承诺组：玩家当场公开3条规则，另一方据此选择一次否决时点；在线组：每一期玩家制定规则，另一方见当前规则并以未来玩家最优回应为前提自行选择是否否决，下一期玩家见到否决反馈再决策。两组双方都有相同目标、合法动作、规则切换成本、否决权及公开类型；只改变规则承诺时序。对方自身收益有平局时分别计算“对玩家最不利/最有利”边界，玩家自己的收益平局选择对方收益更高的提议。数值不是对现实人物性格的描述。

| 对方θ | 同为自身最优的平局规则 | 玩家逐期决策 | 玩家三手预承诺 | 预承诺−在线 |
|---|---|---:|---:|---:|
| A | 对玩家最不利 | 2 | 2 | 0 |
| A | 对玩家最有利 | 9/4 | 11/4 | +1/2 |
| B | 对玩家最不利 | 3/2 | 5/4 | −1/4 |
| B | 对玩家最有利 | 3/2 | 5/2 | +1 |

- **R406**：穷举27条预承诺序列×2个类型，类型不公开、玩家不得针对类型选计划时，重现R390的最不利3/2、最有利17/8；用于证明规则语义一致，不能把本批公开θ数值与R390直接相减。
- **R407/R408**：θ分别为A、B，枚举全27条三手预承诺；对方优化自身三期目标，计算平局上下界。
- **R409/R410**：θ分别为A、B，逐期子博弈逆推，对方始终以三期自己的利益作权衡；保留实际在线轨迹。
- **R411/R412**：同信息时序外其余条件一致，在线优势/预承诺优势均可出现；双方自利并不自动制造某一套优越玩法。
- **R413**：θ=A、善意平局条件下，在线路径第一手提B会被否决而实际走A，下一期B遂可成功。对方自利总收益达到2，允许这种行为并不等于真实对方一定如此。

**最强无聊解释**：知道θ时可以直接算固定计划；对方的收益平局足以大幅改变结果。机制上出现确切的可承诺与可反应差别，但这是经典有限权利/博弈时序结构，不具备对方隐私知识、学习、真实语言协商；**不能称独立社会NPC或新精选**。下一轮若继续该轴，必须先测试隐藏类型时的共同信念和可追踪的外部行动，而非继续换否决成本；在同一协议下比较不提前泄漏θ的诚实响应。

## B｜R414–R421：程序真正获得人无法手动复制的观察时点了吗？

**去情景机制卡**。每期先公布 x∈{0,1}，玩家只能用一个行动槽：**MANUAL** 提前选输出0/1；**RUN** 让已有的四格表根据输入自动输出；**EDIT-X/Y/I/N** 翻转四格中的指定子集、放弃本期输出。第二个独立均匀信号 y 在选行动**以后**才产生，手工不能看到它，RUN中程序在执行时可读到(x,y)再输出。只计当前结果是否与已公布的目标函数匹配，正确+1；绝无并行额外得分。初始四格程序全0。玩家只有在选择 RUN 时能够得到迟到信号的执行价值，不能提前窥见 y。

**第一组8期：公开目标前4期 XOR，后4期 XNOR。**

| 反事实（R编号） | 精确最大期望得分 |
|---|---:|
| R414、R419：程序可读取迟到y，玩家每期看x再 RUN / EDIT / MANUAL | **21/4** |
| R415：仅提前手工选择输出 | 4 |
| R416：程序也只能读到提前的x，无法读到y | 4 |
| R417：程序有迟到传感但禁止编辑，初始全0 | 4 |
| R418：玩家甚至不能先看x就决定 RUN/EDIT | 5 |
| R420：允许最多一次编辑，仍在每期提前见x | **21/4** |

**关键负例**：21/4对4的优势来自程序独有的晚到信息与修改输出表；然而第一次8期原型里，最多编辑**一次**已经追平完整自由策略。没有证据说“反复修规则”的乐趣成立，也没有第二行动槽虚构产能。相对不可根据当期x选择动作的政策只有1/4期望收益差；这种差异可能被简单口诀解释。

**R421迁移检查**：不调原题数字，只换为另一事先写明的目标序列 XOR→XNOR→XOR，每段3期，全部目标事先公开、动作契约不变。迟到传感、0次/最多1次/最多2次/无限次编辑的精确期望依次 **9/2、6、49/8、49/8**；没有迟到传感则是**9/2**。第二次编辑**仅提升1/8**，并非强反复修订循环。此处需要特别观察真人是否能理解“本期早看到x、程序执行时晚看到y”、是否自然改程序、第二阶段会不会觉得只是开关切换。

**归属判断**：比R398的纯吞吐工具严格多出独有观察时点，但与R366的可执行规则、经典条件控制和信息时点构成*已知组合*；暂存探索，不进入6精选、20历史候选认证或Debug。数值都是有限模型，不能代表可理解、想重复、玩家真的会做这些事。

## 研究裁决

- R406–413：**保留作为协议/平局强反证**；当前例子仍是已知博弈结构，拒绝自动晋升。
- R414–421：**有可执行工具独有能力的机制假说**；首局被一次编辑策略解释，迁移局第二次编辑收益很小，真人体验未证实，拒绝自动晋升。
- 下轮研究将区别“存在数学可自适应策略”与“人能以简短理由反复重新思考”，从真正外源目标、规则中途改变以及可辨认的多动作循环中继续找问题。脚本回归之外，任何 CI 都不能回答玩家是否愿意再玩。
