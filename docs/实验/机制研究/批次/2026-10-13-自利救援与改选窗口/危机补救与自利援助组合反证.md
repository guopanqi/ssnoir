# PS01—02｜受损的两个成果与自利救援：真正改变可保住的结果，但没有新社会原语

日期2026-10-13。独立承接 [ATN03](../2026-10-13-多目标注意力与破坏后重规划/研究记录.md) 与 [ACT-R01](研究记录.md)，不是延长任意收益表。脚本：[pattern_partner_salvage_20261013.py](../../../../../tools/content-validator/experiments/pattern_partner_salvage_20261013.py)。Python Fraction、九种准备路线、八种公开场景、每场27个合法后三手方案及243条完整固定日程做精确审计；无新人类/独立Agent/Unity原生体验。

## 心理循环及最强无聊路线

玩家先花两手准备 A/B 工作；两项可能分别遭到失去已有进度的事故（无损、损A、损B、双损，均为1/4）。同时另一个行动者遇到低外部收入2或高外部收入4（各1/2），他亲自补救B的一份进度对自己价值3，故低时愿意、高时退出。玩家观察事故、可能观察外部机会后还有3手A/B/SIDE。A和B各到2可完成，SIDE即时+1。协作者只能在第一手危机后行动完成时**最多一次**协助B+1（若B还需工作）。两项目标能否保住分别记录，不把总效用当作情感关切。

预先提出两条反证：①不理伙伴，只用ATN03的「先AB，发生什么擦除就补什么」是否已全优？②把伙伴换成相同条件下的一次免费B备用工作量，其行动序列是否仍完全相同？另检查 **低/高外部机会直到第一手危机后玩家动作以后才公布** 时，是否真的影响根决策。

## 精确结果

| 机制 (A10,B8,SIDE1) | 最优工具期望 | 分目标结果向量(PA,PB,E SIDE) |
|---|---:|---|
| ATN03无任何额外帮助 | **33/2=16.5** | (1,3/4,1/2) |
| 自利伙伴公开低/高外部机会 | **71/4=17.75** | **(1,7/8,3/4)** |
| 完全相同的一次条件B备用工作量 | **71/4** | **(1,7/8,3/4)** |
| 自利伙伴存在，但外部机会消息推迟到第一手危机后玩家动作后 | **71/4** | 根值相同 |
| 所有行动固定且看不到事故和报价，但保留自利伙伴 | **17** | 固定策略最佳根值（不假定观察） |

不同于上一轮 COUP01 的单线完全旁路，此处至少出现**正常可达且不同的两项目标结果**：前两手 `A,B` 后，两项都失去原进度（概率1/4）——
- 伙伴外部机会低：玩家后三手 `A,A,B`；伙伴在第一手B仍不满时额外做B+1，末手两项都完成。
- 伙伴外部机会高：伙伴退出，玩家后三手 `A,A,SIDE`，A完成、B放弃、SIDE得1；这是10/8/1下一个最优选法。
- 两项进度未损坏且外部机会低时，玩家可以只做`A,SIDE,SIDE`，由同伴完成B；高机会则需做`A,B,SIDE`。这是真正少花一手补救、另拿一份稳定SIDE收益，不是隐形额外加分。

以上按A/B/SIDE结果分别记录；若玩家更重视B，例如(8,10,1)，最优对称地保住B=1、A=7/8，根仍71/4。若两个目标同权10/10/1，根39/2而无伙伴18；SIDE权重为0时根17，无伙伴16。**目标价值不同，玩家真正想保住谁可能不同**；实际想法仍需真人材料，不能从标量单方面决定。

### 强反例与适用边界

1. 伙伴有自己的收入比较（亲自补B得3，退出得2/4），其决策确实符合明确自利收益；但冻结规则完全公开、无未来义务，他每一个状态的工作量都可以由“低报价时开放一次B补救工作量，高报价时没有”逐动作完全复制。**玩家策略层面没有证明新社交关系原语**。第二阶段具体责任归属/后续交易若未落实到规则中，不要用人物表情假装已经有差异。
2. 即便第一手危机后动作时尚不知道外部报价，之后公布时，完整动态根值仍**71/4**。这一冻结例子的第一手可以选择对两种报价都无悔的工作，待伙伴是否补B的反馈出现后再调整剩余两手。**消息早揭未必有行动价值**，不能因为存在后到信息便添加昂贵情报系统。
3. 纯固定五手脚本得17，完整动态17.75，说明本例确有适应性收益，然而同成本普通B工作量依然能给相同期望；“可改选”与“玩法创新”是两道独立检查。最强可读规则只是：先向两目标各投一次；遭受损失后先补需保证的目标，对方有空就由他负责部分B，否则对自己更重要的一项优先保全。
4. 如果未来另造多一位伙伴、更多外部报价或额外事件，只增加分支，不自动改善“玩家具体反复做什么”。再深入应至少提供**另一个行动者在下一个事件中可以拒绝/撤回/附条件授予的真实权利**，并立即同成本ENABLE或条件免费援助对照；且不能把已研究的NEG05“先送恩惠但未来仍退出”作为新发现。

**裁决**：保留为 **ATN03危机后补救 × ACT01自利外部机会** 的成熟正向组合：援助确实改变双损时的可保住成果与SIDE余量，且不被简单单线提前计划完全旁路；但能用条件备用工作量替代，不能认证新独立社会玩法。人类对“被帮助但欠什么”的感受和人物上的责任仍是独立实验议题，不自动进入精选或正式Debug。
