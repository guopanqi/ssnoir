# R253–R260｜不可逆的中途成果：同一操作库存的阶段兑现

日期：2026-10-12；遵守当前唯一研究目标：抽象玩家决策关系，不是正式游戏的剧情/实现。代码：`tools/content-validator/experiments/r253_r260_irreversible_checkpoint.py`；CI：`.github/workflows/ssnoir-r253-r260.yml`。

## 去情景机制卡

玩家必须把「+1、−1、×M」三件工具各执行一次，起始状态2。乘数M=2或3，概率各半；**第一手结束后**才知道本局乘数M。第二手结束时的中间产物被当场评分，如果恰为3获得1分，之后不可撤回或重计；第三手结束时最终产物恰为4再得1分。第一手不能看见M，后两手可以按照观察到的M重新排序同一库存。

玩家反复做的不是分配更多工具，而是：决定第一个不可撤回的变换→观察本局M→安排余下两步，在**中途成果**与最终要求之间取舍。目标公开，步骤和信息时点固定，没有作弊式先知、假扮成另一个游戏的道具系统。

## 八项精确检验

| 编号 | 对照 | 结果 |
|---|---|---|
| R253 | 第一手未知M，之后真实公开并可重排，最大两阶段得分 | **3/2** |
| R254 | 全局最强三步固定顺序（不是挑一个弱固定） | **1** |
| R255 | 独立枚举全部3×2×2=12种完整分支策略 | 与R253相同，**3/2** |
| R256 | 实际首手+1、−1、×M的全反馈Q | 分别 **1/2、3/2、1**，严格应该先−1 |
| R257 | 关闭第二手的中间成果评分，仅终局恰为4得1 | 动态 **1**、固定 **1/2**；**动态−固定的差仍为1/2**，不能将自适应的全部价值归因于新增里程碑 |
| R258 | 先知对照：第一手前就公开M | 最大总得分 **2**；说明有真实不可追回的首步机会成本 |
| R259 | 改用(中间=2/终局=3)、(3/4)、(5/4)、(5/6)几种可达的不同目标对 | 各模型动态3/2、固定1，表明形式不是某一对神奇数字 |
| R260 | 对M=2和M=3的全部3!排列列出真实中间值、终值与评分 | 两套独立枚举前向结果一致，不靠猜选结果 |

例如，最优的第一手是−1。若后来公开M=2，剩余执行+1→×2，终局4、获得终局1分；若公开M=3，剩余执行×3→+1，中间3与终局4都完成、得2分。两个世界各半，总期望3/2。不能在第一手就“先知”M，更不能倒带已发生的状态。

## 退化和主观价值边界

这是R228“中间反馈后重新排序”的**有意义变奏**：新的中间产物也会被不可逆评分，不只关心终局。可是最优规则仍只有一句“先−1，M=2用+1→M，M=3用M→+1”，几乎没有第二次需要不同学习活动的理由；并且关闭里程碑仍留下同样1/2的自适应边际。

因此**不晋升新的独立模式**，不宣称“多一项评分所以增加策略深度”。可以把它作为对“中间目标是否真的改变玩家行动”的设计校验样本。下次应从其他结构族横向探索；若回到操作序，需先提出与这条简明口诀不同的持续活动，不应继续增加里程碑数和工具数。
