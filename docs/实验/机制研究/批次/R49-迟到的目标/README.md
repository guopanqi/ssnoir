# R49 · 迟到的目标：揭示前的资源配置

状态：**第一批候选，数学筛选通过；C# 原生验证待 CI，真人体验未进行**。本批为新的抽象关系研究，不讨论故事和人物映射。R48 原研究保持独立，未被替代。

## 核心假设

三项目标甲、乙、丙，仅一项会在两次准备行动后被指定为必须完成的真目标。甲概率 1/2，乙丙各 1/4，信息不能提前购买；前两颗骰可以投向任何候选，所有准备成果保留；揭示以后余下两颗骰只能投入真目标。每项需四格，判定是坏 +0、中 +1、好 +2，标准 skill=1、2 的 FateStrip。无附加奖励、故事皮肤和秘密判定修正。

要检验的是**尚未确定需求时，怎样分散或集中准备**，以及第一次准备的结果能否有价值地改变第二颗骰的分配。这和 R25「花行动购买信息，再定位」不同：本批的揭示是不可提前的外生事件。

## 先做最强简单策略反证

独立 Python 精确有限模型遍历 126 种无序初始四骰，按其真实权重平均；逐结果求期望，比较以下策略（均可看见开局四颗骰、选择哪颗骰投入）。

| 目标完成概率 | 成长 1 | 成长 2 |
|---|---:|---:|
| 完全自适应，准备阶段逐结果重排 | 81.5881% | 92.3175% |
| 开局选定两次准备对象和骰子，不按第一次结果改动 | 80.8089% | 91.9081% |
| 两次始终准备甲（最可能被指定） | 78.2430% | 89.4950% |
| 一次甲、一次乙/丙（开局选骰，择优另一个目标） | 80.5048% | 91.8822% |

初步裁决：**存在真实的集中/分散取舍，及严格正值的途中调整；但相对强开局计划，自适应只提高约 0.78 / 0.41 个百分点。** 这不足以宣称深度玩法；保留为一种可组合的基础关系，而非「证明好玩」。例如骰子 1/1/1/4 的成长 1 条件下，动态 41.0108%，最强开局固定计划 40.2778%；这是条件反例，不代表典型玩家感受。

精确有理数和更多局部反例可用 Python 脚本 tools/content-validator/experiments/r49_delayed_target_model.py 复算。该模型不含冷静、伤势、免费道具、自动结算与可见性问题；以上数字是数学筛选，不是引擎运行结果。不能把多个同种子策略等同于逐操作共享随机轨迹。
