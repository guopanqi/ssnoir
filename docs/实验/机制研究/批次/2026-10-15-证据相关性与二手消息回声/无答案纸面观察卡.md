# SOURCE01—09：相关证据与来源独立性的无答案纸面观察卡

这只是**独立玩法体验的观察协议**，没有已招募或已测过的人。主持人不应给玩家看[最优结果报告](研究记录.md)和求解器。需要先问参与者是否理解规则，再记录其自发行动和理由；数学分数与人的兴趣是不同证据。

## 可给参与者的共同规则

某个隐藏事实可能是0或1，两种情况原本各50%。桌面上有两个公开报告S1、S2，每份报告可能写“0”或“1”。

- 第一份报告S1自己调查，正确率75%。
- 第二份报告S2有50%概率是**完全照抄S1**；另有50%概率是自己独立调查，正确率75%。真正独立时，两份的随机错误互不影响。玩家不知道目前属于哪一种。
- 玩家可以选择直接押事实0/1（正确+10、错误−28），或安全结束得到+3。
- A组还可以一次核查S2是否抄录（AUDIT，耗一手，成本1），核查会准确告诉你“独立”或“照抄”，但不会直接告诉你真实事实。
- B组可以耗一手获取**新的、确定独立**的第三份75%准确报告（NEW，成本1）。
- C组同时开放AUDIT与NEW，两者同样需要花一手。所有组最多购买一次信息。结算时扣除已经购买信息的成本。
- 完成后揭晓真实事实和第二报告的来源，不能提前透露。

对参与者呈现四种情况：两份都报告0、两份都报告1、一份报告0另一份报告1、一份报告1另一份报告0。通过随机抽取真实世界与正确似然产生这些情况，不要为了方便而把一致/不一致设置成各一半，后者会偷偷改写环境本来的概率。

## 每回合记录

| 观察到S1/S2 | 当下认为哪个事实更可能、为什么 | 选择终结或补充哪种信息 | 补充结果 | 最终押注或SAFE | 对结果的解释 |
|---|---|---|---|---|---|
| | | | | | |

开放追问：“这两个人都这样说，你觉得多提供了多少可信度？”“如果知道第二个人只是转述，第一个人的准确率发生了什么变化？”“如果有第三位真正没听过前两份报告的人，你愿意为此牺牲一次行动吗？”

问的是玩家自己的推断和行动理由，不是让其背贝叶斯分数。尤其**不能暗示应核查来源**：如果所有人都直接去找真正独立的第三个来源，这同样是重要的机制审阅结果。

## 另一个对照：消息传播如何改变后来信息的独立性

向玩家说明一个不同、独立的两动作局面：先收到一份75%可信的报告S1；下一份报告可以在不公开S1的情况下自己调查（HOLD，75%正确），也可以在你提前发布S1后直接转述它（PUBLICIZE），且你发布时可以获得一个公开收益B（0、1、2、3四组）。

二选一后再看S2，选择CLAIM或SAFE。额外记录玩家是否意识到“发布导致了后来报告相同”，不要把S2与S1一致再当独立复核。四组B的最优首行动在数学上可由固定阈值解决；这里只观察玩家是否从行为与信息的因果关系理解其理由。

## 有价值的反馈不只是谁获得更高分

重点记录：自发是否提到“这也许只是同一个来源”；是否误把照抄S1算作第二次独立75%；是否认为AUDIT必然揭示事实；是否看懂NEW有资格保证独立；是不是只按固定公式没觉得人物/关系有任何价值；是否把错误下注损失视作不可补偿的结果。

无提示结束后让参与者自己复述：**我确定知道的事实、我只是推断的事实、我知道两条报告是否独立，这三件事各是什么？** 这一问题是可学习性与信息呈现测试，不是目标叙事认证。

所有未实施情况必须标记“尚无真人”而不是待反馈的用户满意结论。正式Game、精选、Debug一律不变。
