# R245–R252｜付费观察可能改变被观察对象

日期：2026-10-12。第三批横向研究：不继续增加敌人数量，也不从前一批简单追踪玩法强行派生，而是检查**观察行动本身改变下一手对象**是否能形成独立判断。抽象二值环境，没有故事角色/Unity。源码 `tools/content-validator/experiments/r245_r252_observation_changes_target.py`，CI `.github/workflows/ssnoir-r245-r252.yml`。8项编号共用一套冻结规则和信息扰动反证。

## 最小规则与玩家知识契约

3手，隐藏但静态的防守位置A/B初始概率各1/2。每手玩家可：

- 攻击A或B：若避开守卫得**+2**，若被阻挡得**−3**；无论成败都能观察原有防守位置，下次可以按观测选择安全侧。
- `P`：花一手、不攻击，立即观察**旧**防守位置；随后观察活动有概率`f`使目标转移到另一侧。**转移结果不立刻公开**，因此这条消息有可能已经过时。
- `W`：合法结束本时段，得0，不观察，也不改变位置。保证不强迫一次负收益下注来人为提高观察价值。

关键在于玩家完全知道`f`，也知道P观察的是移动**之前**的位置；绝对不能让模型在P结束后偷看被扰动的新位置。本局每手在观察反馈后重新选择行动，收益加和；`f`变体的所有其它奖惩与行动数保持冻结。核心判断是：「现在直接冒负收益风险获得收益和信息，还是花行动取得可靠但会扰动对象的线索？」

本批使用Fraction精确公开信念态最优决策，另有**完全不调用Bellman**的概率质量展开器，执行一条可被玩家理解的公开规则；两者在六个f值上逐个一致，不是只做外观分数。正常根部的A/B/P/W全动作Q均输出，可审查为什么P会从严格最优变为严格劣势。

## 关键设计结论

一条消息为真，不代表它在**玩家实际利用消息的时刻**仍然可靠。R248仅仅把观察后目标翻转概率变成1/4，原本不错的P就从有价值变成负机会成本；R250进一步证明可预测的**必定翻转**并不会破坏信息价值。影响玩家判断的是可预测性及支付代价，而不是“目标被改变”的叙事描述。

反过来，这仍属于P08付费获得信息、P09风险成本、R131信息时点的已有关系之**有用组合变奏**。T=3和一条10%阈值足以完全解释玩家活动，不用继续增加守卫血量或把f扫成大量不同小数救它。作为机制表达素材保留，暂不晋升精选或Debug。

本轮R228–R252三批共25个检查编号，实质是**动态操作构造、隐藏对手学习反证、观测干预的风险与信息**三类研究。三批既无真人试玩也无正式原生，不把“25轮”说成25种成功玩法。下一阶段优先从**让玩家实际做不一样的事**出发，设计无提示的小型纸面试玩所需的可观察操作，尤其要检验玩家能否真正理解中间重排而非死记两条公式。人类反馈仍异步、原样归档。
