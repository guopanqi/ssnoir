# R43：共同隐藏条件与连续反馈

状态：待研究；数学提案。R42反馈改变后续概率却被强固定序解释，下一问题是结果改变玩家对共同条件的认知。区别于边做边看的首次直接揭示：信息逐次积累，不另加探查动作。

四颗公平独立行动骰、单回合、目标4、冷静5，单调主进度；两种方法甲／乙都推进同一个目标，惯用稳／险收益与代价不变。隐藏条件在开局固定且先验各半：条件0使甲按技能0、乙按技能2；条件1交换。方法与行动结果可见，条件不会重抽；玩家知道两种可能，但只从坏／中／好反馈更新认知。冷静5排除伤势主值影响。这里改变的是判定条件，正式实现及玩家呈现尚未验证。

假设：同一次行动既推进又给共同条件提供连续证据，余骰可以选择方法和面值。廉价检查先判断稳做能否按主目标支配删除；不能把骰序改变或A/B换名本身当新体验。强参照：开局选定方法不再换；每次选当前后验更可能占优的方法但骰子自由；最高骰先用但方法自由；开局看四骰后选最佳固定骰序，方法继续随证据最优。所有对照在真实开局固定条件下执行，不把混合概率误写成每手重抽真值。

主目标仅纯完成概率；不优化冷静、耗骰与健康次目标。先冻结这一组，不扫隐藏技能／目标。精确贝叶斯状态可归并相同比例后验，合并骰子排列时保留概率权重。只允许此前结果影响决策，不能偷看隐藏真值。

停止点：最小模型及强族裁决。若当前后验选方法或初始固定序已充分，收窄为可读反馈的基础关系，不靠更多隐藏状态或探查动作救题。仍有解释价值时才查真实最优前缀、独立固定真值枚举；最少也需独立局部固定真值复核以防错误更新。该批不接入Content／原生；未知概率如何清晰呈现仍待后续判断。
