# R43：共同隐藏条件与连续反馈

2026-10-03；状态：已裁决，连续反馈保留为数学扩展材料，当前公开判定下不直接接入；负责人：R43探索者与协调者。专属输出本目录；没有修改计划参数、Content、全局记忆或 HTML。

主结果：**当前后验选择较可能占优的方法，逐126个初始无序手牌都达到自由贝叶斯策略的纯完成值。** 相对固定一种方法，反馈调整方法增加5.89459个百分点；额外自由安排骰序相对最佳初始固定序仅增加0.00595个百分点。选定贪心策略下58.63%的正常路径至少换一次方法：这是连续证据下的响应，不能把后验贪心称为固定流程。数学关系成立，但当前公开判定界面会泄露该隐藏条件，不能直接作为现有可试玩模式。

## 冻结规则与支配筛选

四颗独立公平d6、单回合、目标4、冷静5；开局一次确定隐藏真值，先验各半，之后始终固定。真值0甲按技能0、乙按技能2；真值1甲按技能2、乙按技能0。**最终源码与计划真值标签完全一致，没有换名映射。** 方法共同推进一个单调主目标；判定档坏／中／好均可见。纯完成是唯一目标，不优化耗骰、健康或冷静。

稳做收益0／0／1，快做0／1／2；两动作在同一方法、骰子、真值和命运面下判定档相同。反馈信息只由该判定档决定，因此改为快做不会改变观测、后验或信息获取时点。把任意稳做策略的进度记作虚拟轨迹，并在相同隐藏真值及随机源下改用快做，实际进度始终不少于虚拟进度，到目标只会更早结束。冷静不约束主成功，故快做对纯完成逐结果弱支配稳做，主模型只保留快做。本证明不能推广成冷静／健康全维支配。

规则来源是本目录 [有界研究计划.md](有界研究计划.md) 及正式 [FateStrip.cs](../../../../../Engine/Runtime/Core/FateStrip.cs)。执行前已登记两者、主脚本及独立复核脚本 SHA-256；见 [执行登记.json](执行登记.json)。这些是数学提案，未制作正式 Content。

## 主模型及强控制

状态是剩骰、剩余需求及隐藏真值的整数比例后验 `(a,b)`。只归并公因数相同的后验，允许一个分量为0；坏／中／好概率按两真值相应面数的加权和计算。观测某档后分别乘对应真值的该档面数，再归约整数比例。这个转移是对开局固定真值的 Bayes 更新，不是重新抽取真值。

主模型用 Fraction 精确求解。自由骰选择的输入保持排序；有序族保留骰序，只使用首骰。126个无序初始手牌以排列重数加权，全部不重复有序初始序列合计1296条；有序后缀缓存复用续局值。结果保存逐手牌值、最佳初始序、差值和缓存身份，见 [数学结果.json](数学结果.json)。公开策略只读取当前剩骰、进度、后验，不读取实际真值，见 [公开策略.json](公开策略.json)。

| 策略族 | 精确完成概率 | 完成率 | 能力边界 |
|---|---:|---:|---|
| 自由贝叶斯 | 202525/209952 | 96.462525% | 随反馈自由选择方法与骰子 |
| 开局固定方法 | 112681/124416 | 90.567933% | 开局选甲或乙，之后不换；对称先验下两者相同 |
| 后验贪心方法 | 202525/209952 | 96.462525% | 每手选择较可能具有技能2的方法，骰子继续求解 |
| 最高骰序、方法自由 | 809449/839808 | 96.385007% | 从高到低用骰，方法随反馈最优 |
| 初始最佳固定骰序、方法自由 | 405025/419904 | 96.456571% | 看初始手后选序，后续骰序固定，方法随反馈最优 |

后验贪心在真值0较可能时选乙，真值1较可能时选甲；平后验固定选乙。交换甲乙同时交换真值使完整状态及后续策略镜像，平后验两方法等价；独立复核还逐条件核对了镜像后验与平后验方法值，见下节。

开局固定方法的最终贡献，在给定真值后相互独立且非负，完成事件只看贡献和，因此固定一个骰序即可计算它的最优主值，未遗漏这一族的自由骰序能力。它仍从真实反馈更新条件后验来评价续局，但不允许换方法。

## 独立固定真值复核

[独立固定真值复核.py](独立固定真值复核.py) 直接誊录技能0与2时的六个命运面，不导入主模型的概率表、转移或求解函数。执行通过，见 [独立复核结果.json](独立复核结果.json) 与 [独立复核.log](独立复核.log)。覆盖：

- 一至两骰的648个条件：27种无序剩骰、需求1至4、后验比例1:1／2:1／1:2／3:2／1:0／0:1。独立固定真值计数树重新优化方法及骰子，逐值等于主模型；后验贪心也逐值相同。
- 同一648条件交换后验的镜像核对；168个平后验／行动骰条件，首方法甲乙的值相同。没有用一个任意平局规则制造增量。
- 一个明确后验校准：先验各半，甲用1，坏／中／好概率1/3、1/2、1/6，观测后真值0概率分别3/4、1/2、0。
- 126个初始手牌×5族共630个条件，在真值0与1下分别执行已公开策略。每棵树的真值整局固定，按该真值的六个命运面逐分支；提前终端用 `6^剩骰数` 补全未消费命运序列的计数。合计对应1632960条完整命运序列，所有逐初始手值及加权平均与主结果相同。

最后一项是**全初始手的独立固定真值策略执行**，使用主模型导出的公开策略作为待检查对象；不是独立全局四骰优化。局部树只有一至两骰，不能把两类证据合称独立重算全局最优。原生0、真人0、Unity画面验证0。
