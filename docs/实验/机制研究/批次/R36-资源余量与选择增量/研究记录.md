# R36：资源余量与选择增量

2026-10-03，协调者单独完成数学阶段。**保留为多回合组合候选，进入正式接入与体验裁决；目前尚无本批可试玩入口。** 它校准用户压力/修复参照，并不计成完全新原始机制。

## 为什么改变这个条件

R35目标8在三回合条件下仍几乎被简单族解释。未经伤势和溢出修正的12次惯用风险行动名义平均进度为17.6667；目标8加两项修复总需求12，可能留下过多余量。这是提出容量假设的参照，不是真实可行性证明。

[冻结计划](有界研究计划.md)在结果前只把目标长度改为12，全部结果档仍为+1/+2，不提高行动收益或伤害，不增加第三负担，不扫描下一点。首次跨3/6各生修2负担；推进坏档即时+1压力，未修每轮各+1；既往压力不可退，5失败；三回合、冷静3、基础税1、技能1、完整伤势。全部进度保留，目标12即时成功。对照仅关闭即时坏档加压。目标12首回合最大8，因此所有条件首回合完成必须为0，实际核对通过。

## 正常模型路径中的改判断

[前向质量](可达调整.json)沿选定自由最优策略传递公平手牌/判定/首次伤部位概率，质量守恒且六维结果与根求解最大误差小于2e-14。

| 至少一次事件 | 纯完成 | 早完成 |
|---|---:|---:|
| 使用修复 | 72.3354% | 24.1344% |
| 选择严格优于推进的修复 | 72.3029% | 24.0855% |
| 推进坏档后，取消那1压力会把全局最优所选动作改回推进 | 2.7485% | 9.8578% |
| 上述翻转发生时无头部轻伤 | 2.1298% | 7.5749% |

事件是至少一次路径质量，不是动作次数、真人频率或正式访问。修复动作期望纯完成0.9859、早完成0.3923，不能直接当至少一次概率。最优平手仍有选取约定，这不是所有平手策略共同分布。

反事实只移除上一步探索坏档增加的1压力，保留当前主进度、负担、冷静、伤势和剩骰。必须当前全局最优选择修复、且反事实全局最优确实选择推进，不只是两个动作值交叉。首版只有二选比较，收紧后重算，初检输出保留。

一个实际被早完成策略访问的见证：第2回合，进度8/12，甲乙各需修2，压力3，冷静0、非头部伤势2，仅余6。推进风险好+2到10，却因本轮两项未修结束到压力5，第三回合来不及开始；修复一项，结束压力4，第三回合继续，后续完成机会86.9995%。仅取消上一步坏档那1压力变为2，同骰推进后结束压力4、剩2进度，后续完成97.7945%；同骰修复反而剩4进度，后续93.8114%，所以改回推进。该见证模型状态访问质量约0.5658%，来自真实前向路径，不注入状态，不依赖头伤恢复边界。

## 独立精确核对与边界

[未来一轮独立核对](未来一轮独立核对.json)在7个已受伤非头部后续局面中，独立Fraction枚举126新四骰，合计882条件，逐手主收益最大误差2.22e-16。这里有效技能恒1，末回合修复可以省略并保留其骰：修复不推进、不恢复冷静/技能，减少的结束压力不能带来成功；独立递推仍逐步检查探索坏档的即时压力和7伤先失败。没有套用R33“同档修复替推进”的错误耦合。

精确后续结果核对上面的86.9995%、97.7945%、93.8114%，并核查压力3/4导致另一许可普通状态的推进/修复方向不同；后者不声明正常策略常见。它是选定后续状态的独立优化，不是全部三回合初始手牌独立复核。首次部位均匀和公平独立骰仍是模型假设，沿用R21正式伤势语义不算本批正式校准。

独立初检发现概率表前两骰面漏加技能偏移、另一个对照样例为未生成负担，均被核查中断；根据FateStrip与状态约束修正后882条件全通过。主模型和完整结果未修改，诊断原样保留。它们不是新正式样本。
