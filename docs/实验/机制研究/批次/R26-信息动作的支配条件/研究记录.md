# R26：信息动作的支配条件

2026-10-02，已裁决（纸面必要边界），本会话研究者。R24附赠信息的触发概率不足以建立高骰投资；R25提前探查的机会成本有价值。两批隐藏事实不同，不能直接做因果归因。本批用R25同一目标规则推导一个可复用边界，无需更多游戏样本。

## 最小对照与证明

保持甲乙各3、目标在一处、一次投入一骰、完成正确处成功。若另设“稳健搜索的好档，在推进1的同时也立即定位目标”，它和探查有完全相同的判定概率与冷静代价：坏−1、中0、好分别“搜索+1并定位”或“只定位”。两者信息在同一时刻给出，搜索进度没有新压力/期限等副作用。

在任何未知状态，取任意合法一处的稳健搜索，与探查按相同骰和相同判定结果配对。坏/中后的公开信念、冷静和剩骰相同；好档两者都知道同一个固定真值，搜索还额外留下1进度。如果该处正确，后续需要的进度更少，甚至立即完成；若该处错误，该额外进度可忽略。稳健搜索可以模仿探查之后的全部有收益操作。

因此针对本场完成概率，探查被稳健搜索弱支配。平手保留冷静也不会反转：搜索的提前完成只会省去后续冷静损耗，此结构没有恢复行动/额外成果需要在结束前争取。不必扫骰面、路线名或种子，策略集合与逐结果耦合已经足够。

## 边界与设计含义

成立需要：相同信息、相同获得时点、相同判定/冷静代价；额外进度只有益处；结束仅对应同一目标，没有结束前可争取的其他收益。不能扩大为所有探查动作无价值。

R25普通搜索只在搜满时揭晓，探查可提前定位，所以不满足同一信息时点，支配证明不适用。用户船上推进会产生漏洞，或R13完成前置会开启期限，也不满足无副作用；那种推进有可能不值得直接替代信息行动。

保留的判断标准：**检查信息是另一行动的免费副产物，还是确实提前获得并有机会成本。**写专门调查卡前，先比较最强的普通推进是否已经在同一时刻给出相同信息，避免制作支配动作。免费信息与信息价值都不是策略深度的自动证明。

纸面证明，无新模型、Content、原生、真人或Unity证据。下一由R25真人反馈决定是否深入该基本关系；独立数学问题可以研究跨回合保存定位、但搜索未完成时清零的组合，检查弱手买信息为下一回合准备是否成立。不得直接把单回合83.52%结果套到多回合。
