# 研究员私有｜成功触压/失败触压对照（本批零真人）

这是R518机制的**实际人类理解、计划变化、重玩意愿**验证，不是证明两种机制数学不同；数学规则和最优策略已单独穷举，但不向尚未试玩的人泄漏。

## 操作与反平衡

实际真人两局，每局最多6手，开局(p,d)=(0,0)。组1先甲成功触压再乙失败触压，组2反序；交替分配。每位参与者开始前**预生成一条最多6个公平GO判定结果**，按参与者执行的第1、第2……次GO依次揭晓；VENT/STOP不消耗序列。两局可以使用**同一条预生GO成功失败序列**，用于控制一次实验里的随机差异，但必须记录后一局对先前结果的记忆和练习效应；对不同被试可预生成不同公平序列且不能因操作更改。

压力阈值2；当GO加压到3时即时结束记-4。6手到期或STOP，若p>=3得12，否则得2p。VENT只能将d减1（下限0）且消耗手数。研究员绝不提前告诉下一次GO成功失败，也不按玩家表现实行重抽。

逐手原始记录：组别、试验顺序、随机GO序列、规则、期数、当前(p,d)、玩家动作、这次GO是否成功、更新后的(p,d)、是否提前结束、得分、**参与者原话解释与有无修改原计划**。结尾开放问：哪一个对你产生不同注意力、是否迁移前局策略、是否愿意再次经历；保留原话和负面/无差异观察，提交反馈inbox；研究员后续reviews单独给出解释。

## 数学结果，禁止事前向被试泄漏

在当前冻结规则下，甲成功触压最优31/4=7.75，乙失败触压最优29/4=7.25；各自最好的729条固定完整脚本仅23/4和25/4。**然而两者同一句策略全优**：达到3进度即STOP，压力到2就VENT，否则GO。数学策略一致不等于两者在人类感受上必定等价；人表示“其实就是一样的”也不算错误，应如实记录。
