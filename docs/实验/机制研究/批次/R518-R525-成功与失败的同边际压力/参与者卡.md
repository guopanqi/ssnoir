# 参与者专用｜同一成功率，两种压力来源（当前无人实际试玩）

这是一项两局的纸面小游戏。每局最多6次行动，每次只能选 **GO（推进）**、**VENT（减轻压力）** 或 **STOP（结束）**。

开始时进度0、压力0。GO会进行一次公平的成功/失败判定：成功进度+1，失败进度不变。VENT需要消耗整次行动，压力-1（最少为0）。STOP立即结束。压力上限为2；如果某次GO令压力达到3，整局立即失败，得分-4。主动STOP或用完6次机会：进度至少3，得12分；进度不足3时每份进度得2分。下一次GO前你始终看得见当前进度和压力。

你会玩两种规则，各自重新开始计算6次行动：

- **规则甲**：GO成功时除增加进度外，还会让压力+1。GO失败时压力不变。
- **规则乙**：GO失败时进度不变，但压力+1。GO成功时压力不变。

两局每次GO的成功率始终都是1/2，压力+1的总体机会也都等于1/2；但压力与成败的关系不一样。研究员会为你安排顺序并在你行动后揭晓结果；在选择动作前不会告诉你下一次GO是否成功。

每一手可以用自己的话说：为什么现在继续、消解压力还是停？这次压力变化有没有改变你原来的安排？在第二局里你有没有沿用第一局的判断方法？

两局结束后，可说说哪一局让你更担心、哪一局使成功/失败显得不同、你是否觉得自己在进行不同的选择，以及你是否愿意再玩一组。也可以回答“两个版本没有实际区别”或“不想玩”。

此任务**没有已经采集的真人轨迹或评价**，也不提供数学最优口诀。研究员私有文件不要事先给参与者查看。
