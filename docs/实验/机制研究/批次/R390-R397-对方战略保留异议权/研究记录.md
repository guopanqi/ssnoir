# R390–R397｜对方为了自己的长期目标保留异议权，会怎样改变规则Scenario？

2026-10-12。直接检验[R374](../R374-R381-共同规则与异议权/研究记录.md)的核心证据缺口：原模型里另一方一被限制就立刻花掉唯一否决权，是**短视固定政策**。本批改为对方可理性地决定何时使用异议，最大化自己三回合的行为是否符合私人目标的次数。

**最重要的可比性约束：本批玩家在开局一次性公开承诺完整三手规则序列**，对方因而有充分信息做未来计划。R374是玩家每回合见反馈后重新制订规则；因此两者不能直接相减后声称差额“完全因对方变聪明”。本批与R374唯一严谨的数值比较是其相同固定规则脚本的短视执行方式，及本批战略版各脚本；不混淆信息时点。

## 去情景机制卡

玩家公开希望三手实际结果分别A、B、A；一次性公开三段可执行共同规则：OPEN、ONLY-A、ONLY-B。两个行动者有不同收益：玩家每次实际结果符合自己的公开需求得1，每次改变现有规则成本1/4；对方有稳定私人偏好θ=A或B，始终希望自己每回合实际执行θ（每次得1）。被ONLY-相反方向限制时可用唯一一次否决让规则恢复OPEN。玩家不知道θ；对方知道自己的θ，也知道全计划，决定是否保留这次否决，以最大化自己的**三手总收益**。

有时对方在不同时间否决都能取得同样的个人收益，因此不能凭空断言它在平局时一定伤害玩家。完整记录“自己收益最高时对玩家最有利/最不利”两类平局结论。它们不代表唯一均衡。
