# R188–R197｜资源归属、跨周期半成品与可编排的行动规则

日期2026-10-12。继续最新权威《研究定位与评价》的**无情景玩家决策关系探索**，不是第一章NPC支线续编。承接[前一横向批次R174–R187](../R174-R187-横向抽象机制/研究记录.md)，但本组两个对象分属相隔较远的心理循环：**有限资源的跨周期配置**与**制定未来行动规则**。

## R188–R193：保留的长期目标，作废的短期资源

去剧情规则：一共4手，两手为一周期。每手刚开始，玩家**当时**看见本手资源质量1或2（各概率1/2），选择分配到A或B。A的进度跨周期永久保留，满4后第4手结束兑现价值4；B每周期需要进度2才能在周期末兑现价值2，且周期末清空，包括没完成的半成品。每手仅选一个目标，两条目标的行动**共享**。不允许第1手玩家提前知道第2手骰面。

玩家的正常循环是：

> 看这一手投入质量 → 在今天可能关闭的B和长期可累积的A之间分配 → 观察余量/下一手质量 → 如果B本期可完成则争取，否则考虑把高质量行动投给可留下的A。

### 证据

| 检验 | 明确比较 | 精确结论 |
|---|---|---|
| **R188** | 每手完全看见当前质量与进度后决定A/B | **11/2 = 5.5** 期望成果 |
| **R189** | 从头到尾只能固定4手A/B，枚举全部2⁴种序列 | 最好 **9/2 = 4.5**；例如`AAAB`、`AABA`等 |
| **R190** | 每一时点只看**当前资源质量**就决定A/B，无权查进度；枚举2⁸=256套完整质量条件规则 | 最佳 **19/4 = 4.75**；优于纯固定，但仍低于完整反馈5.5 |
| **R191** | 沿正常最优策略到达的同一手前公共状态，在本手质量1/2两种可能下严格相反的选择 | 真实可达，具体状态/Q值及路径质量由程序列出，而不是注入作者答案 |
| **R192** | 如果B没在周期末完成，允许B的半成品跨周期保留（B已完成则清空以领取下一周期奖） | 全自由根值依然 **11/2**，增量**0**，这一次放松清零规则不改变最佳成果 |
| **R193** | 去掉题材后做结构审查 | **P02容量＋P04资源质量分配＋P05周期清零**三种旧关系的可解释组合，不能凭5.5比4.5就单独认证新机制 |

更有信息量的是R192的阴性结论：**不能因为游戏存在“周期清零”按钮或文字，就把所有价值归因于作废成本**。在此规则/时长里，最佳政策不会利用未完成B的跨期储备，即使给它保留权也没有收益。需要把另一个清零真正生效的需求/容量局面另行提出机制卡，不能直接继续微调数值凑一个显著差异。

本例很适合练习“没有提前预知下一手资源”的公平策略设计，但还不是实质新型玩法。

## R194–R197：玩家选择一条规则，让后续动作自己执行

与资源分配相距较远，本题测试另一个动词：**编排操作规则**，而非每手决定资源给哪条进度条。初始可从四种公开策略选一种，之后四次质量1/2随机输入**自动执行**：
- `A`：不管质量如何都操作A；
- `B`：始终操作B；
- `Q`：如果本次质量是2就操作A，否则B；
- `T`：如果A还没完成，就操作A；否则B。

A、B分别需要3手质量格，完成时各值4；未完成格数有小额终局价值1/10每格。玩家不是给每个输入下单，而是**选一条能处理未来输入的规则**。一个合理的新玩法假说是“让玩家反复设计并修改规则来应对不断变化的输入”，但这必须先抗下面的负例。

| 检验 | 结果 |
|---|---|
| **R194** 四条初始规则完整枚举所有2⁴输入质量序列 | 最好的是**T：A未满先A，满了做B**，期望成果 **1087/160**；这只是一个很短的公开条件口诀 |
| **R195** 在看到前两次真实反馈后允许更换策略，但改写成本相当于损失第3次自动工作 | 最好仍为 **1087/160**，增量0 |
| **R196** A、B目标都变成4格，仍可中途改写 | 最佳初始T **771/160**，改写依旧无增量 |
| **R197** 实质新颖性审查 | 本题的输入反馈和选规则虽然不是纯粹“填钟”，但**四手局内一次选T就是全解**；作为持续反复进行的玩法，还缺真正让玩家修改规则的局面。不晋升 |

这里是一个重要的负面结果：**规则可编辑，并不等于编辑规则会成为值得重复的玩家活动**。如果最初只需要选对一条模板、以后总不值得改，那么“程序设计/动作变形”的概念很容易退化为固定开局配置，类似P13的整备投资。与“行动B的名字由Y变成Z”相比，T确实表达了一条可执行条件规则，但仍没产生跨阶段的规则修订价值。

## 小结：不是24种新玩法，更不是赶出第七个精选

R174–R197合计24个编号实验/反例，实际深挖的是**互惠生产、风险储备/保险、质量与跨周期窗口分配、自动规则编排**四种相邻或交叉的行动关系。成果中没有可充分判定为独立创新、可玩且成熟的新模式。R188最明确的选择价值来自**当前信息与不同持久性的资源目标如何重新分配**；R194最值得长期探索的独立假说是**玩家能否真正创建、修改一种行为规则，而不仅预先套用一个静态阈值**。

下一阶段停止继续扫q、目标长度、局数；可以从两个**不同**的角度尝试小而新颖的设计：
1. 双用途资源除了投给A/B，还能**改变以后骰子的归属规则**，是否出现跨局的注意力迁移/学习，不是普通投资产能？
2. 规则编排不再从预制A/B/Q/T四选一，而是让玩家通过两种基本操作**组成**一段可以被反馈改变的规则；在具体公开状态反复进行编辑，且每次编辑真的优于保留旧规则。

只有新机制卡能严格说明“玩家连续几手做了与旧模式不同的什么”，才继续写大模型。异步真人体验另行设计，不自动进Unity Debug。
