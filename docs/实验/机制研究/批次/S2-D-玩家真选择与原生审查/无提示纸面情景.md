# SSNoir · 两天，三件事情

**一页纸原型／供第一次阅读。不是游戏第一章的正式剧本。**

距夜莺的信被送走，只剩今天。尼尔答应帮她截下那封信；与此同时，码头拳手艾迪也托他办一件急事。艾迪今天等不到回复，就只好自己去承担后果。

- **夜莺的信**：先调查邮路。摸清邮路以后，你还需要亲自交信，才算把这件事办成。**交付只能在今天完成**。
- **艾迪的请求**：需要亲自投入时间处理，**今天过后机会结束**。
- **递信人的踪迹**：最初你还不知道有这件事。调查邮路时，你发现一个陌生人同这封信有关。如果你直接交信，仍没查完的这条踪迹可能断掉；但已经得到的线索不会因为你去办别的事而消失。只要没有交信，这条线可以留到明天。

第一天有**四次行动**，第二天还有**三次**。调查邮路和处理艾迪的请求，各要累积2格才算推进到位；追查陌生人也要2格。每次行动投入一颗骰子，可能得到0、1或2格进度；交信一旦可做，还要单独花一次行动。各项成果可分别获得，错过的机会无法补回来。

## 在这个时刻

今天你已帮完艾迪，也查清了邮路。你知道交信的位置，但刚得到的另一条线索指向那个陌生的递信人。你还没有追到他。

桌面上出现两件真实可做的事情：

**把信交出去**：今天的委托可以确定有结果，但可能永远查不到递信人。

**继续追踪递信人**：你能更接近幕后真相，但这也会消耗今天所剩的行动，可能耽误交信。

同一局里，出现线索的时刻可能早一点，也可能晚一点。你的选择不必每次相同。

## 不给玩法作者答案的三个审阅问题

1. 只看这一页，你是否知道今天**必须**完成的事、明天还能做的事分别是什么？
2. 当你得到新线索时，你觉得“交信”和“追查”的后果是否真的不同？你会先考虑什么？
3. 如果你选择追查，最后没能交信；或者你交信后错过了陌生人，你会觉得那是自己的决定，还是规则偷偷剥夺了机会？

**请先记下直觉，再阅读研究结果。** 作者审阅是异步的，不影响后续研究和技术验证。
