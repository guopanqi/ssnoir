# S2-D｜线索到来后真的还有两件事可选：数学与原生双轨审查

更新：2026-10-12。前置[阶段契约](阶段契约.md)。本批源代码独立编号为 `s2_true_choice_audit.py`，**不要与同时入库的 `s2_real_choice.py` 混成同一模型**：本批把“截信与帮艾迪的承诺期限”都放在第一天（7次行动，第一天4次），而另一个研究稿的6动作不限制交信于第一天。两者同样都是**独立纸面代理**，不能混用期望收益与策略路径。

## D1 情景重新组织而不是另建系统

原R119的失败是：查信可以从1直接获得2格来到3格，线索从2格出现，但主线3格完成同时关闭它，玩家没有操作时机。R121补一手恩赐窗口，又可能只剩追查这一件事。

这次改为很容易讲清的两个**不同工作步骤**：第一天先把信的调查推进到2格，才**得知递信人的身份/踪迹**；之后必须另花一行动“交付信件”，交付才会关闭未完成的递信人追查。新消息出现的一瞬间至少有“交付信件”和“沿线追查”两项现实可行动作，有时“帮艾迪”也还在。第二天交付机会已过，但尚未关闭的递信线索仍可继续追查。两日分别为四、三次纸面行动，所有普通工作1次给0/1/2等概率进度；交信消耗一个行动且确定完成A。B需2格、仅第一天；C需2格、在线索揭示后开启；总成果A2+B2+C2，各永久兑现。**本研究收益仅是冻结代理偏好，不是对作者或玩家的情感判断。**

此组织没有新增“恩赐窗口”，玩家拥有真实的可见目标、公开的第一天截止时间和事先说明的交信代价。调查过线索阈值的一次动作只会使“交信”变成一个新按钮，不会自动关掉追查。

## D2 强策略与消融（数学）

代码：[Exact Fraction](https://github.com/guopanqi/ssnoir/blob/main/tools/content-validator/experiments/s2_true_choice_audit.py)。[独立 CI 验证](https://github.com/guopanqi/ssnoir/actions/runs/38196203976)已成功。对照主例B价值2：

| 检验 | 精确结果 |
|---|---:|
| 全自由DP双成果效用（3目标） | **6598/2187** |
| 24条完全固定行动优先级的最好结果 | **6526/2187** |
| 自由相对固定优先级增量 | **8/243** |
| 可观察条件阈值族的最佳规则 | **6598/2187** |
| 自由相对最佳可学公开规则 | **0** |
| 同时有追查与交信选项的正常路径动作访问质量 | **11/27** |
| 严格优先追查的正常路径访问质量 | **1/9** |
| 严格优先交信的正常路径访问质量 | **8/27** |

在“艾迪已得到帮忙、查信达到2、递信人刚揭示、追查尚为0”的**同一类公开局势**下：
- 还有5次行动时：追查的Q值为 **14/3**，交信为 **4**，因此严格**追查**。
- 只有4次行动时：追查的Q值 **314/81**，交信为 **4**，因此严格**交信**。

两者是同一最优策略的正常可达状态，并不是人为改变结算规则后比较两个系统。两种动作都仍合法且有可兑现后果；只有剩余时间不同，才让正确优先级反转。访问质量是**期望访问次数**，不可说“对应百分比的真人玩家会这么选”。脚本还单独计算每一局是否曾到过严格追查或交信状态的发生概率，详情以Actions JSON为准。

**独立四消融**：关闭C整条追查；让交信后仍可追查；取消C的解锁门槛；取消第一天交信的截止时间。相同七行动、随机结果和收益下：禁用C从6598/2187降至206/81；取消交信关闭则上升至970/243；开局可追C与交信第二天仍可执行，均使最优不下降。**这证明线索的存在、关闭约束与期限有相互独立的数学作用**，而非只是多一张卡。直接关闭C的差为1036/2187（约0.47371）效用点；取消关闭的增量为2132/2187（约0.97485）效用点。绝不将这些效用差称为成功概率或乐趣。

强解释警戒：B价值2的**最强公开条件规则已完全达到自由DP**；B=1.5时本批搜索的同类公开阈值还落后47/486，不等于人类必须复杂规划。停止再扫参数，保留“已学会、可读”的行动逻辑。

## D3 正常策略路径的可信度

冻结同值选择先帮艾迪、再追线索、再交信、最后查信。记录全部以最优策略能到达的公开状态、每条相同行动结果概率和合并后的状态质量，不把“存在一个反例”代替正常路径。在同一局里**严格追查**和**严格交信**的可达概率都非零；而且这两种选择都不是“唯一能点的按钮”。

这里仍有重要故事性疑问：玩家是否重视艾迪帮忙胜过线索背后的人？纸面用统一奖励2无法回答。下一步须由无提示情境审阅而非继续给剧情贴数学标签。
