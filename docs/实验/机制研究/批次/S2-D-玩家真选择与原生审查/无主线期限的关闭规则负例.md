# S2-D 独立反证：主线没有交付期限时，“关闭追查”可能毫无因果价值

2026-10-12。此文件是**一个边界反例**，不是R122–R124正式编号的重复实验。源代码：[六行动实验](../../../../tools/content-validator/experiments/s2_real_choice.py)。该脚本独立于 [七行动正式S2-D数学研究](../../../../tools/content-validator/experiments/s2_true_choice_audit.py)，不可混用期望值、策略质量或默认期限。本负例和正式纸面都不是 C#+Scheme 概率等价。

## 冻结条件

六行动，每天三行动。A调查达到2格揭示递信人，之后专门花一行动「截信」才取得A的2份数学奖励；C追查需2格才能取得奖励2，截信会关闭未完成C；B帮助艾迪仅第一天有效，达2进度取得奖励3/2。调查/追查/帮助分别获得0/1/2等概率的进度。**关键特意与正式版本不同：A的截信动作在第二天仍可做。**

先承认纸面修复有效：首次公开线索状态下「截信」与「追查」同时有真实机会，最优正常轨迹还有严格的“帮艾迪”分支；不能把新增行动卡简单当作玩家选择。

在首次得知线索时，选追查、选截信、优先帮艾迪三个动作均分别在正常最优路径的非零质量条件下严格胜出。**然而这一点不等于“关闭C”本身必不可少**。

### 为什么关闭增量为零

只要截信可延期到第二天、不会因晚截损失奖励，那么任何在“截信后继续追查”的取消关闭版本中可行的动作序列，都可以把截信这一次行动移到追查完成之后：同样花一次行动、同样获得奖励2、没有迟到惩罚。于是允许先截信再追查这一附加选择**不提供新的最优收益**。这是一条动作交换性解释，不需要再扫很多参数。

而 [正式S2-D七行动模型](研究记录.md) 中，「交信」和「帮艾迪」都必须在第一天完成，但追查能延续第二天。先交信可能真的关闭一个未来机会；再晚交信又可能错过交付。正式版本数学[消融](../../../../tools/content-validator/experiments/s2_true_choice_audit.py)证明去掉关闭约束能显著提升期望效用。这两个模型不能合并成一条 “完成目标一定会牺牲追查” 的普适结论。

## 阶段判断

要让**收束一个问题会丧失另一个问题的机会**成为真正值得玩家权衡的独立规则，至少还需要一个不能任意调换动作顺序的时序事实——例如公开的交付期限、无法延后的承诺或阶段转换。仅仅写“截信关闭C”而不约束何时可交信，会被“先追查、再交信”流程完全解释。

不因本负例加入原生调试白名单、第一章正典或新的模式统计。原生已验证的是[另一套七行动纸面对应的独立Scheme场景](../../../../UnityClient/Assets/Resources/Content/scenes/encounters/研究·线索两选.scm)，其真实骰子一次稳进1格，不得回灌到本模型的0/1/2等概率假设。

未验证：不同人对A/B/C的情感价值、玩家是否看懂线索刚出现时的两条路、真人试玩是否有遗憾或重玩欲。下一步应做简短无提示故事审阅，**而非增加第四件事、引入更多资源或提高计算维度**。
