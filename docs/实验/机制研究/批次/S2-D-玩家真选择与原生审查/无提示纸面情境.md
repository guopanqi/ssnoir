# 两天、一封信与一个人的请求——S2-D 无提示纸面审阅

**这是独立的玩法理解实验，不是 SSNoir 第一章正典或正式剧情。** 不必计算任何概率或寻找最优解；我们要看人是否知道自己在决定什么、为什么会在意。

## 已知情况

你只有两天时间。夜莺请你截住一封信；艾迪今晚需要一个人帮他度过麻烦。你可以在第一天调查信件、帮艾迪，或者暂时先做其中一件。调查完成后，可能发现一条递信人的踪迹，这会打开另一种追查方向。

信件**调查完成**并不等于**正式交付**。交付必须由你再花一次行动主动决定。交付后，那条尚未查完的递信人踪迹会消失；你无法再沿着它继续追查。交信与帮助艾迪都必须在第一天完成；追查已经发现的踪迹可延续到第二天。已经完成的成果不会被撤销。

你每行动一次，选择把行动机会放在一个目标上。遇到好结果，可能一次推进两格；一般结果推进一格；坏结果可能毫无进展。目标不同，进度不会自动互通。所有尚未完成的任务可能因为到期失去机会。

## 情境一：消息刚出现

你已经帮艾迪度过难关，也把信查到了发现递信人的阶段。此时你看见两条仍可做的行动：

- **交付信件**：立即兑现夜莺的委托，但失去尚未完成的递信人踪迹。
- **沿线追查**：继续调查谁在送信、背后是谁；会占用今晚仍可以拿去交信的一次行动。

今晚还剩下一点时间，但你知道如果再拖延，交信也会错过期限。你会先做哪件事？你最担心失去的是什么？

## 情境二：时间更紧

保持相同已知事实，但你经历了一次没有获得实质进展的行动。此刻时间更少，交付期限正在迫近。递信人的踪迹仍没有查完。你现在是否会改变决定？改变的理由是人物、真相、行动风险，还是纯粹觉得数学上来不及？

## 不提前告知的审阅问题

1. 你能否在不解释规则的情况下，用一句话说清“调查信件”“交付信件”“沿线追查”是三件什么样的事？
2. 哪一刻你真正有两个想做的选择？如果感觉只剩一个正确答案，请说明。
3. 如果艾迪还没得到帮助，且今晚就会错过，你会怎样理解他与夜莺之间的取舍？
4. 你希望知道哪些信息，才有能力作决定？又有哪些信息不应该变成数学值供你计算？

这是一次**无提示审阅稿**，不提供最优阈值、收益权重或作者预设答案；它不是已实现的真人试玩，不应被标为已验证可玩。历史反馈（R50/R54）指出没有明确目标或者已经不能改道时，再复杂的调整规律也不会有价值。本稿专门暴露这两个问题。
