# 研究员私有｜AUTHOR/MENU配对实验（当前零真人）

不得给尚未结束四局的参与者查看本文件、脚本、期望得分或隐含结论。研究的重点是理解与重复活动，而不是谁达到数学最优。

## 协议与随机化

参与者均玩两张公开目标序列XXAA与XXXX，各序列在AUTHOR与MENU两种方式下各玩一局，一共4局，4回合/局。为控制先后练习效应，按实际参与者交替分配：
- 组1：XXAA-AUTHOR、XXAA-MENU、XXXX-MENU、XXXX-AUTHOR。
- 组2：XXAA-MENU、XXAA-AUTHOR、XXXX-AUTHOR、XXXX-MENU。

每局开局程序**重置0000**；当前目标函数公开；提前x在每回合选择前公示，晚到y在选择**之后**揭晓。四格按00、01、10、11排列。研究员在每局前秘密预生成独立公平的四组(x,y)，不可因为玩家表现而重抽或偷换输入。参与者每局不知后续输入，但目标序列可事前告知。两种方式每次EDIT都占一个完整行动，RUN和MANUAL每回合都只有一个输出机会，没有额外容量。

记录每手：组别/局/期、目标、早x、晚y（先藏后开）、当前四格表、动作、更新后的表、输出及正确性、参与者原话理由、是否改变下一期计划。若受试者把翻转规则理解错，记录原话与纠正时点，避免事后按研究员理想理解改写。

## 数学结果不能先泄漏

R446–R453的4期模型精确最优：XXAA下AUTHOR 11/4、四预设5/2；XXXX下AUTHOR9/4、四预设3。这是**模型最优期望**，不是玩家应得分数，也不是判断喜好或难易的测试答案。随机输入有限局波动很大，分数不足以推断玩家心理。

两模式不具有等价表达力（四预设没有AND/OR），实验只问**主观理解、可学习、迁移、愿否重复**。不能因为AUTHOR某局分数高便声称其创新。若受试者在菜单模式用“本期挑适合函数”而在编辑模式说“预想未来多格”且愿意再玩，可作为一名人的原话证据；若只背固定顺序或嫌编辑麻烦也如实记录。真人回合原话入反馈inbox，后续独立review；目前实验仅完成设计，不虚构参与者。
