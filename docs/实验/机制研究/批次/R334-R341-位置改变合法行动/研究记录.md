# R334–R341｜身体的位置限制了能否行动：先观察还是先抢占侧翼？

2026-10-12。该批是完全去剧情的站位—信息—合法行动模型，不是SSNoir主城地图。脚本 `tools/content-validator/experiments/r334_r341_position_action_rights.py`，CI `.github/workflows/ssnoir-r334-r341.yml`。8编号=一张机制卡的六种时序消融及解释，不认证八种玩法。

## 机制卡及防先知约束

三时段。玩家从中央C出发，目标真实位置为L或R，初始等概率，并在相邻时段按公开概率p随机左右翻转。玩家每时段只能做一件事：

- 第一时段选择 **SCOUT**：留在中央、用尽这手，立刻观测当时真实位置（对后面会移动的目标不保证永远正确）；第二时段才能移到某一侧，第三时段在那里ACT。若当时目标确实在该侧，获得**3**。
- 或第一时段**先移动到L/R侧翼**：没有观察信息；第二时段可以在当前位置ACT，目标在此则立即得**4**；若没命中，会知道自己扑空，但第三时段只能在原侧再次ACT，目标已经翻转过来才得**3**。玩家无法从左侧一步跨过中央抵达右侧并同时执行行动。
- **观察信息绝不提前泄露**：SCOUT仅在第一手已选定后显示θ0。侧翼玩家在扑空之前也看不到θ1。既不存在免费瞬移，也不会因为知道目标就让其停住不动。
- 独立对照：如果`SCOUT`无法看到可利用的信息；或者允许第二次失败后第三时段自由瞬移并执行操作，其它概率与奖励不变。

玩家反复判断是“该先知道位置、随后花时间赶去，还是在不确定时先抢占一个实际能执行行动的站位？”而不是R310只增加付费扫描键或额外得分对象。

## 八项真实轨迹枚举、口算公式与条件反证

在θ0左右各1/2、两次独立翻转概率p下，按秘密路径直接展开所有2×2×2=8条轨迹。所有SCOUT回答到第二步侧翼的**四套完整公开反馈策略**都逐条检验；不使用Bellman缓存，也独立按代数计算：

- 观察后去正确侧翼：期望`3[(1−p)²+p²]`；
- 预先抢占单侧、扑空后原地再试：`2+3p/2`；
- 若允许失败后凭空移动到任一侧立即操作：`2+(3/2)×max(p,1−p)`。

R340：q=0时如果**扑空后也可瞬移换到另一侧**，最佳收益从3变成**7/2**，原本值得SCOUT的局面立刻改变。p=1/4瞬移对照为**25/8**，也明显优于有限移动19/8。即“位置限制未来ACT是否合法”有真实的因果作用。

R341：更精细的方程仍得出**容易学习的条件决策**：目标足够稳定，先观察再赶路；变动增大，先占据能立刻行动的位置。虽然这不同于R286“哪里覆盖概率大”的站位直觉，但与已知的信息时间窗口＋空间移动成本关系高度接近，暂不认定新独立玩法；下一次不得只把p从0.1扫到0.12以凑差异。
