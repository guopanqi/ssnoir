# 无提示纸面试玩 A｜先观察，还是先到能行动的地方？

**仅供参与者。** 请不要在四局完成前查阅研究员规约或数学研究结论。

每局有三个时段（1、2、3）。你站在中央C，目标秘密地位于左翼L或右翼R，开局各半。目标在时段之间可能左右翻转，本局翻转概率会提前告诉你。每次翻转独立；研究员在你选动作之前已经锁定整局的三个真实位置。

你在第1时段必须二选一：

- **观察（SCOUT）**：留在中央，立即看到这一时刻目标在L还是R，但本时段无法赶到并执行行动。第2时段你可以选一个翼移动过去，第3时段在那里尝试行动。若目标那时在你站的位置，得3分；否则0分。
- **抢先抵达L或R**：选择一个翼，在第1时段过去，此时看不到目标。第2时段直接在那里行动：若目标当时在此，得4分并结束本局；若扑空，则你会知道这一事实，第3时段仍可在**同一个翼**再尝试一次，若此时目标在此，得3分；否则0分。你不能在最后一手突然跨到另一翼。

目标在第2和第3时段之间还可能改变位置。观察到的只是当时真实位置，不保证未来仍在原地。你不得以提前偷看未来位置决定本局动作。

四局依次使用公开的翻转概率：**第1局 0；第2局 1/4；第3局 0；第4局 1/4**。每局的真实位置由研究员预抽，不依据你的选择改变。

每局请记录：你首先选择观察/左翼/右翼？为什么？如果观察后发现的位置与你预想不同，你是否调整第二步？如果扑空了，你原先有何计划？本局得分是什么？

第2局和第4局结束后，请写下“我是否改变了判断方法，为什么”。四局结束后，说明你是否还愿意连续再玩两局，以及规则中哪种取舍最值得思考。

**这不是智力测验**：允许凭直觉，不需要先写数学公式。重要的是你在每次选择时真正考虑了什么。
