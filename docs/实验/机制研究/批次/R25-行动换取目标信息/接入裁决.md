# R25接入裁决：冻结后再执行

2026-10-02。通过主模型、2268初始状态独立Fraction固定真值/公开后验核对，以及正常轨迹前向分析后接入。甲/乙的猜名无策略依据；保留的是探查行动的机会成本和首次未定位后的取舍。纯完成83.52%、不探查76.33%；首手探查后自由83.16%、只用最高骰探查83.32%，说明大部分关系可以由简单开局规则解释，不夸大择时或选骰的精细优势。首次未定位后继续探查约5.25%全路径、直接搜索约6.35%，不是条件百分比。

正式两入口：研究·定位再搜、研究·直接搜寻对照。共享规则，只改变是否提供探查行动；甲乙各3、目标固定在一处等概率、一回合、初始冷静5、稳健/风险惯用效果。探查好+1线索，单格完成定位；无搜索进度。搜满空处同样定位另一处。真实目标终局才返回，公开策略不调用内部变量。已定位时去掉探查和错误处动作；Clock进度以真实make-clock持有。

冻结样本16局：自由探查技能1种子7101至7108（8），禁止探查对照技能1 7111至7114（4），成长2自由探查7121至7124（4）。只校准公开转移与操作/结算，不以少数样本估计策略排名。全局数、步数与严格回放据实际输出报告。

关键分支如果未在固定样本覆盖，则以公开操作做最多30次定向覆盖搜索7131至7160，优先覆盖“先探查但没定位，再选择探查/搜索”“搜满空处定位另一处”；每个缺口保存首个完整终止轨迹即停。搜索数/保存数另报。不改变内容或注入状态来跑通，规则冻结后不按胜率调参数。示例余骰1/2/4转搜索和2/3/4再探查有数学证据；正式轨迹没遇到则不声称实际已覆盖这两精确手牌。

本批保留基本模式，未认定真人有趣，未证明多回合组合。载入校验及正式会话/严格回放充分后，冻结运行快照，至少分别隔离回放探查定位与搜空定位。研究目标保持继续研究，R20旧反馈不作为本模式的体验证据。
