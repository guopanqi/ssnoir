# R25：用行动换取目标信息

2026-10-02，已裁决（保留基本模式待试玩），本会话研究者。R24只把附赠信息改为好档揭示，最低骰首手仍近乎足够，并未建立“高骰信息投资”关系。下一问题把信息与推进作为两个可替代用途，允许最便宜的支配/容量检查先排除。

冻结最小关系：甲乙两处各需3进度完成搜索，真正目标只在其中一处，开局等概率固定；四骰一回合、技能1、初始冷静5、惯用稳险推进。正确处搜满3即成功；错误处搜满3即揭晓空处，推知另一处有目标，原进度保留。尚未搜满时，推进结果不揭晓是否正确（概率/进度分布与真值独立，不能从坏中好猜真值）。

另有探查行动，使用稳健三档：坏−1冷静，中0，好+1线索；一格线索完成即定位真正目标。探查不推进搜索；定位后探查与错误处推进均为无收益，可从选择集合中删除。先验对称，所以未知时甲/乙开局猜名本身无策略依据，本批只检验探查与直接搜索的资源取舍。

四次最多损失4冷静加回合税1，不会首次受伤；不需要健康偏好。只看实际拿到目标的概率，平手保留成功冷静。直接搜索和探查信息的最大区别是后者可在搜索完成前揭晓。

预先强参照：禁止探查（搜索到空处后仍自由调整）；直到定位前必须探查；首手强制探查后自由；探查只准最低或最高骰但其余仍优化；开局确定搜索顺序，先做完甲再乙（仍可选探查/用骰）；开局明示目标。只查技能1及2，不扫目标长度/骰数。

停止点：探查是否被直接搜索支配或只在极罕见状态使用；若有价值，检查正常路径中是否存在反向选择、简单口诀是否近乎足够，再独立枚举固定真值核对，之后决定是否制作原型。信息身份在整局固定，揭晓不重抽目标。没有新Content或预设完成指标。

## 结果与保留裁决

独立固定真值复核与前向路径通过后，保留为新基本模式，并接入[定位再搜及直接搜寻对照](README.md)。猜甲乙名字在未知时没有策略依据；有效关系是是否为提前定位支付行动机会成本，以及在未定位后如何用剩骰。

| 策略 | 技能1完成概率 |
|---|---:|
| 完整公开策略 | 83.52% |
| 不提供探查，搜索到空处后仍可调整 | 76.33% |
| 未定位时一直先探查 | 80.49% |
| 首手探查，此后自由 | 83.16% |
| 探查只用最低骰，其余自由 | 80.11% |
| 探查只用最高骰，其余自由 | 83.32% |
| 固定先搜甲（仍可探查），定位后自由 | 83.52% |
| 开局免费定位 | 98.81% |

探查增加约7.19个百分点实际完成概率，但不是精准用骰/择时均有巨大优势。首手探查后自由已接近完整，最高骰探查也很接近。固定先搜甲达完整值，目标名字在未知时对称且换名等价，不能包装成选甲乙的策略深度。技能2完整94.59%，首手探查94.58%，开手更加流程化；不增加规则挽救成长退化。

正常最优路径约88.50%开局探查、88.97%至少探查过一次，平均0.942次探查。约9.41%初始手牌在直接搜索与探查的完成概率差大于1个百分点时更适合直接搜索。例如1/1/2/3手牌，最佳先探查约45.49%，最佳先搜索约50.85%，预留行动数比先确认更重要。以目前条件，不能用“探查永远值得”概括。

首次探查未定位后，立即继续探查的事件质量约5.25%、立即直接搜约6.35%，都是占所有初始路径的质量，不是条件百分比。可达对照：未知、甲乙进度0、冷静5、剩1/2/4时，搜索约43.06%、探查约38.89%；换成剩2/3/4时，探查50.00%、搜索46.30%。两状态均出现在最优公开策略首次未定位后的路径，前者质量约1.23%、后者0.62%。核心是剩余行动质量与信息机会成本，而非靠猜目标在哪。

**裁决：保留信息投资基本模式，待真人体验。**单回合只是隔离机制，不称完整多回合交锋；尚未证明比边做边看更好理解。人如果感到一直先探查，应下调单体优先级；不要用7.19个百分点或少量反例反驳实际体验。R26纸面支配边界说明何时专门信息行动会成为多余：普通推进若同时给相同信息且无副作用，探查可被弱支配。
