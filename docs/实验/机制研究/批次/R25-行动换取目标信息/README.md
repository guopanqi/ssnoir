# 新基本模式：定位再搜

在现有“交锋测试（直接进入）”中选择 **研究·定位再搜**，再试 **研究·直接搜寻对照**。每场一回合，可各玩几次。求解结论在研究记录里，建议玩完再读。

建议单人无伤、四项技能1的新局，不用烟酒药品。入口设冷静5；同伴、已有伤势与更高技能会改变条件，反馈时注明即可。

目标在甲乙其中一处，各占一半。两处各需3搜索进度，正确处搜满即找到目标；搜满空处会确定另一处有目标。未搜满的进度保留到本场结束。

| 行动 | 坏 | 中 | 好 |
|---|---|---|---|
| 甲/乙稳做 | −1冷静 | 无变化 | +1搜索 |
| 甲/乙快做 | −1冷静 | −1冷静、+1搜索 | +2搜索 |
| 探查 | −1冷静 | 无变化 | +1线索，定位目标 |

每手花一颗骰。线索只需1格，但不推进搜索；定位后仍须把正确处搜满3。找到目标立即结束，结束回合尚未找到即到期，另花1冷静。对照只拿掉探查，其他相同。

这次最有用的反馈：

- 是否能清楚区分“知道在哪”与“真正找到”？
- 是否在探查和直接搜之间犹豫过，使用哪颗骰的理由是什么？
- 探查没有定位时，你继续探查还是转去搜索？是否只是每次固定先探查？

这是单回合基本关系，完整游戏里的多回合组合另研究。数学与正式转移已核对；Unity画面、触控和真人体验尚未由研究者验收，不把它称为已证明好玩。

原生入口：

```sh
./run --session encounters/研究·定位再搜 --seed 7101 --growth 1
./run --session encounters/研究·直接搜寻对照 --seed 7112 --growth 1
```
