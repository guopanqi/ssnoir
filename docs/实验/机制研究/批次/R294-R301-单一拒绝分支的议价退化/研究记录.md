# R294–R301｜逐次议价：有拒绝反馈，却不必形成适应性策略

日期2026-10-12。第三项不相邻的抽象活动，研究**向独立行动者提出交换条件、从拒绝推断底线、重新报价**的过程是否区别于固定顺序。完全冻结的纸面反证；**没有建造真正的人格Agent、也不是SSNoir的新Scenario系统**。源码 `tools/content-validator/experiments/r294_r301_offer_screening.py`，CI `.github/workflows/ssnoir-r294-r301.yml`。

## 去情景机制卡

另一方有自己的最低可接受价格θ∈{1,2,3}，等概率且不公开。玩家有3次行动机会，可提出报价p∈{1,2,3}，对方**只在p≥θ时接受**。若成功立刻结束，玩家得到`4-p-t×d`；若拒绝玩家得知`θ>p`，进入下一行动。玩家也可以花一手P准确观察对方底线θ，或者合法W等待而不提价。d是公开时间损失：分别冻结为0、1/4、1/2、1。完整DP严格只可根据**已经实际发生的拒绝、探查**更新底线推断，不能先看私人θ。

心理活动假说：先出一个对自己有利的报价→根据另一方实际反应修改价格→衡量急于成交或保留谈判空间。它与R269多结果诊断、P08付费信息、P02产出取舍相邻，不能因为加了“独立对方”就自动算新机制。

### 为什么这是一条重要的同构反证

一旦报价被接受，谈判立刻结束；**只有遭到拒绝的人才会进入下一次行动**。因此即使第一次拒绝让玩家更新了`θ>p`的确凿信念，第二次报价仍只是一个可以事前写好的“失败后提高多少”的既定序列，不需要复杂的即时重新评估。把其他会谈角色、口才、信任条放进去，也不能自动改变这条结构事实。

本模型的付费探查并没有改变结论。允许先观察θ当然改变可以知道什么，但一手观察的成本与纯提价方案对照后，根部未形成严格额外收益。必须区分“诊断有更多信息”与“为这信息付出的行动值得”。

不扩大θ状态空间和报价数来逃避此反证。要保留真正不同的议价互动，必须在**进入下一步之前出现两个以上实质不同的继续行动结果**（例如对方回应两个不同反建议，玩家能选择不同约束；但这需要再次与R269诊断同构审查），而不是“下一阶段总是因为刚才失败”。本批是**停止的负例**，不增加六精选、20结构候选或Debug；无实际人类、无原生证据。
