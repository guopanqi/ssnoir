# R32：推进生成持续负担

本批按协调者冻结的[有界研究计划](有界研究计划.md)执行。本批日期依当前适用 developer 上下文记录为2026-10-02；不修改旧批日期。已裁决（降级为组合边界），仅在本目录写数学程序及证据。

待证关系：推进第一次跨过3/6分别生成需修复2的持续负担，每轮未修各耗1冷静，因此额外进度可能让未来成本提早发生，R26的“额外进度无害”条件不再成立。问题是这是否形成动态推进/修复判断，或只由“赶得完就推进，否则先修”的简单容量规则解释。

冻结目标8、三回合、冷静3上限5、技能1、惯用稳险、完整伤势、无恢复物品；所有进度保留，负担各只出现一次，未产生不能预修，完成目标即时结束。分别优化A纯完成与B第1/2/3回合完成收益3/2/1、失败0；B只是时间偏好的研究目标，不是游戏奖励。首次四部位均匀与公平独立骰为假设。

先比较只推进、有负担先全部修、容量足够则只推进否则先修（粗容量2×剩骰与当前有效技能正概率最大推进之和分别计算）、每回合开头选整轮只推进或整轮有负担优先修，以及逐开局择这些族最优。族内骰/稳险/修哪个负担/主动结束仍最优。A平手按曾伤、成功伤势、成功冷静；B平手先完成概率再按同次目标，容差1e−12。

停止点：强简单族已解释几乎全部差异，则降级为组合边界，不新增独立试玩。只有差距值得继续才计算可达动态方向与质量；不扫参数、不增加负担或恢复救题，不把目标函数差异归因于单条规则，不把有限数学或复算称为正式校准/真人证据。

## 控制定义与容量边界

只推进永远不修。先修族只要存在未修负担就修，两个负担中修哪个仍可自由优化。粗容量族每一步用 `8−当前进度≤2×剩骰` 判断可能当轮完成，成立则只推进，否则对现有负担优先修、没有负担则推进。当前技能容量族把右侧改为每颗剩骰在当前有效技能下有正概率的最大风险推进之和；它不调用自由求解器选择分支。

每回合固定偏好族在完整新手牌与当前公开状态下选择“本轮只推进”或“本轮有负担优先修”，偏好状态在本轮每个结果后保留，到下一回合才能重选。修复优先偏好会对新产生的负担按照原规则执行，而不是中途重新选偏好。每族内具体骰、稳险、修哪个负担和主动结束都最优。开局择优族逐126手在五个简单族中选该目标下最佳，采用同一次目标。

正概率容量更精细，但不能称严格整回合上界，也不能保证比粗容量族更强：头部轻伤加深为重伤会取消−1技能，当前技能之后可能恢复。明确反例为末回合、进度3、甲负担尚需2、冷静0、头伤3、余骰 `[1,1,4]`：当前技能0的各骰最大推进为1+1+2＝4；先投4风险中档，推进1并使头伤升为4重伤、恢复技能1，然后两颗1都好档各推进2，以1/108正概率共推进5、达到8成功。该许可状态反例说明静态容量不能断言“本轮不可能完成”；它不是自由策略正常可达质量统计。本批保留两容量族名称与结果，不混称。两目标下当前技能容量结果略低于粗容量，也不影响最强简单族裁决。

## 末回合主目标支配

末回合只剩当前成功机会，负担压力只在未完成后的结束发生。将任何一次修复替换为同骰、同稳险的推进，可耦合同一个判定档和冷静代价，得到相同伤势转移，主进度至少增加，随后可模仿原策略的行动；额外负担没有机会影响之后回合。若先出现7伤，两个策略同样失败；如果推进提前完成则即时成功。头部轻伤→重伤的非单调性不破坏这个证明，因为替代行动的冷静代价与伤势完全一致。因此末回合修复对成功主目标被推进弱支配，B末回合收益也同为1×成功概率。

这一证明仅指主目标。修复可以降低失败路径最后结算的伤势，所以在主目标平手后，健康次目标仍可能选择修复；不能把“末回合不会提高成功”写成“所有偏好下绝不修复”。

[末回合支配.py](末回合支配.py)枚举末回合1/2骰、进度3至7、合法负担剩余值、冷静0至3、伤势0至6与轻伤头部状态，共23760个局部状态。修复主目标优势最大0，14842个状态推进严格更好。它和主模型共享转移，是数学耦合证明的局部数值检查，未算独立求解。另用独立容量关系核对首回合上界：四行动达到8必须全为推进风险好档，成功路径没有冷静损耗；公平四骰的最大概率为 `(7/12)^4＝11.578897%`。B自由与多个强族恰好达到此上界，核对通过；这是解析边界检查，不是全局独立求解。[末回合支配.json](末回合支配.json)保存结果及头伤恢复反例。

## 模型身份、验证与裁决

主程序[负担模型.py](负担模型.py)显式保留甲乙剩余修复量。主进度单调保留，触发条件只检查旧进度小于3/6且新进度跨过阈值，因此每个负担只能生成一次；修完后继续推进不会重新生成，没有对称合并造成来源丢失。未产生不能预修。7伤先结算并跳过本步推进，目标8立即成功且不再付压力；最后未完成回合仍结算压力与税。

完整伤势及概率输入复用R21：首次四部位均匀、公平独立骰仍是模型假设；头部轻伤1至3−1技能，重伤4至6下回合三骰且取消技能扣减，中途重伤不拿走已发剩骰，7伤倒下。自由策略每目标91553个缓存状态、每回合固定偏好186823个状态；全部结果约11秒。初次只有粗容量的日志保留为[首次粗容量运行.log](首次粗容量运行.log)，正式结果采用补齐容量变体后的[运行.log](运行.log)与[负担结果.json](负担结果.json)。原生/真人均0。

252个初始手牌条件逐手核对：各自优化目标下，自由不低于开局择最佳简单族；实际运行通过。模型/控制共享转移，不是相互独立证据；末回合检查和冻结隔离重算也不替代独立优化求解。源码哈希、快照与隔离比较见[版本.json](版本.json)、[隔离复核.json](隔离复核.json)、[复现.py](复现.py)。本批仅修改研究脚本，主要风险以实际递推、约束关系、局部证明检查和冻结重算覆盖，不启动未改动Content/引擎的验证流水线。
