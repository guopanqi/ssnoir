# R32：推进生成持续负担

协调者冻结。接续R26“额外进度无害”证明边界与R30纯完成目标限制。研究与参数属于一个新问题，不是给R30增加血量或伤害救题；也不把新目标函数造成的变化归因于单一规则。

## 一个新关系

目标推进到8即时成功。第一次达到/跨过3时产生负担甲，第一次达到/跨过6时产生负担乙；每个负担各需2修复进度，达到2便永久解除。本局最多这两个负担，每个只出现一次。每回合结束每个仍未解除的负担-1冷静，再支付基础-1冷静。推进的额外进度因此可能提前带来之后的行动代价；完成终点则立即解除本次交锋，不再结算压力。

三回合，单人技能1、初始冷静3上限5、无伤、每回合四骰；公平独立d6，首次伤四部位均匀，沿用R21完整伤势（头部轻伤扣1技能、重伤下一回合3骰、7伤失败）。无恢复、无物品、无隐藏信息、无随机增援。推进、修复均用惯用稳险：稳坏-1冷静、中0、好+1对应进度；险坏-1冷静、中-1冷静且+1进度、好+2进度。修复仅对已产生且未解除负担合法，未产生不能预修；同效负担允许证明后对称合并，来源触发旗标必须仍正确。推进/修复全部进度跨回合保留；主动结束合法。伤势溢出先发生，7伤本步失败不可再靠推进成功。

## 两个独立研究目标

A：纯三回合内实际完成，平手先少受伤、成功伤势少、成功冷静多。
B：完成时尚余回合数的期望，即第1/2/3回合完成分别记3/2/1，失败0。它只是明确的研究收益，代表越早完成越好，不是新金币奖励或修改惯用动作数值。平手再比较完成概率、曾伤、成功伤势、成功冷静。必须同时报告完成概率与完成于各回合的概率，不能拿完成率比较B策略的优劣。

两目标分别优化与比较参照。不因B差距增加就声称它更贴近所有玩家；本批只说明选择依赖的目标条件。

## 强反证和停止点

全策略比较至少以下合法强族，族内选择具体骰与稳险仍优化：
1. 只推进，不修复。
2. 有未解除负担则先全部修复，之后推进。
3. 若当前手牌理论最大推进2×剩骰足够完成，则只推进；不足时先修复存在的负担，再推进。容量条件随当前状态重算，但不是调用完整策略选分支。
4. 每回合第一手看公开状态/新骰，选择“整轮只推进”或“整轮有负担优先修”，本轮结果后不改该偏好；下一回合可重选。允许先主动结束；族内用骰最优。最强简单族/逐开局择其中最优作反证。

规则最小且一轮足够：不扫参数、不增加恢复/奖励类别/第三负担救题。若强简单族已解释几乎全部差异，下调为已有模式的组合边界，不新增独立试玩。若仍有值得进一步了解的差异，记录实际可达判断方向及质量，区分规则交互、用骰归属与目标偏好，不只挑尾部例子。正式接入之前仍需协调者裁决；本批先只做数学，不修改Content/native/global。
