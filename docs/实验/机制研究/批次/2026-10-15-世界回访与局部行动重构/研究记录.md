# RETURN：世界层接约是否真正改变再次进入旧交锋的玩法？

日期 2026-10-15；SSNoir长期抽象 Gameplay Pattern Research。继[BRIDGE01—19](../2026-10-15-危机结果跨交锋许可反证/研究记录.md)证明“一次性E/S许可传递，即使两次改道也不是双向回路”之后，本次专门检查更严格的 `L1 → W1 → L2(返回旧局部) → W2`。基于抽象状态和实际可做的动作，不引入正式剧情、游戏工程或新精选。**不把两份Python模型的断言数当成新模式数量。**

## 研究定位及历史去重

- BRIDGE已经有局部危机反馈和下一场需求反馈，却没有世界层**重新改变旧局部交锋**的动作集合。
- [RELAY/PIVOT](../2026-10-15-危机回流与主动失败分支/研究记录.md)已有处理危机兼副产、放弃主目标转替代成果的成熟关系；[HEDGE跨族审计](../2026-10-15-保留选择权跨族审计/研究记录.md)已证明保留旧选择权、等待信号可在有限时间下真的改变策略；[CROSS-SCALE08/09](../2026-10-15-跨期责任与维护税反证/研究记录.md)提示纯跨期维护会退化成固定行动税。
- 本次多出的检验轴是**先接新的世界层工作，再带着合作方的后到状态返回原工作现场进行不同的局部行动，并使结果再次改变世界层选择**。属于成熟 option value / stochastic information / finite-state decision process / encounter composition 的候选组合，不能预设为独立新原语。

## 1. 四个可感知的决策时点

### L1：第一次在旧交锋A行动

选择 `OPEN`（推进/开放合作，风险H概率1/2）或 `GUARD`（安全保护A，不会留下风险，但后续联合修复成功率较低）。随后给出关于最后真实需要A还是B的预测Y，准确率3/4；真正需求W事先各半，并且只有在终局世界层W2时准确公布。

### W1：世界层接不接另一项B工作

看见H和Y，选`ACCEPT`或`DECLINE`。ACCEPT之后，合作方的支援状态K才公开：强/弱各半，和需求W相互独立。合作不是角色自主战略选择模型；K只是外生随机支援强度，不能冒称社交AI。

### L2：世界层选择改变旧交锋的**合法动作**

如果DECLINE，A回来可选：
- `MEND`：保证A最终可兑现，B不可用；
- `KEEP`：不修补，A是否可用取决于原风险。**这一按钮在当前冻结模型被MEND弱支配，是有意保留的无意义候选对照**。

如果ACCEPT，则原来的MEND/KEEP都不再合法，换成：
- `LINK`：联合修复。OPEN且支援强/弱时成功率3/4或1/4；GUARD且强/弱时成功率1/2或1/8。成功则A/B均可兑现；失败B不可用，A只有在原先无风险或GUARD时可保留，并留下不可逆代价2。
- `CUT`：保证B可兑现，但主动放弃A；不产生上述违约成本。
- `ABANDON`：修好A、放弃B，并支付已接约造成的成本2。

这是本批真正的**W→L动作集合变化**：世界层是否接受B，改变返回A时具体能做什么，而不是只给A一份+2奖金。由于K在接受后才可见，返回A时又出现一条新决策信息。

### W2：局部修复结果反过来改变世界结果

返回A的LINK成败已公开，真实W才揭晓。终局只可选一项：可用的A、可用的B、始终合法的ALT或SIDE。兑现符合真实需求的A/B得14，反需求得3；ALT独立得5、SIDE得1，再扣已发生的不可逆违约成本。A、B、ALT保留为**不同结果身份**，不把全部收益理解成同一进度条。

## 2. RETURN01—12：真实完整策略与逐世界求值

[全部规则、强替代、真实世界前向回放](../../../../../tools/content-validator/experiments/pattern_return_world_local_loop_20261015.py) 用Python标准库`Fraction`穷举H、Y、W、K和LINK成败，按逆向最优计算决策，另外直接沿真实世界路径执行并核对收益：

| 冻结制度 | 根最优 | 与完整版差异 |
|---|---:|---|
| 完整OPEN/ GUARD选择、Y、K后到、W真实揭晓 | **1509/128 = 11.7890625** | 基线 |
| 看不到K的强弱，再返回A选择局部动作 | **377/32 = 11.78125** | 仅损失**1/128** |
| 第一阶段没有预测Y | **341/32 = 10.65625** | 预测信息较重要 |
| 最后一阶段未揭晓真需求W | **45/4 = 11.25** | 终局信息有用 |
| W1被迫总是ACCEPT B | **1469/128 = 11.4765625** | 对不合适的危机状态承诺有代价 |
| W1被迫总是DECLINE B | **19/2 = 9.5** | 不合作严重减少结果选项 |
| ACCEPT后仅能LINK，CUT/ABANDON不可选 | **167/16 = 10.4375** | 局部不同方法本身有决策价值 |
| 备用ALT从5提高到8（明确是改奖励） | **25/2 = 12.5** | 充足的普通备选会淡化旧合作 |

**基准初手**：OPEN根1509/128，GUARD根47/4=11.75，差仅5/128；在单一既定收益权重下，GUARD并非根最优。不能把一开始两个按钮同时出现，误称已证明它们都有可取的理由。另一方面，GUARD的最优政策**零违约成本**，而OPEN最优政策期望违约成本5/16；如果有人不可替代地在乎“不让A/B留下承诺破裂”，仅标量多5/128并不足以替其做价值判断。

OPEN之后正常最优的分支：
- 无风险H=0，预测Y=A：ACCEPT，支援高低都LINK；
- 无风险H=0，预测Y=B：ACCEPT，但K弱则CUT、K强则LINK；
- 有风险H=1，预测Y=A：DECLINE后MEND，优先保全A；
- 有风险H=1，预测Y=B：ACCEPT后CUT，主动放弃A保住B。

`H=0,Y=B`发生概率**1/4**，且后到的两种K各发生概率1/8。它在正常最优政策里确实**改变返回旧交锋时所选的行动**，不是静态显示新按钮。若LINK失败而最终转投ALT，发生概率7/128（正常世界前向计算）。最后真实W也能让玩家在A/B/ALT之间择取不同结果。

### 结果身份和承诺的真实分布

上述确定性并列择优规则在真实世界前向模拟（精确枚举，非Monte Carlo）：

| 结果 / 行动身份 | 发生概率或期望 |
|---|---:|
| W1实际接受B | 3/4 |
| 返回A时选择LINK | 3/8 |
| 返回A时选择CUT | 3/8 |
| 最后真正兑现A | 13/32 ≈ 40.63% |
| 最后真正兑现B | 49/128 ≈ 38.28% |
| 最后改做ALT | 27/128 ≈ 21.09% |
| A最终可兑现（不一定被选） | 5/8 |
| B最终可兑现（不一定被选） | 19/32 |
| 已发生的违约成本期望 | 5/16 |

对照GUARD起手：根47/4、违约成本期望0，A/B兑现概率各3/8，ALT1/4。**同分接近也不是所有下游人物/成果都相同**。在这个玩具中没有人类声明偏好，不能拿GUARD无违约成本自动称其道德上较好。

## 3. RETURN-MACRO：完整可用的构造性表示反证

[另一份独立脚本](../../../../../tools/content-validator/experiments/pattern_return_macro_equivalence_20261015.py)穷举如下**11种预先约定的世界层条件计划**：DECLINE后MEND/KEEP两种；ACCEPT后预先指定“若K弱做何事、若K强做何事”的3×3=9种。对每个正常可达的`(L1动作,H,Y)`，逐一计算每种计划的真实期望，与分世界W1选择再回到局部L2临场选动作的Bellman严格对照。

**所有可达信息状态上：最优收益完全相等。** 特别地，`H=0,Y=B`可写成一行`ACCEPT; if K weak CUT else LINK`，不需要复杂算法或必须跨两个UI屏幕才能做对的“高级规划”。当然，玩家仍需**真实看到K**才能执行这条条件计划；可预写不等于新信息无价值。

返回局部交锋之后，将历史压缩为`(A能否兑现,B能否兑现,不可逆成本)`，所有前面实际路径共只需**6类不同的后续结算状态**。脚本枚举全部行动结果，证明同状态不论先前来自OPEN/GUARD、ACCEPT/DECLINE或哪一种LINK反馈，W2在同一真实W时可选成果与收益完全一致。这是普通有限状态的**充分表示**，不是任何有限游戏都不可能创新的泛化证明。

> **结论强度必须区分：**
> 1. 它有真实的L→W→L→W反馈，世界层选择改变再次返回旧交锋的动作；该影响在正概率最优分支中确实被使用。
> 2. K是后到的、有正但仅1/128全局价值的信息，反馈确实改变局部行动，但体验上可能不明显。
> 3. W1决策与L2策略能编译成普通条件菜单；W2只依赖六类终态。并没有构造出无法用有限状态/预先条件政策等价实现的“全新多尺度架构”。
> 4. 任何有限决策游戏都可编码成状态机，所以**状态可压缩本身不是否定玩法价值的理由**。真正未被证明的是玩家是否在这个组合中体验到有意义的、重复的跨层目标关注，而非照一句口诀做数值最佳行动。

## 4. 浏览器与无答案验证等级

另建立独立RETURN四阶段独立HTML（当前会话容器生成附件 `/mnt/data/ssnoir_research/return_trial.html`）作为本会话容器附件，**不属于GitHub提交或Pages已发布页面**。Chromium/Playwright以无提示真实按钮、内部随机风险/支援/修复结果运行了三种完整四步路线，全部成功结算；并用**1600局自动已知规则的短最优政策**随机演练，实得均值11.833125，对照精确11.7890625，差0.04406；实际A/B/ALT分布也接近上述真实世界概率。合成模拟不是1600个真人、不是完整逐随机种子两种语言引擎一致性验证。

三个证据等级严格分开：Python精确模型（数值与规范内核） / Chromium程序冒烟及随机分布（网页实现） / **真人及独立盲Agent反馈尚无**。不能把前两种当成玩家能理解这四层行动的证据。正式Game、已有精选六项、Debug白名单未改动。

## 5. 反证后的下一研究选择

若要将它用作真实作品结构，下一次**不该**再叠加预测层、随从数量或负面时间钟。应先用无答案纸面/浏览器观察让参与者回答：
- 他是否理解`ACCEPT`改变了**回来A时能做什么**，以及“支援强弱”与“最终世界需要哪项成果”是两种不同信息？
- 他会不会在同一局里真实地权衡A的不可逆损失、B的可兑现结果和ALT的安全路线？还是一眼就得到`H1 YA→DECLINE；H1 YB→CUT`口诀，随后完全没有新的关心？
- 对他来说，只有稍高的期望收益是否值得放弃GUARD的零违约结果？需要玩家自己声明关心的结果，不能把研究者的+14/-2口径认作剧情价值。
- 如果移除“返回旧交锋”画面，直接将条件菜单放进世界层，玩家是否觉得实际活动改变？**这才是宏策略等价之外需要体验验证的心理差异。**

如果没有这些体验证据，就将RETURN归档为成熟“跨约束机会×后到支援×交锋返场×条件行为反馈”的组合及严格宏动作压缩负例，不晋升精选。不再线性增加状态与参数。
