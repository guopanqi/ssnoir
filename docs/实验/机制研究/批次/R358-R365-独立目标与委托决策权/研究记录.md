# R358–R365｜决定权给谁：另一个目标不一致的行动者，能否比玩家自己决定得更好？

2026-10-12。首个**改变行动作者而不只是改绑资源的**去情景实验；参考R212资源权利改绑、R342协议及R350他者有固定贡献政策。脚本 `tools/content-validator/experiments/r358_r365_delegation.py`；CI `.github/workflows/ssnoir-r358-r365.yml`。它不是正式SSNoir NPC系统，也没有人的乐趣资料。

## 最小三次决策结构

每次任务有真实隐藏目标θ=A或B，开局公众知道三任务`P(θ=A)=[1/2,3/4,1/2]`。玩家完成自己的目标θ才得1，可以选择：
- **SELF A/B**：自己猜其中一项来执行。执行结束才看见真实θ。没有其他奖励。
- **DELEGATE**：把本次**执行决定权**交给另一个行动者。另一个行动者有自己独立的任务目标φ，事先私下看到φ，**永远选择φ以追求自己的收益1**，并非听从玩家猜测θ。对玩家而言，委托可释放本手注意力额外得1/4，且若φ恰好等于θ也获得本任务的1分。只有委托后才能看到φ与θ是否一致，从而对下一轮继续委托的可靠性更新信念。

两人的任务目标并非总一致：隐藏跨任务稳定关系类型高相关/低相关，各占1/2；前者每次`P(φ=θ)=3/4`，后者仅1/4。玩家**永远不能在本手决定前偷看φ或关系类型**。合作方是独立的目标选择者，但它的目标只有单手，不可夸大为独立生活NPC。

玩家循环：本回合该自己决定，还是让另一方按他的目标行动？看到双方目标相合/相悖以后，我下回合应该继续授权，还是收回控制权？

选择交给对方不等于“多一个被我指挥的骰子”：他实际执行的是φ，且可以与玩家的θ冲突；两者在同一个反事实条件下各有自己的收益函数。不过本三手世界的全部分支很少，没有证明更长周期中存在真正的授权/撤权深度。保留为**值得真人验证的抽象组合候选**，不自动进6精选、20历史候选或Debug。
