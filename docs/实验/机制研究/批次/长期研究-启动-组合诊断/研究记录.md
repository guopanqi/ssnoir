## X01 · 已执行的冻结小实验

**问题**：把“危机打断”和“并行成果取舍”接在一起，是否一定产生真实的重规划，而不仅是额外 FIX 税？

冻结在**Scenario中后段的局部状态**，不伪称这是完整的从开局到结束的Scenario：

- 还可行动2次；当前 A=2/3，B=0/3 或 2/3；完成 A 奖励3、B 奖励4，半成品无奖励。
- 每次行动的机会成本为1/4；玩家可以随时 STOP。
- 正常时 A 动作推进 A 1格，B 动作推进 B 1格。
- 危机时 A 被锁：只能用一手 FIX 解锁 A，或者不理它去做 B。
- 已知状态公开、无随机和叙事。只枚举合法动作序列，精确比较最终奖励减行动成本。
- B 的初始进度视为先前活动造成的不同可进入状态；**本轮没有证明两个状态由同一个完整模型自然到达**。

可复现命令：

```bash
python3 tools/content-validator/experiments/pattern_language_composition_pilot.py
```

本轮已在本地实际运行，脚本所有断言通过；不是 CI、正式引擎或真人试玩。

| 危机 | B 的局部进度 | 最优行动路径 | 最终净值 | “总先修危机再做A”基线 |
|---|---:|---|---:|---:|
| 无 | 0/3 | A → STOP | 2.75 | 2.75 |
| 无 | 2/3 | A→B 或 B→A | 6.50 | 2.75（只追 A 的具体基线） |
| 有 | 0/3 | FIX→A | 2.50 | 2.50 |
| 有 | 2/3 | B→STOP | 3.75 | 2.50 |

反例还显示：如果 B 完成仅奖励2，那么最后一行重新由 FIX→A 最优、净值2.50。**同样的危机与目标图，只有 B 作为有竞争力的另一成果时才出现不同分诊。**

### 此处真正得到什么？

1. **正的组合条件**：危机改变合法行动后，先前在另一目标上的投入可以改变对危机的处理意愿。并行目标不是被动添一根进度条，而可能成为危机中的替代计划。
2. **强阴性边界**：没有活跃的 B 或 B 价值过低时，危机只是一手固定 FIX；不能因为系统同时存在钟、A、B 就宣布出现了重规划。
3. **更强解释**：整个四状态仍由极短的公开口诀解释（危机且 B 临近完成就先拿 B，否则保证 A）。这表明**值得保留的是可组合的条件关系，不是第七个独立原创决策原语**。
4. **证据限制**：此模型确定性、状态手工指定、没有突然出现的危机前的计划，也没有危机中改道后再回来的动态循环。它**没有证明玩家会实际感到自己的计划被打断**；也没有证明这一结构有趣。

**本轮裁决**：X01保留为“有可计算局部实例的已知模式组合”。下一步不是加骰面/做大DP，而是构造具有相同规则、从开局可达 B=0/B=2 和危机不同触发时点的短可玩循环；观察玩家是否主动保留选择权，是否产生可理解的两次判断。要同时比较简单口诀和“不接 B”的消融。

## X02 · 准备与现场的时间窗口（已执行）

**问题**：如果 PREP 只是在开局交一手 ENABLE 税，为什么不能等知道现场情况后再 ENABLE？把准备和现场动作做成**等价可比的时间成本**，测试什么时候出现可复用的两阶段判断。

冻结去情景规则：

- 准备期有一手，可选择 EARN（立即得2点）、PREP_RED 或 PREP_BLUE（没有立刻收益，但赋予对应 SPECIAL 权）。
- 到达现场后才揭示 RED/BLUE 真相；此前可看到 `P(RED)` 预测概率。现场2手，NORMAL每手得1；ENABLE_RED/BLUE花一手获得对应 SPECIAL 权；SPECIAL在真相匹配时一手得4，且一次性。
- 实验组：SPECIAL只有**现场第一手**可使用，代表早到的短窗口。消融组：SPECIAL现场两手都可使用，允许现场先ENABLE后SPECIAL。
- 由研究算法遍历每种准备选择及看到真相后所有合法现场动作序列，计算准备期未知真相时的期望。这里所有结果确定，未知的只是事前状态；不是玩家体验。

可复现命令：

```bash
python3 tools/content-validator/experiments/pattern_language_preparation_pilot.py
```

已在本地执行，所有断言通过。

| 现场早到窗口 | `P(RED)` | EARN期望 | PREP_RED | PREP_BLUE | 最优事前选择 |
|---|---:|---:|---:|---:|---|
| 仅第一手 | 0.5 | 4.0 | 3.5 | 3.5 | EARN |
| 仅第一手 | 0.8 | 4.0 | 4.4 | 2.6 | PREP_RED |
| 可到现场第二手 | 0.5 | 6.0 | 4.5 | 4.5 | EARN→现场ENABLE |
| 可到现场第二手 | 0.8 | 6.0 | 4.8 | 4.2 | EARN→现场ENABLE |

**结论**：只在“机会窗口先于临场购入动作”时，事前 PREP 才可能有净价值；公开预测也会改变是否值得准备。窗口去掉之后，总先EARN、现场知道真相再ENABLE严格优于任何PREP。这给出了“准备保留未来可行动作”的**时序适用条件**，不能把它说成 PREP 本身具有独立玩法价值。

**最强批评**：例子仍可被很短的“预测足够高才准备、否则拿钱”的口诀全解；不知道真相的开局下注是经典概率选择，与[P14探查后不可逆押注](../../结构候选20.md)及[R502的同成本ENABLE](../R502-R509-修复依赖与选项启用同构/研究记录.md)存在关联。此实验没有证明现场的复杂重规划、学习乐趣或有真人验证；它只是确定了**时点不同怎样令两个看似同构的动作不能互换**。

**本轮裁决**：X02从“待模型”更新为“有边界的可执行跨阶段组合证据”，不是独立新原语。下一轮应检查准备与X01同场组合，是否形成比单纯选择概率门槛更复杂但仍可学的决策活动。

## X03 · 情报与目标重估的廉价反证

候选结构：“玩家一开始重视完成 A，中途获得事实后重新考虑 A/B。”需要分清：

- 纯数字版本：信息使A/B完成价值改变，玩家只是根据数字选择收益更高路线。它可以是重要的**信息与目标重新分配**组合，却不自动等同于“剧情/人物意义改变”。
- 目标变更版本：得到事实时，原先承诺是否依旧有效、已经付出的成本会不会改变可选结局、部分成果是否保留、玩家是否拥有真实的拒绝/改约权。这些是不同的结算和行动语义。
- 强反证：如果不知道事实仍可用同一公开口诀获得相同结果，那么信息未产生新的决策活动。仓库 [R526–R533](../R526-R533-隐藏压力因果的零信息价值/研究记录.md) 正是这个负例。

**本轮裁决**：暂时保留已知成熟设计参考与开放机制假设，不用数学优化玩家道德选择，也不自动认证成新模式。

## 自主研究的下一步路线

1. **X01纵向可达性**：补上危机前几手及两个 B 投入状态的自然生成；以更强的公开条件口诀、危机不锁动作、B不存在三组对照反证。模型成立后做无最优提示的短文本试玩；无人反馈可以继续 X02。
2. **X02联合检验**：已完成公平时序对照；尝试使准备改变X01危机后的合法行动，并检查是否只是两个彼此独立的最优口诀相加。
3. **X03跨层分析**：分别制作“新事实只改变数字奖励”与“新事实改变可接受的结算合同/承诺”的两份极短规则，检验是旧信息原语还是出现新的玩家活动。
4. **横向探索仍开启**：Agent可以独立转向他者反馈、跨周期损耗或尚未被地图记录的机制；三张卡片不是固定季度 Roadmap。
5. **低频真人**：只有当需要判断“是否理解/为何会改计划”时提出无解答试玩任务。真人没有反馈时不能写出“玩家喜欢”“体验认证”，但不能因此阻断研究。

## 证据审计

- **确认执行**：X01 的本地 Python 4状态＋低 B 奖励消融；X02 的准备期概率×窗口消融与完整现场动作枚举；两段脚本均已本地通过断言，可独立复现。
- **逻辑与历史对照**：X01/X02 的“是否新模式”判断是结构批评与历史对照；X03只有纸面判断，没有新运行实验。
- **没有执行**：新独立 Agent 盲试玩、C#+Scheme 正式回放、新真人实验和 CI。
- **没有改变**：模式库6、历史候选20、Debug3、正式玩法与原历史试验数据。

研究方式上的变化：**优先保存这类可组合条件与最强反证，而不是把 X01、X02、X03 作为新增精选或往 R 序列上累加三轮。**
