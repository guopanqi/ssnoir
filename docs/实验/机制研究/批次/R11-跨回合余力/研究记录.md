# R11：跨回合余力

2026-10-02，首批已裁决：**留力推进保留试玩；不能宣称已经产生好玩的完整交锋。**本会话研究者独立推进，无其他Agent、自动任务或后台续研。本批已到预先设定的真人反馈停止点。

## 问题与选题推导

R10建议检查：前一回合的结果是否改变下一回合的行动价值。直接组合“路线信息保留+半成品清零”在新回合零进度时有简单长度排序，因此没有制作该组合。R11改查一项现有资源——冷静——能否连接惯用稳险推进与恢复，不新增隐藏信息、敌人或压力钟。

假设：推进和恢复共用同一手骰时，剩余目标、当前冷静、剩余回合与骰子质量共同决定分配；它不能完全由“低骰恢复、高骰推进”“冷静低于固定阈值就恢复”或“每轮先补一次”解释。以这些限制策略和强滚动规划作反证。首批停止点是值得试玩的关系及正式核对，或排除后换方向。

最初登记条件是恢复好档+1、初始冷静5、目标10、三回合；随后发现它对主要目标贡献很小。本批明确追加了恢复强度1/2、起始冷静3/5的边界检查，再冻结正式原型。不是原先就登记过恢复+2，也不能把追加筛选称为独立验证。冻结后新种子检验没有进一步调整正式参数。

## 正式原型

一个目标10，三回合，每回合四骰，进度保留。初始冷静3、上限5；对照只改初始冷静为5。稳做与快做沿用用户给出的结果口径：

| 行动 | 坏 | 中 | 好 |
|---|---|---|---|
| 稳做 | 冷静−1 | 0 | 进度+1 |
| 快做 | 冷静−1 | 冷静−1且进度+1 | 进度+2 |
| 整顿 | 冷静−1 | 0 | 冷静+2，封顶5 |

每个动作投入一颗骰。整顿没有新增资源；满冷静时去掉已被支配的整顿卡。结束回合丢弃剩余骰子、重发四骰，并按引擎规则花1冷静。完成立即结束，第三次结束回合到期。冷静不足仍按游戏受伤、伤势与倒下规则处理。

正式入口为 `研究·留力推进`、`研究·充足余力对照`；唯一执行源为 `Content/scripts/research/跨回合余力.scm`。没有修改引擎、UI、存档或恢复品规则。原型与操作建议见[试玩说明](README.md)。

## 模型目标与适用范围

健康单人起局、技能1、四颗独立均匀d6、不用物品。坏/中/好概率取自正式FateStrip，先最大化“在期限内完成且全过程未受伤”的概率，概率相同时保留更多成功结局冷静。状态为剩余目标、冷静、剩余回合和当前未用骰；不知道未来手牌或判定结果。126种无序四骰手牌保留各自组合权重，缓存续局价值；恢复封顶5，结束回合扣冷静后才进入下一手。

**这是无伤完成模型，不是整个游戏的通关模型。**首次受伤意味着该研究目标已经失败；实际游戏仍允许推进、伤势改变能力、最终完成。正式工具将这类路径标为模型外，并继续使用公开状态策略。没有将首次受伤写成游戏失败，没有模拟全部伤势与长期收益。

平手保留冷静也可能使策略在完成之前多做恢复；本批没有加入“更早完成”的第三目标或虚构外部奖励。玩家是否接受受伤换速度，是下一步需要真实反馈的目标偏好。模型优势不能直接称为实际通关优势。

## 强参照与裁决

同一初始冷静3、目标10、三回合、恢复2的无伤目标：

| 策略 | 无伤完成概率 | 解释 |
|---|---:|---|
| 全状态求解 | 87.39% | 允许三行动、骰序和提前结束回合 |
| 当前回合完整规划，未来先按只推进估计；逐步滚动 | 86.98% | 看当前公开手牌，执行时重新规划，不偷看未来 |
| 固定冷静阈值族的最好结果 | 83.32% | 阈值0至4；最好为0，保留保证终点例外 |
| 每轮开头按冷静阈值用最高骰整顿一次，之后只推进 | 82.12% | 开头阈值1至4的最好结果为3；有保证终点例外 |
| 规划时假设未来冷静回到5，执行仍真实延续 | 83.79% | 错估跨回合资源的策略诊断，不修改游戏 |
| 不用整顿，优化稳险、骰序与换回合 | 74.10% | 强于固定推进套路的消融 |
| 有低骰就用最低骰整顿，否则推进 | 67.37% | 一个故意简单的惯用分配反证 |

固定阈值策略仍优化允许的骰序、稳险与结束回合，不是随便打的弱基准。固定开头策略同样保留这些能力。结果见[强参照](强参照.json)和[固定开局](固定开局.json)。

固定阈值和每轮开头补一次未完全解释关系；“低骰整顿、高骰推进”表现尤其差。恢复同样要通过判定，高骰既可能是可靠进度，也可能是可靠储备。

但强滚动策略只差全局求解0.41个百分点。这更支持**每轮看当前余力与手牌，作清晰的重新分配**；不支持“必须复杂规划未来三回合”的宣传。该滚动参照本身用了回合内求解器，也不能把它称为玩家的一句话规则。

## 回合边界：放弃当前手牌的价值

额外检查不新增动作的已有选择——提前结束回合：

| 条件 | 无伤完成概率 |
|---|---:|
| 不能整顿，强制用完所有骰子再结束回合 | 63.62% |
| 不能整顿，剩骰全≤2、仍有下一轮且冷静够扣1时换回合；其余用完 | 73.26% |
| 不能整顿，自由选择何时结束回合 | 74.10% |
| 可以整顿，强制用完骰子 | 86.16% |
| 可以整顿，自由结束回合 | 87.39% |

低骰可能只带来伤害风险；放弃它们能用一回合和1冷静换一副新手牌。这个关系在没有整顿时已有价值，也基本能被一个简单阈值解释。不能单凭前后约10个百分点差异把它晋升为深度单体。

加入整顿后，剩余骰子还可能用来转换余力，是否丢弃不再只是当前推进价值；用完骰子的损失也明显缩小。恢复与回合边界影响彼此。保留为本原型中的组合关系，没有再创建一份改名同规则的“换手时机”入口。数据见[结束回合约束](结束回合约束.json)、[换手阈值](换手阈值.json)。阈值外的稳险和骰序仍由求解器优化。

## 可达选择与反例的分量

[可达分析](可达分析.json)从正式初始模型沿最优健康策略传播概率，到完成、到期或首次受伤停止。终态总质量为1；完成概率和成功冷静与逆向求解一致。

两种期限均在正常策略轨迹可达的一组例子：还差2进度，冷静1，剩骰1、2、5。仅剩当前回合时，用5快做的续局无伤概率90.28%，先整顿为88.43%；还有下回合时，先整顿97.95%，先推进96.12%。条件只改剩余时间，最佳动作反转。

该配对例子很少见：两种期限状态的到达质量分别约0.293%和0.0112%。它证明固定冷静阈值不是全部解释，**不证明玩家经常遇到这手选择**。更宽的检查中，约34.02%的健康模型起局路径在后续回合至少一次遇到“忽略冷静延续的策略选择会损失超过1个百分点续局无伤概率”的状态。这里是公开策略差异，不是玩家犹豫率。

最优策略至少一次使用整顿的概率92.79%；前三回合使用整顿分别约70.21%、59.54%、30.36%。这些数字含失败判定、平手多保留冷静和终点前补给，不能把高使用率当作策略丰富的证据。严格更好的推进与严格更好的恢复都出现，但体验仍可能是补给流程。

## 边界检查

初始冷静5时，恢复好档+1的全求解约93.97%，不恢复93.50%，主要收益只有0.47个百分点；没有继续把它包装成主候选。恢复好档改为+2、仍封顶5后，初始5全求解95.30%，不恢复93.50%；初始3才出现87.39%对74.10%的较明显差异。

目标8/10/12的邻域在初始冷静5、恢复2下分别得到全求解98.69%/95.30%/87.32%，不恢复98.00%/93.50%/84.39%。初始3的正式条件不声称已经扫完整目标邻域。检查的是储备稀缺性的边界，没有靠扩大进度收益或添加压力状态救题。数据见[初筛](初筛.json)、[恢复邻域](恢复邻域.json)。初筛为早期+1条件；状态计数与耗时不与后期剪枝版本直接比较。

## 本批改进的研究方法

1. **先用约束给策略族上界。**固定冷静阈值策略已允许任意结束回合；再附加一个固定换手阈值只会减少可选动作。因此对应“冷静阈值+换手阈值”组合不能超过83.32%，无需扫描其笛卡尔积。仅适用于这里定义的阈值族与终点例外，不能推广为所有简明策略的上界。
2. **提前去掉被支配动作。**满冷静时整顿不产生储备收益，仍消耗骰子并有坏结果；模型与正式原型都去掉该动作。用手牌等价状态和续局缓存复用计算，不为每个例子重跑会话。
3. **拆开实际结局与研究指标。**模型“首次受伤即无伤目标失败”和正式“受伤仍完成”分栏，避免用保守模型制造通关差距。真人偏好会决定后续目标，而非默认无伤最重要。
4. **反例配对要核对两边可达。**只展示实际策略轨迹中两种期限都有质量的配对，同时明确稀有程度；整体策略偏离另外统计，不能把一个反转当作普遍体验。
5. **强参照决定宣传的范围。**滚动规划已接近全局，裁决降到可学的每轮分配；不因多回合和更多状态就声称长线深度。正式样本只承担实现核对，停止用更多自动局回答真人体验。

## 接续与反馈停止点

R04首批回答：既有冷静延续确实会影响之后的推进行动价值，恢复与换回合也有交互；仍未证实玩家愿意这样玩。下一任务R12接收新原型反馈，先试玩留力推进，再看充足余力对照。需要知道一两手分配变化、整顿是否流程化、是否主动放弃剩骰、是否愿意受伤换速度。

若反馈为持续调整且理由清晰，可保留为适用于低储备状态的基础组合，再研究正式奖励/速度与伤势偏好；若是固定补给或终点前补满，降级恢复关系并检查回合边界的独立呈现；若玩家愿意带伤赶工，先修订目标函数并覆盖伤势后续，不继续沿无伤指标微调数字。信息呈现、成果取舍仍是独立开放方向。

本批无需更多自动对照来决定是否有体验价值。接续者先读本记录及版本，保留已完成验证身份；收到真实反馈再选择下一个便宜的判别。全局接手摘要与队列已更新。
