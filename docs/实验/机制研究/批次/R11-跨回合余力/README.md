# R11 试玩：留力推进

2026-10-02，数学与正式会话核对已完成，尚待本轮真人体验。建议先试玩，再阅读[研究记录](研究记录.md)中的策略分析。

在现有调试面板的“交锋测试（直接进入）”中选择：

1. **研究·留力推进**：先玩这个。进入时冷静设为3，上限5。
2. **研究·充足余力对照**：再作比较。只把初始冷静改为5，其余相同。

从单人、无伤、四项技能均为1的新局进入，先不用烟、酒、药品。入口会设置冷静，不会清除原有伤势。道具没有被脚本禁止；使用后请在反馈中注明，便于判断条件差异。

## 规则

三回合内把一个目标推进到10，完成立即结束。每回合有四颗骰，结束回合时剩余骰子丢弃、重新发骰，同时按现有规则花1冷静。进度和冷静都延续到下一回合；第三次结束回合即到期。

| 行动 | 坏 | 中 | 好 |
|---|---|---|---|
| 稳做 | 冷静−1 | 无变化 | 进度+1 |
| 快做 | 冷静−1 | 冷静−1、进度+1 | 进度+2 |
| 整顿 | 冷静−1 | 无变化 | 冷静+2，上限5 |

每次行动都投入一颗骰。冷静满5时整顿卡暂时不显示；低于5时再出现。你可以主动结束回合，不必把骰子全部用完。

冷静不足照常受伤，受伤后仍可继续。研究原型没有把首次受伤改成游戏失败，也没有新增货币、奖励或压力规则。这里只隔离推进、恢复与换回合的关系。

## 这次需要的反馈

不必逐手抄写；记住一两手具体情况就够了：

- 有没有把本来想用于推进的高骰改投整顿，或反过来？后两回合是否需要重新判断？
- 整顿是一个值得权衡的选择，还是很快形成“冷静低了就补”的固定流程，或者只是临近结束时补满？
- 你是否愿意接受一次受伤来更早完成？有没有主动放弃剩余骰子结束回合？初始冷静5时体验有什么变化？

这些问题用于决定下一步：保留结构、降低为基础关系，或重做研究的目标函数。R10已有的边做边看反馈不会重复索取。

## 原生会话与恢复

```bash
./run --session encounters/研究·留力推进 --seed 2201 --growth 1
./run --session encounters/研究·充足余力对照 --seed 2213 --growth 1
```

以上是交互入口；有物品时按试玩约定自行不用。批内正式工具显式将三类恢复品设为0。
