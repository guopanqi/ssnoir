# R29：信息投资的强反证审查

2026-10-02，已裁决，独立反证审查者。仅本目录有新增文件。R25、R26、共同模型及 Content 只读；没有新原生会话、Content、Unity、真人或代理任务。全局状态与队列由协调者整合。

## 裁决

**保留 R25“用行动提前购买信息”的基本关系，收窄为“一次信息购买＋未定位后的剩余资源分配”。降低把本参数解释成持续探查深度或强动态调查的优先级。**没有发现 R25 偷看、重抽真值或混用规则版本。现有“首手探查后自由”“探查只用最高骰”都允许再次探查；本批补的真正一次限制表明，绝大多数信息收益不需要重复购买。

这也不证明“一次高骰探查永远正确”。最强一次族仍会按初始手牌选择是否买、何时买、用哪颗骰；这些判断由求解器优化，不能把该族称为一条无需判断的玩家口诀。最简单的最高骰首手一次仍有比该族更明显的损失。数学适用边界保留，真人流程感、猜测感与重玩意愿另由试玩决定。

本批按[有界计划](有界审查计划.md)只固定甲乙各3、四骰、冷静5、技能1和2。没有扫目标长度、骰数、先验或阈值。

## 强控制结果

搜索内始终保留最优甲乙选择、稳险选择和资源分配。所有限制都加在探查上，不故意削弱搜索作为参照。中间骰控制允许四骰的两个中间位置择优，优于固定指定其中一枚；“最多一次”在状态中显式保留次数，已经用过后不会把下一手当首次。

| 策略 | 技能1完成 | 比完整低（百分点） | 技能2完成 | 比完整低（百分点） |
|---|---:|---:|---:|---:|
| 完整公开最优（R25） | 83.5167% | 0 | 94.5885% | 0 |
| 不提供探查（R25） | 76.3283% | 7.1885 | 87.6738% | 6.9146 |
| 最多一次探查，时点/用骰自由 | 83.3315% | 0.1852 | 94.4269% | 0.1616 |
| 首手最高骰探查一次，之后只搜 | 82.6823% | 0.8344 | 94.2790% | 0.3095 |
| 首手中间骰择优探查一次，之后只搜 | 78.8904% | 4.6264 | 89.9449% | 4.6436 |
| 首手探查用骰自由，但全局只许一次 | 82.8326% | 0.6841 | 94.2790% | 0.3095 |
| 首手探查；未定位且剩3骰中低骰≤1时再查一次 | 83.1220% | 0.3947 | 94.5274% | 0.0611 |

最后一条固定口诀中“低骰”定义为骰面≤2。首手用骰、允许重复时的用骰仍在该族内择优；不允许第二次后继续探查。重复前余3骰，第二次后余2骰，风险好档理论容量4，足以搜索3。规则预先冻结，没有试几十个阈值后挑最佳者。它是一个小规则加族内优化的强参照，不能称完整人类脚本。

“最多一次”比不探查仍提升技能1 7.0032、技能2 6.7530个百分点，分别保留完整信息增益的 **97.42%/97.66%**。重复信息购买相对于最强一次族的增量上限仅0.1852/0.1616个百分点。这足以支持关系收窄；不等于重复完全无价值。

技能1“最多一次”有约9.80%初始手牌比完整低超过1个百分点，最坏初始手牌差3.0864个百分点（3/3/4/4，质量0.463%）；技能2约8.56%，对应最坏2/2/3/3。这是条件损失，不能只用总完成率把所有局部判断抹去。也不能把这些少数状态当深度或乐趣已证。

中间骰一次显著较差，说明“反正随便拿一枚探查”解释不足；高骰投资与保存足够搜索机会的取舍仍成立。首手最高一次在技能1保存约88.39%的信息增益，技能2约95.52%，已经是很强的简单控制；真正一次族保存更多，仍含资源判断。

历史状态确实重要：相同公开状态“进度0/0、未知、冷静5、剩2/3/4”，最多一次族尚未使用机会时技能1完成50.00%，已使用时46.2963%；技能2分别70.8333%/49.5370%。本批 Float 与 Fraction 都保留累计次数，并前向断言一次族再次探查概率为0。因此没有把“每手都允许首次”误当一次限制。

## 信息真实性与精确复核覆盖

R25 内容脚本在入场时只执行一次 `(random-choice (list '甲 '乙))`，之后定位和搜空只读取已有 `目标位置`；揭示不重抽。正式策略 `state()` 从可见“标注：目标信息”解析位置，未知只得到 None；它用搜索钟、冷静和骰求策略。终局真值只在校准 `check()` 中读取，用于事后核对，不传给执行策略。操作选择的早停只查看 `EncounterResult` 是否存在，不读取未定位真值。

主模型未显式保存未知真值，只在第一次揭示时分成甲/乙各一半；已知以后一直沿同一分支。这在本批是固定真值的等价惰性抽样：

- 先验均匀，未揭晓的坏中好/进度分布与真值独立。
- 未搜满前所有公开历史在两个世界中似然相同，信念持续1/2；好探查或任一处搜满产生完全揭示。
- 两处完成只在正确处立即成功，错误处完成提供另一处确定信息。没有可在定位前旁路读出的真值信号。

R25 的 Fraction 模型确实固定了两个真值世界，按公开观察分组后选择续局，独立实现效果、策略限制和优化。覆盖技能1/2 ×八个策略、126等价初始手牌；免费定位分别核对两世界252手，共 **2268初始条件**，两维“完成概率、成功冷静期望”最大差约1.78e−15。它只共用正式校准的判定输入。

该证明范围是**均匀二元、完全揭示或零信息、真值不影响判定**。`mask` 等权枚举不支持一般带噪后验、非均匀先验、隐变量改变赔率、多个真值或新的观察渠道；改变这些条件时应保存概率权重，不能沿用“未揭晓=1/2”的缓存。126初始手牌覆盖有限模型全部公平手牌，不是引擎种子全集，更不是随机源分布验证。联合独立判定/公平骰与先验仍是模型输入。

本批新增五个控制 ×技能1/2 ×126手，共 **1260初始条件**：Float 复用 R25 转移但添加次数；Fraction 重新实现固定真值、公开观察分组、效果与控制限制，逐手核对两维，最大差 **1.7763568394002505e−15**。前向完成率再与递推吻合。复用转移这部分不是第三份独立引擎证明；Fraction只增加受限策略/历史状态的独立模型复核。

R25 版本列出的16个源文件哈希本批只读重算全匹配，[源版本审计](源版本审计.json)保留明细。本批依赖及脚本身份见[版本](版本.json)。

## R26逐结果支配审查

R26只针对新增的“稳健搜索好档+1进度且立即定位”，其与纯探查使用同一骰、同一档位概率和冷静成本。逐结果耦合足够：坏/中相同，好档二者知道同一固定真值，搜索多1进度。正确处少需搜索，错误处已知后可忽略，原策略有收益的后续操作仍可模拟。完成提早只减少后续负冷静，不损失另一目标或恢复机会。完成概率弱支配，完成概率相同时成功冷静期望也不反转。**当前具体规则下证明成立。**这是弱支配，不保证每个骰/状态严格提高。

复用该证明须同时检查：

1. 替代动作在对应状态合法且耗同样行动资源；信息不只是名字类似，须有同样内容、触发条件、时点和精度。
2. 判定/冷静的联合结果可同骰同结果耦合。只比较边际“揭示概率”相同不足以比较与伤害、结果相关的信息。
3. 额外进度的状态排序单调：不触发漏洞、期限、增援、锁定/承诺、额外税，不删除有收益续局；额外错误处进度可忽略。
4. 自动成功结束不损失其他收益，成功冷静的最优比较不被恢复、带伤收益或“必须经历过程”目标反转。

R25搜索仅搜满才揭示，信息时点不同，第一条关键前提就不成立；本批一次信息收益仍有效。船上推进产生漏洞、前置完成开启期限、搜空会惊动敌人、搜索用另一技能或骰要求、免费调查与付费推进、嘈杂结果提供带噪线索、结束前还可取得别的成果等都应重做比较，不能靠R26宣布调查普遍无价值。“免费副产物”最多是信息行动容易被支配的筛查入口，不是游戏乐趣定理。
