# R29 有界审查计划

2026-10-02，反证审查者，受协调者分配。只写本目录；R25、R26、Content 与全局记忆只读。不新跑原生会话，不添加子代理。

判别问题：R25的提升是否足以保留信息购买基本关系，以及是否应把较宽的“持续探查取舍”收窄为“一次信息购买＋未定位后的资源分配”。先固定R25条件：甲乙各3、开局均匀固定真值、4公平独立骰、技能1和2、冷静5、只看成功及成功冷静。只跑126个等价初始手牌，不改骰数、目标长度、先验或动作效果。

1. 只读审查主模型、精确固定真值模型、正式策略读状态与现有校准证据，列明惰性抽样等价成立条件及后验复核范围；不把18局校准当分布/体验证明。
2. 先冻结五个强控制，全部在合法族内优化搜索路线、稳险和资源，避免人为削弱：
   - 最多一次探查：探查时点与用骰均自由，缓存额外保留累计探查次数。
   - 首手一次最高骰探查，之后只直接搜索，搜索内仍最优。
   - 首手一次中间骰探查：四骰的两个中间位置允许择优，之后只搜索；不预先削弱为固定下中位。
   - 首手一次探查：首手用骰择优，之后只搜索。与R25“首手探查后自由”区别是确实禁止第二次。
   - 容量/低骰口诀：首手探查用骰择优；首次未定位且还剩3骰，其中≤2的骰不超过1枚，再探查一次，此步用骰择优；之后只搜。第二次后仍至少2骰，风险搜索可达最大4，容许搜满3。只查这一条预定口诀，不搜阈值。最高骰首手版可作为同族更具体分解，若需要才列出，不靠扫阈值择优。
3. 复用R25公开转移，为这些控制添加历史状态，不称独立最优证明。对所有新增控制使用独立精确Fraction固定真值公开观察递推，只共用已校准判定输入，逐初始手牌核对两维；另外前向统计完整策略重复探查质量、一次族覆盖信息增益比例、手牌差异及差异是否只来自冷静平手。
4. 审查R26逐结果支配的动作合法性、信息时点、状态单调、自动结束与次目标条件，给出误用边界。

停止点：技能1/2五个控制与有限精确复核完成即可裁决；不扫参数、不用数学反例推翻真人感受。若一次族解释绝大多数收益，收窄R25机制描述与持续判断声称；若差距明确，仍只保留数学适用边界，不宣布好玩已证。
