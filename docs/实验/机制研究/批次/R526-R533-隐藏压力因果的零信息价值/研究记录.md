# R526–R533｜玩家不知道是哪种压力因果，是否就出现了调查玩法？

2026-10-13。R518完成成功触压/失败触压同边际对照，两者最优值不同，但同一句“达到目标即STOP，压力达到上限就VENT，否则GO”全优。下一题不是无意义地再改压力数字，而是一个严厉的机制问题：**把触发方式本身藏起来，玩家是否就有理由探查、学习并改变未来行动？** 如果任何可观察信息不会改变最优决定，所谓未知因果就只是世界设定信息而非真正可玩推断。

## 规则与时点

完全延续[R518去情景机制](../R518-R525-成功与失败的同边际压力/研究记录.md)：6手，GO成功率1/2且成功+1进度，每手有1/2概率加压；VENT减压力1、花一手；STOP兑现，目标3进度值12、否则每份进度2；压力超过2立即-4。**唯一变化**：开局由世界固定地抽一个隐藏因果规则，成功触压/失败触压各1/2，接下来六手不改变。玩家GO完成后仍能看见进度和压力变化，但事先不知是哪种因果。另在对照里允许花一整手INFO直接揭晓因果，不能边查边GO。

精确递推保留隐藏类型及按 GO 反馈形成的后验；不是给代理写一个脚本假装玩家明白了，也不使用真人模拟。

| 编号 | 结果 |
|---|---|
| R526 | 私有因果、正常执行结果可见的完整贝叶斯最优**15/2 = 7.5** |
| R527 | 开局免费**知道真实因果**的两种世界根值平均，仍**15/2**；因果知识在此规则下没有提高最优行动价值 |
| R528 | 不知道触发类型但执行同一公开口诀“p达到3即STOP；d到2即VENT；否则GO”，两种条件下各自全优，先验期望**15/2** |
| R529 | 把INFO放在第一手，消耗整手后按已知规则最优行动，只能得到**187/32 ≈ 5.844**，比直接照常行动低 |
| R530 | 将INFO作为可选动作加入完整最优规划，结果仍**15/2**，开局没有花费这个额外调查动作的必要 |
| R531 | 禁止VENT，隐藏因果下最优**35/8 = 4.375**，压力维护本身确实有价值，但它不需要先识别因果方向 |
| R532 | 普通GO本身直接暴露因果：同时观察到“这次是否成功”和“是否加压”，四种观测组合各对应且只对应一种触发机制，不能将其误称不可能观察 |
| R533 | 压力上限改成3的独立检验：未知因果、事先免费公开因果、同一阈值策略三者均为**33/4 = 8.25**。不是只在危险上限2的一次数值巧合 |

## 设计结论

一个未被玩家知道的规则，不会自动制造“调查/学习”的玩法。即使玩家一手行动之后能够确切判断自己面对的因果类型，如果**知道它也不改变如何合理分配行动**，在数值模型中识别类型的决策价值就是零。R518同边际相关结构的不同美学与反馈语义仍可能被人感到有趣，**不能从这里推断两种模式在人类体验上无差异**；本实验否定的只是“把模式标签藏起来便形成新调查决策”的逻辑。

值得真正继续的版本，必须使玩家了解到哪种因果会改变它下一手确实想做的事，而不是先假设秘密必然有价值。可加入不同可行的行动方法、相互排斥的风险承诺或对未来计划不可逆的改写，但必须与R269主动诊断/P08买信息和强单句策略比较，不能叠复杂数字来逃避本反证。

证据：`tools/content-validator/experiments/r526_r533_hidden_pressure_identity.py`。这不是R37那名真实用户玩过的“隐藏规则”版本，不虚构受试者，也没有正式游戏/Debug变更。
