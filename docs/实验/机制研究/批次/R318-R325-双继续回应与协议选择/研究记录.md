# R318–R325｜对方两个回应都能继续：为什么仍可能只有一条简单策略

2026-10-12，第三条与诊断/空间不邻近的横向研究轴。本批是去情景协议实验，不是假设一个自主AI角色已经部署在SSNoir正式游戏里。脚本 `tools/content-validator/experiments/r318_r325_bilateral_reply.py`，CI `.github/workflows/ssnoir-r318-r325.yml`；共8个检查编号，只研究一套双方回应关系。

## 最小机制卡和知识边界

玩家公开知道自己更偏好结果A或B。另一个主体独立拥有秘密偏好θ∈{A、B、F（两者皆可）}，先验各1/3，玩家**第一次选择时看不到**。玩家先提出协议A或B，主体依照自己偏好行动：喜欢玩家报价则**endorse（支持）**，不喜欢则**counter（提议替代方案）**。注意和R294区别：**支持和反建议都会进入下一手，绝不立刻结束**。

玩家收到真实回应后选 `stick`（坚持原协议）或 `revise`（切换到相反协议）。坚持原协议必须获得支持才有收益；修改协议必须收到反建议才有收益；否则都是0。若成功，最终执行玩家偏好的协议得3，执行另一协议得2。回应确实改变哪一个动作可能产生收益，而不仅是给玩家一份独立的“答案卡”。

玩家反复判断假说：自己第一次应该推荐哪个方向？对方确实表态后是否应坚持、让步，何时违背自己的最初偏好？这与R269条件提问、R294固定涨价一样需要检查强简单规则。

## 八组严格对照

| 编号 | 对照 | 结论 |
|---|---|---|
| R318 | 玩家初始偏好A；对方三类等概率；全部公开响应分支 | 完整最优 **8/3**；若第二步事先固定不看回答，最强 **2** |
| R319 | 玩家自身目标变成B，不改变对方同等分布 | 完整最优 **8/3**；第一手最佳提议随玩家偏好从A翻转到B |
| R320 | 两套独立数学途径：全部2×2×2=8个条件回应协议，及不枚举完整树的阶段性加权Q值最大化 | 完全一致，最终不允许在第一手偷看主体真实θ |
| R321 | 一条最强人类可读口诀：“先提出自己想要的协议；**被支持就坚持，被反建议就修改**” | 已达到 **8/3**、完整最优；回复条件确有价值但不构成长期复杂的谈判思考 |
| R322 | 反建议不再给修订后的可执行协议权利（revise全失效） | 完整/回应盲策略都变成 **2**；**双继续分支是否实质可行动**很重要 |
| R323 | 对方只有A型与B型，不存在F型，各半 | 完整最优 **5/2**，固定最优 **3/2**；不用灵活类型也可有回应条件价值 |
| R324 | F型对方概率从1/3提高到1/2，A/B各1/4 | 完整最优 **11/4**、盲策略 **9/4**；概率变化不是玩法深度证据 |
| R325 | 若对方响应对协议没有任何行动约束，不管对方回应如何，玩家直接选自己偏好结果都得3 | 固定和动态都 **3**，响应信息失去因果；本模型仍是**按两种回应选择动作菜单**，不自动认证成熟独立议价玩法 |

这批比R294有明确新增的**第二个继续分支**：玩家能看到真实不同后果，不能完全预排第二手动作。其数学价值实在存在。但一条“支持就坚持，不支持就修订”的规则便能完全解决，游戏连续体验尚无验证；我们不能把“一个有响应的相对独立NPC”当作机制创新定义。

## 正典与可玩性界限

这里只验证“另一方有独立偏好→两种继续回应→修改执行可行性”。它并未引入隐形关系值/心理记忆，也没有实际人类玩家理解、悬念或故事情感。与R269条件分支、P03信息、R294单一继续分支关系明显。可保留**双向契约关系的基本可解释形式**，待未来研究双方是否能改变各自下一轮承诺、出现多次互相试探时再论独立性。严禁因此往正式游戏增加角色/功能或把它塞进Debug/六精选/20历史候选。
