# DUAL-USE：未完成的A进展能转成B，究竟改变了哪一种决策？

2026-10-18。依据 \`AGENTS.md\`、研究 Skill、权威研究定位、最新 \`main\` 与长期知识地图，复核REC01/02/03、ACTION-MODE/SWITCH、BIL03、HEDGE、STAKE、GOAL、上轮STRESS-CAPACITY。本批只研究去故事化的玩家心理循环，不开发新正式内容，不自动推进精选/历史候选20或Unity Debug。启动时inbox仍仅有R37/R50/R54，questions无新增。研究者本人批评不称为独立盲Agent，无真人或原生体验观察。

## 研究问题和两条竞争假设

**原设想：资源用途改变会不会改变玩家的活动方式？** 不是给一个既有任务加一个更高倍率，而是让先前投在A上的一份未完成进展，稍后既能用于完成A，又能消耗并转化为B的生产材料。玩家需要在后到信息之后亲自决定这份既有投入用于哪里。

**最强无聊解释**：只是制造了一份可交换的库存材料，状态与合法动作都可重命名为普通资源系统；若出现稳定的公开条件口诀、可安全同时准备A/B，则数学优势也不足以说明新型玩家决策。

为避免沿旧REC复制固定ABAB，本批刻意不增加时间长度、更多人物、持续阻塞、骰面变化或十个可转化对象；先锁定四手完整菜单再验证。

## 规则：四手行动与后到需求

- 玩家有四手。每手选 \`BUILD_A\`（A未完成进展+1）、\`BUILD_B\`（B进度+1）、\`SIDE\`（即时获得1）、\`RECYCLE\`（仅当A未完成进展≥1时可选，消耗1 A进展，产生2 B进度）。\`RECYCLE\`是消耗实体旧进展，而非额外免费取得B。
- A需要累计3份未耗掉的进展，B需要2份进展，达到阈值便算该成果已完成；若未完成则不产生终局成果。实际需求W=A/B各半，在第2手行动之后公开，此前不能偷看。
- 完成符合W的成果得12，完成另一项不匹配但实际存在的成果得2；SIDE每份1。总分只是研究时的标量检查，完成A和完成B是不同的物理结果。
- 不限制RECYCLE只能在作者指定的分支触发：从第一手至第四手只要此前确实有A进展，都合法。完整枚举每个状态的合法动作。
- \`COMMON\`是独立对照协议中的同成本安全动作，一手同时给A/B各1份进展。不在基准协议中偷偷使用；如果正式情境确有这类合理动作，就必须与之比较。

## 第一轮：从真实初态是否有严格用途转变？

| 完整协议 | 最优总分 | 真实判断 |
|---|---:|---|
| 基准，W在第二手后公布，可RECYCLE | **27/2=13.5** | 先准备A，后据W变成A成果或B成果 |
| 同规则但禁止RECYCLE | **13** | W=B时不得用旧A进展加速B |
| RECYCLE允许但四手动作必须事前完全固定，不可据W改动 | **9** | 最强固定包含B×2+SIDE×2，不是假定玩家愚蠢地永远做A |
| 需求在第一手后公开 | **27/2** | 第一手A或SIDE保留的行动余裕已够，不再产生新的信息优势 |
| 需求推迟到第三手之后 | **13** | 真正知道W时，只余一手，需先押更多A材料 |
| 四手后才公布W，相当于完全固定 | **9** | 需求太迟，完全失去临场变化 |
| 开放普通COMMON安全联合准备 | **15** | 存在同成本多项目安全路线，动态RECYCLE不再是最优必需 |
| 开放COMMON且限制整个四手固定执行 | **15** | 甚至不用后到信息；固定安全准备足以全解 |

基准最优前两手有两个对称顺序：\`BUILD_A→SIDE\`或\`SIDE→BUILD_A\`。以第一种为例：

- W=A（概率1/2）时后两手\`BUILD_A→BUILD_A\`，A从1格变3格，得匹配A12和已完成SIDE1，总13；
- W=B时\`RECYCLE→SIDE\`，A旧进展1格被消耗，B直接有2格完成匹配B12，另得SIDE，SIDE共2，总14。
- 精确根为(13+14)/2=**27/2**。两个分支都来自正常根策略；不是把人为设计的某个中途背包状态当成测试。
- 禁RECYCLE时，同一前缀W=B需正常\`BUILD_B→BUILD_B\`得到B12加原SIDE1，少了1份后期可做的SIDE，因此基准仅领先**1/2**。不能将「增加了一个RECYCLE按钮」扩大解释成常态玩家需要高阶战略规划。

## 第二轮：真正的“动作语法改变”，还是库存的不同名字？

**全树状态映射**：把(a_progress,b_progress,side)改名为(stock_a,project_b,side)，四行动变成
\`ADD_A_STOCK\` / \`ADD_B_PROGRESS\` / \`SPEND_A_STOCK_FOR_2_B\` / \`SIDE\`。所有当前合法动作、执行后的状态，以及终局A/B阈值在两个记法中**逐状态、逐边、一一相同**。程序从空状态开始逐层检查所有正常可达状态，包括可选COMMON时的完整四手状态，对每条转移及A/B终局数值都作相等断言。

因此该模型中的所谓“改变既有工作的用途”在抽象层完全就是**普通存量的两种用处**。这是强于「最优根值相同」的证据：既不增加新的结果身份，也没有新的信息受众、自主第三人或换挡后的动作规则。

这不表示实体在故事中的用途转换毫无价值。它可以很好地表达“过去投入的工作有了新用处”，只是不应把这种语义自动当成比普通库存更先进的玩法原语。实体物件名称、人物认识与体验层差别不是此同构测试所能否认或证明的。

## 第三轮：阻止虚假复杂度的强替代

1. **公开短策略**：第一手A+SIDE；后来需求A则A+A，需求B则RECYCLE+SIDE。这已经是全树最优；玩家甚至不用理解全部状态统计。
2. **同成本COMMON**：如果存在既能做A又能做B的安全准备，一直可用，固定四手便可以得到15，高于13.5。设计者不能为了保留新的“转换抉择”人为禁掉世界中合理的同时准备。
3. **信息时点而非抽象界面**：第1/2手后得知需求均得13.5，第3手后才知道则13，直到末手完全才知9。因此有意义的是真正**还有多少手数可执行转换**；不是让UI在两个Scenario标签间来回切换。
4. **身份损失**：基准W=B时虽然赢得了B，但A旧进展被实际消费，并没有完成A；若玩家有现实叙事情感去保护A，这与双完成政策绝不等价。研究者给定12/2不能代替真实玩家自己的承诺。

**反例不应过度泛化**：这只证明当前四动作的转换可写成库存语义，不能推断任何一个真实世界的“证据、记忆、资格、关系”都能用可交换库存同构。例如某一份原件不可替代、公开行动会让另一个自主主体改变参加意愿、或转化后改变旧场景合法操作时，必须先明确这些额外规则，再与历史STAKE、GRC/AUDIENCE、RETURN去重，而不是凭“不可同构”就宣布原创。

## 长期知识裁决

**本批保留的模式材料**：后到需求×已有准备的双用途×有代价的用途转换×行动余裕——一个可学、可叙事化的成熟库存转换组合；可以用于用少量卡片表现“原来的工作被拿去救另一件事”。数学证实根正常可达B分支，否定只是作者写在分支旁边的一句说明。

**不保留为独立原语的原因**：完整转移和结算同构可互换库存，最优能由一行条件口诀达到，同价COMMON固定解可强支配；与REC已知双向工序、ACTION-SWITCH固定换挡、STAKE原件守恒、FOCUS/HEDGE窗口已知结构显著重叠。

**后续研究**：优先横向探寻真正不同的动词：转换会不会改变今后可用的合法操作，而不只是把一个库存数字变成另一个库存数字；如果改变了，玩家是否有可见、可学习、正常可达的第二次调整机会？必须对照旧ACTION-SWITCH固定脚本、REC短前瞻、RETURN预写11宏以及真实同成本普通权限资源。没有实际无提示受试者，不假装获得玩法趣味认证；不用新建精选、历史候选、Unity Debug或正式玩法。
