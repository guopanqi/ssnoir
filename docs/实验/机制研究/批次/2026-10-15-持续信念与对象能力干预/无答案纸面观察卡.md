# MEMORY-01—04：无答案纸面观察卡（未实施）

用途：让参与者通过真实选择暴露是否理解“经验学习／能力干预”。这不是数学正确答案测试，更不是已经获得真人反馈的报告。观察者应将此卡与 [研究报告](研究记录.md) 分开发放，不应提前告诉参与者最优策略、收益或预设假说。

## 玩家可见版本 A：反复与同一对象合作

你有四次行动机会。每次可以选择：

- **尝试合作 TRY**：成功获得7，失败损失5。每次都会立即得知成功/失败。
- **安全工作 SAFE**：肯定获得1，不会知道合作对象的更多情况。

这个合作对象的可靠程度可能高，也可能低，各有一半概率。高可靠对象每次成功概率80%；低可靠对象每次成功概率20%。你不知道他是哪种，而且在这四次行动中是同一个对象。每次TRY的结果有随机性，一次失败不必然说明他是低可靠对象。

请逐次记录（主持人根据实际抽取的隐藏类型掷骰，不提前透露身份）：

| 回合 | 本轮可见的历史 | 打算做什么、为什么 | 实际行动 | 结果 | 现在对对象的看法 |
|---|---|---|---|---|---|
| 1 | 无 |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| 4 |  |  |  |  |  |

结束后问开放问题：“你愿意以后继续和同一个对象合作吗？理由是什么？” 不给出任何最优收益或数学规则。

## 玩家可见版本 B：每次都是不同对象

规则、收益、H/L两类可靠率都与A完全一致，但**每个回合都会随机分配一个新的对象**。过去观察到的成功/失败不会揭示下一回合对象的可靠程度。四次行动，使用同样记录表。

建议不同参与者随机分配A、B，而不是让同一个玩家先做A再做B后被教学影响。若在不同组之间比较体验，必须分别报告可理解性、猜测依据和不确定性的描述，不仅比较分数。

## 玩家可见版本 C：可改善对方的能力

八次行动，仍是同一对象。除 TRY(+7/-5)、SAFE(+1) 外，可使用一次 **COACH**，占用当前行动、立即收益0。COACH会把低可靠对象后续每次合作成功概率从20%提高到40%；如果对象原本是高可靠（80%），则不会改变成功概率。对象类型仍然隐藏。

记录是否培训、在第几次行动培训、什么结果让你改变主意、是否想到“偶然失败并不等于能力差”。不应提前提示玩家“先试一次，失败就培训”等答案。

## 观察者单独填写

- 玩家是否把一次失败直接视作类型已确认？
- 两次相互冲突的结果出现后，有没有重新考虑此前判断？
- 玩家是否知道SAFE并不提供新信息？有没有说出“做安全事就是先不认识他”之类自发推理？
- 玩家是否意识到COACH改变的是未来成功率，不只是显示隐藏概率？
- 是否看见为了改善可能很差的对象而主动牺牲一次行动？这是不是他的自主目标，还是为了最大化总收益？
- 是否将对方看作固定概率机器？哪一种人物自主行动会使体验不同？
- 在任何评价中，不得给出“真正最优路径”当成满意度答案。保留原始发言和具体行动历史，不把研究者的分类当成人的反馈。

## 复核材料和边界

研究者先在本地用 `pattern_partner_memory_20261015.py` 和 `pattern_partner_intervention_20261015.py` 检验冻结模型。用户看到的规则版本与数学版的时程必须一一匹配，不要把A/B四回合的数据和C八回合数值直接当相同问题比较。

没有已招募参与者，没有实际试玩次数，没有新的人类认可标记。A/B/C都属于抽象的实验材料；**不是 SSNoir 正式剧情、Unity Debug 关卡或精选模式**。
