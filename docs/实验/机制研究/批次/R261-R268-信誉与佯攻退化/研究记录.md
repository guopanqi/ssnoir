# R261–R268｜公开信誉与佯攻：新动词还是旧的蓄积—消费？

日期2026-10-12。第二条独立研究方向，使用最小去剧情模型，只研究玩家反复选择是否发送真实信号。没有人物、正式游戏代码或人类反馈。脚本 `tools/content-validator/experiments/r261_r268_signal_credibility.py`；工作流 `.github/workflows/ssnoir-r261-r268.yml`。

## 去情景机制卡

每次玩家公开宣告A方向，并决定实际攻击A（H，诚实）还是B（F，佯攻）。守卫按公开的信誉等级c=0/1/2决定多大概率相信并防守A：分别1/2、3/4、1。实际攻击未被守卫挡住则当场得1。H让未来信誉+1，F让未来信誉−1，范围裁到[0,2]。从c=2开始，玩家做5次决定；本规则状态全部公开，**绝不是未知对手心理的模拟**。玩家不断决定的是：现在欺骗赚取立即收益，还是诚实恢复以后欺骗仍有用的信誉。

## 独立穷举与反证

| 编号 | 比较 | 结果 |
|---|---|---|
| R261 | 完整5手有限公开状态DP | **7/2** |
| R262 | 独立枚举全部2⁵=32条完整固定H/F动作序列 | 最强**7/2**，已经与动态DP完全一致 |
| R263 | 完全独立模拟四条可记规则：始终佯攻、交替、信誉见底恢复、每手只看眼前收益 | 最后三条均达**7/2**；始终佯攻只有**13/4** |
| R264 | 如果佯攻从不损失信誉，始终成功的理论对照 | 总收益**5**；揭示信誉限制确实有机会成本 |
| R265 | 如果信号完全不能预测守卫选择，每手永远50/50 | 总收益**5/2**；证明信誉影响当下实际收益 |
| R266 | 每个时间点和公开信誉状态的H/F条件价值完整列出 | 普通公开决策可用一次性穷举复核，没有“不可达信念状态”的秘密优势 |
| R267 | 正常可行方案包含FFHFH以及FHFHF，均达到全局最优 | 确实有消耗信誉与恢复信誉的动作，但不是因为未知对手策略 |
| R268 | 新颖性审查 | **更像P09/P10的储备→消费→恢复循环**，无法证明独立“学习对手/佯攻欺骗”游戏 |

核心反证是**固定序列早已达到最优**，即使真实佯攻和诚实行动都在最优方案中交替出现。把信誉画成“对方怀疑我”不会改变去剧情后玩家实际上管理的是一个公开的生产/消费状态。如果增加对手隐藏性、信誉条或更多动作只是为了躲开这个反证，就违背本研究任务。

因此暂停此版本，不放入精选库或Debug。下一项应横向探索真正不同的玩家活动，而不是调信誉概率。全局收益属于这个数学模型的量化工具，不能当成人类体验评价。
