# R342–R349｜回应改变后续承诺，未来需求出现后还能违约重新行动吗？

2026-10-12。最小公开/隐藏权利协议实验；不是实际AI角色、情感好感条或正式SSNoirScenario。脚本 `tools/content-validator/experiments/r342_r349_renegotiation.py`，CI `.github/workflows/ssnoir-r342-r349.yml`。这8项检查包括一次双轮协议原型及四种消融，不能以回合多为理由自动晋升模式。

## 机制卡：真正出现两次不同的决策

对方有独立秘密偏好θ=A/B/F（F两种都接受，等概率）。玩家先提A或B；对方**支持**与**反建议**都继续下一阶段。若获支持，接受将获得玩家原提议方向的独占执行权并立即得**1/2**；若收到反建议，接受改为对方要求的**相反方向独占权**并得**1**。玩家都可选择**延期/不签**，保留A/B两种权利而无立即收益。

直到再下一阶段，外界实际需求D才公开。θ=A/B时未来需求与此秘密方向相同的概率7/8，θ=F时两种需求各半。玩家没签则能够选需求D得4；签过独占权的玩家若新需求在受限侧，可以选择**违约/重协商**支付2后完成需求得2，也可以遵守原承诺得0。签了对的方向得4。玩家不能在第一提议时看到θ或D，也不能在第二选择时偷看未来D。

心理活动假说：先针对不确定对方提交提议→看对方真实回应→在立即收益与保留以后自由之间选择承诺→新需求公开后再决定守约或付费修改。不同于R318“根据回应执行一次”，多了一次真实的后续合法权利限制与将来的状态更新。
