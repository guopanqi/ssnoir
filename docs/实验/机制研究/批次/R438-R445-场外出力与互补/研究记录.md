# R438–R445｜主体在视线之外行动，会自动形成新的互动玩法吗？

2026-10-13。从[研究定位](../../研究定位与评价.md)出发，先检验最基本的独立性：**玩家不必发命令，对方依旧实际做事**。对照R350固定自主出力、R358授权目标与R430理性否决，不先虚构有完整人格的智能代理。八项冻结纸面计算，代码 `tools/content-validator/experiments/r438_r445_offstage_contribution.py`；无真人数据。

### 去情景规则：看见什么、选择什么、反馈何时到来

4期，每期玩家可做A、B或放弃本期个人工作进行PROBE。另一主体拥有自己隐藏的初始工作取向θ=A/B，各等概率；**无论玩家做什么，它每期仍独立完成其所选A或B**。同一期A/B各完成至少一次，分别计1；重复做相同项只计1，玩家与对方互为补充的资源价值才出现。其实际工作**本期结束后才公开**，不是玩家可以回溯决定的事。该最小体是可控的自主行动脚本，不声称对方具有真正人格、语言或自我规划。

变体 STATIC 对方四期始终做θ。变体 SWITCH 代表简短自身日程：前两期做θ、后两期做另一项；日程规则玩家知道，初始θ不知。PROBE占玩家行动，主体仍工作并给1点，下一期也已能根据产出推断θ。

### 八项检查

| 检查 | 结果 |
|---|---|
| R438 | STATIC最优期望 **15/2 = 7.5**，首期做任一项期望1.5，观察后每期互补得2 |
| R439 | 16条四期固定A/B脚本的**全部**期望都是6 |
| R440 | 简明策略“第一期做A；从第二期按对方前一行动做互补任务”达到完整上界7.5，不需多步复杂策略 |
| R441 | 第一手PROBE只得1，此后完全互补，合计7，低于直接动手后观察的7.5；日常行动已经免费提供识别信息 |
| R442 | 对方报告若比当前再晚一个完整回合，前两期无法利用其偏好，期望降为7 |
| R443 | SWITCH有不同跨期自身日程，最优仍7.5、固定全部6；看出第一手θ便可按公开日程更新互补项 |
| R444 | 对方每期独立重抽偏好，前次报告不再能预测下次，最优退回6 |
| R445 | 仅玩家、仅对方各只能产生4；两行动源协同7.5、数学上限8。大部分直接收益来自多一个行动源、还有一次识别后的互补利用，非新的关系博弈 |

### 结论：独立行动存在，但仍旧被现有基本关系解释

这一模型确实比“对方只等待命令”多了客观的场外行动，也证明玩家必须观察其行动再分配自己的投入。但是**仅一条透明口诀已经全优**；主动PROBE比直接行动更差，相关信息由照常工作免费提供。换成会依自身日程改变任务的主体也未让判断形态更丰富。

归类为 **R350（外源出力）＋资源互补＋信息时点** 的既有组合，尚非独立新玩法，不进入精选或Debug。继续往真实他者推进需要：对方的自主行动不仅透露一个永久类型，还会消耗/建立它自己的真实机会，它会因玩家行为自愿重新规划，而玩家不能仅凭第一次观察永远预测它。不能通过偷偷让它随机改主意伪装为意志。

最强负例：普通工作的正确/错误反馈已经同时承担侦查功能时，单独的“调查对方”动作可能完全被普通劳动支配。数学7.5也绝不是玩家喜爱这种玩法的证据。
