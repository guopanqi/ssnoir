# R46：承诺选择的实时判据

状态：待研究；协调者。接续R45，但不增加游戏规则或改变参数。

R45证明延迟承诺有严格价值，也显示开局专注已保留多数补偿收益。指定最优路径41.74%会延迟、11.10%专注另一条最初推进之外的路线，这与整体增量很小可以同时成立。下一问题不靠新规则扩大差距，而是检查：它是否能由“先赌一手，再按结果决定”的实时判据解释？简单响应达最优不应被误称固定流程；受限目标族仍依赖求解器选骰，也不应被当作完整玩家口诀。

完全复用R45四骰、技能1、冷静5、甲3值1／乙6值2、任一完成立即离开、免费专注关闭另一项并准备+1、惯用稳险及真实公开赔率。R45源码／数学JSON指纹作为输入身份；不重写R45旧证据，不扫描目标／加成参数。目标仍为终局效用，健康和真人体验分开。

先定义可复查的局部判据。专注甲／乙后的终局值可由剩骰独立贡献和的完成概率乘兑现值求得，不需递归自由策略。记两者最大为L。试一手未专注推进：按该骰真实三档概率，计算每档之后立即专注最优的值（若已完成则用立即兑现），加权得Q。若Q>L，试该手并在实际结果出现后重新算一次；否则现在专注。平手优先立即专注，不暗加早完成／冷静次目标。

两种实现：①允许全部合法骰／目标／稳险的一步滚动比较；②只允许“最低骰快做乙”作为试探，其余直接从甲／乙选专注。后者骰／目标维度更可读，仍使用概率比较，不能冒称玩家无需计算。锁定后贡献和不依赖骰序，按固定低骰序执行即可；核对概率多项式与R45锁定子模型相等。

比较自由、开局专注、一次反馈后锁定、两种局部判据的终局值与分布；限定每种策略真正控制的维度。若都近于足够，则保留可解释基础模式，独立原型是否有体验价值仍待真人，不以“简单”直接宣布无趣。若局部判据有显著损失，寻找正常可达首手或配对状态来解释漏掉了什么，不能只报平均差。

停止点：两套明确策略、一个冻结数据版本、一次独立局部／正常前向核对；没有新Content或UI／引擎修改。研究方法的产出是把复杂策略族缩成能展示决策依据的比较，而不是继续累计负结果。尚无运行结果。
