# 目标图变更的因果判别法｜由F1/F2/D2及旧反证提炼

2026-10-13。此页是本批**方法层的归纳**，不是独立新模式、软件规范或第二套研究目标。主结论证据来自[F1/D2](研究记录.md)、[F2](资格变化对照.md)；交叉对照[旧R502同成本ENABLE](../R502-R509-依赖修复与选项启用同构/研究记录.md)、[R526付费信息零价值](../R526-R533-隐藏压力因果的零信息价值/研究记录.md)、[W02三天注意力](../2026-10-13-连续注意力与临时机会/研究记录.md)和[CS2九项设计归纳](../../../../语法的设计研究/Citizen_Sleeper_2_交锋决策模式梳理.md)。

## 为什么分类“串行／并行／替代／额外目标”还不够？

目标图是对象之间的静态关系；玩家真正遇到的是一个**可执行的状态转移系统**：当前知道什么、接下来可以做什么、行动造成什么后果，以及什么会算完成或失败。图上多画一条边未必产生新决策。反过来，两个目标拓扑完全相同，只要一个行动改变了**结算资格**，玩家的判断也可能相反。

我们可以对一个候选组合提出四项最简判断（是设计者检视工具，不是要求引擎生成繁琐数学形式）：

| 变更性质 | 要检查什么 | 这轮证据 |
|---|---|---|
| **A · 可行动作改变** Action Set | 某个历史行动是否让未来新增/失去合法行动？是否只等价于普通同成本ENABLE？ | F1做U打开下一日R，但最强预设日程已取得绝大部分期望；R502有ENABLE同构 |
| **T · 行动后果改变** Transition | 同名动作是否开始损坏另一目标、保留选择权、触发敌方响应或重新解释部分成果？ | D01普通WORK与DECOY标记同一路线且WORK多非负进度时，DECOY冗余；D2 WORK_B触发提早结算时不再冗余 |
| **J · 结束／资格改变** Judgment/Settlement | 完成某目标会否关闭另一目标；旧成果是否仍有兑现资格；是否能主动保留部分成果？ | F2选R撤销B结算权，day3同样可达状态从R改B；D2不允许做B满2后继续做A |
| **O · 信息时点改变** Observation | 玩家何时知道改变发生？揭示时还有什么可改变的合法行动？ | W01/W02早到的机会有条件有价值；R526已可辨别隐藏规则，但额外INFO没用 |

重要：这里的A/T/J/O是一次**检验视角的临时缩写**，不是学界四种官方分类，也不是玩法模式数量。玩家的目标认同、角色关系和感情抉择可能部分来自叙事表达，不需要被数学式完全替代。

## 一个有效的“变化证人”至少长什么样？

- **正常可达**：从一个明示初始状态出发，按公开可执行的行动和外部事件，到达两个需要比较的状态。不能只挑永远不会遇到的调参极值。F1在16条外部日程序列中找到day4同B=4、U出现、R权利有无两条正概率历史；F2在(day3,B=2,R可用,无新U)比较两套合同。
- **独立条件对照**：冻结时间、行动成本、公开信息、其他奖励，只把被讨论的因果边改变。D2仅撤掉B完成自动结束后，DECOY的8对3优势消失；F2仅取消R对B资格的撤销后，同状态改选方向反转。
- **强简单策略**：除了“动态 vs 一条随便写的固定动作”，还需试最强可解释日程／公开条件规则。F1完整159/8对1296套可观察行动存在与否的日程39/2；F2完整69/4对同强基线269/16。这些小优势使“图确实变了”和“值得多轮玩”成为两项不同判断。
- **可体验问题**：首次试玩时玩家是否注意到自己的行动创造了新问题？会不会记得之前的投入或权利损失？有没有不得不犹豫的选择？这最后一项不能由Agent自评/DP替代。

## 六种常见的假进展

1. **加进度条**：目标数多了，最优依旧每轮做最高收益的工作。
2. **加ENABLE前置**：图看似复杂，但全部合法变化等价于花一手启用已知按钮（R502）。
3. **加情报**：知道隐藏规则仍没改变后续决策，买INFO变成行动税（R526）。
4. **加诱饵按钮**：普通推进已经能发同样信号，而且额外进度无害（D01）。
5. **增加数值收益**：增加的总体效用来自多一个可领奖目标，不来自动态重新规划（F1，整体增益3.5但相对强日程仅0.375）。
6. **故意缩小行动容量**：极端临界几乎强制二选一，但换一个正常参数就由稳妥动作支配（Q01、W01）。

这些都是**有用的设计负例**，不是“负面结果因此所有相关模式都不可用”。尤其是F1、F2和D2都有合法、易懂的判断，简单口诀可能反而是优良的教学手段；只有真实体验能决定玩家是否愿意继续。

## 下阶段研究如何不陷入穷举组合？

研究结构不宜随机选若干P编号交叉笛卡尔积。应优先抽取**因果边**：已有模式A的产出是否成为模式B中合法动作/责任/承诺的前提；B的完成会否反过来剥夺A的成果；而不是仅将二者放在同一棋盘。每次选一个最强同构旧例，先想好哪一种消融会令关键选择**确实不存在**。

后续重点是“不只因新任务7分>旧任务6分而转向，而是新目标与玩家过去持有的能力、承诺、已有资料发生不可逆冲突”；然而玩家需要理解的状态应保持极少，不能为了模型灵活而引入难以看见的隐性条件。

**验收边界**：这张判别法只总结本项目少数冻结实例与外部游戏设计归纳，仍需独立场景迁移和真人行为校准。不能称所有Objective Graph的完整形式理论。
