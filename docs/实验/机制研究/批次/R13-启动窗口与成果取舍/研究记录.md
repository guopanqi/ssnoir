# R13：启动窗口与成果取舍

2026-10-02，首批已裁决：**成果取舍与择时开窗保留试玩；无窗口仅作对照。**负责人为本会话研究者；没有其他Agent、自动任务或后台研究。用户选择先积累更多候选再提供反馈，R12留力推进体验继续待补，不作为整个设计空间的阻塞条件。

## 选题与本批界限

R11研究了既有冷静恢复与跨回合分配。本批转向两个不同关系：达到前置阈值主动开启短期责任；容量不足时以完成成果结算，选择是否放弃半成品。这不是继续调冷静恢复参数。

开始时登记了前置3、后续4、三回合，以及单回合成果3/6、价值1/2；比较固定流程、固定目标与开局一次选路。首批停止点为两方向均有明确裁决、至多两份有依据的正式原型及核对；允许全部排除，不为凑模式数量加规则。接入前完成[筛选裁决](筛选裁决.md)，原型参数冻结后才运行正式新种子，未按样本调整正式参数。后续小邻域只用于边界，没有接入更多调参版本。

## 一、成果取舍：放弃半成品，保留可得成果

单回合四骰，小成果3格完成值1，大成果6格完成值2；半成品不计，回合结束统一结算。两项总需9，四骰最多8，因此**正常条件下不可能两项都完成**。这与R07整段完成的“单回合无法同时完成、两回合可能全完成、半成品每回合清零”不同；它明确实现此前队列中“总容量不足、按完成成果结算”的独立基本关系。

行动沿用惯用稳险口径，每次仅投一骰：稳做坏−1冷静、中0、好+1进度；快做坏−1冷静、中−1冷静且+1进度、好+2进度。不增加角色、隐藏信息、过程压力或行动收益尺度。初始冷静5，单手最多四次损失1加一次结束税，严格不会首次受伤，数学模型无需借助无伤失败假设。

目标是最大化明示成果点的期望；平手提高拿到任何成果的概率，再保留结算冷静。成果点不是金币或长期游戏奖励，只在原型结果中返回1/2。若玩家更看重可靠拿1，这也是有效目标；研究者不把期望最优当成玩家必须遵守的攻略。

| 同一规则下的策略 | 期望成果点 | 拿到至少一种成果 |
|---|---:|---:|
| 全程按当前手牌与实际结果调整 | 1.4886 | 90.05% |
| 开局看手牌最优选定一项，之后不换 | 1.3543 | 81.71% |
| 固定争取大成果 | 1.2745 | 63.72% |
| 固定争取小成果 | 0.9881 | 98.81% |

限制策略仍优化每颗骰、稳险与何时结束，不能把差距归因于对照随便打。开局选定用的是初始手牌与完整续局价值，之后只有目标受限；它与全程策略的差距量化了判定结果发生后重新选择目标的价值。

[正常可达分析](可达分析.json)显示，约31.05%的最优模型路径至少一次转目标；每局预期换目标事件0.3508，方向主要是大转小。开局选大质量91.44%、选小8.56%。终局质量为2点58.81%、1点31.24%、0点9.95%；精确前向加权与逆向期望吻合。这是策略行为分布，不是玩家犹豫率，也不是已收集真人数据。

较常见的具体状态：先尝试大成果后，只剩骰5和6，小还差3、大还差5。继续大成果最多4，已经不可能完成；转小可以保证拿1。该状态在最优路径的到达质量约2.16%。这解释的是可见容量下的止损，不是隐藏路线猜测。比较值1对0，不意味着每次换目标都如此明确；小转大也存在，每局事件质量约0.0475。

**裁决**：保留为最小成果取舍模式，尤其值得观察玩家是否愿意舍弃投入。它仍属于目标分配分支；本批另一个时间模式探索不同路径。单回合用于隔离关系，尚不直接承诺完整多回合交锋。

## 二、择时开窗：完成前置会收紧后续选择

三回合内完成前置3与后续4。前置进度保留；前置一完成便开启后续，后续须在**当前回合**完成，否则结束回合即窗口关闭。两段不能并行，前置超出进度不转入后续。初始冷静5、无物品，动作收益与上节相同。

玩家控制开启时点，既可以暂缓前置的最后一格，换新手牌后再开启，也可以在本手条件足够时连续完成。它的关系不是“推进总是越多越好”：跨过前置阈值会移除跨回合等待的选择权。

模型最大化无伤完成概率，平手保留冷静；首次伤势后的继续未建模，真实游戏受伤仍能完成。公开状态只有两段距离、冷静、剩余回合和当前骰子；不知道未来手牌或判定。

| 策略 / 条件 | 无伤完成概率 |
|---|---:|
| 自由选择何时推进、结束回合与开窗 | 88.49% |
| 只在新回合第一手开窗，其余仍完整求解 | 85.80% |
| 强制用完当手，不主动带骰结束回合 | 58.46% |
| 开窗后也能跨回合保留，无窗口对照 | 98.88% |

“不能主动带骰结束”是相关消融，不能拿30个百分点差距单独证明深度。强参照“只在回合第一手开”已解释大部分完成概率，仅差约2.69个百分点，适当定位是**可学的时机基本模式**，不是需要复杂预测的长线规划。无窗口对照更容易，不将两者难度差当作策略价值证据。

增加“开启后余骰的理论最大进度须够后续”的约束，与全求解结果相同：容量不足时开窗被支配。这是支配剪枝；门槛以外仍由完整求解器优化，**不能称为一句容量口诀解决了所有时机选择**。余骰质量阈值也只限制允许开启的动作，其余选择仍优化；数据保留在[首试结果](首试结果.json)。

具体可达状态：前置已经2/3，冷静5，还剩骰2、3，仍有三个回合可用。主动结束的续局无伤完成概率88.54%，最佳继续行动58.57%。若这手完成前置，只剩一骰，最多2，无法完成后续4。这个状态到达质量约6.64%。这里的暂缓是由玩家可读的容量决定。

正常最优模型路径约90.86%至少一次主动带骰结束前置回合；每局预期1.2393次。这个高频行为也提示风险：模式可能被玩家归纳成“存到门槛前，下一轮再开”的流程。直到试玩前，不能排除此解释。到完成/首伤/开窗到期/总期限的终态质量分别约88.49%/2.94%/7.79%/0.78%，前向概率总质量及完成概率与求解匹配。

**裁决**：保留为自行启动期限的基本结构，不直接晋升完整交锋。另接入无窗口对照，只改变后续跨回合保存；不新增恢复、隐藏信息或奖惩来救题。

## 纸面排除与解释范围

同判定同收益下，消耗A的1进度转给B，对比直接推进B没有更好结果、还损失A，被支配；不制作转移版。两个收益相同的动作无代价交替就额外增加进度，只形成固定交替流程，未形成条件性选择。永久确定优惠若目标固定且优惠效果不受已投入影响，可以交换到所有推进之前；该指定最小版本不值得制作。

这里不否定转移、轮换、投资整个分支。新增不确定性、不同目标效用或时限后需另提假设，不顺手加入条件来逃避本批反证。

## 方法改进与接续

本批把“资源容量”“目标函数”“条件变化”提前到筛选阶段：

1. 总容量不足以全拿时，先比较完整求解与看首手后固定目标，隔离**结果出现后**的调整价值；不把开局一次选择包装成持续策略。
2. 同时给出期望与拿到任一成果的概率，显示风险偏好的代价，避免把研究者期望偏好默认成玩家目的。采用一回合冷静容量证明，消除这条方向的伤势模型盲点。
3. 阶段开启先用余骰容量判败，剔除不可能的开启；再用强固定开启时点找流程化。约束对照中仍用求解器的部分明确写出，不冒充人类简单策略。
4. 以少量邻域检查结构如何失效，而非用调参拯救候选：价值相同变成小目标支配；后续增加一格反而强制第一手开启。
5. 前向可达加权复核逆向价值，把转换频率、到达质量与真人犹豫分开。原生只核对冻结后的实现与终止，停止追加样本来回答好玩程度。

下一步可以等用户把新模式与留力推进一起试玩。成果取舍重点问是否会根据结果舍弃投入，还是仅感到失手后的机械补救；开窗重点问是否看见暂缓的理由，还是只学会回合第一手开。若流程化，降为基础关系；若值得保留，再研究如何与其他已解释清楚的关系组合，多回合适配另立假设，不把两个原型直接堆成大题。

若用户继续授权独立探索，不必等待这些反馈：可以研究不同技能/行动者导致的骰子用途差异，或无隐藏真值的可选择信息呈现。先对照固定排序和最强一次分配，保持单一判别问题；不能因为队列有编号就全部并行扫参数。本批状态已更新，长期研究空间仍开放。
