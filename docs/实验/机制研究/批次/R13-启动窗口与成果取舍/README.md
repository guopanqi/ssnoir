# R13 试玩：成果取舍与择时开窗

2026-10-02，两个不同方向的新基本模式，数学与正式会话核对已完成，尚无本批真人反馈。用户选择积累更多候选之后一起试玩；这里不要求现在反馈。

在“交锋测试（直接进入）”里选择，建议顺序：

1. **研究·成果取舍**：单回合，选择完成哪些成果。
2. **研究·择时开窗**：三回合，选择什么时候完成前置、开启下一阶段。
3. **研究·无窗口对照**：择时开窗的对照；后续进度也能跨回合保留。

此前的**研究·留力推进**仍保留，见[R11说明](../R11-跨回合余力/README.md)。可以之后一起试，不必立即把新原型组合成一场大交锋。

从单人无伤、四项技能均为1的新局进入，先不用烟、酒、药品。三个新入口都把冷静设为5；不会清除已有伤势。恢复品未被脚本禁止，若使用请在反馈时注明。

## 共用行动口径

每次投入一颗骰；每回合四骰。稳做：坏−1冷静，中无变化，好+1进度。快做：坏−1冷静，中−1冷静且+1进度，好+2进度。结束回合另花1冷静，未用骰子丢弃。

## 成果取舍

只有一回合。小成果需3进度，完成值1成果点；大成果需6进度，完成值2点。回合结束结算，半成品不计，完成的成果保留。单人四骰最多推进8，无法同时完成需要9格的两项。目标是争取成果；也可以自己决定更看重稳定拿到1，还是争取2。

成果点只是这份研究原型明示的结算值，不发库存奖励。主动结束回合就结算。别因为把某项做了一半，就觉得必须继续；也别把这句话当成总要换目标的攻略。

这一轮在初始冷静5、单人四骰条件下，最多四次行动各损失1，再花一次结束税，因此不会首次受伤。已有伤势、同伴或物品会改变研究条件。

## 择时开窗

三回合内先完成前置3，再完成后续4。前置进度保留；**前置一完成，后续立即开启，而且必须在这一回合结束前完成。**结束回合时后续没做完，窗口就关闭，本次尝试结束。前置多出的进度不会转入后续。

你可以在前置还没完成时主动结束回合，带着已有进度换新手牌。第三次结束回合仍没完成则到期。冷静不足照常受伤，受伤后仍能继续，倒下按游戏处理。

无窗口对照保持相同前置、后续与三回合期限；只取消“后续必须本回合完成”，因此两段进度都能跨回合保留。

## 之后反馈时最有用的东西

记住一两手具体判断即可：成果取舍中，是否因实际结果改目标，换目标像判断还是单纯失败后补救？择时开窗中，是否主动暂缓完成前置，还是很快形成固定开窗流程？两个模式分别是否值得保留，而不只评价完成率。

规则理解、初始条件和道具使用也有帮助。先试玩，再看[研究记录](研究记录.md)中的策略分析，减少提前学套路对体验的影响。
