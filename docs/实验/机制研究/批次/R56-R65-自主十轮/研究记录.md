## 每轮从上一轮学到了什么

### R56 接力奖励

**假设**：R55之后尝试让完成动作产生下一手切线动力。**反证**：在49 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.005248 的期望效用优势。**判断**：固定行动脚本已解释绝大多数收益，奖励易变成一次性流程。**下一步推导**：因为接力太接近开局固定计划，尝试进展本身创造无法忽略的维护负担。
### R57 进展引发维护债

**假设**：推进到阈值时产生独立可修复问题。**反证**：在76 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.031914 的期望效用优势。**判断**：与强固定脚本仍有可测差距，但与既有R37同属进展副作用，创新性不能重复计算。**下一步推导**：把任务成本换成信息成本，检验是否真正出现不同的关系。
### R58 付费获知真实优先级

**假设**：可以耗一行动揭示高价值目标是哪一个。**反证**：在0 / 126 初始手牌上，完全自适应严格优于本批强对照。结果可以完全由所测简单策略解释。**判断**：相对冻结序列的优势很大，但简单的先探查再追揭示目标完全达到自由最优；不是新的高阶动态玩法。**下一步推导**：因此排除只用前置条件决定流程的R59。
### R59 前置解锁

**假设**：必须先推进甲才能开启乙。**反证**：在0 / 126 初始手牌上，完全自适应严格优于本批强对照。结果可以完全由所测简单策略解释。**判断**：强基线与自由完全相等：顺序被规则写死，没有新的条件性选择。**下一步推导**：转向可自由决定时点的储备投资。
### R60 临时储备

**假设**：消耗当前行动储备一次性未来推进。**反证**：在75 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.025883 的期望效用优势。**判断**：相对强参照存在小差距，但局部数值会引导固定先存后花；暂不独立制作正式场景。**下一步推导**：投资仍偏阶段化，改查行动会干扰已有别处进度的持续取舍。
### R61 异线进度衰减

**假设**：推进甲减少乙1进度，反之亦然；成果分别计算。**反证**：在75 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.076051 的期望效用优势。**判断**：十轮中对强开局脚本/简单优先级的剩余差距最大，但衰减可能让玩家只敢专注一路；需审查正常最优路径的改道发生率。**下一步推导**：检验减损是否真的产生逆转，而不是被更聪明的一条专注口诀解释。
### R62 失败防护

**假设**：用一次准备行动吸收接下来坏档损失。**反证**：在60 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.005924 的期望效用优势。**判断**：绝大部分收益被强基线解释，准备很可能变成可计算的开局动作。**下一步推导**：试无额外准备动作时可见的机会位置动态反馈。
### R63 机会反馈

**假设**：每手结果让下一手特定目标获得可见加成。**反证**：在7 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.000061 的期望效用优势。**判断**：几乎到收益上限，最强固定序已接近完整效用；变化虽多、选择意义却极少。**下一步推导**：尝试把选择改成精确匹配而非提供更多奖励。
### R64 精确收尾

**假设**：超过目标值会使积累归零。**反证**：在4 / 126 初始手牌上，完全自适应严格优于本批强对照。结果仅留下 0.000145 的期望效用优势。**判断**：动态收益近乎零，主要是计算当前进度与所需幅度；不用以复杂度自证新模式。**下一步推导**：改探玩家自愿终止的机会成本。
### R65 收益止损

**假设**：随时可放弃剩余机会入袋收益，坏档会丢掉未存成果。**反证**：在0 / 126 初始手牌上，完全自适应严格优于本批强对照。结果可以完全由所测简单策略解释。**判断**：自适应阈值策略完全复制最优，没有独立于简单止损规则的剩余新结构。**下一步推导**：下一批不应再将已能用单阈值概括的结构包装成新发现。

## 十轮之后的判断与研究记忆

R56/R62/R63/R64 动作看上去有规则变化，但固定或响应式口诀几乎解释所有收益，不应靠增加数值复杂度「救题」。R59 的前置解锁只是强制行动顺序。R58 最能说明研究方法为什么需要进化：对冻结目标脚本领先很大，却被「先探查→追揭示对象」一条简单规则**完整解释**，因此不能晋升为独立丰富机制；作为基础关系仍可能有用。

R57与已有R37同属推进的副作用，需审查它是否构成真正不同的抽象关系。R60只留小幅前向研究价值。R61剩余动态差约0.076051为本批最大，但结果不等于真实人类会感到改路、也不等于高乐趣；下一轮 R66 需要对最优路径的真实改路质量做前向审计，并尝试新的可解释简单决策族。R65 在此4骰配置中可被明确止损阈值完整解释，保留为原语不做新模式。

**异步研究原则**：正式试玩可提升某一模式的可信度或改变方向，但 Agent 不因人类尚未反馈就停住。仅当完成当前批次或无明确下一步时存档停止；下一次触发独立读取研究记忆、提出可证伪的新假设继续。R55有独立实验项，人类可按方便的时间试玩；R56–R65 除少数潜力候选外不要求设计者逐项测。
