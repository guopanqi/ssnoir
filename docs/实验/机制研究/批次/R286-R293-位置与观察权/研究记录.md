# R286–R293｜先站在哪、才知道目标在哪：位置选择与后续机动权

日期2026-10-12。与诊断提问不相邻的另一项**抽象玩家决策关系**。这是去名空间控制模型，不是 SSNoir 的城市地图或新引擎功能。实验源码 `tools/content-validator/experiments/r286_r293_spatial_coverage.py`，CI `.github/workflows/ssnoir-r286-r293.yml`。八个编号属于一次空间假说的八项对照/反证，不能认证为八种玩法。

## 最小机制卡

空间共有四个可能事件格0/1/2/3，以及3个可站立观察点L/C/R：L覆盖0、1；C覆盖1、2；R覆盖2、3。玩家初始位于C，5回合内每回合选择原地等待或沿相邻站点移动一步，**移动与观察是同一回合动作**；只能在移动之后看到当轮真实目标并获得当场命中1点，未覆盖则0。目标每轮一定会在4个格子之一出现，它的随机状态遵循公开的Markov规则；初始目标等概率，后续有1/2概率留在原格、概率`q`跳到镜像另一侧、余下概率相邻移动。目标上一回合位置在下一回合公开可见；当前回合**绝不提前泄露**。

玩家实际反复做的是：根据上回合目标推测下一次可能出现哪里，选择一个**能够覆盖可能目标且不会让后续移动太困难**的位置。中央站位覆盖两个中部目标并有左右两侧的即时转移权，不是额外的“目标A/B进度钟”。

R290：最强固定不是挑一条弱路径，而是枚举从中央开始的**全部99条合法五手路径**，每条都用另一个概率传播器不依赖DP前向重放。R291：单看当前预期覆盖量的贪心与更可解释的“目标上次在两侧才向侧边走，否则站中央”的简单追踪法。R292：允许跨越位置距离瞬移的消融；q=0时DP和瞬移**完全相等**，说明该模型下没有实质移动距离成本，不能把收益硬归因于路径限制；q=1/4时允许瞬移才带来145/1024的额外累计覆盖分，路径限制确有因果。R293：结论与同构检验。

最关键的阴性结论是**中央追踪简明法在q=1/4时恰好达到完整DP最优**。这个结构确实有较明显的反馈与空间位置价值，但未创造无法一句话解释的多层策略。q=2/5时中央追踪无法追平DP（320000单位中少32400），但这可能只是高跳跃概率偏好不同，不能用“更难了”证明新的活动形态。

## 玩法意义与终止条件

这个模型与先前R76移动换线、P18路径转换、R54响应对手相邻，却表达的是**在不完全知道下个目标时维护一个有覆盖范围和机动权的位置**。它不是纯资源分配，但它接近传统有限视野下的位置预测/动态布防，不应称游戏机制首次发明。

值得保留的是“先选位置→目标出现→命中/漏失→下一次重新部署”这个小而清楚的活动。退化条件也明确：无非局部跳跃时位移上限没有净影响、而且简单追踪足够好。后续如果继续研究，只能从玩家心理单元/场景可学性深化，**不能再连续扫q来提升最优与贪心的微小数字**。本批没有制作正式场景或真人试玩，保持精选6、历史结构候选20和Debug三项完全不动。
