# SSNoir R108 — 自然线索与专门探查的强简单策略反证

日期：2026-10-12。独立 Python Fraction 纸面计算，非 C# + Scheme 原生，非真人试玩。冻结 R105 四行动模型。

## 问题

R105 发现 K=4、普通工作自然揭示正确地点概率 q=1/4 时，专门探查可产生独立效用。本轮检查这一独立效用是否同时要求玩家进行复杂、难以概括的中途策略规划。

## 规则与对照

四行动，工作 0/1/2 等概率推进，累计3兑现1；K个等先验隐藏地点，探索一处花一手、找到则兑现2、失败排除该地点；专门探查花一手准确定位，仍需再花一手探索；工作以概率q免费定位。两成果兑现后终止。比较全自由最优、直接禁用专门探查、首手强制探查/探索、五类公开可执行的简单策略族。强简单族包含“工作到公开进度阈值或剩余行动阈值，再按剩余地点数决定探查/探索”，扫描进度阈值1–3、剩余行动阈值1–3、地点阈值1–K。简单策略执行时不调用最优值函数。

## 精确结论

- K=4、q=1/4：全自由 133/54；禁用专门探查 121/54；直接消融增量 2/9；最强简单策略同为 133/54，**简单策略剩余增量为零**。
- K=5、q=1/4：全自由 133/54；禁用专门探查 1069/540；增量 29/60；最强简单策略仍为 133/54。
- K=3、q=1/2：全自由 23/9；禁用专门探查 67/27；增量 2/27；最强简单策略同为 23/9。
- K=2 时探查没有独立价值；q=1 时普通工作提供免费可靠线索，探查没有独立价值。
- K=3、q=1/4 的最强简单策略仍有 1/144 差距；K=4、q=0 的差距1/36；K=5、q=0 的差距1/45。这些残差不能自动解释为有趣或复杂。

K=4、q=1/4 的简明最优策略：前两手优先工作；随后如果未定位且候选地点多于3个，并至少还剩2手，则探查，否则直接探索。主线达到进度3后停止工作。

## 正常可达状态的条件反转

根状态（进度0，地点4，未找到，剩4手）：工作价值133/54、探索121/54、探查7/3，工作严格优先。正常最优策略以概率质量1/16到达（进度0，地点4，未找到，剩2手）：工作11/12、探索1、探查2，此时探查严格优先。不同状态下的行动优先级确实反转，但简单口诀已完整解释。

## 语义和边界

已完成成果永久兑现；探索失败永久排除地点；普通工作揭示的地点在同局中固定，不重新抽取；专门探查只提供信息不直接完成探索。新纸面模型不等同正式 P08 Scheme 内容。没有本批 C# + Scheme 原生逐手见证，未取得新的人类试玩反馈。不能将20份源文件或数学证据升级为20个通过研究级门槛的模式；不新增 Debug 场景。
