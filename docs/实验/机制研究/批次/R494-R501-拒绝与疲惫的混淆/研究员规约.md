# 研究员私有｜拒绝与疲惫四手任务（零真人）

执行者不要给参与者看本文件、Python脚本或理论最优。在本场测试里，“人类”只指实际到场、实际逐手作选择的受试者，**不允许Agent代演**。随机在4种(θ,e)组合 (A,0),(A,1),(B,0),(B,1) 中等概率抽取。每局相同θ持续4手，RESTORE令e=1，接受请求当且仅当请求匹配θ且e>0，并把e改为0。拒绝不消耗精力。SELF得1。参与者只得到动作前公开的规则和ASK后ACCEPT/REFUSE，不提前知道隐私状态。

逐手记录：本轮动作、前期参与者预测、实际ACCEPT/REFUSE、得分、研究员私有e变化、参与者原话及其依据。第一次被拒要问“你从这个结果知道了什么、还不知道什么”，不能提示疲惫就是原因。结束时询问他是否认为一个拒绝代表不喜欢、是否知道如何使下一次回应具诊断性，是否愿意重玩。

**只供内部校准的数值**：精确Bayes期望5，最佳256个四手预写不分叉脚本4。透明构造为RESTORE→ASK-A→接受RESTORE、ASK-A / 拒绝ASK-B、SELF，分别6和4，均值5。不可主动教该方案，也不能因参与者没做到而评价其“不会玩”。没有实际参与者，未收集偏好/乐趣结论。
