# 参与者专用｜请求、拒绝与重试（尚未进行真人试玩）

这是只有四次行动的抽象实验，没有故事角色。另一主体有一个稳定、你尚不知道的工作取向A或B；还可能有精力，也可能已经无力。你既不知道取向，也不知道初始精力。两种取向与有力/无力分别等概率。**同一局里取向始终不变**。

每期只能选一件事：ASK-A或ASK-B，请对方完成对应任务；它可能ACCEPT或REFUSE。如果接受，你得3分，对方消耗一份精力；若拒绝得0分。RESTORE：用一手帮对方恢复到有精力，这一手得0分，但不会告诉你其取向。SELF：这一手自己做，可得1分。每次请求后研究员只说接受还是拒绝。局共四手，允许重新考虑下一手；对方不会为了讨好你假装接下自己不想或无力做的任务。

你不需要算最优分数。逐手说出为什么选择当前行动、对上一次拒绝/接受作何解释、下一手是否因此不同。四期后再回看：你是否能区分它“不喜欢这项任务”和“没有力气”？你会不会主动改变测试条件来弄清楚？还愿不愿意再试一局？

参与者不得事先查看同目录`研究员规约.md`或求解器。此卡尚无真人的动作轨迹或评价。
