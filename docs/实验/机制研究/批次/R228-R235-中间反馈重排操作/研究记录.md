# R228–R235｜同一工具库存，中间反馈改变剩余操作顺序

2026-10-12。接续[非交换顺序 R220–R227](../R220-R227-操作次序非交换/研究记录.md)，但研究对象不是“增加一件工具让表达式更难”，而是**已经执行第一步之后，玩家能否根据新观察重新排剩余两步**。不涉及 SSNoir 正式剧情/Unity。脚本 `tools/content-validator/experiments/r228_r235_dynamic_operator_order.py`，验证 `.github/workflows/ssnoir-r228-r235.yml`。

## 去剧情机制卡与知识契约

玩家每局必须把相同的三件工具各用一次：`−1`、`+1`、`×M`。初始结果2。倍增器的真实倍数M在整局开始前已固定为2或3，先验各半；玩家知道分布但**第一手看不到究竟是哪一个**。目标在开始前公开为4或5（各半）。第一手结束后倍数M才被公开，玩家可以据此重新排列剩余两件工具。不能撤回第一个已执行操作，也不能重取库存。若最终结果等于目标，收益1，否则0。

玩家真正反复做的是：**先决定保留哪两种变换的后续排序自由 → 观察真实乘数 → 针对目标重排剩余操作**。此关系在R220仅两个操作、无中间新信息的模型中不存在。

## 八项因果检查

| 编号 | 变化 / 比较 | 结论 |
|---|---|---|
| R228 | 全部可能的首工具、每个M反馈下的两种合法后续顺序 | 目标4可以**必达**；目标5只可**1/2**，初始首工具不同 |
| R229 | 目标公开且M在第一手之后及时公开，可以重新排剩余两件 | 两目标合并的精确成功率 **3/4** |
| R230 | 仍提前知道目标，但M直到全部工具完成后才公开，事先必须固定整套顺序 | **1/2**；真实信息利用增量 **+1/4** |
| R231 | M在第一手之前就已公开 | 仍 **3/4**；提前知道M不再创造额外可能输出 |
| R232 | 目标也等到第一手之后才公布 | 最优只有 **1/2**；首工具无法因目标而调整 |
| R233 | 使用同样三件只含加法、相互可交换的工具（+1/+2/−1），目标仍4或5 | 不论顺序总输出4，只有目标4能命中；消除非交换后“重排”本身失去效用 |
| R234 | 不改变信息时序与判据，换起点3和库存（−1/+2/×M），目标8 | 根据反馈改排列成功率1，事前固定只能1/2；机制条件可迁移至第二个输入与库存 |
| R235 | 明列两种M下全部3!操作序真实输出，并独立枚举首工具+M分支后两步的所有策略 | 不只比较一个作者挑选的“好方案”，完整有限策略空间均已覆盖 |

例子：目标4时，先做`−1`，状态从2变1；若M=2，余下做`+1→×2`得到4；若M=3，则做`×3→+1`得到4。此时玩家不是提前猜对倍数，而是**真正保留了以后重新安排的选项**。若目标是5，最好的首工具则是`+1`，并只在M=2时能用`×2→−1`得到5。这是由**公开目标差异**改变了第一步选择的具体证明。

## 强无聊策略、创新边界

本模型已超越R220“所有操作开局排序一次”，因为即使目标早知，中间公开倍数仍贡献精确成功率1/4。反过来，该模型仍**非常容易被两条公开条件口诀解决**，并未证明玩家在连续多局中仍有新的可玩思考。正常策略是：
1. 目标4：先−1，后视M调余下顺序；
2. 目标5：先+1，只在M=2时有办法命中。

这并不是“数学复杂→游戏更好”的证据，而是**有限库存的后续可重排权**与及时反馈共同造成了一个不同于纯资源容量的活动。与P03/P08信息、R17保留选项、R220非交换操作都是组合关系；尚未验证人类实际会喜欢。裁决：保留**基础组合候选**，暂不增加精选6、历史候选20或Debug3。

下一步不靠再塞第五件工具制造复杂度；先同独立的“学习会变化的对手策略”题比较，避免连续三批仍停留在算术工具排列。同类研究待真人低认知量试玩时可用这两组库存验证玩家是否理解“第一手在保留未来的排序自由”，不提前给解法。
