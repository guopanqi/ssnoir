## 为什么不能只问“同时有几个问题”

几个任务节点同时存在，是一种**目标拓扑描述**；玩家需要反复调整注意力，是一种**决策过程结论**。二者缺少自动推导。仓库已有至少四个不同反例：

1. **ATN01**：A/B都在菜单上，但行动可交换，真实结果只取决于A/B次数；换工作顺序并无意义。
2. **OPEN01/HEDGE**：允许A/B都LIVE不意味着必须并发；直到有首手A机会窗口、旧A仍有可用成果、试B失败可以回A，禁止重叠才严格降低可得收益。移除早窗又有全局先B的串行旁路。
3. **CLOCK**：既使并发暂时有价值，同时LIVE若加速双方deadline，也会让回A的机会消失，允许重叠与禁止重叠在给定原总效用下同根。
4. **FOCUS**：A/B并不是两根自然时钟，实际影响来自**转换方向消耗工作时间**。这可令全做两项的能力消失，从而使晚到需求重要；但允许早期做SIDE、等答案后再工作便使前期切换失去价值。

这四个反例都说明“同一UI上同时有多个计时条”不是心理循环的充分条件。应当追踪**旧投入现在留着做什么、新反馈何时到、另一项工作的出现会改变什么后果**。

## 六层最小诊断，不把数学证据冒充人的体验

| 检查层 | 问题 | 常见错误 |
|---|---|---|
| **目标拓扑** | A/B需双完成、任一完成、还是一个必需一个可选？ | 把所有多节点图称作并发管理 |
| **行动非交换性** | 先A后B和先B后A在合法性、代价、结果上不同吗？ | ATN01计数可交换却假称玩家要规划顺序 |
| **切换与保留成本** | 改方向是否花手、失去旧成果、加速另一项目期限？ | 把同成本SETUP换名就当新操作，或只写“转向有代价”没有机制 |
| **反馈与可用时点** | 新事实在什么手揭晓？当时还剩哪些实际行动？ | 玩家已无法达成另一终局却声称仍可中途改道（RV03） |
| **完成后的余裕** | 既然两个目标仍可达，完成各自后还能拿SIDE、保别的东西或履约吗？ | FOCUS t2/t3/t4两终局仍可达却有20.5/20/19不同余裕 |
| **结果意义与他者意愿** | 玩家真的在乎A或B吗？合作对象实际愿意配合吗？ | 用8/9/12的标量合计代替不可交换的承诺，或将可点按钮当他者同意 |

六层并非新官方术语，而是将历史 **Objective Topology / State Transition System / Decision Structure** 的区分扩充成今后研究时可以复用的具体问题。第三层的本质可落在已知OPS/P14/CLAIM或普通工具SETUP中；第四至第五层是行动时机/容量；第六层需真人体验和真实规则。

## 证据强度严格分层

- **只看DP原总分**只能说当前冻结评价下最佳根值高低。FOCUS主模型动态20.5胜固定15是这种证据；可构造两行全优的公开策略，但不能证明每位真人会照做。
- **可达与最短行动见证**能进一步证实有没有真正可执行的改道余量；FOCUS在t2/t3/t4预置状态时，A/B均能完成，所需行动分别是(1,4)、(3,3)、(2,2)，信息时间改变的是额外余裕。
- **明确成果向量**能解释两个同分策略是否都保住了相同结果；STAKE曾纠正“B旁路使COPY完全无价值”的过强推论，HEDGE也证明同根串行/并行可以产生不同A/B完成概率。
- **逐动作状态同构**才允许把两个机械规则归并为同一操作结构；FOCUS的TO与普通SETUP均使用相同合法行动与状态转换，在89个可达(回合,状态)同构，不会因为名称叫“专注”而变新。
- **玩家感受**必须另看其独立逐手判断、失误、犹豫和是否愿意再玩。仓库现存R37/R50/R54是真实的**不同原型**反馈，不得拿它们替本批补齐体验证据。

## 后续任务该往哪里走

继续改变两个骰面、截止速度或切换成本，大多只会获得更多数值阈值。更有价值的探索是**在单一可读情境中找出玩家自己关心的两个非同质成果**，并观察：
1. 玩家是否会自然为保留未来选项而作前期准备；
2. 他是否意识到先做SIDE等答案有时比早投资更划算；
3. 在消息公布时，他是否真正知道“哪项还来得及、哪项完成后还有余力”；
4. 他是否觉得一项转换操作只是机械税，还是情境中清楚可理解的代价。

这属于待验证问题，已设计[无答案观察卡](无答案观察卡.md)。没有真人前，不把这些问题回答为“玩家已经理解”，也不因模型规模较小而武断否定该成熟组合的可用性。
