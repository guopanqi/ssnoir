# R470–R477｜共同前提的下游成果，发现前提错误后怎样改道？

2026-10-13。延续R454–R461“普通工作一旦自带正确性反馈，另花一次AUDIT无价值”的反证。这里不加入故事角色，尝试另一种操作活动：**先建立多项暂定成果→花行动检验共同前提→依据新事实整体重修或继续投入**。重点检验它与P08买信息、P17污染修理、P19早窗口、R245行动改变知识对象之间是否真正不同。代码 `tools/content-validator/experiments/r470_r477_shared_premise.py`。

## 最小去情景机制

隐藏但全局唯一的前提 θ=A/B，局前等概率固定，玩家不知。4个行动机会。玩家每期选择：
- **MAKE-A / MAKE-B**：制造相应前提之下的暂定成果；第1期有**限时的高产窗口**，一次能做3份，此后三期每次仅1份。没有执行对错反馈。
- **AUDIT**：占一手，揭晓全局θ；已有暂定成果原样保留，不能同手生产。
- **REBASE**：仅在已知θ时合法，占一手，把当前全部不符合θ的暂定成果**整体转换**为匹配的类型，无额外得分、不能同手生产。
- 第4期结束只按匹配真实θ的成果份数计分；错误类型成果得0。AUDIT不可重复。

完整动态策略允许检验后根据θ更改接下来的合法动作；固定脚本必须在开局写满四手，不管AUDIT揭晓什么均按同一动作序列操作（REBASE虽按照已知θ执行，但是否做REBASE不能因反馈改动）。固定方案需要与完整版保持同一动作成本、同一早窗口；不能禁止固定方案修复来制造差异。

## 实际玩家决策、最强无聊基线及裁决

这里同时存在“趁窗口先投”“在不知道真实前提时承担错误累积的风险”“查出错误后是否要花行动改造之前成果”三种不同操作；带早窗口时，AUDIT第一手并非最佳。玩家确实可以在反馈后采取两条不同路线。但最优的四手策略只要一句话：“先做大份、第二手查；正确就继续做，错误就整体重修。”当禁掉第一期高产差异后，则回到先查后做。

因此此例比R454的纯报告可信度更具体地证明了**检验结论会改变未来行动的合法价值与已完成工作的后果**，但尚未超过P08信息＋P17修理＋P19限时机会的已知组合；它是有潜力做短纸面游玩的活动单元，不是可自动晋升的新精选。若再继续，应先问“是否有不同的修复对象/能力，使选择怎样重构下游工作而不只是花1换全体质量”，避免仅增加隐变量或任务数。

全部仅为冻结精确模型与构造性轨迹，无真人、原生Unity或Debug改动。不能用9/2大于4证明玩家感到有趣。
