# R79–R82｜自动探索：等待成本、自然信息与对手追踪的因果验证

2026-10-09。4轮独立有界实验，**全部通过 [GitHub Actions](https://github.com/guopanqi/ssnoir/actions/runs/37946292752)**；R79–R81仍基于 [精确模型](../../../tools/content-validator/experiments/r79_r81_adversarial_rounds.py)，R82单独的 [追击代价消融](../../../tools/content-validator/experiments/r82_pursuit_cost_ablation.py)。每一种是4颗d6、FateStrip成长1、126种有组合权重的无序起始手牌，使用精确有理数计算。不同实验收益定义不同，不比较跨实验绝对值。数学不是原生C#或真人试玩。

## 本批的四个连续问题

### R79 等待信息的真实机会成本

假设与冻结条件：固定4骰、公开迟到线索、选择提前押注、等线索或付行动撤销押注。对等待附加真实损失0/0.5/1，保持掷骰一致。

**反证结果**：waitPenalty0 = {"revokeGainWithWaiting":0,"waitingGainOverForcedEarly":0.890354938}；waitPenalty05 = {"revokeGainWithWaiting":0.485956433,"waitingGainOverForcedEarly":0.392935885}；waitPenalty1 = {"revokeGainWithWaiting":0.878892318,"waitingGainOverForcedEarly":0}。

**当前判断**：有边界的有效关系；保留为可组合基础。**推导记忆**：有撤回权不代表它有价值：必须比较等待的机会成本。撤回效用随公开代价而改变，但不证明玩家实际会撤回或足以做成独立玩法。**后续最便宜的反证**：把等待成本表达为会关闭的实际事件窗口，而不只是终局扣分；做窗口状态可达性证明。

### R80 信息来自普通行动

假设与冻结条件：隐藏真值仅通过正确的信念后验暴露；首个工作行动自然给准确率3/4的线索，独立付费探查每局最多一次。

**反证结果**：none = 2.289847501；paidOnly = 2.579205381；automaticOnly = 2.605423427；automaticWithOptionalPaid = 2.665201823；paidValueWithoutAutomatic = 0.28935788；paidValueWithAutomatic = 0.059778396；strictRootHandsExtraPaidWithAutomatic = 69。

**当前判断**：保留组合研究：显著的信息来源替代性。**推导记忆**：信息由正常工作自然生成后，专门购买信息的价值大幅减小但并未归零；分清信息来源和信息时点，不要禁用显而易见的正常工作来夸大探查。**后续最便宜的反证**：试提高普通行动的成本，检查付费探查剩余严格收益路径，避免使用额外信息动作污染原始场景。

### R81 对手追踪路线初版

假设与冻结条件：4骰、每两行动根据玩家所在位置刷新追踪，带移动动作的直接消融。

**反证结果**：movementGainUnderTracking = 0.226258859；movementGainUnderStationary = 0.226258859；trackingSpecificGain = 0。

**当前判断**：失败，冻结原结果并记录无效因果。**推导记忆**：移动收益与追击反馈完全无关：只是地图有两个车道、移动有用，不能证明对手追踪模式有用。**后续最便宜的反证**：R82给追踪状态设置真实且公开的回合末伤害后果，其他功能保持单独对照。

### R82 追踪改变下一回合的危险位置

假设与冻结条件：4骰，两回合，每回合末敌人攻击此前盯的路径，然后更新下一回合瞄准；隐藏/换位/推进共享骰，对照固定瞄准。

**反证结果**：tracking = 1.835305213；stationary = 1.846968593；movementValueTracking = 0.042995542；movementValueStationary = 0.054658922；opponentEffect = -0.01166338；strictRootHandsAffected = 35。

**当前判断**：有小幅独立反应效应；暂缓原生晋升。**推导记忆**：只有把对手反应连接到真实的可达性/伤害结果，才能证实机制因果；本版有独立但很小的追踪效应，不足以断言好玩。**后续最便宜的反证**：在P18正式Scheme既有原型中控制同一路线和追兵位置，观察‘下回合改盯’改变实际行动选择而不是只改文案。


## 结论及对20候选池的影响

- R79直接回答R78的反例：用户可以等到线索时，撤销承诺原本没有价值；但**等待本身有真实机会成本**后，撤销权可能有独立价值。当前仍只是终局成本模型，不是可玩场景。
- R80把信息来源分为正常工作和付费探查。自然获得准确率3/4的线索，让额外探查从0.28936降到0.05978；仍有69/126起始手牌出现严格正增益，说明专门询问信息没有被完全支配，但其价值比不允许自然信息时小得多。
- R81是明确负例：移动本身对收益的增加为0.226259，无论敌人是否追踪都**完全相等**，证明当前设定中追踪是装饰状态。
- R82针对R81重构追击后果：追踪比固定瞄准使期望结果降低0.011663；35/126初始手牌根值因此变化。只是证明追踪产生后果，尚未有“公开状态引起自愿改路”的原生轨迹或人的评价。

**不自动晋升**：20个 [结构候选](../../结构候选20.json) 与独立的 [Debug白名单](../../../../UnityClient/Assets/Resources/DebugResearchPlaytests.json) 均不变。前者是不同且具来源的潜力池，而不是20个已证明好玩；后者只允许3个人工明确邀请的研究原型。
