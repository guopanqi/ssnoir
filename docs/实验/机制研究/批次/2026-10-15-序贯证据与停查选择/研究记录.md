# EVIDENCE-STOP01｜连续证据、何时停查与安全退出

2026-10-15。接续 INFO-PROD01，检验一次调查即完美知道真相的结构是否可以替换为「不断获得有噪声的新证据，随时结束搜集、冒险判断或安全退出」。先复核已有 TRL 生产性试做、INFO-WINDOW 限期信息、SIG 策略性伪装。**本批研究的是纯统计抽样，不声称属于新原创机制**。

## 冻结规则

未知事实 T=A/B，先验各半。每次 SAMPLE 花玩家确定效用成本1，独立产生一个对真实 T 正确率3/4的 A/B 信号。最多调查3次。玩家可在任何时刻直接 CLAIM 选A或B，判断正确+10，判断错误−6；或 SAFE 退出直接得3。CLAIM/SAFE立即结束。所有规则和信号质量公开，样本彼此条件独立，无对方策略性伪装，无剧情进度。

这是经典有限时域序贯信息决策，与早前「工作进度与信息合一」**不同协议**，不能比较其根分数证明新系统更好。

## 第一轮：策略应当由证据形态决定，而不只是调查次数

[精确Fraction递推和固定N对照](../../../../../tools/content-validator/experiments/pattern_sequential_evidence_20261015.py)用后验p=3^a/(3^a+3^b)（a/b为观察到的两种信号数量）求条件期望。根最大值41/8=**5.125**。

- 第一次观察A后，后验P(T=A)=3/4，仍有2次抽样机会。当前直接CLAIM的价值6，但最优SAMPLE的续值为49/8=6.125。
- 两次观察均为A，后验为9/10、直接CLAIM值42/5=8.4，最后一次抽样并不能严格改善，**停止调查，直接下注A**。
- 前两次观察A/B矛盾，后验返回1/2。CLAIM仅2，SAFE3；剩余一次调查使净期望达到**5**，所以**继续调查**。

这是正常行动树中真实的相反决定：同样已查两次，证据一致应停，证据冲突继续。注意这只是一道成熟的 sequential sampling / optimal stopping 问题，并不是此前没有的玩法原语。

## 第二轮：最强固定次数基线

固定必须查 N=0,1,2,3 次，最后可选CLAIM或SAFE（不能强迫在无信息时猜测），得到：

| 固定样本数N | 最优期望效用 |
|---:|---:|
| 0 | 3 |
| 1 | 5 |
| 2 | 35/8 = 4.375 |
| 3 | 9/2 = 4.5 |
| 可观察证据后随时停查 | **41/8 = 5.125** |

灵活策略只比最强固定策略5高1/8。证明存在正向差异，但**优势很小且容易被简单条件口诀解释**。最初一版固定N计算忘记允许最终SAFE，导致N=2的对照偏低；已经在本地执行时纠正并把修正后的断言提交，不能把旧误差当研究结果。

## 第三轮：样本成本与强安全选项

保持全部条件和信号准确率不变，只审查获取证据的真实成本对停查政策的作用：
- SAMPLE成本0：灵活根15/2=7.5。
- SAMPLE成本1/4：灵活根221/32=6.90625。
- SAMPLE成本1：灵活根41/8=5.125。
- SAMPLE成本2：灵活根4，第一次抽样后直接CLAIM已成为最优，应停止继续检查。

这里改变成本是为了检验停止现象对费用的依赖，不以调参幅度证明好玩。最强无聊路径在高成本时立即成立；零成本则可能连续收集，玩法回到资源上限。

## 同构反证和证据身份

玩家实际重复作出的判断是「当前信念够确定吗？剩余调查能否提升判断？还有更安全的退出吗？」这与数学上的**序贯概率比检验/有限视野最优停止**属于成熟结构；相比 INFO-PROD01 的一次完美调查，确实出现了多次可改变计划的证据反馈，但没有出现新基础原语。

未加入生产性调查，不给每个SAMPLE无理由加+1工作，也没有把独立信号冒充可以伪装的人的真实行为。若将其叠合工作进度与截止，下一批必须先审强SAFE、成本同构和是否有稳定开局查完的短路。新数据均为单一Fraction DP+固定次数穷举，没有独立盲Agent、人类或原生试玩，也没有接入正式Debug和精选。
