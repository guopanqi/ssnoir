# 两次相遇的策略性伪装，与玩家自选不可补偿成果

2026-10-14。恢复 main 8126e82a951b402d20ecd4c289e6d4ca0ba625fe；研究只涉及[抽象决策模式定位](../../研究定位与评价.md)及可复现实验，不开发正式游戏功能。复查[上一批 VOL01/ADV01](../2026-10-14-自选承诺与对抗性注意力/研究记录.md)、[CROSS01](../2026-10-14-目标改变与跨交锋凭据/研究记录.md)、GRC/NEG 策略性拒绝/可信证据和 P16/INF-P01。开始时研究反馈 inbox 仍只有历史 R37/R50/R54，questions 为空。本批无新真人、独立 Agent 盲测、Unity/Scheme 原生游戏证据；数学/离线 HTML 冒烟只能验证所冻结规则，不证明体验。

**两条不相邻的活动：**（一）玩家先观察另一个有自身利益的主体一次行动，然后选择第二次防护；这个行动是否真的携带稳定偏好信息？（二）玩家主动声明哪种不可补偿结果值得保住，在同样的四手规则和强安全工具出现后，其后续操作是否有可理解的不同？不把两套不同协议的分数直接比较。

可复现：[标准库 Fraction 精确脚本](../../../../../tools/content-validator/experiments/pattern_strategic_signal_against_voluntary_goals_20261014.py)；[独立 HTML 无答案试玩](试玩.html)；[Node 离线三条轨迹回归](../../../../../tools/content-validator/experiments/test_stake_observer_20261014.js)。后者不代表一个真人打开过页面。

## SIG01：同一对手连续出现，第一次行动竟可以零信息

### 完整冻结协议和可读循环

另一个行动者拥有稳定的私人类型 T=A/B，先验各半；两次相遇，其行为会影响玩家下一次防护。第一次公开选择对A或B采取行动；若选择自己真正偏好的目标，行动者即时得到自身效用 r，反之得0。**第一次行动的这一收益是对手自己的效用，不计入本次玩家第二阶段受损量**。本模型只比较第二阶段防护的效果，不能把改动 r 后的总福利冒充同规则下的玩家收益变化。

玩家观察到第一次指向的 A/B 后，第二次必须选择保护A或保护B之一。敌手在第二次还能根据自己的利益自由选择攻击A、攻击B或EXIT。打自己偏好的目标收益8，打另一目标收益1；保护某个目标使袭击该目标的收益减少5（按真实效用计算），EXIT得0。无论防护哪边，敌手在第二次都**严格自利地攻击自己偏好的目标**：保护偏好目标后还能取得3，大于打另一侧1；不保护偏好目标则得8。玩家的第二阶段损失等于实际得到的袭击效用，目标是降低损失。

**关键前提：敌手第一次就知道玩家会根据这次公开行动选择下次防护。** 因此不能将第一次“攻A”当作固定准确的喜好证明；敌手会提前考虑伪装来诱使玩家保护错误目标。

### 计算一个可核验的混合序贯均衡（不宣称唯一）

令第一次打自己真正偏好目标的即时自利收益 r=1。考虑双方公开知道的一类对称行为：每种敌手私人类型都以1/2概率第一次选择A、1/2选择B；玩家见首次公开选择s后，以概率 q 保护s，另有1−q保护相反目标。

- A/B第一次公开动作与真实私人类型**独立**：任一动作出现后，用贝叶斯规则更新得到后验仍为 P(T=A)=P(T=B)=1/2。观察本身没有区分力。
- 若敌手第一次诚实选择自己偏好目标，它未来有 q 概率遇到自己的目标受保护，总预期收益为 1+8−5q。
- 若敌手第一次伪装选择另一目标，它未来有 1−q 概率自己的目标受保护，总预期收益为 0+8−5(1−q)。
- 两种行动都合法且对它同样好时：1+8−5q=8−5(1−q)，解出 **q=3/5**。
- 玩家后验始终1/2，保护A还是保护B对预期第二次损失都为 (3+8)/2=**11/2=5.5**，所以这份混合防护在玩家侧也是最优回应。敌手阶段二攻击真实偏好是**严格**最优，第一阶段两条选择在该公开防护回应下无差异而可等概率混合。代码逐类型、逐信号、逐阶段核对了偏离收益和后验。

这是一份数学上的**对称混合均衡存在性证据**，不是证明全部均衡唯一、真实NPC一定混合或玩家已经体验到有趣的推理。尤其不能声称“只要对方有真实偏好，观察一次必能学会”。这里存在明确正反信息边界：**行动可见，但生成行动的激励本身会因玩家未来回应而改变。**

### 最强无聊/错误解释及完整对照

| 冻结信息与行为制度 | 玩家第二阶段损失/总成本 | 不能偷换的解释 |
|---|---:|---|
| r=1且采用上述对称混合均衡，玩家只见第一次公开动作 | **11/2=5.5** | 观察不改变对私人类型的后验 |
| 玩家天真地永远“保护第一次被攻击的那个” | **8** | 这种防护规则使敌手**严格更想伪装**，第一次反向报出另一目标；这不是双方理性均衡 |
| r=6（敌手第一次真实目标产生较高即时自利收益），玩家观察后保护首次目标 | **3** | 真诚第一行动收益6+3=9，伪装只有8，故分离可信；**改变了对手自身效用协议**，不能把不同r下玩家损失下降冒充零成本新增信息 |
| 另有真实、不可伪造、及时的私人类型检验，检验占玩家成本1 | **4**（损失3+费用1） | 在原 r=1 协议里确有信息价值，净比5.5好1.5 |
| 同一真实检验直到防护决定之后才到，仍花成本1 | **13/2=6.5** | 无补救动作可用时迟到证据没有决策价值，还浪费一份成本 |
| 另有同成本制度下假定可用的万能盾，付玩家成本3即可阻挡两目标全部损失 | **3** | 简单完整保护**支配**调查后精准防护4；它是强基线，不是主协议本来拥有的动作 |

为核对“诚实分离”的因果边界，完整求解 r=1、3、4、6 的两个类型针对真实/伪装的收益差，严格为 r−5。r=5仅弱等价而不能宣传稳健诚实；r>5才给出每一类型选择真实首次目标的严格动机。没有为其他均衡或不同于本冻结协议的心理学习作唯一性/通用性推断。

**分类**：成熟的策略性信息揭示 / signaling game × Bayesian belief update × 后续行动的防护价值；参考既有NEG03“策略性拒绝并不透露私人报价”、NEG04真正可信证明、GRC信息改变他者参加行为、EP02沉默携带可推断信号。**本轮新增证据是此前 ADV01 留下的开放问题的严格反证**：即使同一人有稳定真实偏好、出场两次，第一次可观察行动仍可能因预料到玩家防护而零信息。研究不能把“动态二次出场”机械等同“正在学习人物”。

## VOL02：提供真正可玩但未获真人证据的个人结果选择

这部分故意**不修改 CROSS01 的任何原生规则**。参与者先说明自己在乎A、B、A+B、完整解决C，或愿意依据局面决定，然后在两段各2行动的完整公开规则下操作：

- A/B工作量各到2分别得到独立结果A6/B5；SIDE每手+1。
- 第二阶段前才等概率公开需要A/B哪种类型的凭证。
- 第二阶段仍可继续WORK、SIDE；两手DIRECT可取得部分处理C6，符合类型且做满A/B后可花一手SUBMIT取得完整C10。
- 独立强替代版本提供一手SAFE，无需凭证得到完整C10。A/B与C是否值得互换，**先由参与者自行写出意向**，而不是预设自己喜欢15.5。

本批重新从原初态穷举所有9种前两手、两个公开需求的全部合法后两手以及相应终局，在**原综合收益不改**的前提下，将不同的结果承诺视为“每种需求历史都合法达成”的硬约束。这只检验在该承诺之下还有什么可行政策，不把数学证据冒充玩家确实选择了该承诺。

| 自行可能声明的结果关切 | 无万能SAFE：综合期望 / 首期路线 | 带一手万能SAFE：综合期望 / 首期路线 |
|---|---|---|
| FLEX，不固定关切 | **31/2=15.5 / AB** | **17 / AA** |
| 无论公开需求如何都要保A | **29/2=14.5 / AA** | **17 / AA** |
| 始终保B | **27/2=13.5 / BB** | **16 / BB** |
| 必须同时完成A与B | **11 / AABB四手完工** | **11 / AABB四手完工** |
| 必须完整解决C | **31/2=15.5 / AB** | **17 / AA** |

这里的数值全部使用既有模型，一项规则输入都没有因“用户说了我在乎A”而改。此前VOL01集合包含结论依然成立：在相同目标函数下，一个私下自愿的行动自缚只能删菜单，不会带来新的外部资源或让另一个人自行帮助。**正面研究目标并非设计一条新承诺buff**，而是弄明白面对不同合法但互相冲突的结果时，参与者是否自然形成不同的关注、牺牲与后续选择。即便简单AABB做完两项永远有11，也无法在4手同时兼得完整C；增加一手SAFE仍无办法同时保证A、B、完整C。

### 真正建立了哪一份体验工具？

[独立四手自选成果网页](试玩.html)是一个干净的自包含HTML：先选择想保住的结果并写理由；在不见未来A/B要求情况下投2手；需求公布后再投2手；最后显示真实得到的A/B/C、原综合分数、是否达成自己先前声明的目标。可从一局复制原始行动、理由和回顾文字。提供普通/万能SAFE两个冻结协议。它**不上传反馈**，不自行宣布哪条策略正确，不进入正式游戏 Debug。

[Node 离线冒烟](../../../../../tools/content-validator/experiments/test_stake_observer_20261014.js)使用真实页面内联逻辑和简化DOM做三条完整路径：A需求时A/B准备→补A→匹配提交得16；B需求的SAFE版先AA→SAFE→SIDE得17；先SIDE/SIDE再DIRECT×2仅得到部分C，未达到玩家选择的完整C目标。**这仅是软件行为验证，不是浏览器端排版、Pages发布、真人游玩或个人偏好证据。**

因此不能从该网页推出“玩家会自发关心A”；真要检验仍需不看最优策略的独立人类参与，把他首先选择的优先级、是否中途改主意、对不同结果的原因留在真实反馈原件中。普通最优数值不能反驳人为A作出的不可补偿承诺，也不能代替观察。

## 作者独立设计批评与下一阶段问题

1. SIG01可能只是一道经典有限信号博弈计算题。好处是纠正“敌手两次出现就能学到偏好”的误解，但玩家无需会贝叶斯公式。若交互仅显示某人攻击了什么而无足够可信的激励解释，人会误读为随机坏人或不可解释反转。强调查和万能盾可能完全支配所有伪装推理；只有成本、窗口、人物追求都真正成立，才值得作为可玩情景。
2. SIG01仅证明**一个**对称混合序贯均衡存在，不能靠作者挑选均衡伪装成通用唯一预测。r=6的分离来自不同私人即时收益，不是单纯“人变诚实”。报告第二阶段玩家受损值故意不计入敌手第一阶段自身奖励，不能比较两个协议的绝对总福利。
3. VOL02网页能复核真实行动可达性，不能从一张很像问卷的目标选择推断真实情感关切；玩家可能只是从下拉框随便挑一项。后续必须让他用自己的语言解释优先级或离开预设选项，并在具体故事中验证。数学上的“必须保A”约束与玩家真正自愿想保A仍有证据鸿沟。
4. 跨族不能硬拼成更大的抽象项目：自利对手的信号博弈和玩家自选成果是两个不同的心理单元。前者在本次实验中最强反证**信息可以存在却没有信息价值**；后者最强成果是可操作的独立观察工具，尚未得到体验数据。两项均暂归成熟模式语言组合/反证，不晋升精选/Debug，也不夸口玩过。

**后续优先级**：用真正可验证但有成本的信息机会探索“收到正确消息后，还有没有行动窗口兑现？”并继续测试对手能否策略性影响何时显示真实证据；另一方向则应让人体验具体结果为什么不可替代，而不是继续扫描A/B数值。已经有一个可试玩入口，不要持续堆未经使用的HTML原型；没有人的证据时继续跨族反证，明确区分数学、软件冒烟与真人体验。
