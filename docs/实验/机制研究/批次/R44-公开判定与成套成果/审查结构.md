# R44独立结构审查

2026-10-03；已完成。审查者：`r44_bundle_review`；写入仅本批`审查*`文件。独立脚本未读取或导入协调者模型、策略或结果；协调者随后发送的全初始手摘要只用于讨论裁决范围，不用于生成下列独立数值。

## 先排除的动作与对称性

本批最多四次行动，每次最多耗1冷静，回合税1，初始冷静5，故不会进入伤势；主目标仅终局成果效用。快做与稳做采用相同判定档，快做逐档的进度0/1/2不少于稳做0/0/1，更多进度没有副作用，完成封顶，终局效用0/1/2或0/1/3均对已完成项数单调。耦合相同判定档并模拟稳做策略，已提前完成的项若再次被模拟动作选中，可把骰投给另一未完成项，仍保持两项进度分别不少于稳做；双完成可提前结束。因此快做弱支配稳做的终局主效用。

该证明不覆盖冷静／健康偏好，不是快做在真实交锋中的全维支配。两成果所需进度、判定和效用完全相同，换名必须同时交换当前剩余需求及后续目标选择；只有当前状态对称时，才可直接把当前选甲与选乙视为等价。

## 强参照的公平性

- 固定先甲或先乙，仍须允许根据每次结果重选骰子。开局看手牌选两顺序中的较优者，比未看手牌就固定一种更强；它只限制目标次序。
- 补短项，应比较两个正剩余需求，已完成目标退出候选；平手可以优化选甲或乙，骰子仍自由。不能把它说成完整玩家打法。
- 初始固定骰归属必须枚举空组及全给一项，不能要求每组至少两颗或根据双完成容量剪掉单成果保底。每一目标内部骰序对终局完成概率无影响：非负贡献累积达到门槛，不论排列。完成后的本组余骰不能转给另一组。

固定分组的两组判定独立，若完成概率分别为p、q，则一件1、两件B的期望为`p+q+(B−2)pq`。因此B=3改变固定分组族最优分配是允许的，但若两种效用的自由策略仍兼容，不应仅据分区变化宣布出现新的动态判断。

## 独立小树

实际运行：

```sh
python3 docs/实验/机制研究/批次/R44-公开判定与成套成果/审查两骰枚举.py > docs/实验/机制研究/批次/R44-公开判定与成套成果/审查两骰执行.log
```

命令exit0，无继续运行句柄。输入为文件内独立字面六面判定表；没有复用父模型递归。枚举一骰6手、两骰21手，共27手；甲乙剩余需求各0..3；两件价值分别2、3；共864条件。每次判定逐六个等概率面枚举，第一步之后对另一颗骰独立求后续最优。

结果见`审查两骰结果.json`：

- 864条件下，完整稳／险与仅快做主值逐项精确相等；864对称镜像也精确相等。
- 补短项及开局择优的固定先完成顺序，在这864条件均达到自由主值。
- 两件值2改为3时，两目标各自允许自由选骰后的最优目标集合变化0；严格目标反转0。此处只比较目标维度，未宣称骰子最优集合不变。
- 固定初始归属有78个条件低于自由，包含两件值2和3。它显示结果后转让余骰的价值在无互补加成时就存在。

最小见证：剩余需求甲1／乙2，余骰1／1。两件值2，自由与补短项、最佳固定完成顺序都为1，固定归属为8/9。两件值3，前三者为10/9，固定归属17/18。无加成时，初始分区最优为两骰全给甲（8/9胜过一骰一项的5/6）；有加成时，一骰一项最优（17/18胜过全甲8/9）。这确实改变了受限分区族的初始决定；自由族却兼容同一响应规则：对甲先投一颗1点骰，若坏档，则另一颗仍补甲；若中档完成甲，则另一颗争乙；若好档也完成甲，则同样转给乙。允许转让的价值没有依赖成套加成才成立。

## 不把根值相等推广成定理

独立范围是一／两骰条件，不是四骰全局独立最优复算。协调者的全126初始手若显示固定先完成顺序与自由相等，可据此限定冻结关系的根值裁决；不应自动写成任意概率分布或任意许可状态的通用定理。

尤其不能用逐结果耦合证明“先完成一项总支配交错”。固定骰序下，甲乙各3，贡献依次2、2、1、1：先甲导致第二次2溢出，最后只完成一项；按甲乙甲乙分配却完成两项。族内可重选骰序可能在冻结概率下消除期望差，但这与逐路径支配是不同主张。

## 裁决建议与下一问题

若四骰冻结根值与交叉评分均由固定完成顺序／补短项解释，应保留“成套成果”作为组合效用材料，停止本参数的独立原型晋升。分组参照有损失说明资源归属需留后手；不等于成果互补创建新的优先级变化。

本批不靠第三目标、隐藏收益或加倍奖励救题。下一步可转向另一个最小关系，或在真正有理由的多回合组合中问“完成一项之后改变另一项行动的规则，是否比只改变结算效用更能改变后续判断”；先用固定完成顺序、支配和容量反证，不立即上完整新交锋。
