# R18：延后与消除

2026-10-02，首批已裁决，本会话研究者。接续用户持续目标：继续研究，直到证据足以进入下一个阶段。无并行Agent或后台任务。

最小假设：当前必须处理的目标，可以永久完成，也可以花骰暂时解除期限；临时处理保留未来工作，但能利用下一回合的新手牌。区别于单纯目标排序和自行开窗：行动解除现有约束，而不是开启新的约束。

首试：甲需3、乙需5，两回合内全部完成；甲若第一回合结束仍未完成就失败。一次压制需要1进度，完成则把甲期限推迟到第二回合；甲乙进度保留。压制仅在第一回合、甲未完成且未压制时可用。三目标使用同样稳险收益，压制只保留快做卡；中/好足够完成压制，好档多出进度按封顶丢弃。初始冷静5、基础技能1、单人四骰、不用物品。

目标函数限定无伤全部完成，平手保留冷静。最多8次行动及两次回合税，伤势可能发生；本模型排除首次受伤后的路径，不能称为实际通关率。暂无正式内容。

强参照：取消压制但保持原期限；始终先完成甲；始终先压制、之后自由；只准最后一骰压制、其余仍优化。观察压制和直接完成分别何时发生、是否仅救不可能状态。预定边界只查技能2、甲目标2与乙目标4；不做全空间扫参。

停止点：结构明确且简单策略不能完全解释则保留基本关系；若固定压制或固定优先甲足够，缩小主张。不要靠更多敌人、更多倒计时或负修正救题。本批数学裁决后，回看候选库是否应从单体搜索转入组合阶段。

## 首批结果与裁决

首批已完成，停止该最小版本接入。保留“临时解约束与永久完成不同”的纸面关系，不晋升为本轮新试玩。该裁决不排除反复攻击、多敌人、延后累积收益等其他临时控制关系。

都是公平手牌、无伤全部完成模型，不是实际游戏通关率或玩家体验。首试取消压制仅损失不到0.001个百分点，末骰限制已达到自由求解值；甲3/乙4邻域末骰限制与自由也仅差约0.0011个百分点。没有增加更难目标或更多威胁救题。

正常起局前向传播中，压制动作期望数约0.003929，均发生在第一回合最后一颗骰。本规则此时最多尝试一次，故对应约0.393%的模型路径发出压制。不存在本批已观察到的提前压制再安排大量其他工作的策略。前向终端质量和成功概率与递推相符，误差小于1e-10。详见[期限结果](期限结果.json)、[可达分析](可达结果.json)。

原因：甲3一般可用两颗较好的骰完成，两回合总容量有余量；花一骰压制但不推进甲，通常不及直接消除工作。压制只在首轮已不利的尾手留下微小补救。不能拿“多了一张可选卡”当作多了值得玩的策略。

## 证据边界与复现

本批只有数学递推与前向可达分析，没有独立完整最优递推、Content、原生会话、Unity画面或真人证据。正常起局最多8次行动和2次回合税，初始5仍可能受伤；模型把首次受伤后的路径算作无伤事件失败，不代表游戏结束或失败。

[版本记录](版本.json)及[数学快照](数学快照.tar.gz)保存本批两个脚本、结果与官方概率/手牌依赖。快照在隔离目录复算，两份结果除计算耗时字段外结构一致。旧正式批次轨迹按各自快照恢复，本批不绑定新ContentRevision。

## 为什么转入下一阶段

R17发现收手关系在当前条件被一步判断解释、成长很快退化；R18发现延后关系几乎只剩末手补救。再累积这类单体不足以优先占用玩家试玩注意力，而R07/R09/R11/R13/R15已经提供了判断条件不同的基础关系及对照。

因此下一步R19实际筛选一个多回合组合，检验既有关系是否互相改变动作价值。不是宣称设计空间已穷尽，也不把本批失败改写为所有临时控制无效。阶段门槛先记于[R19](../R19-阶段转换与多回合组合/阶段门槛.md)，须通过组合计算、正式转移与版本恢复后才宣布进入第二阶段。
