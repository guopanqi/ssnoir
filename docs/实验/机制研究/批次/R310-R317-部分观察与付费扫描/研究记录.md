# R310–R317｜部分观察下的空间布防：扫描越准确，不一定越值得花行动

2026-10-12。本研究回应R286“位置影响未来观察”的边界；是**无角色、无真实引擎**的四目标格/三站有限模型，不是SSNoir正式地图。数学源 `tools/content-validator/experiments/r310_r317_spatial_information.py`；CI `.github/workflows/ssnoir-r310-r317.yml`。本批8编号只检验一个关系族。

## 去情景机制卡

目标位于格0/1/2/3其中之一，玩家可站在覆盖两格的左/中/右三个站位，每回合只能原地或移动1站，移动在本轮目标出现**之前**决定。与R286不同，玩家普通观察COVER只得到**被当前站位覆盖 / 没被覆盖**这一个二值结果：命中得1；不命中得0。**即使命中也未必知道准确格子**。另可用`SCAN`花整个回合获得**准确格子**，却得0；两个方式都在行动后公开反馈，目标再按已知Markov概率移动到下一轮。

玩家的循环是“有限站位→盲于当前格子的布防→观察二值成功/失败→更新下轮目标信念→再部署”。SCANNING值不值得做，取决于它补充的准确位置信息能否补回放弃的一次命中机会，而不是信息越精确越好。

## 强对照与八项结论

| 编号 | 正交比较 | 结果 |
|---|---|---|
| R310 | 目标保持概率3/4、只局部移动；完整信念DP允许付费SCAN | **32873/8192**累计命中；禁SCAN也**32873/8192** |
| R311 | 保持1/2，另1/4发生非邻近镜像跳跃 | 完整及禁SCAN均**27389/8192**；贪心公开布防在这一版刚好追平DP |
| R312 | 目标永久不动，单纯找位置 | 完整及禁SCAN均**17/4**；始终站中央只能**5/2** |
| R313 | 同规则直接删除付费全位置扫描 | 上述所有三环境根值**增量0**；沿正常最优策略前向传播，没有任何SCAN为严格独优的可达状态 |
| R314 | 不引入额外扫描按钮，改为普通COVER命中时免费报告**准确格子** | R310最佳变为**32983/8192**，R311变为**28545/8192**；可见“部分信息的确丢失了实际最优价值” |
| R315 | 完全独立向前传播“每次站到当前最大预期覆盖地点，打平优先中央”和“永远中央”两种人类可读公开策略 | 局部持续版贪心**30365/8192**低于DP，非邻近版贪心**27389/8192**追平DP；人类能用简明规则处理部分情况 |
| R316 | 比较SCAN的每个可用开局动作Q、沿一条普通最优策略实际可达的严格SCAN优选情况 | 0次；不能在不可达的虚构隐藏状态里声称侦查有用 |
| R317 | 新颖性审核 | **二值观察与位置选择会改变当前的信念，但全情报扫描动作没有独立策略贡献。** 属空间位置、R245信息时间、P08信息购买的组合/支配反例，而不是新调查模式 |

所有后验都是根据玩家真正看到的二值结果更新；数学求解器**绝不直接读取隐藏真实格子**。单独用另一套不调用最优Bellman的概率前向展开对照贪心/站中间策略，代码保存每个时点信念质量与可审查的root-Q。

## 设计含义与停止条件

与R286完整看见上一轮目标的结果相比，这里展示**反馈的表示精度**确实有后续机会价值；但是如果花一整手才能获得准确情报，对剩余4手有限窗口未必合算。不能把能SCAN设为“加入了侦查玩法”就自动放进Debug。

本例也说明“观察能让你更聪明”与“玩家愿意花一次有代价的动作观察”是两种结论。即使赋予SCAN漂亮的望远镜/跟踪情景，也不改变最优的功能性支配。本批按原有数学/真人证据界限，仅归档反例，若未来要探索新活动需改变玩家反复做的事情，而不是继续调目标跳跃概率。
