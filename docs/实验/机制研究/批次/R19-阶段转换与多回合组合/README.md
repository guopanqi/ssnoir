# 第二阶段首试：整段留力

2026-10-02。开始检查多回合组合是否持续产生可理解的判断。第一组是整段完成与冷静延续/恢复，优先试这两场，不用重新试完以前所有入口。求解结果放在[研究记录](研究记录.md)，建议玩完再读。

在现有“交锋测试（直接进入）”中选择：

1. **研究·整段留力**：回合末未完成的工作清零。
2. **研究·进度保留对照**：只取消清零，其他规则完全相同。

建议单人无伤、四项技能均为1的新局，不用烟、酒、药品。入口设置冷静3；已有伤势、同伴与物品会改变研究条件，之后反馈时注明即可。

## 共用规则

三回合内完成两项工作，甲需5、乙需3；两项全部完成立即结束。每回合单人四骰，工作完成后隐藏对应动作；第三次结束回合仍未完成即到期。

甲乙各有稳做、快做，另有整顿，共五种行动：

| 行动 | 坏 | 中 | 好 |
|---|---|---|---|
| 稳做 | −1冷静 | 无变化 | +1进度 |
| 快做 | −1冷静 | −1冷静且+1进度 | +2进度 |
| 整顿 | −1冷静 | 无变化 | +2冷静，上限5 |

每次行动花一颗骰。冷静跨回合延续，结束回合另花1冷静、未用骰子丢弃。冷静不足照常受伤，整顿只恢复冷静；受伤后仍可以推进，倒下按游戏规则退场。实验没有库存或剧情奖励。

整段留力中，完成的工作一直保留；回合末未完成的部分归零。对照中所有进度保留。两项从零开始各至少要3手和2手，无法在同一个四骰回合全完成，因此至少需要两个回合。

## 这次反馈最有用的内容

- 记住一两手：你为什么先整顿、先争取完成一项，或放弃这一轮的剩余骰子？
- 多个回合里，你是否根据实际结果调整过计划，还是很快形成固定补给/固定目标顺序？
- 对照是否让你清楚感觉到区别？如果受伤，是否愿意继续赶工，还是更想保持健康？

可以只给简短体验，不需要完整逐手日志。这是第二阶段需要的真人证据，数学检查不代替它。你之前对整段完成、边做边看的反馈已经保留，不重复索取。
