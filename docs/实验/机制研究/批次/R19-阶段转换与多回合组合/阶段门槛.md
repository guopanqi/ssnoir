第一阶段是基本关系发现和反证，已有真人反馈认可基本模式，但多回合组合体验仍未知。进入第二阶段的依据：

3. 当前新增单体带来的价值已不足以优先占用试玩注意力；裁决需引用本轮证据，不能只因累计批次数而停止。
4. 第二阶段必须落到具体可执行的多回合组合首试及必要对照，证明组合至少改变某些实际分配；没有交互则取消该组合。
5. 完成正式载入、关键转移与终止路径验证，保留可恢复版本；写清模型边界、真人尚未回答的问题及下一次需要的反馈。
