# R50 · 动作回声：改变下一手行动的判定价值

状态：**数学与正式 C# + Scheme 已验证；2026-10-09 已收到首份网页真人反馈。** 玩家感受到准备值变化，却不清楚实验目的、结算和伤势；最新裁决见 [R50人类反馈与同规则双呈现对照](../R50-人类反馈与呈现对照/研究记录.md)。历史数学与执行结论不变。与 R49 的延迟揭示是两条独立假设。

## 研究的问题

上一手行动如何改变下一手动作的价值？这里不产生新的永久钟，不隐藏目标，也不随机更换玩法规则。仅记录上一手选了甲还是乙：

- 甲需要3格，完成立刻得效用1；乙需要5格，完成立刻得效用2。先完成任意一项就结束。未完成得0。
- 四骰、标准 FateStrip 好中坏，坏/中/好分别产生0/1/2进度，成长1、2、3分别测。
- 首手正常判定；下一手如果继续同目标，准备值减1；如果换目标，准备值加1。再下一手重新依当时选择变化；没有永久锁定。
- 每颗骰可以给甲或乙，所有可见信息均公开。**没有任何人物或故事映射。**

对比无前手影响的控制组；完整自由策略与强简单策略的差别也单独算。强简单策略在开局可根据全部四颗骰子决定最有利的「甲乙四手顺序」，**每一步仍可以按照实际判定结果选择哪颗剩余骰子**。因此不能把动态骰序的好处误称为动态目标选择。

## 数学结果

数值是完成所得的期望效用，取值0至2，**不是成功率或乐趣评分**。

| 成长 | 动作回声·自由 | 动作回声·固定目标顺序 | 无回声·自由 | 无回声·固定目标顺序 |
|---|---:|---:|---:|---:|
| 1 | 1.601626 | 1.479843 | 1.733284 | 1.688239 |
| 2 | 1.864562 | 1.812505 | 1.921527 | 1.908341 |
| 3 | 1.973022 | 1.961609 | 1.982588 | 1.979024 |

成长1下，动态重排目标比强固定顺序高 **0.121783 效用单位**；无回声时只有 **0.045045**，新增状态依赖带来的动态增量约 **0.076738**。成长2对应增量约0.038872，成长3约0.007849；成长越高，关系越容易消失。骰子1/1/1/6是明确局部反例之一：回声模型完整自由1.129630，强固定顺序0.916667。

这比 R49 的途中自适应增量更明显，但不可直接称为好玩的新模式。注意：加入回声使完全自由模型的总效用由1.733284降到1.601626，所以不能把「游戏更难」混同「决策更丰富」。本批唯一较强证据是控制变量后，对强固定行动顺序的额外差异。

## 结构差异与局限

与 R42「判定成功之后改变后续技能」不同，本批改变判定机会的原因是**玩家选择哪个目标**，而不是某次判定好坏；其变化可逆，并影响当下选项的机会成本。与普通冷却/固定交替不同：同一目标即将完成时，继续投入可能仍然比换线更好，而此前骰子的实际结果会改变这种取舍。

**正式执行复核**：[GitHub Actions run 37885651004](https://github.com/guopanqi/ssnoir/actions/runs/37885651004) 实际载入 `encounters/研究·动作回声`，12局 C# Session、12次严格回放通过，成长1/2 × seed 7/19/41 × 交替与集中两种脚本路径；会话观察到相同骰面的甲乙卡准备值相差2。仅证明这些路径与公开赔率变化，不是最优策略测试或真人样本。

**强解释性策略审查**：新增 `r50_heuristic_audit.py`，在126初始无序四骰上比较始终甲/乙、严格轮换、距离终点1或2时才坚持、优先收尾等可理解策略，所有策略内部仍逐手优化骰子；完整自由是上界。以 GitHub Actions 保存的精确输出与后续记录为准；不因脚本已加入就断言没有固定套路。

精确模型脚本：tools/content-validator/experiments/r50_recent_action.py。完整枚举126种无序四骰，按实际 d6 权重平均，内部使用有理数计算；这是纸面简化模型，已有正式 C# 会话验证动态准备值、执行与终局的有限路径；模型没有覆盖伤势、物品等全部机制，也没有真人试玩。

此模型已纳入 GitHub Actions 的独立数学筛选步骤；它的数学结论不因此成为原生或真人证据。

下一步：先提出两个能够推翻「动态重排有意义」的解释性简单策略，例如「未完成高价值目标就永远推进它」和「严格轮流行动」，并比较在真实分布下是否已近自由策略；只有差异仍成立，才考虑把 R50 接入正式 Scheme。原则是不因漂亮的百分数而增加规则。


## R50 强可解释策略反证（2026-10-09）

[GitHub Actions run 37886008062](https://github.com/guopanqi/ssnoir/actions/runs/37886008062)已执行独立的 \`r50_heuristic_audit.py\`，遍历126种初始无序四骰，以 Fraction 精确求期望。比较的口诀族包括：总选甲／总选乙、两种固定轮换、上次目标距离终点≤1或≤2时继续否则切换、优先完成距离终点很近的乙／甲。**每个初始手都可挑最优的一条口诀，口诀内部仍逐手优化使用哪颗骰子**；这比拿单条固定规则当对照更强，但不是所有可能的人类启发式。

| 成长 | 完全自适应 | 最佳固定目标序（仍择骰） | 最佳易解释口诀族（仍择骰） | 与口诀族的差距 |
|---|---:|---:|---:|---:|
| 1 | 1.601626 | 1.479843 | 1.482275 | **0.119350** |
| 2 | 1.864562 | 1.812505 | 1.797082 | **0.067480** |
| 3 | 1.973022 | 1.961609 | 1.954598 | **0.018424** |

**裁决**：在低成长条件下，动态改变目标确实包含上述几条简单口诀解释不了的收益，基础关系晋升到**值得认真进行无提示试玩的候选**。成长提升后剩余差距收缩，仍不宣称原生场面的真人决策深度。控制组无回声的整体效用更高，说明加入回声同时让场面变难；不能把总体收益下降包装成更有趣。

下一步不继续用更多阈值去救题：挑几局正常可达手牌与具体操作，让人类玩家在不看求解结果下尝试，并询问他能否预判判定修正、是否有意改变目标以及能否自行总结规则。如果感觉变成强制轮流或机械计算，就下调其体验优先级。
