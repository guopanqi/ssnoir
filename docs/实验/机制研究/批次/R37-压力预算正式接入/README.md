# 压力预算：新多回合试玩候选

在现有「交锋测试（直接进入）」中选择 **研究·压力预算**，随后可试 **研究·回合加压对照**。三回合，不需要先阅读求解结论。

建议单人、无伤、四项技能1的新局，不用烟酒药品；入口设置冷静3，不清除已有伤势或背包。同伴、技能和物品会改变条件，反馈时注明即可。没有改动引擎、UI或游戏的正式收益口径。

- 主进度12，达到立即完成。越早完成，消耗的回合和冷静越少。
- 主进度经过3、6时，各产生一个问题。每个问题需修满2格。
- 未修好的问题，每次结束回合增加1压力；修复只止住后续增长，已有压力保留。
- 推进的坏档增加1压力，修复的坏档不加场面压力。压力达到5立即失败。
- 结束回合另花1冷静；第三次结束回合还没完成则超时。冷静耗尽后，代价继续转为伤势。

| 行动 | 坏 | 中 | 好 |
|---|---|---|---|
| 推进稳做 | −1冷静、+1压力 | 无变化 | +1主进度 |
| 推进快做 | −1冷静、+1压力 | −1冷静、+1主进度 | +2主进度 |
| 甲／乙稳做 | −1冷静 | 无变化 | +1修复 |
| 甲／乙快做 | −1冷静 | −1冷静、+1修复 | +2修复 |

对照只取消「推进坏档加1压力」，其余规则相同。主进度和已修部分跨回合保留；解决过的问题不会重新出现。画面常驻显示本轮结束将增加多少压力。

不必一次反馈所有入口。试玩后，告诉研究者一两手具体决定就够了：什么时候愿意留下问题继续推进？失败后有没有改变下一步计划？结束回合的压力是否容易预测？修复甲乙是否重复、拖沓？有没有能概括整场的固定流程？

正式规则唯一来源是 Content 中的公共脚本与两入口。本批保存18条正式轨迹、192步、18次严格回放；16局预定组，另6次完整覆盖搜索只保留2条补缺轨迹。这些是实现校准，不是玩家测试。Unity画面与本批真人体验尚未验证。
