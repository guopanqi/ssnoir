# OPTION-AUDIT01：保留未来选择权的跨机制族证据审计

日期：2026-10-15。接续 ACTION-SWITCH01，依据研究定位与评价，从已有 HEDGE01—05、FOCUS01—06、CLAIM01—03、OPS01、ACTION-MODE/SWITCH 等**现成证据**提炼一个用于筛选新实验的可证伪判断过程。没有重算各家族根值；这是跨来源核对，不把每个历史实验的效用放到同一排行榜。

## 研究问题
什么时候玩家“留下多条未来路线”是真实的操作决策，什么时候只是UI上同时出现多个任务？

首先拆开六个独立问题：
1. **行动资格仍存在吗？** 过去开启的项目/人际机会是否仍可完成，而不是仅以文字保留。
2. **另一机会的质量是否在此刻未知？** 已知价值时可能直接串行完成最好的任务。
3. **失去旧资格是否不可逆？** 之后是否还能用同等行动成本重新获得。
4. **保留是否有实际费用与容量约束？** 如果完全免费、无限保留，则没有保留与放弃的代价。
5. **新信息到来后，玩家是否还有完成任一路线的行动余裕？** 能到达不等于结束后还能做别的。
6. **普通安全等待/临场重开是否已经支配早期投入？** 如果是，方案只是在故事里虚构焦虑。

## A. HEDGE01—05：目前最强正面因果案例

[原报告](../2026-10-13-主动开启与问题累积/并发工作与保留退路.md)原规则：五手；OPEN/WORK/DROP/SIDE；项目开启后还需两手WORK，若开后三次全局行动未完成会受−4；A只有首手能开启（仅这一版），A价值14或5各半，B价值14或0各半。价值在OPEN时揭晓。

| 反事实 | 原研究精确根 |
|---|---:|
| A仅首手开放，允许真实重叠 | **51/4=12.75** |
| A仅首手开放，但OPEN B前必须先结束A | **47/4=11.75** |
| A随时可重开，允许重叠 | **51/4** |
| A随时可重开，完全禁止重叠 | **51/4** |
| 禁DROP，A首手且允许重叠 | **23/2=11.5** |

在A低5且B未知时，玩家把A留下、开启B；B低0则返回完成A，B高14则DROP A、完成B。这在正常起点有概率1/4确实兑现了旧退路，不是两条并行计时条的装饰。前两个制度的差1来自A低/B低分支可在本已关闭的早窗口之后真正回到A。

**同分异果**：重叠最优有 P(A完成)=3/4、P(B完成)=1/4；无限期重新开A且串行同分的最优有 P(A)=1/2、P(B)=1/2。不能把总收益同分误读为同一人物的同一结果。

严格裁决是「窗口×不可重开×有实用价值的旧退路×新机会后到信息×足够剩余手数」的**成熟组合正例**，而非独立原创原语。它的最优也只是简短条件口诀，尚无真人对负担/眷恋的证据。

## B. FOCUS01—06：保有资格不足以保有余裕

[原报告](../2026-10-13-注意力切换与计划余裕/研究记录.md)给出6手、两项各需3WORK、TO切换焦点费1行动；第2手后才揭晓需求。主制度动态20.5、最强固定15、同成本SETUP逐状态同构；然而允许前两手安全SIDE等待时，安全方案根22，反而支配需要预押的主制度。

另一同族前缀展示真实的**残余行动余裕**差异：
- 需求第2手后公布，最优前缀AA；A终局22，B终局19，根20.5。
- 需求第3手后公布，前缀A→TO_B→SIDE；两种需求都可在余下3手完成，但根20。
- 需求第4手后公布，前缀A→A→TO_B→B；两种需求都只剩最后2手能完成，根19。

三个前缀均保留A/B可达性，却有不同的SIDE余裕。**不仅询问两项能否到达，更应该记录兑现之后各剩多少行动。**

## C. CLAIM01—03：保留选择权与提前兑现奖励共同作用

[原报告](../2026-10-13-跨期操作与可撤回承诺/研究记录.md)原规则下，早期申报A可取得条件性的及时奖励；后到需求B时SOFT可先撤销再申报B但花两手。p(A)=1/4时：SOFT最优12.5，HARD 11.5，SOFT若取消早申报奖励也11.5。提前申报奖金与能付费撤回**只有组合后**才真正改变根，单独一项不够。普通晚期都可申请且无早奖时根13，不能把不同奖励协议下12.5与13说成完全等价。

这里不是HEDGE那种两项同时LIVE，而是过去承诺能够被付费撤销。两者玩家动词不同，不能把它们合为一个“复杂度更高的同模式”。

## D. 连续负例：复杂新动作并不保证保留选择权

- ACTION-MODE01：B紧随A改产C，固定与动态均19，强固定ABAB。
- ACTION-SWITCH01：增加花整手切换转换规则M，固定与动态仍19，强固定MABAB。
- REC01—03：双向余效×暂时阻塞确有重新选择；但简单交替加一手前瞻就完全追平DP的939/64。
- FOCUS的免费SIDE等待与HEDGE的无早窗重开，都允许**朴素串行旁路**，不需要更复杂的多目标注意力心理循环。

**由此不能把“动态高于固定计划”作为唯一认证标准**：已有短条件口诀可能全优；真正反证是与强安全菜单、临场重开、预编译工具和同根不同成果向量比。

## E. 可执行的四级研究判别

1. **集合级**：同一真实起点，有没有至少两个值得区别的终局成果，以及不同真实事件历史的合法后缀？仅做数学可达性判断。
2. **策略级**：最强固定路径、最强可观察条件短策略、强安全等待、临场同成本SETUP、随时重开旧任务各能做到什么？一个简单旁路全解则应归并负例。
3. **后果级**：保留目标A而非B会在终局取得不同实际成果吗？并列输出完成概率、留下的进度、沉没投入和完成后的剩余行动，不用标量遮蔽。
4. **体验级**：玩家是否在事先表述了真实关切之后，实际观察、选择放弃某一关切，并能无提示说明原因？当前**没有本批真人证据**，不允许用前三级代替第四级。

## F. 人类无答案验证的最小对照（未实施）

可直接复用仓库HEDGE无答案观察卡，不新造重复网页。提供至少两种**明示规则**的纸面协议：早窗口且允许同时LIVE、无早窗口且只能串行；试前要求玩家自己说更在乎哪一种实际结果，不要先告知“期望值12.75”。逐手保留原话及事件顺序。先问“如果B很差，你是否仍能回到A”，再显示完整结果；记录玩家是否把已开的A理解为实际退路。禁止把两个不同制度的感受差冒充仅由并行资格一项造成——该对照同时改变了窗口与并行菜单，是联合消融。

## 结论与下一批阈值

本轮没有创造一个新原语，而是明确了**必须联合出现、且有强反事实支持的成熟结构**：只有明确早期窗口、可真实兑现的旧路线、后来才知道的新机会品质、不可免费等价重开、且剩余行动足够时，玩家的“同时保留”才可能在正常起点具有严格用途。对SSNoir有价值的是这类可解释、有结果身份的Scenario决策，而不是持续堆积进度条。

下一批应优先从不同的玩家心理动词出发，而不是调A/B奖励：例如是否有可检验的「同一资源先投到一事，看到局势变化后转投另一事，但原事留下具体不可替代后果」，并与HEDGE当前窗口以及普通可换资源同构对照。若无实际玩家反馈，不把新协议列精选Debug。所有此批数据均引用仓库既有实验，并明确其不同规则和证据边界，没有单独进行新的随机蒙特卡洛或运行Unity。
