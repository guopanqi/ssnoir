# R269–R277｜无提示纸面验证方案（尚未执行）

状态：**预注册的研究规约，不是已获得的人类数据**。纯抽象 A/B/C 提问，不进入正式游戏Debug，不添加网页功能。

## 研究问题

玩家从四个等可能的隐藏类型出发，是否会自己发现“第一问的回答改变第二问应该问什么”，还是记住某套提问口令而没有理解条件诊断？数学版已证明完全可靠回答时完整分支策略1，最佳全部预先固定测试0.75；10%独立误报时对应0.81/0.63。这不能代替人的策略学习。

## 给参与者的任务卡（不附解决方式）

有四种状态：**0、1、2、3**。每一局只有一个隐藏状态，且初始可能性一样。你最多可以问两次“是/否”问题，再猜是哪一个状态。你拥有三种不同问题：

- **A**：属于0或1吗？
- **B**：是0吗？
- **C**：是2吗？

每一局你先问第一问，看到回答后再决定第二问。不能重新提问第三次。最后写下猜测、信心1–5分，以及为什么选择第二问。连续试4局，不提前公开正确提问顺序或奖励最优公式。在练习局让人理解规则，但不要演示固定最优提问法。

**观察指标**：两次提问的完整序列、第二问是否受第一问影响、对两组备选状态的口头解释、是否询问“不同情况下下一问能不能换”、最后一轮是否已感到重复，以及在改名的另一套问题中能否独立迁移相同诊断思想。不要仅根据猜中率评“好玩”。

## 第二组迁移（换内容，但不把答案给玩家）

把状态重新命名为W/X/Y/Z，问题定义改为“W或X？”、“Y？”、“X？”。依旧每局2次提问，但不能让参与者拿第一组的三字母顺序直接填写。重点检查他/她是否主动思考*剩下哪两种可能性还没有被区分*，而不是复现ACB。问“你现在为什么问这个”比询问喜欢程度更重要。

## 研究员记录与防泄漏

工作人员在参与者出场之前暗中等概率抽状态，保证每次问题按照已经抽定的状态给真实回答；如果要验证噪声10%，必须**先独立预生成每一个答案是否翻转**，不能因参与者选择而临时改答。正常试玩先不加噪声，避免概念叠加。遵守反馈与机器的“生成/回答”规则，不依参与者动作更改隐藏真相。

记录每轮：隐藏状态（仅研究员）、问1、答1、问2、答2、最终猜测、信心、提问理由，以及“会不会想再来一次”。不得把数学求解器输出当作真实参与者决定；人类反馈记录和精确证明分别存档。

## 预注册停止与晋升门槛

如果多数参与者无需操作、只读任务说明就给出全套常识固定问法，或首轮结束后只会背诵同一条字母序列而无法在迁移版理解“为什么另一问有用”，则标记**清晰但重复不足**，不进入新Debug试玩。反过来，如果参与者确实主动、可迁移地设计下一问，还需要独立评价多局后是否有趣、测试动作是否直观、是否存在不同于经典二十问的新操作/反馈关系，方可考虑进入高一级的设计筛选。数学正确不等于游戏好玩。
