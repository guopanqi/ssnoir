# R269–R277｜两次诊断：第一次回答改变第二次要问的问题

日期：2026-10-12。第三个独立研究族；不把新剧情/敌人/地图当成机制证据。目标是最小形式的**主动选择诊断问题，而不是一次性花费行动购买固定情报**。脚本 `tools/content-validator/experiments/r269_r277_adaptive_diagnosis.py`；Actions `.github/workflows/ssnoir-r269-r277.yml`。

## 去情景机制卡

系统秘密选取0、1、2、3之一，先验各1/4。玩家最多连续做**两次提问**，每次只得到“是/否”，之后猜中秘密类型才得1。没有任何过程积分或手牌变量。可选的公开测试只有：
- A：秘密是否属于{0,1}？
- B：秘密是否为0？
- C：秘密是否为2？

第二问可以依据第一问的可见答案决定；第一次不能读取隐含类型。允许试验回答被独立翻转，错误概率公开。玩家重复活动是：**针对当前尚不能排除的假设选择下一个能够区分它们的测试**，而不只是固定“调查一次→拿真相→选择目标”。

## 九个检验的主要真值

| 编号 | 比较 | 结果 |
|---|---|---|
| R269 | 回答完全可靠，全部允许第二问依第一答变化 | 正确识别率**100%** |
| R270 | 枚举全部3²=9套事前固定的两道测试，允许最后根据结果选择最优猜测 | 最佳**75%** |
| R271 | 枚举全部3×3×3=27个完整公开分支问法 | 唯一最高**ACB**：先A，A回答“否”问C，“是”问B |
| R272 | 真实可到达的两种第一问回答状态，第二问测试Q有严格差别 | A答否时C最好；答是时B最好。两状态各有概率1/2，不是注入不可达秘密 |
| R273 | 每次回答分别有10%独立错误率，玩家在观测后Bayes更新 | 自适应**81%**，最佳固定两问**63%**；第二问按答案改变仍有明确净收益 |
| R274 | 回答完全随机、与真相无关（错误率50%） | 自由与固定都回到**25%**；新增提问本身不产生任何真实信息 |
| R275 | 比较首问A/B/C在可靠条件下的完整预期 | 分别**100%、75%、75%**，真正决定后续可分辨性的首先是第一问如何划分假设空间 |
| R276 | 两种独立求解：逐条执行27个完整分支提问程序、与不共用策略枚举的阶段性信念态DP | 在错误率0、10%、50%三个冻结版本全部精确一致 |
| R277 | 机制同构和晋升审核 | **有真实适应性提问关系**，但它是典型二叉诊断树/二十个问题的抽象形式；四类答案的最优提问口诀很容易记住，尚不能认证为原创成熟玩法 |

为什么不是“用两颗骰子推进情报条”：A将可能性分成两组，第一问只有在得到反馈后才能知道第二问**B或C中哪一个还能再区分两种候选**。一开始固定两问，即使知道所有规则，也必定有一组秘密类型无法区分。R273的噪声版本也展示这项决策并不是零成本的完美信息玩具。

## 价值与失败边界

这一结构确实和R77“开局买一次信息”有所区别：信息不是一个确定能买到的属性，而是玩家要主动设计一个**问题顺序**。有非常清楚的可学心理模型：发现一个回答排除一部分可能性→选择下一种互补检查→决策。但它显然继承经典主动诊断/二十问玩法，不能因为SSNoir之前较少试验就称世界首次新机制。

决定下一步是否真正值得制作原型的不是81%的数值，而是人类是否享受“自己选择哪类问题值得问”，能否在**不同测试集合**中转移这种思维，而不是背诵ACB公式。保留为**有验证价值的抽象组合候选**，不自动进入六精选/20历史候选/三个Debug白名单。没有真人、没有原生C#+Scheme证据。
