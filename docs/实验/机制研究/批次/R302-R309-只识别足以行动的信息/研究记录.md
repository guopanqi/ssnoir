# R302–R309｜只辨认足以行动的信息：提问、停止与真正的诊断成本

2026-10-12。回应[队列](../../研究队列.md)中“身份识别 vs 能采取正确行动”的边界。本模型仍只有4种隐藏类型、3种公开二值问题、至多两问；**改变的是奖惩真正要求玩家做到什么**。所有信息按真实回答时点公开，玩家可停止；没有角色故事、真人反馈或正式游戏代码。脚本 `tools/content-validator/experiments/r302_r309_decision_relevant_tests.py`，CI `.github/workflows/ssnoir-r302-r309.yml`。

## 去情景机制卡

秘密状态0、1、2、3等概率。可问A“是否为0/1”、B“是否为0”、C“是否为2”。最多两问，每问花费1/8最终效用。玩家可在任意时点**停止**并选择一个实际行动，选中该秘密要求的行动才得1。行动可以相同：0/1都要求X，2要求Y，3要求Z。不需要知道哪种秘密，只需执行正确动作。

循环不是单纯“问满两个问题”：先问是否能改变自己当前的行动→看到回答→如果同一动作已覆盖剩余可能性，**主动保留剩余行动容量**；否则再问有用的题。考虑可完整验证的“停止”动作，防止强迫进行第二次无意义信息购买。

|R309|关系审计|**为了行动只取足够的证据**是信息/机会成本的有用变奏，但“临时改第二问”和“依回答主动停止”是两件不同的决策活动；本三行动实例只需要后者|

这批没有人为比较极差的“固定两个问题永远不看答案”稻草人。强固定基线允许各回答分支主动结束，只禁止改写第二道题目。因此原R269自适应优势不能自动迁移到“真正采取行动”的版本。

原生SSNoir场景无此规则，本批无真人体验。它与P03/P08主动信息、R269经典二叉诊断、R294付费探查近邻，不认证独立新模式。更可重复的研究问题是**玩家决定何时不再调查**，并且此决定必须影响实际后续行动；如果第一问始终已经足够，调查就只是固定剧情开关。
