# R07试玩与复现

优先在现有调试面板的“交锋测试（直接进入）”选择 **研究·整段完成**。A需5、B需3；两回合内完成两项；回合末未完成清零、完成保留。

**研究·保留终点**是一个较基础的可选目标组合：A需2且完成即结束；B需2，必须在结束前争取；只有一回合。

建议无伤、冷静5、技能均为1、先不用恢复品。两入口都使用同一惯用收益：稳做坏-1冷静、中0、好+1；快做坏-1冷静、中-1冷静且+1、好+2。没有叙事包装。

先玩后看[研究记录](研究记录.md)。记录本轮准备先完成哪一项、哪次结果让你换了计划、清零是否带来判断或只是挫败。

对照入口：**研究·分段保留对照**（5/3但进度全保留）、**研究·分段短目标**（4/3且半成品清零）。

终端可进入同一正式规则：

```bash
./run --session encounters/研究·整段完成 --seed 1413 --growth 1
./run --session encounters/研究·保留终点 --seed 1417 --growth 1
```

`筛选.py`、`分段筛选.py`、`强基准.py`可独立复算对应模型，输出会更新其同名分析JSON；不要把复算时间称为原实验时间。定稿5/3结果与邻域身份在报告中区分。

`正式对照.py`保存原生轨迹、检查转移并回放；输出目录已存在时拒绝执行。完整复现时在新检出或隔离目录中使用同一正式版本，避免覆盖本批证据。

[运行快照](运行快照.tar.gz)包含本批Content与当时校验器构建，已验证可在独立临时目录严格回放。解压到新目录，以该目录为工作目录，用其中 `tools/content-validator/bin/Debug/net9.0/SSNoir.ContentValidator.dll --replay` 回放解压后的原生JSON。需要兼容的.NET运行时；这是会话复现快照，不是完整Unity工程备份。原生轨迹位于 `正式对照/*.json.gz`，回放前解压为JSON。
