# 末回合修复的主目标边界

2026-10-02，冻结R32，纸面反证。

在最后一回合，负担仅在结束时收冷静，不在动作之间影响判定或合法推进。修复和推进的判定档、冷静损耗、骰消耗相同。给任意原策略建立一份按原规则推进的“影子状态”，以相同骰、稳险、档位和首次伤部位耦合实际状态；把原策略的所有修复动作替成推进，其余推进保持。仍用影子历史决定动作类型和骰，实际主进度始终不低于影子。影子修复卡的出现/消失只用于模拟，不要求实际继续修复。

在实际提前成功前，两边每步冷静与伤势相同，所以当前有效技能和结果联合分布相同；骰消耗也相同。若影子成功，则实际在同一动作或更早已经达到8，且之前不可能先倒下，因为该时点以前伤势相同。若实际更早成功，后续费用消失。提前触发额外负担只影响回合末，而实际成功立即退出，故不损失成功。若两者都未完成，则本回合结束后均无下一回合。

因此，最后一回合的任意含修复策略可换成无修复策略，其成功概率不下降。A主目标不下降；B在末回合每次成功同记1、失败0，也不下降。这个证明与早先回合不同：早先回合的新增负担会改变下一轮健康与骰数，不能同样替换。

本结论不是全六维支配。替换后的失败路径可能保留更多负担、触发新负担，于结束时更多受伤，曾伤概率可以更高。A/B都把曾伤作为主收益平手后的次目标，因此末回合仍可能选择修复；不能据此断言模型任何最后回合修复都是错误。

精确反例：第三回合进度3、甲负担未修2、乙未出现、冷静1、无伤、唯一剩骰6。有效技能1，好档必然。风险修复+2把甲解除，结束只付税1，冷静归0而无伤；同骰风险推进+2到5，甲仍活，结束甲压力1＋税1，冷静1溢出为首次1伤。双方无法到8，A/B主收益均0；修复曾伤0、替换推进曾伤1。这个失败路径次目标严格反转足以阻止全维支配声明。

“成功路径伤势与冷静不更差”也只在对应原成功路径耦合上成立；若替换新增成功路径，成功加权伤势之和或条件成功平均值不能直接用路径包含关系比较。应按具体目标的词典序，而不是逐列声称全占优。
