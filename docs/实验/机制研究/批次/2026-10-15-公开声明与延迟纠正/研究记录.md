# PLEDGE01—14：公开判断促使别人行动，后到反证与有限纠正

- 本批只补一个**组合关系**：公开一份有噪声却可核实确曾得到的报告，诱发早期行动者A不可撤销地投入、晚期行动者B准备投入；出现准确新证据后，玩家必须决定是否花掉自己仅剩的一手，把真实信息及时交给B。**撤回错误报告不能重置A已承担的损失**。

## 冻结行动图：不要将NPC当成按剧情服从的机器

真实状态T为GOOD/BAD各半。玩家先得到可信认证的二元测试报告s，报告正确率3/4。若s=GOOD，可在早期窗口选择 **ISSUE**（公开正面报告）或 **HOLD**（不公开）；若s=BAD，只允许HOLD，不允许假冒正面认证。

受众A和B各自投资的私人实际回报：T好时+4、T坏时−6。他们在尚未收到晚期真相时看到正面认证报告，认为T好的条件概率为3/4；自利投资期望为(3/4)×4+(1/4)×(−6)=3/2>0，因此**自己愿意投资**，不是玩家按下按钮就强制他们照做。没有正面证书时，不按没有证据的口头保证进行投资。A如果收到ISSUE，在早期立即投资且事后不可撤回。B较晚行动，可依据已有ISSUE投资，或依据最新**可核验、准确**的新证据改变决定。

早期行为之后T的准确证据自动到达玩家。玩家末期只有一次行动，可 **SEND**（把真T的可验证证明交给B；消耗整手、零SIDE）或 **SIDE**（另做自己的工作获得+1，不发送证明）。B有自己的4/−6收益，收到GOOD证明投资、收到BAD证明不投资。没有新证明就仍根据现有ISSUE决定是否投资；HOLD且没有新消息时不会投资。

玩家的研究用目标函数把五条**单独登记**的后果相加：
1. A的实际投资净效益；
2. B的实际投资净效益；
3. 早期ISSUE带给玩家的公开即时收益+2；
4. ISSUE最终被证明虚假时玩家的额外明确后果−12（无论事后是否纠正，早期负担不能取消）；
5. 末期若SIDE，得到+1。

这是一份明确声明的线性研究目标，不是人类道德偏好调查。“额外−12”**只是模型处罚代理**，没有模拟第三方实际根据声誉改变行动，不能称已实现可信的社会信誉系统。B的自主性也只限于看到认证后按个人4/−6收益投资；没有战略说谎、模仿、私有偏好或混合均衡。玩家知道这些规则。

## PLEDGE01—04：初始声明与后期纠正形成真实行动关系

| 同一冻结规则的能力 | 玩家最优根 |
|---|---:|
| 完全没有SEND渠道，B不能得到后期准确证据 | **2** |
| 能在未早期ISSUE时告知真正好消息，但无法对先前虚假ISSUE作负面纠正 | **5/2=2.5** |
| 可用一手SEND发送晚期可核验真T，包括纠正早期错误 | **3** |
| B无需玩家花动作就自动得到晚期准确T | **13/4=3.25** |

正常完整版的最优规则：
- s=BAD：HOLD；晚期若T=GOOD则SEND、否则SIDE；
- s=GOOD：ISSUE；晚期若T=BAD则SEND以阻止B跟着错误证据投资，否则SIDE，因为B已能根据正面证书安全投资。

可纠正负面信息，**反过来改变了早期是否作保证**。s=GOOD时，如果负面纠正受禁，最优HOLD（条件价值13/4），因为错误ISSUE后无法阻止B仍投资；允许纠正时ISSUE的条件期望17/4，严格优于HOLD13/4。正向组合来自“早期报告→A立即投入与B未来准备→晚期真相→玩家花动作纠正B”，不是简单把上一轮的错误奖金数值减小。

### 全世界正向结算及两位受众的损失身份

| T | 第一份s | 世界概率 | 玩家早期 / 晚期动作 | A实际净收益 | B实际净收益 | 玩家公开/负面处罚/SIDE | 玩家总收益 |
|---|---|---:|---|---:|---:|---|---:|
| BAD | BAD | 3/8 | HOLD / SIDE | 0 | 0 | 0/0/+1 | +1 |
| BAD | GOOD | 1/8 | ISSUE / SEND | **−6** | 0 | +2/−12/0 | **−16** |
| GOOD | BAD | 1/8 | HOLD / SEND | 0 | +4 | 0/0/0 | +4 |
| GOOD | GOOD | 3/8 | ISSUE / SIDE | +4 | +4 | +2/0/+1 | +11 |

全世界精确期望向量依序为：A=3/4，B=2，公开收益=1，错误报告额外处罚=−3/2，SIDE=3/4，合计**3**。玩家向B发送纠正后，**不能把A早已失去的6写成“没有任何人受害”**。实际第三方结果应保留，不能仅展示玩家标量根值。

## PLEDGE05：完整条件计划是最强无聊解释

若玩家在第一份报告出现时必须同时预写自己的末期动作（可依s不同，但**不能看真实T后改**），所有可行的早期HOLD/ISSUE和末期SEND/SIDE组合穷举后，最优根仅**9/4=2.25**。与允许T到来后决定相比少3/4。

**但另一种更强对照**，允许玩家事先写一条将来依法执行的、可核验T为条件的完整计划，例如“若s=GOOD就ISSUE，之后若T=BAD则SEND、否则SIDE；若s=BAD就HOLD，之后仅T=GOOD才SEND”，就能与动态计划完全同值**3**。它仍有**晚到事实改变执行分支**，只是脑内策略可以压缩成一句口诀。不能仅以“临场动态 > 固定无条件脚本”宣称新原语；也不能用“策略能事先表述”反证现场无需查看T。

固定预写SEND本身仍传送晚期认证事实，B可自主对所见T作响应；这不是刻意拿无效谣言当静态弱基线。

## PLEDGE06—09：超强信息旁路与角色后果不互换

若B在晚期能够**自动免费查看真T**，玩家无需使用SEND，根**13/4=3.25**，优于现有制度。它同时削弱了“由玩家承担纠正动作”这一活动；如果游戏世界已经公开证据，玩家不能无缘无故再收一手的“告诉他”税。

强替代：早期截止前直接付现金C即可获得一份完美T认证，免去不确定公开的风险；这项工具**在信息质量和时点上强于晚期准确证据**，并非与原诊断同等劳动。对应玩家根**6−C**：C=0得6，C=2得4，C=3与常规模型3同值，C=4得2。不能因为这类更强的假定工具存在数学上界，就宣称弱条件渠道必然无价值；但若真实游戏确实提供廉价先知，责任型Scenario将被旁路。

## PLEDGE10—14：受众会否行动与玩家愿否承担责任是两个门槛

第二份独立Fraction完整世界枚举只改报告准确率q（仍可信可认证）或玩家目标对B自身效益的权重w，不改变A/B私人净收益+4/−6。

**受众自身投资门槛**：q×4+(1−q)×(−6)>0，等价**q>3/5=60%**。q=60%自利平局默认不投资。

**玩家早期ISSUE门槛**：当B的净效益权重w=1、早期公开奖金2、虚假公开处罚12、末期可选择SEND/SIDE时，条件于s=GOOD，ISSUE续期值27q−16，而HOLD值1+3q，故**q>17/24≈70.83%**才选ISSUE。两门槛之间（如q=65%、70%），即使受众愿为正面认证冒险投资，玩家综合承担后果后仍应HOLD。这是“能说服对方”不等于“我应该促使他行动”的具体数学分界。

| q | 受众见证后愿投入？ | 玩家s=GOOD是否ISSUE？ | 全场玩家根 |
|---:|---|---|---:|
| 1/2 | 否 | 否 | 5/2 |
| 3/5 | 否（平局拒绝） | 否 | 5/2 |
| 13/20 | 是 | 否 | 5/2 |
| 7/10 | 是 | 否 | 5/2 |
| 3/4 | 是 | 是 | 3 |
| 9/10 | 是 | 是 | 24/5 |

**福利权重分离**：玩家内部目标对B实际收益的权重w可与B自己选择投资时的私人利害不同。在w=0时玩家末期完全不愿为了避免B失去6而放弃SIDE+1；w>1/6时，已ISSUE且晚期T=BAD，SEND严格优于SIDE。不自动把“对方有自己的利益”视为“玩家必然关心对方”。w=0、1/6、1/4、1/2、1时，完整版玩家根依次为5/4、11/8、3/2、2、3；无SEND渠道分别5/4、11/8、23/16、13/8、2。**不同目标函数之间的分数不能直接拿来作为新机制优劣排名。**

另在q=3/4、w=1固定情况下，公开奖金R=0/1/2/3/4时最优根5/2、5/2、3、7/2、4；虚假发布处罚K=0/8/12/16/20时根9/2、7/2、3、5/2、5/2。R=1与K=16都是最优HOLD/ISSUE平局边界，不能宣称唯一行动。

## 研究裁决：有效组合，不是新社交原语

“从对方收到的消息中获知其将如何行动 → 判断我是否应该提前发声 → 后到真相是否需要我花时间纠正 → 哪些人的损失已不可撤销”，确实是一个可表达的完整Scenario关系。

但是关键环节均有成熟来源：SOURCE的信息公开改变后续认知，RECIP/NEG的可信行为激励，CLAIM带成本的撤回，CASCADE的上游事实与后续成果，CRISIS的事后补救。本文是它们的**明确拼接条件与高强度退化反证**：A必须早期真实行动且损失不能退回、B必须晚期能够回应、纠正必须可核验并有时间成本、廉价早期完美信息不可随手获得。没有任何一个条件本身构成独立原创 gameplay primitive。

**局限**：这里没有真正的战略信号博弈（正面认证来自外部、发布内容不可伪造；没有算接收方对玩家发布概率的均衡猜测）；“声誉−12”仅外生代价，不是未来另一个自主角色的行为；玩家目标人为将A/B收益同权相加；四个世界的短策略无动态算法难度。无实际人物关系、第三方主观反馈、真人或独立盲Agent。不得称本批已经解决“公开认错”“信任恢复”或设计出比RECIP/CLAIM更有趣的新Scenario。

## 执行证明、后续验证

本地Python 3.13标准库Fraction两份模型已真实运行。脚本1由4个真实(T,s)世界、A/B私人投资响应、全部初始/晚期合法动作的穷举和独立五轴向量前向结算构成；脚本2独立按q/w逐世界枚举动作并断言阈值与受众私人最佳反应。GitHub已提交两份同协议源文件；**GitHub Actions独立成功尚未验证**，不能将本地运行说成CI。

无答案三角色纸面观察须分别询问：(i) A/B会否基于认证采取行动；(ii) 玩家会不会因为可以晚期纠正而更愿提前发声；(iii) 发现消息错后是否以为提醒B就消除了A的损失；(iv) 玩家是否主动说出自己放弃SIDE的理由。人类反馈应保留原话、具体世界和行动历史，不把数学预测当实际行为。避免把−12 reput罚额当现实道德标准。

**下一研究方向**：不再调PLEDGE的声誉罚额/人数。跨族比较一个实际玩家连续承诺导致多个受众先后行动的可观察反馈是否比“纯数字一手发送”更清楚；若仅能用外生处罚让玩家纠错，就归还RECIP/CLAIM/CRISIS成熟组合。正式Game、精选、Debug均冻结。
