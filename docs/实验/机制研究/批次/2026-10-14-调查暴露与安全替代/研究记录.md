# 暴露式调查：强安全替代与响应关系的结构反证

2026-10-14。接续 main bc053ed754b826d09a3938e335c3e771ef08edb2、IWT01。遵守研究定位：去情景、只讨论玩家公开动作与自利他者响应，不新增剧情、Unity Debug、精选或真人验证。

## 问题与分层

IWT01 证明了「工作1份＋75%类型报告」的价值，但没有别人观察。此批问：当 TRACK_X 暴露玩家正在关注 X 时，是否出现与 DISC/FOCUS/SIG/ADV 不同的**重复决策活动**？

必须分清三件事：
1. **暴露成本**：公开行动导致固定损失，等价于劣化工作效率。
2. **暴露信号**：对手从行动推断玩家可能做什么；若只有固定规则惩罚，玩家无需真正考虑对手目标。
3. **敌手响应**：对手拥有实际可选的行动、有限预算和私有利益；其选择随玩家公开承诺及保留的后续动作变化。此时可能形成针对谁、何时泄露、何时切换目标的双向判断。

第三种才值得继续；仅把危险进度条加在 TRACK 上不是新原语。

## 对照组一：保留 IWT01 全套安全工具（严格支配）

保持四手、隐藏 T∈{A,B} 等概率、A/B各需三份工作、完成正确A得10/B得8、SIDE每手+1。INSPECT一手准确100%；WORK_A/B安全地+1份；TRACK_X一手原本+1份及独立75%报告。

冻结暴露变体 E0：TRACK_X 的工作在本行动末因公开暴露**立即丢失**，但75%报告仍可见；其他行动和报告规则均不变。对手不会额外攻击安全 WORK，没有其他策略动作。

**逐历史的严格改进替换**：把任意一手 TRACK_X 替换为同成本 INSPECT，能得到完整真实 T，且在 E0 中并不失去任何有效工作（TRACK 的净工作=0）；因此 TRACK_X 在每一个可达信息状态都被 INSPECT 弱支配，有时严格劣于 INSPECT。若已有真实 T，则用安全 WORK_X 或 SIDE 替代亦不差。任何需要 TRACK 的条件政策都能由不使用 TRACK 的政策复现或改进。允许 INSPECT→正确工作三手的根收益是 (10+8)/2=**9**，是该规则中的全局上界：达到正确三份工作必须占至少三手，不知道 T 时无法超越首手完美报告加三手工作的按真值兑现；若首手工作后再检查，最好的逐类型分支也没有额外四手兑现余量。固定损失本身**不**创造「是否暴露目标」的新心理循环。

注意：这项严格反证只适用于 E0 定义的净工作为0、不攻击 WORK 的安全工具。不能直接推论所有「对手观察投资」机制都被支配。

## 对照组二：响应性而非固定惩罚（独立规则审查）

E1（待实测，未声称正面证明）：保留 TRACK 完整工作和报告，对手在公开 TRACK 后可以花**一次**有限干预权：指定 A/B 中一个方向，使该方向下一手 WORK 失效（而非追溯取消已完成工作）；玩家在遭遇该阻碍后可用其他方向的 WORK、SIDE、或一手清障来应对。敌手利益由其目标及玩家成功与否决定；玩家可见其已经使用干预权，但不知道其私人偏好。安全 WORK 不透露本手的类型报告，也不免费避免此前已经生效的阻碍。

与 E0 的关键差异不是加一条危险，而是**当前行动是否会让对手获得对后续行动的条件性封锁权**。玩家必须考虑「这条消息还有没有时间用？我能不能在锁定前先做好难以撤销的工作？对手会不会选择不干预以等待更重要的机会？」这里有机会改变未来合法/有效行动，属于 ADV×DISC×FOCUS 的组合候选。

但该版本至少有三项尚未排除的退化：
- **强替代**：INSPECT 100%且无代价，可先查后安全 WORK 完成目标；对手完全没机会阻碍，故最直观首手 INSPECT 策略仍获9。只靠额外的TRACK信息与封锁，不能声称 E1 会使玩家优先公开调查。
- **简单口诀**：若敌手一见 TRACK 就总用干预权阻止其方向，观察不再提供策略性信息；玩家只需常规修复/绕行。只是在已有危机打断里添固定触发条件。
- **不可逆时点**：若封锁只影响「下一手」，但玩家可用 SIDE 使其自然过期，敌手威胁可能被一手等待无害化；必须把安全 WAIT/SIDE 当成强对照，不能故意删除以制造两难。

因此 E1 尚不能认证有效。当前优先不是继续调随机百分比，而是明确双方可选动作、敌手利益和时序后寻找**双向可达的政策分叉**；再与安全检查/安全工作/免费等待和完整预编译条件动作比较。

## 横向反证：公开本身不等于真实兴趣

考虑 T 未知、玩家基于75%报告选择 TRACK_A。对手只看 TRACK_A，不能合理推断 T=A 必真；玩家也可能为了取得观测而先探错误方向。若研究者直接写“对手看到TRACK_A必知玩家真正目标为A”，等于把玩家不拥有的秘密知识无偿交给了对手。

更严格的问题是：对手看到的是**玩家当前承诺的工作方向**，而非世界真相 T，且玩家可基于线索改方向。要让暴露成为策略信号，至少需要模型化对手对后续实际工作分配的预测；若没有主动对手，只是一个随机扣减器，归并 NEG/危机压力即可。

## 同一研究者的独立反证视角（非盲Agent）

如果真实玩家在首手直接选择100% INSPECT，再把三份安全工作做完，就无需关心暴露系统。这不是玩家「钻空子」，而是作者提供了最合理的工具。若为了拯救暴露玩法，把 INSPECT 设为非法、凭空加入强制公开条款，就没有证明模式本身值得采用。

本次真正的成果是一条可迁移的**设计排除规则**：
> 当无暴露的一手完整报告与安全工作可以在兑现窗口内完整解决问题，而暴露调查的额外收益被即时剥夺时，讨论敌手从调查推断目标只是一种叙事解释，不是新的决策关系。

## 结论与证据身份

- E0：基于明示规则的策略支配证明，**阴性**。IWT01 已有强安全工具完全覆盖暴露式调查；归入 DISC/FOCUS/SIG/ADV 的退化边界，不创建独立新原语。
- E1：提出可证伪的策略性响应组合，但尚未给出双方收益、均衡或可达政策分叉的完整认证；仅保留开放问题，不夸大为数学/真人已验证。
- 无真人、独立Agent盲玩、浏览器实际试玩或Unity原生证据；不修改正式Game/Debug/精选。

下一批应跳出单次信息成本微调，先研究：**一条公开行动能否真正改变对手合法动作，且这种改变在强普通替代下仍值得玩家主动选择？** 需要明确每个主体的收益、动作时序、可见信息、至少一条正常轨迹中双方策略变化；若继续被一手 INSPECT+安全 WORK 压平，即刻停止并转向其他关系族。

## 第二轮：可响应封锁是否改变玩家的重复判断？

为避免继续套用带隐藏类型的复杂模型，先做一个**完全公开、可手算的四手反例**。目标A需要3份真实工作，完成收益10，每次SIDE收益1；玩家只有4手。SAFE工作每手+1，PUBLIC工作一次性+2（整场最多使用一次），二者都可在首手使用。PUBLIC曝光后敌手仅有1枚可封锁下次SAFE工作进度的牌，且无需为敌手虚构信息优势。这个简化协议只用于消融“响应窗口”，不拿它替代IWT01的信息模型。

- 不用PUBLIC：SAFE×3＋SIDE＝**11**。
- PUBLIC无人回应：PUBLIC(2)＋SAFE(1)＋SIDE×2＝**12**。
- **E2 持久封锁**：PUBLIC(2)后敌手宣布下一次SAFE无效；玩家若继续SAFE，消耗一次行动但没有进度，然后还需一次SAFE完成，因此最多10＋1＝**11**；玩家也可选择原本11的安全路线。公开方式的1点额外收益被对方一次响应吃掉。所谓“逼玩家转移注意力”只是固定的收益税。敌人选择必封锁即最强短口诀，不产生互相揣测。
- **E3 一轮有效的临时封锁**：PUBLIC(2)后，只在紧接着的一手SAFE受阻。玩家可以先SIDE，使敌人封锁自然过期，再SAFE完成，最后再SIDE，获得**12**。玩家的固定口诀变成“PUBLIC→SIDE→SAFE→SIDE”，敌手的威胁无成本地被等待吸收。即便加入敌手响应标签，也仍未出现真正变化的最优注意力结构。

注意 E2/E3 在“敌手任意选择封锁或不封锁”的完整二人博弈中，还需要敌手独立收益与行动合法性才能谈均衡。本轮只是**最强响应下玩家可行计划的手工穷举**；不能宣称找到了双方均衡。

### 第三轮：两个横向竞争假说及停机条件

**H1 不可隐藏的行动资格**：公开行动不仅提供更多进展，而是授予双方新的动作资格，比如取得信息必须先让对手获得一次可选择时点的封锁权。若安全INSPECT仍一手100%给出同样信息，必须证明PUBLIC还提供一项安全INSPECT不能复制的*真实能力或进度*，否则回E0。若资格仅是把下一手挡住，回E2/E3。

**H2 公开进度吸引可转移破坏**：玩家公开X，使敌手将唯一破坏资源投到X，另一个目标Y的投入遂变安全。若玩家能以无成本假行动转移敌手，又能得到全部安全进展，则应优先将其视作已知ADV01的诱饵变体；若只能毁掉一份未兑现的真实X进度，依然属于ADV01以牺牲真实库存换幸存方向的组合，而不是新原语。下一批应转向跨交锋资格、行动模式转换或结果重估等非相邻族，而不是一直给这种引诱加钟。

### 总体独立批评

这三轮的最大收获不是一个漂亮的新套路，而是**封锁须有非免费、非固定、可观察的反向计划变化**。E0有强安全信息严格支配；E2敌手必封锁把PUBLIC恢复至普通SAFE值；E3只需一手SIDE即可无害化。单纯开放敌人按钮、增加提示信息或动态危险条，尚未给玩家引入足够不同的判断活动。下次若仍无正常状态双向分叉，直接停止研究这个分支。
