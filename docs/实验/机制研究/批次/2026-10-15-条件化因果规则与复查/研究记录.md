# CAUSAL01—06：条件化规律、诊断、工作反馈与重新检查

日期2026-10-15。SSNoir长期抽象玩法模式研究。承接上一批POLICY/ORDER，主动换一类玩家心理活动：**我现在看到的成功/失败来自什么稳定规律；是否该验证已经形成的解释？** 研究仅冻结抽象规则和信息时序，不写SSNoir人物剧情、不改Game/精选/Debug。

## 历史去重先于新增规则

已阅读知识地图及原始研究：
- [DISC01生产性探查](../2026-10-13-目标生成与生产性发现/研究记录.md)已有“工作同时给情报 vs 全职检查”的强比较，信息准确率和时间阈值重要。
- [MEMORY01—04](../2026-10-15-持续信念与对象能力干预/研究记录.md)已实现稳定对象隐藏类型的多日贝叶斯学习；“持续积累信念”不是本批新发明。
- [SEM01动作语义转换](../2026-10-13-动作语义转化与通用菜单反证/研究记录.md)与[OPS01](../2026-10-13-跨期操作与可撤回承诺/研究记录.md)已反证无条件转换按钮被固定工序或完整预制菜单覆盖。
- [REC01双向动作余效](../2026-10-13-双向动作余效与操作顺序/研究记录.md)将上一次工作留给下一次工作的产出，通常一手前瞻已解释，不应与“学习隐藏规律”混为一谈。

这里的差别是隐藏对象不是人或一台“整体成功率高/低的机器”，而是**当期公开条件与所选操作如何组合才有效的一条稳定响应规则**。当期条件的识别能力本身可关闭，因此能分别检验“获得认识”和“有机会利用认识”。这仍是成熟的POMDP、系统识别、主动诊断与探索—利用问题，不认定全新数学原语。

## 冻结去名规则

每个回合环境有公共条件c∈{0,1}，两个值每回合独立等概率；玩家有A（操作0）、B（操作1）、SAFE和CALIBRATE（诊断）。

世界隐藏且全场稳定θ∈{0,1}，先验各1/2：
- θ=0：若操作a=c，则一次RUN成功概率4/5，否则1/5。
- θ=1：若操作a≠c，则一次RUN成功概率4/5，否则1/5。
- RUN成功当场+7，失败−9，结果立即可见；真实操作并非百分之百可靠。
- SAFE一整轮得到+1，没有信息。
- CALIBRATE占一整轮、当轮收益0。获得关于θ的正向/反向报告，报告与真实θ相符概率q（基准q=9/10）。可多次使用，报告不是强制真相。
- 期初公开c，之后才选动作；若禁用公开c，工作成功虽然可观察，但不同θ的每种动作在随机c下成功率均为1/2，历史不再提供用于下一轮动作匹配的θ信息。

期限n=2—7，无库存、不增加人物、无成本以外的奖励，不把玩家的已知后验直接泄漏为UI。最优策略由Exact Fraction、状态(t,belief,context)的DP求解；第二份程序另外显式记录本批诊断预算、世界状态与可达后验。每个真实θ、每轮实际c及工作/检查的随机信号，均有**独立于逆推的前向枚举核对**。

## CAUSAL01：不观察行动条件时，单纯记住成功与失败无效

以n=4为例：

| 能使用什么？ | 最优期望 | 说明 |
|---|---:|---|
| 不可见当期条件，但准许检查并可记忆 | **4** | SAFE×4；知道θ也无法选择对的操作 |
| c可见但不得保留历史/诊断后的后验 | **4** | 任何一次RUN在先验下即时期望−1，小于SAFE+1 |
| c可见、能依据RUN成功失败学习，但禁用CALIBRATE | **148/25=5.92** | 生产行动本身产生可用于后来行动的证据 |
| c可见、可主动校准q=9/10且可继续更新 | **5534/625=8.8544** | 正常最优第一手是CALIBRATE |

**解释边界**：这里θ可以完美知晓但c不可见时，成功率依然1/2。这是“隐状态知识需要公共上下文才能兑现”的证据，不是证明玩家具有科学家式因果发现体验。把它改名成机器可靠性、密码译码或调查技术，不改变数学形态。

## CAUSAL02：诊断是否值得做，由准确率与生产风险共同决定

保持n=4及原收益不变，仅改诊断准确率：

| q | 有CALIBRATE的最优根 | 禁CALIBRATE的最优根 | 当场CAL值得做？ |
|---:|---:|---:|---|
| 7/10 | 148/25=5.92 | 148/25=5.92 | 否：禁用诊断也能同值 |
| 4/5 | 173/25=6.92 | 148/25=5.92 | 是 |
| 9/10 | 5534/625=8.8544 | 148/25=5.92 | 是 |

q=4/5与单次生产结果的条件辨识强度相同，但CAL本身不会导致−9失败损失；一次工作的先验净收益是−1。因此，检查能有价值，不必意味着“检查的信息比工作更准确”，还可能因为它隔离了风险。换成更高生产报酬或更低失败惩罚，门槛也会改变（本批不拿不同报酬的根值互相做趣味排名）。

## CAUSAL03：第一次诊断后，继续观察生产结果仍有真实作用

n=4，q=9/10：
- 先花一手诊断，再无论之后工作成功失败都只听从**第一次诊断报告**，强简单基线：**213/25=8.52**。
- 可以随着生产结果继续改变后验和操作：**5534/625=8.8544**，相对固定遵从第一次诊断严格增 **209/625≈0.3344**。

这与“完全不诊断”的5.92相比，本批的两个真正不同的问题是：(a)需不需要主动第一次诊断？(b)当后续工作反对初次诊断时，还值不值得改变解释？不能只用“得分更高”概括。

## CAUSAL04：较长时间才为第二次诊断提供真实机会

五回合，q=9/10。玩家先CALIBRATE。若报告说θ=0，期初后验为P(θ=0)=9/10。接下来在c=0时选择RUN0；此时一次失败会将后验变为：

P(θ=0 | CAL正向、c0、RUN0失败) = (9/10×1/5)/(9/10×1/5+1/10×4/5) = **9/13**。

从这个**正常可达**的状态出发，尚余三手时再次CALIBRATE严格最优；如果第一次诊断已经消耗全部测试预算，就只能用其他动作。观察到一条可理解的局部循环：**诊断 → 按解释做事 → 发现矛盾 → 决定是否重新核验**。

这条具体三事件路径（首诊θ0报告、下一轮c0、RUN0失败）的概率为13/200；对称世界和对称条件还会产生类似路径，故重新检查的总概率更高。不能拿一条低概率路径充当所有玩家必然经历的故事。

## CAUSAL05：只允许一次诊断的强对照

| 五回合可用测试次数 | 根期望 |
|---|---:|
| 0 | 5419/625=8.6704 |
| 最多1次 | 7544/625=12.0704 |
| 最多2次 | 15301/1250=12.2408 |
| 不限制 | 15301/1250=12.2408 |

第二次测试比只允许一次严格增加**213/1250=0.1704**；第三次以上没有进一步效益。冻结的最优政策开始必做一次诊断；发生第二次诊断的期望次数对应概率是**13/50=26%**，因为本模型最优使用测试总期望为63/50=1.26，且两次预算已追平不限预算。

同样严格报告强上界：若开局完全免费知道θ，五回合总收益上界为**19**；若第一手花整回合获得完美真值，则上界为**76/5=15.2**。可见本批的12.2408是在不完全且有成本的认识条件下得到，不能误读成已找到理论最高效率。

## CAUSAL06：知道如何去做，不等于每次都应该再去检查

n=5时，诊断准确率q=7/10的完整版根仍与完全禁止主动诊断一致，**5419/625=8.6704**；重复低准确率检查没有价值。q=4/5时最优根6244/625=9.9904，q=9/10时达到15301/1250≈12.2408。

这不是为诊断增加“必须两次”专用剧情开关，而是由每手行动价值、剩余轮次、真实证据矛盾以及下一手能否利用诊断自然出现的策略选择。

## 最强同构批评（同一研究者的独立反证视角）

1. **纯数学上这只是两假设POMDP**。θ隐藏、c可见、结果带噪、检查耗时，和很多医学诊断、工程故障定位、机器校准可一一对应。它不是全新可认证游戏原语。
2. **生产性反馈与检查的互补**已经在DISC、MEMORY诸族出现。本批新归纳只是明确“状态规律与环境线索共同决定信息是否可用”的反事实，以及第二次核验必须超越一次检查强基线。
3. **完整连续后验不是唯一可学形式**。玩家可能只记住“诊断后若工作失败就再查一次”这句短口诀；五回合的精准DP略高于一次诊断，是严格正差，但不能证明人必须计算9/13。
4. **不能把诊断当‘科学方法’的叙事替代**。隐藏规则仍只有一位θ，公共环境每轮随机；没有真实实验者选择控制组、对象自主反应或可被外部验证的故事线。一个机器维修小游戏逐动作同构。
5. **负收益的RUN虽然形成风险，却不证明高难就是价值**。不同失败惩罚会改变诊断的占优区间。应观察玩家是否理解为何一次失败不能证明假设完全错，而不是测试其能忍受多少损失。
6. **完整免费检查严格更强**，若当前游戏提供这样的行动，弱诊断可能完全没有使用场景。必须写明检查时耗、可信度和真实可利用的公开条件。

### 额外浏览器随机分布抽样（仅对一条固定政策）

对本地Chromium版本，在同一网页内用固定种子的伪随机序列跑**2500局**，每局采取固定可读政策：“第一轮CALIBRATE，之后四轮按照第一次诊断报告与公开c执行匹配的A/B，不再参考实际工作成功或失败”。这条政策的数学期望为4×[(0.9×0.8+0.1×0.2)×7+(0.9×0.2+0.1×0.8)×(−9)] = **11.36**。浏览器实际抽样平均 **11.136**，与理论接近；脚本按宽容0.65的容差通过。**该随机抽样不是2500个真人试玩，更不是数学精确证明浏览器每种信号路径都与Python一致**，其作用只是排除网页成功率和收益存在明显实现偏差。
