# S3-V｜同一件物证在两段调查中的真实可执行用途

日期：2026-10-12。源代码依据：
- `UnityClient/Assets/Resources/Content/scenes/world/三封信.scm`（唯一主线状态源）。
- `UnityClient/Assets/Resources/Content/scenes/scenarios/巷子.scm`（第一章之后与莱恩的Scenario）。
- `UnityClient/Assets/Resources/Content/scripts/engine.scm`（`req-item` 为物品要求构造器）。

## 追溯：不先做数学的可执行因果核查

**物证来源**：`三封信.scm` 将“半包「老金牌」香烟”注册为具名物品 `cigs-item`。取信者在邮箱追逐中留下物证时，故事调用 `grant-story-item! cigs-item 1`；没取得则没有该物证，只留下逃向码头居民区的方向。这是有/无物证两种前置状态，并非所有玩家都有。

**第一次可选使用（老街东侧）**：东侧门廊进度已满（4格）、东侧回廊未满且尚未从西侧桥廊获得莱恩名字时，`node-show-cigs-at-counter` 根据 `found-cigarettes?` 生成。标题“把烟盒给柜台后的人看”；字幕明示**“物证；不掷骰。东侧回廊推进两格。烟盒他留下，你不能再带走”**。动作 `:requires (req-item cigs-item 1)`、`advance-east-gallery! 2 #f`，实质是用一次性物件换回廊进展和认出弗兰克可能的方向。

**第二次可选使用（之后《巷子》Scenario）**：实际 `scenes/scenarios/巷子.scm` 的 `node-cigs` 标题为“把烟盒扔到桌上”，要求完全相同的 `req-item "半包「老金牌」香烟" 1`。效果是莱恩对烟盒做出反应，并调用 `advance-lyon! 2`；`cigs-used?` 让本场只能使用一次。这是货栈后与莱恩相遇时的另一种因果收益，不是注释中不存在的假想内容。

## 抽象取舍与不能偷换的结论

**真正的结构是同一独一份物证，两次不同阶段的可选用途**：

> 现在把证物交给店主，换来东侧探索加快；或者把它留在身上，未来遇见莱恩时可能用它直接推动一次Scenario。

这不是同一张“进度+2”卡的两个皮肤：东侧是在探索街区，有真实空间和人物路径；莱恩Scenario是在较晚情节里使用证物要求，直接推动另一个人的形态与对抗。用途都是证据来源处代码可指认的动作，至少具有**有限资源在不同阶段的实质用途**，值得后续检查成本。

但**目前只完成静态官方源码验证**，并未实际在C#+Scheme世界会话中成对测试“交给店主后物品栏清空／Scenario失去此卡”和“保留之后Scenario允许这张卡”。`req-item` 是引擎成本/要求描述，物品耗用应以执行器会话中物品栏前后为准；没有执行就不冒称消费动态已原生验证。

还存在重要的学习与公平问题：

1. **未来用途是否对玩家公开？** 东侧字幕明确“他留下烟盒，你不能带走”，但未告诉玩家未来可能拿它与莱恩对质。玩家失去的是未知未来选项，不能按已经知道后续最优策略评价当下是否做错；必要时靠叙事提前建立保留物证可能有用的常识，而不是给秘密攻略。
2. **玩家是否总有物证？** 邮箱追逐没拿到烟时连东侧加2或莱恩物证卡都不可用。不能以人人都有香烟为数学初始状态。
3. **Scenario时的时间与风险**：`advance-lyon! 2` 不掷骰并不保证能避开所有冷静损失或换掉整个Scenario；目前没有真正与原生概率、剩余骰池和分支结局配对，不比较“省了多少动作”。
4. **西侧提前找到莱恩**：东侧同行探索卡可能已消失，届时这次可选的“交换香烟”可能不再可用；原先东／西的首路选择实际会影响物证使用窗口。
5. **信息失衡**：玩家并不知道西侧通往莱恩；若数学规划器预知先去西就较快找到结果，它还会提前知道香烟后续的Scenario可用，等于双重上帝视角。

## 裁决

**保留为可验证的“跨事件单份物证”基础关系，暂不晋升独立模式**。它通过源代码追溯证明有两处真实用途，但尚未通过消费守恒的原生对照、最强公开策略和正常可达选择统计，也无真人评价。之前的16行动东／西模型刻意未纳入它，**不能拿那份模型的零收益消融否定这个新发现**。

下一次若进入完整评估，先冻结“进度、物品数量、可见后果、未来是否知情、两个用途真实有效的阶段”；最低成本检验是在正式世界已有入口里正常达到东侧柜台，确认物证数量变化与后续Scenario该卡是否出现。禁止改旧内容来让测试通过，不能从第一章初始角色状态直接跳到尚未解锁的Scenario声称原生路径。
