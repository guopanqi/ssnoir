# R76–R78：摆脱双目标竞速的第三批研究

日期：2026-10-09。[精确数学实验（已通过 CI）](https://github.com/guopanqi/ssnoir/actions/runs/37918433181) · [源码](https://github.com/guopanqi/ssnoir/blob/main/tools/content-validator/experiments/r76_r78_diverse_relations.py)。

## R76 的反例：场面比模型重要

R76保留了位置的事实：从慢而保全证物的路线换到快但危险的另一线要付出行动力，对手警戒跟随路径。这个简化模型的新增路线选择值很小，但完全不是零。对于实际游戏，不应因为0.011328就直接晋升；还需看到玩家在中途处于哪条路、看到对手朝哪边改向，以及是否真愿意为换线放弃一颗骰。与[P18既有真实Scheme场景](../../结构候选20.md)相比，当前纸面地图非常贫乏。

## R77 的反例：信息价值 ≠ 信息行动时点价值

查情报提升效用0.289358，证明本模型下知道正确目标值得花行动。但同样初始四骰的强简单策略「首手探查或不探查，之后合理分骰」已经达到2.578582，与自由最优只差0.000624。它可以作为**信息购买基础关系**，但不能自称一套丰富的中途规划系统。下一步R80探索边做边揭示与行动回声组合，不再奖励固定开局购买。

## R78 的核心纠偏：最强反证必须包含常识性方案

若模型要求玩家第1手必须押某目标，随后公开线索，与「不可更改」对照时，赋予玩家撤回权使效用从1.497257提升到2.376149，表面增益+0.878892。

这是假阳性：现实玩家可选择**用首手等待线索，随后再下决定**。模型加入等待且计入消耗一颗骰的机会成本后，即使没有撤回权也取得2.387611；给予撤回权并不再增加收益，126根手牌均无严格增益。撤销权的强度仅是原模型强制玩家提前承诺制造的幻觉。

下一次研究如果要恢复这个议题，必须证明「等待会错失有意义的当下机会」而不是仅缩短时窗让其做不到。同时要检查主动承诺是否可能有别的奖励或代价，否则不要循环调参。
