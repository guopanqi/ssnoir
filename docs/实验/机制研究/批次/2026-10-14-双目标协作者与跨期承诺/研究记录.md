## 研究对象与预先最强反证

历史[ACT01](../2026-10-13-行动权利与自主他者/研究记录.md)已经有真实同伴自利择业造成玩家严格改选；[PS01](../2026-10-13-自利救援与改选窗口/危机补救与自利援助组合反证.md)曾发现自利帮助可被同成本条件化生产工具整树复制；[GRC01/03](../2026-10-13-可信合作与信息公开逆转/研究记录.md)已有可绕过关系导致他者拒绝参与及公开信息有害/有利的跨场景结构；[NEG02](../2026-10-13-可信协商与策略性拒绝/研究记录.md)已证明完整可核验条件合同能够压过事后付费重议。本批不重复命名这些基础概念。

真正要测：
1. 另一个人拥有两种真正不同的目标，自己挑帮哪一边，玩家因此改选——和普通公开类型化工具相比，是否有新的**玩家动作/信息/结果循环**？
2. 玩家预先限制自己未来操作，能让对方现在愿意合作吗？如果有完整同成本条件合同菜单，所谓持续修订计划还剩什么？
3. 之前合同只约束玩家：如果伙伴后来也可因自身高价值机会EXIT，“承诺即长期合作”的理解是否错误？

## MULTI：合作方有自己的A/B成果偏好，玩家依回应改选

三次玩家行动机会。A/B各需3份工作才完成，完成A得10、B得9，SIDE即时得1。第一手可SELF开始独立工作，全部3手自由分配；或者INVITE占完整1手，请另一主体贡献一次工作。后者偏好真实私有T=A/B各半，知道自己要的目标：若其支持的最终目标完成，自己得6，EXIT可获外部2，支持错误目标得0。主体看到邀请后可自主HELP_A / HELP_B / EXIT。玩家看到公开行动后剩2手A/B/SIDE。只有在伙伴实际贡献、共同目标完成时，才额外获得非同一成果的“共同认证”C（在本冻结求值中权重4）。

因A/B各需3份工作，伙伴类型A会严格选HELP_A、类型B会选HELP_B，两人自身的6都严格超过EXIT2；玩家观察其选择后分别两手做A/A或B/B。一个正常完整开局得到两个不同终局，不能事后只说“骰出更多分”。

| 起点协议/最强对照 | 玩家期望 | 独立结果与意义 |
|---|---:|---|
| INVITE + 自利伙伴 + 玩家观察回应再决定工作 | **27/2=13.5** | (P完成A,P完成B,P共同认证C,E SIDE)=(1/2,1/2,1,0) |
| 不邀请SELF，一手A连续做满 | **10** | A成功1、B0、C0 |
| INVITE但事前固定之后两手动作、不据回应改变 | **7** | 固定A/A时，T=A帮A得A与C；T=B因自己目标必败而EXIT |
| 完全普通的AUTO条件工具：等概率给A或B一份工作与同样C资格，类型公开 | **27/2** | 不仅同根，公开类型下全部最优续行、合法动作、分目标结果向量整树相同 |
| 取消C权重，邀请依然提供同样工作 | INVITE **19/2**，SELF **10** | 邀请不再占优，凸显结果身份C是模型输入 |
| SELF完成时也免费领同等C | SELF **14** | 强于INVITE13.5；C为什么不能自己取得须独立说明 |

**判断**：多目标互动与成果差异真实存在，却不构成原创“社交决策原语”的证据：玩家只需“伙伴给哪种一格，我后面两手就做哪种”，同成本可观察条件生产工具完全复刻。机器能复制动作/结果，但不必能复制伙伴偏好的**人物含义**，那是正式叙事与真人体验层面的另一项判断。分结果向量必须与总分并列；对A高度关心的玩家不一定接受50%丢A来换共同C的组合。

## COMMIT：事前自约束如何换取未来两段的合作？

另一套独立三阶段协议，不继承MULTI的A/B点数。t0协作者选择START或EXIT：EXIT给玩家SAFE3，给伙伴真实外部价值w=13/4；START让玩家立即得到初始成果8，开启随后两段工作。尚不知道后面公开的未来需求H/L，各概率1/2。

第1段工作本身价值5，三种真实不同操作：
- PAY：给玩家净2、伙伴自身价值4；保证第2段工作通道。
- COMP：给玩家净3、伙伴自身价值3；仍保证第2段通道。
- BYPASS：给玩家净4、伙伴自身价值0；失去下一段原关系维持的工作通道，第2段只能做独立BACKUP1。
- 只要第1段仍维持通道，第2段项目价值在第1段行动前公开为H=9或L=2；玩家第2段可以从已维持的通道做独立BYPASS得到价值−1。此版伙伴已经在t0授予这项维护权，**第2段没有新一次免费的退出权**。这是一项明确协议假设，见下方CONSENT独立强反证。

伙伴决定t0 START时预见玩家在H/L的行动与自己的真实收益（PAY4/COMP3/BYPASS0），若其预期收益严格超过t0外部w才START；平局明示选择EXIT。玩家可不受约束、绑定一个固定动作或选择预先真正可执行的H/L两类合同，每种未来类型各允许PAY/COMP/BYPASS中的一个：共3²=9项。

| t0行动约束及伙伴反应 | 玩家期望 |
|---|---:|
| 无约束时H自行选COMP、L选BYPASS；伙伴预见自己只得(3+0)/2=3/2<w而拒绝 | **3** |
| 真正绑定H/L都PAY，伙伴得4>w愿START | **29/2=14.5** |
| 绑定H/L都COMP，伙伴得3<w拒绝 | **3** |
| **绑定H PAY、L COMP**，伙伴期望(4+3)/2=7/2>13/4而START | **15** |
| 同最优的另一项完整合同H COMP、L PAY | **15** |
| H PAY、L BYPASS，伙伴预计2<w拒绝 | **3** |

9项合同和独立公开H/L前向轨迹已枚举。至少两项不同合同同达15，不假称唯一。一条完整事前条件合同可把玩家的未来便宜路线锁成伙伴愿意接受的条件，正是GRC/NEG成熟机制；普通预编译的9种“H动作,L动作”全部与合同逐状态同成本映射，不能把它叫作新玩法语法。

**普通强对照**：如果伙伴被迫START，即使玩家未来仍有自由选择权，初始8+(H时11+L时5)/2=**16**，大于15；原始根3完全来自其真正可退出，不是数学硬把动作奖励做低。若H/L只在第1段行动**之后**公布，合同在行动时无法依据H/L选择，最好的固定PAY/PAY仅14.5（原来及时信息下最好的完整合同15）；没有信息时差出来的0.5是及时可用信息的实际作用，不是神秘的新条款。伙伴外部w=2时可COMP/COMP、最优31/2；w=7/2时混合合同与EXIT平局而拒绝，需PAY/PAY得29/2；w=4时即使PAY/PAY平局也EXIT、只得3。上述都依冻结的严格平局规则。

## CONSENT：伙伴在后面也有EXIT选择，会推翻怎样的假设？

这是**明确不同的完整协议**，不可拿它的数字冒称COMMIT的单变量消融。t0 START现在使伙伴付真正沉没行动成本1，初始外部收益改为9/4；t1观察公开H/L后，伙伴又可自行比较：H情况下EXIT得5、L情况下EXIT得2；若CONTINUE则伙伴取得玩家条款对应的PAY4/COMP3/BYPASS0。若伙伴后期EXIT，玩家已得到的初始8仍保存，但第1、2段剩余工作合计只得到BACKUP1。伙伴在t0严格按自己“事后最优选择的期望收益−沉没成本1”与外部9/4比较，决定是否开始。两项不同承诺：只约束玩家的H/L行动，或同时可执行地**限制伙伴后来不再单方EXIT**。

| 一整套t0+t1的合法性制度 | 最优玩家期望 | 实际决定路径 |
|---|---:|---|
| 无玩家承诺、伙伴有t1 EXIT | **9** | 伙伴仍愿START；H/L事后都EXIT，玩家保留初始8+BACKUP1 |
| 只有玩家绑定最优条件合同、伙伴依然有t1 EXIT | **21/2=10.5** | H PAY、L COMP；H时伙伴看见EXIT5高于自己PAY4，离开；L时COMP3>EXIT2，继续 |
| **双方同时受可执行条件合同约束** | **15** | 同条款H PAY、L COMP；伙伴预期自利(4+3)/2−1=5/2>初始EXIT9/4而事前START，之后两类都维持合作 |

两类合同中的全部9个完整动作菜单均经过第二次伙伴选择的单独逆推和前向逐状态核验。**核心发现：玩家愿意履约与对方也被承诺约束完全不同。** 对方有时正因为看见后期能转做自己的高收益工作，才愿意先加入；其后期自主EXIT不会被玩家的单方善意取消。

如果双方互相执行承诺需要额外付真实执行成本c给玩家，双边方案收益15−c与单方最优21/2比较；c<9/2时双边方案严格占优，c>9/2时不如单边，等于9/2两种同值。这只是协议边界，不表示成本可以在正式世界里任意设定。

## 同一研究者的独立设计批评（不是独立Agent或人类试玩）

- **MULTI最强无聊口诀**：“伙伴帮哪个目标，我就把后两手全给哪个”。可学、可表达对他者目标的尊重，但玩家其实无需理解其私人理由；同成本AUTO工具严格整树复制。C的独立身份必须在内容层有实际成立条件，否则将只是为了提高INVITE而加的奖励4。
- **COMMIT最强无聊解释**：“会走便宜路线就没有人愿意提前帮忙，所以现在签一个未来可以执行的条件合同。”完整预编译菜单与事后改条款的体验差异还不能证明。外部主体的自利动机是明确的，却只在t0决策一次，不该说已有持续复杂关系。
- **CONSENT追加的真实区别**：伙伴即使t0愿START，也会在新的H机会下后撤，这是可计算的后期自利选择，不是固定随机拒绝。但玩家仍只需检查H/L条件，未获得真正的协商、信任或多目标长期关系。双边承诺免费时已是最强默认，不能通过增加菜单自称选择深刻。
- 本批模型没有欺骗、信念更新、共赢之外的私有声誉，也没有真人对伦理/好恶的表达。总效用不是人物真正值得保全的A/B/C三类结果的客观兑换率。

**裁决**：保留三个成熟组合/严格反证：（一）自主选择多种真实结果仍可能与普通条件生产工具同构；（二）已知完整条件合同能替代逐次口头承诺和重议；（三）合作权必须逐个主体核对早期及后期EXIT能力，单方可执行的承诺不自动把另一人绑定。**没有新原创原语、精选晋升或正式Debug授权**。

下一轮不再扫w或将HELP6改7。应转向**伙伴会改变自己想要的结果，而不是选择一份固定偏好A/B后贡献一次工作**的两阶段反馈；或跨交锋的两种非补偿成果如何逐场影响可做之事。先和条件AUTO、完整可执行合同、独立自救的强普通菜单比较，并以无提示玩家实际理解为最终体验补充。
