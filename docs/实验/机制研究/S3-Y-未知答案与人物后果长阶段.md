# S3-Y 长阶段｜玩家公开信息、路线选择与真实Scenario代价

开始于 2026-10-12；恢复基线 `68b24d4a8661bd5be2794d399b5de24899bc0624`。从 S3-X 已通过的三条完整 C#+Scheme 世界路线继续；禁止重复已通过的烟盒守恒、先用/后用/无烟路径。此阶段研究对象仍为**可复用的抽象决策关系**，不是把第一章改成数学关卡。

## 唯一阶段目标

验证玩家**不知道东、西路线终点和烟盒未来用途**时，是否仍有合理而可理解的注意力／物证选择；沿人物对话推进后，未获得或提前使用物证到底会影响哪些**真实可用行动、风险及见证场景**。需要严格分开“作者全知、模型求最优”与“玩家当时知道”的信息。

## 连续四个子阶段和验收门槛

1. **Y1 公开信息与隐藏结果的来源审计。** 冻结正式 `三封信.scm` 和 `巷子.scm`：首达东/西时的卡名、行动收益、线索/路线揭晓条件；交出烟盒时公开的成本；后来莱恩才出现的用途。产出四拍可读信息表与机读语义校验，不允许提前公布西侧=莱恩、东侧=弗兰克。
2. **Y2 失去物证后真正的替代行动。** 从原版第二幕形式1确认三项原生操作的属性：低风险信件、带进度及老街压力的高风险提夜莺、0骰物证。先做**静态直接消融**（有/无烟盒、移除高风险或低风险、奖励档），判断哪些风险是动作逻辑自带，哪些只是作者效用猜想。已验证原生0/1消费不重跑；仅有明确未证风险疑点才新增 C# Session。
3. **Y3 玩家信息下的强简单规则。** 将早用与保留写为不泄露未来效用的两阶段抽象，按**公开当下回报**、未知未来上下界和个人物证偏好描述策略；测试“所有人现在都该用／都不该用”是否被反例推翻。禁止用作者预知 `q,l` 的精确阈值当玩家可学攻略。核对正常可达的原生状态来自 S3-X 既有三条轨迹，不为数字利益扫概率表。
4. **Y4 归档与下一阶段分流。** 如 Y1–Y3 只有简单选择而没有新决策结构，就明确判为基础语法并停止数学扩展；将人物/路线的无提示审阅题交给异步反馈。维护批次、记忆、队列、当前状态、模式库/工作台与 CI。不能声称已有人类乐趣证据。

## 成功与负面标准

- **技术**：当前工程的原生可用/不可用、物品1→0三个路径已在 S3-X 验证；Y阶段不拿源码静态分析冒充新原生证据。新可执行审计必须带明确源码定位与反事实，若内容变化自动报错。
- **决策**：指出从一个可观察事件到下一手行为的变化、强公开简单规则、何时由单一路线支配；有条件会改变优先级或只是人物情绪差异均可归档。不要制造额外的压力钟或截止时间。
- **真人**：R37/R50/R54只作为历史约束。此情景还没有无提示真人数据，不晋升模式库精选/20候选，不进 Debug。
- **功能冻结**：不触碰正式剧情、人物/引擎/界面代码，不引入付费 API 或后台任务。提交均为简体中文。
