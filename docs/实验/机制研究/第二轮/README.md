# 第二轮试玩入口

当前优先试玩三种数学原型：

1. **研究·分段兑现**：首轮保留，目标18，储备的积累与兑现。
2. **研究·整备借力**：本轮新增，目标30；两动作，一项准备状态。
3. **研究·稳险选择**：本轮新增，目标28；两动作，没有额外状态。

在 Unity 现有调试面板的“交锋测试（直接进入）”选择相应名字。建议从无伤、技能均为1、冷静5的新局进入，先不用烟、酒、药品。规则没有故事包装；具体数值已经显示在盘面上。

先玩再看策略分析。记录哪一手犹豫、哪一手改变计划，以及改变的原因。三个候选都未经过真人体验评价，Unity 画面和触控也未由本轮验证。

32点整备压力版叫 **研究·借力紧目标**。余热转用仍可玩，当前研究优先级降低。其他带“短目标”“长目标”“无准备”的入口是研究对照。

[第二轮结果与具体反例](研究结果.md)有策略提示，建议试玩后再读。

## 当前证据

- `定稿/数学分析/`：当前八个新配置、两个旧候选，技能1与2的求解、固定策略与可达状态分析。
- `定稿/效率偏好/`：当前两个新候选偏重尽早完成的数学求解。
- `定稿/*对照/`：400局正式会话；其中64局来自参数确定后的新种子。
- `定稿/作者逐步/`与`定稿/作者回归/`：当前稳险作者局，以及32点整备原决定的版本回归。
- `定稿/终止边界/`：两个明确的回合清空与超时边界局。
- `定稿/验证.json`：404局4928步转移核对，以及37局完整观察和事件的严格回放明细。
- `定稿/版本.json`：正式内容指纹、规则文件哈希和复现工具信息。
- `探索/`：定稿前的历史版本，不能与当前结果混算。
- `目标扫参/`：纯模型结果，未配置数值不视为正式会话实验。

## 复现

新输出目录必须不存在。以下是当前版本的分析与基础192局对照：

```bash
python3 tools/content-validator/experiments/mechanism-round2.py analyze \
  /tmp/机制二轮-数学 --growth 1 2

python3 tools/content-validator/experiments/mechanism-round2.py play \
  /tmp/机制二轮-对照 --variants 整备借力 稳险选择

python3 tools/content-validator/experiments/mechanism-round2.py verify \
  /tmp/机制二轮-对照

python3 tools/content-validator/experiments/mechanism-round2.py sweep \
  /tmp/机制二轮-扫参 --variants 整备借力 稳险选择
```

`analyze --objective 效率`使用研究分数12/9/6；没有修改游戏奖励。`sweep`只改变模型目标，不写正式 Content。正式回放要求相同内容与C#构建指纹，新增其他 Content 文件也可能使已有指纹失配。
