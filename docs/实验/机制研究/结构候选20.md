# 20 种可继续深入的交锋决策模式 · 设计候选池 v1

日期：2026-10-09。目标是找出**20 种不同、值得进一步改善的决策语言**，而不是立即把20种放进 Unity 调试菜单。此池从此前75轮抽象研究与已存在的原创 Scheme 场景重新审查得出。每种都有真实源文件、可表达的判断、条件性反转假设和廉价反证；**不意味着20种已证明好玩，且不是20个全部通过人类试玩的游戏关卡**。

## 选择过程：五轮回看与归并

### 筛选循环一：资源分配与风险（P01–P04）

基础资源判断清晰，但 P01 与 P02 的差异是同一行动的概率收益 vs 有限容量下互斥兑现；P03 真正增加新信息，P04 关注骰质量分配。假如只是换骰点数没有新的判断，回退到基础原语。

**P01 稳险选择**（风险分布）。玩家判断：稳妥小进度还是波动大收益。**转折假设**：临近目标与骰质改变风险偏好。**最便宜的反证**：高额收益始终支配稳健行动。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E7%A8%B3%E9%99%A9%E9%80%89%E6%8B%A9.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P02 成果取舍**（有限容量）。玩家判断：小成果易完成还是大成果更有价值。**转折假设**：骰面与剩余机会改变目标可达性。**最便宜的反证**：全部目标都能完成时取舍消失。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%88%90%E6%9E%9C%E5%8F%96%E8%88%8D.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P03 边做边看**（行动即揭示）。玩家判断：知道部分代价后坚持还是改路。**转折假设**：新信息改变余下目标成本。**最便宜的反证**：首手总能完全定位时退化。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E8%BE%B9%E5%81%9A%E8%BE%B9%E7%9C%8B.scm)。已单独批准 Debug 试玩；可异步真人评价。

**P04 按需用骰**（能力分配）。玩家判断：哪颗骰分给哪种能力需求。**转折假设**：技能与目标门槛造成高低骰交叉价值。**最便宜的反证**：永远最高骰推进主目标。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%8C%89%E9%9C%80%E7%94%A8%E9%AA%B0.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。


### 筛选循环二：回合、恢复与信息成本（P05–P08）

P05 是半成品清零，不能错称保留进度；P06 是跨回合恢复冷静，P07 是玩家决定何时启动短窗，P08 是用一次行动购买提前信息。准备/探查若总在开局执行，降为固定流程。

**P05 整段里程碑与回合清零**（整段风险）。玩家判断：把本回合的骰子集中完成一段，还是冒险把它分到不同目标。**转折假设**：半成品到回合末会清零，剩余骰质量和完成门槛改变目标分配。**最便宜的反证**：一组目标可在任何手牌都顺序完成，固定先A再B达到最优。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%95%B4%E6%AE%B5%E5%AE%8C%E6%88%90.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P06 留力推进**（修复与推进）。玩家判断：先恢复冷静还是现在追赶目标。**转折假设**：伤势临界和剩余期限改变恢复价值。**最便宜的反证**：永远首手休息或永远不休息。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E7%95%99%E5%8A%9B%E6%8E%A8%E8%BF%9B.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P07 择时开窗**（主动启动期限）。玩家判断：准备充足后开启倒计时还是立刻出击。**转折假设**：手牌能否在窗口内兑现变化。**最便宜的反证**：窗口充裕时立刻开启固定最优。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%8B%A9%E6%97%B6%E5%BC%80%E7%AA%97.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P08 定位再搜**（花费行动购信息）。玩家判断：先定位正确路还是边试探边寻找。**转折假设**：错误路线成本和剩余骰质量变化。**最便宜的反证**：第一手固定定位接近最优。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E5%AE%9A%E4%BD%8D%E5%86%8D%E6%90%9C.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。


### 筛选循环三：兑现、维护与里程碑（P09–P12）

P09 是已积累收益的风险暴露，P10 是衰减储备的非线性转换，P11 是推进生成负担，P12 是必需目标先完成会关闭额外目标。P09 的停止阈值不能自动算作深度，P11 已有真实文字反馈但仍需要真实逐手判断。

**P09 风险兑现**（自愿退出）。玩家判断：把当前成果兑现还是继续暴露于损失。**转折假设**：失败概率与已积累收益改变退出点。**最便宜的反证**：简单阈值覆盖全部最优。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E9%A3%8E%E9%99%A9%E5%85%91%E7%8E%B0.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P10 储备衰减与非线性兑现**（储备转换）。玩家判断：现在兑现储备还是再投入一手追求非线性收益。**转折假设**：储备临界与期限衰减改变备料和兑现的价值。**最便宜的反证**：固定先备料两次后兑现。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E5%88%86%E6%AE%B5%E5%85%91%E7%8E%B0.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P11 压力预算**（推进制造问题）。玩家判断：现在赶工还是消除自己造成的后续问题。**转折假设**：压力临界与好坏骰改变修理优先级。**最便宜的反证**：一味赶工或者固定先修。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E5%8E%8B%E5%8A%9B%E9%A2%84%E7%AE%97.scm)。已单独批准 Debug 试玩；可异步真人评价。

**P12 完成主目标关闭副目标**（完成关闭机会）。玩家判断：现在完成必需目标结束交锋还是先争副目标。**转折假设**：必需目标距离与副目标可达性影响优先。**最便宜的反证**：副目标始终不值得做。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E4%BF%9D%E7%95%99%E7%BB%88%E7%82%B9.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。


### 筛选循环四：投资、承诺与对手反应（P13–P16）

P13 把现在行动换未来效率；P14 买信息且一旦押注不可逆；P15 开快线永久替换动作组合；P16 对手公开攻击领先项。这四者的因果方向不同，前三项都可能退化为开局固定投资，P16 更需排除前两手已经锁定终局。

**P13 整备借力**（当前投资未来产能）。玩家判断：花一次整备换以后更大收益是否划算。**转折假设**：剩余回合长度让投资回本反转。**最便宜的反证**：弱骰首手固定整备即最优。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%95%B4%E5%A4%87%E5%80%9F%E5%8A%9B.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P14 探查后不可逆押注**（情报与承诺）。玩家判断：耗行动查条件还是凭先验直接押定方案。**转折假设**：余下行动与信息价值改变探查意义。**最便宜的反证**：永远第一手探查。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%83%85%E6%8A%A5%E6%89%BF%E8%AF%BA.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P15 永久切换高风险动作**（承诺式动作替代）。玩家判断：稳步继续还是耗一手开启不可退的强推。**转折假设**：目标距离和剩余冷静改变开快线时机。**最便宜的反证**：第一手固定开快线。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E6%89%BF%E8%AF%BA%E5%88%86%E6%B5%81.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P16 追击领先目标**（对手公开响应）。玩家判断：故意吸引敌人去攻击较廉价的目标吗。**转折假设**：攻击针对领先进度而改变优先级。**最便宜的反证**：玩家一次下注后没有空间调整。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E7%A0%94%E7%A9%B6%C2%B7%E8%BF%BD%E5%87%BB%E9%A2%86%E5%85%88%E7%9B%AE%E6%A0%87.scm)。已单独批准 Debug 试玩；可异步真人评价。


### 筛选循环五：质量、空间与不可逆机会（P17–P20）

P17 主动退掉已获进度换结果质量，P18 对手追踪上次路径而空间路线关联损失证据，P19 早机会和晚机会不能都取，P20 关掉追兵的同时也关掉安全退路。四项都是正式 Scheme 中的有情景原型，但作者初评不能替代真人，前期版本有退化风险。

**P17 证词掺水**（进度污染质量）。玩家判断：要更多证据还是主动退进度消除误判。**转折假设**：达到目标但有污染时撤销进度更好。**最便宜的反证**：清洗总是最后固定一手。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E5%AE%9E%E9%AA%8C%C2%B7%E8%AF%81%E8%AF%8D%E6%8E%BA%E6%B0%B4.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P18 枪口认路**（追踪上次路线）。玩家判断：逃得快还是保住证物并躲避枪口。**转折假设**：敌人改盯玩家上一条路。**最便宜的反证**：最快路线无风险或枪口无视选择。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E5%AE%9E%E9%AA%8C%C2%B7%E6%9E%AA%E5%8F%A3%E8%AE%A4%E8%B7%AF.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P19 等买主现身**（窗口互斥收益）。玩家判断：现在拿确定线索还是冒险等更好机会。**转折假设**：准备衰减与未来窗口共同限制补救。**最便宜的反证**：后续机会根本不可达。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E5%AE%9E%E9%AA%8C%C2%B7%E7%AD%89%E4%B9%B0%E4%B8%BB%E7%8E%B0%E8%BA%AB.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。

**P20 封死退路**（封危险也封出口）。玩家判断：封闭威胁来源是否值得牺牲安全退出。**转折假设**：追兵紧迫度与替代出口耗时改变取舍。**最便宜的反证**：第一回合直接脱身使封门无用。[已有 Scheme 原型](https://github.com/guopanqi/ssnoir/blob/main/UnityClient/Assets/Resources/Content/scenes/encounters/%E5%AE%9E%E9%AA%8C%C2%B7%E5%B0%81%E6%AD%BB%E9%80%80%E8%B7%AF.scm)。未进入 Debug；先做研究者反证与正式轨迹审查。



## 质量层级与准入规则

- **结构入池（20）**：能够清楚指出玩家在权衡什么、什么条件让选择可能变化、有怎样的失败反例，并有真实场景资源。它们仍可能退化成强固定策略；这里只承诺有值得研究的区别，不承诺已好玩。
- **精选研究核心（原有6）**：独立的模式库继续展示最具价值的少数关系，不因数量目标强制扩容。其中 R50 动作回声虽保留历史证据，已有人类结构批评；不必因为曾入核心就留在 Debug。
- **Unity Debug 手动试玩（仅3研究场）**：R09 边做边看、R37 压力预算、R54 追击领先目标，另有剧情 Demo 8 场。此列表由 `UnityClient/Assets/Resources/DebugResearchPlaytests.json` 独立控制，不由候选池自动生成。R55 仅网页对照不等于原生入口。
- **正式成熟/受欢迎**：需要逐手原生回放、实际玩家理解/犹豫/反思的记录才逐步确认，不能用数学优胜、CI绿灯或文件数量代替。没有新玩家反馈时，Agent仍可继续研究但不谎称这层证据。

## 持续改进任务

工作没有因候选数量为20而结束：针对还没有被玩家理解的结构，逐个实行**语义不变量 → 强易懂口诀 → 禁用新增规则消融 → 正常路径是否严格值得重新规划 → 原生逐手验证 → 必要时人工反馈**。不要求每个阶段都对所有候选重复昂贵全套。

优先审查 P17/P18/P19/P20 这四种脱离纯钟数字的场面级结构：是否真的有两条可兑现的路径及触发条件；P11 与 P16 是既有真人反馈参考而非无需再改的完成品。P13/P14/P15 在原数学中可能退化为早期固定承诺，若无法反证就降级。反例与未晋升原因更新到研究记忆，不能为了保持20个数而隐藏失败。

## 给未来 Agent 的操作契约

新增每个 `.scm` 都不会出现在 Debug。只有明确通过人工试玩候选审阅，且证据写入白名单，才允许加入 Debug；仓库中所有试验原型仍可原生命令行测试。筛掉一个结构候选后，应从研究队列中提出另一种**不同因果关系**替换，不以修改目标长度或换名字补齐数量。玩家反馈异步但优先阅读。
