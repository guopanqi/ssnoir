**本轮证据（2026-10-09）**：R54已有五局人类反馈；[后续容量消融](批次/R54-真人反馈容量对照/研究记录.md)确认，5骰提升乙目标兑现，但未增加第三手严格改目标的最优路径比例。Pages 的R54仅新增可选5骰浏览器对照，正式规则不变。**当前优先邀请试玩R50动作回声**。

**在线研究工作台**（开启 GitHub Pages 后）：https://guopanqi.github.io/ssnoir/ 。可直接试玩、提交反馈、再次打开旧反馈继续编辑；使用方法和安全限制见 [Pages 部署说明](在线Pages部署.md)。

这里研究的不是故事和人物，而是**什么样的少量规则，能让玩家根据进展、信息、风险或行动后果不断作出有意义的选择**。一个结果只有胜率差异，并不能证明玩家会觉得有趣。

## 人类从哪里进入

**[打开人类研究工作台（HTML）](研究总览.html)**：研究者解释当前结论、排列最需要真人试玩的实验、给出关键观察问题；R54、R50含可直接在浏览器体验的**独立四骰示意版**，R37和R49列出正式 Unity/C# Scheme 入口。网页草图不等同正式引擎，但便于收集抽象决策体验。

工作台可填写感受、记录哪一步犹豫，自动附上浏览器示意版的操作轨迹。**导出 JSON 后上传到 [反馈/inbox](反馈/inbox/)**，研究者下次继续时需要先阅读这些反馈，并决定改变哪一项研究。[反馈步骤与协议](反馈/README.md)；[当前试玩优先级配置](试玩任务.json)。不必体验所有模型，也不必填写满每个字段。

若直接打开 GitHub 的 HTML 源代码预览而不是下载文件，交互通常不会执行。请从 [GitHub Actions · SSNoir Mechanism Research Atlas](https://github.com/guopanqi/ssnoir/actions/workflows/ssnoir-mechanism-atlas.yml) 的最新成功运行下载 `ssnoir-abstract-pattern-atlas` Artifact，解压后打开 `研究总览.html`；或在本地检出仓库后直接打开同名文件。

## 目前主要结论

[模式库 JSON](模式库.json)选出了六种目前更值得设计者关注的关系：稳险选择、推进制造待处理问题、边做边看、容量不足的成果取舍、对手追击领先目标、动作回声。**精选不等于六种都经真人验证**。R49「迟到的目标」保留为基础模式；R51–R53没有通过强固定策略反证，作为重要的停止记录保存。[R51–R54 研究证据](批次/R51-R54-结构广度探索/研究记录.md)。

数学、正式 Content 和真人观察分别成证据层级，严格不混用。详细依据请看[研究定位与评价](研究定位与评价.md)。

## Agent 每次怎样接续

- 先检查 [反馈/inbox](反馈/inbox/) 有没有新的人类反馈，判断其来自网页示意版还是正式规则；不忽略玩家对理解和重复感的意见。
- 阅读 [当前状态](当前状态.md)、[研究队列](研究队列.md)，先用强简单策略排除没有新增决策价值的结构。
- 决定下一批研究或是否需要人类试玩；按需复用 C# + Scheme 正式 Content、精确模型和严格回放，不另建游戏引擎。
- 更新批次记录、研究结论、[模式库](模式库.json)与[试玩任务](试玩任务.json)；生成并验证 HTML，保持面向设计者的入口同步。
