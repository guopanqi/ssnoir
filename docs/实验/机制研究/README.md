# SSNoir · 抽象玩法结构实验室

**研究对象：玩家反复进行的抽象决策关系。目标：发现有实质差异、值得体验、能够与其他机制组合的玩法设计模式；特别关注有限行动与注意力的有意义选择和分配。**

本目录不是 SSNoir 第一章的剧情验证或制作任务队列。场景、人物、物品和叙事结局可以用于**后来**承载已经研究出的玩法关系，但不能成为本项目的新机制探索依据。2026-10-12 已进行了研究方向清理；所有旧数据与原版研究均保留。
