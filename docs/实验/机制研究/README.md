## 试玩入口

在 Unity 的现有调试面板中，找到“交锋测试（直接进入）”：

1. **研究·分段兑现**：三个动作、一项储备。先试这个。
2. **研究·余热长目标**：两个动作、一项余热。这是余热转用的目标16版本。

建议每次从无伤的新局进入，四项技能均为1，冷静为5。为了和本轮研究条件一致，先不要使用烟、酒、药品。正式游戏仍使用现有背包规则；实验没有禁止这些物品。

这些是数学原型，说明直接展示数值关系，没有故事包装。三回合期限：第一回合入场，结束两次回合后处在第三回合，第三次结束回合即超时。提前完成会保留更多冷静。这里没有新增金币或剧情奖励。

试玩时只需记三件事：你在哪一手犹豫；你为什么改变计划；你是否愿意再玩一局。先不要阅读求解结果，以免先学会套路再评价选择。
