# 当前状态 · SSNoir 抽象玩法研究

截至2026-10-12，完成[R358–R365委托决策权](批次/R358-R365-独立目标与委托决策权/研究记录.md)、[R366–R373编写可执行规则](批次/R366-R373-可组合规则的执行与修订/研究记录.md)、[R374–R381共同规则与异议权](批次/R374-R381-共同规则与异议权/研究记录.md)、[R382–R389非线性规则迁移](批次/R382-R389-非线性规则的迁移与反证/研究记录.md)，共**32项原型内部对照检查**。所有数学脚本独立GitHub Actions成功，[跨机制质量审计](批次/R358-R389-跨心理活动质量审计/研究记录.md)并没有将它们当作32种新机制。

- **委托执行决策权**：玩家与另一个行为者各有自己的目标，授权后对方实际选择的是它自己的目标。根据上次相合/冲突调整授权，全动态**37/16**，全部27个固定授权序最优**9/4**。但“先委托、相合再委托、冲突则亲自做，末手再委托”的简短公开法已完全最优。对方仍只有一手局部目标，不能称具有持续独立生活。
- **可组合、可执行、可修订规则**：玩家通过X/Y/反转子句写自己的持久四格输出规则，在公开输入下决定执行得分或牺牲当手编辑。XOR/XNOR环境完整**111/32**，全部4096固定脚本最优**3**；最多一次编辑依旧3，两种不同子句方可产生收益。真正不同于R198只切换预设模式。
- **共同规则限制另一方行动**：玩家制定双方共享的OPEN/ONLY-A/ONLY-B规则，另一行为者有独立偏好和一次异议权。完整**7/4**、27套固定规则最优**13/8**。但首手观察其偏好后按一个简短条件策略消耗异议权也能全最优，对方不具有跨期最优策略。
- **AND/OR迁移反证**：保留运行/编辑循环，但目标不再互为补集，新增非线性子句N。在部分反馈下完整**16921/4096**，15625固定动作序最优**15/4**；单次编辑已经有正收益，推翻“必须编辑至少两个子句才值得动手”的普遍命题。这说明应关注**维持并测试自己写出的规则**，而不是特定XOR公式。
