# 抽象玩法研究：目标与评价权威

更新：2026-10-13。**本文件是研究目标与评价界限的唯一权威**。文件的职责、归档与可追溯数据流在[实验结构与维护契约](实验结构与维护契约.md)；Agent执行看 [研究Skill](../../../skills/research-mechanisms/SKILL.md)；下一题看[研究队列](研究队列.md)。历史版本原文保存在[校准前归档](归档/2026-10-12-方向校准前/研究定位与评价.md)。

## 研究对象

**这是一项长期、开放的 Gameplay Pattern Research**：研究基础机制、基础决策原语、完整Scenario模式与跨Scenario组织之间的关系，可在这些层次间双向提炼或组合。成熟游戏中已经有效采用的设计模式、Agent 的新假设、组合关系及负面边界均是可保存的知识；见[模式语言与证据地图](模式语言与证据地图.md)及[结构化知识地图](模式语言知识地图.json)。不要求每个有价值的模式都是原创，也不要求全部经过本实验室重新数学认证。


**抽象的玩法决策关系（decision patterns）**：玩家在有限的行动、时间、资源和信息中做出什么**有意义的选择与分配**；行动反馈如何改变未来机会、收益和判断；一组少量规则能否形成可反复学习、运用和变奏的玩法循环。

例子：
- **稳做/险做**：同一行动资源面前选择低波动保底，还是冒险争取高回报。
- **积累/兑现**：半成品越多未来收益越大，但失败损失和行动税也增加；何时保留、保护或兑现？
- **推进/负担**：处理核心目标同时生成未来待处理的问题；如何在推进与控制风险间重新分配注意力？
- **行动互相改变价值**：做A让下一次B更有效、但可能使下次A受到限制；怎样寻找行动顺序和转折？
- **信息/重新选择**：前一手的行动同时告诉玩家新事实，后续还能继续原路线或转向另一目标。

研究的是**重复进行的玩家活动与心理模型**，不是场景、角色、剧情、道具、叙事后果，也不是以状态数、难解程度为美的数学系统。可以完全使用抽象 A/B/C 关系研究。故事与人物是在另一个创作阶段赋予玩法感情和语境的，不可倒过来牵引机制选题。

## 什么才算一个不同的模式

一个模式应能说清：

> 玩家从怎样的公开状态出发，有什么合法行动及代价；这一次行动产生何种反馈；**下一次为什么有理由作不同判断**；这一关系什么时候退化？

新颖性判断：①换题材/换名字/改数值（不新）；②同一关系的可用变奏；③两个旧关系组合产生新的真实判断；④玩家持续活动、信息反馈或资源分配方式发生**实质不同的变化**。③④是优先的新模式研究方向；②若简单而有趣仍可作为有价值的基础积累，但不得改名凑数量。

**去剧情检验**：删掉烟盒、剧院、人物和情感结局，把全部动作改写成无名对象，若玩家仍在做同一流程，不能单凭有不同剧情结果而称新玩法。给玩家更多行动选项、目标或统计上的帕累托前沿，均不自动意味有新的判断。

## 评价维度，不打一个伪科学总分

1. **选择是否有意义**：不止一个合法按钮；至少两种可解释、会互相争夺资源/机会/后果的选项。
2. **反馈与变化**：新的状态、信息和行动后果会怎样改写优先级？**不要求每手一定改道**，可以是一条简洁而可反复运用的判断规则。
3. **清晰、可学**：规则数量、认知负担和玩家能否预测后果；高阶难解不是更好的证据。
4. **抗机械支配**：与最强可解释固定流程、公开条件规则对照；若已有策略完全解释体验，判断是否仍有值得玩的节奏，而非继续加复杂例外。
5. **实质差异与组合力**：是否超出旧模式的皮肤、相加或数字变化？玩家每轮反复做的事是否不同？可否在新局面中重新运用？
6. **体验潜力与失败边界**：什么状态会让人犹豫、发现关系或愿意重试；哪些条件退化为简单流程？保留事实与不确定性，**不能在没有玩家体验时称已证明好玩**。

**长期目标**是积累可复用、可组合、具有已知适用边界的玩法模式语言；历史“争取20种”是阶段性的广度愿景，不是研究完成条件、晋升配额或价值排行榜。失败证据和已知作品先例也应被积累。可自由提出旧名单之外的创新模式，不强制限定于三档骰面或SSNoir现有场景。

## 证据界限

| 层级 | 能证明什么 | 不能自动证明什么 |
|---|---|---|
| 成熟作品设计先例 | 某种关系已在具体作品中被实际采用，是有价值的参考起点 | 拆出单一规则后必然好玩，或适合本作所有场景 |
| 独立 Agent 盲试玩 | 在指定呈现下，另一个不知作者答案的模型能否理解、提出策略和感受问题 | 真实玩家同样理解或愿意重玩 |
| 纸面与逻辑反证 | 退化、支配、结构同构、可用边界 | 玩家实际觉得有趣 |
| 数学模型 | 冻结规则下的可能选择、策略、触发与概率 | 正式引擎一致、人类真的会如此行动 |
| 原生 C#+Scheme | 正式某版本场景规则确实会这样运行 | 此结构有新意或玩家愿意玩 |
| 真人试玩 | 理解、困惑、犹豫、重复感、愿否继续 | 对所有数值/策略的普遍数学结论 |

Agent自主持续研究，无须等待真人反馈；反馈到来时必须真正改变评价或说明为什么不改变。数学求解、原生CI、故事创作各是帮助研究的工具或其它轨道，不是本研究的中心产品。

## 工作方向与晋升边界

从[抽象探索地图](抽象探索地图-20261012校准.md)跨不同心理循环发散：写最小去情景机制卡 → 寻找强无聊基线、同构和现实退化 → 必要时做有限模型、因果对照与最小可玩示意 → 先形成设计上的判断 → 把有意义的证据归档。**不必为了每轮产出代码、正式原生场景或新Debug入口。** 鼓励先归纳模式之间的提供条件、改变价值/合法性、跨尺度兑现和相互压制关系；不以目标图变复杂或DP收益提高证明创造了新的玩法。

- [结构化模式语言地图](模式语言知识地图.json)及其[总览](模式语言与证据地图.md)容纳成熟作品先例、实验发现、组合关系和负面边界；[关系索引](关系索引.md)保留批次证据；[结构候选20](结构候选20.md)是历史候选快照；[模式库](模式库.json)只是设计师选择性呈现的视图。**被精选、被提名、经过真人反馈、数学上有优势是四种独立属性，绝非单一晋升阶梯。**
- 对玩法的真人验证通过已有[研究工作台](研究总览.html)与[试玩任务](试玩任务.json)异步组织，不把题目和数学最优提示提前告诉未试玩的人。
- [反馈原件](反馈/inbox/)不能改写；回复和复核留在[reviews](反馈/reviews/)。
- 正式第一章、道具守恒、夜莺离队属于[独立的内容历史](../正式内容验证/README.md)，已归档的原生证据仍有效，但**不属于默认机制研究队列**。
- 精选模式与人工Unity Debug白名单独立审核，未经人类/来源/质量门槛不得自动晋升。

最基本的接续问题不是“下一个NPC做什么”，而是**“玩家还有什么不同、可重复、有意思的事情可以自己判断和选择？”**


## 2026-10-13 补充：模式语言而非线性晋升漏斗

“候选”“精选”只是历史入池和人类展示集合，不是质量等级，未入选不代表无价值；它们不能代替[长期知识地图](模式语言与证据地图.md)。成熟作品的已有决策结构是有来源的应用先例，可以直接纳入学习和组合，不必当成Agent原创；但不能冒称官方分类或独立受控验证。

同时研究基础决策关系、完整Scenario决策结构及跨Scenario的注意力组织。每种发现分别记录来源、规则成立证据、可理解性/真人反馈与适用边界；负面规律也应保留。允许模式很简单、被熟练玩家迅速学会，并不因为最优口诀短而直接淘汰；不把求解器胜率优势当作趣味或原创性分数。

长期探索有三条可交叉的方向：吸收并分析成熟模式、探索基础关系及相互作用、检验与提炼边界。一次小循环可以是提出假设→独立批评→必要的建模/试玩→沉淀知识，但这四步**不是长期研究的终点**。异步真人反馈提供不可替代的体验校准，却不能成为Agent每批推进的前置条件。成果的主尺度是可复用的判断知识和结构覆盖，而非R编号或模式总数。
