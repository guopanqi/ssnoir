## Goal

为第一章小节三「教训莱恩」做**独立 Stage 空间**：煤渣路尽头的**堆场路口**（谈弗兰克）→ 过道进**修理棚**（拆穿莱恩、收铁盒）。
空间 alone 必须读得出故事；不再借用码头「三号货栈工棚」；**绝不**复用追逐 Stage「巷子」。

## Beat summary（谁 / 冲突 / 结局）

| | |
|---|---|
| **谁** | 尼尔；门口守卫**弗兰克**（摩托旁）；棚里**莱恩**；两边**屋檐下的老街人**（耐心钟 / 围人） |
| **冲突** | 幕一：证明你不是剧院打手、说清带走什么 → 换弗兰克放行。幕二：按约定小心拆莱恩三层形态（端着→翻脸→屈服），逼他自己交铁盒 |
| **结局** | 成功 `'谈`：铁盒到手、莱恩认栽停手。失败 `'被赶出去` / `'倒下`：送回路口，案子未结 |

## Story info checklist（空间 alone 必须能读到）

站在画面里、不读对白，也应看出：

1. **煤渣路尽头的堆场口**——不是码头机械实验区，是货栈后头破棚聚落
2. **黑色旧摩托**停在入口，前灯/排气管还热（弗兰克刚到）
3. **弗兰克**挡在通往棚子的过道前（车把可按烟头）
4. **两边屋檐下有人站着**——围观 / 随时围上来，不是空巷
5. **通往修理棚的过道**（幕间侧身让路）
6. **修理棚内部**：油污**工作台**；台上/旁 **生锈大管钳 + 钝口粗铁剪**（第四节灯桥疑点埋线）
7. **炉子后面的旧铁盒**（底片/照片/信；成功时他松手）
8. **破椅子**（屈服瘫坐）
9. **莱恩**：乱发、油腻旧西装、酸酒气；形态变时姿态从「倚台装样子」到「瘫椅认栽」

## Portal / Stage 模板（工程师照这个做）

**照 `巷子里在打人`（交锋）+ `租屋`（门内 Stage）契约，不要 nest 进码头工棚。**

1. `prefabs/src/<名>.py`：`coll["stage"] = True`；footprint 自洽；全部画面几何只进 `Places/<名>.fbx`
2. `city.blend`：实例放郊野舞台排（与 `租屋` / `巷子里在打人` / 追逐`巷子` 同高 Y），**不占城市地块**
3. 城市侧入口：在挂卡地点（现为 **`码头-巷口`** / 码头 Prefab）放 `PortalIn_<名>`（50mm，无 drag，站入口外看向门洞/过道）
4. Stage 身份 = **Scheme 节点名** = Prefab ID = `Anchor_<名>` = `Camera_<名>`；`:anchor` 只决定门卡挂在城市场景哪，不等于 Stage 名（见 `runtime-contract.md` / `city-box/README.md`）
5. 两幕两区：本 Prefab 内自建  
   - `Anchor_堆场路口`（外：摩托+弗兰克+屋檐人）  
   - `Anchor_修理棚` 或 `Anchor_修理棚-工作台`（内：台/钳剪/炉/铁盒/椅/莱恩）  
   scm 根节点名与上述 Anchor 对齐后，去掉对工棚的 `:anchor` 借用（或仅在世界门卡上保留进城锚点）
6. 预览链：`preview.py -- <名> --clay` → `--game`（lined）→ **用户审后再** try-list / `./build.sh`

参考实现：`prefabs/src/巷子里在打人.py`、`prefabs/src/租屋.py`；流程记在 `prefabs/review/巷子里在打人/prompts.md`。
