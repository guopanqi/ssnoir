# CS 中的城市行动和组合

## 二、《Citizen Sleeper 1》的城市究竟由什么组成？

我查了游戏的官方介绍、开发者 Gareth Damian Martin 的访谈，以及 Dragos、Ankhita、Lem、Emphis 等几条实际人物线。

首先有一个重要发现：《Citizen Sleeper 1》不是把城市设计成很多条人物任务链，而是把人物、地点、工作、资源和时间组织成一个共同的生活系统。

开发者在 Game Developer 的访谈里明确谈到，他希望描写的是城市中经常被科幻作品忽略的人：酒保、厨师、码头工人、机械师。他希望玩家通过日常工作生活，而不是不断进行战斗和冒险，来认识这些人。酒吧轮班、照顾朋友的孩子、维修旧设备、接受零工，都可以成为故事的入口。

这对 SSNoir 很重要。

因为我们的城市也有酒馆、码头、咖啡馆、剧院、老街、黑鸥号。我们不需要让每个地点都成为一个任务发布点。

我把 CS1 的城市内容分成八类。

### 1. 谋生与日常工作（Work）

这是最基础的一层。

玩家到一个地点，可以做当地人平常就在做的事情：
- 拆解废船，获得货币和材料。
- 在酒吧工作，获得收入。
- 在船坞帮忙，获得收入和工作进度。
- 做其他零工，维持生活。

它们通常是可重复行动，投入骰子，得到不同的结果。

但关键是：工作同时具有经济用途和故事用途。

比如玩家在船坞工作，不仅是为了赚钱，也因此认识了 Lem，解锁了新的工作地点，最终认识他和女儿 Mina。

所以工作不是独立于故事的刷钱系统。它本身就是故事发生的地方。

### 2. 探索与熟悉一个地方（Explore）

这是非常值得我们借鉴的一种模式。

玩家进入一个新区域，通常还不知道这里有哪些人、设施和机会。

于是可以通过探索行动逐渐熟悉这个地方。

例如在 Rotunda：
- 玩家可以探索货运站。
- 逐渐完成 Dock Watcher 时钟。
- 完成后，地图上出现新的地点：Ankhita、Sealer Dock、Overlook Bar。
- 另一个同时存在的 Havenage Watchlist 时钟，则可能导致安保人员注意到玩家，进而引出工程师 Feng。

这很有意思：同样是探索，玩家一方面熟悉了环境，另一方面也可能引起别人的注意。

它不是简单的「探索完成，获得一张地图」。

它实际上是：探索一个地方 → 认识这里的社会关系 → 解锁新的人和行动机会 → 产生新的问题。

这对 SSNoir 的老街、码头尤其适用。

### 3. 调查与发现（Investigate）

这是与我们侦探主题最相关的一类。

CS1 的调查通常不是让玩家选择三条独立的线索任务，而是把发现嵌入实际行动。

最值得研究的是 Dragos 的故事。

玩家最初在 Dragos 的废船场工作，逐渐发现一艘叫 Winter Light 的飞船有些不对劲。

于是开启新的 Drive：**Study the Winter Light**。玩家需要在废船场进行 Forensic Trawl（法证调查）。

这个行动同时具有：
- 调查进度。
- 获得废料。
- 失败时可能增加场地清理压力。

调查完成后，玩家发现这艘船并不是简单的反应堆故障，而是有人从外部攻击了飞船，并且船上曾经藏着另一名 Sleeper。

这个发现改变了玩家对这艘船的认识，也改变了 Dragos 对玩家的态度。

我认为这里有一个特别重要的设计：

线索不是一项需要收集的物品，而是玩家通过行动获得的新认识；新认识改变了接下来值得做的事情。

这是我们设计夜莺调查时最应该学习的。

### 4. 修理、建造与生产（Repair / Build / Produce）

这类故事有一个非常自然的结构：

人物遇到问题 → 玩家帮助解决 → 发现还缺少什么 → 获取材料 → 完成建设 → 世界发生变化。

例如 Ankhita：
1. 她的飞船 Ambergris 坏了。
2. 玩家帮助维修船体。
3. 维修过程中有成功进度和失败导致的 Grounded 危险。
4. 如果失败太多，维修方式会改变：Ankhita 不再让玩家碰焊枪，而是要求提供废料。
5. 修好船体之后，她发现还缺少 Shipmind。
6. 玩家需要找到或制造 Shipmind。
7. 装上之后，才进一步展开寻找 Ashton 的故事。

这里值得注意的是，失败并没有简单终止故事，而是改变了玩家接下来需要做的事情。

### 5. 资源收集、交易与交付（Gather / Trade / Deliver）

这是 CS1 很重要的城市连接方式。

比如蘑菇：
- 玩家在 Greenway 探索。
- 找到蘑菇孢子。
- 采集孢子。
- 种植。
- 等待生长。
- 收获蘑菇。

这些资源不是只为了完成一个人的任务。

Emphis 需要蘑菇作为食材，Tala 需要孢子发展酒馆的酿造业务，Riko 则在研究蘑菇的种植。

同一片区域、同一类资源、不同人物的需求，自然地联系起来。

这比给每个人单独设计一个「找到三件任务物品」的小游戏更优雅。

### 6. 照顾、帮助与建立关系（Care / Social）

这是我觉得最容易被传统游戏设计忽略的一类。

CS1 有一个很典型的例子：Lem 和 Mina。

玩家先在船坞工作，认识 Lem 和 Mina。

之后 Lem 需要工作，玩家可以帮忙照顾 Mina。

照顾 Mina 本身就是一个可重复行动：
- 投入骰子。
- 推进 A Ticket Out 时钟。
- 获得一定的能量。
- 逐渐与 Lem 建立关系。

后来殖民船即将离开，玩家必须考虑是否帮助他们一起离开。

早期的一项普通行动，最后成为一个很重要的人生选择。

这件事没有特殊的战斗系统，没有复杂的小游戏。

但它让玩家亲身经历了一个父亲努力工作、一个孩子需要陪伴，以及一个家庭想要寻找新生活的过程。

Gameplay 的价值在于玩家实际参与了什么，而不是行动本身看起来有多复杂。

### 7. 人物自主推进与时间压力（World Events）

CS1 有两类重要的时钟：
- Action Clock：玩家通过行动推动。
- Cycle Clock：随着每天过去自动推进。

两者结合，使城市不是静止等待玩家的。

例如 Dragos 的债务会随着时间推进；如果玩家没有及时帮助他，就会进入另一种解决债务的路径，甚至可能失去他的废船场。

Ethan 的追捕、Lem 的离开、其他人的计划，也会产生自己的时间压力。

这意味着，玩家不是在完成一张任务清单，而是在有限的时间和行动资源里，选择参与哪些人的生活。

### 8. 关键行动与不可逆选择（Critical Actions）

还有一种行动非常值得单独区分：

它只能做一次。

例如：
- 一次性的偷窃。
- 一次性的调查。
- 一次性的潜入。
- 一次性的关键交涉。

这类行动可能决定后续的可用路线。

玩家不能无限重试，必须考虑骰子、能力和当前风险。

这与重复工作不同。重复工作适合构建日常，Critical Action 则适合制造重要的戏剧时刻。

## 三、真正值得学习的是：这些类别如何组合

上面八类并不是八种独立小游戏。

CS1 真正优秀的地方，是让它们互相提供条件和理由。

我把它抽象成一个基本结构：

### 城市事件的基本循环

1. 人物有一个具体需要

维修飞船、偿还债务、寻找失踪的人、照顾孩子、经营酒吧。

2. 地点提供行动

工作、调查、探索、收集、交涉、照顾。

3. 行动产生多重结果

获得资源、推进时钟、发现线索、改变关系、引起危险。

4. 新的局势或需求出现

解锁地点、发现缺少的材料、认识新的人、出现新的危机。

5. 玩家重新决定如何安排行动

继续帮助这个人，转去处理另一件事，或者接受时间流逝带来的后果。

这是我从 CS1 的多条人物线归纳出的组织方式，不是游戏中的单一固定任务模板。
这里面有四种尤其重要的衔接方式。

### A. 发现线索，解锁下一项具体行动

Winter Light 就是例子。

调查发现外部攻击痕迹后，玩家不只是得到一段解释。

他对这艘船的认识发生变化，Dragos 的态度也变化，新的 Drive 随之展开。

在 SSNoir 中，应该这样做：
- 发现照片的特殊冲印标记。
- 确认照片可能来自某家照相馆。
- 回到照相馆，寻找具体的冲印记录。
- 记录引向某个人或某个地点。
- 新的调查行动因此开放。

而不是：

「获得线索 A，获得线索 B，获得线索 C，三个都完成以后，进入下一段剧情。」

### B. 人物需要某种东西，城市本身就提供获取途径

Ankhita 需要 Shipmind。

玩家可能已经在另一条故事线里获得了它，也可以自己收集材料制造。

所以不同故事线不是彼此隔绝的。

这对我们很有启发：

夜莺需要解决旧代理关系，但她需要的不是一个专门设计的「罗科调查道具」。

她需要的是可以核实的旧合同、实际付款记录，以及能够结束当前骚扰的办法。

这些东西应该来自城市原本就存在的地点、工作和人物。

### C. 人物的行动本身就是时钟

Lem 需要工作，Mina 需要照顾；殖民船也不会无限期等待。

这不是玩家接受任务以后，所有人突然开始活动。

人物本来就有自己的生活。

这也是为什么 CS1 的人物线经常能够让玩家感到时间压力，而不必不断增加新的倒计时任务。

### D. 一次行动可以同时推进多个方面

这是我最希望我们在 SSNoir 中学习的。

比如在咖啡馆工作：
- 赚钱。
- 帮露西腾出时间。
- 观察顾客。
- 可能触发一个小人物事件。
- 得到可以用于其他故事的消息。

这比为了露西单独制作一套「文学任务」更自然。

开发者自己也强调过，他希望用一套统一的抽象机制描述从与帮派成员冲突到照顾孩子这样的不同活动。

## 四、但我们也不能过度理想化 CS1

我想特别指出一个容易误解的地方。

CS1 并不是每一条人物线都拥有丰富的玩法。

很多时候，玩家依然是在重复某个动作，填充一个时钟，随后触发一段对白。

甚至它的大部分普通对话选择并不会实质改变后续剧情。根据 Neoseeker 的攻略分析，真正影响许多人物线的，反而是玩家推进了哪些时钟，以及让哪些时钟自然完成。

所以我们不应该把目标定成：

「露西每次出现，都必须有一场可玩的小游戏。」

我认为更好的标准是：

每条重要人物线至少有一两段值得玩家亲自参与的活动，其余部分通过短场景、生活变化和人物对话完成。

这也符合我们希望控制个人开发规模的方向。

## 五、露西应该怎样改？

我先给一个比较明确的判断：

露西不应该成为一个需要玩家不断帮助她完成写作任务的 NPC。她应该成为一个让玩家体验观察生活、发现人物和理解故事的角色。

她和尼尔的职业不同，但两个人其实有一个很好的共同点：

尼尔试图通过观察和调查理解人。

露西试图通过观察和写作理解人。

这可以成为她的核心。

### 建议：露西《第一个读者》

我建议把她的故事组织成一个小型的、带有观察和判断的玩法经历。

#### 第一阶段：认识她

**1. 收据背面的小说**

玩家在咖啡馆工作时，注意到露西在收据背面写东西。

她不太好意思承认自己在写小说。

她告诉尼尔，自己想写一篇短篇侦探小说，寄给一家小杂志。她还想学打字，让自己的稿件看起来更像样。

这里建立她的愿望，但不马上开始任务。

#### 第二阶段：实际行动

**2. 咖啡馆里有一个奇怪的客人**

举一个具体的故事候选：

咖啡馆里有一个固定来的老码头工人，每次都点两杯咖啡，但自己只喝一杯。

露西觉得他在等一个人。

尼尔可以在咖啡馆工作时接触这件事：
- 正常服务：观察他的习惯，顺便挣钱。
- 主动询问：尝试与他交谈，可能遭到拒绝。
- 下班后留意：看看他离开后，另一杯咖啡去了哪里。

如果玩家继续观察，发现另一杯咖啡其实是留给他已经疏远的儿子的。儿子在夜班前偶尔会来取，两人却始终没有真正交谈。

这不是一个案件，而是一段普通人的生活。

玩家可以只获得表面信息，也可以进一步了解。

#### 第三阶段：人物互动与判断

**3. 你觉得这个故事应该怎么写？**

露西拿出自己的初稿。

她想知道尼尔怎么看待这个故事。

玩家可以提出不同的理解：
- 这是一个关于父亲的故事。
- 这是一个关于两个人都不愿意先开口的故事。
- 这个结尾太温柔了，应该让事情变得更糟。

露西不一定接受玩家的建议。她有自己的审美。

但玩家的意见会影响她最后采用的故事版本。

这里真正有趣的是：玩家不只是在听露西说她喜欢写作，而是实际参与了一次创作判断。

#### 第四阶段：自主结果

**4. 她把小说寄出去了**

投稿截止日到来。

她自己决定定稿、寄出。玩家不需要再去帮她完成一次送信任务。

过几天，玩家再次到咖啡馆，看到她收到编辑的回信。

无论结果如何，她都会继续写。

如果被接受，她有一点稿酬，桌上多了一本杂志。

如果被退稿，她有些失望，但会把编辑意见贴在墙上。

之后，她开始写第二篇小说，主人公叫尼尔。

### 这里面真正的玩法是什么？

我认为不是写小说本身，而是三个活动：

| 活动 | 玩家实际在做什么 | 体验 |
| --- | --- | --- |
| 咖啡馆工作与观察 | 服务、观察、询问、留意人物 | 认识城市里的普通人 |
| 理解一个人的故事 | 根据不同信息形成判断 | 观察与推理 |
| 阅读和评价作品 | 阅读、选择解释、提出意见 | 参与创作与人物关系 |

注意，这些活动可以使用现有的骰子、工作行动和地点系统。

不需要给露西专门做一个文学小游戏。

而且它可以和日常经济系统结合：
- 咖啡馆工作本身能挣钱。
- 玩家代班，露西获得学习或写作的时间。
- 玩家观察客人，获得故事素材。
- 玩家不参与，露西仍然继续自己的生活。

一项行动可以同时服务于生存、人物关系和故事体验。

这才是我认为应该从 CS1 学习的地方。

另外，我建议把现有的「四格代班」压缩或重新设计。除非四次代班分别带来不同的体验，否则连续填四格没有足够的价值。一次有具体事件的工作经历，可能比四次重复代班更好。

## 六、夜莺应该怎样改？

我认为夜莺的问题比露西更需要结构调整。

我们不应该把她的调查做成三个同时开放的调查任务。

应该设计成一段有明确调查问题、逐渐形成认识、最终导致行动的侦探故事。

首先确定调查的核心问题：罗科究竟凭什么继续向夜莺索款？他现在又在做什么？

这比「收集三种线索」更有明确的方向。

### 建议的新结构：《银色打火机》

**一条主干，两个可选的调查准备**

**1. 认出这个人**

试唱结束，黑衣人离场。

尼尔注意到他使用的银色打火机，和雨夜曾经见过的东西相同。

这是第一次把两个事件联系起来。

**2. 经理说出他的名字：罗科**

经理告诉尼尔，他曾经是夜莺的演出代理人。

给出旧合同和索款资料。

这里正式开启调查。

**3. 检查旧合同**

尼尔发现罗科确实垫付过费用，但代理期限已经结束。

合同上的旧业务地址和一张货运凭证，提供了继续追查他的方向。

**4. 找到罗科现在的去处**

沿着旧地址追查，发现罗科把一部分旧资料和行李存放在货栈。

货栈成为下一步明确的行动目标。

以下是可选准备，不是进入货栈的硬性前置。

#### A. 查旧账

发现罗科已经收过一笔钱。

**作用：**核实真实欠款，降低结算成本。

#### B. 侧门守候

亲眼看到罗科再次纠缠夜莺。

**作用：**获得当前骚扰的证据，增加交涉筹码。

**5. 货栈对峙**

根据玩家掌握的事实，出现不同的交涉方式。

有付款记录，可以核算真实欠款。

有骚扰证据，可以要求他停止接近夜莺。

两者都有，谈判条件更好。

什么都没有，也可以直接行动，但风险和结算代价更高。

**6. 罗科离城，事情结束**

经理支付报酬。

夜莺不再需要担心后门有人等她。

她主动邀请尼尔去河边。

### 这个改动解决了什么？

第一，调查有了连续的因果关系。

玩家不会同时收到三个互不相关的任务，而是：

认出一个人 → 了解他的过去 → 核实他的索款 → 找到他 → 结束纠缠。

第二，两项可选行动有了不同的价值。

查账不是为了完成一个调查进度。

它回答的是：

「罗科到底还应该得到多少钱？」

侧门守候也不是为了完成另一个调查进度。

它回答的是：

「他现在是否还在威胁夜莺？」

这两个事实可以分别影响最终行动。

第三，不需要人为制造复杂的 AND/OR 汇合。

旧合同、货栈位置构成主干。

查账和侧门守候是额外筹码，不再是两条必须二选一的独立故事线。

第四，失败不应该让调查彻底停摆。

例如查账失败，仍然可以得到一个不完整的记录，但可能损失金钱、冷静，或者引起店主警惕。

侧门守候失败，可能被罗科察觉。

这样玩家仍然能推进，只是最终的局面发生变化。

## 七、我认为我们应该改变命运草图的使用方式

这可能是这次讨论最重要的一个结论。

你现在的两张图，本质上是 Character Fate Graph（人物命运图）。

它非常有价值，但不能承担所有设计工作。

我建议今后每个人物线都分成三个层次。

### 第一层：人物命运（Character Fate）

人物层：这个人经历什么？他的愿望、遭遇、改变和结局是什么？

你现在的草图就是这个层次。

### 第二层：玩家经历（Player Experience）

体验层：玩家在什么时候见到这个人，亲身经历了什么有趣的事情？这一段产生了什么情绪、发现或人物认识？

### 第三层：行动与决策结构（Gameplay Structure）

玩法层：玩家可以采取什么行动、消耗什么、改变什么结果？什么行动解锁下一步？哪些选择可以替代，哪些是必须的？

例如，露西的命运图可以写：

开始写小说 → 投稿 → 得到稿费 → 写第二篇小说

但玩法图应该写：

咖啡馆工作 → 观察人物 → 获得故事素材 → 阅读初稿 → 选择评价 → 看到投稿结果

夜莺也一样：

旧代理人纠缠 → 尼尔调查 → 罗科离城 → 两人亲近

这是命运。

而：

认出打火机 → 查合同 → 核账/守候 → 找到货栈 → 交涉

这是玩家实际进行的行动。

两者相关，但不是同一张图。

## 八、最后，我认为 SSNoir 应该建立怎样的城市设计原则？

结合 CS1，我会确定以下几条。

1. **每个人物都应该有自己的生活循环，而不是只有玩家触发的任务。**露西会写作，艾迪会工作，汤米会跑腿，弗兰克会照顾黑鸥号；玩家不参与，他们也会继续生活。

2. **每个重要人物至少应该有一段值得玩家亲自参与的活动。**不能只有对白，但也不需要每个人都拥有大型 Scenario。

3. **优先让现有城市行动承担多个用途。**工作既可以挣钱，也可以认识人、发现故事、推进人物生活；这比不断增加专用任务机制更有扩展性。

4. **线索必须产生新的认识或行动机会。**不要把调查变成收集线索卡片。

5. **人物的需求应该与城市的资源体系相连。**钱、物资、时间、工作、地点和人际关系，都可以成为故事的连接媒介。

6. **重要行动必须改变局势，而不只是增加进度。**完成行动之后，最好出现新的地点、新的可用行动、新的人物态度，或者新的选择。
