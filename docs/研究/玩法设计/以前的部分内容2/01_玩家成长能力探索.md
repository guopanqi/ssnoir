
# SSNoir｜玩家成长能力探索

> **研究草稿 · 2026-10-22**  
> 适用范围：城市日常行动、Scenario、后续章节的角色成长。  
> **状态：候选机制与实验问题，不是已确定的规则或已实现功能。**  
> 配套文件：[02｜Scenario局势与行动结构探索](02_Scenario局势与行动结构探索.md)。

## 先说清楚：我们想探索什么？

我们希望尼尔从一个只能凭少量骰子应付麻烦的年轻人，成长为能主动控制风险、集中力量、运用本领与自己的行事方式解决复杂局面的人。成长应该**改变玩家如何分配骰子、应对失败和选择行动**，而不只是把同样的 Clock 填得更快。

游戏已经有相对简洁的共同基础：每天有限的行动骰；以骰面决定成功／中立／失败；城市与Scenario共用金钱、冷静、健康等状态；Scenario使用进度和危险 Clock。第一幕提供低复杂度基线。我们先在这套语言中探索「属性 +1」「Push／硬撑」「集中双骰」「改变行动风险」「结果改写」「条件性能力」「行事作风」等可能性，再通过第二幕和独立原型测试它们是否具有可理解、可成长、可重复使用的策略价值。

**研究要点：把“角色自己变强”与“Scenario局势变复杂”分开。** 本文只研究尼尔与玩家自身可掌握的能力。人物意图、局势事实、承诺与风险承担者在配套文件中研究；两者最终要组合，但不要同时一次性加入正式游戏。

## 1. 已有基础与边界

### 1.1 当前设计的共同语言

- **行动骰**：日常分配数量有限；骰面为 1–6。把骰子投入城市中的工作／恢复与Scenario中的具体行动。
- **判定结果**：成功、中立、失败；行动的骰值影响概率，不应默认「成功」等于「一次 Clock +1」，还取决于该行动的效果定义。
- **进度 Clock**：表示事情做到了多少，例如抵达住处、核清工钱。
- **危险 Clock**：表示人物或局势正在恶化，例如「夜莺的恐惧」「争执升级」。
- **冷静**：与接下来一天抽取的骰子品质相联系，主动透支冷静有跨日代价。
- **健康**：与下一天可用骰子数量相联系；Scenario造成的健康损失具有延续性。不要与普通搬运失败损失冷静混淆。
- **Scenario阶段**：已有玩家行动与其他角色／敌人行动的阶段雏形；能力的作用时机需要与此对齐。

此前讨论的**判定候选概率表**如下。正式实现若有调整，以实际代码为准；本文使用它仅用于推导研究问题。

| 有效骰值 | 成功 | 中立 | 失败 |
| --- | ---: | ---: | ---: |
| 6 | 60% | 40% | 0% |
| 5 | 50% | 50% | 0% |
| 4 | 40% | 50% | 10% |
| 3 | 25% | 50% | 25% |
| 2 | 0% | 70% | 30% |
| 1 | 0% | 50% | 50% |

**关键平衡提醒**：这个概率表并不线性。4 → 5 会使失败率从 10% 变为 0%；2 → 3 则第一次获得成功可能。因此任何 `+1/+2` 都可能出现门槛效应。能力的价值应按实测行动分布与多场景模拟评估，而不是只看「平均增加几个点」。

### 1.2 希望得到的成长感

1. **可靠性**：相同情境中，尼尔不再完全依赖高骰和运气。
2. **可控性**：可以主动在当前收益、未来状态、风险类型与行动次数之间交易。
3. **表达性**：同样一个局面，不同成长方向的尼尔擅长不同解决方式。
4. **跨场景复用**：城市工作获得的能力能用于Scenario，Scenario经验也能改变城市日常。
5. **学习曲线**：先学一个操作，再在人物Scenario、复杂危机和后期高危险环境里使用它的变奏。

不要将「玩家可使用的动作越来越多」等同于「必须多出很多 HUD 按钮」；越优先考虑少数、易理解、在不同情境下能组合的能力。

## 2. 候选能力目录

以下均为待试验的候选项；编号便于持续研究，不代表最终要全部保留。

### G01｜基础能力修正：相关行动 +1

**想法**：若尼尔擅长某类事情，执行关联行动时提高其**有效骰值**，例如 `有效骰值 = min(6, 投入骰面 + 能力修正 + 临时修正)`。

可探索的通用能力类别：`身手`（搬运、追逐、脱身）、`眼力`（观察、查账、跟踪）、`手艺`（修理、设备、后台技术）、`周旋`（劝说、交涉、安抚）。这些分类只是草案，应根据真实内容中的行动标签分布决定是否保留或合并。

- 城市用途：周旋影响酒馆工作，身手影响码头搬运，手艺影响剧院零活。
- Scenario用途：眼力影响查账，周旋影响与工头交涉，身手影响雨夜危机的脱身。
- **需要验证**：是否存在过度通用的强技能？`+1` 在特定骰面区间是否把危险行动变成无风险？技能是否只是在降低消耗而非引出新决策？
- **初始约束建议**：先测试 0／+1 两级；暂不引入职业树、经验等级、多个可叠加的装备与增益。

### G02｜Push／硬撑：主动消耗冷静改变当前行动

**想法**：在判定前自愿消耗冷静，换取临时优势。它的区别在于让**今日的能力与明日的行动品质**相互竞争。

候选效果需要分别实验，**不是允许玩家一次 Push 同时得到所有效果**：

| 候选型 | 当次收益 | 研究问题 |
| --- | --- | --- |
| 提值型 | 冷静 −1 → 有效骰值 +2（暂拟） | 玩家是否会在关键时刻主动透支？ |
| 推进型 | 冷静 −1 → 成功时额外推进目标 | 是否只是强骰的固定倍增器？ |
| 风险型 | 冷静 −1 → 改写本行动的一种失败后果 | 是否给玩家新的策略，而非自动规避危险？ |
| 效果型 | 冷静 −1 → 提高某类行动的效果层级 | 是否能更好地区分谨慎行动与冒险行动？ |

**需要明确**：冷静不足能否使用；判定前还是判定后宣布；每行动／每日／每Scenario限制；是否与 G01、G03、G05 叠加；对健康和人物状态的后果是否必须事前可见。

### G03｜改变【行动】的风险类型

这是用户笔记中特别值得保留的想法：一种能力不是简单降低危险，而是**改变这个行动可能承担的危险形式**。

例如雨夜同行：

- 通常「上前喝问」的失败可能增加夜莺的恐惧。
- 尼尔以某种受过训练或具有特定行事作风的方式挡住她、独自上前，可能将风险改为自己承受冷静或健康损失。
- 这不是免费减少总风险，也不是由玩家随意选一个最轻的代价；必须存在情景上合理的行动方式与明确的承担者。

可研究的抽象变换：`风险类型 A → B`、`风险落点 X → Y`、`立即损失 → 延迟后果`。其中风险落点的情景规则与配套文件的「风险承担者」重合；**成长能力负责给尼尔更多可用的转换办法，Scenario结构负责定义具体有什么可以转换。**

测试重点：能否在不同Scenario中表达同一项能力？是否允许无代价把死亡风险转换成廉价冷静损失？风险改写后的叙事动作是否仍合逻辑？

### G04｜改变【行动】的投入类型：集中／双骰行动

**想法**：某个行动原本投入一枚骰子；成长能力允许投入两枚骰子，换取不同的可靠性、效果或执行时机。

至少应做三个**互斥实验版本**：

| 版本 | 候选规则 | 产生的取舍 |
| --- | --- | --- |
| G04-A 提值 | 消耗两枚骰子；一次行动判定；主骰有效值 +2，最高 6 | 两次机会换一次高可靠行动 |
| G04-B 合作 | 消耗两枚骰子；仍一次判定；副骰满足特定行动条件时改变结果效果 | 为行动挑选组合，而不只是堆最大值 |
| G04-C 加速 | 消耗两枚骰子；一次行动同时处理「进度／布置」两种效果，须由行动支持 | 当对手即将行动时，一步完成更复杂的目标 |

**重要**：不能默认双骰等于「免费多一个回合」，也不能允许所有行动不加辨别地投入两枚骰。动作卡必须声明自己的可接受投入方式；若涉及人物意图执行，需统一「使用两个骰子算几个玩家动作／触发几次其他人行动」——首个实验建议算**一次**，这恰恰可能改变博弈。

测量重点：它是否具有超过单纯 `+2` 的策略用途？中低骰是否获得新的价值？是否使其他行动选项失去竞争力？

### G05｜结果改写：改变一次中立或危险的结算

保留用户笔记里的两条原始规则候选：

1. **当行动将增加危险 Clock 时，减少本次增加量 1 点。**
2. **当行动出现「中立」结果时，额外获得 1 点目标进展。**

可以作为技能、专精、行事作风或每场Scenario一次的主动能力。研究时要分开比较：

- **被动常驻**：触发条件满足就生效，易理解，但可能消灭风险。
- **主动限次**：玩家在行动结算时选择是否使用，产生保留时机的决策。
- **附带代价**：额外消耗冷静、金钱或暴露另一项风险。

必须明确先后顺序：判定 → 生成候选进度／危险 → 能力改写 → 具体损伤与 NPC 行动结算；不允许先提示危险满格结局再回头撤销。不能让「中立额外 +1」变成在所有情况下都优于成功，除非这是被有意设计的特殊玩法。

### G06｜条件性规则／概率触发能力

保留用户笔记：**「当使用 xx 行动时，概率获得 xx」**。

候选形式包括：

- 进行特定标签行动时，有概率不消耗额外金钱；
- 在某类动作成功时，有概率再得到少量进展；
- 执行稳妥行动时，有概率获得可重复使用的一次小优势。

这类能力也容易出现**玩家无法理解为何生效**的问题。要同时实验确定触发版（例如每天首次满足条件必定触发）和概率触发版；所有触发需显示依据，并支持固定随机种子复现。不要只因为随机奖励看似刺激就把它当成长价值。

### G07｜行事作风：一组有身份感的特殊能力

这些是**人物塑造与能力成长的候选方向**，不是当前已经存在的职业：

| 作风 | 用户笔记的核心设想 | 可测试的玩法身份 |
| --- | --- | --- |
| 沉得住气 | 每场Scenario一次，降低一次行动造成的危险增长 | 擅长把危机压在可处理范围内 |
| 敢于冒险 | 使用「硬撑」时可增加进展，但承担更高危险 | 以更大代价换取更强爆发 |
| 懂得人情 | 有熟人实际帮忙时，某些求助行动的时间或冷静成本降低 | 擅长借助社会关系，而非凭空召唤同伴 |

获取方式候选：完成剧情动机后自主选择；通过长期行为解锁；特定人物经历提供可选资格。不要未经测试就根据玩家「刷了几次强硬行动」自动发职业；也不能让人物关系变成随叫随到的强力技能。

### G08｜成长点来源：动机、经历、掌握

可以借鉴《Citizen Sleeper》以故事 Drive／动机为成长节点的思想，但具体成长来源不应绑死主线的所有人物故事。

候选原则：

- **固定章节经历提供最基本成长**：确保跳过部分人物剧情也能面对后续难度。
- **可选人物经历提供不同的学习方式**：可能是独特行动、训练机会、作风候选，而不简单堆更多永久 +1。
- **成长点优先奖励有意义的经历，而非机械重复工作**：防止最优策略变成刷普通任务。
- **人际关系的事实与数值能力分离**：艾迪救过尼尔，是具体记忆；它不自动等于「拳击技能 +1」。

## 3. 统一设计语言：能力实际改变什么？

为了便于实现与比较，可以先把能力作用点概括为六类：

| 作用点 | 示例 | 可能改变的玩家决策 |
| --- | --- | --- |
| **概率** | 有效骰值 +1 | 哪枚骰子足以处理该行动？ |
| **效果** | 中立也能推进 1；成功多推进 1 | 是否优先使用能创造更大成果的行动？ |
| **代价** | 使用硬撑消耗冷静 | 今天的进度值不值得明天的损失？ |
| **风险** | 危险 −1；将后果改由尼尔承担 | 应该防止危险，还是承担危险？ |
| **投入** | 一个行动投入两枚骰子 | 集中解决一个问题，还是处理两个问题？ |
| **可执行性** | 学会布置、干预或特定求助办法 | 是否先创造条件，而不是直接推进目标？ |

研究的关键是：**同一能力在不同情境中引起不同策略**。只有提高平均成功率，而没有出现新的资源安排或行动顺序，还不足以证明一个能力具有独立价值。

### 候选动作处理顺序（用于实验，不是正式引擎规范）

```text
查看行动（标签 / 效果 / 风险 / 支持的投入类型）
→ 选择投入骰子（一枚或允许的两枚）
→ 宣布主动能力，支付可预见的代价
→ 计算有效骰值并生成成功／中立／失败
→ 按行动定义生成候选进展、危险与损伤
→ 在明确窗口使用允许的结果改写能力
→ 一次性应用结果，更新状态与场景事实
→ 按Scenario规则推进其他人物意图
→ 判断Scenario是否继续或结算
```

这里尤其需要统一：能力可否在知道判定结果后才使用、如何处理同时填满进度与危险 Clock、连续两枚骰是否算一个行动、以及 NPC 阶段触发时机。

## 4. 同一个能力，怎样跨三个场景复用？

| 场景 | 没有成长时 | 获得成长能力后 | 玩家新增的思考 |
| --- | --- | --- | --- |
| 第一幕《雨夜同行》 | 沿街灯走／穿暗巷，控制夜莺恐惧 | 能用 G05 在关键时压低恐惧，或用 G03 主动接下风险 | 「我愿意为她承担什么？什么时候保留能力？」 |
| 第二幕《少了十块钱》 | 直接交涉、查账、找工友作证 | G01 提高相关行动可靠性；G04 一次集中行动赶在工头收账之前查清 | 「两枚骰集中一次，还是分两步创造后手？」 |
| 第二幕《剧院复排》 | 修理设备／找伴奏／说服导演 | 手艺能力提高工作可靠性；硬撑可在最后期限前冒险 | 「把冷静透支到明天，能否换到她今晚的机会？」 |
| 后期高危险Scenario | 承担健康甚至致命风险 | 组合属性、风险改写和具体退路；不能保证救下所有人 | 「自己的能力究竟该用于谁？」 |

不要因后期风险高就给所有人永久的高加成。更有价值的是玩家真正能计划、干预和承担，但仍可能失败。

## 5. 实验方法：先证明产生了新决策

### 5.1 最小比较矩阵

| 实验 | 变体 | 检验问题 |
| --- | --- | --- |
| E-G1 属性 | 原规则 vs +1 | 平均效率之外，行动骰分配是否变化？ |
| E-G2 发力 | 无 Push vs 消耗冷静强化 | 玩家是否会考虑跨日机会成本？ |
| E-G3 集中 | 单骰 vs 双骰 | 对手可能行动时，一次可靠行动是否值得损失额外骰子？ |
| E-G4 风险改写 | 只能接受后果 vs 可以转移类型／承担者 | 是否出现有意义的自我牺牲与保护？ |
| E-G5 作风 | 不同作风单独测试 | 是否产生不同且合理的最优行动序列？ |
| E-G6 条件触发 | 随机触发 vs 确定触发 | 玩家是否能理解、预测并策略性利用？ |

### 5.2 实验环境

- 使用与正式游戏同源的判定和结算逻辑；尽量不制作另一套互不兼容的数学小游戏。
- 同一情境，固定初始状态、行动列表、人物意图以及随机种子；批量跑多个骰池与资源状况。
- 记录投入的骰子、可用能力、使用时机、结果、Clock 变化、冷静／健康变化、剩余可执行行动。
- 先分别测试单能力，再测试 `能力 × 局势结构`，避免几种能力堆叠后找不到新策略的来源。
- 人工试玩重点检查：玩家是否说得出为什么在这里使用能力，是否感到尼尔变强而不是数字被偷偷改动。

### 5.3 保留或淘汰的标准

**保留**：在至少两个不同情境中产生可解释的新选择；会改变行动时机、资源安排、风险处理或目标顺序；界面反馈足够清楚。

**继续改**：只在一种特殊剧情有效，或与其他能力重复；可能通过修改成本或触发条件改善。

**淘汰或暂缓**：始终是数学上明显的最优按钮、只能做出概率装饰、使低级工作完全失去风险与价值、或让人物行动显得与现实不符。

## 6. 与正式内容开发的先后关系

1. **保留第一幕基线**：酒馆赖账与雨夜同行用于回归测试，不为实验反复改动正式脚本。
2. **第二幕开头允许体验一种简单成长**：先比较「相关行动 +1」与其他候选，不必立刻决定永久技能树。
3. **独立验证 G02/G04**：冷静透支与双骰集中先各自实验；用同样的工钱纠纷控制比较。
4. **第二幕 C03《少了十块钱》作为首个组合原型**：选择一项已显示价值的成长能力，与「工头要收走账本」的局势意图组合。
5. **跨场景复核**：把同一能力应用到剧院复排与普通城市工作；只有成立才加入正式通用规则。
6. **作风与复杂交易留作后续扩展**：不要在第二幕第一版同时上线四项本领、Push、集中、风险转换和三条作风树。

**长期问题**：能否只用少数操作，让尼尔从「尽量应付眼前问题」成长为「有能力布置、预判、集中资源并改变局面的人」，同时让城市日常与剧情Scenario保持同一套因果逻辑？

## 7. 尚未决定的关键问题

- 基础能力到底需要几个类别？是否应按动作标签，而不是职业身份来分类？
- `+1` 是永久修正、可升级到 +2，还是少量特殊行动标签加成？
- `Push` 在判定前使用还是判定后使用？如何避免「冷静耗尽 → 次日骰子低 → 必须更常 Push」的恶性循环？
- 「集中」两枚骰的真实用途是提高数值、增加效果，还是缩短 NPC 能行动的时机？哪一种能同时成立于城市和Scenario？
- 技能与 Push 是否允许叠加到有效骰值 6，从而轻易消除失败风险？
- 行事作风是在玩家选择时确定，还是从过去行动中形成？怎样避免为刷技能而违背人物感情？
- 「改变风险类型」是通用主动能力，还是由具体行动、局势事实与承担者共同允许的选项？
- 最小成长的获取节奏怎样安排，才能使不玩可选支线的玩家也有足够能力面对后期危险？
