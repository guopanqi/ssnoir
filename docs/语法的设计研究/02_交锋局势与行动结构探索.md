# SSNoir｜交锋局势与行动结构探索

> **研究草稿 · 2026-10-22**  
> 适用范围：交锋决策结构、NPC 行动、城市日常事件与跨日责任。  
> **状态：研究假设、设计语言和最小实验方案，不代表已经实现或全部选定。**  
> 配套文件：[01｜玩家成长能力探索](01_玩家成长能力探索.md)。

## 先说清楚：我们想探索什么？

我们已经能用行动骰、进度 Clock、危险 Clock 和危机打断，表现「玩家怎样推进一件事」。现在希望进一步表现**事情本身如何变化，其他人正在做什么，以及玩家如何应对新的现实条件**。

核心方向是：**把交锋从「管理数值进度」扩展为「面对具有独立意志的人，以及不断变化的现实条件」。** 例如工头准备收走账本、艾迪准备出头、尼尔提前抄下工时记录；玩家的一次行动可能推进讨薪，也可能改变人们将采取的行动、留下证据、把风险转移给自己。城市层面则可以将承诺、合同与期限变成真实的未来约束。

这与“玩家成长能力”不同：**本文件研究的是玩家面对什么局面，以及局面怎样根据行动发生变化。** 成长能力属于玩家自身，决定他有多可靠、能够集中多少资源、能不能改变结果；局势机制决定这些能力在什么条件下有意义。两者分开研究，最终再组合验证。

**优先原则**：把这些概念当作可执行的因果规则和内容组织方式，而不是给每项概念都新增 HUD 条、资源或通用按钮。若一种抽象不能在至少两种不同情境中复用，先视为场景设计技巧，而非通用系统。

## 1. 现有基础：我们在什么系统上继续探索？

### 1.1 当前的抽象交锋

一次交锋已经可以包含：

- **目标／进度 Clock**：玩家想促成什么，例如「回到住处」「讨回工钱」。
- **危险 Clock**：什么正在恶化，例如「夜莺的恐惧」「争执升级」。
- **行动**：玩家投入有限的骰子，出现成功／中立／失败，并产生进展、代价或局势变化。
- **危机／障碍**：危险或故事条件触发短促的新问题，迫使玩家调整原有计划。
- **阶段**：在已有巷子交锋中，已出现「玩家行动 → 其他人／敌人行动」的雏形；当前研究不应从零发明完全不同的一套回合制战斗。
- **后果**：冷静、健康、钱、时间、人物关系事实等延续到城市生活。

原有研究将目标拓扑与压力动态区分为：单目标、阶段解锁、并行、替代路径、额外目标、竞速、危险积累、危机打断、目标意义反转等。**这只是整理决策结构的研究分类，不是固定的九种官方模板。** 本文的探索重点是让这些结构中的行动与状态变化更真实。

### 1.2 本文新增的对象与操作

最小候选：

- **人物意图（Intent）**：某人接下来准备做什么；满足时机与条件后实际执行。
- **局势事实（Situation Fact）**：什么条件现在成立；决定哪些行动可用、代价与结果是什么。
- **后果承担者（Consequence Receiver）**：一次危险或损失最终落在谁／什么事物身上。
- **跨日约定（Commitment）**：今天达成的承诺，在未来某个时点改变行动机会、关系与后果。

它们可以通过现有行动操作：**推进、布置、干预、承担／转移、交换、要求／索取**。这些词先作为设计语义，不要在 UI 中强迫所有场景都摆六个同名按钮。

## 2. S01｜人物意图：其他人真的会行动

### 2.1 思想

**一个人物不仅拥有状态，也拥有自己准备采取的下一步行动。** 玩家可以预见、等待、干预或利用某人的行动，但不能把他当作完全听命于主角的棋子。

与单纯危险 Clock 的差别：

- Clock 说「事情逐渐严重」。
- 意图说「如果没有改变，工头接下来会收走账本」。

第二种描述天然产生具体的时间选择和行动顺序。

### 2.2 最小可执行结构

| 字段 | 意义 | 示例 |
| --- | --- | --- |
| 执行者 | 谁准备做事 | 工头 |
| 目标对象 | 他的行动作用于什么 | 账本 |
| 意图说明 | 玩家理解的下一步 | 收走工时记录 |
| 时机 | 何时执行 | 下一次他者行动阶段 |
| 前置条件 | 必须仍然成立的状态 | 账本仍在桌上 |
| 可干预条件 | 玩家通过什么具体行动改变它 | 取得复核同意／阻止拿走／先抄下记录 |
| 执行效果 | 条件满足后的结果 | 现场查账路线关闭；账本转移到办公室 |
| 可见性 | 玩家知道到什么程度 | 看到工头把账本收进包里，意图明确可见 |

**示例规则**：

```text
意图：工头收走账本
触发：进入工头的行动阶段
若：账本仍在现场，且工头未同意当场复核
则：账本移至办公室；「直接检查账本」行动关闭
否则：该意图取消或改为其他行动
```

**需要确认的问题**：

- 他者行动是在每枚骰子结算后、每轮结算后，还是特定 Clock 条件触发后发生？
- 敌人可以同时有几个意图？首轮实验建议一个，随后再增加第二个。
- 哪些意图必须提前告诉玩家？在信息不足时，玩家怎样合理推测？
- 人物能否改变主意？依据什么事实或自有需求？
- 玩家没有参与时，人物是否仍按世界时间继续生活？应该是，但无需每个 NPC 都做高频模拟。

### 2.3 自主性与策略性如何兼容

意图不是「轮到 NPC 时掷骰随机攻击」。可以先采用条件明确的有限规则表，按角色性格决策。例如艾迪倾向保护工友，工头倾向避免丢脸与多付工资，年轻工人优先保住饭碗。玩家的干预会改变他们看见的条件，却不保证人物照办。

研究价值：一个玩家可能选择先保存证据，一个选择先劝艾迪冷静，还有一个选择迅速完成交涉。**如果无论先后都发生同样结局，意图就只是背景动画，需要重做。**

## 3. S02｜局势事实：行动能创造新的解法

### 3.1 思想

玩家除了填 Clock，还能**使某个事实成立**，进而开放／阻断行动，改变风险、信息与结果。它描述的是条件变化，而不是统一的 `成功率 +1`。

示例：

- 「尼尔抄下了工时记录」：即使工头把原账本带走，仍能提出有依据的质疑。
- 「夜莺与尼尔进入亮灯的店铺」：后续不是继续暴露在暗巷；可请求店员帮忙。
- 「剧院找到备用伴奏」：问题从修复原设备转为是否争取导演允许替换。
- 「后巷出口被堵」：某条逃离路线不可用，但可以寻找其他途径。

### 3.2 最小数据模型

| 字段 | 为什么需要 | 示例 |
| --- | --- | --- |
| 事实名称 | 玩家能理解的现实状态 | 工时记录已抄下 |
| 属于谁／在哪里 | 防止变成全城通用魔法 Buff | 记录由尼尔持有 |
| 成立条件 | 怎样创造它 | 成功查看账本并完成抄写 |
| 失效条件 | 怎样被破坏／过期 | 纸条遗失、被销毁或不再有证明力 |
| 作用范围 | 影响哪些行动与人物 | 可继续质疑工资；工头可否认其准确性 |
| 已知范围（可选） | 谁知道这一事实 | 尼尔知道，工头未必知道 |

**最小实现不要上来建立完整知识图谱。** 首个原型只需 1–2 个布尔或枚举事实，并能明确影响行动是否出现；以后如确有需要，再加入持有人、证据可信度、公开范围。

### 3.3 事实如何改变决策，而不是仅仅增添手续？

如果所有路线都必须「先造事实 A，再填进度」，那只是多了一道强制前置任务。

真正有价值的是：

- 玩家可以选择**直接解决**，更快但缺少后手；
- 可以**先布置条件**，牺牲时间换取稳定性；
- 还可以尝试**改变对方行动**，使证据不再重要。

这些路线应该都能依据当前骰池、压力、已有人脉而合理成立，不能一条路线永久压倒其余路线。

## 4. S03｜风险承担者：危险可以转移，而不是凭空消失

### 4.1 思想

一次行动出现不利结果时，不一定只增加一根全局危险 Clock。后果有**具体的承受者**：尼尔、夜莺、艾迪、证人、物品、关系或一项未来机会。

「转移风险」不是任意把坏结果扔给别人，而是玩家采取可被情境解释的方式后，**改变损失实际落在哪里**。

### 4.2 雨夜同行

夜莺的恐惧正在上涨。尼尔上前挡住可疑者，可以让她先去亮处等候，但这使尼尔可能遭到推搡或受伤。

```text
普通穿过暗巷：失败 → 夜莺恐惧增加
尼尔留下挡住来人：失败 → 尼尔冷静／健康可能受损
但：前提是夜莺已经能走向安全位置，尼尔确实暴露于对方
```

关键不是 `恐惧 -1` 换 `健康 -1` 的抽象商店，而是「谁被暴露在风险中」随具体动作改变。

### 4.3 工钱与后期危险

- 艾迪替年轻工友出头，可能使工友免受针对，却让艾迪的工作机会受威胁。
- 弗兰克介入协调，可能暂时保护工友，但他要承担新的谈判责任或信誉风险。
- 尼尔后期替夜莺挡住危险，可以让她脱身，却使自己的健康处于不可逆风险之下。

需要把「减轻危险」「推迟危险」「改变危险类别」「改变危险承担者」区分清楚。前两者未必产生人物伦理问题；后两者更有黑色电影的情感张力。

**设计限制**：危险转换必须提前告知主要后果，并由具体行动、环境与人物意志允许。不能无限把高代价损失转移成廉价损失；如果涉及其他人替主角承担，应考虑其意愿与后续关系，而非用人物当防御值。

## 5. S04｜城市中的承诺、约定、合同与交换

### 5.1 思想

玩家今天答应的事，可以改变明天有多少时间、能选择哪些机会，以及别人为什么相信或不相信他。**承诺是一种未来约束，而不只是好感对白和任务列表。**

例如尼尔答应星期五替露西顶班，随后艾迪同一天希望他帮忙处理工钱纠纷。玩家不仅要选「做哪一条支线」，还得考虑自己曾经答应别人什么。

### 5.2 区分几个概念，不要都做成同一种“任务”

| 概念 | 候选含义 | 是否一定需新系统 |
| --- | --- | --- |
| **需要** | 人物或城市对象存在尚未满足的需求，例如食物、工作、保护、证据 | 不一定；可由已有状态或事件条件表达 |
| **约定／承诺** | 一方答应未来行动，产生时间与关系期待 | 可以是有截止时间的状态事实 |
| **合同** | 双方约定交付、报酬与违约后果 | 可扩展现有委托结构，不必另设“合同点数” |
| **交换** | 现在给予某物，以获取行动、信息或未来条件 | 现有金钱／物品／人情与局势事实可表达 |
| **强制** | 地位、权力或威胁使人物受到不能轻易拒绝的要求 | 应表现实际施压者与拒绝代价，而不是自动禁用按钮 |
| **索取** | 一人主动向另一人要求金钱、信息、帮助或承诺 | 可作为有明确受众与谈判空间的行动 |
| **过期** | 一项机会、承诺或证据的有效期结束 | 需要可靠的世界日程／阶段触发 |

这里的「需要／强制／索取／过期」保留为用户笔记提出的**待研究概念词**；定义只是便于实验的工作解释，不宣称已经有统一数学模型。

### 5.3 最小约定对象

```text
约定：替露西顶班
发起人：露西；承诺者：尼尔
发生时间：星期五下午
预计成本：当日工作机会／行动骰
履行条件：尼尔到场工作，或提前安排被她接受的替班
过期条件：当日下午结束
履行后果：露西有机会去报名
违约后果：按事前通知、不可抗力、失约原因呈现不同反应
```

**重要**：人物不应因为玩家没接任务就停在原地。露西在玩家缺席时仍可另想办法；真正变化的是尼尔有没有履行自己主动作出的承诺。

### 5.4 城市层面可能的新策略

- 接受一个约定，意味着主动占用未来时间。
- 提前交付金钱寻找替代履约方式，可能保留时间，却加重经济压力。
- 一个角色可能主动要求改变原协议；玩家可以同意、拒绝或协商。
- 合同与索取可以引出不平等权力：经理给尼尔工作机会，但要求他为公司做事；可以接受、拒绝，或寻找替代手段。
- 截止时刻与他人独立行动互相作用，可产生不同于单场交锋的多日策略。

避免所有约定变成密密麻麻的待办事项。优先只设计少数值得关心、明确且可被玩家理解的未来承诺。

## 6. S05｜动作语义：推进、布置、干预、承担、交换、索取

这些是对内容与规则的**设计动词**，用于检查是否提供了真正不同的操作方式；它们不必成为统一 UI 的动作按钮。

| 操作 | 玩家希望改变什么 | 常见代价 | 场景例子 |
| --- | --- | --- | --- |
| 推进 | 让目标 Clock 更接近完成 | 消耗骰子，承受失败风险 | 把夜莺送往住处；索回工钱 |
| 布置 | 建立对未来有用的条件或事实 | 当下不直接推进目标 | 抄下账目；找到备用伴奏；确认退路 |
| 干预 | 阻止、延迟或改变他人意图 | 时间、关系或新的危险 | 劝艾迪冷静；让工头暂缓收走账本 |
| 承担／转移 | 改变不利后果由谁承受 | 自己或他人的实际损失 | 尼尔挡在夜莺前面；艾迪替工友出头 |
| 交换 | 用金钱、服务、承诺换条件 | 当下资源或未来义务 | 请人作证；答应经理交换信息 |
| 索取／要求 | 向某个对象主动提出请求或施加要求 | 被拒绝、关系、升级冲突 | 要求工头复核；要求导演允许清唱 |

同一个具体行动可以同时具备两种语义。例如「把账本拍照留证」既是布置事实，也可能刺激工头的意图；「答应帮弗兰克办事」既是交换，又是未来承诺。**不要为了分类纯洁而禁止合理组合。**

### 动作的最小信息

```text
动作名／场景描述：玩家做了什么
需要条件：为什么现在能做
资源投入：一枚骰子、钱、冷静，或其它明确代价
结果分支：成功／中立／失败分别意味着什么
目标变化：进度与危险变化
局势变化：创造、破坏或使用哪些事实
他者反馈：会触发、取消或改变谁的意图
承担者：有后果时由谁实际承受
```

设计时先从剧情行为写动作，然后看其中有哪些可以复用的关系，避免用固定抽象模板反向生产所有剧情。

## 7. 三个完整情境的小规模原型

### S-A｜第一幕《雨夜同行》：最小回归样本

**情感目标**：怎样让一个害怕的人，感到与你待在一起是安全的？

- 目标 `回到住处 0/4`；危险 `夜莺的恐惧 0/3`。
- 基本行动：沿街灯走／穿过暗巷。一次短促的「街灯下的人影」障碍。
- **意图候选**：恐惧过高时，夜莺明确表示想去亮处叫车；她自己执行，不必等尼尔点选。
- **局势事实候选**：已经进入亮灯店铺；店员愿意提供帮助；某条巷子被堵。
- **风险转移候选**：尼尔留下上前查看，夜莺先前往安全处；失败后可能由尼尔承担损伤。

这场戏初期**不应强行加入所有新系统**，主要用于验证新增机制不会破坏第一幕简洁性，以及是否仍能表达夜莺的独立意志。恐惧满格不等于她莫名其妙冲进危险处；应有可理解的安全去向。

### S-B｜第二幕《少了十块钱》：第一优先实验

**基础局面**：年轻工人少拿工钱；艾迪替他争辩；尼尔可以介入；弗兰克有机会协调。

| 对象 | 目标与状态 | 独立行动 |
| --- | --- | --- |
| 尼尔 | 争回工钱／保护艾迪工作 | 查账、谈判、找人、放弃 |
| 工头 | 争执不要扩大／不轻易认错 | 准备收走账本；可能威胁停工 |
| 艾迪 | 替工友出头 | 可能继续争辩，即使尼尔不介入 |
| 年轻工人 | 拿回应得收入，同时保住饭碗 | 可能要求大家别再闹大 |
| 弗兰克 | 维护工人日后的生计 | 可能出面调解，但有自身条件 |

**首个最小版本只实现两个新变化**：

1. `Intent: 工头准备收走账本`；玩家经过一轮行动后可能执行。
2. `Fact: 已经抄下工时记录`；即使账本被收走，仍能通过另一种方式要求复核。

先只给 1 个明确意图、1 个可以创造的事实，沿用原来的 `讨回工钱` 与 `争执升级` Clock。其余人物可维持预写事件和对白。

**最重要的验收问题**：

- 玩家是否有理由直接交涉，而不是必定先抄账本？
- 在工头行动前后，同样一枚骰子的最佳去处是否发生变化？
- 艾迪、工人和工头是否表现出自身目的，而不是仅作为尼尔的奖励容器？
- 玩家失败或不参与时，事件能否继续，并留下合理余波？

### S-C｜第二幕《剧院复排》：跨情境验证

**基础局面**：伴奏设备故障、导演考虑中止赞助人试演、夜莺坚持寻找展示机会。

- 意图：导演准备叫停；夜莺准备自行提出清唱。
- 事实：备用伴奏已找到、某台设备故障、后台人员答应帮忙。
- 行动：修设备（推进技术准备）、找备用（布置替代条件）、与导演交涉（干预意图）、接受清唱（改变原目标而非单纯失败）。
- 代价：时间窗口、工作机会、夜莺对自己演出的判断；不应让尼尔修好机器成为她能否实现梦想的唯一条件。

若「事实 × 意图」只在工钱纠纷成立，在这场试演完全失去意义，说明尚不能称为通用机制。

### S-D｜后期持枪威胁：远期压力测试（暂不制作）

玩家需要让同行者撤离，同时有人持枪、另有人准备报警或逃跑。意图与风险承担者在高危险局面中更加重要。可以借此检验通用规则的扩张能力，但**致命危险必须明确预告、动作与后果可理解；不能把任意骰子失手直接等同于无预警死亡**。

## 8. 推荐的统一两阶段结算（实验协议）

用户已经确定过「玩家行动，然后其他人物行动」的阶段雏形。可先用下述协议测试，而不重写正式架构：

```text
① 呈现当前目标 Clock、危险 Clock、局势事实及可见人物意图
② 玩家选择一项具体行动，满足条件后投入骰子
③ 结算成功／中立／失败，产生目标进展、风险与事实变化
④ 若成长能力允许，对该次结算进行明确且有限的改写
⑤ 更新状态，检查是否已经形成关键结局（如人已安全离开）
⑥ 若交锋仍持续，进入其他人物阶段：按时机与条件执行意图
⑦ 根据新的局势开放、关闭或修改行动
⑧ 返回①；结算结束后记录具体人物和世界事实
```

**尚未定稿的优先级问题**：

- 若玩家行动同时填满目标与危险 Clock，优先完整成功、部分成功还是危险先发作？应由场景规则明确，而非引擎随意决定。
- 他者意图若在阶段末执行，玩家是否有足够信息提前应对？
- 一次双骰「集中」算一次玩家行动还是两个？首个原型建议算一次，但这会显著强化集中能力。
- 一次行动改变事实导致意图条件不再成立时，应先重新验证条件，再决定是否执行。
- 在城市中的跨日意图是否需要完整的回合模拟？初期只需世界事件截止日期与少量关键条件，不必逐小时模拟全城 NPC。

### 关于 UI 与表现

- **Clock**：只有真正需要积累、存在阈值的东西才显示为条。
- **意图**：用人物动作、简洁一句话或提示，表示「他接下来要做什么」；不是每个人头顶永久多一根 Clock。
- **局势事实**：可见证据、出口、道具和环境变化优先通过场景呈现；若影响后续行动，可以在动作说明中明确条件。
- **危险承担者**：行动确认时说明主要风险落点，结算动画和人物对白应回应真实后果。
- **约定**：在需要时显示到期日期与履行条件；不要把全部日常对话变成任务管理面板。

## 9. 机制之间值得优先探索的组合

| 组合 | 可能产生的新策略 | 主要反例与风险 |
| --- | --- | --- |
| 意图 × 事实 | 提前保全关键证据，抵消对方后续行动 | 若抄证据永远必选，只是强制前置 |
| 意图 × 双骰集中 | 一次关键行动消耗更多骰子，却可能减少对方介入机会 | 集中可能成为所有限时交锋的标准答案 |
| 事实 × Push | 透支冷静快速建立一项有利条件 | 冷静成本过低导致无限预备 |
| 风险转移 × 行事作风 | 擅长保护别人的尼尔可承担特殊后果 | 旁人变成可牺牲的数值容器 |
| 约定 × 独立人物意图 | 他人在未来自行行动，玩家必须协调或违约 | 沦为拥挤、琐碎的待办管理 |
| 合同交换 × 事实传播 | 用现实资源、证据或承诺获取帮助 | 无法解释为什么对方会接受交易 |
| 信息的已知范围 × 意图 | 玩家控制谁知道某件事，从而改变其行动 | 为首轮实验加入完整信息图谱过早、过重 |

**组合成立的证据不是结构图更复杂，而是同样一组骰子与状态下，玩家出现多种具有因果理由的策略。**

## 10. 实验与正式开发的安排

### P0｜固定基线

- 保留第一幕的可回归交锋版本，包括酒馆麻烦、雨夜同行；提取与现有系统同源的判定和 Clock 结算逻辑。
- 给实验增加固定随机种子、可导出的行动日志、初始局势快照；不要为了研究另造一套不一致的规则。

### P1｜先证明一个意图与一个事实有价值

- 在第二幕工钱纠纷中，只增加工头收账意图与抄账事实。
- 比较 `仅 Clock`、`Clock + 意图`、`Clock + 事实`、`Clock + 两者` 四种版本。
- 观察行动顺序、任务结果、损失与可行路径，而不仅是平均完成时间。

### P2｜和玩家成长机制组合

- 从配套文件中选择一项已验证的能力（例如集中双骰或主动硬撑）加入同一个工钱场景。
- 比较：无成长无局势／仅成长／仅局势／两者都有；检验是否出现单独机制无法带来的策略。
- 若相同局势只剩一条明显最优路线，优先调整成本和意图时机，不急于增加新对象。

### P3｜第二个情境复用

- 将相同的 `Intent / Fact` 规则用于剧院复排，检验它是否能描述完全不同的人物目标和环境变化。
- 再试一次简单的风险承担者调整；跨日承诺作为生活原型单独验证。

### P4｜筛选并接入第二幕

- 正式内容开发可继续推进旧街、新工作、夜莺彩排、露西报名；不必等待所有机制实验完成。
- 首个第二幕集成版本最多吸收 1–2 种已验证的通用新机制，其余留在研究队列。
- 记录机制成功案例、失败反例、用户体验反馈；后续第三／四幕再探索规模更大的多人物意图、证据传播、合同与强制。

### 怎么判断实验是否值得保留？

1. **有决策差异**：玩家会因为人物将要行动或事实已经变化，而重新安排动作顺序。
2. **有多种合理策略**：不存在对所有骰池与人物状态都明显统治其他选择的固定套路。
3. **人物保持独立**：NPC 不会因玩家不点击而永远暂停；不同人物的行为符合其处境。
4. **结果能被解释**：玩家知道为什么一个行动突然不可用、为什么危险由某人承担。
5. **能跨情境复用**：工钱与剧院都能运用，不需要为每个场景另造一套隐藏规则。
6. **有叙事后果**：后续生活记住具体事件，而不是只存储抽象关系分数。

## 11. 当前需要持续探索、而不必急着定稿的问题

- 「局势事实」究竟是普通脚本标签、拥有持有人和持续时间的对象，还是更一般的世界状态？在什么规模下升级抽象才值得？
- 人物意图的时机应与「每次玩家行动／每轮其他角色行动／特定剧情节点」怎样对应？
- NPC 意图何时公开、何时隐蔽？隐藏行动若无法预知，会不会破坏策略公平性？
- 一个意图被干预失败后，人物应继续原计划、升级为更危险行为，还是改用其他手段？
- 风险转移要在判定前选定还是结果之后才可主动发动？与玩家「改变行动风险类型」的成长能力如何分工？
- 「需要、索取、合同、强制、过期」之间能否总结出共同的对象模型，还是应维持为叙事动作／状态条件？
- 时间成本是玩家一枚骰子、一个完整日程窗口，还是他者行动阶段？不要无依据地用统一计量代替真实时间概念。
- 是否有可能从人物意图与局势事实自然发展出更高级的「证据传播／故事版本」玩法，而无需制作全面的名声系统？

> 本文的目标不是立即发明完整的交锋 AI 或都市模拟器，而是让少量可执行条件产生新选择。优先证明最小关系：**我行动后，别人会按自己的意图行动；我的行动能先改变现实条件，从而改变下一次可以做什么。**
