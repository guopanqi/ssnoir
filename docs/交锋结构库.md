# 交锋结构库

> 交锋设计的结构参考。来源:Citizen Sleeper 1/2 的合同语法、其祖先
> Blades in the Dark 的时钟语法,以及现有原语(clock / turn-rule /
> define-rule / 单位闭包 / 阶段 flag)的可行组合。
> 每种结构给出:钟表形态、它测试玩家的什么、本作的适用场景、实现要点。
> 夜莺线已用的结构标注 ★。用法原则见文末 §7。

## 1. 时间与压力类

### 1.1 赛跑 ★(警告)

- **形态**:目标钟(玩家推)vs 危险钟(自动走 + 坏结果追加)。
- **测试**:效率——每颗骰都在和时间换。
- **适用**:审讯、拆解、抢救、任何"在事情恶化前办成"。
- **要点**:最基础的形态,也最容易滥用;连用两场就该换结构。

### 1.2 守局 ★(抢人)

- **形态**:胜利钟**自动走**(援军/黎明/涨潮),失败钟由敌方推;
  玩家动作全部是防御,不直接产生胜利。
- **测试**:止损与分诊——不求赢,只求撑到转机。
- **适用**:守店、守人、守夜、等巡警、等涨潮开船。
- **要点**:时间反转是它的全部新鲜感;玩家第一次发现"熬"是动词。

### 1.3 加速压力

- **形态**:危险钟的每回合推进量随回合数递增(1→2→3)。
- **测试**:前置投入——晚打的每一颗骰都更贵。
- **适用**:火灾、失血、风暴逼近、消息扩散。
- **要点**:与赛跑同骨架,曲线不同;开场就要在文案里预告"它会越来越快"。

### 1.4 警戒阶梯

- **形态**:危险钟不是满格即败,而是**分档改规则**:2 格守卫起疑
  (判定加难/修正消失),4 格封锁(部分动词消失),6 格才失败。
- **测试**:风险管理——玩家自己决定在哪一档收手。
- **适用**:潜入仓库、赌场出千、在警局眼皮下办私事。
- **要点**:把"失败"从悬崖变成斜坡;每档的规则变化必须在钟备注里预告。

### 1.5 慢交锋(跨日危机)

- **形态**:交锋结构长在城市里——危机钟按**天**走而非按回合,
  每天在地点提供 1–2 个应对动词,与日常生活抢同一个骰池。
- **测试**:生活与危机的并行调度。
- **适用**:酒馆被盯上的那几天、疫病、河水上涨、罢工。
- **要点**:引擎上这是"带钟的地点",不是 encounter;
  但设计语法与交锋同构,是城市与交锋之间的桥结构。

## 2. 目标形态类

### 2.1 多目标取舍 ★(货单/账袋)

- **形态**:主目标之外若干副目标钟,时间只够填一部分。
- **测试**:贪婪管理——要哪个、放弃哪个。
- **适用**:任何赛跑/守局的加料;副目标最好在**别处**兑现(跨场报偿)。
- **要点**:副目标错过就永久错过,才有重量。

### 2.2 见好就收(push-your-luck)

- **形态**:每次行动累积收益(战利品/情报),危险同步上升;
  **"离开"动词永远可用**——随时结算带走已得的;失败则吐出一部分或全部。
- **测试**:贪心的自知——赌桌结构,银行你自己开。
- **适用**:废仓库搜刮、赌局、趁乱打劫、翻尸体口袋。
- **要点**:引擎上 end-encounter 随时可调,天然支持;
  结算文案要按"拿了多少"分层。

### 2.3 谱系结局(谈判换价)★(了断·最后报价的雏形)

- **形态**:没有二元胜负,只有**条款谱系**——钟的最终位置决定成交价
  /条件;玩家可随时拍板,拖得越久条款变动(可能更好也可能更坏)。
- **测试**:见好就收的社交版;对"够了"的判断。
- **适用**:讨价、谈判、分赃、招安。
- **要点**:结局按钟位分 3–4 档写文案;它把 roll 的方差直接翻译成故事差异。

### 2.4 隐藏胜利条件(侦探场)

- **形态**:终结动词开局是锁着的;调查动词逐步揭示"哪个假设为真"
  (三个嫌疑人/三种说法),对错误假设行动有代价,对正确假设行动即终结。
- **测试**:先想后动;信息的价值。
- **适用**:指认勒索者、辨认卧底、拆穿骗局——**侦探游戏的本命结构**。
- **要点**:线索揭示用 flag 开关动词;错误指认的代价必须真实(危险钟大跳)。

### 2.5 精确序列(仪式)

- **形态**:若干步骤钟必须**按顺序**完成,每步一种判定;失败不推
  危险钟,而是把当前步骤清零/加成本。可叠一条软时限。
- **测试**:手艺与节奏——有限骰子在固定工序上的排布。
- **适用**:开保险柜、伪造文件、外科手术、调一杯决定性的酒。
- **要点**:步骤间的判定技能要横跨多能力,否则退化为单技能检定链。

## 3. 空间与移动类

### 3.1 位移轨道(护送/穿越)

- **形态**:一条位置钟(A→B 共 N 段),每段附着不同的局部危险
  /局部动词——每推进一段,场面换一次小皮。
- **测试**:微缩旅途;队形与节奏。
- **适用**:护送夜莺过老街、把私货运出码头、雨夜送信。
- **要点**:段落切换用 flag 换渲染节点集;它是"多阶段"的连续版,
  也是将来出城远征的场内预演。

### 3.2 双战线

- **形态**:两个并行子容器共享你的骰池,各有各的目标/危险钟;
  有同伴时可指派谁守哪边。
- **测试**:注意力是资源;同伴的价值第一次可量化。
- **适用**:前门谈判后门搬货、同时守两个证人、声东击西。
- **要点**:两线的失败后果要不对称(一边丢钱一边丢人),否则退化为对称刷格。

### 3.3 多阶段合同 ★(了断)

- **形态**:接近→行事→脱身,整场换幕;每幕自己的钟与动词集,
  幕间结转修正。
- **测试**:全局资源规划——为最后一幕留骰子/留状态。
- **适用**:大节拍终局、抢劫、越狱。
- **要点**:幕数 ≤3;每幕必须有独立的失败含义,否则只是长。

## 4. 对手形态类

### 4.1 不可战胜的追猎者

- **形态**:一个无法移除的单位(Laine 型),只能拖延;
  胜利 = 完成目标钟 + 脱身钟,追猎者的压力随回合加速。
- **测试**:认清"不是每场架都要打赢"。
- **适用**:老板的保镖在场时办事、躲仇家、从疯狗嘴里捞人。
- **要点**:拖延动词要多样(挡路/误导/借人群),且都不减少它,只买回合。

### 4.2 竞争者(同场对手戏)

- **形态**:对手也在填**他的**目标钟(turn-rule 替他掷进度);
  你可以推自己的钟,也可以花骰子**破坏他的**——两个都是合法骰槽。
- **测试**:进攻与干扰的配比。
- **适用**:两拨人抢同一件货、竞拍、赛跑式寻物。
- **要点**:他的进度必须可见且有波动(替他掷骰),否则像倒计时不像对手。

### 4.3 人心钟(观众裁决)

- **形态**:胜负钟之外,第三个钟记录**在场者的心**(街坊/工友/她);
  它不决定成败,决定**结算时写回城市的关系与文案**。
  你可能赢了架,输了街。
- **测试**:手段的社会成本;赢的方式比赢更重要。
- **适用**:当众冲突、公审、酒馆斗殴——劳工街区的一切。
- **要点**:粗暴动词推坏它、克制动词养好它;结算时按钟位写回关系差分。

### 4.4 同伴入场(有名有姓的骰子)

- **形态**:同伴作为场内单位,提供专属动词或额外骰,但**有自己的
  危险钟**;用他越狠,他越暴露。
- **测试**:是否舍得消耗一个人。
- **适用**:老周压场、她在场的任何交锋。
- **要点**:同伴受伤必须写回城市(暂离/关系),否则只是一颗好用的骰子。

## 5. 资源与代价类

### 5.1 吃背包(补给消耗战)

- **形态**:判定动词很少或很贵,**物品是真正的推进货币**——
  绷带/药/酒/工具各自换格;测试的是进场前的背包。
- **测试**:准备与库存,而非当场手气。
- **适用**:救火、救人、加固门窗、熬过一夜风暴。
- **要点**:每种物品限用次数;没带够的玩家用骰子硬顶(更疼但可行)。

### 5.2 明码退场(拖延与代价)

- **形态**:任何时刻可以花钱/物/关系**立刻结束**交锋,退场价
  逐回合变动(涨:事态恶化;跌:对方也在耗)。
- **测试**:止损时机;把"认怂"变成有价格的决策而非失败。
- **适用**:被围、被讹、谈崩之后的缓冲。
- **要点**:价格曲线要在钟备注里可见;退场结局单独写,不等于失败。

### 5.3 骰子磨损(状态入场费)

- **形态**:交锋按**入场时的健康/压力**改变可用骰数或判定修正;
  场内坏结果优先磨状态而非推钟。
- **测试**:城市里的生活质量直接折算成场内战力——存量的兑现。
- **适用**:任何大交锋的入场规则,而非独立结构。
- **要点**:引擎已有压力/健康,只需入场读取;修正必须在动词副标题可见。

## 6. 信息类

### 6.1 迷雾开局(先侦察后交锋)

- **形态**:场内前 1–2 回合只有侦察动词,敌方钟表/单位数**不可见**
  (渲染为"?");侦察揭开后才出现攻防动词。
- **测试**:为信息付费的意愿。
- **适用**:进陌生场子、赴不明之约。
- **要点**:与"赌注可读"原则的边界——**不可见的只能是难度,
  赌注(输了会怎样)开局就要写明**。

### 6.2 中途并发症 ★(抢人·后门)

- **形态**:进行到指定回合/条件,冒出必须处理的新钟。
- **测试**:预留冗余;计划外的分诊。
- **适用**:任何主结构的加料;一场最多一个。
- **要点**:并发症要抢骰子,不要抢注意力以外的东西;
  它的出现条件可以随机化(第 2 或第 3 回合)以防背板。

## 7. 用法原则

1. **一场一个主结构,至多一个修饰件**(并发症/副目标/人心钟都是修饰件)。
   两个主结构叠加 = 玩家读不懂的一锅粥。
2. **连续两场不用同一主结构。**结构就是戏剧:换结构才是换戏。
3. **赌注永远可读**:任何结构下,"输了会怎样、几回合内会输"必须
   开局可见;可以藏难度,不能藏后果(§6.1 是唯一的受控例外)。
4. **副目标跨场兑现,主目标当场兑现**——副目标的价值在未来,
   才值得从主目标嘴里抢骰子。
5. **每种结构测试玩家的一种东西**(效率/止损/贪心/时机/背包/人心)。
   选结构时先问:这场戏想考玩家什么?再问:这个考点和本节拍的
   故事问题是不是同一句话。
6. 结构清单是菜单不是任务:demo 阶段只用已验证的(★),
   新结构每章引入至多一两种,让玩家的"结构识字率"跟着章节走。
