# 交锋结构库

> 一个想法的收集处。做新交锋时来翻一翻:有合用的想法就拿去拓展,
> 没有就构思新的——构思出来、做出来、觉得好,再记回这里。
> 好想法值得反复出现:玩家靠重复认识一个东西,练熟之后在新情景里
> 用上它会感到高兴;重复到发腻,就是发明新东西的时候。

## 用词提示(只是提示,不是约束)

- **原语**:引擎认识的最小单位——Clock、好中坏判定、turn-rule、
  单位闭包、双头条……原语可以组合出新原语;哪个组合用得特别多,
  将来值得为它单独设计 UI。
- 其余的都只是**想法**:小的,是一个原语与一种情景的相遇
  (一根钟表示两头拉扯的人心、表示追逐中的距离);大的,是几个
  想法合在一起的整套设计(话题拔河、单位化打斗)。
- 策略是玩家自己的事,设计里只写"这场想考玩家什么"。
- CS2指的是CitizenSleeper2

## 小想法(可单独撑一场,也可给大想法加料)

来源:Citizen Sleeper 1/2 的合同语法、其祖先 Blades in the Dark 的
时钟语法,以及现有原语的可行组合。

### 时间与冷静

- **赛跑**:目标钟(玩家推)vs 危险钟(自动走 + 坏结果追加)。
  考效率——每颗骰都在和时间换。最基础也最易滥用,连用两场就该换。
- **守局**:胜利钟**自动走**(援军/黎明/涨潮),失败钟由敌方推;
  玩家动作全是防御。考止损与分诊——不求赢,只求撑到转机;
  玩家第一次发现"熬"是动词。
- **加速消耗**:危险钟每回合推进量递增(1→2→3)。考前置投入——
  晚打的每颗骰更贵。开场就要在文案里预告"它会越来越快"。
- **警戒阶梯**:危险钟分档改规则(2 格起疑、4 格封锁、6 格才失败),
  把失败从悬崖变斜坡。考风险管理——玩家自己决定在哪档收手;
  每档变化在钟备注里预告。
- **慢交锋(跨日危机)**:危机钟按**天**走,长在城市地点里,
  与日常生活抢同一个骰池。引擎上是"带钟的地点"不是 encounter,
  但语法同构,是城市与交锋之间的桥。

### 目标形态

- **多目标取舍**:主目标外若干副目标钟,时间只够填一部分。
  考贪婪管理;副目标最好在**别处**兑现,错过就永久错过才有重量。
- **见好就收**:每次行动累积收益、危险同步上升,"离开"永远可用,
  失败吐出一部分。赌桌结构,银行你自己开;结算文案按拿了多少分层。
- **谱系结局**:没有二元胜负,钟的最终位置决定成交条款;随时可拍板,
  拖越久条款变动。把 roll 的方差直接翻译成故事差异;结局按钟位写 3–4 档。
- **隐藏胜利条件(侦探场)**:终结动词开局锁着,调查动词逐步揭示
  哪个假设为真;对错误假设行动有真实代价。考先想后动、信息的价值。
- **精确序列(仪式)**:步骤钟须按顺序完成,每步一种判定;失败清当前
  步骤而非推危险钟。步骤间技能要横跨多能力,否则退化为单技能检定链。

### 空间与移动

- **位移轨道**:一条位置钟(A→B 共 N 段),每段附着不同局部危险与
  动词——每推进一段换一次小皮。「抢人」在此之上加了**距离经济**
  (领先距离自动缩、清段回血、机关保险),见做出来的例子。
- **双战线**:两个并行子容器共享骰池,各有各的目标/危险钟。
  考注意力;两线失败后果要不对称,否则退化为对称刷格。
- **多阶段(换幕)**:接近→行事→脱身整场换幕,幕间结转修正。
  考全局资源规划——为最后一幕留骰子。幕数 ≤3,每幕要有独立的失败含义。

### 对手形态

- **不可战胜的追猎者**:一个无法移除的单位,只能拖延;拖延动词要多样
  且都不减少它,只买回合。考认清"不是每场架都要打赢"。
- **竞争者**:对手也在填**他的**目标钟(turn-rule 替他掷进度),
  你可推自己的也可花骰破坏他的。他的进度要可见且有波动,否则像倒计时。
- **人心钟**:胜负之外第三个钟记录在场者的心;不决定成败,决定结算时
  写回城市的关系与文案——你可能赢了架,输了街。粗暴动词推坏、克制养好。
- **同伴入场**:同伴作为场内单位提供专属动词或额外骰,但有自己的
  危险钟——用他越狠他越暴露。同伴受伤必须写回城市,否则只是好用的骰子。

### 资源与代价

- **吃背包**:判定动词很少或很贵,物品是真正的推进货币。
  考进场前的准备而非当场手气;没带够的用骰子硬顶,更疼但可行。
- **明码退场**:任何时刻可花钱/物/关系立刻结束交锋,退场价逐回合变动。
  把"认怂"变成有价格的决策而非失败;退场结局单独写。
- **状态入场费**:按入场时的健康/冷静改变可用骰数或骰子质量;
  场内坏结果优先磨状态而非推钟——城市里的生活质量折算成场内战力。

### 信息

- **迷雾开局**:前 1–2 回合只有侦察动词,敌方钟表渲染为"?"。
  考为信息付费的意愿。边界:**可以藏难度,不能藏后果**——
  赌注开局就要写明。
- **中途并发症**:进行到指定回合冒出必须处理的新钟。考预留冗余;
  一场最多一个,出现回合可随机(第 2 或第 3)防背板。

## 关于人的想法(候选,尚未做出来)

CS 1/2 的合同大多面向**物**:采集、打捞、破解、抢修。物只会衰减:
你消耗它,它不回嘴。本作是黑色电影,核心是**和人的种种互动**——
打斗、谈判、调情、套话、跟踪、逼问、威胁、欺骗——而**人会回应**。
校验一个新想法是否"面向人":这个对手能不能回应我的手段?
回应有五种面——回手(身体)、变脸(情绪)、撒谎(信息)、
倒戈(关系)、记仇(记忆)。答不上来的,还是一台画了人脸的资源机器。

- **情绪状态机**:人没有 HP,有状态轴(镇定→动摇→恐惧→崩溃);
  每个状态换一套他的招和你的解法;胜利 = 推进目标状态**并按住**,
  目标在轴的中段,**过冲有代价**(推过头他崩溃胡说,口供作废)。
  状态明牌,过冲风险写在动词副标题。
- **口供是货物**:交锋产出不是满格时钟,是几张带**可信度**的
  "他说的话",其中可能有假;信哪张留给城市侧交叉验证,信错留疤。
  调查风险从"查不到"变成"查到了假的"。
- **关系三角**:场上两三人彼此有**边**(老板—保镖—账房),动词不打人
  打边:挑拨、拉拢、当众揭穿;断边即拆协同。边要可见(谁听谁的)。
  了断第一幕"收账人使眼色"是雏形——下一步让边本身可攻击。
- **亮筹码与诈**:城市攒的筹码场内亮出即生效、不掷骰,但一次性且
  对方永远记得;诈 = 亮一张没有的牌,被识破灾难性反噬且跨场。
  成功率由可见的疑心档决定,不引入暗骰。
- **距离走廊**:距离经济的变体,目标是**保持在带宽内**——太近被发现,
  太远跟丢;对方换段不断改变走廊宽度。只有人会回头——
  "他回头了"就是走廊突然收窄的叙事理由。
- **单位记忆**:具名单位**跨场记账**——饶过的人下次不下死手,
  羞辱过的人下一章认出你。每笔记忆都要在后续兑现至少一次,否则删掉。
  场景由此反向改写城市,通道变成双向。

### 交谈(话题拔河)——人际对手戏

- **形态**:话题 = 一根 5 位双头条(他收口 ↔ 他松口),开话题占 1 骰,
  指针居中;场内动词是**手法**(稳推 / 重压 / 花钱垫),好中坏 = 推拉
  数值,全局判定语义不破。对方的台词挂在**指针所在区**上(占上风 /
  僵持 / 起戒心),与到达路径无关——文本线性增长,每话题约 8 句。
  端点才结算:拉满松口入账、滑底谈崩推危险钟、随时可收手不结算;
  回合末每根挂着的条向收口滑 1(**话会冷**)。对方按表主动丢
  **疑问 = 出生在你劣势位的话题**;同一时刻最多两根条(你的 + 他的),
  与空间线(物,静态可重复)争夺骰子。
- **考什么**:大层分诊(这颗骰给哪张卡)× 小层手法(推幅赌博)×
  沉没成本(救不救正在滑落的话题)。
- **换皮**:轴两端命名(套话:说漏 ↔ 收口;谈判:让价 ↔ 翻脸;
  审讯:招供 ↔ 缄默;调情:动心 ↔ 起疑);情绪段落换话题池;
  危险钟含义(疑心 / 敌意 / 尴尬)。
- **难度**:条长、疑问频率、冷却速度、段落附加代价、池尽重开的修正。

### 搜集(静态场景)
这个来自于CS2，是里面最经常用的一种模式，对于静态的事物，静态的动作进行长时间的搜集，推进。
主要考验玩家的问题是 多目标选择，紧急分诊，多个角色的骰子分配，减少时间还是贪心，多等待时间还是冒险
经常用到的元素 有很多，暂略

- **形态**:CS2 合同语法照用——目标钟 / 副目标钟 + 危险钟(可自动走),
  "离开 / 见好就收"动词常备。**物不回应**:动词可重复、无冷却、
  没有话头规则,这正是它与交谈的手感分界。
- **考什么**:骰值分配 × 贪心管理(推哪个钟、什么时候走)。
- **换皮**:危险钟曲线(匀速 / 加速 / 警戒阶梯)、副目标数量与
  跨场兑现、迷雾开局。
- **难度**:危险钟总格与走速、副目标的诱惑力、判定风险档。

### 打斗拆招(单位化)——身体冲突
是紧急分诊的一种人的对象化和复杂化

- **形态**:每个麻烦是一个具体的人——命数 + 出招倒数 + 明牌招式
  (威胁类型互斥:磨冷静 / 伤健康 / 偷钱 / 吃进度);对单位两类动词:
  压制(重置其出招)与击倒(伤命数);重要敌人的招**预告**(倒数、
  落点、拆法可见),每招至少三种答案——拆招(稳,无进度)、硬吃
  (省骰,用资源付账)、抢拍打崩(倒数内造成足够伤害则招作废);
  夺人类招可撂倒执行者。道具一次性、无判定,是低骰出口。
  回合末统一结算所有出招。
- **考什么**:分诊(先处理哪个人)× 每招答案经济随健康余量 / 敌方
  余命 / 残兵状态漂移。
- **换皮**:单位配置表(命数、节奏、威胁类型)、指挥官单位
  (力量倍增器)、增援钟、变速档(Boss 撕破脸)、幕结构。
- **难度**:单位数量与首招错峰、招式威力、变速档阈值、道具供给。



## 组合想法时的建议

- 一场一个主想法,至多一件加料;两个主想法叠加是玩家读不懂的一锅粥。
- 连续两场别用同一个主想法——换想法就是换戏。
- 赌注永远可读:输了会怎样、几回合内会输,开局可见。
- 选想法时先问:这场想考玩家什么? 这个考点和本小节的故事问题是不是同一句话?
