# 对话立绘画风探索

用途：比较三种对话模式人物立绘技法在黑色界面中的情绪、角色辨识与信息密度。这里是风格探索图，不是正式人物资源；正式游戏角色仍须遵守人物设定总表的描线、透明画布和统一全身尺度要求。

每张图旁的 `*-prompt.txt` 保存本轮提示词。Gemini Image Web 的原始输出、manifest、会话记录保存在 `tmp/gemini-image-web/dialogue-portrait-techniques/`。

## 初步审阅

- 夜莺：三种版本都保留卷发、风衣与手提包；木刻的刻线对比最强，电影半调暖光最贴近雨夜氛围，漫画版轮廓更柔和。
- 艾迪：三种版本都保留毛巾、拳手体格与缠手；电影半调最有舞台聚光感，木刻排线最粗粝，漫画版色块更亲近。
- 汤米：三种版本都保留宽松旧西装、软呢帽、磨损鞋与斜倚姿态；木刻的虚张声势感最强，漫画版更轻巧，电影半调更像传统黑色电影人物。

九张图目前是独立出图，尚未合成到实际对话UI中，也没有做透明化或舞台尺寸验收。
