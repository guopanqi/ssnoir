# Pascal Campion 配色尝试

只参考配色关系，不模仿完整画风：低饱和的冷蓝夜色作环境底，局部暖金灯光照亮人物脸、手和少量服装细节，保留黑色漫画线稿与暗色背景。这样将人物的暖光与地图已有的深蓝、暖白和琥珀灯点连接起来。
