# 用户选图：汤米全身画像

- 输入：[用户选图原稿](汤米-用户选图-原稿.png)，2816×1536，含左侧全身及右侧特写。
- 输出：[全身 PNG](汤米-用户选图-全身.png)，1024×1536，RGBA。
- 使用 imagegen 做背景提取，保留左侧单手提衣襟、另一手垂下的全身造型，去掉右侧特写与纸底。生成式提取并非逐像素原稿蒙版。
- 检查了浅色和深色背景叠加效果：头发、手指与双鞋完整；脸、衬衫、袖口和鞋面浅色保留；人物周围及双腿之间具有真实 alpha 透明区域，没有棋盘格背景或地面投影。
- 工作台副本：`experiments/游戏UI原型/assets/汤米-限色.png`。在对应人物的图片地址中填写 `assets/汤米-限色.png`，显示方式选择“原图”。这是一张提取候选，不自动发布为 Unity 正式人物资源。
