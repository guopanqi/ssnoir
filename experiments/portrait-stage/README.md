# portrait-stage — 立绘舞台表演实验组

共同目的：研究 2D 立绘人物在舞台上的表演力——
对白节奏、走位、停顿、姿势切换、灯光道具，以及人物画风与舞台的融合。
人物素材是各实验独立的舞台素材，不替换正式游戏立绘。
