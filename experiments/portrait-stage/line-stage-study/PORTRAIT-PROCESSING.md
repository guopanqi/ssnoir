# 人物画面处理的边界

素材选择负责人物画稿与姿势；演出负责站位、时间、说话与离场。人物画面处理只接收已选好的图片，不决定角色与故事时序。

背景遮挡是原图下面的一层剪影，有自己的开关、对象、底色、强度和柔化。当前仅原版 Neon 有对齐的轮廓。原图调整共享人物对象，亮度、调色、描边/亮线、纹理/渐隐各有独立开关与重置。色板亮部、描线颜色、覆盖线颜色分别归各自模块；描边辉光不作用于覆盖纹理。关闭模块只停止其效果，保留其参数；单模块重置不修改其他模块。未启用的组使用真实 disabled 控件；参数可保留但不生效。

画面调整预设只替换调整参数，保留调整对象和全部背景遮挡参数；“重置画面调整”同样不改遮挡。“重置遮挡”只重置遮挡。固定比较栏使用自己的预设，不读取主画面编辑器参数。场景受光与投影仍属于布景融合，和人物原图调整分别控制。

文件职责：`portrait-settings.js` 定义默认值和纯数据预设；`editor.js` 只构建控件、更新参数、执行预设/重置与记录；`portrait-renderer.js` 接收舞台与参数，分别绘制剪影、SVG 滤镜与 CSS 效果，不绑定控件；`main.js` 选择素材与比较栏参数并协调演出和渲染。参数记录版本为 4，遮挡对象使用 silhouetteTarget，调整对象使用 target。

浏览器交互检查：修改原图亮度后重置调整，遮挡仍开启且对象仍为两个人；选择“只提亮原图”后亮度为 140%，遮挡及对象保持；开关正确禁用/启用相应参数，页面无 error/warn。未修改 Unity 游戏侧渲染。

模块拆分检查：Node 断言确认模块参数无重复归属，关闭描边后保留亮度、色板和纹理的有效参数；浏览器开启亮度并设为 140%，开启描边并修改线宽后单独重置描边，亮度仍为 140%，描边关闭并恢复默认。页面无 error/warn。
