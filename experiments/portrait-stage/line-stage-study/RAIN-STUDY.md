# 雨夜求助

新增故事选择，保留路灯故事，默认雨夜。六句对白与主要等待时长来自 experiments/portrait-stage/portrait-theatre-lab/portrait-theatre-story-claude-sonnet-5-5.html 的 C1.run。尼尔通过对讲机回应，全程不显示在室外；夜莺入场、等待、进门渐隐。新布景为线绘酒店门面、对讲机和门内暖光，雨线由故事时间驱动，暂停冻结、跳转即时恢复。门铃与门锁蜂鸣使用 Web Audio，连续雨声随播放暂停和故事切换关闭。

这是现有平面人物舞台的适配，并非原 HTML 全量复刻：复用原版 Neon 基础人物，没有雨伞、伸手按铃的新姿势；按铃用声效表达。进门用平移与渐隐、开门用暖光，未复刻原稿骨骼表情或门叶动画。门铃两音同时触发，未复刻第二音 450ms 延迟；雨声是低通噪声近似，无新配音。

story.js 保存故事与时间状态，player.js 保留播放器；故事切换重置拍点、停止播放，画风与后处理选择保留。main.js 渲染雨线与角色可见性，scenery.js 保存酒店线绘。

检查：main/story/sound 模块语法通过；六句对白、门铃与蜂鸣事件、尼尔不可见、夜莺最终渐隐、门光关闭、雨强度收尾、播放器末尾及路灯32拍恢复逻辑通过。未运行浏览器视觉/交互、人工听感或 Unity；这些不是实际渲染验收。
