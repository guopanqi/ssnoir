# 流畅轮廓的四种处理方向

用户否定写实和直接填色的卡通人物后，本轮只用原版夜莺统一比较视觉处理，不改舞台素材。

1. 柔和色面：线条粗细有变化，选定位置有柔和、半透明色面，不平均填满每个封闭形状。
2. 局部显形：轮廓断续，部分头发与衣服融入暗处，肩、脸与裙褶通过局部光面显形。
3. 淡彩笔触：流畅笔线与疏松淡彩配合，边缘省略，保留负空间。
4. 丝网印刷：少量流动曲面、叠印色层和负空间表达体积，局部微量颗粒。

均使用正式原版夜莺作参考，Gemini 单张顺序生成。原始提示词与图片存于本目录，生成记录位于 `tmp/gemini-image-web/flowing-studies/`。这些是光与色面处理的造型试稿，背景尚未抠除，不作为透明立绘直接使用。
