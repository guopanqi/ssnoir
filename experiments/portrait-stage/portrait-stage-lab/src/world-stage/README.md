# 世界底图上的立绘剧场比较

入口 `http://127.0.0.1:5178/world-stage.html`。这是新增 Web 试验，不覆盖前三版，不修改 Unity 运行时舞台。

底图来自 2026-10-08 本轮正式 Unity Preview：`.cache/portrait-world-comparison/20261008-125327-679961/`。`result.json` 确认生成完成。使用当前 Main、正式资产与调色链的 Editor 机位图，格兰德酒店和城市全景各一张；没有用生成图替代游戏世界，没有执行 Play 对照验证。

世界 → 半透明色幕布与少量雾色 → 局部光池 → 几何道具 → PNG 人物 → 字幕。幕布默认冷蓝灰、72%；可换暖褐/灰紫与透明度，不影响人物 alpha。少量道具采用 Claude 实验中用户喜欢的几何填色语言：路灯的杆、罩、灯泡和淡三角光束；门、电铃、桌椅与台灯也保持克制的色块。没有新增整张舞台背景。

六种夜莺：四种 flowing studies、此前体块描线稿、原版 Neon。切换只换图片，不重置当前对白、站位与道具。尼尔独立选择 02 同画法试稿或此前体块稿，不随夜莺切换。

02 原稿的暗处曾和灰背景连在一起，直接去灰会导致建筑线穿过人物。Gemini 根据该稿另生成亮绿背景的完整人物，保留暗部不透明面，输出 `art/world-stage/02-stage.png`；尼尔另用自己的原版身份图和这张的画法生成。当前 02 已完整全身，其余旧探索稿部分裁切、服装和姿态尚未统一；这轮用于比较色线与世界的协调，不宣称是严格同身份同姿势的量化评测。

`tools/prepare-world-stage.mjs` 输出透明对比资产，不修改原稿。旧灰背景稿用边缘连通去底；原版 Neon 用亮度 alpha，移去麦克风；02 与尼尔用绿幕去底。`art/world-stage/` 保留提示词、原图和浏览器实拍。

五个拍点：登场、质问、沉默/远离、重新开口、道具靠近查看。台词取已有第一章基准，仅用于构图，不是酒店正式剧情。播放可停止；切换画法不停止，便于在相同拍点比较。这里没有新增表情姿势，不能据此判断换图演技；倾斜和位移只检验空间表达。

文件：`data.js` 保存选项和拍点；`props.js` 保存少量 SVG 布景；`main.js` 组织图层与试演；`style.css` 统一虚拟 1280×720 舞台，按容器缩放，无设备布局分支。

验证：`node tools/check-world-stage.mjs` 检查六种画法、切换保持拍点、三个布景、道具中央过渡、世界/色幕布/透明度、图层开关、播放停止与窄窗口；`npm run build` 包含该入口。
