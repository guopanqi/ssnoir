# 素台六幕

入口：`http://127.0.0.1:5178/baselines.html`。原入口 `/` 保留。

六个固定情节基准：雨夜求助、金牌烟盒、隐瞒莱恩后的争执、报酬与准备离开、经理搭肩装电话、经理解除委托。对白与事实作为共同基准，演出为这次独立实验的改编；不是正式第一章内容脚本。

舞台只有一个纯色底。电铃、桌椅、电话、伞、烟盒和线索材料是独立可撤换的道具，没有环境图片、墙面、地板或装饰性布景。原有角色图复用，新增经理与尼尔搭肩的双人图，用一次明确的接触表现单方面的亲近。

`stories.js` 保存六幕对白、动作与停顿，`stage.js` 负责本组人物和道具，`style.css` 为独立视觉。复用原实验的 Player 与声音类。每幕末尾停留并显示重看/下一幕；提供自动/手动、暂停、声音、隐藏字幕以及节点回看。所有窗口使用同一 1280×720 舞台缩放。

观演重点：

- 烟盒出现时，能否读到她迟疑，再将话题交回？
- 争执结束后，能否读到他继续合作但尚未释怀？
- 门口的一问，能否让此前的沉默变得有意义？
- 搭肩与电话，能否同时表现热情和越界？
- 解雇时的礼貌，能否留下比争吵更压抑的效果？

声音为合成的雨、电铃、开锁与关门，没有配音。双人图的替换是关键姿势切换，并非连续骨骼动画；拿伞与交材料为道具位置/显隐抽象，没有制作手指抓握。此处检验少量姿势与走位的表达，而不是模拟写实动作。

生成原图和提示词：`art/baselines/contact.png`、`contact-prompt.txt`；去绿处理：`tools/prepare-contact.mjs`。检查：`node tools/check-baselines.mjs`（需已安装 Chrome，且开发服务在 5178 端口）。检查完整指令链和全部节点重建时缩短等待；暂停、接触、道具与窄窗口截图保留实际时间。
