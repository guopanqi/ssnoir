# Neon Puppet Theatre · Three.js / 骨骼与描线实验

这是 SSNoir 的**独立实验**，位于 \`experiments/portrait-stage/neon-rig-three/\`。
不修改 Claude 剧场、不替换 Unity 正式立绘，不向正式游戏添加运行时功能。

## 研究问题

正式 Neon 描线人物（\`.neon.json\`）是否能够直接拆解为可驱动的线条，通过少量骨骼和关节，在极简黑色舞台完成可读的动作？

现阶段回答是一个待视觉审阅的工程性假设：**可以为线条施加自动估计的软权重骨骼变形**，但无法仅凭现有的散列描线路径，可靠识别每个独立肢体、解决前后遮挡或推断真实的人体关节。不能把当前实现声称为已完成的自动绑定工具。

## 来源与数据

- Claude 剧场参考：\`../portrait-theatre-claude/src/js/chapters/07-tavern-exit.js\` 和 \`04-chase.js\`；借鉴的是演出事件次序与节奏，没有复用 SVG 人物代码。
- 正式游戏形象来源：\`../../../UnityClient/Assets/Resources/Portraits/Neon/\`（从仓库根目录）。
- \`data/\` 中保存七份正式 \`.neon.json\` 的**逐字数据语义副本**，没有重新描绘线条。人物：尼尔、尼尔_醉站、尼尔_醉行、尼尔_靠墙、码头工人、码头工人_奔跑、黑影。正式源图及姿势仍由 UnityClient 管理。
- 浏览器只下载这里的 7 份小 JSON，不加载 Unity 工程、原始 PNG 或整座剧场；每个路径的相邻点变成 Three.js 的动态细带三角形，避免依赖 1px WebGL Line 的不同平台线宽实现。

## 结构

- \`rig.js\` — 检测路径范围和估计各关节位置，针对头颈、双肩/肘、臀/膝对每个路径点做空间加权旋转，更新 Three.js 动态 BufferGeometry。
- \`scenes.js\` — 两段确定性、可任意时间采样的演出状态，没有异步计时副作用。
- \`main.js\` — 同一舞台、摄影机、少量布景及可动道具、渲染与播放控制。
- \`index.html\` / \`style.css\` — 16:9 剧场、对照开关、回放/暂停/拖动，适配小屏。
- \`data/\` — 只供实验使用的正式描线路径快照。
- \`test.mjs\` — 结构和时间轴回归检查。

## 运行

在仓库根目录：

\`\`\`bash
cd experiments/portrait-stage/neon-rig-three
python3 -m http.server 5189
# 打开 http://localhost:5189
node --test test.mjs
\`\`\`

浏览器需连接到 jsDelivr 下载 Three.js 0.180.0 ESM；之后实验数据由本地服务提供。不能直接用 \`file://\` 打开，因为 ES module 和 \`fetch()\` 的限制。

URL 定点验收：\`?scene=drunk&t=10&pause=1&joints=1\` 或 \`?scene=chase&t=12&pause=1\`。

## 两段演出

1. **酒馆醉步（21 秒）**：灯亮、尼尔出门、失衡前行、扶墙、突然加剧的踉跄、恢复行动、退场。复用正式尼尔/醉站/醉行/靠墙三张指定姿势，增加关节与整体摆动。
2. **街角追逐（26 秒）**：码头工人拿走信封、尼尔放下报纸、两人起跑、横向运动造成背景掠过与人群交错、逃者入巷、尼尔急刹并跟进。使用正式尼尔与码头工人的普通/奔跑描线路径，路人使用正式黑影。

## 对照实验与验收

页面有三项独立开关：

- 关节驱动：关闭后保留整张官方描线路径与整体走位、摇摆，不再变形。
- 使用已有姿势资产：关闭后只使用两人的基础描线，通过同一绑定驱动完成动作，比较关键姿势的必要性。
- 显示自动关节点：定位关节估计误差。

**建议人工逐帧关注**：头部与帽子有没有裂开、外套衣摆和手臂是否被错分、手肘是否有断裂、腿部是否像橡皮一样弯曲、人物接地是否稳定、奔跑是否有足够的跨度、巷口缩放是否造成瞬间变形。视觉好坏不得仅凭 JS 语法检查作结论。

本实验的不足：当前关节位置按轮廓总高度比例自动估计，人物外套、长裙、重叠肢体无法精确语义分割；没有遮挡层级重绘、逆运动学、真正的 3D 模型或美术校正的 mesh skinning。适合作为判断这种技术**值得不值得深化**的原型，不是生产级骨骼资产流水线。
