# AGENTS — 本实验的接手说明

先读 [README.md](README.md) 的目录与工作流。上级 `AGENTS.md` 的约定同样适用（直接在 `main`、不过度设计、不打兼容补丁）。

## 架构要点
- 无框架、无打包器；`build.mjs` 只是把 `src/js/*.js` 按文件名顺序拼进同一个全局作用域。**文件名前缀即依赖顺序**：`<50` 的是基础层，`chapters/` 目录内按文件名排序组成 `const SC=[C1, …]`（C1、C7 两个共用对象定义在 45-chapter-objects.js，由 01-rain-night.js、09-lamp-quarrel.js 引用），`>=60` 是启动层。
- 新增章节：在 `src/js/chapters/` 加 `NN-name.js`，内容是**一个以 `,` 结尾的对象字面量** `{n,sub,sh,pos,bg,set,mk,ini,run}`；章节编号文字由 `60-boot.js` 的 `ZH(i+1)` 按序号自动生成，无需手改；文件名前缀必须唯一。布景加在 `40-sets.js` 的 `SETS.xxx`。
- 章节对象：`n` 名称、`sub` 副标题、`sh` 按钮短名、`pos` 地图点位(世界坐标)、`bg` 舞台底色、`set` 布景容器 id（`#hotel/#lamp/#set3`）、`mk` 生成布景 SVG、`ini()` 初始人物位置、`run(k,H)` 异步演出时间线，`H` 提供 `w/say/go/fl/n/y/mono…`。
- 人物：`CH` 里定义，`P(id,{x,y,s,f,face,b,h,al,ar,ll,lr,cl:{…},show…})` 改姿势。**`show:1` 才可见**（ini 里漏写则人物隐身——追逐章曾因此看不到尼尔）。
- 立绘式表演（追逐章已采用）：每个姿势是一整张“立绘”（`POSES` 全局姿势表，助手 `pose/mv/bob` 在 `30-runtime.js`：肢体角度+前倾+头，配合 `face`），换姿势时整张切换（人物加 `snap` 类，只关掉肢体/表情的补间，根节点位移补间保留）；走位、背景卷动、镜头保持连续流畅，奔跑只用整体上下颠簸（`bnc` 类），不做关节摆动。以后换成生成的立绘图时，替换 `POSE` 表与 `pose()` 即可。见 `chapters/04-chase.js`。其他章仍是关节补间，可按同样方式迁移。
- 暂停机制：`sleep(ms,k)` 轮询 `paused` 与 `gen` 令牌；任何新的异步等待必须用 `w()`，不要裸 `setTimeout`/`await` 否则暂停与切章会失效（`throw 0` 即被取消）。

## 踩过的坑
- **SVG id 必须全局唯一**：渐变 `mg` 曾与人物 id 冲突导致整页点击无反应。新增 id 前全局搜索。
- 布景线条类 `.set path` 有统一样式（描边、dash 出现动画、`.lit` 点亮）；新增形状用 `LL()/RR()` 助手以带上 `pathLength=1` 与 `--d` 延迟。
- `@keyframes shk` 曾缺失，震屏无效；现已在 style.css。
- 地图字/邮箱等布景上不要放中文字形（用户明确要求去掉）。

## 设计准则（用户已确认，勿违背）
1. 黑色电影气质，人物是成年人，不是卡通。
2. 舞台布景不必全屏；每个地点一个标志物（路灯、桌灯、邮箱、巷口……）。
3. 桌上吊灯＝尼尔的家，其他人/其他地点不再使用，玩家一见就知在哪。
4. 路灯、舞台像音符般逐渐亮起等“点亮”手法是好设计，保留。
5. 第 1 章雨夜在尼尔公寓楼下（301 对讲），不是格兰德酒店。
6. 对白以各章代码为准（来自用户原稿）；章节里“我拟写”的对白已在副标题标注（如邮箱）；设计备注不上台。
7. 追逐用定格姿势切换（模拟立绘），不用关节摆动；追逐须能看见尼尔；入巷要自然（转角→背影纵深）。
8. 世界/舞台过渡：地图 → `#world` 放大(7.2×)+模糊 → 舞台；结束后缩回。
9. 章节顺序：一 序幕夜 · 二 第一日清晨 · 三 第一日酒馆 · 四 雨夜 · 五 求助 · 六 邮箱 · 七 追逐 · 八 烟盒 · 九 独探 · 十 酒醉(酒馆出门) · 十一 房东(催租) · 十二 次日 · 十三 巷口 · 十四 路灯 · 十五 弗兰克 · 十六 平静 · 十七 电话 · 十八 第三封信 · 十九 质问 · 二十 莱恩家 · 二十一 安全 · 二十二 介入 · 二十三 解雇 · 二十四 彩排 · 二十五 照相馆冲印 · 二十六 照相馆查来源（以 `chapters/` 文件名顺序为准）。序幕夜与八、九两章内容有重叠（酒醉/回家），待用户决定是否合并。
10. 未实现的 Three.js 参考方向：webgl-outlines、Moebius 后处理、LineSegments2/LineMaterial、HD-2D 倾斜移轴、spine-threejs。

## 验证清单（改动后）
1. `node build.mjs --check`；2. `test_play.py … full` 无 JS 错误；3. 对改动的章节跑 `sheet`/`realtime_capture` 看图；4. 提交 `src/` 与 `dist/`；5. 如需更新在线版，用 Artifact 工具对上面 README 的 URL 重新发布 `dist` 文件。
- 立绘做不出密集剧烈的动作：醉步/奔跑等循环动作用“少量整张姿势 + 整体缓慢摆动（`swy`/`swy2`/`bnc` 类）+ 连续位移”表现，不要高频切换姿势（见 07-tavern-exit.js）。
- 长对话不要让两人干站着：用舞台调度制造空间感与关系气氛——走位远近（靠近=压力/关心，转身走开=回避）、道具动作（衣帽架挂取帽包伞、首饰摊桌、饭菜冒热气、点烟）、镜头缓推/拉远 `dolly(scale,x%,y%,ms)`（对 #bg/#fg 缩放，章节结束自动复位）、灯光明暗 `lamp()`、环境声（`rainS` 窗外雨、`ticks` 钟表滴答、雾笛）、`sigh(id)` 原地叹气、`at(ms,fn)` 在台词进行中不阻塞地触发动作。台词文字不得增删。示例见 `chapters/02-indoor-plea.js`。

## 电影式硬切（序幕夜首次使用）
- `h.cut(swap,hold=1500)`：瞬黑（无过渡）→ 黑场停 `hold` 毫秒 → 瞬亮。`swap` 在黑场里换景；换景后线稿直接画满（`.set.now` 关掉描线过渡），不是渐显。切幕前自己 `murmur().stop()` 让声音一起断掉。
- `h.scene(mk,front,props)` 整体替换布景/前景/道具；`hum([[x,y,s,f],…])` 往 `#props` 放轻轻摇晃的人群剪影；`gl(id,x,y,o,ms,r)` 移动道具，`GL(id)` 是酒杯道具标记。
- 章节对象加 `hardOut:1`：收场不做拉远运镜，瞬黑 1.5 秒后直接回地图。
- 酒保擦杯/放回架子是共用动作 `wipeGlass(w,n)`/`shelveGlass(w)`（`33-props.js`），白天酒馆布景 `SETS.barDay` + 前景 `BDC`，第二日酒馆可直接复用。
- 角色 id 不能与布景里已有元素 id 撞名（`#bt` 是门铃，所以酒保叫 `bm`）。新角色：`bm` 酒保、`ed` 艾迪、`ho` 旅馆老板（画在尼尔身后）。
