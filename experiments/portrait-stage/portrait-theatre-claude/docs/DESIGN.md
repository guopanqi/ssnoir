# 设计准则与章节清单

## 准则（来自用户反馈）
1. 黑色电影气质，人物是成年人，不是卡通。
2. 舞台布景不必全屏；每个地点一个标志物（路灯、桌灯、邮箱、巷口……）。
3. 桌上的吊灯＝尼尔的家，其他人/其他地点不再使用，玩家一见就知在哪。
4. 路灯、舞台像音符般逐渐亮起等"点亮"手法是好设计，保留。
5. 第 1 章雨夜在尼尔公寓楼下（301 对讲），不是格兰德酒店。
6. 故事对白来自用户稿；章节里"我拟写"的对白已在副标题标注（如邮箱）。
7. 追逐用定格姿势切换（模拟立绘），不用关节摆动；追逐须能看见尼尔；入巷要自然（转角→背影纵深）。
8. 世界/舞台过渡：地图 → `#world` 放大(7.2×)+模糊 → 舞台；结束后缩回。
