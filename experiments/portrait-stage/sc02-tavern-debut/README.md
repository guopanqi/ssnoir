# SC-A02 · 酒保与夜莺初次亮相（线绘场景 + 人偶定格姿势）

单文件网页实验：把正式剧本 SC-A02（固定开场）在「线条构造的舞台」上演出来。
接续 [../portrait-theatre-claude/](../portrait-theatre-claude/) 的基准实验，两条结论：

- **保留**（来自 Claude 版的确认项）：舞台由线条逐笔画出、逐渐出现；灯像音符一样逐个点亮；黑色电影气质。
- **改掉**（Claude 版被嫌弃的点）：动作迟缓沉闷。本实验里，人物是**关节人偶**，但姿势**定格切换**
  （像换一张立绘），不做慢速关节补间；走位只用整体位移补间；台词节奏收紧。

## 与正式立绘的对应

演出里人偶只用来「摆姿势」：每个姿势是一个数据项（肢体角度 + 前倾 + 头 + 视线 + 表情），
换姿势是瞬时整张切换（`pose()` + `POSES` 表，`snap` 类只关掉内部补间）。将来正式游戏用
不同姿势/表情的**立绘本**时，替换 `POSES` 表和 `pose()` 即可——时间线一行不用改。
表情同理：`SKY` 表里的嘴形/眉数据换成表情立绘整脸替换。

## 场次还原（SC-A02 文字 → 舞台节拍）

| 剧本舞台指示 | 演出实现 |
| --- | --- |
| 酒馆还没坐满，酒保擦玻璃杯 | 三三两两的观众剪影常时轻晃 + 擦杯循环 |
| 麦克风短促噪声，酒保朝台上看一眼 | `buzz()` + 酒保/尼尔同时定格为侧目姿势，镜头孔（iris）偏向舞台 |
| 追光亮起、等伴奏两小节、开始演唱 | 追光锥渐亮、三盏台脚灯逐个亮起；钢琴两小节后哼唱旋律 |
| 镜头稍远，先舞台与观众，不急着特写 | 登台全程不推镜头；对白与演唱并行压低 |
| 末尾侧面近景：听见掌声，短暂的笑 | 全剧唯一次推镜（缓推 1.5×），一个收得很快的 smile，随后拉回 |
| 向乐手点头，酒保收走空杯 | 点头定格两拍 + 空杯从吧台被放回架子 |

对白全部一字不改（吧台五句 + 演唱中四句）。除惟一一次推近/拉回外不用其他运镜。

## 用法

浏览器直接打开 `index.html`（单文件，无依赖；字体离线自动回退），点「开 场」播放。

## 验证

不引入 playwright 等额外依赖（本项目约定）。验证方式：

1. **静态自查**：对姿势/手↔道具坐标做几何验算（手臂角度 → 手端点位置 → 道具坐标对位），
   镜像窗口（f=1 面向左）与朝右窗口（f=0）分开验算。
2. **运行自查**：浏览器打开页面播放，看 console 无报错、构图与节拍正常。
   `node --check` 只保证脚本语法，不代表画面正确。

素材是本实验独立的舞台素材，不替换正式游戏立绘。
