# SSNoir · Neon Cutout Puppet / 实验 02

此目录是 `experiments/portrait-stage/neon-rig-three/` 的**同级独立实验**。不修改 Claude 剧场、Unity 正式资产或旧的骨骼变形实验。

## 研究问题

上一轮直接弯曲完整的 `.neon.json` 路径，导致帽子、长外套和胳膊之间出现橡皮状变形。本轮改为明确的 rigid cutout：尼尔由 13 块独立的图层组成（头帽、躯干、腰胯、双上臂、双前臂和手、双大腿、双小腿与鞋、两片衣摆），每个部件对应独立描线图像，使用**手工确定的关节位置和父子关系**，在 Canvas 2D 中做刚体旋转，没有任意顶点拉伸。

图像由本轮新生成的黑白／象牙色描线尼尔美术实验得到，与正式尼尔同一设计方向（礼帽、长风衣、高对比黑体块、稀疏亮色描线），**不是正式游戏角色图片的逐像素复制**。局部连接及身份相似度尚需人工验收，不替换正式资源。

## 三段演出

- `drunk`，14 秒：从酒馆出门、摇晃、失衡、扶墙、重新迈步。
- `brace`，11 秒：独立伸手、身体重心转移、扶住墙、放开。
- `run`，12 秒：两腿交替、摆臂与衣摆的延迟、急刹。正面切片不等于有足够侧向跑步姿势，这是本轮的重要限制。

页面有三种视图：剧场演出、**生成的关键姿势参考与动态 Cutout 对照**、拆解后的 13 部件。支持拖动进度条、暂停、重播、倍速、显示支点、关闭关节旋转和独立衣摆。

## 文件

- `rig.json`：每块图层 `parent/crop/sourcePivot/joint/z`，连接关系全部显式记录；每块图层保持完整局部形状。
- `rig.js`：rig 校验、无环检查、父子变换矩阵和绘制顺序。
- `scenes.js`：三段时间轴的确定性状态采样（没有动画累积误差）。
- `main.js`：剧场布景、播放控制、对照视图及浏览器入口。
- `assets/puppet-atlas.png`：由新生成人物拆分图制作的透明图集，轻量运行资源。
- `assets/reference-*.png`：新生成的基础、醉步、扶墙、奔跑四种关键姿势，**仅作对照**，不冒充程序生成的动画帧。
- `tools/make_atlas.py`：从高分辨率 `source-atlas.png` 再生小图集的脚本（高分辨率来源只在本地实验包保留，以免主仓库增重）。
- `tools/preview.py`：不依赖浏览器的确定性合成截帧工具；用真实分层 PNG 与实际时间轴导出关键帧。
- `tools/verify-browser.py`：有可用 Chromium 时进行真正的页面运行与截图。

## 运行

```bash
cd experiments/portrait-stage/neon-cutout-puppet
python3 -m http.server 5190
# 浏览器打开 http://localhost:5190
node --test test.mjs
```

无需 Three.js / npm 依赖。之所以改用原生 Canvas 2D，是因为本轮的判断对象是有遮挡关系的 2D 分层刚体，Canvas 层级与 DrawImage 足以完成，并且离线可运行；并不是 3D skinned mesh 的方案。

可使用参数在特定时间检查：`?scene=brace&t=6&pause=1&view=compare`。

## 实图初步观察 / 未解决问题

已用 Pillow/OpenCV 的独立组合渲染器，在实图上检查了静态组装、醉步、扶墙、奔跑的多个时间点（见 `captures/python-preview.jpg`）。静态组装保持帽子、双排扣风衣、腰带和鞋的身份特征；扶墙靠上臂和前臂作为独立刚体转到水平支撑，比把整张角色拉弯更清晰。动作脚部仍存在滑动，奔跑只能读为大步快走，尚不能达到生成的专用跑步关键姿势表现力。接缝和绘制顺序存在可见瑕疵，不应认定为生产级人物资产。

实验说明了**拆分部件可避免橡皮形变，但部件化本身并不自动产生有表现力的动作**。当视角由正面转成奔跑侧向或需要精确扶墙接触时，仍需要额外方向的部件套装、手部姿势和脚底约束。下一步应先提高一个人物的部件细度与动画可读性，再考虑通用资产生产工具链。
