## 具体修复

落地机位原目标高度3.5，横移35–50%时机体顶部超过画面约4.97%。只抬目标到4.6虽能避免完整画面裁切，但仍可能被CutscenePlayer的2.39:1上下黑边挡住。因此最终使用：

- Camera_联合起吊-落地位置保持 `(11,-24,4.8)`，目标 `(0,-6.5,4.6)`。
- 焦距32mm改为24mm，FocusTarget同步。其他动画、几何和剧本未改。
- 源生成器与现有blend机位同时更新，局部构建与标准发布完成，见publish-final.log。
