# SSNoir 游戏 UI 原型

这里维护可体验的 UI 设计实验：用相同样本比较排版与反馈，不作为游戏规则或正式剧情的来源。直接扩充对应实验，不按日期或执行批次另建目录。

## 入口与设计问题

| 入口 | 设计问题 | 可比较的内容 |
| --- | --- | --- |
| [行动与状态](index.html) | 玩家能否理解投入、判定与后果？ | 骰子修正、概率、结算反馈、角色状态、圆形／横条 Clock |
| [对话布局](index.html?experiment=dialogue) | 阅读对白与人物空间如何分配？ | 右侧连续记录、底部当前对白；切换保留进度 |
| [事件单页](event-sheet.html) | 重复事件怎样保留画面感、减少对白打断？ | 淡黄纸张、可选墨线插画、短文与结果；首次接对白、再次一页带过、房租收据与报纸 |
| [对象与行动编组](grouping.html) | 地点、对象、行动和目标如何建立清楚的关系？ | 共用标题、场景两翼、对象分栏；单对象、不同对象、跨目标与密集总览 |

在仓库根目录执行 `python3 -m http.server 8768 --bind 127.0.0.1`，打开 `http://127.0.0.1:8768/experiments/游戏UI原型/`。统一通过静态 HTTP 服务预览，JS module 不使用 file URL。

## 扩展方式

- 同一设计问题的候选方案：在已有实验中增加布局，共用样本与进度，不复制一整页。
- 新的对话文本：编辑 `dialogue/sample.js`；姓名、正文和旁白标记属于数据，布局规则放在 CSS。
- 新的对象关系样本：在 `grouping/main.js` 的 `reset()` 扩展。对象承载目标与进度，行动通过 `targets` 引用目标，Container 只代表地点范围。
- 独立设计问题：增加独立页面及同名目录，并在入口导航与本表登记。等确有重复时再提取共用组件，不预先建立通用 UI 框架。
- 对照应说明观察什么、交互方法与局限；截图只记录可审阅结果，不代替可体验原型。

## 共同约束

统一 720 高设计画布，不按设备切换尺寸或结构；可用宽度影响缩放／宽高比。纸白为正文，暖金 `#E8C35A` 强调行动与收益，红色 `#E83323` 表示损伤与失败；正式 Unity Linear 项目的色值转换仍由运行时颜色令牌统一处理。

对话默认使用尼尔与夜莺描线资源，右侧版保留连续记录，底部版叠在完整人物舞台上。两种布局共享对白、选择与阅读进度。进入时两个人物从左右缓动滑入，退出时反向退场；发言者抬亮并微微上提，旁白时双方保持可见。入退场期间通过真实 disabled 状态锁定推进，场景原控件使用 inert，退出后恢复原状态。

- 点击对白或空格／Enter：第一次补全当前句，再次推进。文字速度可选舒缓、标准、快速和即显；系统减少动态效果偏好同时减少动画和逐字显示。
- 最后一条开场对白读完后出现选项。可点击、使用方向键切换焦点、按 1／2 选择；后续双方台词仍逐句播放，不会一次跳过两句。
- 画面右上角“自动”按阅读停留时间推进，到选择或结尾暂停。“回看”打开已发生的记录并暂停播放；Esc 先关闭回看，再次按下退出对话。回看时画布内其他控件 inert，外部工作台仍可操作。
- “重播入场”重新体验当前布局的完整开场；切换候选布局不重置进度。关闭后可从“对话”再次进入。

“替换人物画像”位于画布外。双方分别支持选择本地 PNG／JPEG／WebP／AVIF，或填写 HTTP(S) 图片地址／相对本页面的项目路径；可调整姓名、画幅缩放、上下位置和左右镜像。默认图片使用黑底白线的亮度蒙版；替换图片默认保留原图颜色与透明度，也可切回描线蒙版。推荐透明 PNG／WebP，不自动去除背景。无效图片、读取超时或超过 20 MB 会反馈并保留当前画像；异步加载较慢的旧请求不会覆盖新选择。恢复默认只影响对应角色。图片与参数只留在当前浏览器预览会话，重播和布局切换保留，刷新恢复默认，不写入正式游戏或存档。

画像设置下方增加“人物与场景”调节区。先选择左／右人物，再用“原始颜色”“夜景融合”“偏暗冷光”“酒馆暖光”比较；“原图对比”暂时关闭调色，返回后保留原参数。“精调明暗、冷暖与边缘”支持亮度、对比度、饱和度、冷暖、0–1.5 像素边缘柔化和底部淡出。底部淡出按源图片画布高度计算，因此画幅和留白会影响结果。背景参照可在城市场景、深蓝和中灰之间切换，方便检查图片边缘与色差。上述效果只改变舞台显示，源 PNG 保持原样，重播或切换布局保留当前调节。未发言人物通过降低亮度变暗，维持正常透明度，避免实心画像透出身后的建筑。

对话数据仍来自 `dialogue/sample.js`，仅为排版与交互示例，不写入正式剧情。演出节奏参考 [inkle 对 Heaven’s Vault 对话节奏的说明](https://medium.com/@inklestudios/pacing-dialogue-5bd5a99bfc20)，入退场与缓动参考 [Ren’Py 的 transition 体系](https://www.renpy.org/doc/html/transitions.html)；本原型保留 SSNoir 的统一画布与描线人物。

编组默认以 Citizen Sleeper 式“两翼行动 → 场景对象 → 下方目标牌”为探索方向。其他对象以入口切换展开；密集样本使用摘要与局部展开，不宣称六组完整卡片能同时排下。跨目标影响单独标识，不合并对象身份。尚未验证 Unity 投影、遮挡与动态镜头。

原型测试覆盖放骰、推进、选择、布局切换与关闭；正式数值、叙事和可发布性以 Engine、内容脚本及 Unity 实际验证为准。工程构建和回归证据应放 `artifacts/工程验证/`，不放本目录。

工作台界面分为一级实验导航与二级候选布局。对话模式隐藏行动控制与说明；布局按钮直接切换并保留当前进度。行动样本参数默认折叠。预览是页面内区域，不锁住外部实验导航。

## 事件单页实验

`event-sheet.html` 与 `event-sheet/` 提供独立的分格事件呈现实验，沿用 1280 × 720 画布。淡黄纸张上不设标题与插画分隔线；每件事由三个 beat 组成，每拍一幅墨线示意与一句话。三格与下方三行文字依次同步淡入，已出现内容保留，正文末尾显示并排的小型效果标签，底部显示关闭按钮；点击图文可提前推进。可切换包扎、逗笑、房租、报纸示例，首次包扎可接两句对白。文字默认即显，插画先浮现、文字紧随；打字模式连续书写，下一句开始时同步淡入下一格，不再逐句停顿。插画可关闭，减少动态效果偏好关闭动画。工作台可重放，不写入游戏状态。正式 Spotlight 尚未改造，示例文本和数值仅供排版评审。

分格选择支持三格等宽、末格放大、中间特写，以及左大右侧上下两格。默认末格放大。布局只决定画格比例和位置，切换保留播放进度；beat 的图文顺序不变。墨线示意保留整幅画，不自动裁切，正式插画需要按目标画幅构图。
