## 故事和控制

对白来自 `../portrait-stage-lab/src/baselines/stories.js` 中完整 truth 段落；长句仅为字幕分拍，没有更改含义或删去对话。总长约 78 秒，22 拍。含两次质问、夜莺的解释、沉默疏远、她先带路和尼尔延后跟上。无新配音。

播放/暂停、重播、上一拍/下一拍、进度拖动及 0.5/1/2/3 倍速度。画风、参数与比较模式不重置播放器。同一拍点的三组画风并排同步；远景另外提供三个固定预设对照。

`story.js` 保存内容与关键状态，`player.js` 负责时间和播放，`cast.js` 负责图片映射，`scenery.js` 负责线条布景，`main.js` 组织界面。纯静态模块页面，无新依赖。

## 第五轮：Claude 提示词与实时后处理编辑器

按用户要求直接加入编辑器，未继续操作浏览器或提交生图。读取用户粘贴的 Claude 建议作为设计资料，提取通用底稿、负面提示词和十二个风格片段到 prompt-library.js；没有执行资料中“先各生成四张”或拆姿势的建议。提示词工作台支持多选组合、编辑底稿/负面词、锁定当前身份/服装/同一姿势，并选中文本供复制；点击实时预设同时选中对应提示词（推荐组合为 1+2+4）。

实时预设包含原画、暗填充细亮线、单侧金边、墨线轮廓、等高线覆盖示意、Deco 色板、黑白高对比、版画排线示意、蓝图施工线示意、霓虹边缘、雨雾柔边和推荐组合。参数增加原画亮区提取及门槛、完整/单侧/内侧细边、辉光、下端渐隐、人物颗粒、红蓝错位、主体色板档数、暖色区域估计、覆盖线强度。有限色板将主体亮度映射到填充色与描线色间的 2–5 档；其他叠层可能增加最终屏幕颜色。亮区提取不是人工分离的干净线稿；暖色识别不是语义分割，不虚构嘴唇或围巾。

UI 明确指出：覆盖等高线和施工线是示意，无法从位图恢复真实人体体积；镂空剪纸、单线连笔、实际书法笔重、Potrace 矢量化、头发/手臂拆层需要新素材或加工。没有把资料中这些方向说成已生成的资产或功能。现有角色图、故事进度控制、同步对照及走位保留；用户刷新页面后加载新模块。

检查：模块语法、12 种提示词、12 个预设及全参数组合滤镜生成检查通过；滤镜 SVG XML 均可解析，无 NaN/undefined，目标人物与渐隐设置正确。编辑器与提示词模块 HTTP 200。遵从用户减少 computer use 的要求，本轮未做浏览器视觉/交互验收，不将上述静态与模块检查称作实际渲染验证。
