## 原稿源码分析

来源：用户给出的 `Downloads/立绘剧场 · 线绘世界 · Claude Sonnet 5.5.html`。浏览器安全策略拒绝 `file:` 页面，未截图或实际播放该原稿；以下属于源码证据。

- `world` 是独立城市层，入场缩放到 7.2，应用 `blur(6px) brightness(1.4)`，随后 opacity 为 0。演出时城市已经退场，并非始终保持模糊背景。
- `hotel`、`lamp` 是另外绘制的舞台：描线动画后给主体填近黑色，提供遮挡与体积。线条并非全部悬空透视的线框。
- 酒店通过正面立面、重复窗格、柱廊、门与电铃组织大尺度空间；门光与局部窗光成为叙事焦点。路灯通过一根灯杆、路沿、光锥与地面椭圆组织小空间，两个人从左右进入。
- `blur` 在背景 SVG 与人物 SVG 之间，用径向遮罩保留中心、模糊边缘。`iris` 再降低外围明暗，人物在二者上方保持清楚。
- 酒店光孔参数 20%/52%，路灯为 34%/62%；但标准 `mask-image` 的停止点固定为 22%/62%，只有 WebKit 声明采用变量，因此不能把两组数字直接当作跨浏览器实际模糊范围。
- 道具和环境响应对白：门开启、窗灯亮灭、路灯闪动/变暗，而不仅是更换背景。

## 新实验

新场景为「码头仓库檐下」：屋顶与檐口的大轮廓、卷门、侧门、吊灯、路沿，用稀疏线构成位置关系。另有简洁路灯布景。人物尺寸、地面基线固定，不做平台分支。

远景三个预设：完全退场（alpha 0）、重度失焦（虚拟 1600 宽下 blur 28 / alpha 24%）、3D 残影（blur 5 / alpha 30%）。可独立调整模糊、残留与舞台线条。并排比较保持人物、布景、站位相同，远景使用三个固定预设。模糊按容器宽度缩放，保证缩略图与主画面同等失焦比例。

人物三种处理：原色；低饱和并压低明暗；低饱和加局部暖色受光及接触/延伸投影。使用 alpha mask 叠加克制的暖光，并非生成了新人物或获得了真实 3D 光照。已有体块立绘保持身份、服装、朝向和脚底基线。当前演出采用 Claude 原版路灯戏的对白与等待节奏，共 32 拍、约 57 秒，支持暂停、逐拍、拖动进度与倍速。主画风收拢为 N2 / C1，两人统一中性姿势，尼尔已生成成组版本；历史方向折叠。脚步、电流声、灯闪与逐字字幕共用时间轴。说话时人物保持稳定，只有走路有轻微起伏。详细制作与验收见 CAST-STUDY.md。

素材来源：`portrait-stage-lab/public/assets/filled-cast/` 的尼尔站立、夜莺站立/低头 PNG；`world-stage/hotel.png` 的现有 Unity 建筑机位图。底图为俯视建筑，和舞台眼平透视不同，只能检验城市残影的干扰程度；不能据此下结论说所有匹配机位的 3D 背景都不好。

## 当前判断

大建筑场景优先采用城市退场，靠舞台线条提供明确的空间。路灯可容许极弱的失焦远景，但俯视残影会叠出另一种透视，不如退场或重度失焦干净。人物融合最明显的改善来自共同地面和光源，不需要把人物改成纯线条。面部仍须比环境清楚；第一轮过暗调色已经回调。建筑线条避开头部与主要动作区域。
