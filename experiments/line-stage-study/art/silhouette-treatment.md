# Neon 剪影遮挡试验

编辑器增加独立「剪影遮挡（原版 Neon）」开关、底色、强度和边缘柔化；复用人物目标选择，不需要启用原有调色滤镜。默认关闭，便于用户比较。该层在人物原图下面，Neon 图片不修改。SVG 遮罩由导入脚本中的人工轮廓路径生成，与原图裁切 viewBox 对齐并跟随镜像、位置和离场透明度。仅 originalNeon 生效；其他填色图不加此遮罩。夜莺手臂内侧有独立留空路径。

雨线放到人物背后，避免穿脸。原稿的发光像素并不是人体实体，遮罩轮廓是人工近似，肩手和头发的贴合仍需实际舞台审阅；不宣称从 alpha 自动恢复了身体。

检查：editor.js 模块语法、默认开关与两张 SVG 资源检查通过。浏览器实际对比雨夜故事「门铃响起」同一进度下的开关状态，确认开启后门框与对讲机线条不再穿过人物。修复旧 CSS 缓存导致遮罩层为 static、宽高为 0 的问题，样式链接增加版本参数。视觉记录：silhouette-fixed.png。未运行 Unity。
