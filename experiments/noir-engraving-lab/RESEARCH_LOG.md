## Baseline 0.1

当前版本建立第一套可运行基线：

- 无纹理程序化街区；
- 选择性 EdgesGeometry 描线；
- 冷色主光 / 补光；
- 雨、指数雾、街灯光锥；
- Bloom；
- luminance → black/white normalization → finite levels → Bayer dither → cold ramp；
- 四个固定镜头。

这仍是“基线”，不是经过验证的最终画风。下一阶段先研究 Shape，不继续叠加新效果。


## 2026-10-03 — Hero / Context / Silence

**问题**

普通街屋的轮廓线是否真的帮助空间阅读，还是把背景重新拉回前景。

**固定条件**

四个 benchmark 镜头、几何、主光、空气和 Print 均保持不变。

**变量**

普通街屋主体从 Context 改为 Silence；剧院、仓库和后巷连桥继续保留 Hero，少数结构细节保留 Context。重新加入轻量 Line 诊断。

**观察**

- 01 剧院：Hero 线仍明确强调剧院，普通街屋消失的结构线没有破坏街道纵深。
- 02 仓库：仓库屋顶与主体轮廓仍可读，远处街屋更安静。
- 03 后巷：连桥仍是唯一明显结构线之一，前景黑块没有被重新勾亮。
- 04 城市压缩：街屋不再形成连续白边，建筑层级更依赖明暗面和 silhouette。
- Shape → Line 的平均亮度变化在四镜头中约为 +0.001 到 +0.002，说明线层开始从“全局滤镜”退回为稀疏的信息层。

**结论**

- 保留：Hero / Context / Silence 三级语义，其中 Silence 是正式的一等状态。
- 放弃：普通背景建筑默认描边。
- 尚不确定：Context 的 0.11 opacity 是否还可继续降低，暂不调整。

**原因**

线仍能帮助关键物件被识别，但背景不再因为几何边缘本身而获得视觉优先级。这样更符合“显示什么与不显示什么同样重要”的 Noir Engraving 原则。

**迁回 Unity**

CityBox 资产应允许显式的 line importance / outline mask，而不是统一屏幕空间 Outline。Hero、Context、Silence 应由叙事和构图层级决定。


## 2026-10-03 — 低角度侧后主光

**问题**

全局主光是否可以减少道路亮面积，同时保留建筑垂直面的可读性。

**固定条件**

四镜头、几何、线层、仓库/后巷叙事光和 Print 均不变。

**变量**

主光从较高的 [-42, 30, -28] 改为更低的 [-44, 17, -30]，强度不变。

**观察**

- 01 剧院：道路明显退暗，建筑侧面仍保持层级。
- 02 仓库：Final 中 bright>20% 从约 38.3% 降至 25.4%，此前抢眼的道路亮面缩小，仓库工作区仍可读。
- 03 后巷：由于灯光层隔离，几乎不受影响，证明叙事光隔离有效。
- 04 城市压缩：水平面更黑，明暗带更接近街道峡谷，而不是均匀照亮的城市模型。

**结论**

- 保留：更低、更掠射的全局侧后主光。
- 放弃：让全局 Key 以较陡角度同时照亮道路和建筑。
- 尚不确定：是否还需要进一步把 Context 建筑从全局 Key 中分层隔离。

**原因**

在相同强度下，降低入射角自然减少水平面的受光，同时加强垂直面的方向感。这比单独压暗道路材质更接近可迁移的摄影规律。

**迁回 Unity**

优先从 Directional / large-area key 的方向关系控制水平面与垂直面的受光比例，而不是依赖后处理压暗地面。


## 2026-10-03 — 稀疏叙事色墨

**问题**

Noir Print 是否应该把所有叙事色都压成冷白，还是允许极少量暖色 / 红色穿透。

**固定条件**

四镜头、几何、线层、灯光、空气、黑白归一化、有限色阶与 Dither 均不变。

**变量**

Print 在冷色 ramp 之后增加严格的色度门控：只有源画面中确实具有明显红色或暖黄色偏向、且亮度处于可读区间的像素，才混入少量 red / warm ink。

**观察**

- 01 剧院：竖牌重新保留暗红色，入口与极少数灯点保留暖色；建筑和雨仍保持冷色版画。
- 02 仓库：主体几乎不受影响，只留下很少的暖色灯点，没有出现整体彩色化。
- 03 后巷：远端门从冷白恢复为唯一暖色目标，近中景仍保持黑蓝。
- 04 城市压缩：红色剧院牌与少数暖窗可作为远距离定位点，其余城市保持冷色。

**结论**

- 保留：经过色度门控的少量叙事色墨。
- 放弃：Final 阶段把红牌、暖门等叙事信号统一压成冷白。
- 尚不确定：不同剧情状态是否需要动态更换色墨配额，留到 Narrative Image 阶段。

**原因**

色彩不是环境装饰，而是稀缺的信息资源。只允许极少数有理由的物件穿透 Print，可以保留版画统一性，同时让叙事亮点拥有与冷白高光不同的语义。

**迁回 Unity**

SSNoirStylize 可在最终冷色量化之后增加受 mask / chroma gate 控制的 narrative ink 通道；不应恢复通用全彩材质。
