# 夜城视觉迁往 Unity：以已接受画面为基准

目标：保留同一城市几何，把 Three.js 已接受的材质、光照、大气、画面处理和活动分别迁入现有 Unity 城市实现。不是重新设计画风。UI 暂不在范围内。

## 已接受参数

2026-10-04 用户当前页面完整参数已读取：40辆车，车速1，尾迹12、亮度0.65、尾灯红度0.12；4艘船，船速1、尾波0.30；路灯光晕0.65，光池1，暖点光增益0.40，Bloom0.26，窗光1，流动雾0.30，颗粒0.022，饱和0.78，曝光1.15。已写入 config/visualProfile.js，其余隐藏参数保留。

这些是 Three.js 管线的控制值，不可直接当作 Unity 等值参数；灯光单位、HDR、Bloom 与色彩处理实现均需对照画面校准。

## 本地代码审计结果（未运行 Unity）

- Unity 使用 URP 14.0.12，已有 WorldPalette.asset、CitySharedMaterialImporter、CityWorldVisuals、CityWorldOverview。正式资产继续走 CityBox 的 City.fbx，不导入实验 GLB 替代发布链。
- 世界机位当前配光是两盏方向光（主光0.85、补光0.14）加线性距离雾（1450–2300）；Three.js 则有不同主光方向、地面高度雾和流动雾，以及14个暖点光、辉光 sprite、地面光池三种不同职责。
- Main.unity 的相机序列化配置 m_RenderPostProcessing=0；Global Volume Profile 的 Bloom、Tonemapping、ColorAdjustments、FilmGrain、Vignette 都 active=0。检索未发现运行时代码直接启用这些效果。实际运行画面仍需后续确认。
- 旧 SSNoirStylizeFeature 的序列化 Intensity=0，当前不能归因于其正在覆盖颜色；其算法会把亮度映射到蓝灰色阶，迁移时应继续保持关闭，避免未来重新启用后抹掉暖光/霓虹色相。视频使用该 Feature 的共享材质，不能随意删掉全局功能。
- 原建筑材质、窗光及描线已有共享映射，但值与 Three.js 替换材质不同。主要轮廓是 CityBox 已生成的几何描线，不需要加一次全边屏幕描线。

## 建议实现顺序

1. **固定对照条件**：同一城市版本、世界镜头、16:9画幅和分辨率；隐藏UI。核对 Three.js GLB 是否与当前正式 City.fbx 属于同一构建。Three.js 世界机位[-1040,960,110]、目标[-226.1,82.1,27.7]、垂直FOV22.87。依据项目坐标契约，Unity位置应为[1040,960,110]、目标[226.1,82.1,27.7]，另乘City根缩放；先核对实际导入变换。
2. **先对齐静态画面**：沿用 WorldPalette 的材质角色，校准建筑暗面、蓝灰环境线、暖/冷窗、象牙发光地标。普通建筑用受光材质；窗和主要轮廓采用独立发光表现，不让普通建筑也发光。
3. **复现光源职责**：扩展 CityWorldOverview 的世界灯光，冷主光建立建筑面；暖点光照亮局部立面；billboard 提供灯晕；贴地渐变面提供光池。后三者强度独立。移动端先保留少量实际点光，其余光池/辉光用廉价几何，不逐盏添加实时阴影。
4. **复现后处理与雾**：先使用 URP Bloom/调色作为可运行起点；高度雾、流动雾与暗部颗粒必要时把 referencePost.js 的数学逻辑移植到独立 Renderer Feature/HLSL。管线阶段应按原 HDR 链核对，不直接照抄URP默认顺序；原实验顺序是场景→Bloom→大气→调色/颗粒→Output，ACES与曝光的实际生效位置需核对。避免与内置色调映射重复处理。只启用世界所需的配置，确保地点/视频不被不加区分地改色。
5. **静态画面通过后再加活动**：从 CityBox 导出正式道路/河道数据，复用确定性路径驱动车、短尾迹、船与尾波；不要让 Unity 正式运行依赖实验室 public/ 文件夹。

## 工程边界与验收

在现有 WorldPalette / Overview 入口上实现，新增小而明确的环境后处理与活动模块，不另建第二个城市管理系统。先取得一张 Unity 世界无UI画面对照，再检查一个聚焦地点的画风延续；不要同时重建建筑和更换材质算法，避免无法定位差异。

对照看建筑体块是否仍可读、暖光面积、地标辉光宽度、线条主次、暗部层次与颜色关系。无需承诺像素一致；不能把“Unity编译通过”当作视觉迁移完成。最终需实际Unity截图和手机性能检查。

迁移已于2026-10-04落地第一版，正式 Unity 世界/码头 Editor 与 Play 预览通过。实现、截图、范围与未验证项见 `city-box/prefabs/review/世界/Unity夜城迁移/README.md`。
