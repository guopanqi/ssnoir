# Design: Noir Theatre Engraving

## 视觉假设

这个方向不是“把 3D 渲成一张版画”，而是让 3D 世界按舞台布景的原则被观看：大部分世界允许消失，少数形体被硬光切出来，线只在需要解释结构时出现，排线只承担媒介统一和暗部方向感。

### 1. Shape — 建筑模型

宏观城市首先必须靠轮廓和高低关系成立。局部后巷首先必须靠墙、门、消防梯、人物和前景遮挡成立。即使关掉线刻与最终印刷层，也应当可读。

### 2. Light — 黑色电影

灯光不是平均照明。城市用一盏高位硬 key 决定屋顶和街谷的关系；后巷用门光、逆光和极弱环境光建立阅读焦点。普通路灯不自动成为柔和点光源。

### 3. Line — 选择性解释

结构线来自两层：少量几何 EdgesGeometry + 屏幕空间亮度边缘。两者都受阈值限制，不追求每个物体都有轮廓。

### 4. Print — 有限灰阶与局部排线

排线只在暗部出现，且使用两组方向不同、阈值不同的线；中亮部保持干净。最终图像使用有限灰阶、极轻颗粒和暗角，但不使用 Bloom。

## 不做的事情

- 不使用模型表面贴图建立风格。
- 不为单一截图写 Shader 分支。
- 不全场描边。
- 不通过霓虹色或强 Bloom 制造“黑色电影感”。
- 不让两个场景拥有两套完全不同的后处理参数。

## 循环规则

每轮至少看四个固定镜头。一次主要只改一个层级，并在 `RESEARCH_LOG.md` 记录观察与结论。自动指标只负责发现退化，不替代视觉判断。
