# 桥头＋周边街区：尺度实验

预览：http://127.0.0.1:5173/district.html（默认世界远景）。
源码：`src/district-study/`；入口：`district.html`；独立构建：`npx vite build --config vite.district.config.js`；截图：`captures/district-study/`（本地生成，Git 忽略）。

## 主要问题

桥头已认可的描线与块面，扩展到两岸数个街区后，能否在世界、街区和地点尺度维持同一种视觉语言？

固定桥头主体和共用 `src/post/bridgePrint.js` 的明暗映射、曝光。扩展河道、岸线和支路，加入普通街屋、低矮沿河门面、阶梯办公楼、锯齿屋顶仓库、水塔、两座次要桥和更远的城市剪影。两岸使用不同的高度节奏，桥头保留最集中的银白亮面。所有模型仍是程序化几何；没有使用游戏原有网格，没有替换正式地图、Scheme 或 Unity 资源。

## 机位与对照

- `?view=world`：世界远景，检查河道、地标、亮区与整体密度。
- `?view=district`：街区中景，检查背景与桥头的层级。
- `?view=bridge`：桥头近景，检查扩展后是否损坏原局部构图。
- `?view=reverse`：对岸回望，检查其他方向的遮挡与阴影。

“受光 / 描线”切换最终明暗整理。“随距离简化线条”默认开启，可以关闭对照。
简化按线条包围球估算屏幕像素大小，省略太小的线条，不改模型实体，不按设备或特定机位设置隐藏分支。它并非完整的 LOD 系统：当前采用硬阈值，临界尺寸可能出现跳变；网格细节、亮窗和雾不受该开关控制。
H 隐藏面板，拖动旋转，滚轮缩放；点击固定机位恢复相机。

## 观察与限制

缩远时以河道、跨河亮面、屋顶群和地标剪影阅读；靠近后栏杆、窗线、拱廊恢复。普通建筑仅强调檐口与少量窗带，避免远景的全棱线网。
仍存在程序化街屋形体重复、道路过于规则、地面留白偏大的问题；此次研究尺度关系，不是正式城市重做，也没有接入地点导航、碰撞或游戏数据。扩大的阴影覆盖范围会降低局部阴影精度，不能把这一实验的阴影配置当作已优化的移动端方案。

迁移到 Unity 时，应保留街区/地标层级、岸线与亮面组织、按屏幕尺寸减少结构线的原则；重新实现对应材质与线条系统，再用真实世界资产验证。
