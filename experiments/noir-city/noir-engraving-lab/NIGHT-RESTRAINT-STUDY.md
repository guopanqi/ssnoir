入口：`http://127.0.0.1:5173/night-restraint.html?view=world`。四个 URL 机位：world（原世界）、quay（原北岸）、avenue（原长街）、reverse（原屋顶）。恒定 16:9；拖动旋转，滚轮缩放。没有 HUD、地标标签或调参 GUI。

## 用户确认的基准

用户称“夜与霓虹”的对应文件是 CityBox 的 `prefabs/review/世界/雾与霓虹`。其整体风格正确，任务是减少脏感，不是重新设计画风。初轮银蓝色、第二轮只恢复近似颜色的方案均被用户否定：遗漏了太多原画面的内容与氛围。两轮替代管线已经移除。

当前直接复制原 world.js/post.js 到独立实验的 scene/referenceCity.js、post/referencePost.js。city.glb、roads.json、lamps.json 是原实验资源的独立快照。原实验源文件未修改。保留全部原材质分类、月光方向、14 个暖点光对建筑的照明、路灯辉光/光池、地标发光描线、天空、高度雾、流动雾、原河面处理、窗光与原机位。

- 颗粒 .05 → .008；色差 .0016 → 0。
- Bloom .42 → .38，保留半径和阈值；路灯辉光增益 1 → .9，光池与真实点光保持 1。
- 饱和度 .82 → .78；不替换原建筑/窗光色彩。
- 六种彩色灯牌收为珊瑚、青绿、琥珀三种；数量仍为 16，灯牌 halo opacity .32 → .24。
- 原道路、46 辆车与头尾车灯保留；补充车体和车顶，车身方向跟随行进方向。

全局清理参数在 config/visualProfile.js；原材质分配保存在 referenceCity.js，避免再改写原画风。镜头只在 shots.js。main.js 只装配与同步。

## 恢复原版 UI 与标签稳定性（最新）

用户反馈两个地点标签持续抖动，并要求布局和基本样式以原实验为准。HUD 现在直接取自原 hud.js/index.html 的人物剪影、任务框、卡片刻痕、菜单和物品布局；独立包装保持固定720设计高度与聚焦/返回、参数面板。仅收束成灰白文字/细边及一处淡琥珀交互色，取消多主题入口。原实验未修改，拖拽仍移除，仅提供选中预览。

标签原代码本来已复制一致。静态审阅发现 placed 与 hudZones 共用数组，追加标签后可把标签矩形误认为 HUD（没有 dir 字段），导致无效避让；已拆开数组。保留原屏幕投影、引线和碰撞避让，移除避让成功后定时回落引发的往返，让偏移在镜头静止时保持稳定；镜头投影明显移动或视口改变时重新计算。HUD避让区域随统一设计缩放。

验证：独立构建通过，已查看并保存 ui-reference.jpg 整体截图。未进行持续动画的深入 computer use 测试；标签稳定性与手动镜头体验交给用户复核。
