# Portrait Theatre：立绘剧场表达力实验

独立的网页短戏实验。原生 JavaScript、HTML/CSS 与 Web Animations API，Vite 仅用于本地服务和构建。

```bash
cd experiments/portrait-stage-lab
npm install
npm run dev -- --port 5178
```

浏览器打开终端显示的地址。`npm run build` 生成 `dist/`。

## 内容与交互

- 雨夜来客：人物进场、电铃画外回应、停顿、低头、开门与退场。
- 一份赔钱的委托：双人对白、隐瞒、准备离开、叫住与接近。
- 舞台动作试台：单独试验并行移动、换姿势、变暗、震动与闪光。

七组表达力短戏，其中四组提供 A/B 对照，默认进入《那包烟》：

- 《那包烟》：对白相同，比较静态对白与停顿、低头；加入烟盒道具。
- 《把地址写下来》：对白相同，比较保持距离与退开半步；静态版保留等长等待。
- 《上车再答应》：对白相同，比较三人静态对白与经理中途入场、改变站位。
- 《门前的一句话》：对白和回身距离相同，只比较立即转回与停住后转回。
- 《门还开着》：守门剪影堵住出口，弗兰克从画外说话，检验非暴力威胁。
- 《那封信先留下》：移动信件、人物延迟反应与收起，刻意检验缺少伸手姿势的边界。
- 《灯灭的那一刻》：黑场、合成脚步和撞击、画外倒下与灯光恢复；建议开启声音。

使用 A/B 按钮切换版本，会从头重新播放。幕落后显示三个观察问题，不记录或评分玩家回答。经理是 Gemini 新生成的一张姿势立绘，提示词、原图与 manifest 保存在 `art/`，`tools/prepare-manager.mjs` 输出透明素材。

自动播放按字数留阅读时间，暂停时停止计时；也可随时手动推进。隐藏字幕观察会强制自动播放、隐藏对白及场内标题，只保留舞台表演，关闭后恢复此前的自动播放偏好。没有角色配音，因此隐藏字幕只检验动作、空间和停顿，不能评价对白或声音表演。

点击舞台、Enter 或空格推进对白：第一次补全打字，第二次进入下一句。无字动作自动完成。P 暂停，R 重播。按钮支持选择场次、声音开关和试演面板。面板可跳到任意拍；跳拍先重建前面拍点的最终状态，避免错位。重播或切换场次取消旧演出。

声音是 Web Audio 合成雨声、电铃、门锁、脚步与撞击提示，没有角色配音。默认静音，手动开启。固定 1280×720 舞台按容器等比缩放，所有设备采用同一布局。

## 文件边界

- `src/stories.js`：角色素材、原始短戏。
- `src/studies.js`：七组实验剧本、版本与观察问题。
- `src/stage.js`：人物、环境、声音、动画和特效。
- `src/player.js`：播放顺序、等待、暂停与跳拍。
- `src/main.js`：页面、素材预载和试演控制。
- `src/style.css`：舞台与实验页面样式。
- `art/nightingale-prompt.txt`、`art/neil-prompt.txt`：Gemini 最终提示词。
- `art/nightingale-poses.png`、`art/neil-poses.png`：Gemini 原始双姿势图，保留制作来源。
- `tools/prepare-cast.mjs`：绿幕去背景、裁切与每人两姿势脚底对齐；输出到 `public/assets/`。

人物是本实验独立设计的 1940 年代剪纸印刷风格，不替换正式游戏立绘。夜莺、尼尔每人两张姿势图，经理一张。背景和电铃为 SVG/CSS，分层便于演出。缺失人物、姿势、场景或未知指令会直接报错。

## 编排原则

台词不自动附带动作。只在情绪、关系或情节改变时移动、换姿势。素材预载完成后才开始演出。无骨骼动画、无每字说话抖动、无自动镜头游走。实验台的幕后注释不进入正式游戏对白。

## 验证

本地 dev 服务启动后，`node tools/check-stage.mjs` 检查原始三场和七组短戏与全部 A/B 全流程、隐藏字幕自动播放、暂停、跳拍道具重建、对照站位和较窄窗口无横向溢出。`node tools/capture.mjs` 导出实际浏览器画面到 `art/preview-*.png`。

守门人复用尼尔图的纯黑剪影，只承担堵路与人数，没有独立身份细节。新增的片段是实验材料，不视为正式故事定稿。观察问题只显示，不保存答案。
