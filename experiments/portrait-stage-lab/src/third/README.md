# 立绘剧场 · 第三版

入口：`http://127.0.0.1:5178/third.html`。第一版 `/`、第二版 `/baselines.html` 保留。

在第一版的播放方式、说话者提亮、试演面板和动作试台上，结合其他实验中用户选定的表达：

- 布景与道具：深色填充、少量表面纹理、明确外边线。雨夜只留下门、门铃和雨，其余场景按剧情保留桌椅、伞、电话等独立道具。
- 人物：重新设计为实心灰色体块、少量明暗面与克制描线的完整 PNG 立绘，不采用 SVG 身体分件。尼尔有站立、摘帽；夜莺有站立、低头；经理有单人和双人搭肩姿势。
- 查看道具：烟盒从手边移动到舞台中央放大，人物压暗；查看结束后收回，人物重新成为注意力中心。不是手指抓握模拟。
- 关系动作：经理先靠近，再进一步；尼尔身体微微后倾，随后切到保持不回应的搭肩姿势。经理离开后尼尔恢复直立。
- 第一版细节：说话者提亮、听者压暗、移动、姿势切换、局部震动、全场闪光、音效、暂停、重播、节点跳转与隐藏字幕继续可用。

六幕剧情基准来自第二版既定文本，另加动作试台。本组是演出实验，不修改正式第一章内容。没有生成环境背景图；少量 SVG 用于道具与布景，PNG 用于人物。

`stories.js` 从既定六幕与第一版动作试台创建本组数据，集中调整演出；`stage.js` 负责道具样式、查看过渡、倾斜与人物光线；`player.js` 扩展查看、倾斜、门、片名、幕布光池等演出指令；`main.js` 保留第一版控制界面。查看与倾斜可重建，暂停也暂停相应动画。三个入口一起打包。

当前人物的原图、提示词与制作说明放在 `art/filled-cast/`，透明立绘在 `public/assets/filled-cast/`，由本组独立的 `cast.js` 引用。生成使用 Gemini Image Web，去背景、裁切和姿势对齐用 `tools/prepare-filled-cast.mjs`。`art/third/` 保留舞台截图及此前搭肩稿。第一、二版仍使用原有角色素材。

运行：原实验目录 `npm run dev -- --port 5178`。
检查：`node tools/check-third.mjs`，使用已安装 Chrome。完整指令链和每个节点重建缩短等待；道具查看与暂停、人物光线、搭肩、窄窗口、隐藏字幕保留实际浏览器交互。没有角色配音；搭肩的两个人是同一张关系姿势，无法分别为两半调亮。

第六幕补充：交接材料后停顿，再用两段慢移走向剧院门。门先打开，尼尔离场后才骤然关上；合门声与局部门框震动同步，随后留 1.8 秒静场。门动画可暂停，跳到末拍也会重建离场和门状态。


电影感补充：整场切换先用 550ms 淡出旧画面，黑底片名用 650ms 淡入、停留 1400ms，再用 950ms 露出舞台，留 350ms 才继续动作。拍点跳转直接重建场面，不重复片名。转场可暂停，快速切场会取消旧演出。

对白为无框、居中的衬线字幕，保留角色色和文字投影。幕布、光池、布景、人物为独立层；`atmospheres.js` 定义冷色雨夜、暖色室内和剧院的冷暖分区。第六场逐步减弱尼尔的光池，离场后经理的光池也收弱。

舞台本身透明，幕布初始不透明度 84%，滑块可调到 0%。「透明底检查」只在舞台下方展示棋盘格，供检查叠加效果，不属于故事布景。光池与边缘暗角仍是独立半透明效果。这是 Web 实验的透明叠加能力，尚未接入正式游戏环境。

## 道具、人物和光的情绪配合

`expressive-scenes.js` 集中保存这一轮各场的演出调整，保持既定对白：雨夜开锁后才出现门边暖光；烟盒辨认时冷光暂时收弱，话题转回后恢复；第三场以路灯替换椅子，两次关键沉默分别闪烁，并延长先走与跟上的间隔；第四场明确接案后才提升暖光；第五场经理离场后电话移向尼尔，留下一小团暖光。

新增 `flicker` 是不改变最终灯态的短暂演出，灯泡和光池一起变暗、恢复；可以暂停。跳到后续拍点只重建稳定状态，不重放闪烁。专项检查为 `node tools/check-expressive.mjs`。
