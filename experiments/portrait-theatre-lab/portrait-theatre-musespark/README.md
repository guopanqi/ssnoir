# Portrait Theatre · musespark（立绘剧场网页实验）

模型：Muse Spark 1.3 Free（目录后缀 `musespark` 即模型名）。

独立网页短戏实验，不依赖已有实验，不依赖 npm / 构建工具。双击 `index.html` 或用任意静态服务器打开即可观看。

```bash
cd experiments/portrait-theatre-musespark
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

## 观看方式

- 顶部选择片段一～六，自动从头播放。
- 点击舞台 / 空格 / 回车：第一次补全打字，第二次进入下一拍。
- 按钮：播放/暂停（P）、重播（R）、上拍/下拍、声音开关（默认关，浏览器自动播放限制）。
- 自动按字数留阅读时间；暂停时停止计时。

## 演什么

按基准剧本原样保留六个片段的对白、事件顺序和人物知情程度，未改故事含义：

1. 雨夜求助（夜莺楼下按铃，尼尔画外电铃回应，雨、开锁、门缝光）
2. 看见烟盒（红色"金牌"烟盒是全场唯一的饱和红色道具，挤变形）
3. 隐瞒莱恩后的争执（面对面→错开→带路，距离表达信任裂痕）
4. 准备离开，被叫住（收东西、戴帽、拿伞、转身、眼泪）
5. 经理安装电话（经理迎上、拍肩、搭肩侵入站位；工人+电话为次要人物/道具）
6. 经理解雇尼尔（尼尔全程沉默缩小，经理保持体面姿态，大门砰地关上）

## 舞台手段（少而有表达力）

- 纯色背景：每幕一色，无背景图、无环境布景；地点只靠 1～2 件道具建立（电铃/门、烟盒、伞帽、电话/线、剧院大门）。
- 人物：内联 SVG 剪影立绘（夜莺/尼尔/经理/工人），无外部图片。姿势只有：常态、低头、转开、靠近/侵入、缩小，无骨骼动画。
- 关系用站位和明暗说：说话者提亮，另一人压暗；疏远拉开距离，亲近/压迫重叠站位。
- 灯光：单聚光 + 说话者高亮；门缝光、剧院顶光为硬切。
- 声音：Web Audio 合成雨、电铃、锁扣、门 slam，无配音、无外部音频。
- 特效只用：雨线、门缝光、烟盒抖动、眼泪两滴、门 slam 震动。

## 文件边界

- `index.html`：结构与控制条。
- `style.css`：舞台、人物、道具、灯光样式。
- `play.js`：六幕拍点数据（对白与舞台指示的唯一来源）。
- `stage.js`：渲染、播放、暂停/重播、声音合成、特效。
- 本目录无依赖、无构建产物，可直接归档。

## 验证

- `node --check play.js && node --check stage.js` 通过。
- 本地开服后人工走完六幕：播放、暂停、重播、跳幕、声音开关均正常；较窄窗口无横向溢出。
