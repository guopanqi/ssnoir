# R220–R227｜同样两件工具，顺序本身改变做出来的东西

日期：2026-10-12。第三条横向研究轴，回到**无人物、无进度条数量差异的操作次序**。源脚本 `tools/content-validator/experiments/r220_r227_noncommuting_order.py`，独立CI `.github/workflows/ssnoir-r220-r227.yml`。没有原生正式内容或新人类体验。本批8项编号**只是一套可证伪的操作序候选与多组因果对照**，不是8种模式。

## 机制卡：玩家实际做什么

手头只有两项操作，一项「+1」，一项「×2」，**必须各执行一次**，数量和总耗时均固定。起始值2。两项操作的顺序可以自行安排，两个可能结果不同：
- 先「+1」后「×2」：`(2+1)×2=6`；
- 先「×2」后「+1」：`2×2+1=5`。

本局的期望结果可能是5，也可能是6，各半。具体要求会**在玩家开始安排操作前公开**。因此反复决策不是把资源投A/B，或买更好的操作，而是**从已经相同的操作库存中，决定执行的顺序**。没有更复杂的隐藏规则，也不存在前置购买成本。

可变奏心理活动是：「观察要产生什么→想清两步操作如何影响彼此→安排执行顺序→得到结果→面对新的输入和目标再组合」。这种活动类似构造表达式、安排程序或工艺流程；它和R194初始套用四种模板、R198根据匹配翻转一个模式相比，更接近**实际操作对象的变换**，但仍是极简纸面实验。

## 分轮反证

| 编号 | 实验 | 精确结论 |
|---|---|---|
| R220 | 固定相同两件工具，把全部2!排列独立展开 | 两种输出明确为**5与6**，不是“多耗一颗骰”造成 |
| R221 | 目标在玩家安排次序**以前**准确公开 | 两种目标均能精确制作，成功率**1**；出发前完全固定次序，只能命中其一，**1/2** |
| R222 | 目标等到执行完第一件操作才公开，而第二件已被库存决定 | 结果**1/2**，晚到的信息无法更改次序 |
| R223 | 把操作改成能交换顺序的「+1」「+2」（同起点2、用同样库存） | 任一排列输出都是5，对两种原定要求5/6，公开目标后最高仍只有**1/2**；证明“操作顺序真有因果”而不仅要求公开 |
| R224 | 换另一组操作与初值：起始3，「−1」「×2」，目标4或5 | 两种顺序各能命中一个目标；及时公开成功1，固定1/2。这个判断可以迁移到第二种组合 |
| R225 | 同一操作库存、相同使用次数、相同成本 | 只有**排列**变了最终结果；这不是P02式选择多拿哪项资源 |
| R226 | 把独立的同类小局连续玩3次，新的目标各自公开 | 每次独立编排都能全部命中，3次全对概率1；如果三次一开始就把全部顺序固定，三次全对概率**1/8** |
| R227 | 最强解释与新颖性 | 当前两个输出只需一条规则“目标5就倍增在前，目标6就倍增在后”，**尚不能认证完整新玩法** |

### 严格控制与未解决的体验问题

R223不仅把成功率“调低”，而是**在操作可交换时顺序不能引起任何差异**，这是检验操作序本身是不是新决策对象的结构性消融；晚到消息则独立检验“知道要做什么”与“此时还来不来得及重新排序”。

但是它也有一个清楚的弱点：玩家实际上只做了**一个二选一排列**，规则极易学会，重复3次还是同样判断。R226的“全对概率”只能说明信息与可控性，不能把反复三局描述为三次新鲜有趣体验。

研究裁决：**候补的不同活动形态——用非交换操作排列产生目标结果**；在现有结构候选20外不自动作为认证模式，不加入精选/Debug。要认真继续，不应该单纯增加数值或操作张数，把两件变十件只会提升排列难度。下一步应先加入一种自然、清楚的反馈：每个操作有可观察的中间效果，且可以决定是否保留/重新排序剩余操作，玩家因此产生反复的表达式推理，而不是死记两条固定答案。再考虑最小可玩体验，问玩家是在理解顺序规则还是只是猜对答案。
