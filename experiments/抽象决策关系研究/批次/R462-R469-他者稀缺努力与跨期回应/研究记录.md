# R462–R469｜第二主体真正权衡自己的跨期努力，玩家在做什么？

2026-10-13。接续R438的“主体只是照自己固定时刻表工作”阴性结论，这次让另一方拥有**有限努力预算、每期可自行工作或休息、为自身三期总利益而规划**。玩家不是它的主人。研究的是抽象决策关系，而非NPC角色剧情。本批8项冻结模型检查；数学与重放，非真人/独立LLM真人模拟。

## 最小循环及完整信息协议

三期。每期先出现双方看得见的独立公共信号 s=A/B（概率各半），玩家选工作A或B。玩家自己的工作算1点，另一方若工作**不同**任务再加1，重复同一任务无额外产出。另一方看到玩家本期动作后，自行选择工作A、工作B或REST；它有总共2份努力，工作扣1，REST不扣。它不直接最大化玩家得分，而按它自己的三期个人收益行动：本期做b获基础收益（t0 A/B均0；t1/t2 A为0、B为1），若b与公共信号一致另外+2，若b与玩家本期工作相同再+2。REST自己的收益0。

双方都知道以上规则、剩余努力、公共信号和每期动作。未来信号尚不知道。玩家每期收到他者的**实际行动**反馈，再决定下一期；另一方用完整未来利益作序贯最优回应，决策权由它自己持有。若另一方自身最优有平局，分别算对玩家最不利/最有利两种规则；玩家自己同分按A优先。没有假装未知性格、不按剧本指派动作。

## 8项可复核反证

| 编号 | 冻结检查与结果 |
|---|---|
| R462 | 双方理性逐期最优：玩家三期覆盖期望 **4**，另一方自身收益 **7**；通过全部2³=8条信号路径独立逐期回放核对 |
| R463 | 第一手信号A，玩家选B、另一方自愿REST；信号B，玩家选A、另一方REST。若玩家在信号A时选A，另一方反而做A造成重复；反之同理 |
| R464 | 第二期仍有2努力时，信号A玩家选A且另一方做A，信号B玩家选A且另一方做B；**玩家对另一方当前努力的影响与第一期不同** |
| R465 | 对方只最大化自己本期收益、不算未来的短视消融：玩家 **7/2**、对方 **13/2**；未来自利优化并非只是将固定NPC表换标签 |
| R466 | 取消“对方做与玩家相同任务得到私益加成”：玩家 **5**、对方 **5**，对方仍理性出力但当前两人的工作选择不再影响其自己的价值 |
| R467 | 改变对方自身收益平局择法为有利玩家：根仍 **4/7**；不能默认为所有中间选择都唯一，但本冻结根稳健 |
| R468 | 玩家**仅第一手**不知道当期公共信号、从第二期恢复完整响应：只能得 **15/4**；同一未来在线协议，不与预承诺整套脚本混比 |
| R469 | 他者的努力由2增到3，玩家仍 **4**、他者自身提升到 **10**。给伙伴更多能力不自动增加玩家的活动或收益 |

**最强无聊策略**：完整8条可达的公共信号路径中，玩家最优动作全部能写成“第一手做与当前信号相反的任务，从第二手起永远做A”。这是真正的自利博弈，但尚没有一个必须反复理解、协商对方的复杂决策循环。反常的局部行为（故意避免让别人现在出力）有研究趣味，不过在当前模型没有证明是新的独立模式。

### 重要边界

- 比R438外源照日程工作更接近**自主目的**：对方会为将来保留努力，而且看到玩家做什么后自己的即时收益会变。
- 仍然是**完全公开规则和收益**的三期序贯有限博弈。没有不完整互相理解、另一个主体的自然生活、外部自发目标变化或真人评价。
- R465短视与未来理性是**不同的对方行为假设**，不能将4−3.5直接说成“玩家适应对方心理得到的增益”；R468才在同一未来理性协议下控制单一公开信号时点。
- 与经典稀缺容量调度、有限前瞻博弈、合作冲突和R390有可归并部分，不晋升第7精选；继续可研究玩家对其真实自身损失的反馈能否产生多次的“改主意”，而不是延长三手造更大策略树。
