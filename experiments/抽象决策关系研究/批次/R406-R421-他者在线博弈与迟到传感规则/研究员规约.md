# 研究员私有规约｜迟到输入测试（未执行真人）

每局独立预先抽出固定的 x、y 序列，x、y均为公平独立0/1；每期按时点**只给x**，参与者承诺 MANUAL-0/1、RUN或EDIT以后才揭示y及判分。不得因为参与者选了 EDIT 或表现差而重抽、换目标、挪动阶段边界。初始4格0000，显示顺序为00/01/10/11。

记录：局、期、目标函数、公开x、隐藏y（不能提前宣读）、操作前四格、参与者动作、操作后四格、得分、参与者逐手原话、是否在下一期主动修正理解。不让记录者用“合理决策/玩家应当”替代真实原话。某一回合 RUN 后的输出由当前四格按实际xy读出；EDIT当期不得RUN。

原型数学内部对照：8期XOR→XNOR晚到传感完整最优21/4，无晚到读取、仅手工、无编辑各4；若玩家无法先观察x再决定编辑/执行，则5；至多编辑一次也21/4。9期XOR→XNOR→XOR时零编辑9/2、一次6、两次或无限次49/8。**这些数字不向参与者提示，绝不能当真人得分或感受**。

记录的关键并非“接近最优”，而是受试者有没有理解两个决策时点、能否跟随阶段切换把同一持久规则重新利用、会不会只有一次编辑就变得机械。不要替模型模拟人类；没有人的回合记录就保持“未执行”。
