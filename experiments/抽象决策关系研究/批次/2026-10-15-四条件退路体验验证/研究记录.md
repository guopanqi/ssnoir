# HEDGE-OBSERVE02｜四条件退路观察协议与独立规则回归

日期：2026-10-15。本批从 HEDGE-REPLAY01、HEDGE原始无答案观察卡和OBSERVE01开始。核心任务不是再证明根收益，而是将“参与者是否真在乎保留旧事”分成可证伪的玩家行为与理解指标。历史反馈inbox仅R37/R50/R54，当前**未开展真人实验**。

## 一、先发现旧观察的混淆项

旧卡按允许并行→禁止重叠→取消早窗的顺序重复试玩，会让同一参与者在第二、第三局提前掌握最佳路线。三局数据不能等同三份独立的首次盲玩；不同组同时改变了窗口和资格，因此需至少2×2因子矩阵，不能把全部体验差异归于“并行”。

冻结HEDGE五行动原规则：OPEN花一手且揭示A价值14/5、B价值14/0（对每个项目独立H/L）；WORK两手完成；DROP一手；SIDE一手收益1；OPEN后三次全局行动仍未完成则−4；终局未关闭的LIVE再受−4。A早窗=只能第一手OPEN A；无早窗=任一时点可OPEN（若从未开过）；禁止重叠=只有当前无LIVE才能OPEN另一项目。不显示推荐线路及最佳期望值。

| 组别 | A仅第一手可以开启 | 可以并行LIVE | 测试的实际差异 |
|---|---|---|---|
| EW-P | 是 | 是 | 早窗下真正可保留A并去查B |
| EW-S | 是 | 否 | A未完成/未放弃时无法OPEN B |
| NW-P | 否 | 是 | 旧A可晚开，是否仍自愿并行 |
| NW-S | 否 | 否 | 无早窗串行是否替代退路 |

单变量对比：EW-P vs EW-S只改并行；EW-P vs NW-P只改早窗；NW-P vs NW-S只改并行；EW-S vs NW-S只改早窗。这四对并不保证心理隔离：同一人反复玩会产生学习，必须按组别分别标记是否首次暴露规则。

## 二、可执行规则审计

[独立Python规则执行器](../../../../tools/content-validator/experiments/hedge_observation_protocol_20261015.py)按OPEN/WORK/DROP/SIDE逐手结算，显示当前合法动作、实际揭晓的H/L、因到期造成的损失；将没有权限的动作直接判为非法，**不擅自改成SIDE**。该文件包含四因子组合的开局许可测试及三套既有代表性政策×四种事件，共12条轨迹的逐行动回放。回归预期：

- 早窗并行公开政策：期望51/4，A完成率3/4，B完成率1/4；
- 早窗串行公开政策：期望47/4，A完成率1/2，B完成率1/4；
- 无早窗串行公开政策：期望51/4，A完成率1/2，B完成率1/2；
- 早窗/允许并行、A=L/B=L 的路径 OPEN_A→OPEN_B→WORK_A→WORK_A→DROP_B，A完工收益5；
- 早窗/禁止重叠同状态必须先DROP A再OPEN B，低低保底路径收益1。

规则执行器独立于原HEDGE动态求解器；**它只检验给定路径的结算，不证明全局最优**。本地运行同协议脚本通过回归，后续仓库可使用 python3 tools/content-validator/experiments/hedge_observation_protocol_20261015.py 再执行。

## 三、真正观察的不是分数，而是三个可独立判定的行为

**O1 事前关切与动作一致性。** 让参与者自由回答“你更想让A完成、B完成、都保住，还是目前都无所谓？为什么？”允许“都无所谓”。保留文本原句和时间戳。记录后续是否真的采取使其关切可达的行动；若在获得信息后改变关切，应原样记录变化而非自动判不一致。

**O2 退路的无提示因果理解。** 当A低但尚可完成、B价值未知时，不主动提醒什么叫退路。观察他是否自己保留A去OPEN B。终局显示总分**之前**，自由问“你当时还能回去完成A吗？为什么？”“是什么让A不再能打开/完成？”将误解、含糊、临场猜对分开编码。

**O3 真实舍弃与反事实理解。** 在发生A=L、B=L或A=L、B=H的分支后，先自由请其解释失去了哪些成果及是哪一步令其失去。再问“如果只能改一手你改哪一手？”分别记录当前局下可行、不可行的结果。只有行动与讲述都指向同一件实际成果，才可初步判断这名参与者确实注意了那项损失；不从数值最优直接读出“责任感”。

这三项之外可记录每手耗时、是否询问合法性、是否抱怨期满罚款或觉得毫无人物意义。人类即使符合最优政策，也可能只是找到口诀；应专门询问是否只感到“低就试新，高就做完”。

## 四、实施顺序与防泄漏要求

1. **首次体验**优先采用不同参与者间分配到EW-P/EW-S/NW-P/NW-S，每人只看自己的规则卡和当前合法动作，不看其它组或最优表。
2. 若必须同人比较四组，事前排列平衡四种开始顺序；第一局是唯一可视为初遇的观察，此后三局标注“已学习”。不能将重复后的平均得分直接解释成机制更好。
3. 建议记录预先固定的A/B类型序列，但不让研究者在局中依据参与者行为临时挑类型；不同组可以对齐相同类型序列。明示演示局/正式局，不能偷偷改变样本。
4. 每一步只宣读公开事实：合法动作、已知OPEN价值、过去行动和截止；绝不提示“留A当备用”“这一步再DROP会最优”。
5. 每局终止后先询问自由因果复述，再公布价值与完整历史。若人类说“不关心A和B”，这是有效负例，不能让其勉强代入角色补救数据。

## 五、原始记录结构与停止阈值

建议每次存 participant_pseudonym、trial_group、order_index、first_exposure、event_seed_or_precommit、initial_priority_raw、actions[{step,visible_state,legal_actions,action,reveal,reason_raw}]、outcome_raw、causal_explanation_raw、counterfactual_raw、observer_interventions、post_explanation、learning_exposure。不要存姓名、账号或其它个人识别信息。

明确负面信号：多数参与者只讨论最优化、误解时间规则、无法解释旧A何时失去行动许可、把规则视作抽象任务列表，或只记住固定口诀，则不能宣称“玩家体验到了并发责任”。如果所有人都主动讲出舍弃的A/B，但看不懂哪步致使损失，优先改进信息呈现，而不是再加行动系统。

## 六、证据等级

本批完成**设计审计 + 因子拆分 + 可执行四规则判定器 + 本地回归**。无真实参与者、无独立盲Agent、无Unity游戏体验、无新原语，严格不扩展精选/Debug/正式Game。旧HEDGE和OBSERVE协议保留为来源；本协议独立补充旧卡的顺序混淆而不替换原历史证据。

下一研究工作不应继续制造第六个没有人试玩的信息/退路模型。优先采集真实初次玩家无提示行动和因果理解；若做不到，研究转向异质结果在策略级的独立证据，不能假设人会感到故事重量。
