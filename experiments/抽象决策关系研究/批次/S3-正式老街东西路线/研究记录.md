# S3第二次收束｜正式《三封信》老街东／西路线的顺序与内容损失

日期：2026-10-12。本报告接续 [S3长阶段](../../S3-并行调查与人物后果阶段计划.md)，直接核对当前唯一运行内容 `UnityClient/Assets/Resources/Content/scenes/world/三封信.scm`。不要把前一篇 [手稿纲要模型](../S3-第一章第二节并发与条件事件/研究记录.md) 当成现行正式规则：**源码中的第二节主调查发生在“码头居民区”的老街东／西空间前沿，不是同期开出一条“码头目击者”Scenario。** 码头另一次“寻找莱恩”调查属于第三封信阶段（现行 story-stage 的后续小节）。这是本轮必须保留的**版本纠错**。

## Ⅰ 正式内容的真实玩家动作

- 尼尔第一趟独闯老街：`warren-alone-max=6`，好/中档推进2/1，坏档扣冷静，2格和4格分别发生被拒绝的情节，满6只揭示“一个外来人办不了”，**不会自己找到莱恩**。这一拍完成时原生调用夜莺对白、把陪同日定为 `world-day + singer-wait-days`，并展示“明天巷口会合”。
- 约定那天，夜莺自动加入，同伴能力改变实际社交判定。同行之后老街只有**东／西两条路线**，各需要两段，每段进度上限4；完成一段，下一段的位置卡才出现，不是让玩家在同一UI中刷四根相同的钟。
- 东侧门廊4 → 东侧回廊4，最终见弗兰克，得知他不是勒索者，可建立一条人物关系。西侧楼梯4 → **额外一道需掷骰解决的拦路事件** → 上层桥廊4，最终住户指出“莱恩”，引发夜莺个人关系的揭露。
- 西路名字揭晓 `bridge-identified? #t` **立即隐藏未完成的东侧路线卡**；之后如果还没见过弗兰克，另有“自己走东侧那条回廊”这张8格的单独调查。只有之前东侧门廊已满4时才预先给这张新任务**2格**；门廊不足4／东侧回廊的残余进度不会完整转用。
- 一件真实可选的独立资源关系：若仍有金牌香烟且走通东侧门廊，玩家可以**把烟盒交给柜台**，无须掷骰，东侧回廊直接前进2格，但唯一物证被拿走。它是“有限实物→局部情报和省行动”的可见交换，而不是另加一种等待钟表。还没有对这个交换完整后期物证价值做强反证，不应先认定必用或必留。

## Ⅱ 无须随机计算即可证明的顺序边界

先暂时只数投入的有效**进度格**，不把进度当行动次数（原生实际结果0/1/2且有冷静风险、不同技能）；忽略西侧额外拦路、烟盒和人物对白：

| 计划 | 东线／弗兰克所需进度 + 西线／莱恩所需进度 | 合计 |
|---|---|---:|
| 东侧两段全部走满后，西侧查出名字 | 8+8 | **16** |
| 西侧先查到名字，此后单独寻找弗兰克 | 8+8 | **16** |
| 东侧门廊4格刚走满就转西侧，之后再单独找弗兰克 | 4+8+6 | **18** |
| 东侧门廊只走出1格就转西侧，之后再单独找弗兰克 | 1+8+8 | **17** |
| 东侧门廊4格、回廊又2格，就转西侧，之后单独找弗兰克 | 4+2+8+6 | **20** |

因此，源码注释“东西两条走完、整体成本差不多”只覆盖**完整执行某一路线**；不等于“中途切到西侧也能完整继承已有进度”。这一丢弃可能是有意义的沉没成本，也可能只是惩罚了不知真相、好奇探索的人；不能从数学上直接宣布应当保留。上面的计量排除道具及社交风险，绝非正式局数的证据。

## Ⅲ Exact Fraction 强反证：真实路线长度但仍非官方完整规则

[冻结Python审查](../../../../tools/content-validator/experiments/s3_real_warren_routes.py) · [GitHub Actions运行及原始JSON](https://github.com/guopanqi/ssnoir/actions/runs/38201263351)。

为了隔离“路线顺序和剩余可用动作”，采用比真实场景更窄的纸面代理：**夜莺已经加入后**剩余16行动，东/西两路线长度完整采用现有4+4，任何工作好/中/坏各有1/3概率给2/1/0进度；西侧拦路是一项单独的骰行动，简化为坏不通过、中好通过；不计真实技能差别、人物冷静、西侧不同解决方式、金牌烟物品、世界具体天数和剧情节奏；获得莱恩名字代理奖励3，认识弗兰克代理奖励2。这是作者指定效用，不是玩家情感。

| 策略/反事实 | 精确结果 |
|---|---:|
| 全自由DP | **153393848/43046721** |
| 固定先西侧，之后寻找弗兰克 | **153392248/43046721** |
| 固定先东侧，再走西侧 | **121713752/43046721** |
| 自由相对最佳固定顺序优势 | **1600/43046721**（约0.000037） |
| 西侧问出名字后不再隐藏东侧卡 | **153393848/43046721**（本模型变化0） |
| 西侧结束后，把全部东侧进度等量转入单独找弗兰克 | **153393848/43046721**（变化0） |
| 直接取消西侧拦路骰行动 | **170091232/43046721**（显著提高） |

正常最优策略路径中，相对“西侧优先”的严格偏离访问质量仅 **24401/14348907**（约0.00170 次/局的加权访问量，不是人类频率）。在东西入口均可选择时，严格应先东侧的访问质量只有 **1721/1594323**；绝大多数可达选择在这份效用代理下仍严格偏好西侧。可达反例出现在时间严重不足／已连续得到零收益的极小剩余分支，**不足以让这套路线被认证为需要高阶中途策略**。

两项“取消失去东侧进度”的直接消融**零收益**并不证明正式游戏没有此问题，恰好说明这个纸面偏好从根部几乎完全采取西侧优先，所以很少主动触碰东侧进度。若要评估老街真实体验，必须让玩家不知道哪条路线会先得到莱恩，并允许玩家出于关心弗兰克/想了解夜莺的过去而走东侧；该数学代理不能回答这种行为。

## Ⅳ 额外的信息契约反证

**玩家并不知道作者的路线答案。** 东侧卡的公开文字是夜莺换旧外套穿门廊、西侧是住户地盘与她熟悉的生活；源码中“东侧对应弗兰克、西侧对应莱恩”是作者预设，玩家不能提前读这个结果。数学自由DP甚至最佳“先西侧”固定顺序，都是用**预先知道路线结局的作者视角**选出来的。

因此，连0.000037的策略差都**不能**当作真正玩家“更善于策略”的收益。更值得研究的是：
- 玩家没有路线答案时，是否仍然能凭人物、地标和当下线索决定先走哪一侧；
- 西侧说出莱恩后立刻失去东侧的夜莺同行场景，**实际失去的是演出与人物理解机会，不只是进度**；
- 门廊已投资的烟盒/进度是否明确告诉玩家若改变路线会怎样保留，是否让人误以为已投入的东西全都能带到下一阶段。

## Ⅴ 是否升级原生 C# + Scheme？

本轮**没有新增正式原生执行证据**。现行源码已包含两条路线的实际操作，但重新演算完整世界路径还会引入正典夜莺入队、道具、冷静和不同技能与日历；为了验证一个数学上未被晋升的策略差，自动改世界阶段或编造入口属于不合适的手段。证据等级是：
- **源码静态审阅**：现有台阶/事件/关闭/物证是真的内容规则，是否实际触发请另做正式会话；
- **独立 Exact Fraction**：仅能断言冻结代理里的期望和有限模型反证；
- **真人**：没有新试玩反馈；此前R54对“换路已不可行”的批评是风险提示，不是已证明本版失败。

若下一轮确实需要玩家研究，优先在**真实当前第一章第二节**正式单会话核对：西侧桥廊完成后东侧行动是否当场消失、已有东侧门廊4格是否使自寻弗兰克起始进度2，并观察陪同/离队的叙事展示，不编造另一份游戏系统。原有 Debug 精选不扩大。

## 裁决与接续

**不晋升新机制。** 最有价值的新判断：**“知道真相的作者”与“尚不知道哪条路有效的玩家”面对的不是同一种选择问题。** 当前版本的东、西路线首先是空间探索和人物相遇次序，其次才是数学成果进度。固定先西的极高上界不代表玩家应该被教会先西；其效用取决于目前未建模的人物内容。

**下一阶段：S3-真实物证交换与玩家知识。** 看独一份烟盒在东侧可立即换两格，但在后面是否仍有实际、而非注释想象的用途；先用静态溯源及真实可达入口审查，再决定是否需要 C#+Scheme 原生对照。审查“失去人物场景”时保留夜莺第三封信/莱恩身份的正典揭示顺序。旧手稿假设模型归档为非当前规则；不要再向它追加强奖励扫描。
