# R236–R244｜从对手反应学习其规则：信息有效≠试探有价值

2026-10-12。与R228操作顺序相距较远的第二条抽象研究轴：**对手会根据玩家动作防守、甚至因成败改变防守规律**。全部规则使用A/B和隐藏二值状态，避免用“新的敌人、追击故事”包装P16/R51/R82旧结构。脚本 `tools/content-validator/experiments/r236_r244_opponent_belief.py`；CI `.github/workflows/ssnoir-r236-r244.yml`；没有SSNoir正式C#+Scheme新内容或人类试玩。

## 无剧情机制卡：玩家真实能知道什么

每局4手，玩家每手选攻击A、攻击B，或**P：只看对手防守信息、不攻击**。初始上一次玩家行动记录为A，对手内部隐藏类型为：阻挡上一次玩家选的方向（track）或阻挡反向（invert），先验各半。

每手**必须先选动作**，才有资格看到这手当前守卫实际阻挡哪边。攻击未被阻挡成功得1，被挡得0；其成败本身就让两方向之一的挡位可被反推出，**同样暴露了当手真实隐藏类型**。花一手P也会看到当前守卫，收益0。不允许先看当前守卫再选A/B。

每手反馈之后，对手隐藏类型会以公开转移概率变化，再由下一手玩家上一次选择决定下一步防守方向。分别考察：
- **完全不变的类型**（跨回合学习）；
- **每次1/4随机翻转类型**；
- **根据玩家是否成功反应**：玩家成功后3/4几率反转原规则，失败后仅1/4反转；
- **每回合1/2翻转**：上一手信息不能预测下一手。

玩家尝试的心理活动：「试探→认识对方规则→预判下个防守→尝试诱导变化」。对照R54有响应但未独立证明诱敌决策价值，本批要先问探查行动是否真的新增一个有用动作，而不是靠额外隐藏条/随机概率制造忙碌。

## R236–R244：精确结果与强反证

| 编号 | 试验 | 结论 |
|---|---|---|
| R236 | 对手隐藏规则永不变 | 完整公开反馈最优**7/2**；首手平均1/2，后3手各有把握避开 |
| R237 | 规则每回合独立按1/4几率翻转 | 最优**11/4**；后每手最高命中概率3/4 |
| R238 | 对手因玩家成功更可能翻转（3/4 vs失败1/4） | 最优仍**11/4**，但是**最强事前固定完整A/B方案也达到11/4**；“敌人会响应你”不能证明玩家在策略上真的需要学习 |
| R239 | 对手每回合以1/2几率独立翻转，彻底破坏记忆价值 | 最优**2**，最强固定也2；被动观测无先验预测效力 |
| R240 | 启用/彻底移除专门的P侦查动作 | 所有版本**完整根值相同**；在正常开局P的行动价值严格低于至少一个可攻击动作 |
| R241 | 独立前向模拟一条简单**公开可学**策略 | “首手任选A；之后由上一手命中/被挡推出旧规则，再按照较可能的下一步规则选未设防方向”，全部四版本**追平完整信念态DP** |
| R242 | 额外完整枚举2⁴条无反馈A/B攻击脚本 | 随机切换为最好2 vs有反馈11/4；但R238的响应型版本固定**11/4**已追平动态11/4，因果不等于学习价值 |
| R243 | 正常最优公开路径的两动作Q比较 | 程序报告实际前向概率质量和严格优先动作，禁止注入隐藏类型的作者特权 |
| R244 | 新颖性裁决 | 本版本仍是**已知P03信息+P16响应式防守**的很短学习规则；付费试探被普通攻击严格替代，不能单独晋升新模式 |

**特别重要的反证R238**：即使敌人按玩家成败自我调整，而且每次玩家可从反馈推断旧规则，最强预先写定四手攻击序也已经得到全部自由最优收益。在这个精确定义下，讲述“敌人会学习，因此玩家也要学会诱敌”是错误归因。

## 结论、继续研究的门槛

本研究的核心不是对手难以理解，而是确认了一个**信息行动弱支配陷阱**：如果普通行动已经免费提供完全等价的信息、又可能有正收益，那么只交信息的专门P动作缺乏存在理由。和先前R26/R77/P08的信息购买反证方向一致；不能在P动作上加一个别名救它。

这批**停止**按不同翻转概率继续刷同构状态。下一次研究真正需要问的是：**玩家若想操纵对手的信息，就必须付出不同于普通推进的机会成本或制造某种可逆误导，且在正常公开路径下自愿选择哪种动作？**应先有不依赖情景、公开可理解的机制卡与强普通攻击基线，再决定是否进行新一轮精确建模。本批没有新真人反馈、正式原生或Debug晋升；6精选/20历史候选维持原状。
