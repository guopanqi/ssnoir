# REC01—REC03｜行动改变下一行动的生产价值：从简单交替到条件重规划

2026-10-13。SSNoir长期抽象玩法模式研究；本批以[研究定位与评价](../../研究定位与评价.md)及最新队列为准。**去情景，仅A/B/临时阻塞，非正式游戏特性**。本轮先从两个相邻动作互相创造条件的决策循环着手，再以强策略、取消关键因果边、结果向量核对独立验证。不借NPC剧情、提高难度、随机层数来认证新玩法。此前同日[GOAL01/DISC01](../2026-10-13-目标生成与生产性发现/研究记录.md)处理了“主动生成目标”和“在工作中获得信息”，本批关注的是另一个轴：**先做A是否能改变下一次B的实际生产率，而不仅把B加进菜单**。

可执行、标准库Fraction、81条公开信号史穷举：[pattern_reciprocal_actions_20261013.py](../../../../tools/content-validator/experiments/pattern_reciprocal_actions_20261013.py)。它是数学规则验证，不代表真人或独立盲Agent试玩、正式引擎验证、已有成熟作品的专属机制。

## 0. 去名规则：玩家在反复决定什么？

四回合，每回合1次行动；当回合的操作阻塞公开可见，才作决定。三种情况独立发生：无阻塞概率1/2；A暂不可用概率1/4；B暂不可用概率1/4。无其他秘密、没有未来预知。合法动作：

- **A**：正常使A进度+1；如果上一手**恰是B**，本手变为A+2。
- **B**：正常使B进度+1；如果上一手**恰是A**，本手变为B+2。
- **SIDE**：即刻获得1个独立的确定成果，本手占用全部行动，同时切断此前留给A/B的余效。
- A、B各有自身进度0—4；第4回合后A进度达到3得10，B进度达到3得8；无中途兑现，不限在已满时还能操作但无法再次领取奖励。
- 上一步的生产余效是**短命的行动关系**，不是可以永久带走的钥匙，也不是随意兑换成金钱的通用代币。当前选择既获得进度，也改变下一手哪种动作效率更高。

直观心理循环：

> 看见本轮能做什么 → 想起上一手给哪种操作留下余效 → 比较现在继续累积与转用余效 → 实际推进一个目标，并改变下一手的生产条件 → 下一轮面对新的阻塞重算。

这不是“按人物进度条填点”；但是**设计上是否足够好玩仍需体验证据**。

## REC01：同一合法开局存在严格改选，不靠空降中途进度

动态规划：观察当前阻塞之后再决策，未来阻塞未知。每次行动都正经耗一手。所有3^4=81条公共阻塞序列从A/B进度皆0、上一动作为空的共同起点出发复核，求解器不偷看未来序列。

**根期望 939/64 = 14.671875**。

从开局公开为“无阻塞”或“仅B被阻塞”的情况，玩家都严格选择A，于是下一回合自然抵达(A=1,B=0,上一动作A)。此时可以出现两种正常公共结果：

- 下一回合仍无阻塞：做**B**，使用A留下的余效；当前动作的总未来最优值B是129/8=16.125，继续A仅85/8=10.625。**严格选择B**。
- 下一回合B被阻塞：此时B非法，改继续**A**（总未来值85/8=10.625），优于SIDE的35/4=8.75。

这是一种确实发生的**反馈引发重新选择**。更关键的因果消融：在完全相同的第二回合状态、无阻塞信号下，**关闭双向余效**时，继续A严格优于做B；也就是说“新想法”不是只因A/B字母名称发生变化。

## REC02：三组强解释反证

### A. 不是“多一个能切换的按钮”本身就新

在全部四手中如果永远不阻塞任何动作，固定执行A→B→A→B便可实现A/B都达完成线，总收益**18**，已经是理论上可获得的所有A/B终局奖励。无需按局势重排。去掉真实阻塞窗口时，双向余效退化为**固定交替生产节奏**。

### B. 不是仅与愚蠢的始终做A相比

同一时点/阻塞规则下，分别评估：

| 策略及对照 | 精确期望 | 与当前最优之差 |
|---|---:|---:|
| 双向余效 + 完整逐状态DP | 939/64 = **14.672** | 0 |
| **遇到可用动作便交替**：上一手A就优先B，反之优先A | 227/16 = **14.188** | 31/64 = 0.484 |
| **最强事前固定四手序列**：每手选A/B，碰阻塞就用另一种，共2^4=16条 | 801/64 = **12.516** | 69/32 = 2.156 |
| **交替规则+一手前瞻**：对本手三种候选，估计此后按上述简单交替策略的收益，选择当下期望最好的一手 | **939/64 = 14.672** | **0** |
| 取消所有跨行动余效，其它窗口/奖励不变 | 1193/128 = **9.320** | 不可当作新颖性分数 |

一个可读的**短前瞻规则已完全达到DP**。因此即使出现81种可观测信号历史、复杂轨迹、严格改选，也不能据此说玩家有了高阶策略体验。真实活动可能只是“尽量交替，有必要时稍微看一下下一手”。

这同样不表示该模式没价值：简单、容易理解、可以被剧场情境展现的生产关系本身可能有好的节奏。但需要人的无答案体验来评价，而不是数学循环代替。

### C. 余效来自哪条生产关系？不等同于更强通用加成

固定其它规则，仅修改生产余效的合法触发条件：

| 动作关系 | 根期望 |
|---|---:|
| A/B彼此使下一次对方+1（双向互惠） | **939/64 ≈ 14.672** |
| 只有A→B额外+1 | 2567/256 ≈ 10.027 |
| 只有B→A额外+1 | 2691/256 ≈ 10.512 |
| 两方向都没有余效 | 1193/128 ≈ 9.320 |
| 任何上一手生产，都令下一次任何生产+1（不限切换） | **2027/128 ≈ 15.836** |
| 只要重复上一步生产方向便额外+1 | 431/32 ≈ 13.469 |

双向关系的确是一项必要的本地因果材料，但**并非在所有同样时长/奖励模型中必然产生最高产出**。普遍的“上手做过任何工作，下次就更有效”甚至在这组数值中产出更高；它解除具体方向的要求，所以不是两者等量预算的完全同构测试，不能反过来宣称普通加成全面支配双向余效的玩法心理。

适用边界也很具体：如现场不应出现临时禁用A/B、玩家始终可固定A-B轮换，则这项结构更接近普通生产工序；如上下游的余效总能当场无额外成本通过其他操作创建，仍应与该替代动作比成本，不要刻意不给替代选项维持“双向动作”标签。

## REC03：除了最优总分，两个目标实际各得到什么？

完全相同的81条公共阻塞历史，记录真实各目标终局**是否完成**，并独立记录SIDE即时成果，得到三维结果向量（均为期望，不是三种相加的人类价值）：

| 事前策略 | P(A完成) | P(B完成) | E(SIDE成果) | 用冻结10/8/1权重计算的总期望 |
|---|---:|---:|---:|---:|
| 当前数值的动态最优 | **117/128≈91.4%** | **83/128≈64.8%** | 11/32≈0.344 | 939/64 |
| 简单交替 | 27/32≈84.4% | **23/32≈71.9%** | 0 | 227/16 |
| 最佳固定ABAB | 89/128≈69.5% | 89/128≈69.5% | 0 | 801/64 |

**动态最优比简单交替更可能完成A，却更不可能完成B。** 虽然总期望高，玩家若特别关心B，完全可能更喜欢简单交替。不能让“10点的A与8点的B”这种研究者临时设定的权重，将实际的目标取舍变成客观好坏结论。

从这里得到的不是新玩法，而是重要的**评价手段**：对于两个真正都值得关心的目标，务必同时报告各自的完成概率、丢失或沉没的投入、保住的可选动作，而不只给出一个统一的期望得分。否则数学最优会把一个人物的失利隐藏在另一个目标的高收益中。这与[STG01证人与听证](../2026-10-13-情境选择与注意力验证/研究记录.md)保留不同价值与后果的目的相呼应，但**未将剧情直接作为抽象机制选题**。

## 目前裁决及后续可证伪问题

- **保留** REC01 为**双向生产余效×临时操作阻塞**的可复用组合案例，有自然可达的严格行动改选。
- **归并** REC02：去阻塞变固定ABAB；强一手前瞻全优；单向、通用、重复加成是必要的对照族。不能另造一个精选或只为更高DP差继续加时钟。
- **新增评价原则，不新增新模式** REC03：总最优并不一定使所有目标各自更好。应使用分目标结果向量评价“是否真实兼顾”，同时保留无量纲偏好可能存在的事实。
- **待体验而不阻塞自主研究**：玩家是否从A留下的余效感觉到下一次B的价值？临时封锁是否被当作意外需要应变，还是只会惹人烦？玩家会不会只按ABAB按键，感到单调而不是双向生产？只能靠真正独立的试玩与逐手原话；本次没有此数据。
- **下一更有价值的去情景问题**：如果A留下的余效不仅让B+1，还**改变B的操作类型、结果或空间位置**，玩家会不会产生超出交替节奏的新活动？先找“用一个非固定动词修改下一个动作的语法”的最小反证、即时可见反馈、完整配置菜单等价基线。若仍只会固定按顺序，直接归并，不再扩时间/收益参数。
