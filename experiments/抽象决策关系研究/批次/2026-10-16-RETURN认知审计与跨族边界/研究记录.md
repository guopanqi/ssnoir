# RETURN-COMPREHENSION v2：完整选择可观察性、策略压缩与跨尺度体验的证据界限

日期：2026-10-16。研究性质：**协议审计 + 实验工具修复 + 跨模式独立反证视角**，不构成一项新原创玩法，也未取得真人/独立盲 Agent 的行为证据。冻结原始 RETURN 数学规则，正式 Game、六精选、Debug 不动。

## 一、从已证事实接续，而不是再扫描 K 概率

- [RETURN 源研究](../2026-10-15-世界回访与局部行动重构/研究记录.md) 的完整根 **1509/128**。接受 B 之后旧Scenario A 的动作集合发生真实变化，K 弱/强可分别让正常可达的 H0、Y=B 分支改选 CUT/LINK。
- [RETURN-MACRO](../../../../tools/content-validator/experiments/pattern_return_macro_equivalence_20261015.py) 对所有可达公开状态证明 **2 条 DECLINE 宏计划 + 9 条 ACCEPT 条件计划 = 11 条**，在冻结的期望收益上逐状态与现场决策同值。返回Scenario之后的结算信息可以压缩为六类 (A 可用、B 可用、违约) 状态。
- 支援 K 有无可见对全局期望的差值只有 **1/128**；初手 OPEN 对 GUARD 期望差只有 **5/128**，GUARD 却确保零违约。不能将“概率非零”和“玩家通常会察觉、在意”混为一谈。
- 这些是形式策略与结算规则证据，不意味着人类必须、能够或乐于执行最优宏计划。

## 二、审计发现：原观察材料实际不支持完整四阶段行为结论

[前次预注册](../2026-10-15-跨层判断可理解性审计/研究记录.md)写明需要观察 L1、W1、L2、W2 的玩家动作和结果身份，但[第一版封存卡校验工具](../../../../tools/content-validator/experiments/pattern_return_comprehension_protocol_20261015.py)有两处**研究工具边界**：

1. 七条卡各自包含固定的 start=OPEN/GUARD，所以工具实际上只能验证给定初手下的结算与覆盖，**不能记录参加者如何在 OPEN/GUARD 之间做第一手抉择**。如果主持人把这工具的开局当成受试者选的，会产生伪行为数据。
2. 调用 world_final 自动拿该局的最优最终成果；A/B/ALT/SIDE 从未由受试者逐项选。故结果只能证明**模型中什么最划算**，不能证明参加者在乎哪项成果、愿不愿放弃安全结果或是否真实转投 ALT。
3. 第一版 staged_and_macro_same 是同一 outcome 函数的双调用校验，适合验算封存卡，不是两个独立交互实现的玩家轨迹比较。未有任何实际认知数据，因此此前文件正确自报的“未有受试者”必须继续保留。

**修订原则**：不要偷偷改写已经预注册的预期效果，也不要把有缺陷的模拟过程当成七份人类实验；保留旧工具作为“给定动作的物理卡校验”，新增独立前瞻性 v2 会话工具作为潜在受试途径。

## 三、已实现：冻结事件、真实参与者选择、两种决策组织

新脚本：[pattern_return_session_20261016.py](../../../../tools/content-validator/experiments/pattern_return_session_20261016.py)。用标准库即可进行交互式文本试玩；无需正式Game或浏览器发布。

- **封存共同事件**：仍使用原七张 (Y,K,W,LINK 成败) 情况。原卡指定的 start 仅作为历史回归锚点；实际 L1 由受试者自己选 OPEN/GUARD。同一封存危险事件若选 GUARD 则 H=0，若选 OPEN 则依卡内的 H 实现。原卡的每种 LINK 结果用共享成功阈值复制历史给定开局的结果，不把它作为独立的总体随机样本。
- **S：现场分阶段**：L1 选 OPEN/GUARD；W1 看见 H、Y 后选 ACCEPT/DECLINE；L2 如果 ACCEPT 才看见 K 并选 LINK/CUT/ABANDON，否则选 MEND/KEEP；W2 看见真实需求与实际可兑现成果后，**自己选 A/B/ALT/SIDE**。
- **M：提前条件承诺**：L1 同上；W1 先选接约与否，若接受就分别填写“K 弱时做什么”和“K 强时做什么”，若拒绝就填 MEND/KEEP；L2 才公开 K 并执行已经承诺的动作，不能再改；W2 与 S 一样由受试者自由选最终成果。M 的十一条**可能计划**用结构化填写界面而非十一按钮平铺呈现，减少不必要的菜单数量差。
- 每阶段只呈现当前公开的 H/Y/K/W；统一展示真实已知概率与合法动作。受试者行动及其自由解释分别记录，不自动选择最优结局。
- 记录器仅在主持人明确执行 \`--run\` 时写入**本机路径**，没有上传或虚构受试记录。

命令：

\`\`\`bash
python3 tools/content-validator/experiments/pattern_return_session_20261016.py --selftest
python3 tools/content-validator/experiments/pattern_return_session_20261016.py --run --condition S --card 1 --output /tmp/return-S-001.json
python3 tools/content-validator/experiments/pattern_return_session_20261016.py --run --condition M --card 1 --output /tmp/return-M-001.json
\`\`\`

被试只看标准输出、作答与动作，不读脚本源码、这份研究报告或原最优政策。如果需真实严格的双盲主持，应另外提供独立封闭播放器；当前 CLI 是**可复现工具，不是盲测已经发生**。

## 五、同一研究者的独立反证视角：不能把数学等价误当体验同构

### 反证 A：所有有限期决策本来就能写成事前条件政策

M 包含所有关于未来已知公开信号 K 的条件动作，且冻结模型的收益、偏好在各时点不变。于是 S 的贝尔曼最优可以提前写成 M 的可执行条件脚本，这本身是有限期确定规则的标准性质。它削弱的是“不能提前规划”的强论断；**不能**证明人类实际能轻松写出计划，或者说两种操作顺序在人类心中没有区别。

判断应分开：
- **表达等价（policy expressiveness）**：两个版本允许实现的条件行动政策是否同集合——在本冻结模型是；
- **物理结果等价（payoff/state equivalence）**：采取同一条件行动、遇到同一封存事件是否结算一致——回归已证明；
- **认知与体验等价（cognitive/experiential equivalence）**：人在两个呈现下是否理解一样、关注一样、会主动调整一样——**完全未证**。

### 反证 B：S/M 同时改变了至少三个东西

S/M 不仅是“有无世界地图再进入场景”的界面差别，还分别改变：

1. **承诺时点**：M 在支援 K 公开之前就不可逆地提交两条条件动作；S 在看见 K 后可以重新思考。
2. **条件表达负担**：M 要一次填写两条未来可能性；S 只回答当前已发生的一个分支，认知工作量/记忆占用不同。
3. **呈现分组与目标感**：S 有先决定世界是否接 B、再处理局部旧 A 的显式阶段；M 一次把未来动作并在一起。

即使 S 更易理解，也不能仅归因为“两层组织”；可能是延迟决定或“当前只展示当下合法动作”帮助了参与者。即使 M 一样好，也只说明一次写条件计划对某些受试者有用，不说明Scenario回访设计无价值。若真正需要拆因，在先有实际观察之后再设计“同样晚选动作但不分屏”或“分屏但事前预写宏”的对照，不能用新增模型状态假装完成实验。

### 反证 C：冻结收益的最优行为可能本来就缺乏丰富体验

正常最优策略可以概述为：无风险且 Y=A，接约并尝试 LINK；无风险且 Y=B，接约，弱 K 改 CUT、强 K 做 LINK；有风险且 Y=A，拒绝并 MEND；有风险且 Y=B，接受后 CUT。W2 则面对已经可兑现的 A/B/ALT 选择更符合真需求的结果。

这是可学习的条件策略，不必然无聊，但它可能把复杂的“世界→Scenario→世界”叙述压缩成短口诀。**K 的期望价值只有 1/128**，若抽样的人没有注意到 K 带来的风险分叉，不能说他已经观察到了真实两层关系。S/M 体验差异也可能主要来自终局对 A/B/ALT 意义的自选，而非数学期望。

## 六、从其它关系族横向归纳的审计问题

不能把 RETURN 的四次画面转换直接等同于《Citizen Sleeper 2》中的多尺度注意力组织；必须看各层实际争夺哪些有限机会。已有以下研究可作为强负面对照：

- [BRIDGE](../2026-10-15-危机结果跨Scenario许可反证/研究记录.md)：局部发资格票到另一Scenario，第二次看需求虽然改变使用的票，却没有真正的 W→旧 L 再进入；只是单向状态传递。RETURN 在**动作集合**层面的返场结构更强。
- [HEDGE/保留选择权](../2026-10-15-保留选择权跨族审计/研究记录.md)：局部保留 A 后开 B 的优势依赖最早不可重开的窗口；一旦允许后期开 A，先 B 后 A 的普通串行策略压平并行优势。这提示 RETURN 同样要检查可随时重新获得资格的强正常替代。
- [PLEDGE 延迟纠正](../2026-10-15-公开声明与延迟纠正/研究记录.md)：稍后补救 B 不能消除已经给 A 造成的成本；RETURN 的 LINK 失败违约罚 2 不是简单把数字补到 A 就能抹掉，不过玩家是否在意这一损失仍无证据。
- [CUST/INV/STAKE 结果身份研究](../../研究队列.md)：不同合法终局的存在，不能替参与者声明“我想保留 A 而非换更高分的 B”。用**自由选择的结果及未提示理由**而不是最大分作为下一轮主要证据。

因此要严格区别四层：**真实可执行的反向作用**、**普通策略是否可用短政策表示**、**玩家当场是否重新规划**、**玩家是否自发在乎不可替代的后果**。它们不是同一条单向的“越复杂越好”的价值链。

## 七、下一次研究位置与停止条件

1. 先要**实际参与者的 S/M 逐时点轨迹**，至少每组有封存事件相同的可比较个案；保留原话、行动、是否发生违约、最终自主选 A/B/ALT/SIDE、是否因 K 或 LINK 反馈重新说明自己的目标。短样本只作个案解释，不宣称显著性。
2. 观察后可判别究竟是**条件计划事先填写过难**、**真实返场动作的关切**，还是**终局不同身份带来的选择**。如条件宏计划与分阶段一样被自然理解，停止推动“必须多层切屏”的形态主张。
3. 如无法获取真实参与者，**不再通过增加后到随机变量、返回次数、人物或目标数来优化这组 RETURN 数值**；横向转向另一心理活动或已发行游戏的已知Scenario，重点看资源争夺、局部不可挽回义务、玩家自发再分配注意力。
4. 保留方法性改进与失败解释在模式语言知识地图；不新增精选、不开放正式 Unity Debug、不修改任何正式 Game/剧情。

**当前证据状态：**可用于真实选择的工具与规则回归完成；真人、真正独立上下文的盲 Agent、真实故事情境中的无提示理解、是否有乐趣，全部仍为未验证。

## 八、历史用户反馈的异步校准（不是RETURN受试者）

复核 [反馈/inbox](../../反馈/inbox)：当前仅有2026-10-09的R37、R50、R54三项已有设计者反馈，[questions](../../反馈/questions)仍没有新的回答。此处仅提炼其**对设计检验标准的启发**，不当成本次RETURN的真人试玩。

- R37「压力预算」指出：高质量骰子可以直奔目标，低质量骰子转而修补危机；其有趣之处是**质量不同导致下一手关切改变**。RETURN没有此类逐手资源质量选择，不能假设玩家会自然感到相同的犹豫。
- R50「动作回声」指出原型虽有修正下一手的潜力，**却缺少清楚的时间、目标和为什么要做的说明**。因此v2互动开场需要中性写明「旧A与新B、最后只能兑现一项成果」，但不提前告诉被试接受B关闭MEND或K弱/强的最优政策。
- R54「对手追击领先目标」指出玩家可能第一手就定好目标，随后骰子资源耗尽使**理论上的改道不再现实可行**。这对RETURN的提醒是：不能只看W2仍显示A/B/ALT按钮，要同时记录真实可兑现资格、实际行动、改道是否由玩家主动选择，而不只是系统最后自动选高分。

三份历史反馈的含义是**判别实验的失败风险**，并不是人类认可/否定RETURN、偏好S还是M的证据。它们反而进一步支持先做真实自选行动的观察，而非继续给RETURN添加更多目标钟。独立脚本已补充中性目标说明。
