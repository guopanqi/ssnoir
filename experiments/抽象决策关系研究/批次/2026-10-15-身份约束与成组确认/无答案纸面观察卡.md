# CHAIN：两次调查、四个未知身份——无答案纸面观察卡（未执行）

本卡不包含最优调查起点、揭晓后的目标或已知正确策略。主持人不得同时给玩家看[完整研究记录](研究记录.md)、DP数值和对象候选的程序计算。没有招募人类，没有实际无提示试玩次数。

## 玩家版：完整规则

这里有四个人A、B、C、D和四个不同的身份0、1、2、3。**每个身份恰好属于一个人**，不存在重复身份。你知道部分候选范围：

| 人物 | 可能身份 |
|---|---|
| A | 0、1、2 |
| B | 0、1、3 |
| C | 0、2、3 |
| D | 0、1、2、3（还没有排除任何一个） |

研究员先按所有满足这些条件的完整排列**等概率随机抽一份真实答案**，但不告诉你。你有**两次调查机会**。一次调查可点名一人，研究员便准确告诉你这一个人的真实身份，耗掉一次机会；之后你可以修改关于所有人的推断，再决定第二次调查谁。两次机会结束后，请给出四个人的身份，允许标记“不确定”，不强制填完。

你可以自己使用纸笔记录候选关系和排除，不额外扣分。研究员只公布被调查那人的身份，不会告诉你其他人的猜测是否正确。所有四人的真实答案在最后一起揭示。

## 玩家记录

| 选择点 | 现在确信什么？ | 现在最想查谁？为什么？ | 调查得到的结果 | 哪些没查的人变得更确定了？ |
|---|---|---|---|---|
| 第一次 | | | | |
| 第二次 | | | | |
| 全部结束 | | | | |

主持人可问“你为什么先查这个人？”“你是怎样利用四人身份不可重复这条约束的？”“你觉得看到一人身份后，第二次还该查原先决定的人吗？”但不提示哪个对象才是理论最优。允许失败，记录其实际行动与原话。

## 独立对照组

- **A：一对一匹配**。照上述完整规则玩，允许第一手结果改变下一手调查对象。
- **B：去掉唯一性**。仍有同样候选表，但不同人**可以拥有相同身份**；每人的身份在候选中独立随机抽取。玩家仍只有两次精准调查。注意这一消融不可避免地改变完整世界集合，不能在结果中冒称两组共享完全相同的分布。
- **C：必须先写好两次调查对象**。仍然是A的一对一规则，但开局须一次性写好查哪两个人；第一手结果会知道，但第二手不得改选。其它世界分布、候选和报告精度不变。
- **D：减少公开候选限制**。可选择取消A/B/C其中一条已知限制，D仍全部允许；使用另一份预先冻结的分组世界集合，观察行动策略是否仍按同样理由成立。不要把这个变化与B、C同时施加在同一组人身上。

优先独立参与者分组；若同一人连续玩多版，必须记录顺序与学习影响，避免后一版的熟练结果冒充机制效果。

## 不要替玩家回答的体验问题

玩家是否注意查明一个身份会排除它在其他人身上的可能性？会不会先查候选最多的人，还是误认为那个人“线索太少不值得管”？得知第一手结果后会不会主动放弃之前计划的第二目标？全部识别之后是否真正知道为何四人身份已确定，还是依赖主持人的一句“你猜对了”？

比较的是**实际解题策略的理解、可解释性和重复可学性**，不是数学求解器的平均值、出招速度或研究者对人物的叙事解释。若真人把此玩法看作一次简单数独/填表，且没有任何关心的结果，那正是应记录的负面反馈。

## 成组确认另外单列

若需要验证“反馈过密会诱发猜答案”，使用与上述调查**完全分开的纸面问答**：玩家可提交一整份四人完整身份猜测，主持人仅答“是否至少三人正确”，不逐项透露；或玩家可问“某人是否为某身份”，主持人只答是/否。比较查询成本、是否主动猜测而非寻找线索。这是微型验证器实验，不是《Obra Dinn》正式三命运验证机制的复刻。

没有真人、没有可靠性评价，不加入SSNoir精选、Debug或Game。
