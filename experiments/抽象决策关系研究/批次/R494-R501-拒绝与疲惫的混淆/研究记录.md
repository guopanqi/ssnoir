# R494–R501｜一次拒绝，到底是不愿意还是没力气？

2026-10-13。延续R462自利努力与R478可信信号两条独立研究线。**没有完整人格模拟**：这里只给对方一个稳定私有取向θ=A/B（各1/2）和私有初始努力e=0/1（各1/2）。另一方会根据自己的稳定取向及实际能力自愿接受/拒绝玩家提出的A/B请求；接受会消耗一份努力。拒绝可能有两种不同原因：目标不符合它的取向，或能力已经耗尽。

## 逐回合协议与玩家操作

4次行动。玩家每回合选ASK-A、ASK-B、RESTORE或SELF。ASK-X如果θ=X且对方有努力e=1，则对方ACCEPT，玩家得3，努力变0；其余情况REFUSE，本手玩家得0。玩家每次ASK后知道接受/拒绝，不直接知道θ和e。RESTORE占一手，无得分，将其努力重新设为1；SELF占一手固定得1。RESTORE不是免费通知，也没有第二行动槽。对方从自己的持久取向选择是否接受，并受真实努力限制，但**不自主安排外部日程，不预判所有未来优惠**，只能视为最小可追踪的动机+能力模型。

| 检查 | 精确结果 |
|---|---|
| R494 | 一开局ASK-A而被拒：有概率3/4，被拒之后的三个初始状态仍可能为(A,0)、(B,0)、(B,1)，权重相等；因此拒绝无法直接证明θ=B |
| R495 | 接受/拒绝公开、四手策略可根据反馈更新，最优期望 **5** |
| R496 | 256条完全预写、不能按接受/拒绝改道的四手策略中最好 **4** |
| R497 | 禁止RESTORE：最优 **4** |
| R498 | ASK结果对玩家不公开：最优 **4**（行动仍产生相同的真实结果，但不可作为下一次选择的知识） |
| R499 | θ在开局已知、努力仍不知：最优 **6** |
| R500 | 只有初始努力已知、θ仍不知：最优 **23/4** |
| R501 | 接受每次只得2，则根最优**4**；每次得4，根最优**13/2**；主动诊断不是任意数值都值得用 |

独立可构造根最优策略：RESTORE先统一能力→ASK-A，此时ACCEPT当且仅当θ=A。接受则RESTORE、ASK-A，最终总分6；拒绝则ASK-B、SELF，最终得4；均值5。这一策略无需知道完整最优状态表便能执行。

## 裁决与边界

本实验中，玩家主动改变另一个主体的**可行动能力**，才使同一句请求转化为可辨识的情报。没有RESTORE就可能把拒绝误认为意愿；**可靠的行动实验取决于被测对象的状态，而不只是你问了什么**。它与R478的物理可验证证据有所区别：R478的证据有真实性的类型合法性，而这里是先消除一个明确干扰变量，再观察行为。

但核心可重复策略仍极简：“先恢复能力，再问一次，按接受/拒绝分叉”。无法证明存在长期的双向理解活动，归并P06恢复＋P08购买信息＋R269可干预诊断，不晋升精选与Debug。更进一步必须让另一个人自己面对私有机会、可能自愿保留努力，并让恢复/邀请对其未来真实利益造成后果；仅重复问两次并不新。脚本 `tools/content-validator/experiments/r494_r501_refusal_and_exhaustion.py`，无真人/正式引擎验证。
