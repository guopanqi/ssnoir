# S2-D 实验收束：真实选择 → 反证 → 原生 → 人类验收

更新：2026-10-12。**进行中**。冻结输入：main 在 R121 后的 S2 阶段记录、研究记忆及 feedback/inbox 的 R37/R50/R54 三份原始反馈。该文件仅是 S2 已有阶段的末段实施与接续，不新增产品 feature。

## 要解决的唯一缺口

R119 在同一次行动「新线索达到2格，主线又达到3格」使 C 刚开放就关闭；R121 虽补上一手 grace，却往往只有 C 合法。用户 R54 原始反馈强调：决定换目标时已投入太多，另外一边无法做完；R50 原始反馈强调目标与期限不清。验收不是多一个可点节点，而是**在行动结果出现后，公开可见 A/C（可能还有B），三者至少两件仍能分别兑现不同结果**。

### D1｜语义冻结与强反证

用现有六行动、两日期的三目标纸面情景，仅调整**线索揭示与主线收束的阶段顺序**：A 的调查进度达到2时停止，在玩家下一次明确选择并花一行动「截信」前不会结算主线；C「追线索」在A=2时开放，仍需2进度；B第一天需2进度。杜绝同一动作开关线索。冻结 reward A=2,B=3/2,C=2；工作0/1/2均概率1/3。必须直接禁用C、去掉C解锁门槛、去掉A收束时C关闭、去掉B当日截止，各自有精确差值。与六类固定优先级和公开状态口诀比较，不能仅用固定脚本假证复杂性。

### D2｜正常可达状态 + 双向严格选择

通过完整最优策略前向展开、唯一平手规则计算：玩家**首次看到C**时，至少存在真实路径质量 >0 且严格最优选 A 的状态，以及质量>0且严格最优选 C 的状态；B还开放时也测试它是否可严格更好。与“原R121仅C可做”直接对照；访问次数与首次机会到达概率分开。

### D3｜隔离原生会话证据

只为研究创作一个**明确不属于正式第一章**的 Scheme 研究场景，用旧 DSL，保持无需自动扫描进入 Debug。C# Session 应见证：A 调查至2后一次渲染同时有「截信」「追线索」两张合法动作；截信后关闭线索，不在消息出现时关闭；选择追线索产生C进展且保留截信可能；B在第一日仍可救，日界后不可救。以提交时最新 Content SHA 与原生 seed 标注。纸面数学奖励不是原生骰池概率，不互称相同规则。

### D4｜可读性与恢复

只给出一页人物/期限/行动/后果说明，不向真人提供最优策略；保留**需要玩家反馈**状态，不会伪装成已完成真人验证。更新S2计划、结构化记忆、状态、队列、模式库与工作台；打印证据链接、失败边界、下一次恢复动作。旧 Debug R09/R37/R54 不扩容，未成熟结构候选不晋升。
