# 玩法模式语言 · 长期知识地图（初版）

> 更新：2026-10-13。研究入口见[定位与评价](研究定位与评价.md)，执行准则见[研究 Skill](../../skills/research-mechanisms/SKILL.md)。本页是**跨批次的组合关系与边界札记**。机器可读节点/关系的权威目录为[模式语言知识地图.json](模式语言知识地图.json)，精简总览在[模式语言与证据地图](模式语言与证据地图.md)。本页不是精选名单，也不是对所有历史记录的重新认证。源记录仍是各条结论的权威。

## 1. 保存知识，不制造单向晋升漏斗

研究成果至少有五种不同身份：**成熟作品的已知用法**、**抽象研究得到的关系**、**关系组合与适用条件**、**有效的否定结论**、**等待证据的假设**。它们都应可被下一 Agent 检索、复用，不必经过“候选→精选→Debug”才能进入知识地图。

每条知识使用**正交维度**描述：

- **研究对象**：基础机制 / 决策原语 / 一段完整Scenario / 跨Scenario组织。层次不是价值等级，同一条知识可以跨层连接。
- **证据来源**：已发行游戏的设计先例、规则推理、冻结数学模型、可执行原型、正式 C#+Scheme、Agent 盲试玩、真人试玩。可以并存，明确版本和具体声称。
- **已知与未知**：决策关系是否成立、何种简单策略足以解释、可读性与体验价值、能否跨情境迁移。不要把来源、验证层级、设计建议合并成一个“可信度评分”。
- **研究状态**：已描述 / 待检验 / 结构有证据 / 观察到人类反应 / 有重要反例 / 适用范围已收窄；一条关系可以同时有正面证据与负面边界。

“精选六种”是现有工作台的有限展示视图，**其中并非六种都有真人反馈**；“历史20候选”是截至2026-10-09的有源候选快照；R510–R533等后续研究的成果不因为没有追加到两个名单就失效。不同名单的基数不能相加当作互异模式数。保留原[模式库](模式库.json)、[结构候选20](结构候选20.md)、[关系索引](关系索引.md)及[原始批次](批次)；本页建立横向连接，不搬移或改写历史记录。

## 2. 四层语言与跨层推导

| 层次 | 应问什么 | 主要知识 |
|---|---|---|
| M · Mechanics | 玩家实际能执行什么行动、接受什么结果？ | 投骰、行动数、风险、进度、资源、可见状态、钟 |
| D · Decision Primitives | 哪两种机会/代价难以兼得？本手反馈怎样改变下一手价值？ | 稳险、积累/兑现、信息/承诺、选择权、相互作用 |
| E · Scenario Patterns | 一段任务的目标图、压力和行动集合怎样随玩家行为改变？ | 危机打断、部分成果、并行/替代、重规划、目标重估 |
| A · Gameplay Architecture | 多段Scenario之间如何形成新的注意力和承诺尺度？ | 跨周期整备、世界层多问题、局部与全局嵌套 |

探索必须双向：可以自 D 组合为 E/A，也可以从成熟 E/A 拆解为 D/M。**组合后的目标不是“规则更多”，而是玩家原本的判断对象、合法行动、信息或承诺在循环中真正改变。**

## 3. 成熟作品已有的结构参考

[Citizen Sleeper 2 Scenario决策模式梳理](../../docs/研究/玩法设计/以前的部分内容2/Citizen_Sleeper_2_Scenario决策模式梳理.md)提供九种**设计抽象归纳**，不是官方分类、完整任务转录，也不是本实验的“原创九种”。它们作为有商业作品应用先例的设计素材，可直接参与组合，不以重新通过实验室求解器为前提；但具体到 SSNoir 的规则与玩家体验仍应重新验证。

| 连接轴 | 已知模式 | 研究者应检查的真正差别 |
|---|---|---|
| 目标组织 | 单目标、阶段解锁、并行 AND、替代 OR、主/额外目标 | 目标间依赖、开放窗口、完成条件是否造成注意力取舍 |
| 压力动态 | 外部竞速时钟、玩家行动累积危险、危机打断 | 危险来自什么？危机是否**改写可行动作**，还是固定缴税 |
| 结果组织 | 完成/部分成果/机会丧失、目标意义重估 | 何时可主动停止？信息是否改变玩家**想达成什么** |
| 跨时间尺度 | 能力损耗、事前准备与队伍配置 | 准备能否改变现场应对方式，而不仅是提高一个判定值 |

**证据身份**：“成熟作品存在相近设计语言”来自上述设计研究，不等于每条抽象都有经过独立受控用户实验的证据。任何具体任务细节引用需回到游戏核对。尤其目标意义重估可能主要依靠叙事认同，不应与纯数值收益改权重混为一谈。

## 5. 组合时记录“相互作用边”，而非仅计数

建议连接类型：

1. **提供条件**：D1 产生 D2 才会出现的公开状态或机会。
2. **改变价值**：D1 会改变 D2 的行动收益、失败成本或判断时点。
3. **改变合法性**：D1 开放/关闭 D2 的动作集合、目标、撤退权。
4. **竞争同一资源**：D1 与 D2 不能同时满足，但要证实不是简单高收益优先。
5. **跨尺度兑现**：一段Scenario的选择影响下一段Scenario的可行动作/目标，而非只加数值。
6. **相互压制/同构**：加入 D2 后 D1 不再有自主选择价值，或整体等价于较简单的旧模式。

仅有“AND＋压力＋额外目标”的并列标签不算新组合知识；必须给出一个**正常可达**的前后局面，指出玩家为何需要调整计划，并提出“固定修理、固定交替、先短后长”等最强反例。

## 6. 长期研究开放边界

- **当前优先**：危机是否改变行动集合、准备与现场的跨尺度关系、信息是否改变目标/承诺；三者是探索入口，不是被指定的唯一题目。
- **下一类假设**：新目标进入时是否重排注意力、短期与长期收益的冲突、对手主动回应而不是随机产压、局部计划在关卡内重构操作动词。
- **知识更新**：每完成一个问题，将“模式/组合边/条件/最强反例/证据身份/未来体验问题”加入本图或原索引；允许合并与修订，不为了数量创建编号。
- **真人校准**：只在有不能由规则验证替代的清晰体验问题时提供独立、无解答提示的最小试玩；未得到反馈时照常推进别的问题。
- **不自动变更**：模式库精选视图、Unity Debug白名单及正式剧情/内容，均不因地图加入某条记录而自动扩大。

首轮具体组合诊断见[长期研究启动：组合诊断](批次/长期研究-启动-组合诊断/研究记录.md)。
