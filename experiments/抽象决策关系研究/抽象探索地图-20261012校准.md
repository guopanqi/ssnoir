# 研究重新校准：抽象玩法形态探索地图

2026-10-12。供下一 Agent 自主选题，不是一个固定关卡计划。权威目标见[研究定位与评价](研究定位与评价.md)。本文件**不替代**历史关系索引、候选20和原始批次；它恢复探索的横向广度，防止最新的剧情情景自动成为研究方向。

## 先用「玩家做什么」描述模式

好的描述通常是一个连续变化的动词序列。例如：

- **选择哪里投入 → 某种状态因投入而改变 → 重新评估下一次投入**。
- **积累有风险的半成品 → 判断何时兑现 → 带着兑现结果进入另一段循环**。
- **观察不确定信息 → 尝试验证或利用 → 将新的认识改变成一次不可撤回的选择**。
- **在互相妨碍的行动方法间切换 → 一种方法为另一种方法制造机会/后果**。

这些是心理活动和规则关系，而不是故事或叙述修辞。三个同时出现的“重要人物”，在去名测试后仍可能只是三根相加进度条。相反，同一目标的两种操作方式也可能具有真正的新玩法结构。

## 应横向探索的不同关系族

表格是研究空间示例，已有候选只是防重复参照。每条都应先写无剧情最小原型和最强反证，不因属于表内就假定值得玩。

| 研究轴 | 玩家真正反复决定什么 | 先问的负例/已有参考 |
|---|---|---|
| **资源分配与适配** | 同样资源投向不同对象，怎样因资源性质、已投入进度和后来结果而调整归属 | P02/P04；可能只是最短目标优先 |
| **积累与兑现** | 继续增加暴露中的成果，还是花行动把它转成永久价值；下一周期如何重来 | 早期分段兑现、R17止损；可能只是固定阈值 |
| **动作互为条件/生产关系** | 做A会改变B的效果、代价或可做性，B又怎样反馈给A | 余热转用/动作回声；可能只是ABAB交替 |
| **压力与恢复的双重用途** | 当前进展如何制造未来负担，何时处理负担会反过来帮助或牺牲另一目标 | pressure/R36；可能只剩开局固定修补 |
| **信息与下注** | 逐步知道什么、已投入成果如何改变再学习的价值，何时停止收集信息 | P03/P08/R110；第一次查完即必做剩余动作则不新 |
| **限期、储存与跨周期节奏** | 哪些进度留得住、哪些窗口可主动开启，今天使用时间意味着明天什么 | P05/P07；晚开或早开可被单一流程支配 |
| **行动集合/玩法阶段的转换** | 当前做的事在下一阶段改变可用动作、技能或目标；玩家的**活动方式**有何变化 | R113/R157已做解锁；只有“又多一根进度条”则不新 |
| **反馈主体与局部对抗** | 对方如何针对玩家的行动改变威胁，玩家能否识别与利用反馈而非只承受随机数 | P16/R51；若对手只是随机生产进度则是资源补给 |
| **不可逆选择与保留选择权** | 什么时候自愿关闭一部分未来选项换取另一种操作优势 | R17/R45；无补偿承诺受未承诺策略支配 |
| **多层次注意力循环** | 小单元的执行与大单元的目标选择怎样互相影响；局部完成是否改变世界层面决策 | CS1/CS2结构启发；当两层都只是独立填钟则停止 |

不要让这张表冻结搜索边界。鼓励新假设例如：循环在几手中重构操作动词、局部目标与长期目标出现不同的优化方向、规则主动改变玩家看到的可行动作、资源同时代表生产力与暴露风险。每次都与本表/历史索引交叉避免同构。

## 一次真正的横向研究应该怎么做

1. **提出不同的循环**：先选择两三种*决策结构不相邻*的疑问，暂时不写人物、地点或剧情。每个只用1–3条最小规则和一两句话描述行动与反馈。
2. **做去名检验**：把叙事全部换成A/B、计时、成果、风险，重新描述玩家反复做的事情。若变成已知模式，立即归并历史，不靠增加复杂度抢救。
3. **找支配/低成本反证**：玩家是否固定按一个顺序必胜？是否只凭一次信息就结束？是否真能自己选择改换行动方向？当单一规则已经解释时，记录并转向另一族。
4. **深挖少数原型**：只有留下真实新判断或明显不同的动作循环，才设计可纸面/网页试玩的最小状态、数学计算与机制消融；精确模型说明假设成立，不代替感受。
5. **总结并改变探索地图**：对照已验证六精选及20历史候选，看新的解释是合并旧模式、改进旧模式还是可能开辟新玩法；汇报“可以玩的是什么”，不是“完成几轮算法”。

**阶段性判断推荐格式：**「玩法最小循环」→「一个正常局面中的具体选择」→「反馈如何使第二次判断不同」→「最强无聊策略」→「为什么这是/不是实质新玩法」→「进一步体验需要什么」。无足够证据时写“潜力假说”，而不是“发现第七/第21个模式”。

## S/R历史归位

- **S3-X香烟守恒、S3-Z人物离队**：独立的内容与正典一致性问题；数学上可用“唯一资源可前后交换”解释，但**不再是抽象研究最高优先级**。
- **R125–R130证人期限/人物连带**：抽象成“动作改变另一个选项的可达性/短窗口”；和已有期限、互斥机会对照。
- **R131–R148自主同伴/指挥**：抽象成“存在外源行动/是否值得付费提高确定性”；强简单策略和已知容量/整备关系解释多数差异。
- **R149–R173人物议程、事件新目标、双人物连锁**：只能作为“未来行动集合随外部事件条件变化”的旧纸面案例，不能将下批默认定义成增加第三个NPC或更多故事分支。
- **历史20结构候选**：保持原文件、原始证据与质量标记；不是20个通过体验验证的好模式，也不是只许研究这20种。

新的 R 编号只管理实验证据和回归，不代表找到一种新玩法；失去新颖性的方向可以当场停止，无需凑满一批数字。
