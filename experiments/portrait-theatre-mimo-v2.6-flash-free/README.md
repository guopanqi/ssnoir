# Portrait Theatre · mimo-v2.6-flash-free（立绘剧场网页实验）

模型：MiMo-V2.6-Flash Free（目录后缀 `mimo-v2.6-flash-free` 即模型名）。

独立的网页短戏实验：不依赖已有实验、不依赖构建工具，纯 HTML / CSS / 原生 JavaScript。
双击 `index.html` 即可观看，或用任意静态服务器：

```bash
cd experiments/portrait-theatre-mimo-v2.6-flash-free
python3 -m http.server 8137
# 浏览器打开 http://127.0.0.1:8137/
```

## 观看方式

- 幕布卡片点「开演」（同时解锁浏览器音频），从片段一开始。
- 点击舞台 / 空格 / 回车 / →：进入下一拍；← 上一拍（会无动画地重建到该拍）。
- 按钮与快捷键：P 暂停或继续、R 重播、M 声音开关、数字键 1–6 直接跳片段。
- 自动播放按字数留阅读时间；暂停时所有计时器（含后台舞台动作）停止，继续时按剩余时间恢复。
- 每段落幕显示「片段结束」，可重看本段或进下一段。

## 演什么

六个片段的对白、事件顺序与人物知情程度按基准剧本逐字保留，由
`tools/check-script.mjs` 对照 `tools/baseline.txt` 校验；构图、形象、姿势、道具、节奏自由编排。

1. **雨夜求助**：夜莺撑伞冒雨而来，在电铃前收伞、按 301、恳求；尼尔只有对讲机里的声音——面板在他说话时脉冲发光，明确「不在楼下」。开锁、门开、她转身进门。
2. **看见烟盒**：红色「金牌」烟盒是全场唯一饱和红；被挤变形后盒身歪斜。夜莺看完后背过身去，两步距离拉远——怀疑说不出口。
3. **隐瞒莱恩后的争执**：点烟、指问、逼近距离，再一寸寸退开；结尾她背身带路，尼尔停顿后跟上。
4. **准备离开，被叫住**：桌上放着帽子、手袋和收伞；她收东西、换上戴帽持伞的离场姿态，眼泪是两滴落下的蓝色灯珠。
5. **经理安装电话**：经理迎上、拍肩、搭肩（手臂横搭在尼尔肩线），最后转身指着工人下令。
6. **经理解雇尼尔**：同一段关系的另一面。尼尔全程沉默、低头攥帽，交接材料后从大门离开，门砰地关上，舞台随之一震。

> 每段标题即基准剧本的「片段N：…」原文。

## 舞台手段

- **纯色背景**：每幕一色，无背景图、无环境布景；地点只靠 1–2 件道具建立
  （电铃面板与门、烟盒、街灯、桌与帽伞手袋、墙上的电话与工人、剧院大门）。道具全部是霓虹灯管风格的内联 SVG。
- **人物**：`角色库` 的霓虹立绘按需生成透明素材；站位、朝向、姿势、明暗（说话者亮、其余压暗）承担关系。
- **光**：街灯光锥、桌灯暖光、门缝漏光、幕布聚光，都是分层的纯色光形，不是背景图。
- **声**：Web Audio 现场合成雨声、电铃、对讲接通、开锁、门轴、脚步、拍肩、纸张、门 slam 与电话铃；无配音、无外部音频。
- **特效**：雨线、门缝光、烟盒变形、眼泪两滴、关门震动，仅此而已。无骨骼动画、无自动镜头游走。

## 文件边界

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构与控制条 |
| `src/script.js` | 六幕拍点数据：对白、舞台指示、编排 cue 的唯一来源 |
| `src/stage.js` | 状态 → DOM 的渲染、道具 SVG、姿势与走位 |
| `src/player.js` | 拍点推进、阅读时长、暂停 / 重播 / 跳拍重建 |
| `src/audio.js` | Web Audio 合成音效 |
| `src/main.js` | 幕布、导航、说明区、键盘、舞台缩放 |
| `src/style.css` | 舞台、人物、道具、灯光、字幕、幕布样式 |
| `src/cast.js`、`assets/cast/` | 由 `tools/prepare-cast.mjs` 生成，勿手改 |
| `tools/baseline.txt` | 基准剧本原文（校验依据） |
| `tools/prepare-cast.mjs` | 黑底霓虹图 → 背景透明、内部填实黑、脚底对齐的舞台素材 |
| `tools/check-script.mjs` | 对白与舞台指示逐字校验 + 姿势 / 道具 / 音效 / 站位可解析性检查 |
| `art/` | 新增姿势的提示词与 Gemini 原图 |

## 素材

人物沿用 `角色库/人物形象设定总表.md` 的霓虹视觉契约（纯黑底、白色灯管主线、单色点缀）：
夜莺取 10 张既有姿势图，尼尔取 9 张，经理取基础图。本实验新生成 6 张：

- `art/gen/nightingale-umbrella.png` 雨中撑伞进场
- `art/gen/nightingale-ring.png` 抬手按电铃、收伞拄地
- `art/gen/nightingale-leaving.png` 戴帽、挎包、持伞的离场姿态
- `art/gen/manager-shoulder.png` 手臂横搭肩（片段五的身体接触）
- `art/gen/manager-point.png` 伸手指向工人（片段五）
- `art/gen/worker-kneel.png` 蹲姿工人剪影（次要人物，只有外轮廓）

提示词在 `art/prompts/`。`node tools/prepare-cast.mjs` 重新生成 `assets/cast/`。

## 验证

- `npm run check` = 六个 `src/*.js` 语法检查 + `tools/check-script.mjs`：
  当前结果为「6 个片段、52 句对白、18 条舞台指示与基准剧本逐字一致；26 个姿势、12 件道具、9 种音效全部可解析」。
- `npm run check-page` = Playwright 无头浏览器实测（`file://` 直接打开）：开演、六幕逐拍字幕与舞台状态、
  暂停 / 继续 / 重播、上一拍 / 下一拍跳拍重建、落幕与重看、声音开关、窄窗口等比缩放无横向溢出，
  无 console / page error；截图写入 `art/preview-*.png`。

人物立绘是本实验独立设计与编排的舞台素材，不替换正式游戏立绘。
