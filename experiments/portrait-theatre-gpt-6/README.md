# Portrait Theatre — GPT-6

独立、零依赖的网页立绘剧场实验。使用纯 HTML、CSS、JavaScript 和内嵌 SVG 立绘，按提供的六个基准片段完整演出。不存在背景图片、完整场景模型、外部字体或远程 API。

## 观看

直接打开 `index.html` 即可观看。进入页面自动从片段一开始；可播放/暂停、全文时间轴拖动、选择六幕、重播、调速。键盘：Space 暂停/继续，←/→ 快退/快进 5 秒，R 重播当前幕，M 音效。

Web Audio 合成雨声、电锁、碰肩和关门声，不添加配音。浏览器需用户首次点击音效按钮才能启用声音。

## 剧场理念

- **雨夜求助**：仅出现夜莺的立绘；尼尔用 301 电铃的声音标识在场。门口一道灯光回应她的请求。
- **看见烟盒**：唯一被放大的道具是挤变形的红色烟盒；夜莺看向它但不说出联想。
- **隐瞒莱恩后的争执**：对话中的回避、等待、前后行走表现关系裂缝；没有瞬间修复信任。
- **准备离开，被叫住**：夜莺真的朝雨伞移动；被叫住后才转回，眼泪在答应之后出现。
- **经理安装电话**：经理跨越尼尔的私人距离、碰触肩膀；工人作为静态次要立绘出现。
- **经理解雇尼尔**：沿用相同的经理形象，但调度变得有距离，最后由门关闭收束。

`script.js` 中各幕的 `base` 表示初始舞台状态，`cues` 表示对白、非对白动作、姿态和道具状态。时间线可随机跳转、暂停和恢复，舞台状态由已累计的 cue patch 确定。

## 运行 / 本地服务

可直接双击打开；也可以在当前目录执行 `python3 -m http.server 8080` 并访问 `http://localhost:8080`。

## 约束

保留原有对白、事件顺序和人物知情程度；舞台提示仅用于表现原文已有的动作与停顿；没有新对白。此实验探索有限立绘和剧场调度的表达边界，并非独立的游戏关卡或 SSNoir 客户端。
