# Portrait Theatre — GPT-6

独立、零依赖的网页立绘剧场实验。使用纯 HTML、CSS、JavaScript 和内嵌 SVG 立绘，按提供的六个基准片段完整演出。不存在背景图片、完整场景模型、外部字体或远程 API。

## 观看

直接打开 `index.html` 即可观看。进入页面自动从片段一开始；可播放/暂停、全文时间轴拖动、选择六幕、重播、调速。键盘：Space 暂停/继续，←/→ 快退/快进 5 秒，R 重播当前幕，M 音效，V 配音。

Web Audio 合成雨声、电锁、碰肩和关门声。另加入浏览器原生 Web Speech 的中文配音：夜莺、尼尔、经理可分别选择系统音色；选角面板支持试听。须主动点击「开启配音」，不能绕过浏览器自动播放限制。

## 剧场理念

- **雨夜求助**：仅出现夜莺的立绘；尼尔用 301 电铃的声音标识在场。门口一道灯光回应她的请求。
- **看见烟盒**：唯一被放大的道具是挤变形的红色烟盒；夜莺看向它但不说出联想。
- **隐瞒莱恩后的争执**：对话中的回避、等待、前后行走表现关系裂缝；没有瞬间修复信任。
- **准备离开，被叫住**：夜莺真的朝雨伞移动；被叫住后才转回，眼泪在答应之后出现。
- **经理安装电话**：经理跨越尼尔的私人距离、碰触肩膀；工人作为静态次要立绘出现。
- **经理解雇尼尔**：沿用相同的经理形象，但调度变得有距离，最后由门关闭收束。

`script.js` 中各幕的 `base` 表示初始舞台状态，`cues` 表示对白、非对白动作、姿态和道具状态。时间线可随机跳转、暂停和恢复，舞台状态由已累计的 cue patch 确定。

## 运行 / 本地服务

可直接双击打开；也可以在当前目录执行 `python3 -m http.server 8080` 并访问 `http://localhost:8080`。

## 约束

保留原有对白、事件顺序和人物知情程度；舞台提示仅用于表现原文已有的动作与停顿；没有新对白。此实验探索有限立绘和剧场调度的表达边界，并非独立的游戏关卡或 SSNoir 客户端。
## 人物配音 / Voice Casting（GPT-6 第二版）

入口：播放条中的 **开启配音** 和 **选角 / 试音**。声音通过观看者浏览器的 `speechSynthesis` API 生成，并非真人录制，无网络 TTS、密钥或额外依赖。默认按中文音色名称和声音特征尝试分别选择角色，并设定语速、音高；可以手动指定、试听。

剧本对白不变，不会朗读舞台提示。系统以 `SpeechSynthesisUtterance.onend` 为依据，在配音长于字幕时间时等待语音完成；暂停会暂停配音，跳转和重播会取消上一句。播放速度变更影响下一句台词。不同浏览器／系统的可用中文音色与朗读质量不同；无中文音色时可能需要安装语音包或更换浏览器。音轨不随网页打包，无法保证所有机器音质一致。

网页版 `index.html` 为**单文件**交付（样式、程序、立绘与配音逻辑均内嵌），可直接双击观看。
