## 首轮目视记录

- **汤米**：手枪手势和宽肩轮廓明确；没有明显踮脚，仍像稳稳站立，后续可单独强化脚尖着地与失衡感。
- **尼尔**：压帽、笔记本、创可贴和迈步都可读，风衣下摆带出运动方向。
- **夜莺**：回头姿态和礼服 S 曲线明确；手套动作没有完全按“拉下一半”呈现。
- **经理**：张臂与披衣形成宽拱，热情笑容配细眯眼；生成了烟嘴，符合造型方向。
- **艾迪**：递出两瓶琥珀酒的透视关系最强，体格与羞怯表情也成立；衣裤出现额外灰色阶，限色仍需收紧。
- **罗科**：帽檐黑影、前探姿态与卷起的纸张形成威胁感；笑容不明显，纸张更像卷纸而非折皱合同。

以上是视觉探索候选，不是正式游戏人物资源；下一轮优先修汤米的踮脚动作，并收紧艾迪与罗科的专属表演细节。
