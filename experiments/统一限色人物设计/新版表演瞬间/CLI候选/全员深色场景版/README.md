# 全员深色场景版候选

按统一“深色是底，亮线是形，暖琥珀是人气，颗粒是空气”方案生成，使用 Gemini Image Web CLI / Flash。共 10 张主候选：汤米、罗科各一张墨线版；尼尔、夜莺、经理、艾迪各一张墨线版与一张水洗版。汤米另有一张加强踮脚的修订候选。

所有版本都是独立文生图，没有上传原图做编辑；因此墨线版与水洗版是同一设计方向的候选对照，动作细节可能不同，不是同一张底稿的精确改色。画布输出为 1536×2752 JPEG、纯灰背景；不是透明资源，也不是正式接入资产。

## 目视记录

- 汤米首轮没有踮脚；修订图两脚明显抬起，读成夸张踮脚／小跳步，活泼感更强，但离真实脚尖支撑仍有距离。
- 尼尔压帽、创可贴、笔记本、迈步和风衣斜向剪影可读；水洗版风衣色块较宽，琥珀笔记本很小。
- 夜莺回望、露背礼服、半脱长手套和 S 形裙摆可读；水洗版裙摆刷痕更明显，动作的向前迈步感偏弱。
- 经理的张臂拱形、披衣、对称姿态和笑眼反差可读；水洗版在西装一侧增加了较宽的青灰刷涂。
- 艾迪递两瓶酒和厚实体格清楚；画面采用较近的上身透视，虽然两鞋完整，但并未达到“手比头还大”的极端透视。琥珀瓶面积略显突出，需结合场景确认 5% 限制。
- 罗科帽影盖住上半脸、露齿笑和合同可读；姿态前倾但身体问号剪影不算很强。

这些是视觉探索候选。下一步如需做严格同底稿 A/B、统一人物相对高度或透明化，需以所选候选另行处理和审阅。
