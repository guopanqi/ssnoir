## 处理记录

- 六张源图均为 1536×2752。输出保留原画布、原比例与完整画面，只去除均匀中性灰背景，不裁切、不缩放。
- 背景色按每张图四角估算，并根据 JPEG 背景压缩偏差去除；人物边缘用源图色板恢复少量抗锯齿透明度。源 JPEG 保留不变。
- `全员透明底预览.png` 将透明 PNG 合成到深藏青色上，便于检查灰底残留与轮廓边缘。
- 按用户指示，五张角色 PNG 已放入 `UnityClient/Assets/Resources/Portraits/Characters/`。
- 夜莺新图从深藏青底抠出背景，缩放到与原资源相同的 937×1678 画布。原图备份为 `UnityClient/Assets/Resources/Portraits/Characters/夜莺-备份.png`，备份另有独立 `.meta`；替换图沿用原夜莺资源 GUID，现有引用保持稳定。
- 该目录在 `NeonPortraitLibrary.UseNeon == false` 时读取。资源已放入 Resources，Unity 舞台运行时预览尚未执行；本次没有改动 Loader 或启用该模式。
