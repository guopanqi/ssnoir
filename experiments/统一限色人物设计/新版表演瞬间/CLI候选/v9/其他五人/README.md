## 目视记录

- 汤米首轮更像踮脚跳步；站稳修订版双脚平落，保留宽肩黑块、手枪手势和活泼显摆的神态。
- 尼尔成熟版设为三十岁出头，脸部比例和神情更稳重；压帽、创可贴、笔记本、迈步和风衣飘起都可读。
- 尼尔全黑服装修订版将帽子、风衣、裤子、领带和鞋统一压为黑色，纸色只留给脸和手、衬衫、笔记本及小块胶布；鞋子也明确为黑色，读图符合服装黑色的要求。
- 最新版改为静止站姿，双脚站稳，去掉迈步和风吹衣摆；衣服内部不再使用纸色痕迹或高光笔触，保持纯黑，纸色仅用于脸手、衬衫和笔记本。
- 最新修订改为站立抽烟：一手自然拿烟，另一手插兜，不扶帽也不拿本子。眼睛改用短线条而非点状，目光平静并朝同一方向；服装仍为纯黑，鞋也为黑色。
- 经理双臂张开和披衣形成宽拱，黑色内侧剪影清楚。
- 艾迪的递酒姿势、拳带和厚实体格可读；伸手透视不够强，手未明显大于头部。
- 罗科的驼背前探、帽檐阴影、露齿笑和卷起合同可读；合同表现为卷纸，没有显出敲掌动作。
- 五张的冷白外沿均比“4–6 像素、断续、左上侧略粗”的要求更宽、更连续，但呈硬边笔触，没有变成柔光。
