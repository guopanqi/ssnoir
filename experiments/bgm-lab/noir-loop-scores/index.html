把选中的 BGM 接进游戏

音频都在 audio/ 与 variants/ 目录下（.m4a 为压缩分发版，.wav 为无损母带， 是由 generate-bgm.mjs 重新生成的）。推荐在游戏里用 Web Audio 解码后循环——内存中的 AudioBuffer 循环是逐采样无缝的，<audio loop> 在部分浏览器会有几十毫秒的间隙。

方案一 · Web Audio（推荐，真无缝）

async function playLoop(url, volume = 0.8) {
  const ctx = new AudioContext();
  const data = await (await fetch(url)).arrayBuffer();
  const buffer = await ctx.decodeAudioData(data);
  const src = ctx.createBufferSource();
  src.buffer = buffer; src.loop = true;          // 逐采样无缝循环
  const g = ctx.createGain(); g.gain.value = volume;
  src.connect(g).connect(ctx.destination);
  src.start(); return { src, g };
}
// 切场景：旧 src.stop()，新起一次 playLoop。淡入淡出用 g.gain.linearRampToValueAtTime。

方案二 · Howler.js（省事）

new Howl({ src: ['audio/02-smoky-club.m4a'], loop: true, volume: 0.8 }).play();

方案三 · 原生 <audio>（最简单，可能有极小间隙）

<audio src="audio/01-rainy-alley.m4a" loop autoplay volume="0.8"></audio>
