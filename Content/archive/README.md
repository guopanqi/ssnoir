# archive —— 不再挂载的内容

这里的脚本**不进游戏**：`world/world.scm` 不 `load-file` 它们，`--validate` 也不会解析它们。
留在仓库里只有一个用途：**当写法参考**。要读某种结构怎么写（多路线结局、追车、潜入、
消耗品在交锋里的用法），来这里翻。

因此它们**不保证还能跑**。引擎和 DSL 会继续往前走，这里的脚本不跟。想把某一段捡回去，
按当时的 `engine.scm` 重写，不要指望原样加载。

- `world/夜莺.scm`、`world/人物/萨姆.scm`、`world/陌生人藏身处.scm`
  demo 短篇《夜莺》的三次逼近。它和第一章《三封信》讲的是同一个人、不同的故事——
  两套同时挂着只会让人分不清哪一份是真的。第一章是真的。
- `encounters/夜莺·抢人`、`夜莺·夜查`、`夜莺·警告`、`夜莺·了断`
  只能从上面那三个模块进入，跟着一起下线。
- `encounters/悬案`、`combat`、`infiltration`
  早期的结构试验，从来没有接进城市。

一并作废的还有**办案通行证**：它的消费者全在这半边，留着会让人以为它是活的。
以后真需要「程序干预」这类道具，按那时的需求重新造一件。
