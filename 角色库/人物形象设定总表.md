# 第一章人物形象设定总表

## 当前人物视觉方向（2026-10-08）

人物由**实心体块、少量明暗大面和克制描线**构成，与游戏建筑的填充及外边线相协调。纯线条 Neon 缺少实体感；彩色剪纸人物又偏离游戏气质，两者都不作为后续新设计的目标。

- 主形用深灰、石灰、蓝灰等低饱和填充建立；少量明暗面表达衣料与身体体积。
- 外轮廓优先读取，内部线只保留五官、衣领、帽檐与关键结构，不平均描满所有褶皱。
- 保持成年人的正常比例和黑色电影气质，避免大头、夸张笑脸、鲜艳肤色与卡通分件人物。
- 舞台人物仍使用完整立绘，姿势变体维持身份、比例和脚底基线。

首批尼尔、夜莺、经理的新方向实验在 `experiments/portrait-stage-lab/art/filled-cast/`；当前仅接入第三版 Web 剧场，尚未覆盖正式游戏肖像。下方 Neon 契约与 Prompt 保留为历史设计档案；身份与剪影信息仍可参考，旧的镂空与发光线要求不再约束新设计。

## 核心视觉契约（Visual Pillars）

1. **纯黑背景与镂空负空间**：统一使用纯黑底（#000000），人物内部镂空（Hollow black fill），不使用任何灰度阴影或大面积纯色色块填充。
2. **真实弯曲玻璃霓虹管为基础骨架（Bent Glass Tubes）**：所有人物的主体身形、服装折线、面部轮廓一律采用纯净、明亮的白色发光霓虹灯管线条勾勒，严禁琐碎衣服褶皱与多余内饰线。
3. **极简写意面部**：面部大面积留黑，仅用两三笔极简外轮廓（下颚、鼻梁折线）表现神韵，严禁额头纹、鱼尾纹、法令纹等细碎老化皱纹。
4. **极度克制的单色点缀**：
   - 绝不全身上色，绝不使用大面积彩色灯管。
   - 仅在人物**最具身份代表性或故事象征性的核心物件**上，赋予单一色彩的霓虹微光（如香烟火星、蓝图、警徽、麦克风等）。
5. **极高辨识度的剪影（Silhouette Recognition）**：
   - 靠体态量感、头部发型/帽子、经典肢体动作和时代道具建立第一眼识别度。
