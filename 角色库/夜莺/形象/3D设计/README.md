# 夜莺 3D 形象设计（2026-09-14）

目的：把霓虹平面立绘的夜莺翻成能进交锋场景的 3D 形体，和 `city-box/props/人形/` 的人群 canon 同一套语言（无脸、大面切割、粘土材质、只描剪影或硬边）。

- `01-三视图-canon.png`：前/侧/后/四分之三四视图。核心决定：人群靠礼帽檐在俯视里读成圆盘，夜莺靠**头发体量**当帽檐——几个大瓣的头盔状发型，俯视是一个软圆盘。无脸，斜裁长裙单锥体，不对称裙摆露一条腿，一手抵锁骨、头低侧。
- `02-机位对照.png`：45° 游戏机位、20° 低光长影，夜莺夹在两个 canon 礼帽男之间。可读性：软圆顶 vs 平圆盘、窄肩 vs 宽肩、光滑锥裙 vs 敞开外套下摆。

未定：头是否再缩（Gemini 抗拒缩头，01 比人群 canon 头大一档）；是否要第二个体态（唱歌/转身）。

## 自审与返工（2026-09-14 下午）

第一轮描线预览夜莺不过关：抬起的手臂和躯干糊成一块（四分之三视里重叠，混元连成一体），光滑形体上跑硬边描线只抓到杂线。尝试过把她也做成大面切割（04），人立刻变成家常裙主妇——**女性形体不该棱角化，这条路否掉**。

定稿做法：
- 图：05（光滑 S 身段，同 01），送混元用**正面视图**裁图（`hy-input-05front.png`），正面手臂和身体之间有缝。
- 模：`夜莺05-geo.fbx` → `夜莺05-medium.fbx` 4078 面，两条手臂都独立。
- 描线：夜莺 `outline="hull"`（只描剪影），尼尔 `hard_edges`。预览 `06-描线预览-v2.png`。
- 遗留：无脸的"脸"是个楔子，正面近看像鸟嘴；游戏机位下只是一个下巴尖，先不管。

## 带色描线（2026-09-14）

`pipeline/outline.py` 新增对象属性 `line_hex`：线/壳按颜色单独建材质（`M_描线_壳_<hex>`），FBX 自带材质描述带进 Unity。
试过按亮度补偿发光——Unity 没开 Bloom，超过白点就被压成白线，色相全丢；改成最亮通道封顶 1.25。
比过 #5A78FF（霓虹立绘取样的蓝）和 #9FB4FF（浅蓝）：浅蓝几乎就是白，定 #5A78FF。预览 `07-描线预览-带色.png`。
带色线比白线暗一档是物理事实，接受；反而正好把"特别角色"和主角/人群分了层。
