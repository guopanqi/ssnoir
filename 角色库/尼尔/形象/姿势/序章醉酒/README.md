# 序章醉酒姿势

依据尼尔已有软帽、便装夹克形象，通过 make-images / Gemini Image Web 生成一张四姿势图；上排醉站、醉行，下排扶墙、摸钥匙。完整提示词、候选图和生成记录保留在此目录。房东候选和修订稿见 `角色库/房东/形象`。

`加工.py` 去除色键背景、清除边缘杂色，将四个等大格子按同一倍率放入 1024 方形画布，鞋底落在 y=1000；不按各姿势的总高度独立放大。房东另用相同地面基线，保留较矮身形。生成实际资源及遮挡轮廓后，运行 `tools/portrait-neon/process.py` 生成描线数据，再将 `.neon.json` 的 ground 设置为 1000/1024。历史 Neon 路径沿用，图片使用真实 RGBA 透明度和填充体块。

正式资源：`尼尔_醉站`、`尼尔_醉行`、`尼尔_扶墙`、`尼尔_摸钥匙`、`房东_抱臂`。两场同景深绘制均为 308×308，入门时缩小只用于表达后退景深。剧场参考 Claude 的 `07-tavern-exit.js` 与 `08-landlord.js`；日期、状态和房租仍由主线处理。

灰度修订采用 `四姿势-灰度修订.png`：压暗填充并去除偏蓝颜色，保持原图姿势与比例。两段演出的人物 brightness 统一为 .9，减少中灰体块抢眼；不逐姿势补偿。`四姿势-修订.png` 为动作尝试候选，未采用。
