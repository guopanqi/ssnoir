# 序章描线姿势

正式原图为 `四姿势-描线.png`，上排醉站、醉行，下排扶墙、摸钥匙。房东使用 `角色库/房东/形象/抱臂-描线.png`。内部纯黑，仅轮廓和必要动作结构用灰白描线。其余填充图和灰度修订图都是被否定的制作候选，不再用于运行时。

`加工.py` 按同一倍率拆分四格，保留头身尺度，鞋底统一 y=1000/1024。运行时主图沿用已有尼尔的灰度转透明导入（grayScaleToAlpha=1，alphaIsTransparency=0）；身体遮挡由独立完整 silhouette 处理，不能把主图内部导入成灰色实体。描线数据由 `tools/portrait-neon/process.py` 生成，ground=1000/1024。

两场同景深人物均按 308×308 绘制，取消此前统一压暗 brightness 的补偿。生成原图、实际资源和真实 Unity 舞台预览都要检查，不以能加载或能播放代替风格验收。
