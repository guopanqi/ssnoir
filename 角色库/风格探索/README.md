# 风格探索 · 立绘对话画风

三人物（夜莺 / 艾迪 / 汤米）× 五画风的立绘候选样本，Gemini 网页（Nano Banana 2）生成，供对话立绘画风选择比较。

- 命名：`<人物>_<风格>.png`，A 简化漫画线 / B 手绘颗粒感 / C 粗黑白木刻 / E 线描淡彩 / F 赛璐珞网点。
- 配色口径：统一深蓝黑夜景底、象牙白/钨丝琥珀暖光，与游戏城市夜景一致；背景纯色无环境物。
- 取景：全身含双脚立绘，居中，面向观众略偏，面部可读，便于对话界面近景裁切。
- 提示词：`*_prompt.txt` 为各图完整提示词；`_make_prompts.py` 为提示词合成脚本，改脚本可整批重生成。
