# 姿势立绘重制：沿用基础图尺度

旧姿势图混用截腿、全身和坐姿的取景，并被重新撑满画布；基础图统一后，换姿势仍会出现人物大小跳变。本轮用 Gemini Image Web 编辑当前标准基础图，重制全部正式姿势，保留人物身份和现有画风。

只上传基础立绘作为尺度与身份参考，旧姿势以文字描述动作。双参考试作会被旧姿势的大取景带偏，贝恩斯的首张试作因此拒收；`立定-02.png` 为通过审阅的候选。标准画布1024×1024，统一物理绘制尺度，站立脚底约y=1000；坐姿、弯腰、奔跑不重新撑满，不要求人物可见高度相同。

各人物目录保存生成图与提示词。生成对话、输入哈希及原始返回文件由CLI保存在`tmp/gemini-image-web/`。`制作基准.json`记录通过审阅的工程资源、参考图和实际接地位置；这不是运行时缩放补偿，不含逐人大小修正。

接入时保留原PNG的资源名和GUID，重建线稿、点缀、骨架与遮挡；所有姿势尺寸都在图片制作阶段统一，不修改剧本来调大调小人物。

## 已接入范围

共26张：贝恩斯5张、夜莺9张、尼尔9张、码头工人奔跑、酒客甲瘫坐、酒客乙半躺。每张都从同角色的正式基础图生成，未调用Tripo。`同尺度验收.png`保留完整画布用于成组审阅，坐姿与半躺的人体尺寸按头部和躯干比较，不强求总高度相同。

原图及线稿、点缀、骨架、遮挡同步接入正式Resources；没有逐人物或逐姿势的运行时缩放修正。

26套资源通过源文件哈希、原图/线稿/点缀/遮挡的1024画幅、骨架与接地点一致性检查；`./run --test-theatre`通过。贝恩斯街头入口导出69个关键帧并审阅立定、低踢和换回立定，`贝恩斯街头-对照.png`对应截图中的瘦子对白拍。该图为离线构图预览，不包含真实城市背景、GPU灯效或玩家输入；未运行游戏Play Mode验证。
