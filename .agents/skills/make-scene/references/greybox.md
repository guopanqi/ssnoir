# 灰盒

`prefabs/src/<名>.py`：Blender 后台脚本，原语（`mesh_obj / add_box / add_cyl / box / empty`）从 `pipeline/greybox.py` import，一个顶层集合 = 场景名。模板看 `prefabs/src/巷子里在打人.py`（小）和 `prefabs/src/晚宴.py`（大、带生成道具）。

## 坐标与尺度

- 原点在地面中心，`Z=0` 是地面，米制。长轴沿 +Y，镜头在 -Y 一侧向 +Y 看；朝镜头那面墙按等轴剖切惯例只留护墙板高（`LOW_H ≈ 1.4`），远墙和侧墙全高。
- 集合属性 `footprint = [x, y]`（外接矩形，含露台等外挂部分）；不居中时加 `footprint_offset`。
- 把常量放在文件头（`W, L, WALL_H, LOW_H, BAR_Y, TERRACE_W …`），布局改动只动常量。

## 搭法

- 先结构（地、墙、台阶、柱、窗洞），再大件家具（吧台、卡座、舞台），再小件（椅、桌、花瓶）。每一层跑一次 `blender -b --python pipeline/preview.py -- <名>` 看图。
- 家具用小函数（`booth()`、`armchair()`、`bistro_set()`…）返回一个对象，参数是位置和朝向。这些占位体日后会被生成模型替换，但**先用它们把布局定下来**，别一上来就等模型。
- 弧形（圆桌、半环卡座、弧形台阶）用 `add_cyl(seg=12–24)` 或分段方块；现行描线会给弧面出剪影线，段数不用太高。
- 圆柱要沿 X/Y 躺倒（拱窗顶）时用带 `axis=` 的 `add_cyl`，不要旋转整个 bmesh（会把已加的方块一起转歪）。
- 场景放在台上的东西（钢琴在乐池台上）记得给 z；生成模型脚底归零，不会自己找台面。

## 审图

单体预览用 `Camera_<名>`（就是游戏机位）看：主要分区是否都在画面里、有没有被前景墙/柱挡住、镜头是否太低（吊灯、台口楣挡视线就抬高）。左墙挡住露台或卡座 → 剖切到 `LOW_H`。

## 来自晚宴

- 镜头先高后退：吊灯、台口楣压住画面就抬高；要一屏收下整厅带露台，机位在 z≈33、-L/2-26。
- 靠墙的大件离墙半米，否则壁柱和窗框会挡掉正面。
